24.6 — 向派生类添加新功能

● 机器译文 课程 24.6 查看英文原文

在 继承简介 课程中，我们提到使用派生类最大的好处之一是能够重用已编写的代码。你可以继承基类的功能，然后添加新功能、修改现有功能或隐藏不需要的功能。在本课及接下来的几课中，我们将更详细地了解如何完成这些操作。

首先，让我们从一个简单的基类开始：

#include <iostream>

class Base
{
protected:
    int m_value {};

public:
    Base(int value)
        : m_value { value }
    {
    }

    void identify() const { std::cout << "I am a Base\n"; }
};

现在，让我们创建一个继承自 Base 的派生类。因为我们希望派生类能够在实例化派生对象时设置 m_value 的值，所以我们将让 Derived 构造函数在初始化列表中调用 Base 构造函数。

class Derived: public Base
{
public:
    Derived(int value)
        : Base { value }
    {
    }
};

向派生类添加新功能

在上面的例子中，由于我们可以访问 Base 类的源代码，如果需要，我们可以直接向 Base 添加功能。

有时我们可能可以访问基类，但不想修改它。考虑这样一种情况：你刚刚从第三方供应商那里购买了一个代码库，但需要一些额外的功能。你可以向原始代码添加内容，但这并不是最佳解决方案。如果供应商向你发送更新怎么办？你的添加内容要么会被覆盖，要么你必须手动将它们迁移到更新中，这既耗时又有风险。

或者，有时甚至不可能修改基类。考虑标准库中的代码。我们无法修改标准库中的代码。但我们可以继承这些类，然后向派生类添加我们自己的功能。对于第三方库也是如此，你只获得了头文件，但代码是预编译的。

无论哪种情况，最好的答案是派生你自己的类，并向派生类添加你需要的功能。

Base 类的一个明显遗漏是缺少让公有成员访问 m_value 的方式。我们可以通过在 Base 类中添加一个访问函数来解决这个问题——但为了示例，我们将把它添加到派生类中。由于 m_value 在 Base 类中被声明为 protected，Derived 可以直接访问它。

要向派生类添加新功能，只需像平常一样在派生类中声明该功能：

class Derived: public Base
{
public:
    Derived(int value)
        : Base { value }
    {
    }

    int getValue() const { return m_value; }
};

现在，公有成员可以在 Derived 类型的对象上调用 getValue() 来访问 m_value 的值。

int main()
{
    Derived derived { 5 };
    std::cout << "derived has value " << derived.getValue() << '\n';

    return 0;
}

这会产生以下结果：

derived has value 5

虽然可能很明显，但 Base 类型的对象无法访问 Derived 中的 getValue() 函数。以下代码无法工作：

int main()
{
    Base base { 5 };
    std::cout << "base has value " << base.getValue() << '\n';

    return 0;
}

这是因为 Base 中没有 getValue() 函数。函数 getValue() 属于 Derived。由于 Derived 是一个 Base，Derived 可以访问 Base 中的内容。然而，Base 无法访问 Derived 中的任何内容。
