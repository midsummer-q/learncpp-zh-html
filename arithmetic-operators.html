6.2 — 算术运算符

● 机器译文 课程 6.2 查看英文原文

一元算术运算符

有两个一元算术运算符：正号（+）和负号（-）。提醒一下，一元运算符是只接受一个操作数的运算符。

运算符符号形式操作
一元正号++xx 的值
一元负号--xx 的相反数

浮点类型的 一元负号 运算符返回操作数乘以 -1 的结果。换句话说，如果 x = 5，那么 -x 就是 -5。

浮点类型的 一元正号 运算符返回操作数的值。换句话说，+5 是 5，+x 是 x。通常你不需要使用这个运算符，因为它是多余的。它被添加主要是为了与 一元负号 运算符。

为了可读性，这两个运算符都应该紧挨着操作数前面（例如 -x，而不是 - x)。

不要混淆 一元负号 运算符与 二元减法 运算符，它们使用相同的符号。例如，在表达式 x = 5 - -3;中，第一个减号是 二元减法 运算符，第二个是 一元负号 运算符。

二元算术运算符

有 5 个二元算术运算符。二元运算符是接受左操作数和右操作数的运算符。

运算符符号形式操作
加法+x + yx 加 y
减法-x - yx 减 y
乘法*x * yx 乘以 y
除法/x / yx 除以 y
取余%x % yx 除以 y 的余数

加法、减法和乘法运算符的工作方式与现实生活一样，没有任何注意事项。

除法和取余需要一些额外的解释。我们将在下面讨论除法，在下一课中讨论取余。

整数除法和浮点数除法

最容易将除法运算符视为有两种不同的“模式”。

如果其中一个（或两个）操作数是浮点数值，那么 除法运算符 执行浮点数除法。 浮点数除法 返回一个浮点数值，并保留小数部分。例如， 7.0 / 4 = 1.75， 7 / 4.0 = 1.75、和 7.0 / 4.0 = 1.75与所有浮点算术运算一样，可能会发生舍入误差。

如果两个操作数都是整数， 除法运算符 则执行整数除法。 整数除法 会丢弃任何小数部分并返回一个整数值。例如， 7 / 4 = 1 因为结果的小数部分被丢弃了。类似地， -7 / 4 = -1 因为小数部分被丢弃了。

使用 static_cast<> 对整数进行浮点除法

这就引出了一个问题——如果我们有两个整数，并且希望在不丢失小数部分的情况下进行除法，该怎么做呢？

在课程 4.12 -- 类型转换与static_cast简介，我们展示了如何使用 static_cast<> 运算符将 char 转换为整数，以便它打印为整数而不是字符。

我们可以类似地使用 static_cast<> 将整数转换为浮点数，以便进行 浮点除法 而不是 整数除法。考虑以下代码：

#include <iostream>

int main()
{
    constexpr int x{ 7 };
    constexpr int y{ 4 };

    std::cout << "int / int = " << x / y << '\n';
    std::cout << "double / int = " << static_cast<double>(x) / y << '\n';
    std::cout << "int / double = " << x / static_cast<double>(y) << '\n';
    std::cout << "double / double = " << static_cast<double>(x) / static_cast<double>(y) << '\n';

    return 0;
}

这会产生以下结果：

int / int = 1
double / int = 1.75
int / double = 1.75
double / double = 1.75

上述说明，如果任一操作数是浮点数，结果将是浮点除法，而不是整数除法。

除以 0 和 0.0

除数为 0 的整数除法将导致未定义行为，因为结果在数学上是未定义的！

#include <iostream>

int main()
{
	constexpr int apples { 12 };
	std::cout << "You have " << apples << " apples. Enter how many people to divide them between: ";
	int x {};
	std::cin >> x;

	std::cout << "Each person gets " << apples / x << " whole apples.\n"; // apples 和 x 是 int，所以这是整数除法

	return 0;
}

如果你运行上述程序并输入 0，你的程序很可能会崩溃。尽管试试，它不会损害你的计算机。

除以浮点值 0.0 的结果是由实现定义的（即行为由编译器/架构决定）。在支持 IEEE754 浮点格式的架构上，结果将是 NaN 或 Inf。在其他架构上，结果很可能是未定义行为。

相关内容

我们在 NaN 和 Inf 在课程 4.8 -- 浮点数。

你可以通过运行以下程序并输入 0 或 0.0：

#include <iostream>

int main()
{
	constexpr int apples { 12 };
	std::cout << "You have " << apples << " apples. Enter how many servings of apples you want: ";

	double d {};
	std::cin >> d;

	std::cout << "Each serving is " << apples / d << " apples.\n"; // d 是 double，所以这是浮点数除法

	return 0;
}

来查看你的程序的行为。

运算符符号形式操作
加法赋值+=x += y将 y 加到 x
减法赋值-=x -= y从 x 中减去 y
乘法赋值*=x *= y将 x 乘以 y
除法赋值/=x /= y将 x 除以 y
取余赋值%=x %= y将 x / y 的余数放入 x

到目前为止，当你需要给变量加 4 时，你可能已经这样做了：

x = x + 4; // 将 x 的现有值加 4

这可行，但有点笨拙，并且需要两个运算符（operator+ 和 operator=）来执行。

因为编写像 x = x + 4 这样的语句非常常见，所以 C++ 为了方便提供了五个算术赋值运算符。不必编写 x = x + 4，你可以写 x += 4。而不是 x = x * y，你可以写 x *= y。

因此，上述代码变为：

x += 4; // 将 x 的现有值加 4

修改性运算符与非修改性运算符

能够修改其某个操作数值的运算符非正式地称为 修改性运算符。在 C++ 中，大多数运算符是非修改性的——它们仅使用操作数来计算并返回一个值。然而，有两类内置运算符会修改其左操作数（同时返回一个值）：

  • 赋值运算符，包括标准赋值运算符（=）、算术赋值运算符（+=， -=， *=， /=、和 %=）和位赋值运算符（<<=， >>=， &=， |= 和 ^=)。
  • 递增和递减运算符（++ 和 -- ）。我们在课程 6.4 -- 自增/自减运算符和副作用。

中讨论它们。此列表不包括运算符 ==， !=， <=、和 >=，因为这些是非修改性的关系（比较）运算符（ = 表示“等于”）。我们在课程 6.7——关系运算符与浮点数比较。

进阶读者

中讨论它们。重载运算符可以被重新定义为与内置运算符不同的行为，这可能包括修改左操作数，即使内置版本不这样做（反之亦然）。例如，用于输出的重载版本 operator<< 会修改其左操作数（输出流对象）。
