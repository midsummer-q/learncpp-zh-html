16.7 — 数组、循环和符号挑战解决方案

● 机器译文 课程 16.7 查看英文原文

在课程 4.5 -- 无符号整数，以及为什么要避免使用它们，我们注意到通常更倾向于使用有符号值来表示数量，因为无符号值的行为可能出人意料。然而，在课程 16.3 -- std::vector 和无符号长度与下标问题中，我们讨论了 std::vector （以及其他容器类）如何使用无符号整型 std::size_t 作为长度和索引。

这可能导致如下问题：

#include <iostream>
#include <vector>

template <typename T>
void printReverse(const std::vector<T>& arr)
{
    for (std::size_t index{ arr.size() - 1 }; index >= 0; --index) // index 是无符号的
    {
        std::cout << arr[index] << ' ';
    }

    std::cout << '\n';
}

int main()
{
    std::vector arr{ 4, 6, 7, 3, 8, 2, 1, 9 };

    printReverse(arr);

    return 0;
}

这段代码首先反向打印数组：

9 1 2 8 3 7 6 4

然后表现出未定义行为。它可能打印垃圾值，或者导致程序崩溃。

这里有两个问题。首先，我们的循环执行条件是 index >= 0 （换句话说，只要 index 为正），当 index 为无符号时，该条件始终为真。因此，循环永远不会终止。

其次，当我们递减 index 且其值为 0时，它会回绕到一个很大的正值，然后我们在下一次迭代中用这个值来索引数组。这是一个越界索引，会导致未定义行为。如果向量为空，我们也会遇到同样的问题。

虽然有很多方法可以解决这些具体问题，但这类问题很容易引发 bug。

使用有符号类型作为循环变量更容易避免此类问题，但也有其自身的挑战。以下是使用有符号索引的上述问题版本：

#include <iostream>
#include <vector>

template <typename T>
void printReverse(const std::vector<T>& arr)
{
    for (int index{ static_cast<int>(arr.size()) - 1}; index >= 0; --index) // index 是有符号的
    {
        std::cout << arr[static_cast<std::size_t>(index)] << ' ';
    }

    std::cout << '\n';
}

int main()
{
    std::vector arr{ 4, 6, 7, 3, 8, 2, 1, 9 };

    printReverse(arr);

    return 0;
}

虽然这个版本按预期工作，但由于添加了两个 static_cast，代码显得杂乱。 arr[static_cast<std::size_t>(index)] 尤其难以阅读。在这种情况下，我们以显著的可读性代价换来了安全性的提升。

这是另一个使用有符号索引的例子：

#include <iostream>
#include <vector>

// 计算 std::vector 中平均值的函数模板
template <typename T>
T calculateAverage(const std::vector<T>& arr)
{
    int length{ static_cast<int>(arr.size()) };

    T average{ 0 };
    for (int index{ 0 }; index < length; ++index)
        average += arr[static_cast<std::size_t>(index)];
    average /= length;

    return average;
}

int main()
{
    std::vector testScore1 { 84, 92, 76, 81, 56 };
    std::cout << "The class 1 average is: " << calculateAverage(testScore1) << '\n';

    return 0;
}

用 static_cast 使代码变得杂乱，这非常糟糕。

那么我们应该怎么做？这是一个没有理想解决方案的领域。

这里有很多可行的方案，我们将按照从我们认为最差到最好的顺序呈现。你可能会在别人编写的代码中遇到所有这些方案。

作者注

虽然我们将以 std::vector为背景进行讨论，但所有标准库容器（例如 std::array）的工作方式类似，并且面临相同的挑战。以下讨论适用于其中任何一个。

保持有符号/无符号转换警告关闭

如果你想知道为什么有符号/无符号转换警告通常默认关闭，这个主题就是关键原因之一。每次我们使用有符号索引对标准库容器进行下标操作时，都会生成一个符号转换警告。这会迅速填满你的编译日志，淹没可能真正合法的警告。

因此，避免处理大量有符号/无符号转换警告的一种方法是直接保持这些警告关闭。

这是最简单的解决方案，但我们不推荐这样做，因为这也将抑制可能引发 bug 的合法符号转换警告的生成。

使用无符号循环变量

许多开发者认为，既然标准库数组类型设计为使用无符号索引，那么我们就应该使用无符号索引！这是一个完全合理的立场。我们只需要格外小心，避免因此遇到有符号/无符号不匹配的问题。如果可能，避免将索引循环变量用于除索引以外的任何用途。

如果我们决定采用这种方法，那么应该使用哪种无符号类型呢？

在课程 16.3 -- std::vector 和无符号长度与下标问题中，我们注意到标准库容器类定义了嵌套类型别名 size_type，这是一种用于数组长度和索引的无符号整型。 size() 成员函数返回 size_type、和 operator[] 使用 size_type 作为索引，因此使用 size_type 作为索引类型在技术上是最一致且最安全的无符号类型（因为它适用于所有情况，即使在极少数情况下 size_type 不是 size_t时也是如此）。例如：

#include <iostream>
#include <vector>

int main()
{
	std::vector arr { 1, 2, 3, 4, 5 };

	for (std::vector<int>::size_type index { 0 }; index < arr.size(); ++index)
		std::cout << arr[index] << ' ';

	return 0;
}

然而，使用 size_type 有一个主要缺点：因为它是嵌套类型，要使用它，我们必须显式地在其名称前加上容器的完整模板化名称（这意味着我们必须输入 std::vector<int>::size_type 而不是仅仅 std::size_type）。这需要大量输入，难以阅读，并且因容器和元素类型而异。

当在函数模板内部使用时，我们可以使用 T 作为模板参数。但我们还需要在类型前加上 typename 关键字成为常量：

#include <iostream>
#include <vector>

template <typename T>
void printArray(const std::vector<T>& arr)
{
	// 依赖类型需要 typename 关键字前缀
	for (typename std::vector<T>::size_type index { 0 }; index < arr.size(); ++index)
		std::cout << arr[index] << ' ';
}

int main()
{
	std::vector arr { 9, 7, 5, 3, 1 };

	printArray(arr);

	return 0;
}

如果你忘记 typename 关键字，你的编译器可能会提醒你添加它。

进阶读者

任何依赖于包含模板参数的类型名称被称为 依赖名称。依赖名称必须加上关键字 typename 前缀才能用作类型。

在上面的例子中， std::vector<T> 是一个带有模板参数的类型，因此嵌套类型 std::vector<T>::size_type 是一个依赖名称，必须加上 typename 前缀才能用作类型。

你可能会偶尔看到数组类型被别名化，以使循环更易读：

    using arrayi = std::vector<int>;
    for (arrayi::size_type index { 0 }; index < arr.size(); ++index)

一个更通用的解决方案是让编译器为我们获取数组类型对象的类型，这样我们就不必显式指定容器类型或模板参数。为此，我们可以使用 decltype 关键字，它返回其参数的类型。

    // arr 是某种非引用类型
    for (decltype(arr)::size_type index { 0 }; index < arr.size(); ++index) // decltype(arr) 解析为 std::vector<int>

然而，如果 arr 是引用类型（例如，通过引用传递的数组），上述方法不起作用。我们需要先从 arr：

template <typename T>
void printArray(const std::vector<T>& arr)
{
	// arr 可以是引用或非引用类型
	for (typename std::remove_reference_t<decltype(arr)>::size_type index { 0 }; index < arr.size(); ++index)
		std::cout << arr[index] << ' ';
}

中移除引用。不幸的是，这不再非常简洁或容易记忆。

因为 size_type 几乎总是 size_t的typedef，许多程序员干脆跳过使用 size_type ，直接使用更容易记忆和输入的 std::size_t ：

    for (std::size_t index { 0 }; index < arr.size(); ++index)

除非你使用自定义分配器（你可能不会），我们认为这是一个合理的方法。

使用有符号循环变量

尽管这使得使用标准库容器类型稍微困难一些，但使用有符号循环变量与我们代码其余部分采用的最佳实践一致（倾向于使用有符号值表示数量）。我们越能一致地应用最佳实践，总体错误就越少。

如果我们要使用有符号循环变量，需要解决三个问题：

  • 我们应该使用哪种有符号类型？
  • 以有符号值获取数组长度
  • 将有符号循环变量转换为无符号索引

我们应该使用哪种有符号类型？

这里有三个（有时四个）好的选项。

  1. 除非你处理非常大的数组，使用 int 应该没问题（特别是在int为4字节的架构上）。 int 是我们默认用于所有事情的有符号整数类型，当我们不关心具体类型时，这里也没有理由不同。
  2. 如果你处理非常大的数组，或者想更谨慎一些，可以使用名称奇怪的 std::ptrdiff_t。这个typedef通常用作 std::size_t。
  3. 因为 std::ptrdiff_t 的有符号对应物。名称奇怪，另一个好方法是定义你自己的索引类型别名：
using Index = std::ptrdiff_t;

// 使用索引的示例循环
for (Index index{ 0 }; index < static_cast<Index>(arr.size()); ++index)

我们将在下一节展示一个完整的例子。

定义自己的类型别名还有一个潜在的未来好处：如果C++标准库将来发布一种设计用作有符号索引的类型，那么可以轻松地修改 Index 以别名该类型，或者查找/替换 Index 为该类型的名称。

  1. 在可以从初始化器推导出循环变量类型的情况下，可以使用 auto 让编译器推导类型：
    for (auto index{ static_cast<std::ptrdiff_t>(arr.size())-1 }; index >= 0; --index)

在C++23中， Z 后缀可用于定义与 std::size_t 对应的有符号类型的字面量（可能是 std::ptrdiff_t)：

    for (auto index{ 0Z }; index < static_cast<std::ptrdiff_t>(arr.size()); ++index)

以有符号值获取数组长度

  1. 在C++20之前，最好的选择是将 static_cast 的返回值 size() 成员函数或 std::size() 转换为有符号类型：
#include <iostream>
#include <vector>

using Index = std::ptrdiff_t;

int main()
{
    std::vector arr{ 9, 7, 5, 3, 1 };

    for (auto index{ static_cast<Index>(arr.size())-1 }; index >= 0; --index)
        std::cout << arr[static_cast<std::size_t>(index)] << ' ';

    return 0;
}

这样，由 arr.size() 返回的无符号值将被转换为有符号类型，因此我们的比较运算符将有两个有符号操作数。并且由于有符号索引在变为负数时不会溢出，我们不会遇到使用无符号索引时出现的回绕问题。

这种方法的缺点是使循环变得杂乱，难以阅读。我们可以通过将长度移出循环来解决这个问题：

#include <iostream>
#include <vector>

using Index = std::ptrdiff_t;

int main()
{
    std::vector arr{ 9, 7, 5, 3, 1 };

    auto length{ static_cast<Index>(arr.size()) }; 
    for (auto index{ length-1 }; index >= 0; --index)
        std::cout << arr[static_cast<std::size_t>(index)] << ' ';

    return 0;
}
  1. 在C++20中，使用 std::ssize()：

如果你想要更多证据表明C++设计者现在认为有符号索引是正确的方式，请考虑在C++20中引入的 std::ssize() 该函数以有符号类型（可能是 ptrdiff_t)。

#include <iostream>
#include <vector>

int main()
{
    std::vector arr{ 9, 7, 5, 3, 1 };

    for (auto index{ std::ssize(arr)-1 }; index >= 0; --index) // std::ssize 在 C++20 中引入
        std::cout << arr[static_cast<std::size_t>(index)] << ' ';

    return 0;
}

将有符号循环变量转换为无符号索引

一旦我们有了有符号循环变量，当我们尝试将该有符号循环变量用作索引时，就会遇到隐式符号转换警告。因此，我们需要某种方法将我们的有符号循环变量转换为无符号值，以便在打算将其用作索引的地方使用。

  1. 明显的选择是将有符号循环变量静态转换为无符号索引。我们在前面的示例中展示了这一点。不幸的是，我们需要在每次对数组进行下标操作时都这样做，这使得数组索引难以阅读。
  2. 使用短名称的转换函数：
#include <iostream>
#include <type_traits> // for std::is_integral and std::is_enum
#include <vector>

using Index = std::ptrdiff_t;

// 辅助函数，将 `value` 转换为 std::size_t 类型的对象
// UZ 是 std::size_t 类型字面量的后缀。
template <typename T>
constexpr std::size_t toUZ(T value)
{
    // 确保 T 是整数类型
    static_assert(std::is_integral<T>() || std::is_enum<T>());
    
    return static_cast<std::size_t>(value);
}

int main()
{
    std::vector arr{ 9, 7, 5, 3, 1 };

    auto length { static_cast<Index>(arr.size()) };  // 在 C++20 中，优先使用 std::ssize()
    for (auto index{ length-1 }; index >= 0; --index)
        std::cout << arr[toUZ(index)] << ' '; // 使用 toUZ() 以避免符号转换警告

    return 0;
}

在上面的示例中，我们创建了一个名为 toUZ() 的函数，旨在将整数值转换为 std::size_t类型的值。这允许我们将数组索引写为 arr[toUZ(index)]，这相当可读。

  1. 使用自定义视图

在之前的课程中，我们讨论了 std::string 拥有一个字符串，而 std::string_view 是存在于别处的字符串的视图。关于 std::string_view 的一个巧妙之处在于它可以查看不同类型的字符串（C风格字符串字面量、 std::string和其他 std::string_view），同时为我们提供一致的接口。

虽然我们不能修改标准库容器以接受有符号整数索引，但我们可以创建自己的自定义视图类来“查看”标准库容器类。通过这样做，我们可以定义自己的接口，使其按我们想要的方式工作。

在以下示例中，我们定义了一个自定义视图类，它可以查看任何支持索引的标准库容器。我们的接口将做两件事：

  • 允许我们使用 operator[] 以有符号整数类型访问元素。
  • 以有符号整数类型获取容器的长度（因为 std::ssize() 仅在C++20中可用）。

这使用了运算符重载（我们在课程 13.5 -- 重载 I/O 运算符简介中简要介绍过）来实现 operator[]你不需要知道 SignedArrayView 是如何实现的才能使用它。

SignedArrayView.h：

#ifndef SIGNED_ARRAY_VIEW_H
#define SIGNED_ARRAY_VIEW_H

#include <cstddef> // for std::size_t and std::ptrdiff_t

// SignedArrayView 提供了一个容器的视图，支持使用有符号索引进行索引
// 允许我们使用有符号索引处理这些类型
template <typename T>
class SignedArrayView // 需要 C++17
{
private:
    T& m_array;

public:
    using Index = std::ptrdiff_t;

    SignedArrayView(T& array)
        : m_array{ array } {}

    // 重载operator[]以接受有符号索引
    constexpr auto& operator[](Index index) { return m_array[static_cast<typename T::size_type>(index)]; }
    constexpr const auto& operator[](Index index) const { return m_array[static_cast<typename T::size_type>(index)]; }
    constexpr auto ssize() const { return static_cast<Index>(m_array.size()); }
};

#endif

main.cpp:

#include <iostream>
#include <vector>
#include "SignedArrayView.h"

int main()
{
    std::vector arr{ 9, 7, 5, 3, 1 };
    SignedArrayView sarr{ arr }; // 创建std::vector的有符号视图

    for (auto index{ sarr.ssize() - 1 }; index >= 0; --index)
        std::cout << sarr[index] << ' '; // 使用有符号类型进行索引

    return 0;
}

改为索引底层的C风格数组

在课程 16.3 -- std::vector 和无符号长度与下标问题，我们注意到，与其索引标准库容器，不如调用 data() 成员函数并索引该函数返回的结果。由于 data() 将数组数据作为C风格数组返回，而C风格数组允许使用有符号和无符号值进行索引，这避免了符号转换问题。

int main()
{
    std::vector arr{ 9, 7, 5, 3, 1 };

    auto length { static_cast<Index>(arr.size()) };  // 在 C++20 中，优先使用 std::ssize()
    for (auto index{ length - 1 }; index >= 0; --index)
        std::cout << arr.data()[index] << ' ';       // 使用data()避免符号转换警告

    return 0;
}

我们认为这种方法是索引选项中的最佳选择：

  • 我们可以使用有符号循环变量和索引。
  • 我们不必定义任何自定义类型或类型别名。
  • 使用 data() 对可读性的影响并不大。
  • 在优化代码中应该没有性能损失。

唯一明智的选择：完全避免索引！

上面介绍的所有选项都有各自的缺点，因此很难推荐一种方法优于另一种。然而，有一个选择比其他选择明智得多：完全避免使用整数值进行索引。

C++提供了几种其他遍历数组的方法，这些方法根本不使用索引。如果我们不使用索引，就不会遇到所有这些有符号/无符号转换问题。

两种常见的无索引数组遍历方法包括基于范围的for循环和迭代器。
