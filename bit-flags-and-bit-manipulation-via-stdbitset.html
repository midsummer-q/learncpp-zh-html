O.1 — 位标志与位操作：std::bitset

● 机器译文 课程 O.1 查看英文原文

在现代计算机体系结构中，内存的最小可寻址单元是字节。由于所有对象都需要有唯一的内存地址，这意味着对象至少需要占用一个字节。对于大多数变量类型来说，这没问题。然而，对于布尔值来说，这有点浪费（双关语）。布尔类型只有两种状态：true（1）或 false（0）。这组状态只需要一个位来存储。但是，如果一个变量必须至少是一个字节，而一个字节是8位，那就意味着一个布尔值使用了1位，而其他7位未被使用。

在大多数情况下，这没问题——我们通常不会因为内存紧张而需要关心浪费的7位（我们更应该优化可理解性和可维护性）。然而，在某些存储密集型的情况下，将8个独立的布尔值“打包”到一个字节中以节省存储空间是有用的。

要做到这些，我们需要能够在位级别操作对象。幸运的是，C++ 为我们提供了实现这一点的工具。修改对象中的单个位称为 位操作。

作者注

位操作在某些编程环境中使用很多（例如图形、加密、压缩、优化），但在一般编程中不那么常见。

因此，整个章节都是可选阅读。随意跳过或略读，稍后再回来。

位标志

到目前为止，我们使用变量来保存单个值：

int foo { 5 }; // 将 foo 赋值为 5（可能使用 32 位存储）
std::cout << foo; // 打印值 5

然而，我们也可以不将对象视为保存单个值，而是将对象中的每个位视为一个独立的布尔值。当对象的单个位被用作布尔值时，这些位被称为 位标志。

术语

值为 0 的位被称为“假”、“关”或“未设置”。
值为 1 值为
的位被称为“真”、“开”或“已设置”。当一个位从 0 转换为 1 变为 1 转换为 0或反之，我们说它被“翻转”或“取反”。

顺便说一句……

在计算中， 标志 是一个值，用于指示程序中某个条件是否存在。对于位标志，值为 true 表示条件存在。

类似地，在美国，许多邮箱侧面有小的（通常是红色的）物理标志。当有外发邮件等待邮递员取走时，标志被升起，表示有外发邮件。

要定义一组位标志，我们通常使用适当大小的无符号整数（8位、16位、32位等，取决于我们有多少个标志），或者 std::bitset。

#include <bitset> // for std::bitset

std::bitset<8> mybitset {}; // 8 位大小意味着可容纳 8 个标志

最佳实践

位操作是少数几个你应该明确使用无符号整数（或 std::bitset)。

）的场合之一。在本课中，我们将展示如何通过 std::bitset轻松进行位操作。在接下来的几课中，我们将探讨如何以更困难但更通用的方式进行位操作。

位编号和位位置

对于给定的位序列，我们通常从右向左编号，从0开始（而不是1）。每个数字表示一个 位位置。

76543210  Bit position
00000101  Bit sequence

对于位序列 0000 0101，位置0和2的位值为1，其他位值为0。

通过 std::bitset

在课程 5.3 -- 数字系统（十进制、二进制、十六进制和八进制） 我们已经展示了如何使用 std::bitset 以二进制打印值。然而，这并不是 std::bitset 唯一有用的功能。

std::bitset 提供了4个对位操作有用的关键成员函数：

  • test() 允许我们查询一个位是0还是1。
  • set() 允许我们将一个位设置为开（如果位已经打开，则不做任何操作）。
  • reset() 允许我们将一个位设置为关（如果位已经关闭，则不做任何操作）。
  • flip() 允许我们将一个位的值从0翻转到1，或反之。

这些函数中的每一个都将我们要操作的位的位置作为其唯一参数。

下面是一个示例：

#include <bitset>
#include <iostream>

int main()
{
    std::bitset<8> bits{ 0b0000'0101 }; // 我们需要 8 位，从位模式 0000 0101 开始
    bits.set(3);   // 将位位置 3 设置为 1（现在我们有 0000 1101）
    bits.flip(4);  // 翻转位 4（现在我们有 0001 1101）
    bits.reset(4); // 将位 4 重新设置为 0（现在我们有 0000 1101）

    std::cout << "All the bits: " << bits<< '\n';
    std::cout << "Bit 3 has value: " << bits.test(3) << '\n';
    std::cout << "Bit 4 has value: " << bits.test(4) << '\n';

    return 0;
}

这会打印：

All the bits: 00001101
Bit 3 has value: 1
Bit 4 has value: 0

我们介绍了 0b 二进制字面量前缀和 ' 数字分隔符在课程 5.3 -- 数字系统（十进制、二进制、十六进制和八进制）。

给我们的位命名可以使代码更易读：

#include <bitset>
#include <iostream>

int main()
{
    [[maybe_unused]] constexpr int  isHungry   { 0 };
    [[maybe_unused]] constexpr int  isSad      { 1 };
    [[maybe_unused]] constexpr int  isMad      { 2 };
    [[maybe_unused]] constexpr int  isHappy    { 3 };
    [[maybe_unused]] constexpr int  isLaughing { 4 };
    [[maybe_unused]] constexpr int  isAsleep   { 5 };
    [[maybe_unused]] constexpr int  isDead     { 6 };
    [[maybe_unused]] constexpr int  isCrying   { 7 };

    std::bitset<8> me{ 0b0000'0101 }; // 我们需要 8 位，从位模式 0000 0101 开始
    me.set(isHappy);      // 将位位置 3 设置为 1（现在我们有 0000 1101）
    me.flip(isLaughing);  // 翻转位 4（现在我们有 0001 1101）
    me.reset(isLaughing); // 将位 4 重新设置为 0（现在我们有 0000 1101）

    std::cout << "All the bits: " << me << '\n';
    std::cout << "I am happy: " << me.test(isHappy) << '\n';
    std::cout << "I am laughing: " << me.test(isLaughing) << '\n';

    return 0;
}

如果我们想同时获取或设置多个位呢？

std::bitset 并没有让这变得容易。为了做到这一点，或者如果我们想使用无符号整数位标志而不是 std::bitset，我们需要转向更传统的方法。我们将在接下来的几节课中介绍这些方法。

的大小 std::bitset

一个潜在的意外是 std::bitset 是为速度而非内存节省而优化的。一个 std::bitset 的大小通常是容纳这些位所需的字节数，向上 取整 到最近的 sizeof(size_t)，在32位机器上是4字节，在64位机器上是8字节。

因此，一个 std::bitset<8> 通常使用4或8字节的内存，尽管技术上只需要1字节来存储8位。因此， std::bitset 在追求便利而非内存节省时最为有用。

查询 std::bitset

还有其他一些经常有用的成员函数：

  • size() 返回 bitset 中的位数。
  • count() 返回 bitset 中被设置为 true。
  • all() 返回一个布尔值，指示是否所有位都被设置为 true。
  • any() 返回一个布尔值，指示是否有任何位被设置为 true。
  • none() 返回一个布尔值，指示是否没有位被设置为 true。
#include <bitset>
#include <iostream>

int main()
{
    std::bitset<8> bits{ 0b0000'1101 };
    std::cout << bits.size() << " bits are in the bitset\n";
    std::cout << bits.count() << " bits are set to true\n";

    std::cout << std::boolalpha;
    std::cout << "All bits are true: " << bits.all() << '\n';
    std::cout << "Some bits are true: " << bits.any() << '\n';
    std::cout << "No bits are true: " << bits.none() << '\n';
    
    return 0;
}

这会打印：

8 bits are in the bitset
3 bits are set to true
All bits are true: false
Some bits are true: true
No bits are true: false
