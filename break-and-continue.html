8.11 — Break 和 continue

● 机器译文 课程 8.11 查看英文原文

Break

尽管你已经在 break 语句的上下文中见过 switch 语句（8.5 -- Switch语句基础），但它值得更全面的讨论，因为它也可以用于其他类型的控制流语句。 break语句 会导致 while 循环、do-while 循环、for 循环或 switch 语句结束，执行将继续进行到被跳出的循环或 switch 之后的下一条语句。

跳出 switch

在 switch 语句的上下文中， break 通常在每个 case 的末尾使用，以表示该 case 已完成（这可以防止落入后续 case）：

#include <iostream>

void printMath(int x, int y, char ch)
{
    switch (ch)
    {
    case '+':
        std::cout << x << " + " << y << " = " << x + y << '\n';
        break; // 不要落入下一个 case
    case '-':
        std::cout << x << " - " << y << " = " << x - y << '\n';
        break; // 不要落入下一个 case
    case '*':
        std::cout << x << " * " << y << " = " << x * y << '\n';
        break; // 不要落入下一个 case
    case '/':
        std::cout << x << " / " << y << " = " << x / y << '\n';
        break;
    }
}

int main()
{
    printMath(2, 3, '+');

    return 0;
}

参见课程 8.6 -- Switch 的落入和作用域 了解更多关于落入的信息，以及一些额外的示例。

跳出循环

在循环的上下文中， break 语句可用于提前结束循环。执行将继续进行到循环结束后的下一条语句。

例如：

#include <iostream>

int main()
{
    int sum{ 0 };

    // 允许用户输入最多 10 个数字
    for (int count{ 0 }; count < 10; ++count)
    {
        std::cout << "Enter a number to add, or 0 to exit: ";
        int num{};
        std::cin >> num;

        // 如果用户输入 0 则退出循环
        if (num == 0)
            break; // 立即退出循环

        // 否则将数字加到总和中
        sum += num;
    }

    // 执行将在 break 之后继续到这里
    std::cout << "The sum of all the numbers you entered is: " << sum << '\n';

    return 0;
}

该程序允许用户最多输入 10 个数字，并在最后显示所有输入数字的总和。如果用户输入 0，break 会导致循环提前终止（在输入 10 个数字之前）。

以下是上述程序的一个示例执行：

Enter a number to add, or 0 to exit: 5
Enter a number to add, or 0 to exit: 2
Enter a number to add, or 0 to exit: 1
Enter a number to add, or 0 to exit: 0
The sum of all the numbers you entered is: 8

一个 break 也是跳出故意无限循环的常见方式：

#include <iostream>

int main()
{
    while (true) // 无限循环
    {
        std::cout << "Enter 0 to exit or any other integer to continue: ";
        int num{};
        std::cin >> num;

        // 如果用户输入 0 则退出循环
        if (num == 0)
            break;
    }

    std::cout << "We're out!\n";

    return 0;
}

上述程序的一个示例运行：

Enter 0 to exit or any other integer to continue: 5
Enter 0 to exit or any other integer to continue: 3
Enter 0 to exit or any other integer to continue: 0
We're out!

Break 与 return

新手程序员有时难以理解 break 和 return。一个 break 语句终止 switch 或循环，执行继续在 switch 或循环之后的第一条语句处进行。 return 语句终止循环所在的整个函数，执行继续在函数被调用的地方进行。

#include <iostream>

int breakOrReturn()
{
    while (true) // 无限循环
    {
        std::cout << "Enter 'b' to break or 'r' to return: ";
        char ch{};
        std::cin >> ch;

        if (ch == 'b')
            break; // 执行将在循环后的第一条语句处继续

        if (ch == 'r')
            return 1; // return 将导致函数立即返回给调用者（在本例中为 main()）
    }

    // 中断循环导致执行在此处恢复

    std::cout << "We broke out of the loop\n";

    return 0;
}

int main()
{
    int returnValue{ breakOrReturn() };
    std::cout << "Function breakOrReturn returned " << returnValue << '\n';

    return 0;
}

以下是该程序的两个运行结果：

Enter 'b' to break or 'r' to return: r
Function breakOrReturn returned 1

Enter 'b' to break or 'r' to return: b
We broke out of the loop
Function breakOrReturn returned 0

继续

浮点类型的 continue 语句 提供了一种方便的方式来结束循环的当前迭代，而不终止整个循环。

以下是使用 continue 的一个示例：

#include <iostream>

int main()
{
    for (int count{ 0 }; count < 10; ++count)
    {
        // 如果数字能被4整除，跳过本次迭代
        if ((count % 4) == 0)
            continue; // 进入下一次迭代

        // 如果数字不能被4整除，继续执行
        std::cout << count << '\n';

        // continue 语句跳转到这里
    }

    return 0;
}

该程序打印从 0 到 9 中所有不能被 4 整除的数字：

1
2
3
5
6
7
9

一个 continue 语句通过使当前执行点跳转到当前循环的底部来工作。

在 for 循环的情况下，for 循环的结束语句（在上面的示例中， ++count）在 continue 之后仍然执行（因为这发生在循环体结束之后）。

在使用 continue 语句与 while 或 do-while 循环时要小心。这些循环通常在循环体内改变条件中使用的变量的值。如果使用 continue 语句导致这些行被跳过，那么循环可能会变成无限循环！

考虑以下程序：

#include <iostream>

int main()
{
    int count{ 0 };
    while (count < 10)
    {
        if (count == 5)
            continue; // 跳转到循环体末尾

        std::cout << count << '\n';

        ++count; // 当 count 达到5后，这条语句永远不会执行

        // continue 语句跳转到这里
    }

    return 0;
}

该程序旨在打印 0 到 9 之间除 5 以外的每个数字。但它实际上打印：

0
1
2
3
4

然后进入无限循环。当 count 等于 5， if 语句求值为 true，而 continue 导致执行跳转到循环底部。 count 变量从未递增。因此，在下一次循环中， count 仍然 5， if 语句仍然 true，程序继续无限循环。

当然，你已经知道，如果你有一个明显的计数器变量，你应该使用 for 循环，而不是 while 或 do while 循环。

关于使用 break 和 continue 的争论

许多教科书告诫读者不要在循环中使用 break 和 continue ，因为它会导致执行流程跳跃，并且可能使逻辑流程难以理解。例如，一个 break 位于复杂逻辑中间时，可能会被忽略，或者不清楚在什么条件下应该触发它。

然而，如果明智地使用， break 和 continue 可以通过减少嵌套块的数量和降低复杂循环逻辑的需求来帮助使循环更易读。

例如，考虑以下程序：

#include <iostream>

int main()
{
    int count{ 0 }; // 统计循环迭代的次数
    bool keepLooping { true }; // 控制循环是否结束
    while (keepLooping)
    {
        std::cout << "Enter 'e' to exit this loop or any other character to continue: ";
        char ch{};
        std::cin >> ch;

        if (ch == 'e')
            keepLooping = false;
        else
        {
            ++count;
            std::cout << "We've iterated " << count << " times\n";
        }
    }

    return 0;
}

这个程序使用一个布尔变量来控制循环是否继续，以及一个仅在用户不退出时运行的嵌套块。

这是一个更易于理解的版本，使用 break 语句：

#include <iostream>

int main()
{
    int count{ 0 }; // 统计循环迭代的次数
    while (true) // 循环直到用户终止
    {
        std::cout << "Enter 'e' to exit this loop or any other character to continue: ";
        char ch{};
        std::cin >> ch;

        if (ch == 'e')
            break;

        ++count;
        std::cout << "We've iterated " << count << " times\n";
    }

    return 0;
}

在这个版本中，通过使用一个单一的 break 语句，我们避免了使用布尔变量（以及理解其预期用途和值在哪里改变），一个 else 语句和一个嵌套块。

浮点类型的 continue 语句最有效地用于 for 循环的顶部，当满足某些条件时跳过循环迭代。这可以让我们避免嵌套块。

例如，不要这样：

#include <iostream>

int main()
{
    for (int count{ 0 }; count < 10; ++count)
    {
        // 如果数字不能被4整除...
        if ((count % 4) != 0) // 嵌套块
        {
                // 打印数字
                std::cout << count << '\n';
        }
    }

    return 0;
}

我们可以这样写：

#include <iostream>

int main()
{
    for (int count{ 0 }; count < 10; ++count)
    {
        // 如果数字能被4整除，跳过本次迭代
        if ((count % 4) == 0)
            continue;

        // 不需要嵌套块

        std::cout << count << '\n';
    }

    return 0;
}

最小化使用的变量数量和保持嵌套块数量少，这两者都比 break 或 continue 对代码可理解性的损害更大。因此，我们认为明智地使用 break 或 continue 是可以接受的。

最佳实践

当 break 和 continue 能简化循环逻辑时，就使用它们。

关于使用提前返回的争论

对于 return 语句也有类似的争论。不是函数中最后一条语句的 return 语句被称为 提前返回。许多程序员认为应该避免提前返回。一个只在函数底部有一个 return 语句的函数具有简洁性——你可以假设该函数将接受参数，执行其实现的任何逻辑，并返回结果，没有偏差。额外的 return 会使逻辑复杂化。

反对的观点是，使用提前返回可以让函数在完成时立即退出，从而减少阅读不必要的逻辑，并最小化条件嵌套块的需求，这使代码更易读。

一些开发者采取中间立场，只在函数顶部使用提前返回进行参数验证（捕获传入的错误参数），然后之后只有一个 return。

我们的立场是，提前返回利大于弊，但我们认识到这其中有实践的艺术。

最佳实践

当提前返回能简化函数逻辑时，就使用它们。
