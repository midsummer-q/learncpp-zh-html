24.7 — 调用继承的函数与重写行为

● 机器译文 课程 24.7 查看英文原文

默认情况下，派生类继承基类中定义的所有行为。在本课中，我们将更详细地研究成员函数是如何被选择的，以及如何利用这一点来改变派生类中的行为。

当在派生类对象上调用成员函数时，编译器首先查看派生类中是否存在具有该名称的函数。如果存在，则考虑所有具有该名称的重载函数，并使用函数重载解析过程来确定是否存在最佳匹配。如果不存在，编译器会沿着继承链向上查找，依次检查每个父类。

换句话说，编译器将从至少有一个具有该名称的函数的派生程度最高的类中选择最佳匹配函数。

调用基类函数

首先，让我们探讨当派生类没有匹配函数但基类有时会发生什么：

#include <iostream>

class Base
{
public:
    Base() { }

    void identify() const { std::cout << "Base::identify()\n"; }
};

class Derived: public Base
{
public:
    Derived() { }
};

int main()
{
    Base base {};
    base.identify();

    Derived derived {};
    derived.identify();

    return 0;
}

这会打印：

Base::identify()
Base::identify()

当 base.identify() 被调用时，编译器会查找名为 identify() 的函数是否在类 Base中定义。它定义了，所以编译器检查它是否匹配。它匹配，因此被调用。

当 derived.identify() 被调用时，编译器会查找名为 identify() 是否在 Derived 类中定义。它没有定义。因此它移动到父类（在本例中是 Base），并再次尝试。 Base 定义了一个 identify() 函数，所以它使用了那个。换句话说， Base::identify() 被使用是因为 Derived::identify() 已经不存在了。

这意味着如果基类提供的行为足够，我们可以直接使用基类的行为。

重定义行为

然而，如果我们在 Derived::identify() 在 Derived 类中定义了，它就会被使用。

这意味着我们可以通过在派生类中重新定义函数，使函数在派生类中工作方式不同！

例如，假设我们希望 derived.identify() 来打印 Derived::identify()。我们只需在 identify() 在 Derived 类中添加函数，使其在调用函数时返回正确的响应。 identify() 字面量初始化 Derived 播种），我们将其用作全局

要修改基类中定义的函数在派生类中的工作方式，只需在派生类中重新定义该函数。

#include <iostream>

class Base
{
public:
    Base() { }

    void identify() const { std::cout << "Base::identify()\n"; }
};

class Derived: public Base
{
public:
    Derived() { }

    void identify() const { std::cout << "Derived::identify()\n"; }
};

int main()
{
    Base base {};
    base.identify();

    Derived derived {};
    derived.identify();

    return 0;
}

这会打印：

Base::identify()
Derived::identify()

请注意，当你在派生类中重新定义函数时，派生函数不会继承基类中同名函数的访问说明符。它使用在派生类中定义时所使用的访问说明符。因此，基类中定义为私有的函数可以在派生类中重新定义为公有的，反之亦然！

#include <iostream>

class Base
{
private:
	void print() const 
	{
		std::cout << "Base";
	}
};
 
class Derived : public Base
{
public:
	void print() const 
	{
		std::cout << "Derived ";
	}
};
 
 
int main()
{
	Derived derived {};
	derived.print(); // 调用 derived::print()，该函数是公有的
	return 0;
}

添加现有功能

有时我们不想完全替换基类函数，而是希望在派生对象调用时为其添加额外的功能。在上面的例子中，请注意 Derived::identify() 完全隐藏了 Base::identify()！这可能不是我们想要的。我们可以让派生函数调用同名的基类版本（以便重用代码），然后为其添加额外的功能。

要让派生函数调用同名的基类函数，只需进行普通的函数调用，但在函数前加上基类的作用域限定符。例如：

#include <iostream>

class Base
{
public:
    Base() { }

    void identify() const { std::cout << "Base::identify()\n"; }
};

class Derived: public Base
{
public:
    Derived() { }

    void identify() const
    {
        std::cout << "Derived::identify()\n";
        Base::identify(); // 注意此处对 Base::identify() 的调用
    }
};

int main()
{
    Base base {};
    base.identify();

    Derived derived {};
    derived.identify();

    return 0;
}

这会打印：

Base::identify()
Derived::identify()
Base::identify()

当 derived.identify() 执行时，它解析为 Derived::identify()。在打印 Derived::identify()之后，它调用 Base::identify()，它会打印 Base::identify()。

这应该相当直接。为什么我们需要使用作用域解析运算符（::）？如果我们定义了 Derived::identify() 加上前缀，像这样：

#include <iostream>

class Base
{
public:
    Base() { }

    void identify() const { std::cout << "Base::identify()\n"; }
};

class Derived: public Base
{
public:
    Derived() { }

    void identify() const
    {
        std::cout << "Derived::identify()\n";
        identify(); // 没有作用域解析会导致自调用和无限递归
    }
};

int main()
{
    Base base {};
    base.identify();

    Derived derived {};
    derived.identify();

    return 0;
}

调用函数 identify() 而不使用作用域解析限定符，将默认为当前类中的 identify() ，即 Derived::identify()。这将导致 Derived::identify() 调用自身，从而导致无限递归！

在尝试调用基类中的友元函数时，我们可能会遇到一个棘手的问题，例如 operator<<。因为基类的友元函数实际上不是基类的一部分，使用作用域解析限定符是行不通的。相反，我们需要一种方法让我们的 Derived 类暂时看起来像 Base 类，以便能够调用正确版本的函数。

幸运的是，这很容易做到，使用 static_cast。下面是一个例子：

#include <iostream>

class Base
{
public:
    Base() { }

	friend std::ostream& operator<< (std::ostream& out, const Base&)
	{
		out << "In Base\n";
		return out;
	}
};

class Derived: public Base
{
public:
    Derived() { }

 	friend std::ostream& operator<< (std::ostream& out, const Derived& d)
	{
		out << "In Derived\n";
		// static_cast 将 Derived 转换为 Base 对象，因此我们调用正确的 operator<< 版本
		out << static_cast<const Base&>(d); 
		return out;
    }
};

int main()
{
    Derived derived {};

    std::cout << derived << '\n';

    return 0;
}

因为一个 Derived 是一个 Base，我们可以将我们的 static_cast 对象 Derived 转换为一个 Base 引用，这样使用 operator<< 的适当版本 Base 被调用。

这会打印：

In Derived
In Base

派生类中的重载解析

正如本课开头所述，编译器将从至少有一个该名称函数的派生程度最高的类中选择最佳匹配函数。

首先，让我们看一个简单的例子，其中我们有重载的成员函数：

#include <iostream>

class Base
{
public:
    void print(int)    { std::cout << "Base::print(int)\n"; }
    void print(double) { std::cout << "Base::print(double)\n"; }
};

class Derived: public Base
{
public:
};


int main()
{
    Derived d{};
    d.print(5); // 调用 Base::print(int)

    return 0;
}

对于调用 d.print(5)，编译器没有找到名为 print() 在 Derived的函数，因此它检查 Base ，在那里它找到了两个同名函数。它使用函数重载解析过程来确定 Base::print(int) 比 Base::print(double)。因此， Base::print(int) 被调用，正如我们所期望的那样。

现在让我们看一个行为可能与我们预期不符的例子：

#include <iostream>

class Base
{
public:
    void print(int)    { std::cout << "Base::print(int)\n"; }
    void print(double) { std::cout << "Base::print(double)\n"; }
};

class Derived: public Base
{
public:
    void print(double) { std::cout << "Derived::print(double)"; } // 此函数已添加
};


int main()
{
    Derived d{};
    d.print(5); // 调用 Derived::print(double)，而不是 Base::print(int)

    return 0;
}

对于调用 d.print(5)，编译器找到一个名为 print() 在 Derived的函数，因此它只会考虑 Derived 中的函数，以确定解析到哪个函数。这个函数也是 Derived 中对此函数调用的最佳匹配函数。因此，这调用的是 Derived::print(double)。

由于 Base::print(int) 有一个参数，对于 int 参数来说比 5 更匹配，你可能期望这个函数调用解析为 Derived::print(double)。但因为 Base::print(int)中至少有一个 d 我们还调用了 Derived函数， print() 比 Derived、和 Derived 派生程度更高，所以 Base中的函数甚至不会被考虑。 Base 那么如果我们实际上想要

呢？一种不太好的方法是在 d.print(5) 解析为 Base::print(int)中定义一个 Derived::print(int)：

#include <iostream>

class Base
{
public:
    void print(int)    { std::cout << "Base::print(int)\n"; }
    void print(double) { std::cout << "Base::print(double)\n"; }
};

class Derived: public Base
{
public:
    void print(int n) { Base::print(n); } // 可行但不太好，因为我们必须定义 
    void print(double) { std::cout << "Derived::print(double)"; }
};

int main()
{
    Derived d{};
    d.print(5); // 调用 Derived::print(int)，它调用 Base::print(int)

    return 0;
}

虽然这可行，但不太好，因为我们必须为每个想要传递到 Derived 的重载在 Base中添加一个函数。这可能会增加很多额外的函数，而这些函数本质上只是将调用路由到 Base。

一个更好的选择是在 Derived 中使用 using 声明，使所有具有特定名称的 Base 函数在 Derived：

#include <iostream>

class Base
{
public:
    void print(int)    { std::cout << "Base::print(int)\n"; }
    void print(double) { std::cout << "Base::print(double)\n"; }
};

class Derived: public Base
{
public:
    using Base::print; // 使所有 Base::print() 函数有资格参与重载决议
    void print(double) { std::cout << "Derived::print(double)"; }
};


int main()
{
    Derived d{};
    d.print(5); // 调用 Base::print(int)，这是在 Derived 中可见的最佳匹配函数

    return 0;
}

通过使用 using 声明 using Base::print; 在 Derived，我们告诉编译器所有名为 Base 的函数应该在 print 中可见， Derived这将使它们有资格参与重载决议。因此， Base::print(int) 被选中而不是 Derived::print(double)。
