章节回顾

在每个（非静态）成员函数内部，关键字 这个 是一个常量指针，保存当前隐式对象的地址。我们可以让函数返回 *this 引用，以实现 方法链，即在一个表达式中对同一个对象调用多个成员函数。

优先将类定义放在与类同名的头文件中。简单的成员函数（如访问函数、空体的构造函数等）可以在类定义内部定义。

优先将非简单的成员函数定义在与类同名的源文件中。

在类类型内部定义的类型称为 嵌套类型 （或 成员类型）。类型别名也可以嵌套。

在类模板定义内部定义的成员函数可以使用类模板本身的模板参数。在类模板定义外部定义的成员函数必须重新提供模板参数声明，并且应该（在同一文件中）定义在类模板定义的正下方。

静态成员变量 是静态存储期的成员，由类的所有对象共享。即使没有实例化任何类对象，静态成员也存在。优先使用类名、作用域解析运算符和成员名来访问它们。

将静态成员设为 inline 允许它们在类定义内部初始化。

静态成员函数 是可以在没有对象的情况下调用的成员函数。它们没有 *this 指针，并且不能访问非静态数据成员。

在类的内部， 友元声明 （使用 friend 关键字）可以用来告诉编译器某个其他类或函数现在是友元。一个 友元 是被授予对另一个类的私有和受保护成员完全访问权限的类或函数（成员或非成员）。一个 友元函数 是一个函数（成员或非成员），它可以像类的成员一样访问类的私有和受保护成员。一个 友元类 是一个可以访问另一个类的私有成员和保护成员的类。

a) 首先，让我们创建一个名为 MonsterType的作用域枚举，表示怪物类型。包括以下怪物类型：Dragon、Goblin、Ogre、Orc、Skeleton、Troll、Vampire和Zombie。添加一个额外的maxMonsterTypes枚举器，以便我们可以计算有多少个枚举器。

e) 现在我们希望能够打印我们的怪物，以便验证它是否正确。编写两个函数：一个名为 getTypeString() ，返回怪物的类型字符串；另一个名为 print() ，其输出与下面的示例程序匹配。

以下程序应该能够编译：

int main()
{
	Monster skeleton{ Monster::skeleton, "Bones", "*rattle*", 4 };
	skeleton.print();

	Monster vampire{ Monster::vampire, "Nibblez", "*hiss*", 0 };
	vampire.print();

	return 0;
}

并打印：

Bones the skeleton has 4 hit points and says *rattle*.
Nibblez the vampire is dead.

f) 现在我们可以创建一个随机怪物生成器。让我们考虑一下我们的 MonsterGenerator 将如何工作。理想情况下，我们会要求它给我们一个 Monster，它会为我们创建一个随机的。因为 MonsterGenerator 没有任何状态，这是一个适合用命名空间的候选。

创建一个 MonsterGenerator 命名空间。在命名空间内创建函数 generate()。该函数应返回一个 Monster。目前，让它返回 Monster{ Monster::skeleton, "Bones", "*rattle*", 4}；

以下程序应该能够编译：

int main()
{
	Monster m{ MonsterGenerator::generate() };
	m.print();

	return 0;
}

并打印：

g) 向 MonsterGenerator 命名空间之外的同名函数冲突。 getName(int) 将接受一个介于0到5（含）之间的数字，并返回你选择的名字。 getRoar(int) 也将接受一个介于0到5（含）之间的数字，并返回你选择的吼叫声。同时更新你的 generate() 函数以调用 getName(0) 和 getRoar(0)。

以下程序应该能够编译：

int main()

h) 现在我们将随机生成怪物。从 8.15 -- 全局随机数 (Random.h) 获取“Random.h”代码，并保存为Random.h。然后使用 Random::get() 生成随机的怪物类型、随机名字、随机吼叫声和随机生命值（介于1到100之间）。

以下程序应该能够编译：

#include "Random.h"

int main()
{
	Monster m{ MonsterGenerator::generate() };
	m.print();

	return 0;

Mort the zombie has 61 hit points and says *growl*
