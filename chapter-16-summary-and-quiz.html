术语 复制语义 指的是决定如何复制对象的规则。当我们说复制语义被调用时，意味着我们做了某些会导致对象副本的事情。

当数据的所有权从一个对象转移到另一个对象时，我们说数据已被 移动。

移动语义 指的是决定数据如何从一个对象移动到另一个对象的规则。当调用移动语义时，任何可以移动的数据成员都会被移动，任何不能移动的数据成员则会被复制。移动数据而非复制数据的能力可以使移动语义比复制语义更高效，尤其是当我们可以用廉价的移动替换昂贵的复制时。

通常，当一个对象被同类型的另一个对象初始化或赋值时，会使用复制语义（假设复制没有被省略）。当对象的类型支持移动语义，并且初始化器或赋值的来源是右值时，移动语义将自动被使用。

我们可以按值返回支持移动的类型（如 std::vector 和 std::string）。这些类型会廉价地移动它们的值，而不是进行昂贵的复制。

按某种顺序访问容器中的每个元素称为 遍历，或 遍历 容器。遍历有时也被称为 迭代 或 迭代 容器。

循环常用于遍历数组，使用循环变量作为索引。注意差一错误，即循环体执行次数多一次或少一次。

一个 基于范围的for循环 （有时也称为 for-each循环) 允许遍历容器而无需显式索引。遍历容器时，优先使用基于范围的for循环而不是普通for循环。

使用类型推导（auto) 与基于范围的for循环一起使用，让编译器推断数组元素的类型。当你通常按（const）引用传递该元素类型时，元素声明应使用（const）引用。始终考虑使用 const auto& ，除非你需要处理副本。这将确保即使元素类型后来改变，也不会创建副本。

无作用域枚举可以用作索引，并有助于提供关于索引含义的任何信息。

当我们需要一个表示数组长度的枚举器时，添加一个额外的“count”枚举器很有用。你可以使用assert或static_assert来确保数组的长度等于count枚举器，从而保证数组用预期数量的初始化器初始化。

数组长度必须在实例化时定义且之后不能更改的数组称为 固定大小数组 或 固定长度数组。一个 动态数组 （也称为 可调整大小数组）是一种在实例化后可以改变大小的数组。这种可调整大小的能力正是 std::vector 的特殊之处。

一个 std::vector 可以在实例化后通过调用 resize() 成员函数并指定新的期望长度。

在 std::vector， 的上下文中，容量 是指 std::vector 已分配存储空间的元素数量，而 长度 是当前正在使用的元素数量。我们可以询问一个 std::vector 我们可以通过 capacity() 成员函数。

当一个 std::vector 改变其管理的存储量时，这个过程称为 重新分配。由于重新分配通常需要复制数组中的每个元素，因此重新分配是一个昂贵的过程。因此，我们希望尽可能避免重新分配。

下标运算符（operator[]）和 at() 成员函数基于向量的长度，而不是容量。

std::vector 有一个成员函数叫做 shrink_to_fit() ，它请求向量将其容量缩小到与其长度匹配。这个请求是非强制性的。

项目添加到栈和从栈中移除的顺序可以描述为 后进先出（LIFO）。最后放入栈中的盘子将是第一个被取出的盘子。在编程中，一个 栈 是一种容器数据类型，其中元素的插入和移除以 LIFO 方式进行。这通常通过两个操作实现，分别称为 push 和 pop。

浮点类型的 std::vector 成员函数 push_back() 和 emplace_back() 会增加 std::vector，并且如果容量不足以插入该值，将导致重新分配。当push触发重新分配时， std::vector 通常会分配一些额外的容量，以便在下次添加元素时无需再次触发重新分配。

浮点类型的 resize() 成员函数改变 vector 的长度，并在必要时改变容量。
浮点类型的 reserve() 成员函数仅改变容量（如果需要）

要增加 std::vector：

  • 使用 resize() 中的元素数量，当通过索引访问 vector 时使用。这会改变 vector 的长度，使你的索引有效。
  • 使用 reserve() 当使用栈操作访问 vector 时使用。这会增加容量而不改变 vector 的长度。

两者都 push_back() 和 emplace_back() 将一个元素压入栈。如果要压入的对象已经存在， push_back() 和 emplace_back() 是等价的。然而，在为了将临时对象推入向量而创建临时对象的情况下， emplace_back() 可能更高效。当创建新的临时对象添加到容器时，或者当你需要访问显式构造函数时，优先使用emplace_back()。否则优先使用push_back()。

有一个特殊的实现用于 std::vector<bool> 有一个特殊的实现，它可能通过类似地将8个布尔值压缩到一个字节中，从而在空间上更高效。

std::vector<bool> 不是一个向量（它不要求在内存中连续），也不存储 bool 值（它保存一个位集合），也不符合C++对容器的定义。尽管 std::vector<bool> 在大多数情况下表现得像向量，但它不能完全与标准库的其他部分兼容。与其他元素类型一起工作的代码可能无法与 std::vector<bool>。因此， std::vector<bool> 通常应该避免使用。

#include <cassert>
#include <iostream>
#include <string_view>
#include <type_traits> // for std::is_integral and std::is_enum
#include <vector>

namespace Items
{
    enum Type: int
    {
        health_potion,
        torch,
        arrow,
        max_items
    };
}

std::string_view getItemNamePlural(Items::Type type)
{
    switch (type)
    {
        case Items::health_potion:  return "health potions";
        case Items::torch:          return "torches";
        case Items::arrow:          return "arrows";

        default:                    return "???";
    }
}

std::string_view getItemNameSingular(Items::Type type)
{
    switch (type)
    {
        case Items::health_potion:  return "health potion";
        case Items::torch:          return "torch";
        case Items::arrow:          return "arrow";

        default:                    return "???";
    }
}

// 辅助函数，将 `value` 转换为 std::size_t 类型的对象
// UZ 是 std::size_t 类型字面量的后缀。
template <typename T>
constexpr std::size_t toUZ(T value)
{
    // 确保 T 是整数类型
    static_assert(std::is_integral<T>() || std::is_enum<T>());
    
    return static_cast<std::size_t>(value);
}


void printInventoryItem(const std::vector<int>& inventory, Items::Type type)
{
    bool plural { inventory[toUZ(type)] != 1 };
    std::cout << "You have " << inventory[toUZ(type)] << ' ';
    std::cout << (plural ? getItemNamePlural(type) : getItemNameSingular(type)) << '\n';
}

// 库存物品应为整数数量，因此这里不需要函数模板
int countTotalItems(const std::vector<int>& inventory)
{
    int sum { 0 };
    for (auto e: inventory)
        sum += e;
    return sum;
}

int main()
{
    std::vector inventory { 1, 5, 10 };
    assert(std::size(inventory) == Items::max_items); // 确保我们的库存具有正确数量的初始化器

问题 #3

编写一个函数，该函数接受一个 std::vector，返回一个 std::pair ，其中包含数组中最小值和最大值元素的索引。关于 std::pair 的文档可以在 这里找到。对以下两个向量调用该函数：

    std::vector v1 { 3, 8, 2, 5, 7, 8, 3 };
    std::vector v2 { 5.5, 2.7, 3.3, 7.6, 1.2, 8.8, 6.6 };

程序应输出以下内容：

With array ( 3, 8, 2, 5, 7, 8, 3 ):
The min element has index 2 and value 2
The max element has index 1 and value 8

With array ( 5.5, 2.7, 3.3, 7.6, 1.2, 8.8, 6.6 ):
The min element has index 4 and value 1.2
The max element has index 5 and value 8.8

显示答案

#include <iostream>
#include <vector>

template <typename T>
std::pair<std::size_t, std::size_t> findMinMaxIndices(const std::vector<T>& v)
{
    // 假设元素 0 是最小值和最大值
    std::size_t minIndex { 0 };
    std::size_t maxIndex { 0 };

    // 查看剩余元素，看是否能找到更小或更大的元素
    for (std::size_t index { 1 }; index < v.size(); ++index)
    {
        if (v[index] < v[minIndex])
            minIndex = index;
        if (v[index] > v[maxIndex])
            maxIndex = index;
    }

    return { minIndex, maxIndex };
}

template <typename T>
void printArray(const std::vector<T>& v)
{
    bool comma { false };
    std::cout << "With array ( ";
    for (const auto& e: v)
    {
        if (comma)
            std::cout << ", ";

        std::cout << e;
        comma = true;
    }
    std::cout << " ):\n";
}

int main()
{
    std::vector v1 { 3, 8, 2, 5, 7, 8, 3 };
    printArray(v1);
    
    auto m1 { findMinMaxIndices(v1) };
    std::cout << "The min element has index " << m1.first << " and value " << v1[m1.first] << '\n';
    std::cout << "The max element has index " << m1.second << " and value " << v1[m1.second] << '\n';

    std::cout << '\n';
    
    std::vector v2 { 5.5, 2.7, 3.3, 7.6, 1.2, 8.8, 6.6 };
    printArray(v2);

    auto m2 { findMinMaxIndices(v2) };
    std::cout << "The min element has index " << m2.first << " and value " << v2[m2.first] << '\n';
    std::cout << "The max element has index " << m2.second << " and value " << v2[m2.second] << '\n';

    return 0;
}

#include <iostream>
#include <limits>
#include <vector>

template <typename T>
std::pair<std::size_t, std::size_t> findMinMaxIndices(const std::vector<T>& v)
{
    // 假设元素 0 是最小值和最大值
    std::size_t minIndex { 0 };
    std::size_t maxIndex { 0 };

    // 查看剩余元素，看是否能找到更小或更大的元素
    for (std::size_t index { 1 }; index < v.size(); ++index)
    {
        if (v[index] < v[minIndex])
            minIndex = index;
        if (v[index] > v[maxIndex])
            maxIndex = index;
    }

    return { minIndex, maxIndex };
}

template <typename T>
void printArray(const std::vector<T>& v)
{
    bool comma { false };
    std::cout << "With array ( ";
    for (const auto& e: v)
    {
        if (comma)
            std::cout << ", ";

        std::cout << e;
        comma = true;
    }
    std::cout << " ):\n";
}

int main()
{
    std::vector<int> v1 { };
    std::cout << "Enter numbers to add (use -1 to stop): ";

    while (true)
    {
        int input{};
        std::cin >> input;
        if (input == -1)
            break;

        if (!std::cin) // 如果之前的提取失败
        {
            std::cin.clear(); // 将我们恢复到“正常”操作模式
            std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n'); // 并删除错误的输入

        }

        v1.push_back(input);
    }

    // 如果数组为空
    if (v1.size() == 0)
    {
        std::cout << "The array has no elements\n";
    }
    else
    {
        printArray(v1);

        auto m1 { findMinMaxIndices(v1) };
        std::cout << "The min element has index " << m1.first << " and value " << v1[m1.first] << '\n';
        std::cout << "The max element has index " << m1.second << " and value " << v1[m1.second] << '\n';
    }

    return 0;
}

#include <iostream>
#include <string_view>
#include <vector>
#include "Random.h"

namespace Settings
{
    constexpr int wrongGuessesAllowed { 6 };
}

namespace WordList
{
    // 在此处定义您的单词列表
    std::vector<std::string_view> words { "mystery", "broccoli" , "account", "almost", "spaghetti", "opinion", "beautiful", "distance", "luggage" };

    std::string_view getRandomWord()
    {
        return words[Random::get<std::size_t>(0, words.size()-1)];
    }
}

class Session
{
private:
    // 游戏会话数据
    std::string_view m_word { WordList::getRandomWord() };
    int m_wrongGuessesLeft { Settings::wrongGuessesAllowed };
    std::vector<bool> m_letterGuessed { std::vector<bool>(26) };

    std::size_t toIndex(char c) const { return static_cast<std::size_t>((c % 32)-1); }

public:
    std::string_view getWord() const { return m_word; }

    int wrongGuessesLeft() const { return m_wrongGuessesLeft; }
    void removeGuess() { --m_wrongGuessesLeft; }

    bool isLetterGuessed(char c) const { return m_letterGuessed[toIndex(c)]; }
    void setLetterGuessed(char c) { m_letterGuessed[toIndex(c)] = true; }

    bool isLetterInWord(char c) const
    {
        for (auto ch: m_word) // 逐个遍历单词的每个字母
        {
            if (ch == c)
                return true;
        }

        return false;
    }

    bool won()
    {
        for (auto c: m_word) // 逐个遍历单词的每个字母
        {
            if (!isLetterGuessed(c))
                return false;
        }
        
        return true;
    }
};

void draw(const Session& s)
{
    std::cout << '\n';

    std::cout << "The word: ";
    for (auto c: s.getWord()) // 逐个遍历单词的每个字母
    {
        if (s.isLetterGuessed(c))
            std::cout << c;
        else
            std::cout << '_';
    }

    std::cout << "   Wrong guesses: ";
    for (int i=0; i < s.wrongGuessesLeft(); ++i)
        std::cout << '+';


    for (char c='a'; c <= 'z'; ++c)
        if (s.isLetterGuessed(c) && !s.isLetterInWord(c))
            std::cout << c;

    std::cout << '\n';
}

char getGuess(const Session& s)
{
    while (true)
    {
        std::cout << "Enter your next letter: ";

        char c{};
        std::cin >> c;

        // 如果用户做了坏事，再试一次
        if (!std::cin)
        {
            // 修复它
            std::cin.clear();
            std::cout << "That wasn't a valid input.  Try again.\n";
            std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
            continue;
        }
        
        // 清除任何多余的输入
        std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');

        // 如果用户输入了无效字符，再试一次
        if (c < 'a' || c > 'z')
        {
            std::cout << "That wasn't a valid input.  Try again.\n";
            continue;
        }

        // 如果该字母已被猜过，再试一次
        if (s.isLetterGuessed(c))
        {
            std::cout << "You already guessed that.  Try again.\n";
            continue;
        }

        // 如果执行到这里，这一定是一个有效的猜测
        return c;
    }
}

void handleGuess(Session &s, char c)
{
    s.setLetterGuessed(c);
    
    if (s.isLetterInWord(c))
    {
        std::cout << "Yes, '" << c << "' is in the word!\n";
        return;
    }
    
    std::cout << "No, '" << c << "' is not in the word!\n";
    s.removeGuess();
}

int main()
{
    std::cout << "Welcome to C++man (a variant of Hangman)\n";
    std::cout << "To win: guess the word.  To lose: run out of pluses.\n";

    Session s{};

    while (s.wrongGuessesLeft() && !s.won())
    {
        draw(s);
        char c { getGuess(s) };
        handleGuess(s, c);
    }

    // 绘制游戏的最终状态
    draw(s);

    if (!s.wrongGuessesLeft())
        std::cout << "You lost!  The word was: " << s.getWord() << '\n';
    else
        std::cout << "You won!\n";
    
    return 0;
}
