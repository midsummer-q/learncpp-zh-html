在本章中，我们探讨了与运算符重载相关的主题，以及重载类型转换和与拷贝构造函数相关的主题。

总结

运算符重载是函数重载的一种变体，它允许你为你的类重载运算符。当重载运算符时，运算符的意图应尽可能保持与原始运算符的意图一致。如果运算符应用于自定义类时的含义不清晰且不直观，则应改用命名函数。

运算符可以作为普通函数、友元函数或成员函数进行重载。以下经验法则可以帮助你确定在特定情况下哪种形式最合适：

  • 如果要重载赋值（=）、下标（[]）、函数调用（()）或成员选择（->），请以成员函数的形式进行。
  • 如果要重载一元运算符，请以成员函数的形式进行。
  • 如果你要重载一个修改其左操作数的二元运算符（例如 operator+=），如果可以的话，将其作为成员函数实现。
  • 如果你要重载一个不修改其左操作数的二元运算符（例如 operator+），将其作为普通函数或友元函数实现。

类型转换可以被重载以提供转换函数，这些函数可用于显式或隐式地将你的类转换为另一种类型。

拷贝构造函数是一种特殊类型的构造函数，用于从同一类型的另一个对象初始化对象。拷贝构造函数用于从同一类型的对象进行直接/统一初始化、拷贝初始化（Fraction f = Fraction(5,3)），以及按值传递或返回参数时。

如果你不提供拷贝构造函数，编译器会为你创建一个。编译器提供的拷贝构造函数将使用成员初始化，即拷贝的每个成员都从原始成员初始化。出于优化目的，拷贝构造函数可能会被省略，即使它有副作用，所以不要依赖你的拷贝构造函数实际执行。

默认情况下，构造函数被视为转换构造函数，这意味着编译器将使用它们将其他类型的对象隐式转换为你的类的对象。你可以通过在构造函数前使用 explicit 关键字来避免这种情况。你还可以在你的类中删除函数，包括拷贝构造函数和重载的赋值运算符（如果需要）。如果调用了已删除的函数，将导致编译器错误。

赋值运算符可以被重载以允许对你的类进行赋值。如果你不提供重载的赋值运算符，编译器会为你创建一个。重载的赋值运算符应始终包含自赋值检查（除非它被自然处理，或者你正在使用拷贝并交换惯用法）。

新程序员经常混淆赋值运算符和拷贝构造函数的使用时机，但这相当直接：

  • 如果在复制发生之前必须创建新对象，则使用拷贝构造函数（注意：这包括按值传递或返回对象）。
  • 如果在复制发生之前不需要创建新对象，则使用赋值运算符。

默认情况下，编译器提供的拷贝构造函数和赋值运算符执行成员初始化或赋值，这是一种浅拷贝。如果你的类动态分配内存，这很可能会导致问题，因为多个对象最终会指向同一块分配的内存。在这种情况下，你需要显式定义它们以进行深拷贝。更好的是，如果可能，避免自己进行内存管理，而使用标准库中的类。

问题 #2

编写一个名为 Average 的类，该类将跟踪传递给它的所有整数的平均值。使用两个成员：第一个应为类型 std::int32_t，用于跟踪到目前为止你看到的所有数字的总和。第二个应跟踪到目前为止你看到的数字数量。你可以将它们相除以找到平均值。

a) 编写使以下程序运行所需的所有函数：

int main()
{
	Average avg{};
	std::cout << avg << '\n';
	
	avg += 4;
	std::cout << avg << '\n'; // 4 / 1 = 4
	
	avg += 8;
	std::cout << avg << '\n'; // (4 + 8) / 2 = 6

	avg += 24;
	std::cout << avg << '\n'; // (4 + 8 + 24) / 3 = 12

	avg += -10;
	std::cout << avg << '\n'; // (4 + 8 + 24 - 10) / 4 = 6.5

	(avg += 6) += 10; // 2 次调用链在一起
	std::cout << avg << '\n'; // (4 + 8 + 24 - 10 + 6 + 10) / 6 = 7

	Average copy{ avg };
	std::cout << copy << '\n';

	return 0;
}

#include <iostream>
#include <cstdint> // for fixed width integers

class Average
{
private:
	std::int32_t m_total{ 0 }; // 到目前为止我们看到的所有数字的总和
	int m_numbers{ 0 }; // 到目前为止我们看到数字的计数

public:
	Average()
	{
	}

	friend std::ostream& operator<<(std::ostream& out, const Average& average)
	{
        // 处理尚未看到任何数字的情况
		if (average.m_numbers == 0)
		{
			out << 0;
			return out;
		}

		// 我们的平均值是我们看到的数字总和除以我们看到的数字计数
		// 我们需要记住这里进行浮点除法，而不是整数除法
		out << static_cast<double>(average.m_total) / average.m_numbers;

		return out;
	}

	// 因为 operator+= 修改其左操作数，我们将其写为成员函数
	Average& operator+=(std::int32_t num)
	{
		// 用新数字增加我们的总数
		m_total += num;
		// 并将计数增加 1
		++m_numbers;

		// 返回 *this 以便有人想要链式调用 '+=' 操作
		return *this;
	}
};

int main()
{
	Average avg{};
	std::cout << avg << '\n';

	avg += 4;
	std::cout << avg << '\n';
	
	avg += 8;
	std::cout << avg << '\n';

	avg += 24;
	std::cout << avg << '\n';

	avg += -10;
	std::cout << avg << '\n';

	(avg += 6) += 10; // 2 次调用链在一起
	std::cout << avg << '\n';

	Average copy{ avg };
	std::cout << copy << '\n';

	return 0;
}

显示答案

int 在某些平台上可能是16位，这意味着我们的 Average 对象只能有最大分子值32,767。使用 std::int32_t 保证32位整数值，这给了我们更大的工作范围。

#include <iostream>
#include <cassert> // for assert

class IntArray
{
private:
	int m_length{ 0 };
	int* m_array{ nullptr };

public:
	explicit IntArray(int length)
		: m_length{ length }
	{
		assert(length > 0 && "IntArray length should be a positive integer");

		m_array = new int[static_cast<std::size_t>(m_length)] {};
	}

	// 执行深拷贝的拷贝构造函数
	IntArray(const IntArray& array)
		: m_length{ array.m_length }
	{
		// 分配一个新数组
		m_array = new int[static_cast<std::size_t>(m_length)] {};

		// 将元素从原始数组复制到新数组
		for (int count{ 0 }; count < array.m_length; ++count)
			m_array[count] = array.m_array[count];
	}

	~IntArray()
	{
		delete[] m_array;
	}

	// 如果你在这里得到奇怪的值，你可能忘记在拷贝构造函数中进行深拷贝了
	friend std::ostream& operator<<(std::ostream& out, const IntArray& array)
	{
		for (int count{ 0 }; count < array.m_length; ++count)
		{
			out << array.m_array[count] << ' ';
		}
		return out;
	}

	int& operator[] (const int index)
	{
		assert(index >= 0);
		assert(index < m_length);
		return m_array[index];
	}

	// 执行深拷贝的赋值运算符
	IntArray& operator= (const IntArray& array)
	{
		// 自赋值保护
		if (this == &array)
			return *this;

		// 如果这个数组已经存在，删除它以免内存泄漏
		delete[] m_array;

		m_length = array.m_length;

		// 分配一个新数组
		m_array = new int[static_cast<std::size_t>(m_length)] {};

		// 将元素从原始数组复制到新数组
		for (int count{ 0 }; count < array.m_length; ++count)
			m_array[count] = array.m_array[count];

		return *this;
	}

};

IntArray fillArray()
{
	IntArray a(5);
	a[0] = 5;
	a[1] = 8;
	a[2] = 2;
	a[3] = 3;
	a[4] = 6;

	return a;
}

int main()
{
	IntArray a{ fillArray() };

	// 如果你在这里得到奇怪的值，你可能忘记在拷贝构造函数中进行深拷贝了
	std::cout << a << '\n';

	auto& ref{ a }; // 我们使用这个引用来避免编译器的自赋值错误
	a = ref;

	IntArray b(1);
	b = a;

	a[4] = 7; // 改变 a 中的值，b 不应改变

	// 如果你在这里得到奇怪的值，你可能忘记进行自赋值检查了
	// 如果 b 以 7 结尾，你可能忘记在拷贝赋值中进行深拷贝了
	std::cout << b << '\n';

	return 0;
}

浮点数是一个带有小数点的数字，小数点后的位数可以是可变的。定点数是一个带有小数部分的数字，其中小数部分的位数是固定的。

在这个测验中，我们将编写一个类来实现一个具有两位小数的定点数（例如 12.34、3.00 或 1278.99）。假设该类的范围应为 -32768.99 到 32767.99，小数部分应包含任意两位数字，我们不希望出现精度错误，并且我们希望节省空间。

显示答案

实现定点数有很多不同的方法。因为定点数本质上是浮点数的一个子情况（其中小数点后的位数是固定的而不是可变的），使用浮点数似乎是一个明显的选择。但浮点数存在精度问题。对于固定的小数位数，我们可以合理地枚举所有可能的小数值（在我们的例子中，.00 到 .99），因此使用具有精度问题的数据类型并不是最佳选择。

更好的解决方案是使用一个16位有符号整数来保存数字的非小数部分，以及一个8位有符号整数来保存小数部分。

#include <cassert>
#include <cstdint> // for fixed width integers
#include <iostream>

class FixedPoint2
{
private:
	std::int16_t m_base{}; // 这里是我们的小数部分
	std::int8_t m_decimal{}; // 这里是我们的小数部分

public:
	FixedPoint2(std::int16_t base = 0, std::int8_t decimal = 0)
		: m_base{ base }, m_decimal{ decimal }
	{
		// 如果数字的非小数部分和小数部分中有一个（或两个）为负数，则该数字应被视为负数
		if (m_base < 0 || m_decimal < 0)
		{
			// 确保 base 为负数
			if (m_base > 0)
				m_base = -m_base;
			// 确保 decimal 为负数
			if (m_decimal > 0)
				m_decimal = -m_decimal;
		}
	}

	explicit operator double() const
	{
		return m_base + (static_cast<double>(m_decimal) / 100);
	}
};

// 这不需要访问类的内部成员，因此可以在类外部定义
std::ostream& operator<<(std::ostream& out, const FixedPoint2& fp)
{
	out << static_cast<double>(fp);
	return out;
}

{

#include <cassert>
#include <cstdint> // for fixed width integers
#include <iostream>

class FixedPoint2
{
private:
	std::int16_t m_base{}; // 这里是我们的小数部分
	std::int8_t m_decimal{}; // 这里是我们的小数部分

public:
	FixedPoint2(std::int16_t base = 0, std::int8_t decimal = 0)
		: m_base{ base }, m_decimal{ decimal }
	{
		// 如果数字的非小数部分和小数部分中有一个（或两个）为负数，则该数字应被视为负数
		if (m_base < 0 || m_decimal < 0)
		{
			// 确保 base 为负数
			if (m_base > 0)
				m_base = -m_base;
			// 确保 decimal 为负数
			if (m_decimal > 0)
				m_decimal = -m_decimal;
		}

		// 如果 decimal 超出范围（无论哪个方向），
		// 调整 decimal 使其在范围内，
		// 并调整 base 以补偿从 decimal 中移除的单位数
		// 感谢读者 David Pinheiro 简化了这一点
		m_base += m_decimal / 100;    // 整数除法
		m_decimal = m_decimal % 100;  // 整数余数
	}

	explicit operator double() const
	{
		return m_base + (static_cast<double>(m_decimal) / 100);
	}

	friend bool testDecimal(const FixedPoint2 &fp);
};

// 这不需要访问类的内部成员，因此可以在类外部定义
std::ostream& operator<<(std::ostream& out, const FixedPoint2& fp)
{
	out << static_cast<double>(fp);
	return out;
}

// 以便该函数可以访问 FixedPoint2 的私有成员

{

		return fp.m_decimal >= 0 && fp.m_decimal < 100;

建议：这一步会有点棘手。分三步完成。首先，解决 double 参数可以直接表示的情况（变量 a 修改 c 以上）。然后，更新你的代码以处理 double 参数存在舍入误差的情况（变量 d & e）。变量 f 和 g 应由我们在上一步中添加的溢出处理来处理。

对于所有情况： 显示提示

提示：你可以通过乘以 10 将小数点右侧的一位数字移到左侧。乘以 100 可移动两位。

对于变量 a 修改 c： 显示提示

提示：你可以通过将 double 静态转换为整数来获取 double 的非小数部分。要获取小数部分，可以减去基数部分。

对于变量 d & e： 显示提示

提示：你可以使用 std::round() 函数（包含在头文件 <cmath>中）对数字（小数点左侧）进行四舍五入，并使用 std::trunc()。

显示答案

#include <cassert>
#include <cmath>
#include <cstdint> // for fixed width integers
#include <iostream>

class FixedPoint2
{
private:
	std::int16_t m_base{}; // 这里是我们的小数部分
	std::int8_t m_decimal{}; // 这里是我们的小数部分

public:
	FixedPoint2(std::int16_t base = 0, std::int8_t decimal = 0)
		: m_base{ base }, m_decimal{ decimal }
	{
		// 如果数字的非小数部分和小数部分中有一个（或两个）为负数，则该数字应被视为负数
		if (m_base < 0 || m_decimal < 0)
		{
			// 确保 base 为负数
			if (m_base > 0)
				m_base = -m_base;
			// 确保 decimal 为负数
			if (m_decimal > 0)
				m_decimal = -m_decimal;
		}

		// 如果 decimal 超出范围（无论哪个方向），
		// 调整 decimal 使其在范围内，
		// 并调整 base 以补偿从 decimal 中移除的单位数
		// 感谢读者 David Pinheiro 简化了这一点
		m_base += m_decimal / 100;    // 整数除法
		m_decimal = m_decimal % 100;  // 整数余数
	}

	// 我们将委托给之前的构造函数，这样我们就不必重复负数处理和溢出处理逻辑
	FixedPoint2(double d) :
		FixedPoint2(
			static_cast<std::int16_t>(std::trunc(d)),
			static_cast<std::int8_t>(std::round(d * 100) - std::trunc(d) * 100)
		)
	{
	}

	explicit operator double() const
	{
		return m_base + (static_cast<double>(m_decimal) / 100);
	}
};

// 这不需要访问类的内部成员，因此可以在类外部定义
std::ostream& operator<<(std::ostream& out, const FixedPoint2& fp)
{
	out << static_cast<double>(fp);
	return out;
}

int main()
{
	FixedPoint2 a{ 0.01 };
	std::cout << a << '\n';
	assert(static_cast<double>(a) == 0.01);

	FixedPoint2 b{ -0.01 };
	assert(static_cast<double>(b) == -0.01);

	FixedPoint2 c{ 1.9 }; // 确保我们处理个位数小数
	assert(static_cast<double>(c) == 1.9);
    
	FixedPoint2 d{ 5.01 }; // 存储为 5.0099999... 所以我们需要四舍五入
	assert(static_cast<double>(d) == 5.01);

	FixedPoint2 e{ -5.01 }; // 存储为 -5.0099999... 所以我们需要四舍五入
	assert(static_cast<double>(e) == -5.01);

	// 处理参数的小数四舍五入到 100 的情况（需要将 base 增加 1）
	FixedPoint2 f { 106.9978 }; // 应该存储为 base 107 和 decimal 0
	assert(static_cast<double>(f) == 107.0);

	// 处理参数的小数四舍五入到 -100 的情况（需要将 base 减少 1）
	FixedPoint2 g { -106.9978 }; // 应该存储为 base -107 和 decimal 0
	assert(static_cast<double>(g) == -107.0);

	return 0;
}

	}

	}

	{
		return fp1.m_base == fp2.m_base && fp1.m_decimal == fp2.m_decimal;

{

	in >> d;

	return in;
}

{
