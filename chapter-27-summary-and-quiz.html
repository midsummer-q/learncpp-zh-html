27.x — 第27章 总结与测验

● 机器译文 课程 27.x 查看英文原文

章节回顾

异常处理提供了一种机制，将错误或其他异常情况的处理与代码的正常控制流解耦。这使得我们可以更自由地根据具体情况选择最合适的时机和方式来处理错误，从而减轻（甚至消除）返回码带来的许多混乱。

一个 抛出 语句用于引发异常。 try 块 会查找其内部编写或调用的代码所抛出的异常。这些异常会被路由到 catch 块，这些块会捕获特定类型的异常（如果匹配）并进行处理。默认情况下，被捕获的异常被视为已处理。

异常会立即被处理。如果引发异常，控制权会跳转到最近的封闭 try 块，寻找能够处理该异常的 catch 处理程序。如果找到匹配的 try/catch，堆栈会展开到 catch 块的位置，然后控制权从匹配的 catch 顶部开始继续执行。如果没有找到 try 块或没有匹配的 catch 块，程序会调用 std::terminate，并以未处理异常错误终止。

可以抛出任何数据类型的异常，包括类。

catch 块可以配置为捕获特定数据类型的异常，也可以通过使用省略号（...）设置捕获所有异常的处理程序。捕获基类引用的 catch 块也会捕获派生类的异常。标准库抛出的所有异常都派生自 std::exception 类（位于 exception 头文件中），因此通过引用捕获 std::exception 将捕获所有标准库异常。可以使用 what() 成员函数来确定抛出了哪种 std::exception。

在 catch 块内部，可以抛出新的异常。由于这个新异常是在与该 catch 块关联的 try 块外部抛出的，因此它不会被该 catch 块捕获。可以使用关键字 throw 本身从 catch 块中重新抛出异常。不要使用捕获的异常变量重新抛出异常，否则可能导致对象切片。

函数 try 块提供了一种捕获函数内部或关联成员初始化列表中任何异常的方法。它们通常仅用于派生类构造函数。

永远不要从析构函数中抛出异常。

浮点类型的 不抛出 异常说明符可用于表示函数是不抛出/不失败的。

std::move_if_noexcept 会在对象具有 noexcept 移动构造函数时返回可移动的右值，否则返回可复制的左值。我们可以将 noexcept 说明符与 std::move_if_noexcept 结合使用，仅在存在强异常保证时使用移动语义（否则使用复制语义）。

最后，异常处理确实有成本。在大多数情况下，使用异常的代码运行速度会稍慢，并且处理异常的成本非常高。应该只在处理异常情况时使用异常，而不是用于正常的错误处理情况（例如无效输入）。

章节测验

  1. 编写一个 Fraction 类，该类具有一个接受分子和分母的构造函数。如果用户传入的分母为 0，则抛出类型为 std::runtime_error 的异常（包含在 stdexcept 头文件中）。在主程序中，要求用户输入两个整数。如果 Fraction 有效，则打印该分数。如果 Fraction 无效，则捕获 std::exception，并告知用户他们输入了无效的分数。

以下是程序一次运行的输出示例：

Enter the numerator: 5
Enter the denominator: 0
Invalid denominator

显示答案

#include <iostream>
#include <stdexcept> // for std::runtime_error
#include <exception> // for std::exception

class Fraction
{
private:
	int m_numerator = 0;
	int m_denominator = 1;

public:
	Fraction(int numerator = 0, int denominator = 1)
		: m_numerator{ numerator }
		, m_denominator{ denominator }
	{
		if (m_denominator == 0)
			throw std::runtime_error("Invalid denominator");
	}

	friend std::ostream& operator<<(std::ostream& out, const Fraction& f1);

};

std::ostream& operator<<(std::ostream& out, const Fraction& f1)
{
	out << f1.m_numerator << '/' << f1.m_denominator;
	return out;
}

int main()
{
	std::cout << "Enter the numerator: ";
	int numerator{};
	std::cin >> numerator;

	std::cout << "Enter the denominator: ";
	int denominator{};
	std::cin >> denominator;

	try
	{
		Fraction f{ numerator, denominator };
		std::cout << "Your fraction is: " << f << '\n';
	}
	catch (const std::exception& e)
	{
		std::cerr << e.what() << '\n';
	}

	return 0;
}
