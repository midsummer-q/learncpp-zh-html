快速回顾

如果对运算符的优先级有任何疑问或可能产生混淆，始终使用括号来消除歧义。

算术运算符的工作方式与常规数学中相同。取余运算符（%）返回整数除法的余数。

递增和递减运算符可用于轻松地递增或递减数字。尽可能避免使用这些运算符的后缀版本。

注意副作用，特别是在函数参数求值顺序方面。不要在同一个语句中对一个变量多次应用具有副作用的操作。

逗号运算符可以将多个语句压缩成一个。通常将语句分开写更好。

浮点类型的 条件运算符 (?:）（有时也称为 算术 if 运算符）是一个三元运算符（接受3个操作数的运算符）。给定一个形式为 c ? x : y的条件操作，如果条件 c 求值为 true 为真，则 x 将被求值，否则 y 将被求值。条件运算符通常需要加括号，如下所示：

  • 在复合表达式（包含其他运算符的表达式）中使用条件运算符时，将整个条件运算符括在括号中。
  • 为了可读性，如果条件包含任何运算符（函数调用运算符除外），请将条件括在括号中。

关系运算符可用于比较浮点数。注意在浮点数上使用相等和不等运算符。

逻辑运算符允许我们形成复合条件语句。

小测验时间

完成以下程序：

#include <iostream>

// 在此处编写函数 getQuantityPhrase()

// 在此处编写函数 getApplesPluralized()

int main()
{
    constexpr int maryApples { 3 };
    std::cout << "Mary has " << getQuantityPhrase(maryApples) << ' ' << getApplesPluralized(maryApples) << ".\n";

    std::cout << "How many apples do you have? ";
    int numApples{};
    std::cin >> numApples;

    std::cout << "You have " << getQuantityPhrase(numApples) << ' ' << getApplesPluralized(numApples) << ".\n";
 
    return 0;
}

示例输出：

Mary has a few apples.
How many apples do you have? 1
You have a single apple.

getQuantityPhrase() 应接受一个表示某物数量的 int 参数，并返回以下描述：

  • < 0 = “negative”
  • 0 = “no”
  • 1 = “a single”
  • 2 = “a couple of”
  • 3 = “a few”
  • > 3 = “many”

getApplesPluralized() 应接受一个表示苹果数量的 int 参数，并返回以下内容：

  • 1 = “apple”
  • 否则 = “apples”

此函数应使用条件运算符。

显示提示

提示：从函数返回 C 风格字符串字面量作为 std::string_view。

显示答案

#include <iostream>
#include <string_view>

std::string_view getQuantityPhrase(int num)
{
    if (num < 0)
        return "negative";
    if (num == 0)
        return "no";
    if (num == 1)
        return "a single";
    if (num == 2)
        return "a couple of";
    if (num == 3)
        return "a few";
    return "many";
}

std::string_view getApplesPluralized(int num)
{
    return (num == 1) ? "apple" : "apples";
}

int main()
{
    constexpr int maryApples { 3 };
    std::cout << "Mary has " << getQuantityPhrase(maryApples) << ' ' << getApplesPluralized(maryApples) << ".\n";

    std::cout << "How many apples do you have? ";
    int numApples{};
    std::cin >> numApples;

    std::cout << "You have " << getQuantityPhrase(numApples) << ' ' << getApplesPluralized(numApples) << ".\n";
 
    return 0;
}
