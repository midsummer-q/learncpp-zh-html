8.x — 第8章 总结与测验

章节回顾

CPU在程序中执行的具体语句序列称为程序的 执行路径。一个 直线程序 每次运行时都走相同的路径。

控制流语句 （也称为 流程控制语句）允许程序员改变正常的执行路径。当控制流语句导致程序开始执行某个非顺序的指令序列时，这被称为 分支。

一个 条件语句 是一个指定某些关联语句是否应该被执行的语句。

If 语句 允许我们根据某个条件是否为 true。 Else语句 在关联条件为 false时执行。你可以将多个if和else语句串联起来。

一个 悬垂 else 发生在当不清楚哪个 if statement 一个 else statement 与哪个语句关联时。 Dangling else 语句与最后一个未匹配的 if statement 在同一个块中匹配。因此，我们通过确保 dangling else 语句的主体放在一个块中，轻松避免 if statement 语句的问题。

一个 空语句 是一个仅由分号组成的语句。它什么也不做，用于语言要求存在语句但程序员不需要该语句执行任何操作的情况。

Switch语句 提供了一种更清晰、更快速的方法来在多个匹配项之间进行选择。Switch语句仅适用于整型类型。 Case 标签 用于标识被评估条件要匹配的值。如果找不到匹配的case标签，则执行 default标签 下面的语句。

当执行从一个标签下的语句流入后续标签下的语句时，这被称为 穿透。一个 break statement （或 return statement）可用于防止穿透。[[fallthrough]]属性可用于记录有意的穿透。

Goto 语句 允许程序跳转到代码中的其他位置，无论是向前还是向后。通常应避免使用它们，因为它们可能产生 意大利面条式代码，即程序的执行路径看起来像一碗意大利面条。

While循环 允许程序在给定条件评估为 true时循环。条件在循环执行之前评估。

一种 无限循环 是一个条件始终评估为 true的循环。除非使用其他控制流语句停止，否则这些循环将永远循环。

一个 循环变量 （也称为 counter）是一个整型变量，用于计算循环执行的次数。每次循环执行称为一次 迭代。

Do while循环 类似于while循环，但条件在循环执行之后而不是之前评估。

For循环 是最常用的循环，当你需要循环特定次数时非常理想。 差一错误 发生在循环迭代次数多一次或少一次时。

break 语句 允许我们跳出 switch、while、do while 或 for 循环（也适用于 range-based for loops，我们尚未介绍）。 continue 语句 允许我们立即进入下一次循环迭代。

终止 允许我们终止程序。 正常终止 表示程序以预期方式退出（并且 status code 将指示是否成功）。 std::exit() 在 main结束时自动调用，也可以显式调用来终止程序。它会进行一些清理，但不会清理任何局部变量，也不会展开调用栈。

C++ 包含另外两个与停止相关的函数。 发生在程序遇到某种意外错误而必须关闭时。 std::abort 可以被调用来进行异常终止。

一种 算法 是一个有限的指令序列，可以遵循它来解决某个问题或产生某个有用的结果。如果一个算法被认为是 有状态的 相反， 无状态的 算法不存储任何信息（并且必须在调用时提供它所需的所有信息）。当应用于算法时，术语 状态 指的是有状态变量中保存的当前值。

如果一个算法被认为是 确定性的 ，那么对于给定的输入（为 start提供的值），它总是产生相同的输出序列。

一个 伪随机数生成器（PRNG） 是一种生成数字序列的算法，其属性模拟随机数序列。当实例化 PRNG 时，一个称为 随机种子 （或 种子 （简称）的初始值（或一组值）可以用来初始化 PRNG 的状态。当 PRNG 用种子初始化后，我们说它已经被 播种。种子值的大小可以小于 PRNG 状态的大小。当这种情况发生时，我们说 PRNG 被 欠播种。PRNG 开始重复自身之前的序列长度称为 周期。

一个 随机数分布 将 PRNG 的输出转换为其他数字分布。一个 均匀分布 是一种随机数分布，它在两个数字X和Y之间（包括边界）以相等的概率产生输出。

问题 #1

在课程 4.x -- 第4章总结与测验，我们编写了一个程序来模拟球从塔上落下。由于当时还没有循环，球只能下落5秒。

采用下面的程序并修改它，使球下落所需的秒数直到它到达地面。更新程序以使用所有涵盖的最佳实践（命名空间、constexpr 等）。

#include <iostream>

// 从用户获取塔高并返回
double getTowerHeight()
{
	std::cout << "Enter the height of the tower in meters: ";
	double towerHeight{};
	std::cin >> towerHeight;
	return towerHeight;
}

// 返回 "seconds" 秒后的当前球高
double calculateBallHeight(double towerHeight, int seconds)
{
	const double gravity { 9.8 };
    
	// 使用公式：s = (u * t) + (a * t^2) / 2
	// 这里 u（初速度）= 0，所以 (u * t) = 0
	const double fallDistance { gravity * (seconds * seconds) / 2.0 };
	const double ballHeight { towerHeight - fallDistance };

	// 如果球会低于地面，将其放在地面上
	if (ballHeight < 0.0)
		return 0.0;
    
	return ballHeight;
}

// 打印球离地高度
void printBallHeight(double ballHeight, int seconds)
{
	if (ballHeight > 0.0)
		std::cout << "At " << seconds << " seconds, the ball is at height: " << ballHeight << " meters\n";
	else
		std::cout << "At " << seconds << " seconds, the ball is on the ground.\n";
}

// 计算当前球高并打印
// 这是一个辅助函数，使操作更简单
void calculateAndPrintBallHeight(double towerHeight, int seconds)
{
	const double ballHeight{ calculateBallHeight(towerHeight, seconds) };
	printBallHeight(ballHeight, seconds);
}

int main()
{
	const double towerHeight{ getTowerHeight() };

	calculateAndPrintBallHeight(towerHeight, 0);
	calculateAndPrintBallHeight(towerHeight, 1);
	calculateAndPrintBallHeight(towerHeight, 2);
	calculateAndPrintBallHeight(towerHeight, 3);
	calculateAndPrintBallHeight(towerHeight, 4);
	calculateAndPrintBallHeight(towerHeight, 5);
       
	return 0;
}

#include <iostream>

namespace Constants
{
	constexpr double gravity { 9.8 };
}

// 从用户获取塔高并返回
double getTowerHeight()
{
	std::cout << "Enter the height of the tower in meters: ";
	double towerHeight{};
	std::cin >> towerHeight;
	return towerHeight;
}

// 返回 "seconds" 秒后的当前球高
// // 注意：这个函数可以是 constexpr，但我们还没有介绍 constexpr 函数
double calculateBallHeight(double towerHeight, int seconds)
{
	// 使用公式：s = (u * t) + (a * t^2) / 2
	// 这里 u（初速度）= 0，所以 (u * t) = 0
	const double fallDistance { Constants::gravity * (seconds * seconds) / 2.0 };
	const double ballHeight { towerHeight - fallDistance };

	if (ballHeight < 0.0)
		return 0.0;
    
	return ballHeight;
}

// 打印球离地高度
void printBallHeight(double ballHeight, int seconds)
{
	if (ballHeight > 0.0)
		std::cout << "At " << seconds << " seconds, the ball is at height: " << ballHeight << " meters\n";
	else
		std::cout << "At " << seconds << " seconds, the ball is on the ground.\n";
}

// 计算当前球高并打印
// 这是一个辅助函数，使操作更简单
double calculateAndPrintBallHeight(double towerHeight, int seconds)
{
	const double ballHeight{ calculateBallHeight(towerHeight, seconds) };
	printBallHeight(ballHeight, seconds);

	return ballHeight;
}

int main()
{
	const double towerHeight{ getTowerHeight() };

	int seconds { 0 };
	while (calculateAndPrintBallHeight(towerHeight, seconds) > 0.0)
	{
		++seconds;
	}
       
	return 0;
}

#include <iostream>

bool isPrime(int x)
{
    return false;
    // // 使用 for 循环编写这个函数
}

int main()
{
    assert(!isPrime(0)); // // 如果 isPrime(0) 为真则终止程序
    assert(!isPrime(1));
    assert(isPrime(2));  // // 如果 isPrime(2) 为假则终止程序
    assert(isPrime(3));

    assert(isPrime(13));

相关内容

assert 是一个预处理器宏，如果关联的参数求值为 false，则终止程序。所以当我们写 assert(!isPrime(0))时，意思是“如果 isPrime(0) 为真，则终止程序”。我们在第 9.6 -- Assert 和 static_assert。

显示答案

// // 确保即使我们在发布模式下编译，assert 也会触发
#undef NDEBUG

#include <cassert> // for assert
#include <iostream>

// // 非优化版本
bool isPrime(int x)
{
    if (x <= 1) // // 如果 x 是负数、0 或 1，则该数不是质数
        return false;

    for (int test{ 2 }; test < x; ++test)
    {
        if (x % test == 0) // // 如果 x 能被整除
            return false;  // // 那么这个数不是质数
    }

    return true; // // 如果没有找到任何除数，那么 x 一定是质数
}

int main()
{
    assert(!isPrime(0));
    assert(!isPrime(1));
    assert(isPrime(2));
    assert(isPrime(3));
    assert(!isPrime(4));
    assert(isPrime(5));
    assert(isPrime(7));
    assert(!isPrime(9));
    assert(isPrime(11));
    assert(isPrime(13));
    assert(!isPrime(15));
    assert(!isPrime(16));
    assert(isPrime(17));
    assert(isPrime(19));
    assert(isPrime(97));
    assert(!isPrime(99));
    assert(isPrime(13417));

    std::cout << "Success!\n";

    return 0;
}

额外加分：

上述解决方案中的 for 循环有两个缺点：

  • 它检查偶数除数。我们不需要测试这些（除了 2）。
  • 它检查每个数直到 x 以判断它是否为除数。一个非质数（合数）必须至少有一个小于或等于其平方根的除数，因此检查超过 x 平方根的除数是不必要的。 std::sqrt(x) （在 <cmath> 头文件中）返回 x。

的平方根。对于后者，我们有两个选择：在循环之前计算 std::sqrt(x) ，然后测试循环变量与该值。或者，我们可以通过比较两边平方来完全优化 std::sqrt(x) （感谢读者 JJag 的建议）（如果需要更多帮助，请查看提示）。我们将在测验解决方案中使用后一种选项。

显示提示

提示：给定两个变量 a >= 0 和 b >= 0，我们可以对比较 a <= sqrt(b) 的两边进行平方，比较仍然成立。这给出了 a * a <= sqrt(b) * sqrt(b)，这相当于 a * a <= b。

更新上述解决方案以实现这两个优化。

显示答案

#include <cassert>
#include <cmath> // for std::sqrt
#include <iostream>

// // 优化版本
bool isPrime(int x)
{
    if (x <= 1)     // // 如果 x 是负数、0 或 1，则该数不是质数
        return false;
    if (x == 2)     // // 数字 2 是唯一的偶质数
        return true;
    if (x % 2 == 0) // // 任何其他偶数都不是质数
        return false;

    // // 对于任何大于等于 3 的数，测试奇数（这就是我们加 2 的原因）
    // // 在 3 和 sqrt(x) 之间，看它们是否是除数
    // // 另请参阅 https://stackoverflow.com/questions/5811151/why-do-we-check-up-to-the-square-root-of-a-number-to-determine-if-the-number-is
    // // 由于 test >= 0 且 x >= 0，我们可以将 test < std::sqrt(x) 优化为 test * test < x
    for (int test{ 3 }; test * test <= x; test += 2)
    {
        if (x % test == 0) // // 如果 x 能被整除
            return false;  // // 那么这个数不是质数
    }

    return true; // // 如果没有找到任何除数，那么 x 一定是质数
}

int main()
{
    assert(!isPrime(0));
    assert(!isPrime(1));
    assert(isPrime(2));
    assert(isPrime(3));
    assert(!isPrime(4));
    assert(isPrime(5));
    assert(isPrime(7));
    assert(!isPrime(9));
    assert(isPrime(11));
    assert(isPrime(13));
    assert(!isPrime(15));
    assert(!isPrime(16));
    assert(isPrime(17));
    assert(isPrime(19));
    assert(isPrime(97));
    assert(!isPrime(99));
    assert(isPrime(13417));

    std::cout << "Success!\n";

    return 0;
}

问题 #3

实现一个 Hi-Lo 游戏。首先，你的程序应该随机选择一个介于 1 和 100 之间的整数。用户有 7 次机会猜这个数字。

如果用户没有猜对数字，程序应告诉他们猜高了还是猜低了。如果用户猜对了数字，程序应告诉他们赢了。如果猜的次数用完了，程序应告诉他们输了，并显示正确的数字。游戏结束时，应询问用户是否想再玩一次。如果用户没有输入 'y' 或 'n'，则再次询问。

对于这个测验，假设用户输入一个有效的数字。

显示答案

#include <iostream>
#include "Random.h" // https://www.learncpp.com/cpp-tutorial/global-random-numbers-random-h/

// // 如果用户赢了返回 true，输了返回 false
// 我们在这个程序中不使用返回值，但拥有它并不会增加复杂性，并且在未来的更新中可能会有用
// （例如，如果我们想将赢/输消息移出函数，或者根据赢/输条件化其他行为）
bool playHiLo(int guesses, int min, int max)
{
	std::cout << "Let's play a game. I'm thinking of a number between " << min << " and " << max << ". You have " << guesses << " tries to guess what it is.\n";
	const int number { Random::get(min, max) }; // 这是用户需要猜测的数字

	// 遍历所有猜测
	for (int count{ 1 }; count <= guesses; ++count)
	{
		std::cout << "Guess #" << count << ": ";

		int guess{};
		std::cin >> guess;

		if (guess > number)
			std::cout << "Your guess is too high.\n";
		else if (guess < number)
			std::cout << "Your guess is too low.\n";
		else // 猜测 == 数字，所以用户赢了
		{
			std::cout << "Correct! You win!\n";
			return true;
		}
	}

	// 用户输了
	std::cout << "Sorry, you lose. The correct number was " << number << '\n';
	return false;
}

bool playAgain()
{
	// 不断询问用户是否想再玩一次，直到他们选择 y 或 n。
	while (true)
	{
		char ch{};
		std::cout << "Would you like to play again (y/n)? ";
		std::cin >> ch;

		switch (ch)
		{
		case 'y': return true;
		case 'n': return false;
		}
	}
}

int main()
{
	constexpr int guesses { 7 }; // 用户有这么多猜测次数
	constexpr int min     { 1 };
	constexpr int max     { 100 };

	do
	{
		playHiLo(guesses, min, max);
	} while (playAgain());

	std::cout << "Thank you for playing.\n";

	return 0;
}
