13.14 — 类模板参数推导（CTAD）与推导指引

● 机器译文 课程 13.14 查看英文原文

类模板参数推导（CTAD） C++17

从 C++17 开始，当从类模板实例化对象时，编译器可以从对象的初始化器类型推导出模板类型（这被称为 类模板参数推导 或 CTAD ）。例如：

#include <utility> // for std::pair

int main()
{
    std::pair<int, int> p1{ 1, 2 }; // 显式指定类模板 std::pair<int, int>（C++11 起）
    std::pair p2{ 1, 2 };           // 使用 CTAD 从初始化器推导出 std::pair<int, int>（C++17）

    return 0;
}

CTAD 仅在未提供模板参数列表时执行。因此，以下两种情况都是错误的：

#include <utility> // for std::pair

int main()
{
    std::pair<> p1 { 1, 2 };    // 错误：模板参数太少，两个参数均未推导
    std::pair<int> p2 { 3, 4 }; // 错误：模板参数太少，第二个参数未推导

    return 0;
}

作者注

本网站的许多后续课程都会使用 CTAD。如果你使用 C++14 标准（或更早版本）编译这些示例，你会收到关于缺少模板参数的错误。你需要显式地向示例添加这些参数才能使其编译。

由于 CTAD 是一种类型推导形式，我们可以使用字面量后缀来改变推导出的类型：

#include <utility> // for std::pair

int main()
{
    std::pair p1 { 3.4f, 5.6f }; // 推导为 pair<float, float>
    std::pair p2 { 1u, 2u };     // 推导为 pair<unsigned int, unsigned int>

    return 0;
}

模板参数推导指引 C++17

在大多数情况下，CTAD 开箱即用。然而，在某些情况下，编译器可能需要一点额外的帮助来理解如何正确推导模板参数。

你可能会惊讶地发现，以下程序（与上面使用 std::pair 的示例几乎相同）在 C++17 中无法编译：

// 定义我们自己的 Pair 类型
template <typename T, typename U>
struct Pair
{
    T first{};
    U second{};
};

int main()
{
    Pair<int, int> p1{ 1, 2 }; // ok：我们显式指定了模板参数
    Pair p2{ 1, 2 };           // 在 C++17 中编译错误（在 C++20 中正常）

    return 0;
}

如果你在 C++17 中编译此代码，你可能会收到类似“类模板参数推导失败”或“无法推导模板参数”或“没有可行的构造函数或推导指引”的错误。这是因为在 C++17 中，CTAD 不知道如何为聚合类模板推导模板参数。为了解决这个问题，我们可以向编译器提供一个 推导指引，它告诉编译器如何为给定的类模板推导模板参数。

以下是带有推导指引的相同程序：

template <typename T, typename U>
struct Pair
{
    T first{};
    U second{};
};

// 这是为我们的 Pair 提供的推导指引（仅在 C++17 中需要）
// 用类型 T 和 U 的参数初始化的 Pair 对象应推导为 Pair<T, U>
template <typename T, typename U>
Pair(T, U) -> Pair<T, U>;
    
int main()
{
    Pair<int, int> p1{ 1, 2 }; // 显式指定类模板 Pair<int, int>（C++11 起）
    Pair p2{ 1, 2 };           // 使用 CTAD 从初始化器推导出 Pair<int, int>（C++17）

    return 0;
}

这个示例应该在 C++17 下编译。

我们的 Pair 类的推导指引非常简单，但让我们仔细看看它是如何工作的。

// 这是为我们的 Pair 提供的推导指引（仅在 C++17 中需要）
// 用类型 T 和 U 的参数初始化的 Pair 对象应推导为 Pair<T, U>
template <typename T, typename U>
Pair(T, U) -> Pair<T, U>;

首先，我们使用与我们的 Pair 类相同的模板类型定义。这是有道理的，因为如果我们的推导指引要告诉编译器如何推导 Pair<T, U>的类型，我们必须定义 T 和 U 是什么（模板类型）。其次，在箭头的右侧，我们放置了我们要帮助编译器推导的类型。在这种情况下，我们希望编译器能够推导出类型为 Pair<T, U>的对象的模板参数，所以我们在这里放的就是这个。最后，在箭头的左侧，我们告诉编译器要查找什么样的声明。在这种情况下，我们告诉它查找一个名为 Pair 的对象声明，该对象有两个参数（一个类型为 T，另一个类型为 U）。我们也可以将其写为 Pair(T t, U u) （其中 t 和 u 是参数的名称，但由于我们不使用 t 和 u，我们不需要给它们命名）。

综上所述，我们告诉编译器，如果它看到一个 Pair 的声明，带有两个参数（类型分别为 T 和 U ），它应该将类型推导为 Pair<T, U>。

因此，当编译器在程序中看到定义 Pair p2{ 1, 2 }; 时，它会说：“哦，这是一个 Pair 的声明，有两个类型为 int 和 int的参数，所以使用推导指引，我应该将其推导为 Pair<int, int>“。

” 以下是一个类似的示例，针对采用单个模板类型的 Pair：

template <typename T>
struct Pair
{
    T first{};
    T second{};
};

// 这是为我们的 Pair 提供的推导指引（仅在 C++17 中需要）
// 用类型 T 和 T 的参数初始化的 Pair 对象应推导为 Pair<T>
template <typename T>
Pair(T, T) -> Pair<T>;

int main()
{
    Pair<int> p1{ 1, 2 }; // 显式指定类模板 Pair<int>（C++11 起）
    Pair p2{ 1, 2 };      // CTAD 用于从初始化器中推导 Pair<int>（C++17）

    return 0;
}

在这种情况下，我们的推导指引将一个 Pair(T, T) （一个 Pair 带有两个类型参数 T）转换为 Pair<T>。

提示

C++20 增加了编译器自动为聚合体生成推导指引的能力，因此推导指引通常只需为 C++17 兼容性提供。

因此，没有推导指引的 Pair 版本在 C++20 中应该能够编译。

std::pair （以及其他标准库模板类型）带有预定义的推导指引，这就是为什么我们上面使用 std::pair 的示例在 C++17 中无需我们自己提供推导指引就能正常编译。

进阶读者

非聚合体在 C++17 中不需要推导指引，因为构造函数的存在起到了相同的作用。

带默认值的类型模板参数

就像函数参数可以有默认实参一样，模板参数也可以被赋予默认值。当模板参数没有显式指定且无法推导时，将使用这些默认值。

下面是我们 Pair<T, U> 类模板程序的修改版本，其中类型模板参数 T 和 U 默认类型为 int：

template <typename T=int, typename U=int> // 默认 T 和 U 为 int 类型
struct Pair
{
    T first{};
    U second{};
};

template <typename T, typename U>
Pair(T, U) -> Pair<T, U>;

int main()
{
    Pair<int, int> p1{ 1, 2 }; // 显式指定类模板 Pair<int, int>（C++11 起）
    Pair p2{ 1, 2 };           // 使用 CTAD 从初始化器推导出 Pair<int, int>（C++17）

    Pair p3;                   // 使用默认的 Pair<int, int>

    return 0;
}

我们对 p3 的定义没有显式指定类型模板参数的类型，也没有初始化器可以从中推导这些类型。因此，编译器将使用默认值中指定的类型，这意味着 p3 产生一个 int 结果，因此变量 Pair<int, int>。

CTAD 不适用于非静态成员初始化

当使用非静态成员初始化初始化类类型的成员时，CTAD 在此上下文中不起作用。所有模板参数必须显式指定：

#include <utility> // for std::pair

struct Foo
{
    std::pair<int, int> p1{ 1, 2 }; // ok，模板参数显式指定
    std::pair p2{ 1, 2 };           // 编译错误，CTAD 不能在此上下文中使用
};

int main()
{
    std::pair p3{ 1, 2 };           // ok，CTAD 可以在此处使用
    return 0;
}

CTAD 不适用于函数参数

CTAD 代表类模板 实参 推导，而不是类模板 形参 推导，因此它只会推导模板参数的类型，而不是模板参数本身。

因此，CTAD 不能用于函数参数。

#include <iostream>
#include <utility>

void print(std::pair p) // 编译错误，CTAD 不能在此处使用
{
    std::cout << p.first << ' ' << p.second << '\n';
}

int main()
{
    std::pair p { 1, 2 }; // p 被推导为 std::pair<int, int>
    print(p);

    return 0;
}

在这种情况下，你应该使用模板代替：

#include <iostream>
#include <utility>

template <typename T, typename U>
void print(std::pair<T, U> p)
{
    std::cout << p.first << ' ' << p.second << '\n';
}

int main()
{
    std::pair p { 1, 2 }; // p 被推导为 std::pair<int, int>
    print(p);

    return 0;
}
