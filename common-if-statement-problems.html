8.3 — 常见的 if 语句问题

● 机器译文 课程 8.3 查看英文原文

本课是课程 8.2 -- If statements and blocks的延续。在本课中，我们将探讨使用 if 语句时出现的一些常见问题。

嵌套 if 语句与悬垂 else 问题

可以在其他 if 语句中嵌套 if 语句：

#include <iostream>

int main()
{
    std::cout << "Enter a number: ";
    int x{};
    std::cin >> x;

    if (x >= 0) // 外部 if 语句
        // 以这种方式嵌套 if 语句是不良的编码风格
        if (x <= 20) // 内部 if 语句
            std::cout << x << " is between 0 and 20\n";

    return 0;
}

现在考虑以下程序：

#include <iostream>

int main()
{
    std::cout << "Enter a number: ";
    int x{};
    std::cin >> x;

    if (x >= 0) // 外部 if 语句
        // 以这种方式嵌套 if 语句是不良的编码风格
        if (x <= 20) // 内部 if 语句
            std::cout << x << " is between 0 and 20\n";

    // 这个 else 属于哪个 if 语句？
    else
        std::cout << x << " is negative\n";

    return 0;
}

上述程序引入了一个潜在的歧义来源，称为 悬垂 else 问题。上述程序中的 else 语句是与外部 if 语句匹配还是与内部 if 语句匹配？

答案是，else 语句与同一块中最后一个未匹配的 if 语句配对。因此，在上述程序中，else 语句与内部 if 语句匹配，就好像程序是这样写的：

#include <iostream>

int main()
{
    std::cout << "Enter a number: ";
    int x{};
    std::cin >> x;

    if (x >= 0) // 外部 if 语句
    {
        if (x <= 20) // 内部 if 语句
            std::cout << x << " is between 0 and 20\n";
        else // 附加到内部 if 语句
            std::cout << x << " is negative\n";
    }

    return 0;
}

这导致上述程序产生错误的输出：

Enter a number: 21
21 is negative

为了避免嵌套 if 语句时出现此类歧义，最好将内部 if 语句显式地包含在一个块中。这样我们就可以将 else 语句明确地附加到内部或外部 if 语句上：

#include <iostream>

int main()
{
    std::cout << "Enter a number: ";
    int x{};
    std::cin >> x;

    if (x >= 0)
    {
        if (x <= 20)
            std::cout << x << " is between 0 and 20\n";
        else // 附加到内部 if 语句
            std::cout << x << " is greater than 20\n";
    }
    else // 附加到外部 if 语句
        std::cout << x << " is negative\n";

    return 0;
}

块内的 else 语句附加到内部 if 语句，块外的 else 语句附加到外部 if 语句。

展平嵌套的 if 语句

嵌套的 if 语句通常可以通过重构逻辑或使用逻辑运算符（在课程 6.8 -- 逻辑运算符中介绍）来展平。嵌套较少的代码更不容易出错。

例如，上面的例子可以展平如下：

#include <iostream>

int main()
{
    std::cout << "Enter a number: ";
    int x{};
    std::cin >> x;

    if (x < 0)
        std::cout << x << " is negative\n";
    else if (x <= 20) // 仅在 x >= 0 时执行
        std::cout << x << " is between 0 and 20\n";
    else // 仅在 x > 20 时执行
        std::cout << x << " is greater than 20\n";

    return 0;
}

下面是另一个例子，它使用逻辑运算符在单个 if 语句中检查多个条件：

#include <iostream>

int main()
{
    std::cout << "Enter an integer: ";
    int x{};
    std::cin >> x;

    std::cout << "Enter another integer: ";
    int y{};
    std::cin >> y;

    if (x > 0 && y > 0) // && 是逻辑与——检查两个条件是否都为真
        std::cout << "Both numbers are positive\n";
    else if (x > 0 || y > 0) // || 是逻辑或——检查任一条件是否为真
        std::cout << "One of the numbers is positive\n";
    else
        std::cout << "Neither number is positive\n";

    return 0;
}

空语句

一个 空语句 是一种只包含一个分号的表达式语句：

if (x > 10)
    ; // 这是一个空语句

空语句不执行任何操作。它们通常用于语言要求存在语句但程序员不需要语句的情况。为了可读性，空语句通常放在单独的行上。我们将在本章后面介绍循环时看到有意使用空语句的例子。

空语句很少有意与 if 语句一起使用。然而，它们可能会无意中给新手（或粗心的）程序员带来问题。考虑以下代码片段：

if (nuclearCodesActivated()); // 注意这一行末尾的分号
    blowUpTheWorld();

在上面的代码片段中，程序员不小心在 if 语句的末尾放了一个分号（这是一个常见错误，因为分号结束许多语句）。这个看似无害的错误可以正常编译，并导致代码片段像这样执行：

if (nuclearCodesActivated())
    ; // 分号充当空语句
blowUpTheWorld(); // 而这一行总是被执行！

警告

注意不要用分号“终止”你的 if 语句，否则你想要有条件执行的语句将无条件执行（即使它们在一个块内）。

提示

在 Python 中， pass 关键字充当空语句。它通常用作稍后实现的代码的占位符。因为它是一个单词而不是符号， pass 不太容易被误用，并且更易于搜索（允许你稍后轻松找到这些占位符）。

for x in [0, 1, 2]:
  pass               # To be completed in the future

在 C++ 中，我们可以通过使用预处理器来模拟 pass ：

#define PASS

void foo(int x, int y)
{
    if (x > y)
        PASS;
    else
        PASS;
}

int main()
{
    foo(4, 7);

    return 0;
}

为了与其他 C++ 语句保持一致，我们的 PASS 需要一个尾随分号。 PASS 被预处理器剥离，尾随分号被编译器解释为空语句。

条件中的 operator== 与 operator=

在你的条件中，你应该使用 operator== 来测试相等性，而不是 operator= （这是赋值）。考虑以下程序：

#include <iostream>

int main()
{
    std::cout << "Enter 0 or 1: ";
    int x{};
    std::cin >> x;
    if (x = 0) // 哎呀，我们在这里使用了赋值而不是相等性测试
        std::cout << "You entered 0\n";
    else
        std::cout << "You entered 1\n";

    return 0;
}

这个程序可以编译并运行，但在某些情况下会产生错误的结果：

Enter 0 or 1: 0
You entered 1

事实上，这个程序总是产生结果 You entered 1。这是因为 x = 0 首先将值 0 切换到 x，然后求值为 x，现在是 0，这是布尔值 false。由于条件总是 false，所以 else 语句总是执行。
