23.6 — 容器类

● 机器译文 课程 23.6 查看英文原文

在现实生活中，我们无时无刻不在使用容器。你的早餐麦片装在盒子里，书页被封面和装订包裹，你可以在车库里用容器存放各种物品。没有容器，处理这些对象会极其不便。想象一下，读一本没有装订的书，或者吃没有碗装的麦片，那将是一团糟。容器提供的价值主要在于它能够帮助组织和存储放入其中的物品。

中讨论了一种常见的不变量类型，称为“类不变量”。类似地， 容器类 是一种设计用于持有和组织另一种类型（另一个类或基本类型）的多个实例的类。有许多不同种类的容器类，每种都有各自的优点、缺点和使用限制。编程中最常用的容器是数组，你已经见过很多例子了。尽管C++有内置的数组功能，但程序员通常使用数组容器类（std::array或std::vector），因为它们提供了额外的优势。与内置数组不同，数组容器类通常提供动态调整大小（当添加或删除元素时）、在传递给函数时记住其大小，并进行边界检查。这不仅使数组容器类比普通数组更方便，也更安全。

容器类通常实现一套相当标准化的最小功能集。大多数定义良好的容器将包含以下函数：

  • 创建一个空容器（通过构造函数）
  • 向容器中插入一个新对象
  • 从容器中移除一个对象
  • 报告容器中当前对象的数量
  • 清空容器中的所有对象
  • 提供对存储对象的访问
  • 对元素进行排序（可选）

有时某些容器类会省略其中一些功能。例如，数组容器类通常省略插入和删除函数，因为它们速度慢，并且类设计者不希望鼓励使用它们。

容器类实现了一种“成员属于”关系。例如，数组的元素是数组的成员（属于数组）。注意，我们使用的是“成员属于”的常规含义，而不是C++类成员的含义。

容器的类型

容器类通常有两种不同的变体。 值容器 是 组合 存储它们所持有的对象的副本（因此负责创建和销毁这些副本）。 引用容器 是 聚合 存储指向其他对象的指针或引用（因此不负责创建或销毁这些对象）。

与现实生活中容器可以容纳你放入的任何类型对象不同，在C++中，容器通常只持有一种数据类型。例如，如果你有一个整数数组，它只会持有整数。与某些其他语言不同，许多C++容器不允许你随意混合类型。如果你需要容器同时持有整数和双精度浮点数，通常必须编写两个单独的容器来实现（或者使用模板，这是一个高级C++特性）。尽管使用上有这些限制，容器仍然非常有用，它们使编程更简单、更安全、更快速。

一个数组容器类

在这个例子中，我们将从头编写一个整数数组类，实现容器应具备的大部分常见功能。这个数组类将是一个值容器，它将持有它组织的元素的副本。顾名思义，该容器将持有一个整数数组，类似于 std::vector<int>。

首先，让我们创建IntArray.h文件：

#ifndef INTARRAY_H
#define INTARRAY_H

class IntArray
{
};

#endif

我们的IntArray需要跟踪两个值：数据本身和数组的大小。因为我们希望数组能够改变大小，所以必须进行一些动态分配，这意味着我们必须使用指针来存储数据。

#ifndef INTARRAY_H
#define INTARRAY_H

class IntArray
{
private:
    int m_length{};
    int* m_data{};
};

#endif

现在我们需要添加一些构造函数，以便能够创建IntArray。我们将添加两个构造函数：一个构造空数组，另一个允许我们构造一个预定大小的数组。

#ifndef INTARRAY_H
#define INTARRAY_H

#include <cassert> // for assert()
#include <cstddef> // for std::size_t

class IntArray
{
private:
    int m_length{};
    int* m_data{};

public:
    IntArray() = default;

    IntArray(int length):
        m_length{ length }
    {
        assert(length >= 0);

        if (length > 0)
            m_data = new int[static_cast<std::size_t>(length)]{};
    }
};

#endif

我们还需要一些函数来帮助清理IntArray。首先，我们将编写一个析构函数，它简单地释放任何动态分配的数据。其次，我们将编写一个名为erase()的函数，它将擦除数组并将长度设置为0。

    ~IntArray()
    {
        delete[] m_data;
        // 我们不需要在此处将 m_data 设置为 null 或将 m_length 设置为 0，因为该函数执行后对象将立即被销毁
    }

    void erase()
    {
        delete[] m_data;

        // 我们需要确保在此处将 m_data 设置为 nullptr，否则它将
        // 指向已释放的内存！
        m_data = nullptr;
        m_length = 0;
    }

现在让我们重载[]运算符，以便我们可以访问数组的元素。我们应该确保索引参数具有有效值，这可以通过使用assert()函数来实现。我们还将添加一个访问函数来返回数组的长度。到目前为止的代码如下：

#ifndef INTARRAY_H
#define INTARRAY_H

#include <cassert> // for assert()
#include <cstddef> // for std::size_t

class IntArray
{
private:
    int m_length{};
    int* m_data{};

public:
    IntArray() = default;

    IntArray(int length):
        m_length{ length }
    {
        assert(length >= 0);

        if (length > 0)
            m_data = new int[static_cast<std::size_t>(length)]{};
    }

    ~IntArray()
    {
        delete[] m_data;
        // 我们不需要在此处将 m_data 设置为 null 或将 m_length 设置为 0，因为该函数执行后对象将立即被销毁
    }

    void erase()
    {
        delete[] m_data;
        // 我们需要确保在此处将 m_data 设置为 nullptr，否则它将
        // 指向已释放的内存！
        m_data = nullptr;
        m_length = 0;
    }

    int& operator[](int index)
    {
        assert(index >= 0 && index < m_length);
        return m_data[index];
    }

    int getLength() const { return m_length; }
};

#endif

至此，我们已经有了一个可以使用的IntArray类。我们可以分配给定大小的IntArray，并且可以使用[]运算符来检索或更改元素的值。

然而，我们的IntArray仍然有一些事情不能做。我们仍然不能改变它的大小，仍然不能插入或删除元素，仍然不能对它进行排序。复制数组也会引起问题，因为那将浅拷贝数据指针。

首先，让我们编写一些代码来允许调整数组大小。我们将编写两个不同的函数来实现这一点。第一个函数reallocate()会在调整大小时销毁数组中的任何现有元素，但它会很快。第二个函数resize()会在调整大小时保留数组中的任何现有元素，但它会很慢。

#include <algorithm> // for std::copy_n

    // reallocate 调整数组大小。任何现有元素都将被销毁。此函数操作快速。
    void reallocate(int newLength)
    {
        // 首先我们删除任何现有元素
        erase();

        // 如果我们的数组将为空，则在此处返回
        if (newLength <= 0)
            return;

        // 然后我们必须分配新元素
        m_data = new int[static_cast<std::size_t>(newLength)];
        m_length = newLength;
    }

    // resize 调整数组大小。任何现有元素都将保留。此函数操作缓慢。
    void resize(int newLength)
    {
        // 如果数组长度已经合适，我们就完成了
        if (newLength == m_length)
            return;

        // 如果我们要调整大小为空数组，则执行该操作并返回
        if (newLength <= 0)
        {
            erase();
            return;
        }

        // 现在我们可以假设 newLength 至少为 1 个元素。此算法
        // 的工作原理如下：首先我们将分配一个新数组。然后我们
        // 将元素从现有数组复制到新数组。
        // 完成后，我们可以销毁旧数组，并使 m_data
        // 指向新数组。

        // 首先我们必须分配一个新数组
        int* data{ new int[static_cast<std::size_t>(newLength)] };

        // 然后我们必须确定要从现有数组复制多少个元素到
        // 新数组。我们希望复制尽可能多的元素，数量为
        // 两个数组中较小的那个的大小。
        if (m_length > 0)
        {
            int elementsToCopy{ (newLength > m_length) ? m_length : newLength };
            std::copy_n(m_data, elementsToCopy, data); // 复制元素
        }
 
        // 现在我们可以删除旧数组，因为我们不再需要它
        delete[] m_data;

        // 并使用新数组！请注意，这只是使 m_data 指向
        // 与我们动态分配的新数组相同的地址。因为
        // 数据是动态分配的，所以当它超出作用域时不会被销毁。
        m_data = data;
        m_length = newLength;
    }

呼！这有点棘手！

让我们也添加一个拷贝构造函数和赋值运算符，以便我们可以复制数组。

    IntArray(const IntArray& a): IntArray(a.getLength()) // 使用普通构造函数适当设置数组大小
    {
        std::copy_n(a.m_data, m_length, m_data); // 复制元素
    }

    IntArray& operator=(const IntArray& a)
    {
        // 自赋值检查
        if (&a == this)
            return *this;

        // 适当设置新数组的大小
        reallocate(a.getLength());
        std::copy_n(a.m_data, m_length, m_data); // 复制元素

        return *this;
    }

许多数组容器类会在这里停止。然而，以防你想看看插入和删除功能如何实现，我们将继续编写它们。这两种算法都与resize()非常相似。

   void insertBefore(int value, int index)
    {
        // 检查我们的索引值是否合理
        assert(index >= 0 && index <= m_length);

        // 首先创建一个比旧数组大一个元素的新数组
        int* data{ new int[static_cast<std::size_t>(m_length+1)] };

        // 复制索引之前的所有元素
        std::copy_n(m_data, index, data); 

        // 将我们的新元素插入到新数组中
        data[index] = value;

        // 复制插入元素之后的所有值
        std::copy_n(m_data + index, m_length - index, data + index + 1);

        // 最后，删除旧数组，改用新数组
        delete[] m_data;
        m_data = data;
        ++m_length;
    }

    void remove(int index)
    {
        // 检查我们的索引值是否合理
        assert(index >= 0 && index < m_length);

        // 如果这是数组中最后一个剩余元素，则将数组设为空并退出
        if (m_length == 1)
        {
            erase();
            return;
        }

        // 首先创建一个比旧数组少一个元素的新数组
        int* data{ new int[static_cast<std::size_t>(m_length-1)] };

        // 复制索引之前的所有元素
        std::copy_n(m_data, index, data); 

        // 复制被删除元素之后的所有值
        std::copy_n(m_data + index + 1, m_length - index - 1, data + index); 

        // 最后，删除旧数组，改用新数组
        delete[] m_data;
        m_data = data;
        --m_length;
    }

以下是我们的IntArray容器类的完整代码。

IntArray.h:

#ifndef INTARRAY_H
#define INTARRAY_H

#include <algorithm> // for std::copy_n
#include <cassert> // for assert()
#include <cstddef> // for std::size_t

class IntArray
{
private:
    int m_length{};
    int* m_data{};

public:
    IntArray() = default;

    IntArray(int length):
        m_length{ length }
    {
        assert(length >= 0);

        if (length > 0)
            m_data = new int[static_cast<std::size_t>(length)]{};
    }

    ~IntArray()
    {
        delete[] m_data;
        // 我们不需要在此处将 m_data 设置为 null 或将 m_length 设置为 0，因为该函数执行后对象将立即被销毁
    }

    IntArray(const IntArray& a): IntArray(a.getLength()) // 使用普通构造函数适当设置数组大小
    {
        std::copy_n(a.m_data, m_length, m_data); // 复制元素
    }

    IntArray& operator=(const IntArray& a)
    {
        // 自赋值检查
        if (&a == this)
            return *this;

        // 适当设置新数组的大小
        reallocate(a.getLength());
        std::copy_n(a.m_data, m_length, m_data); // 复制元素

        return *this;
    }

    void erase()
    {
        delete[] m_data;
        // 我们需要确保在此处将 m_data 设置为 nullptr，否则它将
        // 指向已释放的内存！
        m_data = nullptr;
        m_length = 0;
    }

    int& operator[](int index)
    {
        assert(index >= 0 && index < m_length);
        return m_data[index];
    }


    // reallocate 调整数组大小。任何现有元素都将被销毁。此函数操作快速。
    void reallocate(int newLength)
    {
        // 首先我们删除任何现有元素
        erase();

        // 如果我们的数组将为空，则在此处返回
        if (newLength <= 0)
            return;

        // 然后我们必须分配新元素
        m_data = new int[static_cast<std::size_t>(newLength)];
        m_length = newLength;
    }

    // resize 调整数组大小。任何现有元素都将保留。此函数操作缓慢。
    void resize(int newLength)
    {
        // 如果数组长度已经合适，我们就完成了
        if (newLength == m_length)
            return;

        // 如果我们要调整大小为空数组，则执行该操作并返回
        if (newLength <= 0)
        {
            erase();
            return;
        }

        // 现在我们可以假设 newLength 至少为 1 个元素。此算法
        // 的工作原理如下：首先我们将分配一个新数组。然后我们
        // 将元素从现有数组复制到新数组。
        // 完成后，我们可以销毁旧数组，并使 m_data
        // 指向新数组。

        // 首先我们必须分配一个新数组
        int* data{ new int[static_cast<std::size_t>(newLength)] };

        // 然后我们必须确定要从现有数组复制多少个元素到
        // 新数组。我们希望复制尽可能多的元素，数量为
        // 两个数组中较小的那个的大小。
        if (m_length > 0)
        {
            int elementsToCopy{ (newLength > m_length) ? m_length : newLength };
            std::copy_n(m_data, elementsToCopy, data); // 复制元素
        }
 
        // 现在我们可以删除旧数组，因为我们不再需要它
        delete[] m_data;

        // 并使用新数组！请注意，这只是使 m_data 指向
        // 与我们动态分配的新数组相同的地址。因为
        // 数据是动态分配的，所以当它超出作用域时不会被销毁。
        m_data = data;
        m_length = newLength;
    }

    void insertBefore(int value, int index)
    {
        // 检查我们的索引值是否合理
        assert(index >= 0 && index <= m_length);

        // 首先创建一个比旧数组大一个元素的新数组
        int* data{ new int[static_cast<std::size_t>(m_length+1)] };

        // 复制索引之前的所有元素
        std::copy_n(m_data, index, data); 

        // 将我们的新元素插入到新数组中
        data[index] = value;

        // 复制插入元素之后的所有值
        std::copy_n(m_data + index, m_length - index, data + index + 1);

        // 最后，删除旧数组，改用新数组
        delete[] m_data;
        m_data = data;
        ++m_length;
    }

    void remove(int index)
    {
        // 检查我们的索引值是否合理
        assert(index >= 0 && index < m_length);

        // 如果这是数组中最后一个剩余元素，则将数组设为空并退出
        if (m_length == 1)
        {
            erase();
            return;
        }

        // 首先创建一个比旧数组少一个元素的新数组
        int* data{ new int[static_cast<std::size_t>(m_length-1)] };

        // 复制索引之前的所有元素
        std::copy_n(m_data, index, data); 

        // 复制被删除元素之后的所有值
        std::copy_n(m_data + index + 1, m_length - index - 1, data + index); 

        // 最后，删除旧数组，改用新数组
        delete[] m_data;
        m_data = data;
        --m_length;
    }

    // 一些额外的函数，仅为了方便
    void insertAtBeginning(int value) { insertBefore(value, 0); }
    void insertAtEnd(int value) { insertBefore(value, m_length); }

    int getLength() const { return m_length; }
};

#endif

现在，让我们测试一下以证明它有效：

#include <iostream>
#include "IntArray.h"

int main()
{
    // 声明一个包含10个元素的数组
    IntArray array(10);

    // 用数字1到10填充数组
    for (int i{ 0 }; i<10; ++i)
        array[i] = i+1;

    // 将数组大小调整为8个元素
    array.resize(8);

    // 在索引5的元素之前插入数字20
    array.insertBefore(20, 5);

    // 删除索引为3的元素
    array.remove(3);

    // 在末尾和开头分别添加30和40
    array.insertAtEnd(30);
    array.insertAtBeginning(40);

    // 更多测试以确保复制构造/赋值数组
    // 不会破坏任何东西
    {
        IntArray b{ array };
        b = array;
        b = b;
        array = array;
    }

    // 打印所有数字
    for (int i{ 0 }; i<array.getLength(); ++i)
        std::cout << array[i] << ' ';

    std::cout << '\n';

    return 0;
}

这会产生以下结果：

40 1 2 3 5 20 6 7 8 30

尽管编写容器类可能相当复杂，但好消息是你只需要编写一次。一旦容器类工作正常，你就可以随意使用和重用，无需额外的编程工作。

一些可以/应该做的额外改进：

  • 我们可以将其做成模板类，这样它就能适用于任何可复制类型，而不仅仅是 int。
  • 我们应该添加各种成员函数的 const 重载，以正确支持 const IntArray。
  • 我们应该添加对移动语义的支持（通过添加移动构造函数和移动赋值运算符）。
  • 在执行调整大小或插入操作时，我们可以移动元素而不是复制它们。

进阶读者

一些与异常处理相关的高级改进：

  • 在执行调整大小或插入操作时，仅当元素的移动构造函数是 noexcept 时才移动它们，否则复制它们（27.10 -- std::move_if_noexcept)。
  • 为调整大小或插入操作提供强异常安全保证（27.9 -- 异常规范和 noexcept)。

还有一点：如果标准库中的某个类满足你的需求，请使用它而不是自己创建。例如，与其使用 IntArray，不如使用 std::vector<int>。它经过实战检验，高效，并且与标准库中的其他类配合良好。但有时你需要一个标准库中不存在的专用容器类，因此了解如何在需要时创建自己的容器类是有好处的。
