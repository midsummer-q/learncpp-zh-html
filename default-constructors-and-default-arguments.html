14.11 — 默认构造函数与默认参数

● 机器译文 课程 14.11 查看英文原文

一个 默认构造函数 是不接受任何参数的构造函数。通常，这是一个被定义为没有参数的构造函数。

下面是一个包含默认构造函数的类的示例：

#include <iostream>

class Foo
{
public:
    Foo() // 默认构造函数
    {
        std::cout << "Foo default constructed\n";
    }
};

int main()
{
    Foo foo{}; // 无初始化值，调用 Foo 的默认构造函数

    return 0;
}

当上述程序运行时，会创建一个类型为 Foo 的对象。由于没有提供初始化值，默认构造函数 Foo() 被调用，并输出：

Foo default constructed

类类型的值初始化与默认初始化

如果类类型有默认构造函数，那么值初始化和默认初始化都会调用该默认构造函数。因此，对于像上面示例中的 Foo 类，以下两种方式本质上是等价的：

    Foo foo{}; // 值初始化，调用 Foo() 默认构造函数
    Foo foo2;  // 默认初始化，调用 Foo() 默认构造函数

然而，正如我们在课程 13.9 -- 默认成员初始化中已经讨论过的，对于聚合类型，值初始化更安全。由于很难判断一个类类型是聚合类型还是非聚合类型，更安全的做法是对所有类型都使用值初始化，而不必担心这个问题。

最佳实践

对于所有类类型，优先使用值初始化而不是默认初始化。

带默认参数的构造函数

与所有函数一样，构造函数最右边的参数可以有默认参数。

相关内容

我们在课程 11.5 -- 默认参数。

例如：

#include <iostream>

class Foo
{
private:
    int m_x { };
    int m_y { };

public:
    Foo(int x=0, int y=0) // 具有默认参数
        : m_x { x }
        , m_y { y }
    {
        std::cout << "Foo(" << m_x << ", " << m_y << ") constructed\n";
    }
};

int main()
{
    Foo foo1{};     // 使用默认参数调用 Foo(int, int) 构造函数
    Foo foo2{6, 7}; // 调用 Foo(int, int) 构造函数

    return 0;
}

这会打印：

Foo(0, 0) constructed
Foo(6, 7) constructed

如果构造函数的所有参数都有默认参数，那么该构造函数就是默认构造函数（因为它可以在没有参数的情况下调用）。

我们将在下一课（14.12 -- 委托构造函数)。

重载构造函数

因为构造函数是函数，所以它们可以被重载。也就是说，我们可以有多个构造函数，以便以不同的方式构造对象：

#include <iostream>

class Foo
{
private:
    int m_x {};
    int m_y {};

public:
    Foo() // 默认构造函数
    {
        std::cout << "Foo constructed\n";
    }

    Foo(int x, int y) // 非默认构造函数
        : m_x { x }, m_y { y }
    {
        std::cout << "Foo(" << m_x << ", " << m_y << ") constructed\n";
    }
};

int main()
{
    Foo foo1{};     // 调用 Foo() 构造函数
    Foo foo2{6, 7}; // 调用 Foo(int, int) 构造函数

    return 0;
}

上述结论的一个推论是，一个类应该只有一个默认构造函数。如果提供了多个默认构造函数，编译器将无法区分应该使用哪一个：

#include <iostream>

class Foo
{
private:
    int m_x {};
    int m_y {};

public:
    Foo() // 默认构造函数
    {
        std::cout << "Foo constructed\n";
    }

    Foo(int x=1, int y=2) // 默认构造函数
        : m_x { x }, m_y { y }
    {
        std::cout << "Foo(" << m_x << ", " << m_y << ") constructed\n";
    }
};

int main()
{
    Foo foo{}; // 编译错误：构造函数调用有歧义

    return 0;
}

在上面的示例中，我们实例化 foo 时没有提供参数，因此编译器会寻找一个默认构造函数。它会找到两个，并且无法区分应该使用哪一个构造函数。这将导致编译错误。

隐式默认构造函数

如果非聚合类类型对象没有用户声明的构造函数，编译器将生成一个公有的默认构造函数（以便该类可以被值初始化或默认初始化）。这个构造函数被称为 隐式默认构造函数。

考虑以下示例：

#include <iostream>

class Foo
{
private:
    int m_x{};
    int m_y{};

    // 注意：未声明任何构造函数
};

int main()
{
    Foo foo{};

    return 0;
}

这个类没有用户声明的构造函数，因此编译器会为我们生成一个隐式默认构造函数。该构造函数将用于实例化 foo{}。

隐式默认构造函数等价于一个没有参数、没有成员初始化列表、且构造函数体中没有语句的构造函数。换句话说，对于上面的 Foo 类，编译器会生成如下代码：

public:
    Foo() // 隐式生成的默认构造函数
    {
    }

隐式默认构造函数主要在我们有类没有数据成员时有用。如果类有数据成员，我们可能希望它们能够用用户提供的值进行初始化，而隐式默认构造函数不足以满足这一点。

使用 = default 生成显式默认的默认构造函数

在某些情况下，我们会编写一个与隐式生成的默认构造函数等价的默认构造函数，这时我们可以告诉编译器为我们生成一个默认构造函数。这个构造函数被称为 显式默认的默认构造函数，可以通过使用 = default 语法来生成：

#include <iostream>

class Foo
{
private:
    int m_x {};
    int m_y {};

public:
    Foo() = default; // 生成一个显式默认的默认构造函数

    Foo(int x, int y)
        : m_x { x }, m_y { y }
    {
        std::cout << "Foo(" << m_x << ", " << m_y << ") constructed\n";
    }
};

int main()
{
    Foo foo{}; // 调用 Foo() 默认构造函数

    return 0;
}

在上面的示例中，由于我们有一个用户声明的构造函数（Foo(int, int)），通常不会生成隐式默认构造函数。但是，因为我们告诉编译器生成这样一个构造函数，它就会生成。这个构造函数随后将被用于实例化 foo{}。

最佳实践

优先使用显式默认的默认构造函数（= default) 而不是具有空体的默认构造函数。

显式默认的默认构造函数与空的用户定义构造函数

至少有两种情况下，显式默认的默认构造函数与空的用户定义构造函数行为不同。

  1. 当对类进行值初始化时，如果该类具有用户定义的默认构造函数，则对象将被默认初始化。然而，如果该类具有一个不是用户提供的默认构造函数（即，隐式定义的默认构造函数，或使用 = default定义的默认构造函数），则对象将在默认初始化之前被零初始化。
#include <iostream>

class User
{
private:
    int m_a; // 注意：没有默认初始化值
    int m_b {};

public:
    User() {} // 用户定义的空构造函数

    int a() const { return m_a; }
    int b() const { return m_b; }
};

class Default
{
private:
    int m_a; // 注意：没有默认初始化值
    int m_b {};

public:
    Default() = default; // 显式默认的默认构造函数

    int a() const { return m_a; }
    int b() const { return m_b; }
};

class Implicit
{
private:
    int m_a; // 注意：没有默认初始化值
    int m_b {};

public:
    // 隐式默认构造函数

    int a() const { return m_a; }
    int b() const { return m_b; }
};

int main()
{
    User user{}; // 默认初始化
    std::cout << user.a() << ' ' << user.b() << '\n';

    Default def{}; // 零初始化，然后默认初始化
    std::cout << def.a() << ' ' << def.b() << '\n';

    Implicit imp{}; // 零初始化，然后默认初始化
    std::cout << imp.a() << ' ' << imp.b() << '\n';

    return 0;
}

在作者的机器上，这会打印：

782510864 0
0 0
0 0

注意 user.a 在默认初始化之前没有被零初始化，因此保持未初始化状态。

实际上，这应该无关紧要，因为你应该为所有数据成员提供默认成员初始化器！

提示

对于没有用户提供的默认构造函数的类，值初始化将首先对类进行零初始化，而默认初始化则不会。因此，默认初始化可能比值初始化性能更高（代价是安全性较低）。如果你希望在初始化大量没有用户提供的默认构造函数的对象的代码段中榨取每一丝性能，那么将这些对象改为默认初始化可能值得探索。或者，你可以尝试将类改为具有空体的默认构造函数。这避免了使用值初始化时的零初始化情况，但可能会抑制其他优化。

  1. 在 C++20 之前，具有用户定义的默认构造函数（即使具有空体）的类会使该类成为非聚合类型，而显式默认的默认构造函数则不会。假设该类在其他方面是聚合类型，前者会导致该类使用列表初始化而不是聚合初始化。从 C++20 开始，这种不一致性得到了解决，因此两者都会使该类成为非聚合类型。

仅在合理时创建默认构造函数

默认构造函数允许我们在没有用户提供的初始化值的情况下创建非聚合类类型的对象。因此，只有当创建具有所有默认值的类类型对象有意义时，类才应提供默认构造函数。

例如：

#include <iostream>

class Fraction
{
private:
    int m_numerator{ 0 };
    int m_denominator{ 1 };

public:
    Fraction() = default;
    Fraction(int numerator, int denominator)
        : m_numerator{ numerator }
        , m_denominator{ denominator }
    {
    }

    void print() const
    {
        std::cout << "Fraction(" << m_numerator << ", " << m_denominator << ")\n";
    }
};

int main()
{
    Fraction f1 {3, 5};
    f1.print();

    Fraction f2 {}; // 将得到分数 0/1
    f2.print();

    return 0;
}

对于表示分数的类，允许用户创建没有初始化器的 Fraction 对象是有意义的（在这种情况下，用户将得到分数 0/1）。

现在考虑这个类：

#include <iostream>
#include <string>
#include <string_view>

class Employee
{
private:
    std::string m_name{ };
    int m_id{ };

public:
    Employee(std::string_view name, int id)
        : m_name{ name }
        , m_id{ id }
    {
    }

    void print() const
    {
        std::cout << "Employee(" << m_name << ", " << m_id << ")\n";
    }
};

int main()
{
    Employee e1 { "Joe", 1 };
    e1.print();

    Employee e2 {}; // 编译错误：没有匹配的构造函数
    e2.print();

    return 0;
}

对于表示雇员的类，允许创建没有名字的雇员是没有意义的。因此，这样的类不应具有默认构造函数，以便如果类的用户尝试这样做，将导致编译错误。
