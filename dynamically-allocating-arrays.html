19.2 — 动态分配数组

● 机器译文 课程 19.2 查看英文原文

除了动态分配单个值，我们还可以动态分配变量数组。与固定数组不同，固定数组的大小必须在编译时确定，而动态分配数组允许我们在运行时选择数组长度（这意味着长度不需要是 constexpr）。

作者注

在这些课程中，我们将动态分配 C 风格数组，这是最常见的动态分配数组类型。

虽然你可以动态分配一个 std::array，但通常最好使用非动态分配的 std::vector 在这种情况下。

要动态分配数组，我们使用 new 和 delete 的数组形式（通常称为 new[] 和 delete[]）：

#include <cstddef>
#include <iostream>

int main()
{
    std::cout << "Enter a positive integer: ";
    std::size_t length{};
    std::cin >> length;

    int* array{ new int[length]{} }; // 使用数组 new。注意长度不必是常量！

    std::cout << "I just allocated an array of integers of length " << length << '\n';

    array[0] = 5; // 将元素 0 设置为值 5

    delete[] array; // 使用数组 delete 释放数组

    // 我们不需要将数组设置为 nullptr/0，因为它在此之后立即超出作用域

    return 0;
}

因为我们正在分配一个数组，C++ 知道它应该使用数组版本的 new 而不是标量版本的 new。本质上，new[] 运算符被调用，即使 [] 没有放在 new 关键字旁边。

动态分配数组的长度类型为 std::size_t。如果你使用非 constexpr 的 int，你需要 static_cast 切换到 std::size_t 因为这被认为是窄化转换，否则编译器会发出警告。

注意，由于这块内存是从与固定数组不同的地方分配的，数组的大小可以非常大。你可以运行上面的程序并分配长度为 1,000,000（甚至可能 100,000,000）的数组而不会出现问题。试试看！因此，在 C++ 中需要分配大量内存的程序通常采用动态分配。

动态删除数组

当删除动态分配的数组时，我们必须使用数组版本的 delete，即 delete[]。

这告诉 CPU 它需要清理多个变量而不是单个变量。新手程序员在处理动态内存分配时最常见的错误之一是在删除动态分配的数组时使用 delete 而不是 delete[]。对标量数组使用标量版本的 delete 会导致未定义行为，例如数据损坏、内存泄漏、崩溃或其他问题。

关于数组 delete[] 的一个常见问题是：“数组 delete 如何知道要删除多少内存？”答案是数组 new[] 会跟踪为变量分配了多少内存，以便数组 delete[] 可以删除适当数量的内存。不幸的是，这个大小/长度对程序员不可访问。

动态数组与固定数组几乎相同

在课程 17.8 -- C 风格数组退化，你了解到固定数组保存第一个数组元素的内存地址。你还了解到固定数组可以退化为指向数组第一个元素的指针。在这种退化形式中，固定数组的长度不可用（因此也无法通过 sizeof() 获取数组大小），但除此之外几乎没有区别。

动态数组的生命始于一个指向数组第一个元素的指针。因此，它具有相同的局限性，即不知道自己的长度或大小。动态数组的功能与退化的固定数组完全相同，不同之处在于程序员负责通过 delete[] 关键字释放动态数组。

初始化动态分配的数组

如果你想将动态分配的数组初始化为 0，语法非常简单：

int* array{ new int[length]{} };

在 C++11 之前，没有简单的方法将动态数组初始化为非零值（初始化列表仅适用于固定数组）。这意味着你必须遍历数组并显式地给元素赋值。

int* array = new int[5];
array[0] = 9;
array[1] = 7;
array[2] = 5;
array[3] = 3;
array[4] = 1;

超级烦人！

然而，从 C++11 开始，现在可以使用初始化列表初始化动态数组了！

int fixedArray[5] = { 9, 7, 5, 3, 1 }; // 在 C++11 之前初始化固定数组
int* array{ new int[5]{ 9, 7, 5, 3, 1 } }; // 从 C++11 开始初始化动态数组
// 为了避免写两次类型，我们可以使用 auto。这通常用于名称较长的类型。
auto* array{ new int[5]{ 9, 7, 5, 3, 1 } };

注意，这种语法在数组长度和初始化列表之间没有 operator=。

为了保持一致性，固定数组也可以使用统一初始化进行初始化：

int fixedArray[]{ 9, 7, 5, 3, 1 }; // 在 C++11 中初始化固定数组
char fixedArray[]{ "Hello, world!" }; // 在 C++11 中初始化固定数组

显式指定数组大小是可选的。

调整数组大小

动态分配数组允许你在分配时设置数组长度。然而，C++ 没有提供内置的方法来调整已分配的数组的大小。可以通过动态分配新数组、复制元素并删除旧数组来绕过这个限制。但这容易出错，尤其是当元素类型是类时（类有特殊的创建规则）。

因此，我们建议避免自己这样做。使用 std::vector 的别名。

小测验时间

问题 #1

编写一个程序：

  • 询问用户想要输入多少个名字。
  • 动态分配一个 std::string 数组。
  • 要求用户输入每个名字。
  • 调用 std::sort 对名字进行排序（参见 18.1 -- 使用选择排序对数组进行排序 和 17.9 -- 指针算术和下标)
  • 打印排序后的名字列表。

std::string 支持通过比较运算符 < 和 > 比较字符串。你不需要手动实现字符串比较。

你的输出应该匹配以下内容：

How many names would you like to enter? 5
Enter name #1: Jason
Enter name #2: Mark
Enter name #3: Alex
Enter name #4: Chris
Enter name #5: John

Here is your sorted list:
Name #1: Alex
Name #2: Chris
Name #3: Jason
Name #4: John
Name #5: Mark

提醒

您可以使用 std::getline() 读取包含空格的名称（参见课程 5.7 -- std::string 简介)。

提醒

要使用 std::sort() 使用指向数组的指针，手动计算 begin 和 end

std::sort(array, array + arrayLength);

显示答案

#include <algorithm> // std::sort
#include <cstddef>
#include <iostream>
#include <string>

std::size_t getNameCount()
{
    std::cout << "How many names would you like to enter? ";
    std::size_t length{};
    std::cin >> length;

    return length;
}

// 要求用户输入所有名称
void getNames(std::string* names, std::size_t length)
{
    for (std::size_t i{ 0 }; i < length; ++i)
    {
        std::cout << "Enter name #" << i + 1 << ": ";
        std::getline(std::cin >> std::ws, names[i]);
    }
}

// 打印排序后的名称
void printNames(std::string* names, std::size_t length)
{
    std::cout << "\nHere is your sorted list:\n";

    for (std::size_t i{ 0 }; i < length; ++i)
        std::cout << "Name #" << i + 1 << ": " << names[i] << '\n';
}

int main()
{
    std::size_t length{ getNameCount() };

    // 分配一个数组来保存名称
    auto* names{ new std::string[length]{} };

    getNames(names, length);

    // 对数组进行排序
    std::sort(names, names + length);

    printNames(names, length);

    // 不要忘记使用数组 delete
    delete[] names;
    // 我们不需要将 names 设置为 nullptr/0，因为它将在此之后立即
    // 超出作用域。

    return 0;
}
