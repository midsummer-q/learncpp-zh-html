8.7 — Goto 语句

● 机器译文 课程 8.7 查看英文原文

接下来要介绍的控制流语句是无条件跳转。无条件跳转会使执行跳转到代码中的另一个位置。术语“无条件”意味着跳转总是发生（不像 if 语句或 switch 语句，跳转仅根据表达式的结果有条件地发生）。

在 C++ 中，无条件跳转通过 goto 语句实现，跳转的目标位置通过 语句标签标识。与 switch case 标签类似，语句标签通常不缩进。

以下是一个 goto 语句和语句标签的示例：

#include <iostream>
#include <cmath> // for sqrt() function

int main()
{
    double x{};
tryAgain: // 这是一个语句标签
    std::cout << "Enter a non-negative number: "; 
    std::cin >> x;

    if (x < 0.0)
        goto tryAgain; // 这是 goto 语句

    std::cout << "The square root of " << x << " is " << std::sqrt(x) << '\n';
    return 0;
}

在这个程序中，用户被要求输入一个非负数。然而，如果输入了负数，程序会使用 goto 语句跳回到 tryAgain 标签。然后再次要求用户输入一个新数字。通过这种方式，我们可以不断要求用户输入，直到他或她输入有效值。

以下是该程序的一个示例运行：

Enter a non-negative number: -4
Enter a non-negative number: 4
The square root of 4 is 2

语句标签具有函数作用域

在关于对象作用域的章节（第 7 章）中，我们介绍了两种作用域：局部（块）作用域和文件（全局）作用域。语句标签使用第三种作用域： 函数作用域，这意味着标签在整个函数中可见，即使在其声明点之前也是如此。goto 语句及其对应的 statement label 必须出现在同一个函数中。

虽然上面的示例展示了一个向后跳转（跳转到函数中前面的点）的 goto 语句，但 goto 语句也可以向前跳转：

#include <iostream>

void printCats(bool skip)
{
    if (skip)
        goto end; // 向前跳转；语句标签 'end' 在此处可见，因为它具有函数作用域
    
    std::cout << "cats\n";
end:
    ; // 语句标签必须与一个语句关联
}

int main()
{
    printCats(true);  // 跳过打印语句，不打印任何内容
    printCats(false); // 打印 "cats"

    return 0;
}

这会打印：

cats

除了向前跳转之外，上面的程序中还有几个值得注意的有趣之处。

首先，注意语句标签必须与一个语句关联（因此得名：它们标记一个语句）。因为函数的末尾没有语句，我们不得不使用一个空语句以便有一个语句可以标记。其次，我们能够跳转到由 end 标记的语句，即使我们还没有声明 end ，这是因为语句标签具有函数作用域。语句标签不需要前向声明。第三，值得明确指出的是，上面的程序风格不佳——使用 if 语句跳过打印语句会比使用 goto 语句跳转更好。

跳转有两个主要限制：只能在单个函数内跳转（不能从一个函数跳转到另一个函数），并且如果向前跳转，不能跳过任何在跳转目标位置仍在作用域内的变量的初始化。例如：

int main()
{
    goto skip;   // 错误：此跳转非法，因为...
    int x { 5 }; // 这个已初始化的变量在语句标签 'skip' 处仍在作用域内
skip:
    x += 3;      // 如果 x 未初始化，这甚至该如何求值？
    return 0;
}

注意，你可以向后跳过一个变量初始化，并且当初始化执行时，变量将被重新初始化。

避免使用 goto

在 C++（以及其他现代高级语言）中，使用 goto 是被避免的。 Edsger W. Dijkstra，一位著名的计算机科学家，在一篇著名但难读的论文《 Go To 语句被认为有害》中阐述了避免使用 goto 的理由。goto 的主要问题是它允许程序员任意地在代码中跳转。这造成了不雅地被称为“意大利面条式代码”的情况。 意大利面条式代码 是指执行路径像一碗意大利面条（缠绕纠结）的代码，使得极难遵循此类代码的逻辑。

正如 Dijkstra 略带幽默地说：“程序员的质量是他们所编写的程序中 go to 语句密度的递减函数”。

几乎任何使用 goto 语句编写的代码都可以使用 C++ 中的其他结构（如 if 语句和循环）更清晰地编写。一个显著的例外是当你需要退出嵌套循环但不想退出整个函数时——在这种情况下，使用 goto 跳转到循环之后可能是最清晰的解决方案。

进阶读者

以下是一个使用 goto 退出嵌套循环而不退出函数的刻意示例：

#include <iostream>

int main()
{
    for (int i = 1; i < 5; ++i)
    {        
        for (int j = 1; j < 5; ++j)
        {
            std::cout << i << " * " << j << " is " << i*j << '\n';
            
            // 如果乘积能被 9 整除，则跳转到 "end" 标签
            if (i*j % 9 == 0)
            {
                std::cout << "Found product divisible by 9.  Ending early.\n";
                goto end;
            }
        }

        std::cout << "Incrementing the first factor.\n";
    }

end:
    std::cout << "And we're done." << '\n';

    return 0;
}
