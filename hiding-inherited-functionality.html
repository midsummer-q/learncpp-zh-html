24.8 — 隐藏继承的功能

● 机器译文 课程 24.8 查看英文原文

更改继承成员的访问级别

C++ 允许我们在派生类中更改继承成员的访问说明符。这可以通过使用 使用声明 来标识（作用域限定的）基类成员，并在派生类中为其指定新的访问说明符。

例如，考虑以下 Base 类：

#include <iostream>

class Base
{
private:
    int m_value {};

public:
    Base(int value)
        : m_value { value }
    {
    }

protected:
    void printValue() const { std::cout << m_value; }
};

由于 Base::printValue() 被声明为 protected，它只能被 Base 或其派生类调用。公有成员无法访问它。

让我们定义一个 Derived 类，将 printValue() 的访问说明符改为 public：

class Derived: public Base
{
public:
    Derived(int value)
        : Base { value }
    {
    }

    // Base::printValue 作为 protected 继承，因此公有成员无法访问
    // 但我们通过 using 声明将其改为 public
    using Base::printValue; // 注意：这里没有括号
};

这意味着以下代码现在可以工作：

int main()
{
    Derived derived { 7 };

    // printValue 在 Derived 中是 public，因此这是可以的
    derived.printValue(); // 打印 7
    return 0;
}

你只能更改派生类通常可以访问的基类成员的访问说明符。因此，你永远不能将基类成员的访问说明符从 private 改为 protected 或 public，因为派生类无法访问基类的私有成员。

隐藏功能

在 C++ 中，除了修改源代码外，无法从基类中移除或限制功能。然而，在派生类中，可以隐藏基类中存在的功能，使其无法通过派生类访问。这可以通过更改相关的访问说明符来实现。

例如，我们可以将公有成员设为私有：

#include <iostream>

class Base
{
public:
	int m_value{};
};

class Derived : public Base
{
private:
	using Base::m_value;

public:
	Derived(int value) : Base { value }
	{
	}
};

int main()
{
	Derived derived{ 7 };
	std::cout << derived.m_value; // 错误：m_value 在 Derived 中是 private

	Base& base{ derived };
	std::cout << base.m_value; // 可以：m_value 在 Base 中是 public

	return 0;
}

这使我们能够获取设计不良的基类，并在派生类中封装其数据。或者，我们可以不公开继承 Base 的成员并通过覆盖其访问说明符将 m_value 设为私有，而是私有继承 Base，这样一开始 Base 的所有成员都会被私有继承。

然而，值得注意的是，虽然 m_value 在 Derived 类中是私有的，但在 Base 类中仍然是公有的。因此，Derived 中对 m_value 的封装仍然可以通过转换为 Base& 并直接访问该成员来破坏。

进阶读者

出于同样的原因，如果 Base 类有一个公有虚函数，而 Derived 类将其访问说明符改为 private，公有成员仍然可以通过将 Derived 对象转换为 Base& 并调用虚函数来访问私有的 Derived 函数。编译器会允许这样做，因为该函数在 Base 中是公有的。然而，由于对象实际上是 Derived，虚函数解析将解析并调用（私有的）Derived 版本的函数。访问控制不在运行时强制执行。

#include <iostream>

class A
{
public:
    virtual void fun()
    {
        std::cout << "public A::fun()\n";
    }
};

class B : public A
{
private:
    virtual void fun()
    {
         std::cout << "private B::fun()\n";
   }
};

int main()
{
    B b {};
    b.fun();                  // 编译错误：不允许，因为 B::fun() 是 private
    static_cast<A&>(b).fun(); // 可以：A::fun() 是 public，运行时解析为 private B::fun()

    return 0;
}

也许令人惊讶的是，对于基类中的一组重载函数，无法更改单个重载的访问说明符。你只能更改它们全部：

#include <iostream>

class Base
{
public:
    int m_value{};

    int getValue() const { return m_value; }
    int getValue(int) const { return m_value; }
};

class Derived : public Base
{
private:
	using Base::getValue; // 将所有 getValue 函数设为 private

public:
	Derived(int value) : Base { value }
	{
	}
};

int main()
{
	Derived derived{ 7 };
	std::cout << derived.getValue();  // 错误：getValue() 在 Derived 中是 private
	std::cout << derived.getValue(5); // 错误：getValue(int) 在 Derived 中是 private

	return 0;
}

在派生类中删除函数

你也可以在派生类中将成员函数标记为已删除，以确保它们无法通过派生对象调用：

#include <iostream>
class Base
{
private:
	int m_value {};

public:
	Base(int value)
		: m_value { value }
	{
	}

	int getValue() const { return m_value; }
};

class Derived : public Base
{
public:
	Derived(int value)
		: Base { value }
	{
	}


	int getValue() const = delete; // 将此函数标记为不可访问
};

int main()
{
	Derived derived { 7 };

	// 以下代码无法工作，因为 getValue() 已被删除！
	std::cout << derived.getValue();

	return 0;
}

在上面的例子中，我们将 getValue() 函数标记为已删除。这意味着当我们尝试调用派生版本的函数时，编译器会报错。注意，Base 版本的 getValue() 仍然可以访问。我们可以通过两种方式调用 Base::getValue()：

int main()
{
	Derived derived { 7 };

	// 我们可以直接调用 Base::getValue() 函数
	std::cout << derived.Base::getValue();

	// 或者我们可以将 Derived 向上转换为 Base 引用，getValue() 将解析为 Base::getValue()
	std::cout << static_cast<Base&>(derived).getValue();

	return 0;
}

如果使用强制转换方法，我们转换为 Base& 而不是 Base，以避免复制 Base 部分 derived。
