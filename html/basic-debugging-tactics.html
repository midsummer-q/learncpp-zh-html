3.4 — 基本调试策略

● 机器译文 课程 3.4 查看英文原文

在上一课中，我们探讨了一种通过运行程序并利用猜测来定位问题所在的策略。在本课中，我们将探讨一些基本的策略，用于实际进行这些猜测并收集信息以帮助发现问题。

调试策略 #1：注释掉你的代码

让我们从一个简单的方法开始。如果你的程序表现出错误行为，一种减少需要搜索代码量的方法是将某些代码注释掉，看看问题是否依然存在。如果问题保持不变，那么被注释掉的代码很可能不是问题的原因。

考虑以下代码：

int main()
{
    getNames(); // 要求用户输入一组名字
    doMaintenance(); // 做一些随机的事情
    sortNames(); // 按字母顺序排序
    printNames(); // 打印已排序的名字列表

    return 0;
}

假设这个程序应该按字母顺序打印用户输入的名字，但它却按逆字母顺序打印。问题出在哪里？是 getNames 输入名字不正确？是 sortNames 将它们逆向排序？是 printNames 逆向打印？可能是其中任何一个。但我们可能怀疑doMaintenance()与问题无关，所以让我们把它注释掉。

int main()
{
    getNames(); // 要求用户输入一组名字
//    doMaintenance(); // 做一些随机的事情
    sortNames(); // 按字母顺序排序
    printNames(); // 打印已排序的名字列表

    return 0;
}

有三种可能的结果：

  • 如果问题消失，那么 doMaintenance 一定是导致了问题，我们应该把注意力集中在那里。
  • 如果问题没有变化（这更可能），那么我们可以合理地假设 doMaintenance 没有责任，我们可以暂时将整个函数排除在搜索范围之外。这并不能帮助我们理解实际问题是在调用 doMaintenance之前还是之后，但它减少了我们后续需要检查的代码量。
  • 如果注释掉 doMaintenance 导致问题演变成其他相关问题（例如程序停止打印名字），那么很可能 doMaintenance 正在做一些其他代码所依赖的有用操作。在这种情况下，我们可能无法判断问题是在 doMaintenance 还是其他地方，因此我们可以取消注释 doMaintenance 并尝试其他方法。

警告

别忘了你注释掉了哪些函数，以便之后能取消注释它们！

在做了许多与调试相关的修改后，很容易遗漏一两个未撤销的改动。如果发生这种情况，你最终会修复一个 bug 却引入其他 bug！

此时有一个好的版本控制系统非常有用，因为你可以在主分支上对比你的代码，查看所有与调试相关的修改（并确保在提交更改之前将它们还原）。

提示

另一种替代方法，而不是反复添加/删除或取消注释/注释调试语句，是使用第三方库，该库允许你将调试语句留在代码中，但在发布模式下通过预处理器宏将它们编译掉。 dbg 就是这样一种仅头文件库，旨在帮助实现这一点（通过 DBG_MACRO_DISABLE 预处理器宏）。

我们在课程中讨论了仅头文件库 7.9 -- 内联函数和变量。

调试策略 #2：验证你的代码流程

在更复杂的程序中，另一个常见问题是程序调用函数的次数过多或过少（包括完全不调用）。

在这种情况下，在函数顶部放置语句来打印函数名会很有帮助。这样，当程序运行时，你可以看到哪些函数被调用了。

提示

在打印用于调试的信息时，使用 std::cerr 而不是 std::cout。原因之一是 std::cout 可能会被缓冲，这意味着在你请求 std::cout 输出文本和实际输出之间可能会有一些时间。如果你使用 std::cout 输出，然后你的程序立即崩溃， std::cout 可能还没有实际输出。这可能会误导你关于问题所在的位置。另一方面， std::cerr 是无缓冲的，这意味着你发送给它的任何内容都会立即输出。这有助于确保所有调试输出尽快出现（以牺牲一些性能为代价，而在调试时我们通常不在意性能）。

使用 std::cerr 也有助于明确输出的信息是针对错误情况而非正常情况。

我们会在课程中进一步讨论何时使用 std::cout vs std::cerr 进一步在课程 9.4 -- 检测和处理错误。

考虑以下不能正常工作的简单程序：

#include <iostream>

int getValue()
{
	return 4;
}

int main()
{
    std::cout << getValue << '\n';

    return 0;
}

你可能需要禁用“将警告视为错误”才能使上述代码编译通过。

尽管我们期望这个程序打印值 4，它应该打印的值是：

1

在 Visual Studio（可能还有其他一些编译器）上，它可能改为打印以下内容：

00101424

相关内容

我们讨论为什么某些编译器打印 1 而非地址（以及如果你的编译器打印 1 但你希望它打印地址该怎么办）在课程 20.1 -- 函数指针。

让我们在这些函数中添加一些调试语句：

#include <iostream>

int getValue()
{
std::cerr << "getValue() called\n";
	return 4;
}

int main()
{
std::cerr << "main() called\n";
    std::cout << getValue << '\n';

    return 0;
}

提示

在添加临时调试语句时，不缩进它们可能会有所帮助。这样以后更容易找到它们并删除。

如果你使用 clang-format 来格式化代码，它会尝试自动缩进这些行。你可以这样抑制自动格式化：

// 关闭 clang-format
std::cerr << "main() called\n";
// 开启 clang-format

现在，当这些函数执行时，它们会输出自己的名字，表明它们被调用了：

main() called
1

现在我们可以看到函数 getValue 从未被调用过。一定是调用函数的代码有问题。让我们仔细看看这行代码：

    std::cout << getValue << '\n';

哦，看，我们忘了在函数调用上加括号。应该是：

#include <iostream>

int getValue()
{
std::cerr << "getValue() called\n";
	return 4;
}

int main()
{
std::cerr << "main() called\n";
    std::cout << getValue() << '\n'; // 在此处添加了括号

    return 0;
}

这样现在就会产生正确的输出。

main() called
getValue() called
4

然后我们可以移除临时的调试语句。

调试技巧 #3：打印值

对于某些类型的错误，程序可能会计算或传递错误的值。

我们也可以输出变量（包括参数）或表达式的值，以确保它们正确。

考虑以下本应相加两个数字但却无法正确运行的程序：

#include <iostream>

int add(int x, int y)
{
	return x + y;
}

void printResult(int z)
{
	std::cout << "The answer is: " << z << '\n';
}

int getUserInput()
{
	std::cout << "Enter a number: ";
	int x{};
	std::cin >> x;
	return x;
}

int main()
{
	int x{ getUserInput() };
	int y{ getUserInput() };

	int z{ add(x, 5) };
	printResult(z);

	return 0;
}

以下是该程序的一些输出：

Enter a number: 4
Enter a number: 3
The answer is: 9

这不对。你看到错误了吗？即使在这个简短的程序中，也可能很难发现。让我们添加一些代码来调试我们的值：

#include <iostream>

int add(int x, int y)
{
	return x + y;
}

void printResult(int z)
{
	std::cout << "The answer is: " << z << '\n';
}

int getUserInput()
{
	std::cout << "Enter a number: ";
	int x{};
	std::cin >> x;
	return x;
}

int main()
{
	int x{ getUserInput() };
std::cerr << "main::x = " << x << '\n';
	int y{ getUserInput() };
std::cerr << "main::y = " << y << '\n';

	int z{ add(x, 5) };
std::cerr << "main::z = " << z << '\n';
	printResult(z);

	return 0;
}

以下是上述输出：

Enter a number: 4
main::x = 4
Enter a number: 3
main::y = 3
main::z = 9
The answer is: 9

变量 x 和 y 得到了正确的值，但变量 z 并非如此。问题一定出在这两点之间，这使得函数 add 成为关键嫌疑对象。

让我们修改函数 add：

#include <iostream>

int add(int x, int y)
{
std::cerr << "add() called (x=" << x <<", y=" << y << ")\n";
	return x + y;
}

void printResult(int z)
{
	std::cout << "The answer is: " << z << '\n';
}

int getUserInput()
{
	std::cout << "Enter a number: ";
	int x{};
	std::cin >> x;
	return x;
}

int main()
{
	int x{ getUserInput() };
std::cerr << "main::x = " << x << '\n';
	int y{ getUserInput() };
std::cerr << "main::y = " << y << '\n';

	int z{ add(x, 5) };
std::cerr << "main::z = " << z << '\n';
	printResult(z);

	return 0;
}

现在我们将得到输出：

Enter a number: 4
main::x = 4
Enter a number: 3
main::y = 3
add() called (x=4, y=5)
main::z = 9
The answer is: 9

变量 y 的值为 3，但不知何故我们的函数 add 中，参数得到的值为 5 y。我们肯定传错了参数。果然：

	int z{ add(x, 5) };

就是这样。我们传递了字面量 5 而不是变量的值 y 作为参数。这很容易修复，然后我们可以移除调试语句。

再举一个例子

这个程序与前一个非常相似，但也没有按预期工作：

#include <iostream>

int add(int x, int y)
{
	return x + y;
}

void printResult(int z)
{
	std::cout << "The answer is: " << z << '\n';
}

int getUserInput()
{
	std::cout << "Enter a number: ";
	int x{};
	std::cin >> x;
	return --x;
}

int main()
{
	int x{ getUserInput() };
	int y{ getUserInput() };

	int z { add(x, y) };
	printResult(z);

	return 0;
}

如果我们运行这段代码并看到以下输出：

Enter a number: 4
Enter a number: 3
The answer is: 5

嗯，出了问题。但问题出在哪里？

让我们用一些调试代码来检测这段程序：

#include <iostream>

int add(int x, int y)
{
std::cerr << "add() called (x=" << x << ", y=" << y << ")\n";
	return x + y;
}

void printResult(int z)
{
std::cerr << "printResult() called (z=" << z << ")\n";
	std::cout << "The answer is: " << z << '\n';
}

int getUserInput()
{
std::cerr << "getUserInput() called\n";
	std::cout << "Enter a number: ";
	int x{};
	std::cin >> x;
	return --x;
}

int main()
{
std::cerr << "main() called\n";
	int x{ getUserInput() };
std::cerr << "main::x = " << x << '\n';
	int y{ getUserInput() };
std::cerr << "main::y = " << y << '\n';

	int z{ add(x, y) };
std::cerr << "main::z = " << z << '\n';
	printResult(z);

	return 0;
}

现在让我们用相同的输入再次运行程序：

main() called
getUserInput() called
Enter a number: 4
main::x = 3
getUserInput() called
Enter a number: 3
main::y = 2
add() called (x=3, y=2)
main::z = 5
printResult() called (z=5)
The answer is: 5

现在我们立刻看到出了问题：用户输入了值 4，但main的 x 却得到了值 3。从用户输入到该值被赋给main的变量之间一定出了问题 x。让我们通过向函数添加一些调试代码来确保程序从用户那里得到了正确的值 getUserInput：

#include <iostream>

int add(int x, int y)
{
std::cerr << "add() called (x=" << x << ", y=" << y << ")\n";
	return x + y;
}

void printResult(int z)
{
std::cerr << "printResult() called (z=" << z << ")\n";
	std::cout << "The answer is: " << z << '\n';
}

int getUserInput()
{
std::cerr << "getUserInput() called\n";
	std::cout << "Enter a number: ";
	int x{};
	std::cin >> x;
std::cerr << "getUserInput::x = " << x << '\n'; // 添加了这行额外的调试代码
	return --x;
}

int main()
{
std::cerr << "main() called\n";
	int x{ getUserInput() };
std::cerr << "main::x = " << x << '\n';
	int y{ getUserInput() };
std::cerr << "main::y = " << y << '\n';

	int z{ add(x, y) };
std::cerr << "main::z = " << z << '\n';
	printResult(z);

	return 0;
}

输出为：

main() called
getUserInput() called
Enter a number: 4
getUserInput::x = 4
main::x = 3
getUserInput() called
Enter a number: 3
getUserInput::x = 3
main::y = 2
add() called (x=3, y=2)
main::z = 5
printResult() called (z=5)
The answer is: 5

通过这一行额外的调试代码，我们可以看到用户输入被正确接收到getUserInput的变量中 x。然而，不知何故，main的变量 x 却得到了错误的值。问题一定出在这两个点之间。剩下的唯一可疑之处是函数的返回值 getUserInput。让我们更仔细地看看那一行。

	return --x;

嗯，这很奇怪。那个 -- x 前面的是什么符号？我们还没有在这些教程中讲到它，所以如果你不知道它的意思，不用担心。但即使不知道它的意思，通过你的调试努力，你可以合理地确定这一行是有问题的——因此，很可能这个 -- 符号导致了问题。

由于我们真的想要 getUserInput 只返回 x让我们删除 -- 然后看看会发生什么：

#include <iostream>

int add(int x, int y)
{
std::cerr << "add() called (x=" << x << ", y=" << y << ")\n";
	return x + y;
}

void printResult(int z)
{
std::cerr << "printResult() called (z=" << z << ")\n";
	std::cout << "The answer is: " << z << '\n';
}

int getUserInput()
{
std::cerr << "getUserInput() called\n";
	std::cout << "Enter a number: ";
	int x{};
	std::cin >> x;
std::cerr << "getUserInput::x = " << x << '\n';
	return x; // 移除了 x 前面的 --
}

int main()
{
std::cerr << "main() called\n";
	int x{ getUserInput() };
std::cerr << "main::x = " << x << '\n';
	int y{ getUserInput() };
std::cerr << "main::y = " << y << '\n';

	int z{ add(x, y) };
std::cerr << "main::z = " << z << '\n';
	printResult(z);

	return 0;
}

现在输出：

main() called
getUserInput() called
Enter a number: 4
getUserInput::x = 4
main::x = 4
getUserInput() called
Enter a number: 3
getUserInput::x = 3
main::y = 3
add() called (x=4, y=3)
main::z = 7
printResult() called (z=7)
The answer is: 7

程序现在正确运行。即使不理解 -- 在做什么，我们也能识别出导致问题的具体代码行，然后修复了问题。

为什么使用打印语句调试并不好

虽然为了诊断目的而在程序中添加调试语句是一种常见的初级技术，也是一种实用的技术（尤其是当由于某种原因无法使用调试器时），但由于许多原因，它并不是那么好：

  1. 调试语句会使你的代码变得杂乱。
  2. 调试语句会使你的程序输出变得杂乱。
  3. 调试语句需要修改代码来添加和删除，这可能会引入新的错误。
  4. 调试语句在使用完后必须删除，这使得它们不可重复使用。

我们可以做得更好。我们将在后续课程中探讨如何做到这一点。
