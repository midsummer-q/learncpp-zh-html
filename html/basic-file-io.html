28.6 — 基本文件I/O

● 机器译文 课程 28.6 查看英文原文

C++中的文件I/O与普通I/O非常相似（只有一些小的额外复杂性）。C++中有3个基本的文件I/O类：ifstream（派生自istream）、ofstream（派生自ostream）和fstream（派生自iostream）。这些类分别用于文件输入、输出和输入/输出。要使用文件I/O类，需要包含fstream头文件。

与cout、cin、cerr和clog流不同，它们已经准备好使用，文件流需要由程序员显式设置。然而，这非常简单：要打开一个文件进行读取和/或写入，只需实例化一个适当的文件I/O类对象，并将文件名作为参数。然后使用插入（<<）或提取（>>）运算符向文件写入或读取数据。完成后，有几种方法可以关闭文件：显式调用close()函数，或者让文件I/O变量离开作用域（文件I/O类的析构函数会为你关闭文件）。

文件输出

在下面的例子中，我们将使用ofstream类进行文件输出。这非常简单：

#include <fstream>
#include <iostream>
 
int main()
{
    // ofstream用于写入文件
    // 我们将创建一个名为Sample.txt的文件
    std::ofstream outf{ "Sample.txt" };

    // 如果无法打开输出文件流进行写入
    if (!outf)
    {
        // 打印错误并退出
        std::cerr << "Uh oh, Sample.txt could not be opened for writing!\n";
        return 1;
    }

    // 我们将向此文件写入两行
    outf << "This is line 1\n";
    outf << "This is line 2\n";

    return 0;
	
    // 当outf超出作用域时，ofstream的
    // 析构函数将关闭文件
}

如果你查看项目目录，应该会看到一个名为Sample.txt的文件。如果用文本编辑器打开它，你会看到它确实包含我们写入文件的两行内容。

注意，也可以使用put()函数向文件写入单个字符。

文件输入

现在，我们将读取上一个例子中写入的文件。注意，如果到达文件末尾（EOF），ifstream返回0。我们将利用这一点来确定读取多少内容。

#include <fstream>
#include <iostream>
#include <string>

int main()
{
    // ifstream用于读取文件
    // 我们将从一个名为Sample.txt的文件中读取
    std::ifstream inf{ "Sample.txt" };

    // 如果无法打开输出文件流进行读取
    if (!inf)
    {
        // 打印错误并退出
        std::cerr << "Uh oh, Sample.txt could not be opened for reading!\n";
        return 1;
    }

    // 当仍有内容可读时
    std::string strInput{};
    while (inf >> strInput)
        std::cout << strInput << '\n';
    
    return 0;
	
    // 当inf超出作用域时，ifstream的
    // 析构函数将关闭文件
}

这会产生以下结果：

This
is
line
1
This
is
line
2

嗯，这不是我们想要的。记住，提取运算符会在空白处断开。为了读取整行，我们必须使用getline()函数。

#include <fstream>
#include <iostream>
#include <string>

int main()
{
    // ifstream用于读取文件
    // 我们将从一个名为Sample.txt的文件中读取
    std::ifstream inf{ "Sample.txt" };

    // 如果无法打开输入文件流进行读取
    if (!inf)
    {
        // 打印错误并退出
        std::cerr << "Uh oh, Sample.txt could not be opened for reading!\n";
        return 1;
    }

    // 当仍有内容可读时
    std::string strInput{};
    while (std::getline(inf, strInput))
	std::cout << strInput << '\n';
    
    return 0;
	
    // 当inf超出作用域时，ifstream的
    // 析构函数将关闭文件
}

这会产生以下结果：

This is line 1
This is line 2

缓冲输出

C++中的输出可能是缓冲的。这意味着输出到文件流的任何内容可能不会立即写入磁盘。相反，多个输出操作可能会被批处理并一起处理。这主要是出于性能原因。当缓冲区被写入磁盘时，这被称为 刷新 缓冲区。导致缓冲区刷新的方法之一是关闭文件——缓冲区的内容将被刷新到磁盘，然后文件被关闭。

缓冲通常不是问题，但在某些情况下可能会给粗心的人带来麻烦。主要问题在于当缓冲区中有数据，然后程序立即终止（无论是崩溃还是调用exit()）。在这些情况下，文件流类的析构函数不会执行，这意味着文件从未关闭，因此缓冲区从未刷新。在这种情况下，缓冲区中的数据不会写入磁盘，并且会永久丢失。这就是为什么在调用exit()之前显式关闭所有打开的文件总是一个好主意。

可以使用ostream::flush()函数或向输出流发送std::flush来手动刷新缓冲区。这两种方法都可以确保缓冲区的内容立即写入磁盘，以防程序崩溃。

一个有趣的注意事项是，std::endl也会刷新输出流。因此，过度使用std::endl（导致不必要的缓冲区刷新）可能会对缓冲I/O的性能产生影响，因为刷新操作代价高昂（例如写入文件）。出于这个原因，注重性能的程序员通常使用'\n'而不是std::endl来向输出流插入换行符，以避免不必要的缓冲区刷新。

文件模式

如果我们尝试写入一个已经存在的文件会发生什么？再次运行输出示例会发现，每次程序运行时原始文件都会被完全覆盖。如果我们想将更多数据追加到文件末尾呢？事实证明，文件流构造函数接受一个可选的第二个参数，允许你指定文件应如何打开。这个参数称为模式，它接受的有效标志位于ios类中。

Ios文件模式含义
app以追加模式打开文件
ate在读取/写入之前定位到文件末尾
二进制以二进制模式打开文件（而不是文本模式）
在以读取模式打开文件（ifstream的默认模式）
out以写入模式打开文件（ofstream的默认模式）
trunc如果文件已存在则将其清空

可以通过按位或（使用|运算符）组合多个标志。ifstream默认使用std::ios::in文件模式。ofstream默认使用std::ios::out文件模式。而fstream默认使用std::ios::in | std::ios::out文件模式，这意味着默认情况下可以同时读取和写入。

提示

由于fstream的设计方式，如果使用std::ios::in且打开的文件不存在，它可能会失败。如果需要使用fstream创建新文件，请仅使用std::ios::out模式。

让我们编写一个程序，将另外两行追加到之前创建的Sample.txt文件中：

#include <iostream>
#include <fstream>

int main()
{
    // 我们将传递ios::app标志以告诉ofstream追加
    // 而不是重写文件。我们不需要传递std::ios::out
    // 因为ofstream默认使用std::ios::out
    std::ofstream outf{ "Sample.txt", std::ios::app };

    // 如果无法打开输出文件流进行写入
    if (!outf)
    {
        // 打印错误并退出
        std::cerr << "Uh oh, Sample.txt could not be opened for writing!\n";
        return 1;
    }

    outf << "This is line 3\n";
    outf << "This is line 4\n";
    
    return 0;
	
    // 当outf超出作用域时，ofstream的
    // 析构函数将关闭文件
}

现在，如果我们查看Sample.txt（使用上述示例程序之一打印其内容，或在文本编辑器中加载它），我们将看到以下内容：

This is line 1
This is line 2
This is line 3
This is line 4

使用open()显式打开文件

就像可以显式关闭文件流一样，也可以使用open()显式打开文件流。open()的工作方式与文件流构造函数相同——它接受一个文件名和一个可选的模式。

例如：

std::ofstream outf{ "Sample.txt" };
outf << "This is line 1\n";
outf << "This is line 2\n";
outf.close(); // 显式关闭文件

// 哎呀，我们忘记了一些东西
outf.open("Sample.txt", std::ios::app);
outf << "This is line 3\n";
outf.close();
