24.2 — C++ 中的基本继承

● 机器译文 课程 24.2 查看英文原文

现在我们已经从抽象意义上讨论了什么是继承，接下来让我们谈谈它在 C++ 中是如何使用的。

C++ 中的继承发生在类之间。在继承（is-a）关系中，被继承的类称为 父类， 基类，或 超类，而执行继承的类称为 子类， 派生类，或 子类。

在上图中，Fruit 是父类，Apple 和 Banana 都是子类。

在这个图中，Triangle 既是 Shape 的子类，又是 Right Triangle 的父类。

子类从父类继承行为（成员函数）和属性（成员变量）（受限于一些访问限制，我们将在后续课程中介绍）。
这些变量和函数成为派生类的成员。

因为子类是完整的类，它们当然可以拥有自己特定的成员。我们稍后会看到一个例子。

Person 类

这是一个表示通用人员的简单类：

#include <string>
#include <string_view>

class Person
{
// 在这个例子中，为了简单起见，我们将成员设为公有
public: 
    std::string m_name{};
    int m_age{};

    Person(std::string_view name = "", int age = 0)
        : m_name{ name }, m_age{ age }
    {
    }

    const std::string& getName() const { return m_name; }
    int getAge() const { return m_age; }

};

由于这个 Person 类旨在表示通用人员，我们只定义了任何类型的人都共有的成员。每个人（无论性别、职业等）都有姓名和年龄，因此这里表示了这些。

注意，在这个例子中，我们将所有变量和函数都设为 public。这纯粹是为了保持示例简单。通常我们会将变量设为 private。我们将在本章后面讨论访问控制及其与继承的交互。

BaseballPlayer 类

假设我们想编写一个程序来跟踪一些棒球运动员的信息。棒球运动员需要包含特定于棒球运动员的信息——例如，我们可能想存储球员的击球率和本垒打次数。

这是我们不完整的 BaseballPlayer 类：

class BaseballPlayer
{
// 在这个例子中，为了简单起见，我们将成员设为公有
public:
    double m_battingAverage{};
    int m_homeRuns{};

    BaseballPlayer(double battingAverage = 0.0, int homeRuns = 0)
       : m_battingAverage{battingAverage}, m_homeRuns{homeRuns}
    {
    }
};

现在，我们还想跟踪棒球运动员的姓名和年龄，而这些信息已经在 Person 类中有了。

我们有三种选择来将姓名和年龄添加到 BaseballPlayer：

  1. 直接将姓名和年龄作为成员添加到 BaseballPlayer 类中。这可能是最糟糕的选择，因为我们重复了 Person 类中已有的代码。对 Person 的任何更新都必须在 BaseballPlayer 中重复进行。
  2. 使用组合将 Person 作为 BaseballPlayer 的成员。但我们必须问自己：“BaseballPlayer 有一个 Person 吗？”不，没有。所以这不是正确的范式。
  3. 让 BaseballPlayer 从 Person 继承这些属性。记住，继承表示 is-a 关系。BaseballPlayer 是一个 Person 吗？是的。所以继承在这里是一个好的选择。

使 BaseballPlayer 成为派生类

要让 BaseballPlayer 从 Person 类继承，语法相当简单。在类 class BaseballPlayer 声明之后，我们使用冒号、关键字“public”和要继承的类的名称。这称为 公有继承。我们将在后续课程中详细讨论公有继承的含义。

// BaseballPlayer 公有继承 Person
class BaseballPlayer : public Person
{
public:
    double m_battingAverage{};
    int m_homeRuns{};

    BaseballPlayer(double battingAverage = 0.0, int homeRuns = 0)
       : m_battingAverage{battingAverage}, m_homeRuns{homeRuns}
    {
    }
};

使用派生图，我们的继承关系如下：

当 BaseballPlayer 继承自 Person 时，BaseballPlayer 获得 Person 的成员函数和变量。此外，BaseballPlayer 定义了自己的两个成员：m_battingAverage 和 m_homeRuns。这很合理，因为这些属性是特定于 BaseballPlayer 的，而不是任何 Person 都有的。

因此，BaseballPlayer 对象将有 4 个成员变量：来自 BaseballPlayer 的 m_battingAverage 和 m_homeRuns，以及来自 Person 的 m_name 和 m_age。

这很容易证明：

#include <iostream>
#include <string>
#include <string_view>

class Person
{
public:
    std::string m_name{};
    int m_age{};

    Person(std::string_view name = "", int age = 0)
        : m_name{name}, m_age{age}
    {
    }

    const std::string& getName() const { return m_name; }
    int getAge() const { return m_age; }

};

// BaseballPlayer 公有继承 Person
class BaseballPlayer : public Person
{
public:
    double m_battingAverage{};
    int m_homeRuns{};

    BaseballPlayer(double battingAverage = 0.0, int homeRuns = 0)
       : m_battingAverage{battingAverage}, m_homeRuns{homeRuns}
    {
    }
};

int main()
{
    // 创建一个新的 BaseballPlayer 对象
    BaseballPlayer joe{};
    // 给它分配一个名字（我们可以直接这样做，因为 m_name 是公有的）
    joe.m_name = "Joe";
    // 打印名字
    std::cout << joe.getName() << '\n'; // 使用我们从 Person 基类获得的 getName() 函数

    return 0;
}

输出值为：

Joe

这段代码可以编译并运行，因为 joe 是一个 BaseballPlayer，而所有 BaseballPlayer 对象都有一个从 Person 类继承的 m_name 成员变量和 getName() 成员函数。

Employee 派生类

现在让我们编写另一个也继承自 Person 的类。这次，我们将编写一个 Employee 类。雇员“是一个”人，因此使用继承是合适的：

// Employee 公有继承自 Person
class Employee: public Person
{
public:
    double m_hourlySalary{};
    long m_employeeID{};

    Employee(double hourlySalary = 0.0, long employeeID = 0)
        : m_hourlySalary{hourlySalary}, m_employeeID{employeeID}
    {
    }

    void printNameAndSalary() const
    {
        std::cout << m_name << ": " << m_hourlySalary << '\n';
    }
};

Employee 从 Person 继承了 m_name 和 m_age（以及两个访问函数），并添加了两个成员变量和一个自己的成员函数。注意，printNameAndSalary() 同时使用了它所属类（Employee::m_hourlySalary）和父类（Person::m_name）的变量。

这给我们一个如下所示的派生图：

注意，Employee 和 BaseballPlayer 没有直接关系，尽管它们都继承自 Person。

这是一个使用 Employee 的完整示例：

#include <iostream>
#include <string>
#include <string_view>

class Person
{
public:
    std::string m_name{};
    int m_age{};

    Person(std::string_view name = "", int age = 0)
        : m_name{name}, m_age{age}
    {
    }

    const std::string& getName() const { return m_name; }
    int getAge() const { return m_age; }

};

// Employee 公有继承自 Person
class Employee: public Person
{
public:
    double m_hourlySalary{};
    long m_employeeID{};

    Employee(double hourlySalary = 0.0, long employeeID = 0)
        : m_hourlySalary{hourlySalary}, m_employeeID{employeeID}
    {
    }

    void printNameAndSalary() const
    {
        std::cout << m_name << ": " << m_hourlySalary << '\n';
    }
};

int main()
{
    Employee frank{20.25, 12345};
    frank.m_name = "Frank"; // 我们可以这样做，因为 m_name 是公有的

    frank.printNameAndSalary();
    
    return 0;
}

这会打印：

Frank: 20.25

继承链

可以从一个本身派生自另一个类的类继承。这样做时没有什么值得注意或特别的——一切都像上面的例子一样进行。

例如，让我们编写一个 Supervisor 类。Supervisor 是一个 Employee，而 Employee 是一个 Person。我们已经编写了一个 Employee 类，所以让我们用它作为基类来派生 Supervisor：

class Supervisor: public Employee
{
public:
    // 这个 Supervisor 最多可以监督 5 名员工
    long m_overseesIDs[5]{};
};

现在我们的派生图如下所示：

所有 Supervisor 对象都继承 Employee 和 Person 的函数和变量，并添加自己的成员变量 m_overseesIDs。

通过构建这样的继承链，我们可以创建一组可重用的类，这些类在顶层非常通用，并在每个继承级别逐渐变得更加具体。

为什么这种继承有用？

从基类继承意味着我们不必在派生类中重新定义基类的信息。我们通过继承自动获得基类的成员函数和成员变量，然后只需添加我们想要的额外函数或成员变量。这不仅节省了工作，而且意味着如果我们更新或修改基类（例如添加新函数或修复错误），所有派生类都会自动继承这些更改！

例如，如果我们向 Person 添加一个新函数，那么 Employee、Supervisor 和 BaseballPlayer 将自动获得访问权限。如果我们向 Employee 添加一个新变量，那么 Supervisor 也会获得访问权限。这使我们能够以简单、直观且低维护的方式构建新类！

总结

继承允许我们通过让其他类继承其成员来重用类。在未来的课程中，我们将继续探索这是如何工作的。
