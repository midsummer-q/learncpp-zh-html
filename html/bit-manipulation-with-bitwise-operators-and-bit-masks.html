O.3 — 使用位运算符和位掩码进行位操作

● 机器译文 课程 O.3 查看英文原文

在上一节关于位运算符的课程中（O.2 -- 位运算符），我们讨论了各种位运算符如何对操作数中的每个位应用逻辑运算符。现在我们了解了它们的功能，让我们看看它们更常见的用法。

位掩码

为了操作单个位（例如打开或关闭它们），我们需要某种方法来识别我们想要操作的特定位。不幸的是，位运算符不知道如何处理位位置。相反，它们使用位掩码。

一个 位掩码 是一个预定义的位集合，用于选择哪些特定位将被后续操作修改。

考虑一个现实生活中的例子：你想粉刷一个窗框。如果不小心，你不仅会粉刷窗框，还会粉刷玻璃本身。你可以买一些遮蔽胶带，把它贴在玻璃和其他你不想粉刷的部分。然后当你粉刷时，遮蔽胶带会阻止油漆接触到任何你不想粉刷的东西。最终，只有未遮蔽的部分（你想粉刷的部分）被粉刷。

位掩码对位执行的功能基本相同——位掩码阻止位运算符接触我们不想修改的位，并允许访问我们想要修改的位。

让我们首先探讨如何定义一些简单的位掩码，然后我们将向你展示如何使用它们。

在 C++14 中定义位掩码

最简单的位掩码集合是为每个位位置定义一个位掩码。我们使用 0 来屏蔽我们不关心的位，使用 1 来表示我们想要修改的位。

虽然位掩码可以是字面量，但它们通常被定义为符号常量，以便赋予有意义的名称并易于重用。

由于 C++14 支持二进制字面量，定义这些位掩码很容易：

#include <cstdint>

constexpr std::uint8_t mask0{ 0b0000'0001 }; // 表示位 0
constexpr std::uint8_t mask1{ 0b0000'0010 }; // 表示位 1
constexpr std::uint8_t mask2{ 0b0000'0100 }; // 表示位 2 
constexpr std::uint8_t mask3{ 0b0000'1000 }; // 表示位 3
constexpr std::uint8_t mask4{ 0b0001'0000 }; // 表示位 4
constexpr std::uint8_t mask5{ 0b0010'0000 }; // 表示位 5
constexpr std::uint8_t mask6{ 0b0100'0000 }; // 表示位 6
constexpr std::uint8_t mask7{ 0b1000'0000 }; // 表示位 7

现在我们有一组符号常量，代表每个位位置。我们可以使用它们来操作位（我们稍后将展示如何操作）。

在 C++11 或更早版本中定义位掩码

由于 C++11 不支持二进制字面量，我们必须使用其他方法来设置符号常量。有两种好的方法。

第一种方法是使用十六进制字面量。

相关内容

我们在课程中讨论了十六进制 5.2 -- 字面量。

以下是十六进制转换为二进制的方法：

十六进制0123456789一个BCDEF
二元0000000100100011010001010110011110001001101010111100110111101111

因此，我们可以像这样使用十六进制定义位掩码：

constexpr std::uint8_t mask0{ 0x01 }; // 0000 0001 的十六进制
constexpr std::uint8_t mask1{ 0x02 }; // 0000 0010 的十六进制
constexpr std::uint8_t mask2{ 0x04 }; // 0000 0100 的十六进制
constexpr std::uint8_t mask3{ 0x08 }; // 0000 1000 的十六进制
constexpr std::uint8_t mask4{ 0x10 }; // 0001 0000 的十六进制
constexpr std::uint8_t mask5{ 0x20 }; // 0010 0000 的十六进制
constexpr std::uint8_t mask6{ 0x40 }; // 0100 0000 的十六进制
constexpr std::uint8_t mask7{ 0x80 }; // 1000 0000 的十六进制

有时前导的十六进制 0 会被省略（例如，而不是 0x01 你只会看到 0x1）。无论哪种方式，如果你不熟悉十六进制到二进制的转换，这可能有点难以阅读。

一种更简单的方法是使用左移运算符将单个位移到正确的位置：

constexpr std::uint8_t mask0{ 1 << 0 }; // 0000 0001 
constexpr std::uint8_t mask1{ 1 << 1 }; // 0000 0010
constexpr std::uint8_t mask2{ 1 << 2 }; // 0000 0100
constexpr std::uint8_t mask3{ 1 << 3 }; // 0000 1000
constexpr std::uint8_t mask4{ 1 << 4 }; // 0001 0000
constexpr std::uint8_t mask5{ 1 << 5 }; // 0010 0000
constexpr std::uint8_t mask6{ 1 << 6 }; // 0100 0000
constexpr std::uint8_t mask7{ 1 << 7 }; // 1000 0000

测试一个位（查看它是开还是关）

现在我们有一组位掩码，我们可以将它们与位标志变量结合使用来操作我们的位标志。

要确定一个位是开还是关，我们使用 按位与 与相应位的位掩码结合：

#include <cstdint>
#include <iostream>

int main()
{
	[[maybe_unused]] constexpr std::uint8_t mask0{ 0b0000'0001 }; // 表示位 0
	[[maybe_unused]] constexpr std::uint8_t mask1{ 0b0000'0010 }; // 表示位 1
	[[maybe_unused]] constexpr std::uint8_t mask2{ 0b0000'0100 }; // 表示位 2 
	[[maybe_unused]] constexpr std::uint8_t mask3{ 0b0000'1000 }; // 表示位 3
	[[maybe_unused]] constexpr std::uint8_t mask4{ 0b0001'0000 }; // 表示位 4
	[[maybe_unused]] constexpr std::uint8_t mask5{ 0b0010'0000 }; // 表示位 5
	[[maybe_unused]] constexpr std::uint8_t mask6{ 0b0100'0000 }; // 表示位 6
	[[maybe_unused]] constexpr std::uint8_t mask7{ 0b1000'0000 }; // 表示位 7

	std::uint8_t flags{ 0b0000'0101 }; // 8 位大小意味着可容纳 8 个标志

	std::cout << "bit 0 is " << (static_cast<bool>(flags & mask0) ? "on\n" : "off\n");
	std::cout << "bit 1 is " << (static_cast<bool>(flags & mask1) ? "on\n" : "off\n");

	return 0;
}

这会打印：

bit 0 is on
bit 1 is off

让我们检查一下这是如何工作的。

在 flags & mask0的情况下，我们有 0000'0101 & 0000'0001。让我们对齐它们：

0000'0101 &
0000'0001
---------
0000'0001

然后我们将 0000'0001 转换为 bool转换为布尔值。由于任何非零数字转换为 true ，并且这个值有一个非零数字，所以计算结果为 true。

在 flags & mask1的情况下，我们有 0000'0101 & 0000'0010。让我们对齐它们：

0000'0101 &
0000'0010
---------
0000'0000

由于零值转换为 false ，并且这个值只有零数字，所以计算结果为 false。

设置一个位

要设置（打开）一个位（值为 1），我们使用按位或等于（运算符 |=）与相应位的位掩码结合：

#include <cstdint>
#include <iostream>

int main()
{
    [[maybe_unused]] constexpr std::uint8_t mask0{ 0b0000'0001 }; // 表示位 0
    [[maybe_unused]] constexpr std::uint8_t mask1{ 0b0000'0010 }; // 表示位 1
    [[maybe_unused]] constexpr std::uint8_t mask2{ 0b0000'0100 }; // 表示位 2 
    [[maybe_unused]] constexpr std::uint8_t mask3{ 0b0000'1000 }; // 表示位 3
    [[maybe_unused]] constexpr std::uint8_t mask4{ 0b0001'0000 }; // 表示位 4
    [[maybe_unused]] constexpr std::uint8_t mask5{ 0b0010'0000 }; // 表示位 5
    [[maybe_unused]] constexpr std::uint8_t mask6{ 0b0100'0000 }; // 表示位 6
    [[maybe_unused]] constexpr std::uint8_t mask7{ 0b1000'0000 }; // 表示位 7
    
    std::uint8_t flags{ 0b0000'0101 }; // 8 位大小意味着可容纳 8 个标志

    std::cout << "bit 1 is " << (static_cast<bool>(flags & mask1) ? "on\n" : "off\n");

    flags |= mask1; // 打开位 1

    std::cout << "bit 1 is " << (static_cast<bool>(flags & mask1) ? "on\n" : "off\n");

    return 0;
}

这会打印：

bit 1 is off
bit 1 is on

我们也可以同时打开多个位，使用 按位或：

flags |= (mask4 | mask5); // 同时打开位 4 和位 5

重置一个位

要重置（清除）一个位（为值0），我们使用 按位与 和 按位非 一起：

#include <cstdint>
#include <iostream>

int main()
{
    [[maybe_unused]] constexpr std::uint8_t mask0{ 0b0000'0001 }; // 表示位 0
    [[maybe_unused]] constexpr std::uint8_t mask1{ 0b0000'0010 }; // 表示位 1
    [[maybe_unused]] constexpr std::uint8_t mask2{ 0b0000'0100 }; // 表示位 2 
    [[maybe_unused]] constexpr std::uint8_t mask3{ 0b0000'1000 }; // 表示位 3
    [[maybe_unused]] constexpr std::uint8_t mask4{ 0b0001'0000 }; // 表示位 4
    [[maybe_unused]] constexpr std::uint8_t mask5{ 0b0010'0000 }; // 表示位 5
    [[maybe_unused]] constexpr std::uint8_t mask6{ 0b0100'0000 }; // 表示位 6
    [[maybe_unused]] constexpr std::uint8_t mask7{ 0b1000'0000 }; // 表示位 7
    
    std::uint8_t flags{ 0b0000'0101 }; // 8 位大小意味着可容纳 8 个标志

    std::cout << "bit 2 is " << (static_cast<bool>(flags & mask2) ? "on\n" : "off\n");

    flags &= ~mask2; // 关闭位 2

    std::cout << "bit 2 is " << (static_cast<bool>(flags & mask2) ? "on\n" : "off\n");

    return 0;
}

这会打印：

bit 2 is on
bit 2 is off

我们可以同时关闭多个位：

flags &= ~(mask4 | mask5); // 同时关闭位 4 和位 5

关键提示

某些编译器可能会对以下行发出符号转换的警告：

flags &= ~mask2;

因为类型 mask2 小于 int， operator~ 导致操作数 mask2 经历整型提升为类型 int。然后编译器抱怨我们试图使用 operator&= ，其中左操作数是无符号的，右操作数是有符号的。

如果是这种情况，请尝试以下方法：

flags &= static_cast<std::uint8_t>(~mask2);

我们在课程中讨论这个问题 O.2 -- 位运算符。

翻转一个位

要切换（翻转）一个位的状态（从0到1或从1到0），我们使用 按位异或：

#include <cstdint>
#include <iostream>

int main()
{
    [[maybe_unused]] constexpr std::uint8_t mask0{ 0b0000'0001 }; // 表示位 0
    [[maybe_unused]] constexpr std::uint8_t mask1{ 0b0000'0010 }; // 表示位 1
    [[maybe_unused]] constexpr std::uint8_t mask2{ 0b0000'0100 }; // 表示位 2 
    [[maybe_unused]] constexpr std::uint8_t mask3{ 0b0000'1000 }; // 表示位 3
    [[maybe_unused]] constexpr std::uint8_t mask4{ 0b0001'0000 }; // 表示位 4
    [[maybe_unused]] constexpr std::uint8_t mask5{ 0b0010'0000 }; // 表示位 5
    [[maybe_unused]] constexpr std::uint8_t mask6{ 0b0100'0000 }; // 表示位 6
    [[maybe_unused]] constexpr std::uint8_t mask7{ 0b1000'0000 }; // 表示位 7

    std::uint8_t flags{ 0b0000'0101 }; // 8 位大小意味着可容纳 8 个标志

    std::cout << "bit 2 is " << (static_cast<bool>(flags & mask2) ? "on\n" : "off\n");
    flags ^= mask2; // 翻转位 2
    std::cout << "bit 2 is " << (static_cast<bool>(flags & mask2) ? "on\n" : "off\n");
    flags ^= mask2; // 翻转位 2
    std::cout << "bit 2 is " << (static_cast<bool>(flags & mask2) ? "on\n" : "off\n");

    return 0;
}

这会打印：

bit 2 is on
bit 2 is off
bit 2 is on

我们可以同时翻转多个位：

flags ^= (mask4 | mask5); // 同时翻转位 4 和位 5

位掩码和 std::bitset

std::bitset 支持全套位运算符。因此，尽管使用函数（test、set、reset 和 flip）来修改单个位更容易，但如果你愿意，也可以使用位运算符和位掩码。

为什么要这样做？这些函数只允许你修改单个位。位运算符允许你同时修改多个位。

#include <bitset>
#include <iostream>

int main()
{
	[[maybe_unused]] constexpr std::bitset<8> mask0{ 0b0000'0001 }; // 表示位 0
	[[maybe_unused]] constexpr std::bitset<8> mask1{ 0b0000'0010 }; // 表示位 1
	[[maybe_unused]] constexpr std::bitset<8> mask2{ 0b0000'0100 }; // 表示位 2 
	[[maybe_unused]] constexpr std::bitset<8> mask3{ 0b0000'1000 }; // 表示位 3
	[[maybe_unused]] constexpr std::bitset<8> mask4{ 0b0001'0000 }; // 表示位 4
	[[maybe_unused]] constexpr std::bitset<8> mask5{ 0b0010'0000 }; // 表示位 5
	[[maybe_unused]] constexpr std::bitset<8> mask6{ 0b0100'0000 }; // 表示位 6
	[[maybe_unused]] constexpr std::bitset<8> mask7{ 0b1000'0000 }; // 表示位 7

	std::bitset<8> flags{ 0b0000'0101 }; // 8 位大小意味着可容纳 8 个标志
	std::cout << "bit 1 is " << (flags.test(1) ? "on\n" : "off\n");
	std::cout << "bit 2 is " << (flags.test(2) ? "on\n" : "off\n");

	flags ^= (mask1 | mask2); // 翻转位 1 和位 2
	std::cout << "bit 1 is " << (flags.test(1) ? "on\n" : "off\n");
	std::cout << "bit 2 is " << (flags.test(2) ? "on\n" : "off\n");

	flags |= (mask1 | mask2); // 打开位 1 和位 2
	std::cout << "bit 1 is " << (flags.test(1) ? "on\n" : "off\n");
	std::cout << "bit 2 is " << (flags.test(2) ? "on\n" : "off\n");

	flags &= ~(mask1 | mask2); // 关闭位 1 和位 2
	std::cout << "bit 1 is " << (flags.test(1) ? "on\n" : "off\n");
	std::cout << "bit 2 is " << (flags.test(2) ? "on\n" : "off\n");

	return 0;
}

这会打印：

bit 1 is off
bit 2 is on
bit 1 is on
bit 2 is off
bit 1 is on
bit 2 is on
bit 1 is off
bit 2 is off

使位掩码有意义

将我们的位掩码命名为“mask1”或“mask2”告诉我们正在操作哪个位，但没有说明该位标志实际用于什么。

一个最佳实践是给位掩码起有用的名称，作为记录位标志含义的方式。以下是我们可能编写的一个游戏示例：

#include <cstdint>
#include <iostream>

int main()
{
        // 定义一系列物理/情绪状态
	[[maybe_unused]] constexpr std::uint8_t isHungry   { 1 << 0 }; // 0000 0001
	[[maybe_unused]] constexpr std::uint8_t isSad      { 1 << 1 }; // 0000 0010
	[[maybe_unused]] constexpr std::uint8_t isMad      { 1 << 2 }; // 0000 0100
	[[maybe_unused]] constexpr std::uint8_t isHappy    { 1 << 3 }; // 0000 1000
	[[maybe_unused]] constexpr std::uint8_t isLaughing { 1 << 4 }; // 0001 0000
	[[maybe_unused]] constexpr std::uint8_t isAsleep   { 1 << 5 }; // 0010 0000
	[[maybe_unused]] constexpr std::uint8_t isDead     { 1 << 6 }; // 0100 0000
	[[maybe_unused]] constexpr std::uint8_t isCrying   { 1 << 7 }; // 1000 0000

	std::uint8_t me{}; // 开始时所有标志/选项都关闭
	me |= (isHappy | isLaughing); // 我开心且大笑
	me &= ~isLaughing; // 我不再大笑了

	// 查询几个状态
	// （我们将使用 static_cast<bool> 将结果解释为布尔值）
	std::cout << std::boolalpha; // 打印 true 或 false 而不是 1 或 0
	std::cout << "I am happy? " << static_cast<bool>(me & isHappy) << '\n';
	std::cout << "I am laughing? " << static_cast<bool>(me & isLaughing) << '\n';

	return 0;
}

以下是使用 std::bitset 实现的相同示例：

#include <bitset>
#include <iostream>

int main()
{
        // 定义一系列物理/情绪状态
	[[maybe_unused]] constexpr std::bitset<8> isHungry   { 0b0000'0001 };
	[[maybe_unused]] constexpr std::bitset<8> isSad      { 0b0000'0010 };
	[[maybe_unused]] constexpr std::bitset<8> isMad      { 0b0000'0100 };
	[[maybe_unused]] constexpr std::bitset<8> isHappy    { 0b0000'1000 };
	[[maybe_unused]] constexpr std::bitset<8> isLaughing { 0b0001'0000 };
	[[maybe_unused]] constexpr std::bitset<8> isAsleep   { 0b0010'0000 };
	[[maybe_unused]] constexpr std::bitset<8> isDead     { 0b0100'0000 };
	[[maybe_unused]] constexpr std::bitset<8> isCrying   { 0b1000'0000 };


	std::bitset<8> me{}; // 开始时所有标志/选项都关闭
	me |= (isHappy | isLaughing); // 我开心且大笑
	me &= ~isLaughing; // 我不再大笑了

	// 查询几个状态（我们使用 any() 函数查看是否有任何位仍被设置）
	std::cout << std::boolalpha; // 打印 true 或 false 而不是 1 或 0
	std::cout << "I am happy? " << (me & isHappy).any() << '\n';
	std::cout << "I am laughing? " << (me & isLaughing).any() << '\n';

	return 0;
}

这里有两点需要注意：首先，std::bitset 没有一个方便的函数允许你使用位掩码查询位。因此，如果你想使用位掩码而不是位置索引，你必须使用 按位与 来查询位。其次，我们使用了 any() 函数，如果任何位被设置则返回 true，否则返回 false，以查看我们查询的位是保持打开还是关闭。

位标志何时最有用？

敏锐的读者可能会注意到，上面的示例实际上并没有节省任何内存。8 个单独的布尔值通常需要 8 个字节。但上面的示例（使用 std::uint8_t）使用了 9 个字节——8 个字节用于定义位掩码，1 个字节用于标志变量！

当你有很多相同的标志变量时，位标志最有意义。例如，在上面的示例中，假设不是一个人（我），而是有 100 个人。如果你为每个人使用 8 个布尔值（每个可能的状态一个），你将使用 800 字节的内存。使用位标志，你将使用 8 个字节用于位掩码，100 个字节用于位标志变量，总共 108 字节的内存——大约节省了 8 倍的内存。

对于大多数程序，使用位标志节省的内存量不值得增加的复杂性。但在有数万甚至数百万个相似对象的程序中，使用位标志可以大幅减少内存使用。如果你需要，这是一个有用的优化工具。

还有另一种情况，位标志和位掩码可能很有意义。假设你有一个函数可以接受 32 个不同选项的任意组合。编写该函数的一种方法是使用 32 个单独的布尔参数：

void someFunction(bool option1, bool option2, bool option3, bool option4, bool option5, bool option6, bool option7, bool option8, bool option9, bool option10, bool option11, bool option12, bool option13, bool option14, bool option15, bool option16, bool option17, bool option18, bool option19, bool option20, bool option21, bool option22, bool option23, bool option24, bool option25, bool option26, bool option27, bool option28, bool option29, bool option30, bool option31, bool option32);

希望你会给参数起更具描述性的名称，但这里的重点是向你展示参数列表有多冗长。

然后，当你想要调用该函数并将选项 10 和 32 设置为 true 时，你必须这样做：

someFunction(false, false, false, false, false, false, false, false, false, true, false, false, false, false, false, false, false, false, false, false, false, false, false, false, false, false, false, false, false, false, false, true);

这非常难以阅读（是选项 9、10 还是 11 被设置为 true？），并且意味着你必须记住哪个参数对应哪个选项（设置“编辑标志”是第 9、10 还是第 11 个参数？）。

相反，如果你像这样使用位标志定义函数：

void someFunction(std::bitset<32> options);

那么你可以使用位标志只传入你想要的选项：

someFunction(option10 | option32);

这更具可读性。

这是 OpenGL（一个备受推崇的 3D 图形库）选择使用位标志参数而不是多个连续的布尔参数的原因之一。

以下是 OpenGL 中的一个示例函数调用：

glClear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT); // 清除颜色和深度缓冲区

GL_COLOR_BUFFER_BIT 和 GL_DEPTH_BUFFER_BIT 是位掩码，定义如下（在 gl2.h 中）：

#define GL_DEPTH_BUFFER_BIT               0x00000100
#define GL_STENCIL_BUFFER_BIT             0x00000400
#define GL_COLOR_BUFFER_BIT               0x00004000

涉及多个位的位掩码

虽然位掩码通常用于选择单个位，但它们也可以用于选择多个位。让我们看一个稍微复杂一点的例子。

彩色显示设备（如电视和显示器）由数百万个像素组成，每个像素可以显示一个彩色点。每个彩色点是由三束光组合而成的：一束红光、一束绿光和一束蓝光（RGB）。这些光的强度变化会产生不同的颜色。

通常，给定像素的 R、G 和 B 的强度由一个 8 位无符号整数表示。例如，红色像素的 R=255，G=0，B=0。紫色像素的 R=255，G=0，B=255。中灰色像素的 R=127，G=127，B=127。

在为像素分配颜色值时，除了 R、G 和 B 之外，通常还使用第四个值 A。“A”代表“alpha”，它控制颜色的透明度。如果 A=0，颜色完全透明。如果 A=255，颜色不透明。

R、G、B 和 A 通常存储为一个 32 位整数，每个分量使用 8 位：

32 位 RGBA 值
位 31-24位 23-16位 15-8位 7-0
RRRRRRRRGGGGGGGGBBBBBBBBAAAAAAAA
红色绿色蓝色alpha

以下程序要求用户输入一个 32 位十六进制值，然后提取 R、G、B 和 A 的 8 位颜色值。

#include <cstdint>
#include <iostream>

int main()
{
	constexpr std::uint32_t redBits{ 0xFF000000 };
	constexpr std::uint32_t greenBits{ 0x00FF0000 };
	constexpr std::uint32_t blueBits{ 0x0000FF00 };
	constexpr std::uint32_t alphaBits{ 0x000000FF };

	std::cout << "Enter a 32-bit RGBA color value in hexadecimal (e.g. FF7F3300): ";
	std::uint32_t pixel{};
	std::cin >> std::hex >> pixel; // std::hex 允许我们读入十六进制值

	// 使用按位与来隔离给定颜色的像素，
	// 然后将值右移到底部8位
	const std::uint8_t red{ static_cast<std::uint8_t>((pixel & redBits) >> 24) };
	const std::uint8_t green{ static_cast<std::uint8_t>((pixel & greenBits) >> 16) };
	const std::uint8_t blue{ static_cast<std::uint8_t>((pixel & blueBits) >> 8) };
	const std::uint8_t alpha{ static_cast<std::uint8_t>(pixel & alphaBits) };

	std::cout << "Your color contains:\n";
	std::cout << std::hex; // 以十六进制打印以下值

        // 提醒：std::uint8_t 可能会打印为字符
        // 我们使用 static_cast 转换为 int 以确保它打印为整数
	std::cout << static_cast<int>(red)   << " red\n";
	std::cout << static_cast<int>(green) << " green\n";
	std::cout << static_cast<int>(blue)  << " blue\n";
	std::cout << static_cast<int>(alpha) << " alpha\n";

	return 0;
}

这将产生输出：

Enter a 32-bit RGBA color value in hexadecimal (e.g. FF7F3300): FF7F3300
Your color contains:
ff red
7f green
33 blue
0 alpha

在上面的程序中，我们使用 按位与 来查询我们感兴趣的 8 位集合，然后我们将它们 右移 成一个 8 位值，以便将它们打印为十六进制值。

总结

总结如何设置、清除、切换和查询位标志：

要查询位状态，我们使用 按位与：

if (flags & option4) ... // 如果设置了 option4，则执行某些操作

要设置位（打开），我们使用 按位或：

flags |= option4; // 打开选项 4。
flags |= (option4 | option5); // 打开选项 4 和 5。

要清除位（关闭），我们使用 按位与 替换为 按位取反：

flags &= ~option4; // 关闭选项 4
flags &= ~(option4 | option5); // 关闭选项 4 和 5

要翻转位状态，我们使用 按位异或：

flags ^= option4; // 翻转 option4 从开到关，或反之
flags ^= (option4 | option5); // 翻转选项 4 和 5
