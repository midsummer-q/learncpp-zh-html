位运算符

C++ 提供了 6 个位操作运算符，通常称为 位 运算符：

运算符符号形式该操作返回一个值，其中：
左移<<x << n来自 x 的位向左移动 n 个位置，新位为 0。
右移>>x >> n来自 x 向右移动 n 个位置，新位为 0。
按位取反~~x来自 x 的每一位被翻转。
按位与&x & y当 x 和 y 是 1。
按位或|x | y当 x 和 y 等于 1。
按位异或^x ^ y当 x 和 y 中的对应位不同时，该位被设置。

这些是非修改运算符（它们不修改操作数）。

作者注

在以下示例中，我们主要使用 4 位二进制值。这是为了方便并保持示例简单。在实际程序中，使用的位数取决于对象的大小（例如，一个 2 字节的对象将存储 16 位）。

为了提高可读性，我们可能还会省略 0b 代码示例之外的二进制字面量的前缀（例如，不使用 0b0101，我们可能选择使用 0101)。

位运算符是为整型类型和 std::bitset定义的。我们将在示例中使用 std::bitset ，因为以二进制形式打印输出更容易。

避免对有符号整型操作数使用位运算符，因为许多运算符在 C++20 之前会返回实现定义的结果，或者有其他潜在的陷阱，通过使用无符号操作数（或 std::bitset)。

最佳实践

为了避免意外，请将位运算符与无符号整型操作数或 std::bitset。

一起使用。

浮点类型的 按位左移 (<<) 运算符将位向左移动。左操作数是提供初始位序列的表达式，右操作数是一个整数，指定要移动的位数。例如，当我们写 x << 2时，我们是在说“生成一个值，其中来自 x 已被左移了2个位置。

左操作数不会被修改，而从右侧移入的新位是 0。

以下是一些左移位序列的例子 0011：

0011 \<\< 1 is 0110
0011 \<\< 2 is 1100
0011 \<\< 3 is 1000

注意，在第三种情况下，我们将一个 1 位移出了数字的末端！被移出位序列的位将永远丢失。

浮点类型的 按位右移 (>>) 运算符的工作方式类似，但将位向右移动。

以下是一些右移位序列的例子 1100：

1100 />/> 1 is 0110
1100 />/> 2 is 0011
1100 />/> 3 is 0001

注意，在第三种情况下，我们将一个位移出了数字的右端，因此它丢失了。

让我们在 C++ 中做一个可以编译和运行的例子：

#include <bitset>
#include <iostream>

int main()
{
    std::bitset<4> x { 0b1100 };

    std::cout << x << '\n';
    std::cout << (x >> 1) << '\n'; // 右移1位，得到0110
    std::cout << (x << 1) << '\n'; // 左移1位，得到1000

    return 0;
}

这会打印：

1100
0110
1000

进阶读者

C++ 中的位移是 字节序无关的。左移总是朝向最高有效位，右移朝向最低有效位。

什么！？operator<< 和 operator>> 不是用于输入和输出的吗？

它们确实是。

如今的程序通常不会大量使用按位左移和右移运算符来移位。相反，按位左移运算符更常与 std::cout （或其他输出流对象）一起使用来输出文本。考虑以下程序：

#include <bitset>
#include <iostream>

int main()
{
    unsigned int x { 0b0100 };
    x = x << 1; // 使用operator<<进行左移
    std::cout << std::bitset<4>{ x } << '\n'; // 使用operator<<进行输出

    return 0;
}

该程序打印出：

1000

在上面的程序中， operator<< 如何知道在一种情况下移位，而在另一种情况下输出 x ？答案是它查看操作数的类型。如果左操作数是整数类型，那么 operator<< 知道执行其通常的位移行为。如果左操作数是输出流对象，如 std::cout，那么它知道应该执行输出。

同样适用于 operator>>。

相关内容

这种运算符根据参数类型改变其行为的能力利用了称为 运算符重载的特性，我们将在后面的课程 13.5 -- 重载 I/O 运算符简介。

中介绍。注意，如果你同时使用 operator<< 进行输出和左移，则需要使用括号来进行左移：

#include <bitset>
#include <iostream>

int main()
{
	std::bitset<4> x{ 0b0110 };

	std::cout << x << 1 << '\n'; // 打印x的值（0110），然后打印1
	std::cout << (x << 1) << '\n'; // 打印x左移1位的结果（1100）

	return 0;
}

这会打印：

01101
1100

第一行打印 x (0110的值，然后打印字面量 1。第二行打印 x 左移 1 (1100)。

按位非

浮点类型的 按位取反 运算符 (~) 概念上很简单：它只是将每个位从 0 转换为 1翻转，反之亦然。

~0011 is 1100
~0000 0100 is 1111 1011

进阶读者

当解释为整数时，按位 NOT 结果中的位数会影响产生的值。

以下程序说明了这一点：

#include <bitset>
#include <iostream>

int main()
{
    std::bitset<4> b4{ 0b100 }; // b4是0100
    std::bitset<8> b8{ 0b100 }; // b8是0000 0100

    std::cout << "Initial values:\n";
    std::cout << "Bits: " << b4 << ' ' << b8 << '\n';
    std::cout << "Values: " << b4.to_ulong() << ' ' << b8.to_ulong() << "\n\n";    

    b4 = ~b4; // 翻转b4为1011
    b8 = ~b8; // 翻转b8为1111 1011
    
    std::cout << "After bitwise NOT:\n";
    std::cout << "Bits: " << b4 << ' ' << b8 << '\n';
    std::cout << "Values: " << b4.to_ulong() << ' ' << b8.to_ulong() << '\n';    

    return 0;
}

这会打印：

Initial values:
Bits: 0100 00000100
Values: 4 4

After bitwise NOT:
Bits: 1011 11111011
Values: 11 251

最初， b4 和 b8 都设置为 0b100。当用前导零填充时， b4 最终变成 0100 和 b8 为 00000100，并在下一行打印出来。

然后我们使用 to_ulong() 成员函数来解释这些位的值，将其解释为一个 long 整数。你可以看到，两者都 b4 和 b8 打印出值 4。尽管位数不同，但它们表示相同的值。这是因为前导零位对解释后的整数没有贡献任何值。

然后我们使用按位非来翻转每个数的位，所以 b4 现在的位是 1011 和 b8 现在的位是 1111 1011。当作为整数打印时，打印出的值是 11 和 251。如你所见，这些值不再相同。这是因为前导一位对解释后的整数有贡献，而 b8 比 b4。

按位或

按位或 （|）的工作方式很像它的逻辑或对应物。如果你还记得，逻辑或的结果为 true (1）如果两个操作数中的任何一个为 操作数 是 true，否则结果为 false (0)。

然而，逻辑或应用于整个操作数（产生单个真或假结果），而按位或应用于操作数中的每一对位（为每一位产生单个真或假结果）。

让我们用一个例子来说明这一点。考虑表达式 0b0101 | 0b0110。

提示

要手动进行任何二进制按位运算，最容易的方法是将两个操作数像这样对齐：

0 1 0 1 OR (or whatever bitwise operation you are doing)
0 1 1 0

然后，对每一 列 的位应用运算，并将结果写在下面。

在第一列中， 0 或 0 等于 0，所以我们在线下面放一个0。

0 1 0 1 OR
0 1 1 0
-------
0

第二列， 1 或 1 等于 1。第三列 0 或 1 等于 1。第四列， 1 或 0 等于 1。

0 1 0 1 OR
0 1 1 0
-------
0 1 1 1

我们的结果是 0111 二进制。

#include <bitset>
#include <iostream>

int main()
{
	std::cout << (std::bitset<4>{ 0b0101 } | std::bitset<4>{ 0b0110 }) << '\n';

	return 0;
}

这会打印：

0111

我们可以对复合按位或表达式做同样的事情，例如 0b0111 | 0b0011 | 0b0001。如果一列中的任何一位是 1，则该列的结果为 1：

0 1 1 1 OR
0 0 1 1 OR
0 0 0 1
--------
0 1 1 1

以下是上述代码：

#include <bitset>
#include <iostream>

int main()
{
	std::cout << (std::bitset<4>{ 0b0111 } | std::bitset<4>{ 0b0011 } | std::bitset<4>{ 0b0001 }) << '\n';

	return 0;
}

这会打印：

0111

按位与

按位与 （&）的工作方式与上述类似，只是它使用与逻辑而不是或逻辑。也就是说，对于操作数中的每一对位，按位与将结果位设置为 true (1）如果两个配对的位都是 1、和 false (0）否则。

考虑表达式 0b0101 & 0b0110。将每一位对齐并对每一列位应用按位与：

0 1 0 1 AND
0 1 1 0
--------
0 1 0 0

#include <bitset>
#include <iostream>

int main()
{
	std::cout << (std::bitset<4>{ 0b0101 } & std::bitset<4>{ 0b0110 }) << '\n';

	return 0;
}

这会打印：

0100

类似地，我们可以对复合按位与表达式做同样的事情，例如 0b0001 & 0b0011 & 0b0111。如果一列中的所有位都是 1，则该列的结果为 1。

0 0 0 1 AND
0 0 1 1 AND
0 1 1 1
--------
0 0 0 1

#include <bitset>
#include <iostream>

int main()
{
	std::cout << (std::bitset<4>{ 0b0001 } & std::bitset<4>{ 0b0011 } & std::bitset<4>{ 0b0111 }) << '\n';

	return 0;
}

这会打印：

0001

按位异或

最后一个运算符是 按位异或 (^)，也称为 异或。

对于操作数中的每一对位，按位异或将结果位设置为 true (1当且仅当配对位中恰好有一个为 1、和 false (0时。换句话说，按位异或将结果位设置为 true 当配对位不同时（一个为 0 ，另一个为 1)。

考虑表达式 0b0110 ^ 0b0011：

0 1 1 0 XOR
0 0 1 1
-------
0 1 0 1

也可以按列方式计算复合异或表达式，例如 0b0001 ^ 0b0011 ^ 0b0111。如果一列中有偶数个 1 位，结果为 0。如果有奇数个 1 位，结果为 1。

0 0 0 1 XOR
0 0 1 1 XOR
0 1 1 1
--------
0 1 0 1

按位赋值运算符

与算术赋值运算符类似，C++ 提供了按位赋值运算符。这些运算符会修改左操作数。

运算符符号形式该操作修改左操作数，其中：
左移<<x <<= n将 x 的位向左移动 n 个位置，新位为 0。
右移>>x >>= n将 x 向右移动 n 个位置，新位为 0。
按位与&x &= y当 x 和 y 是 1。
按位或|x |= y当 x 和 y 等于 1。
按位异或^x ^= y当 x 和 y 中的对应位不同时，该位被设置。

例如，与其写 x = x >> 1;，你可以写 x >>= 1;。

#include <bitset>
#include <iostream>

int main()
{
    std::bitset<4> bits { 0b0100 };
    bits >>= 1;
    std::cout << bits << '\n';

    return 0;
}

该程序打印出：

0010

顺便说一句……

没有按位非赋值运算符。这是因为其他按位运算符是二元的，但按位非是一元的（那么 ~= 运算符的右侧应该放什么呢？）。如果你想翻转一个对象的所有位，可以使用普通赋值： x = ~x;

按位运算符对较小的整数类型执行整型提升 高级

如果按位运算符的操作数是小于 int的整数类型，这些操作数将被提升（转换）为 int 或 unsigned int，并且返回的结果也将是 int 或 unsigned int。例如，如果我们的操作数是 unsigned short，它们将被提升（转换）为 unsigned int，并且操作的结果将作为 unsigned int。

返回。在许多情况下，这无关紧要。

相关内容

我们在课程 10.2 -- 浮点数和整型提升。

中介绍了整型提升。然而，当对宽度小于 int 或 unsigned int的整数类型使用按位运算符时，有两种情况需要注意：

  • operator~ 和 operator<< 对宽度敏感，并且可能根据操作数的宽度产生不同的结果。
  • 将结果初始化或赋值给较小整数类型的变量是一种窄化转换（因为将 int 或 unsigned int 转换为较小的整数类型可能导致数据丢失）。这在列表初始化中是不允许的，并且你的编译器可能会或可能不会对窄化赋值发出警告。

以下程序展示了这些问题（假设32位整数）：

#include <bitset>
#include <cstdint>
#include <iostream>

int main()
{
    std::uint8_t c { 0b00001111 };
    
    std::cout << std::bitset<32>(~c) << '\n';     // 错误：打印 11111111111111111111111111110000
    std::cout << std::bitset<32>(c << 6) << '\n'; // 错误：打印 0000000000000000001111000000
    std::uint8_t cneg { ~c };                     // 错误：从 unsigned int 到 std::uint8_t 的窄化转换
    c = ~c;                                       // 可能的警告：从 unsigned int 到 std::uint8_t 的窄化转换
 
    return 0;
}

这些问题可以通过使用 static_cast 将位运算的结果转换回较窄的整数类型来解决。以下程序产生了正确的结果：

#include <bitset>
#include <cstdint>
#include <iostream>

int main()
{
    std::uint8_t c { 0b00001111 };

    std::cout << std::bitset<32>(static_cast<std::uint8_t>(~c)) << '\n';     // 正确：打印 00000000000000000000000011110000
    std::cout << std::bitset<32>(static_cast<std::uint8_t>(c << 6)) << '\n'; // 正确：打印 0000000000000000000011000000
    std::uint8_t cneg { static_cast<std::uint8_t>(~c) };                     // 编译通过
    c = static_cast<std::uint8_t>(~c);                                       // 无警告
 
    return 0;
}

警告

位运算符会将操作数提升为较窄的整数类型到 int 或 unsigned int。

operator~ 和 operator<< 对宽度敏感，并且可能根据操作数的宽度产生不同的结果。 static_cast 在使用之前，将此类位运算的结果转换回较窄的整数类型，以确保正确的结果。

最佳实践

尽可能避免对小于 int 的整数类型进行位移操作。

总结

总结如何使用列方法评估位运算：

评估按位或时，如果某一列中的任何位为1，则该列的结果为1。
评估按位与时，如果某一列中的所有位都为1，则该列的结果为1。
评估按位异或时，如果某一列中1的位数为奇数，则该列的结果为1。

在下一课中，我们将探讨如何将这些运算符与位掩码结合使用，以方便位操作。

问题 #2

位旋转类似于位移，只是移出的一端会补回到另一端。例如 0b1001 << 1 会是 0b0010，但左旋转1位的结果是 0b0011 实现一个函数，对 std::bitset<4>进行左旋转。对于这个问题，可以使用 test() 和 set()。

以下代码应该执行：

#include <bitset>
#include <iostream>

// "rotl" 代表 "rotate left"
std::bitset<4> rotl(std::bitset<4> bits)
{
// 在此处编写你的代码
}

int main()
{
	std::bitset<4> bits1{ 0b0001 };
	std::cout << rotl(bits1) << '\n';

	std::bitset<4> bits2{ 0b1001 };
	std::cout << rotl(bits2) << '\n';

	return 0;
}

并打印以下内容：

0010
0011

显示答案

#include <bitset>
#include <iostream>

std::bitset<4> rotl(std::bitset<4> bits)
{
	// 跟踪最左边的位是否为 1
	const bool leftbit{ bits.test(3) };

	bits <<= 1; // 执行左移（将最左边的位移出末尾）

	// 如果最左边的位是 1
	if (leftbit)
		bits.set(0); // 将最右边的位设置为 1

	return bits;
}

int main()
{
	std::bitset<4> bits1{ 0b0001 };
	std::cout << rotl(bits1) << '\n';

	std::bitset<4> bits2{ 0b1001 };
	std::cout << rotl(bits2) << '\n';

	return 0;
}

我们将函数命名为“rotl”而不是“rotateLeft”，因为“rotl”是计算机科学中一个公认的名称，也是标准函数的名称， std::rotl。

问题 #3

额外挑战：重做测验#2，但不要使用 test 和 set 函数（使用位运算符）。

显示提示

提示：如何将最左边的位移到最右边的位置？

显示提示

提示：考虑一下“移位”的视角

显示答案

#include <bitset>
#include <iostream>

// 感谢读者 Chris 提供此解决方案
std::bitset<4> rotl(std::bitset<4> bits)
{
	// bits << 1 执行左移
	// bits >> 3 处理最左边位的旋转
	return (bits<<1) | (bits>>3);
}

int main()
{
	std::bitset<4> bits1{ 0b0001 };
	std::cout << rotl(bits1) << '\n';

	std::bitset<4> bits2{ 0b1001 };
	std::cout << rotl(bits2) << '\n';

	return 0;
}
