4.9 — 布尔值

● 机器译文 课程 4.9 查看英文原文

在现实生活中，我们经常问或被问可以用“是”或“否”回答的问题。“苹果是水果吗？”是的。“你喜欢芦笋吗？”不。

现在考虑一个可以用“真”或“假”回答的类似陈述：“苹果是水果”。这显然是真。或者，“我喜欢芦笋”。绝对是假（呃！）。

这种只有两种可能结果（是/真，或否/假）的句子非常常见，以至于许多编程语言都包含一种特殊的类型来处理它们。这种类型被称为 布尔型 类型（注意：Boolean在英语中正确大写，因为它以发明者乔治·布尔的名字命名）。

布尔变量

布尔变量是只能有两个可能值的变量： true、和 false。

要声明布尔变量，我们使用关键字 bool。

bool b;

要初始化或赋值一个 true 或 false 值给布尔变量，我们使用关键字 true 和 false。

bool b1 { true };
bool b2 { false };
b1 = false;
bool b3 {}; // 默认初始化为 false

就像一元负号运算符（-）可以使整数变为负数一样，逻辑非运算符（!）可以将布尔值从 true 切换到 false，或 false 切换到 true：

bool b1 { !true }; // b1 将被初始化为 false
bool b2 { !false }; // b2 将被初始化为 true

布尔值实际上不是以单词“true”或“false”存储在布尔变量中。相反，它们以整数值存储： true 存储为整数 1、和 false 存储为整数 0。类似地，当评估布尔值时，它们实际上不会评估为“true”或“false”。它们评估为整数 0 （false）或 1 （true）。因为布尔值存储整数值，它们被认为是一种整数类型。

打印布尔值

当我们打印布尔值时， std::cout 打印 0 对于 false、和 1 对于 true：

#include <iostream>

int main()
{
    std::cout << true << '\n'; // true 求值为 1
    std::cout << !true << '\n'; // !true 求值为 0

    bool b {false};
    std::cout << b << '\n'; // b 为 false，求值为 0
    std::cout << !b << '\n'; // !b 为 true，求值为 1
    return 0;
}

输出：

1
0
0
1

使用 std::boolalpha 来打印 true 或 false

如果您想 std::cout 来打印 true 或 false 而不是 0 或 1，您可以输出 std::boolalpha。这不会输出任何内容，但会改变 std::cout 输出 bool 值。

下面是一个示例：

#include <iostream>

int main()
{
    std::cout << true << '\n';
    std::cout << false << '\n';

    std::cout << std::boolalpha; // 将布尔值打印为 true 或 false

    std::cout << true << '\n';
    std::cout << false << '\n';
    return 0;
}

这会打印：

1
0
true
false

您可以使用 std::noboolalpha 将其重新关闭。

整数到布尔类型的转换

使用统一初始化时，您可以使用整数字面量初始化变量 0 （对于 false）和 1 （对于 true）（但您其实应该使用 false 和 true 代替）。其他整数字面量会导致编译错误：

#include <iostream>

int main()
{
	bool bFalse { 0 }; // 可以：初始化为 false
	bool bTrue  { 1 }; // 可以：初始化为 true
	bool bNo    { 2 }; // 错误：不允许窄化转换

	std::cout << bFalse << bTrue << bNo << '\n';
	
	return 0;
}

然而，在整数可以转换为布尔类型的任何上下文中，整数 0 会转换为 false，而任何其他整数会转换为 true。

#include <iostream>

int main()
{
	std::cout << std::boolalpha; // 将布尔值打印为 true 或 false

	bool b1 = 4 ; // 拷贝初始化允许从 int 到 bool 的隐式转换
	std::cout << b1 << '\n';

	bool b2 = 0 ; // 拷贝初始化允许从 int 到 bool 的隐式转换
	std::cout << b2 << '\n';

	return 0;
}

这会打印：

true
false

注意： bool b1 = 4; 可能会生成警告。如果是这样，您必须禁用将警告视为错误才能编译该示例。

输入布尔值

使用……输入布尔值 std::cin 有时会让新手程序员感到困惑。

考虑以下程序：

#include <iostream>

int main()
{
	bool b{}; // 默认初始化为 false
	std::cout << "Enter a boolean value: ";
	std::cin >> b;
	std::cout << "You entered: " << b << '\n';

	return 0;
}

Enter a Boolean value: true
You entered: 0

等等，什么？

默认情况下， std::cin 只接受布尔变量的数值输入： 0 等于 false、和 1 等于 true. 任何其他数值都将被解释为 true，并会导致 std::cin 进入失败模式。任何非数值输入都将被解释为 false 并会导致 std::cin 进入失败模式。

相关内容

我们在第...课中讨论了失败模式（以及如何退出） 9.5 -- std::cin与处理无效输入。

在这个例子中，因为我们输入了 true， std::cin 静默失败，并将 b 切换到 false。因此，当 std::cout 打印一个值给 b，它会打印 0。

为了允许 std::cin 接受单词 false 和 true 作为输入，你首先需要输入到 std::boolalpha：

#include <iostream>

int main()
{
	bool b{};
	std::cout << "Enter a boolean value: ";

	// 允许用户输入 'true' 或 'false' 作为布尔值
	// 这是区分大小写的，因此 True 或 TRUE 将不起作用
	std::cin >> std::boolalpha;
	std::cin >> b;

	// 我们也将布尔值输出为 `true` 或 `false`
	std::cout << std::boolalpha;
	std::cout << "You entered: " << b << '\n';

	return 0;
}

然而，当 std::boolalpha 启用后，数值将不再被接受（它们会被计算为 false 并导致std::cin进入失败模式）。

警告

启用 std::boolalpha 输入时仅允许小写 false 或 true 被接受。带有大写字母的变体将不被接受。 0 和 1 也将不再被接受。

请注意，我们使用 std::cin >> std::boolalpha; 来输入布尔值，作为 true 或 false、和 std::cout << std::boolalpha; 来输出布尔值，作为 true 或 false。这些是独立的控制项，可以启用（使用 std::boolalpha）或禁用（使用 std::noboolalpha）分别设置。

布尔返回值

布尔值常被用作检查某事是否为真的函数的返回值。这类函数通常以单词 等于 （例如 isEqual）或 has （例如 hasCommonDivisor）。

考虑以下示例，它与上面的示例非常相似：

#include <iostream>

// 如果 x 和 y 相等则返回 true，否则返回 false
bool isEqual(int x, int y)
{
    return x == y; // operator== 如果 x 等于 y 则返回 true，否则返回 false
}

int main()
{
    std::cout << "Enter an integer: ";
    int x{};
    std::cin >> x;

    std::cout << "Enter another integer: ";
    int y{};
    std::cin >> y;

    std::cout << std::boolalpha; // 将布尔值打印为 true 或 false
    
    std::cout << x << " and " << y << " are equal? ";
    std::cout << isEqual(x, y) << '\n'; // 将返回 true 或 false

    return 0;
}

以下是该程序两次运行的输出：

Enter an integer: 5
Enter another integer: 5
5 and 5 are equal? true

Enter an integer: 6
Enter another integer: 4
6 and 4 are equal? false

这是如何工作的？首先我们读入整数值用于 x 和 y。接下来，表达式 isEqual(x, y) 被求值。在第一次运行中，这会导致调用函数 isEqual(5, 5)在函数内部， 5 == 5 被求值，产生值 true。该值 true 被返回给调用者，由 std::cout。在第二次运行中，对 isEqual(6, 4) 的调用返回值 false。

布尔值需要一点时间适应，但一旦你理解了它们，它们的简洁性会让你耳目一新！布尔值也是语言的重要组成部分——你最终使用它们的次数会超过其他所有基本类型的总和！
