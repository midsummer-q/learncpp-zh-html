● 机器译文 课程 11.x 查看英文原文

干得好。函数模板可能看起来相当复杂，但它们是一种非常强大的方式，能让你的代码适用于不同类型的对象。我们将在未来的章节中看到更多模板相关内容，所以请做好准备。

章节回顾

函数重载 允许我们创建多个同名函数，只要每个同名函数具有不同的参数类型集合（或者函数可以通过其他方式区分）。这样的函数称为 重载函数 （或 重载 （简称）。返回类型不用于区分。

在解析重载函数时，如果找不到精确匹配，编译器会优先选择可以通过数值提升匹配的重载函数，而不是那些需要数值转换的。当调用一个已被重载的函数时，编译器会根据函数调用中使用的参数尝试将函数调用匹配到合适的重载。这称为 重载解析。

一种 歧义匹配 发生在编译器找到两个或更多可以匹配重载函数调用的函数，并且无法确定哪个最佳时。

一个 默认参数 是为函数参数提供的默认值。具有默认实参的参数必须始终是最右边的参数，并且在解析重载函数时不用于区分函数。

函数模板 允许我们创建一个类似函数的定义，作为创建相关函数的模式。在函数模板中，我们使用 类型模板参数 作为占位符，代表我们稍后要指定的任何类型。告诉编译器我们正在定义模板并声明模板类型的语法称为 模板参数声明。

从函数模板（带有模板类型）创建函数（带有特定类型）的过程称为 函数模板实例化 （或 实例化（简称）。当这个过程因函数调用而发生时，称为 隐式实例化。实例化的函数称为 函数实例 （或 实例 （简称），有时也称为 模板函数)。

模板实参推导 允许编译器从函数调用的实参推导出用于实例化函数的实际类型。模板实参推导不进行类型转换。

模板类型有时称为 泛型类型，使用模板编程有时称为 泛型编程。

在C++20中，当auto关键字用作普通函数中的参数类型时，编译器会自动将函数转换为函数模板，每个auto参数成为一个独立的模板类型参数。这种创建函数模板的方法称为 缩写函数模板。

一个 非类型模板参数 是一种具有固定类型的模板参数，作为传入的 constexpr 值的占位符。

当 count(2.3) 被调用时，编译器将实例化具有原型的函数 count<double>(double) 并调用它。这是一个新的函数，拥有自己的 static c 变量，因此这将返回值 1。

当 count<double>(1) 被调用时，编译器会看到我们显式请求了 double 版本的 count()。由于之前的语句，这个函数已经存在，因此 count<double>(double) 将被调用，并且 int 参数将被隐式转换为 double。这个函数将返回值 2。

问题 #4

这个程序的输出是什么？

#include <iostream>

int foo(int n)
{
    return n + 10;
}

template <typename T>
int foo(T n)
{
    return n;
}

int main()
{
    std::cout << foo(1) << '\n'; // #1

    short s { 2 };
    std::cout << foo(s) << '\n'; // #2
    
    std::cout << foo<int>(4) << '\n'; // #3

    std::cout << foo<int>(s) << '\n'; // #4

    std::cout << foo<>(6) << '\n'; // #5
    
    return 0;
}

显示答案

11
2
4
2
6

在情况1中， foo(1) 精确匹配 foo(int) ，因此非模板函数 foo(int) 被调用。

在情况2中， foo(s) 不精确匹配非模板函数 foo(int) ，但参数 s 可以转换为 int ，因此 foo(int) 是一个候选。然而，编译器更倾向于使用函数模板 foo<T>(T) 来生成精确匹配 foo<short>(short)。所以这调用 foo<short>(short)。

在情况3中， foo<int>(4) 是对 foo<int>，所以 foo(int) 的显式调用。编译器生成 foo<int>(int) 并调用它。

在情况4中，这也是对 foo<int>的显式调用。编译器将参数 s 到 int 提升以匹配参数。

在情况5中，这种语法只会匹配函数模板，因此 foo(int) 不被考虑。 foo<int>(int) 被调用。
