快速回顾

复合数据类型 （也称为 复合数据类型）是可以由基本数据类型（或其他复合数据类型）构造的数据类型。

浮点类型的 值类别 表示表达式解析为值、函数或某种对象。

一种 左值 是求值为具有标识的函数或对象的表达式。具有 标识 的对象或函数具有标识符或可识别的内存地址。左值有两种子类型： 可修改左值 是可以修改的左值，而 不可修改左值 是其值无法修改的左值（通常因为它们是 const 或 constexpr）。

一种 右值 是不是左值的表达式。这包括字面量（字符串字面量除外）以及函数或运算符的返回值（按值返回时）。

一个 引用 是现有对象的别名。一旦定义了引用，对引用的任何操作都会应用于被引用的对象。C++ 包含两种类型的引用：左值引用和右值引用。 左值引用 （通常简称为 引用）充当现有左值（如变量）的别名。 左值引用变量 是一个充当左值（通常是另一个变量）引用的变量。

引用初始化 的初始化形式。当引用用对象（或函数）初始化时，我们说它 到该对象（或函数）。被引用的对象（或函数）有时称为 被引用的对象（或函数）有时称为。

左值引用不能绑定到不可修改的左值或右值（否则您将能够通过引用更改这些值，这将违反它们的 const 性质）。因此，左值引用有时被称为 指向非 const 的左值引用 （有时简称为 非 const 引用)。

一旦初始化，C++ 中的引用就不能 重新绑定，意味着它不能更改为引用另一个对象。

当被引用的对象在引用之前被销毁时，引用将指向一个不再存在的对象。这样的引用称为 悬空引用。访问悬空引用会导致未定义行为。

通过使用 const 关键字声明左值引用时，我们告诉左值引用将其引用的对象视为const。这样的引用称为 指向const值的左值引用 （有时称为 指向const的引用 变为 const引用）。const 引用可以绑定到可修改左值、不可修改左值和右值。

一个 临时对象 （有时也称为 未命名对象 或 匿名对象）是在单个表达式中为临时使用而创建（然后销毁）的对象。

当使用 通过引用传递，我们将函数参数声明为引用（或 const 引用），而不是普通变量。调用函数时，每个引用参数都绑定到相应的实参。由于引用充当实参的别名，因此不会复制实参。

浮点类型的 取地址运算符 （&）返回其操作数的内存地址。 解引用运算符 （*）将给定内存地址的值作为左值返回。

一个 指针 是一个对象，它持有 内存地址 （通常是另一个变量的地址）作为其值。这允许我们存储某个其他对象的地址以供以后使用。与普通变量一样，指针默认不初始化。未初始化的指针有时称为 野指针。一个 悬空指针 是指向不再有效（例如，因为它已被销毁）的对象的指针。

除了内存地址，指针还可以保存一个额外的值：空值。 空值 （常简称为 null）是一个特殊值，表示某物没有值。当指针持有空值时，意味着该指针没有指向任何东西。这样的指针称为 空指针。这些 空指针 关键字表示空指针字面值。我们可以使用 nullptr 来显式初始化或给指针赋空值。

指针应持有有效对象的地址，或设置为 nullptr。这样我们只需要测试指针是否为空，就可以假设任何非空指针都是有效的。

一个 指向 const 值的指针 （有时称为 指向 const 的指针 （简称）是一个指向常量的（非 const）指针。

一个 const 指针 是一个初始化后地址不能被改变的指针。

一个 指向 const 值的 const 指针 不能更改其地址，也不能通过指针更改其指向的值。

使用 按地址传递，调用者不提供对象作为实参，而是提供对象的地址（通过指针）。这个指针（持有对象的地址）被复制到被调用函数的指针参数中（该参数现在也持有对象的地址）。然后函数可以解引用该指针以访问其地址被传递的对象。

按引用返回 返回绑定到被返回对象的引用，从而避免复制返回值。使用返回引用有一个主要注意事项：程序员必须确保被引用的对象比返回引用的函数存活得更久。否则，返回的引用将悬空（引用一个已被销毁的对象），使用该引用将导致未定义行为。如果参数通过引用传递给函数，那么通过引用返回该参数是安全的。

如果函数返回一个引用，并且该引用用于初始化或赋值给一个非引用变量，返回值将被复制（就像按值返回一样）。

变量的类型推导（通过 auto 关键字）会从推导出的类型中丢弃任何引用或顶层 const 限定符。如果需要，可以在变量声明中重新应用这些限定符。

按地址返回 的工作方式与返回引用几乎相同，只是返回的是指向对象的指针而不是对象的引用。

小测验时间

问题 #1

对于 operator << 右侧的每个表达式，指出该表达式是左值还是右值：

a)

std::cout << 5;

显示答案

字面量是右值，因此 5 是右值

b)

int x { 5 };
std::cout << x;

显示答案

表达式 x 标识变量 x，因此这个表达式是左值。

c)

int x { 5 };
std::cout << x + 1;

显示答案

表达式 x + 1 计算一个临时值，因此这个表达式是右值。

d)

int foo() { return 5; }
std::cout << foo();

显示答案

函数的返回值（按值返回时）是右值。

e)

int& max(int &x, int &y) { return x > y ? x : y; }
int x { 5 };
int y { 6 };
std::cout << max(x, y);

显示答案

max() 返回一个左值引用，它是左值

问题 #2

这个程序的输出是什么？

#include <iostream>

int main()
{
	int x{ 4 };
	int y{ 6 };

	int& ref{ x };
	++ref;
	ref = y;
	++ref;

	std::cout << x << ' ' << y;

	return 0;
}

显示答案

7 6

记住，引用不能重新绑定，所以 ref = y 并不使 ref 成为 y的引用。它等价于 x = y。

附注释说明：

#include <iostream>

int main()
{
	int x{ 4 };
	int y{ 6 };

	int& ref{ x }; // ref 现在是 `x` 的别名
	++ref;   // x 现在是 5
	ref = y; // x 现在是 6
	++ref;   // x 现在是 7

	std::cout << x << ' ' << y; // 打印 7 6

	return 0;
}

问题 #3

说出两个理由，说明为什么我们更倾向于尽可能使用 const 引用传递参数，而不是非 const 引用。

显示答案

  1. 非 const 引用参数可用于修改参数的值。如果我们不需要这种能力，最好使用 const 引用传递，这样就不会意外修改参数。
  2. 非 const 引用参数只能接受可修改的左值作为参数。const 引用参数可以接受可修改的左值、不可修改的左值或右值作为参数。

问题 #4

const 指针和指向 const 的指针有什么区别？

显示答案

const 指针是其地址不能改变的指针（不能重新指向其他对象）。但是，被指向的对象的值可以改变。
指向 const 的指针是指向一个对象，该对象的值不能通过该指针改变。但是，指针可以重新指向另一个对象。

问题 #5

编写一个名为 sort2 ，允许调用者传入两个 int 变量作为参数。函数返回时，第一个参数应保存两个值中较小的那个，第二个参数应保存较大的那个。

提示： std::swap() 函数（在 <algorithm> 头文件中）可用于交换两个变量的值。例如， std::swap(x, y) 交换变量 x 和 y。

以下代码应能运行并打印注释中注明的值：

#include <iostream>

int main()
{
    int x { 7 };
    int y { 5 };

    std::cout << x << ' ' << y << '\n'; // 应打印 7 5

    sort2(x, y); // 确保排序在需要交换值时正常工作
    std::cout << x << ' ' << y << '\n'; // 应打印 5 7

    sort2(x, y); // 确保排序在不需要交换值时正常工作
    std::cout << x << ' ' << y << '\n'; // 应打印 5 7

    return 0;
}

显示答案

#include <algorithm> // for std::swap
#include <iostream>

void sort2(int& lesser, int& greater)
{
    // 如果值未排序，我们需要交换它们以使其有序
    if (lesser > greater)
        std::swap(lesser, greater);

    // 如果我们自己编写交换函数，可以这样做：
    // int swap { lesser };
    // lesser = greater;
    // greater = swap;

}

int main()
{
    int x { 7 };
    int y { 5 };

    std::cout << x << ' ' << y << '\n';

    sort2(x, y); // 确保排序在需要交换值时正常工作
    std::cout << x << ' ' << y << '\n';

    sort2(x, y); // 确保排序在不需要交换值时正常工作
    std::cout << x << ' ' << y << '\n';

}
