恭喜！你又完成了一章。你关于结构体获得的知识将在我们学习C++最重要的主题——类时派上用场！

快速回顾

一个 程序定义类型 （也称为 用户定义类型) 是一种我们可以创建用于自己程序的自定义类型。枚举类型和类类型（包括结构体、类和联合体）允许创建程序定义类型。程序定义类型必须先定义才能使用。程序定义类型的定义称为 类型定义。类型定义不受单一定义规则的约束。

一种 枚举 （也称为一个 枚举类型 或 enum) 是一种复合数据类型，其中每个可能的值都定义为一个符号常量（称为 枚举项）。枚举是 独立类型，意味着编译器可以将它们与其他类型区分开（与类型别名不同）。

无作用域枚举 之所以这样命名，是因为它们将枚举器名称放在与枚举定义本身相同的作用域中（而不是像命名空间那样创建新的作用域区域）。无作用域枚举也为其枚举器提供了命名的作用域区域。无作用域枚举会隐式转换为整数值。

有作用域枚举 与无作用域枚举类似，但不会隐式转换为整数，并且枚举器是 时，只有 放置在枚举的作用域区域中（而不是枚举定义所在的作用域区域）。

一个 结构体 （是 结构的缩写）是一种程序定义的数据类型，允许我们将多个变量捆绑到单个类型中。属于结构体（或类）的变量称为 数据成员 （或 成员变量）。要访问特定的成员变量，我们使用 成员选择运算符 (operator.）放在结构体变量名和成员名之间（对于普通结构体和结构体引用），或者使用 指针成员选择运算符 (operator->）（对于指向结构体的指针）。

在一般编程中，一个 聚合数据类型 （也称为一个 聚合) 是任何可以包含多个数据成员的类型。在C++中，数组和仅包含数据成员的结构体是 聚合体。

聚合使用一种称为 聚合初始化的初始化形式，它允许我们直接初始化聚合的成员。为此，我们提供一个 初始化器列表 作为初始化器，它只是一个逗号分隔的值列表。聚合初始化执行 成员式初始化，这意味着结构体中的每个成员按声明顺序初始化。

在C++20中， 指定初始化器 允许你显式定义哪些初始化值映射到哪些成员。成员必须按照在结构体中声明的顺序初始化，否则会导致错误。

当我们定义结构体（或类）类型时，我们可以为每个成员提供默认初始化值作为类型定义的一部分。这个过程称为 非静态成员初始化，初始化值称为 默认成员初始化器。

出于性能原因，编译器有时会在结构体中添加间隙（这称为 填充），因此结构体的大小可能大于其成员大小之和。

一个 类模板 是用于实例化类类型（结构体、类或联合体）的模板定义。 类模板参数推导（CTAD） 是C++17特性，允许编译器从初始化器中推导模板类型参数。

问题 #1

在设计游戏时，我们决定要有怪物，因为每个人都喜欢打怪物。声明一个表示怪物的结构体。怪物应该有一个类型，可以是以下之一：食人魔、龙、兽人、巨型蜘蛛或史莱姆。

每个怪物还应该有一个名字（使用 std::string），以及一个生命值，表示它们在死亡前能承受多少伤害。编写一个名为printMonster()的函数，打印出结构体的所有成员。实例化一个食人魔和一个史莱姆，使用初始化列表初始化它们，并将它们传递给printMonster()。

你的程序应产生以下输出：

This Ogre is named Torg and has 145 health.
This Slime is named Blurp and has 23 health.

显示答案

#include <iostream>
#include <string>
#include <string_view> // C++17

// // 我们的怪物结构体代表单个怪物

struct Monster
{
	// // 将不同的怪物类型定义为枚举
	enum Type
	{
		ogre,
		dragon,
		orc,
		giant_spider,
		slime,
	};

	Type type{};
	std::string name{}; // // Monster 应拥有其名称的所有权
	int health{};
};

// // 返回怪物类型的名称作为字符串
// // 由于这可能在别处使用，最好将其作为单独的函数
constexpr std::string_view getMonsterTypeString(Monster::Type type)
{
	switch (type)
	{
	case Monster::ogre:          return "Ogre";
	case Monster::dragon:        return "Dragon";
	case Monster::orc:           return "Orc";
	case Monster::giant_spider:  return "Giant Spider";
	case Monster::slime:         return "Slime";
	}

	return "Unknown";
}

// // 打印怪物的统计信息
void printMonster(const Monster& monster)
{
	std::cout << "This " << getMonsterTypeString(monster.type) <<
		" is named " << monster.name <<
		" and has " << monster.health << " health.\n";
}

int main()
{
	Monster ogre{ Monster::ogre, "Torg", 145 };
	Monster slime{ Monster::slime, "Blurp", 23 };

	printMonster(ogre);
	printMonster(slime);

	return 0;
}

问题 #2

指定每个给定类型的对象应该按值、常量地址还是常量引用传递。你可以假设接受这些类型作为参数的函数不会修改它们。

a) char

显示答案

char 是基础类型，因此应按值传递。

b) std::string

显示答案

std::string 每次复制字符串时都必须创建副本。请通过 const 引用传递。

c) unsigned long

显示答案

unsigned long 是基础类型，因此应按值传递。

d) bool

显示答案

bool 是基础类型，因此应按值传递。

e) 枚举类型

显示答案

枚举类型保存整数值（通常是 int）。由于整数值按值传递，因此枚举类型应按值传递。

f)

struct Position
{
  double x{};
  double y{};
  double z{};
};

显示答案

Position 是结构体类型，应通过 const 引用传递。

g)

struct Player
{
  int health{};
  // // Player 结构体仍在开发中。将来会添加更多成员。
};

显示答案

尽管 Player 当前状态只包含一个 int ，按值传递很快，但将来会添加更多成员。我们不想在添加成员时更新所有使用 Player 的地方，因此通过 const 引用传递。

h) int （当 null 是有效参数时）

显示答案

通常我们会按值传递 int ，但如果还想传递 null 值，那么按地址传递是个好选择，因为我们可以传递 int，或 nullptr。

i) std::string_view

显示答案

std::string_view 不会创建被查看字符串的副本，并且复制成本低。按值传递。

问题 #3

创建一个类模板，名为 Triad ，包含三个相同模板类型的成员。同时创建一个函数模板，名为 print ，可以打印 Triad。以下程序应能编译：

int main()
{
	Triad t1{ 1, 2, 3 }; // // 注意：使用 CTAD 推导模板参数
	print(t1);

	Triad t2{ 1.2, 3.4, 5.6 }; // // 注意：使用 CTAD 推导模板参数
	print(t2);

	return 0;
}

并产生以下结果：

[1, 2, 3][1.2, 3.4, 5.6]

如果你使用 C++17，则需要提供一个推导指引以使 CTAD 工作（参见 13.14 -- 类模板参数推导（CTAD）和推导指南 了解相关信息）。

显示答案

#include <iostream>

template <typename T>
struct Triad
{
	T first {};
	T second {};
	T third {};
};

// // 如果使用 C++17，我们需要提供推导指引（C++20 中不需要）
// // 具有三个相同类型参数的 Triad 应推导为 Triad<T>
template <typename T>
Triad(T, T, T) -> Triad<T>;

template <typename T>
void print(const Triad<T>& t)
{
	std::cout << '[' << t.first << ", " << t.second << ", " << t.third << ']';
}

int main()
{
	Triad t1{ 1, 2, 3 };
	print(t1);

	Triad t2{ 1.2, 3.4, 5.6 };
	print(t2);

	return 0;
}
