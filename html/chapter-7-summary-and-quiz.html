章节回顾

我们在本章中涵盖了很多内容。干得好，你做得非常棒！

一个 复合语句 或 块 是一组零个或多个语句，编译器将其视为单个语句。块以 { 符号开始，以 } 符号开始，要执行的语句放在其中。块可以在任何允许单个语句的地方使用。块末尾不需要分号。块通常与 if statements 一起使用，以执行多个语句。

用户定义命名空间 是您为自己的声明定义的命名空间。C++提供的命名空间（如 global namespace）或库提供的命名空间（如 namespace std）不被视为用户定义命名空间。

您可以通过 作用域解析运算符(::)访问命名空间中的声明。作用域解析运算符告诉编译器，右操作数指定的标识符应在左操作数的作用域中查找。如果没有提供左操作数，则假定为全局命名空间。

局部变量是在函数内定义的变量（包括函数参数）。局部变量具有 块作用域，这意味着它们从定义点到所在块结束都在作用域内。局部变量具有 自动存储期，这意味着它们在定义点创建，在所在块结束时销毁。

嵌套块中声明的名称可以 隐藏 或 名称隐藏 外部块中同名的变量。应避免这种情况。

全局变量是在函数外部定义的变量。全局变量具有 文件作用域，这意味着它们从声明点到文件末尾都是可见的。全局变量具有 静态存储期，这意味着它们在程序启动时创建，在程序结束时销毁。尽可能避免静态变量的动态初始化。

标识符的 链接性 决定该名称的其他声明是否引用同一个对象。局部变量没有链接。具有 内部链接 的标识符可以在单个文件中被看到和使用，但不能从其他文件访问。具有 外部链接 的标识符可以在定义它们的文件以及其他代码文件中被看到和使用（通过前向声明）。

尽可能避免非const全局变量。const全局变量通常被认为是可接受的。如果您的编译器支持C++17，请使用 内联变量 作为全局常量。

局部变量可以通过 静态 关键字。

一个 限定名称 是包含关联作用域的名称（例如 std::string）。 非限定名 是不包含作用域限定符的名称（例如 string)。

using语句 （包括 using声明 和 using指令）可用于避免显式限定命名空间的标识符。 使用声明 允许我们使用非限定名称（无作用域）作为限定名称的别名。 using 指令 将命名空间中的所有标识符导入到using指令的作用域中。通常应避免这两者。

内联展开 是一个过程，其中函数调用被替换为被调用函数定义中的代码。使用 inline 关键字被称为 内联函数。

内联函数和变量有两个主要要求：

  • 编译器需要能够在每个使用该函数的翻译单元中看到内联函数或变量的完整定义（仅前向声明是不够的）。如果同时提供了前向声明，定义可以出现在使用点之后。
  • 内联函数或变量的每个定义必须相同，否则会导致未定义行为。

在现代C++中，术语 inline 已经演变为“允许多个定义”。因此，内联函数是允许在多个文件中定义的函数。C++17引入了 内联变量，即允许在多个文件中定义的变量。

内联函数和变量对于 仅头文件库特别有用，这些库由一个或多个头文件实现某些功能（不包含 .cpp 文件）。

最后，C++支持 未命名命名空间，它会隐式地将命名空间中的所有内容视为具有内部链接。C++还支持 内联命名空间，它为命名空间提供了一些基本的版本控制功能。

小测验时间

问题 #1

修复以下程序：

#include <iostream>

int main()
{
	std::cout << "Enter a positive number: ";
	int num{};
	std::cin >> num;


	if (num < 0)
		std::cout << "Negative number entered.  Making positive.\n";
		num = -num;

	std::cout << "You entered: " << num;

	return 0;
}

显示答案

#include <iostream>

int main()
{
	std::cout << "Enter a positive number: ";
	int num{};
	std::cin >> num;


	if (num < 0)
	{ // 这里需要代码块，以便在 num < 0 时两个语句都执行
		std::cout << "Negative number entered.  Making positive.\n";
		num = -num;
	}

	std::cout << "You entered: " << num;

	return 0;
}

问题 #2

编写一个名为 constants.h 的文件，使以下程序能够运行。如果你的编译器支持C++17，请使用内联 constexpr 变量。否则，使用普通的 constexpr 变量。 maxClassSize 的值应为 35。

main.cpp:

#include "constants.h"
#include <iostream>

int main()
{
	std::cout << "How many students are in your class? ";
	int students{};
	std::cin >> students;


	if (students > Constants::maxClassSize)
		std::cout << "There are too many students in this class";
	else
		std::cout << "This class isn't too large";

	return 0;
}

显示答案

constants.h：

#ifndef CONSTANTS_H
#define CONSTANTS_H

namespace Constants
{
	inline constexpr int maxClassSize{ 35 }; // 如果不支持C++17，请移除 inline 关键字
}
#endif

main.cpp:

#include "constants.h"
#include <iostream>

int main()
{
	std::cout << "How many students are in your class? ";
	int students{};
	std::cin >> students;


	if (students > Constants::maxClassSize)
		std::cout << "There are too many students in this class";
	else
		std::cout << "This class isn't too large";

	return 0;
}

问题 #3

编写一个函数 int accumulate(int x)。该函数应返回所有传递给此函数的 x 值的总和。

显示提示

提示：使用静态局部变量来存储总和。

以下程序应运行并产生注释中注明的输出：

#include <iostream>

int main()
{
    std::cout << accumulate(4) << '\n'; // 打印 4
    std::cout << accumulate(3) << '\n'; // 打印 7
    std::cout << accumulate(2) << '\n'; // 打印 9
    std::cout << accumulate(1) << '\n'; // 打印 10

    return 0;
}

显示答案

#include <iostream>

int accumulate(int x)
{
    static int sum{ 0 }; // 在程序开始时将 sum 初始化为 0
    sum += x;
    return sum;
}

int main()
{
    std::cout << accumulate(4) << '\n'; // 打印 4
    std::cout << accumulate(3) << '\n'; // 打印 7
    std::cout << accumulate(2) << '\n'; // 打印 9
    std::cout << accumulate(1) << '\n'; // 打印 10

    return 0;
}

3b) 额外加分：上述 accumulate() 函数有两个缺点是什么？

显示答案

  1. 没有常规方法在不重新启动程序的情况下重置累加。
  2. 没有常规方法同时运行多个累加器。

进阶读者

这两个缺点都可以通过使用函数对象（21.10 -- 重载括号运算符）而不是静态局部变量来解决。
