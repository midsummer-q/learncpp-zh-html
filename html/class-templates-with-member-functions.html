15.5 — 带成员函数的类模板

● 机器译文 课程 15.5 查看英文原文

在课程 11.6 -- 函数模板我们了解了函数模板：

template <typename T> // 这是模板参数声明
T max(T x, T y) // 这是 max<T> 的函数模板定义
{
    return (x < y) ? y : x;
}

使用函数模板，我们可以定义类型模板参数（例如 typename T），然后将它们用作函数参数的类型（T x, T y)。

在课程 13.13 -- 类模板中，我们介绍了类模板，它允许我们将类型模板参数用于类类型（结构体、类和联合体）的数据成员类型：

#include <iostream>

template <typename T>
struct Pair
{
    T first{};
    T second{};
};

// 这是我们的 Pair 的推导指引（C++17 或更早版本需要）
// 用类型 T 和 T 的参数初始化的 Pair 对象应推导为 Pair<T>
template <typename T>
Pair(T, T) -> Pair<T>;

int main()
{
    Pair<int> p1{ 5, 6 };        // 实例化 Pair<int> 并创建对象 p1
    std::cout << p1.first << ' ' << p1.second << '\n';

    Pair<double> p2{ 1.2, 3.4 }; // 实例化 Pair<double> 并创建对象 p2
    std::cout << p2.first << ' ' << p2.second << '\n';

    Pair<double> p3{ 7.8, 9.0 }; // 使用之前 Pair<double> 的定义创建对象 p3
    std::cout << p3.first << ' ' << p3.second << '\n';

    return 0;
}

相关内容

我们在课程 13.14 -- 类模板参数推导（CTAD）和推导指南。

中讨论了推导指引。在本课中，我们将结合函数模板和类模板的元素，更深入地研究具有成员函数的类模板。

成员函数中的类型模板参数

作为类模板参数声明一部分定义的类型模板参数既可以用作数据成员的类型，也可以用作成员函数参数的类型。

在下面的示例中，我们重写了上面的 Pair 类模板，将其从结构体转换为类：

#include <ios>       // for std::boolalpha
#include <iostream>

template <typename T>
class Pair
{
private:
    T m_first{};
    T m_second{};

public:
    // 当我们在类定义内部定义成员函数时，
    // 属于类的模板参数声明适用
    Pair(const T& first, const T& second)
        : m_first{ first }
        , m_second{ second }
    {
    }

    bool isEqual(const Pair<T>& pair);
};

// 当我们在类定义外部定义成员函数时，
// 我们需要重新提供模板参数声明
template <typename T>
bool Pair<T>::isEqual(const Pair<T>& pair)
{
    return m_first == pair.m_first && m_second == pair.m_second;
}

int main()
{
    Pair p1{ 5, 6 }; // 使用 CTAD 推断类型 Pair<int>
    std::cout << std::boolalpha << "isEqual(5, 6): " << p1.isEqual( Pair{5, 6} ) << '\n';
    std::cout << std::boolalpha << "isEqual(5, 7): " << p1.isEqual( Pair{5, 7} ) << '\n';

    return 0;
}

以上内容应该相当简单，但有一些值得注意的地方。

首先，由于我们的类有私有成员，它不是聚合体，因此不能使用聚合初始化。相反，我们必须使用构造函数来初始化类对象。

由于我们的类数据成员是类型 T，我们将构造函数的参数设为类型 const T&，以便用户可以提供相同类型的初始化值。因为 T 可能复制成本很高，所以通过 const 引用传递比按值传递更安全。

请注意，当我们在类模板定义内部定义成员函数时，不需要为成员函数提供模板参数声明。此类成员函数隐式使用类模板参数声明。

其次，对于非聚合类，我们不需要推导指引即可使 CTAD 工作。匹配的构造函数为编译器提供了从初始化器推导模板参数所需的信息。

第三，让我们更仔细地研究在类模板定义外部定义成员函数的情况：

template <typename T>
bool Pair<T>::isEqual(const Pair<T>& pair)
{
    return m_first == pair.m_first && m_second == pair.m_second;
}

由于此成员函数定义与类模板定义分离，我们需要重新提供模板参数声明（template <typename T>），以便编译器知道 T 是什么。

是什么。此外，当我们在类外部定义成员函数时，需要用类模板的完全模板化名称来限定成员函数名（Pair<T>::isEqual，而不是 Pair::isEqual)。

注入类名

在之前的课程中，我们提到构造函数的名称必须与类的名称匹配。但在上面的 Pair<T> 类模板中，我们将构造函数命名为 Pair，而不是 Pair<T>。尽管名称不匹配，但这仍然有效。

在类的范围内，类的非限定名称称为 注入类名。在类模板中，注入类名作为完全模板化名称的简写。

因为 Pair 是 Pair<T>的注入类名，在我们的 Pair<T> 类模板范围内，任何使用 Pair 的地方都将被视为我们写了 Pair<T> 因此，尽管我们将构造函数命名为 Pair，编译器会将其视为我们写了 Pair<T> 现在名称匹配了！

这意味着我们也可以像这样定义我们的 isEqual() 成员函数：

template <typename T>
bool Pair<T>::isEqual(const Pair& pair) // 注意参数类型为 Pair，而不是 Pair<T>
{
    return m_first == pair.m_first && m_second == pair.m_second;
}

因为这是 Pair<T>的成员函数的定义，所以我们处于 Pair<T> 类模板的作用域内。因此，任何对 Pair 是 Pair<T>！

关键提示

在课程 13.14 -- 类模板参数推导（CTAD）和推导指南的使用，我们注意到 CTAD 不适用于函数参数（因为它是参数推导，而非参数推导）。然而，将注入的类名用作函数参数是可以的，因为它是完全模板化名称的简写，而不是 CTAD 的使用。

在类外部定义类模板的成员函数的位置

对于类模板的成员函数，编译器需要同时看到类定义（以确保成员函数模板被声明为类的一部分）和模板成员函数定义（以了解如何实例化模板）。因此，我们通常希望将类及其成员函数模板定义在同一个位置。

当成员函数模板定义在 在 类定义内部时，模板成员函数定义是类定义的一部分，因此任何能看到类定义的地方也能看到模板成员函数定义。这使事情变得简单（代价是使类定义变得杂乱）。

当成员函数模板定义在 函数 类定义外部时，通常应将其定义在类定义的正下方。这样，任何能看到类定义的地方也能看到紧跟在类定义下方的成员函数模板定义。

在典型情况下，当类定义在头文件中时，这意味着任何在类外部定义的成员函数模板也应定义在同一个头文件中，位于类定义的下方。

关键提示

在课程 11.7 -- 函数模板实例化中，我们注意到从模板隐式实例化的函数是隐式内联的。这包括非成员和成员函数模板。因此，将定义在头文件中的成员函数模板包含到多个代码文件中没有问题，因为从这些模板实例化的函数将是隐式内联的（链接器会去重）。

最佳实践

任何在类定义外部定义的成员函数模板都应定义在类定义的正下方（在同一文件中）。

小测验时间

问题 #1

编写一个名为 Triad 的类模板，该类模板具有 3 个私有数据成员，这些成员具有独立的类型模板参数。该类应具有构造函数、访问函数以及一个在类外部定义的 print() 成员函数。

以下程序应能编译并运行：

#include <iostream>
#include <string>

int main()
{
	Triad<int, int, int> t1{ 1, 2, 3 };
	t1.print();
	std::cout << '\n';
	std::cout << t1.first() << '\n';

	using namespace std::literals::string_literals;
	const Triad t2{ 1, 2.3, "Hello"s };
	t2.print();
	std::cout << '\n';

	return 0;
}

并产生输出：

[1, 2, 3]
1
[1, 2.3, Hello]

显示答案

#include <iostream>
#include <string>

template <typename T, typename U, typename V>
class Triad
{
private:
	T m_first{};
	U m_second{};
	V m_third{};

public:
	Triad(const T& first, const U& second, const V& third)
		: m_first{ first }
		, m_second{ second }
		, m_third{ third }
	{
	}

	const T& first() const { return m_first; }
	const U& second() const { return m_second; }
	const V& third() const { return m_third; }

	void print() const;
};

template <typename T, typename U, typename V>
void Triad<T, U, V>::print() const
{
	std::cout << '[' << m_first << ", " << m_second << ", " << m_third << ']' ;
}

int main()
{
	Triad<int, int, int> t1{ 1, 2, 3 };
	t1.print();
	std::cout << '\n';
	std::cout << t1.first() << '\n';

	using namespace std::literals::string_literals;
	const Triad t2{ 1, 2.3, "Hello"s };
	t2.print();
	std::cout << '\n';

	return 0;
}

问题 #2

如果我们移除 const 来自... print() 函数声明和定义，程序将无法编译。为什么？

显示答案

t2 是一个 const 对象，因此只能对 t2调用 const 成员函数。如果我们将 print() 设为非 const 成员函数，那么 t2 不允许调用它。这是因为非 const 成员函数可能会修改隐式对象，这将违反 const 对象（本例中为t2 ）的常量性。
