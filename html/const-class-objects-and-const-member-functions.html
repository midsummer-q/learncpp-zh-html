14.4 — 常量类对象和常量成员函数

● 机器译文 课程 14.4 查看英文原文

在课程 5.1 -- 常量变量（命名常量）中，你了解到基本数据类型的对象（int， double， char等）可以通过 const 关键字成为常量。所有常量变量必须在创建时初始化。

const int x;      // 编译错误：未初始化
const int y{};    // 正确：值初始化
const int z{ 5 }; // 正确：列表初始化

类似地，类类型对象（结构体、类和联合体）也可以通过 const 关键字成为常量。这样的对象也必须在创建时初始化。

struct Date
{
    int year {};
    int month {};
    int day {};
};

int main()
{
    const Date today { 2020, 10, 14 }; // 常量类类型对象

    return 0;
}

与普通变量一样，当你需要确保类类型对象在创建后不被修改时，通常希望将它们设为常量（或 constexpr）。

禁止修改常量对象的数据成员

一旦常量类类型对象被初始化，任何修改该对象数据成员的尝试都是不允许的，因为这会违反对象的常量性。这包括直接更改成员变量（如果它们是公有的），或者调用设置成员变量值的成员函数。

struct Date
{
    int year {};
    int month {};
    int day {};

    void incrementDay()
    {
        ++day;
    }
};

int main()
{
    const Date today { 2020, 10, 14 }; // 常量

    today.day += 1;        // 编译错误：不能修改常量对象的成员
    today.incrementDay();  // 编译错误：不能调用修改常量对象成员的成员函数

    return 0;
}

常量对象不能调用非常量成员函数

你可能会惊讶地发现，这段代码也会导致编译错误：

#include <iostream>

struct Date
{
    int year {};
    int month {};
    int day {};

    void print()
    {
        std::cout << year << '/' << month << '/' << day;
    }
};

int main()
{
    const Date today { 2020, 10, 14 }; // 常量

    today.print();  // 编译错误：不能调用非常量成员函数

    return 0;
}

尽管 print() 没有尝试修改成员变量，但我们调用 today.print() 仍然违反了常量性。这是因为 print() 成员函数本身没有被声明为常量。编译器不允许我们在常量对象上调用非常量成员函数。

常量成员函数

为了解决上述问题，我们需要将 print() 设为常量成员函数。 常量成员函数 是一个保证不会修改对象或调用任何非常量成员函数（因为它们可能修改对象）的成员函数。

将 print() 设为常量成员函数很简单——我们只需在函数原型中，参数列表之后、函数体之前添加 const 关键字：

#include <iostream>

struct Date
{
    int year {};
    int month {};
    int day {};

    void print() const // 现在是一个常量成员函数
    {
        std::cout << year << '/' << month << '/' << day;
    }
};

int main()
{
    const Date today { 2020, 10, 14 }; // 常量

    today.print();  // 正确：常量对象可以调用常量成员函数

    return 0;
}

在上面的例子中， print() 已被设为常量成员函数，这意味着我们可以在常量对象（如 today)。

进阶读者

对于在类定义外部定义的成员函数， const 关键字必须同时用于类定义中的函数声明和类定义外部的函数定义。我们在课程 15.2 -- 类和头文件。

构造函数不能设为常量，因为它们需要初始化对象的成员，这需要修改它们。我们在课程 14.9 -- 构造函数简介。

一个试图更改数据成员或调用非常量成员函数的常量成员函数会导致编译错误。例如：

struct Date
{
    int year {};
    int month {};
    int day {};

    void incrementDay() const // 设为常量
    {
        ++day; // 编译错误：常量函数不能修改成员
    }
};

int main()
{
    const Date today { 2020, 10, 14 }; // 常量

    today.incrementDay();

    return 0;
}

在这个例子中， incrementDay() 已被标记为常量成员函数，但它试图更改 day。这将导致编译错误。

常量成员函数可以像往常一样修改非成员（如局部变量和函数参数）并调用非成员函数。常量仅适用于成员。

关键提示

常量成员函数不能：修改隐式对象，调用非常量成员函数。
常量成员函数可以：修改不是隐式对象的对象，调用常量成员函数，调用非成员函数。

常量成员函数可以在非常量对象上调用

常量成员函数也可以在非常量对象上调用：

#include <iostream>

struct Date
{
    int year {};
    int month {};
    int day {};

    void print() const // 常量
    {
        std::cout << year << '/' << month << '/' << day;
    }
};

int main()
{
    Date today { 2020, 10, 14 }; // 非常量

    today.print();  // 正确：可以在非常量对象上调用常量成员函数

    return 0;
}

因为常量成员函数可以在常量对象和非常量对象上调用，所以如果成员函数不修改对象的状态，它应该被设为常量。

最佳实践

一个不（且永远不会）修改对象状态的成员函数应该被设为常量，以便它可以在常量对象和非常量对象上调用。

小心将 const 应用于哪些成员函数。一旦成员函数被设为常量，该函数就可以在常量对象上调用。之后移除成员函数上的 const 将破坏任何在常量对象上调用该成员函数的代码。

通过常量引用传递的常量对象

虽然实例化常量局部变量是创建常量对象的一种方式，但更常见的方式是通过常量引用将对象传递给函数。

在课程 12.5 -- 通过左值引用传递我们讨论了通过常量引用而不是按值传递类类型参数的优点。回顾一下，按值传递类类型参数会导致创建类的副本（速度慢）——大多数情况下，我们不需要副本，对原始参数的引用就可以正常工作并避免创建副本。我们通常将引用设为常量，以允许函数接受常量左值参数和右值参数（例如字面量和临时对象）。

你能找出以下代码的问题吗？

#include <iostream>

struct Date
{
    int year {};
    int month {};
    int day {};

    void print() // 非常量
    {
        std::cout << year << '/' << month << '/' << day;
    }
};

void doSomething(const Date& date)
{
    date.print();
}

int main()
{
    Date today { 2020, 10, 14 }; // 非常量
    today.print();

    doSomething(today);

    return 0;
}

答案是，在 doSomething() 函数内部， date 被视为常量对象（因为它通过常量引用传递）。而对于这个常量 date，我们调用了非常量成员函数 print()。由于我们不能在常量对象上调用非常量成员函数，这将导致编译错误。

修复很简单：将 print() 设为常量：

#include <iostream>

struct Date
{
    int year {};
    int month {};
    int day {};

    void print() const // 现在为常量
    {
        std::cout << year << '/' << month << '/' << day;
    }
};

void doSomething(const Date& date)
{
    date.print();
}

int main()
{
    Date today { 2020, 10, 14 }; // 非常量
    today.print();

    doSomething(today);

    return 0;
}

现在在函数 doSomething()， const date 中，将能够成功调用常量成员函数 print()。

成员函数的常量与非常量重载

最后，虽然不常见，但可以重载成员函数，使其具有同一函数的常量版本和非常量版本。这是因为常量限定符被视为函数签名的一部分，因此两个仅在常量性上不同的函数被认为是不同的。

#include <iostream>

struct Something
{
    void print()
    {
        std::cout << "non-const\n";
    }

    void print() const
    {
        std::cout << "const\n";
    }
};

int main()
{
    Something s1{};
    s1.print(); // 调用 print()

    const Something s2{};
    s2.print(); // 调用 print() const
    
    return 0;
}

non-const
const

重载一个函数的常量版本和非常量版本通常是在返回值需要具有不同常量性时进行的。这相当罕见。
