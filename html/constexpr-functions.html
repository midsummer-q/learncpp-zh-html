F.1 — Constexpr 函数

● 机器译文 课程 F.1 查看英文原文

在课程 5.6 -- Constexpr 变量，我们介绍了 constexpr 关键字，用于创建编译时（符号）常量。我们还介绍了常量表达式，即可以在编译时而非运行时求值的表达式。

常量表达式的一个挑战是，对普通函数的调用不允许出现在常量表达式中。这意味着我们不能在需要常量表达式的任何地方使用这样的函数调用。

考虑以下程序：

#include <iostream>

int main()
{
    constexpr double radius { 3.0 };
    constexpr double pi { 3.14159265359 };
    constexpr double circumference { 2.0 * radius * pi };
    
    std::cout << "Our circle has circumference " << circumference << "\n";

    return 0;    
}

这会产生以下结果：

Our circle has circumference 18.8496

为 circumference 设置复杂的初始化器并不理想（并且需要我们实例化两个辅助变量， radius 和 pi）。所以让我们把它变成一个函数：

#include <iostream>

double calcCircumference(double radius)
{
    constexpr double pi { 3.14159265359 };
    return 2.0 * pi * radius;
}

int main()
{
    constexpr double circumference { calcCircumference(3.0) }; // 编译错误
    
    std::cout << "Our circle has circumference " << circumference << "\n";

    return 0;    
}

这段代码更清晰。但它无法编译。Constexpr 变量 circumference 要求其初始化器是常量表达式，而调用 calcCircumference() 不是常量表达式。

在这种特定情况下，我们可以将 circumference 设为非 constexpr，程序就能编译。虽然我们会失去常量表达式的好处，但至少程序能运行。

然而，在 C++ 中还有其他情况（我们将在未来介绍），我们没有其他选择，只有常量表达式才能满足要求。在这些情况下，我们确实希望能够使用函数，但对普通函数的调用就是不行。那么我们该怎么办？

Constexpr 函数可以在常量表达式中使用

一个 constexpr 函数 是允许在常量表达式中调用的函数。

要使函数成为 constexpr 函数，我们只需在函数返回类型前使用 constexpr 关键字。

关键提示

浮点类型的 constexpr 关键字用于向编译器和其他开发者表明该函数可以在常量表达式中使用。

下面是与上面相同的示例，但使用了 constexpr 函数：

#include <iostream>

constexpr double calcCircumference(double radius) // 现在是一个 constexpr 函数
{
    constexpr double pi { 3.14159265359 };
    return 2.0 * pi * radius;
}

int main()
{
    constexpr double circumference { calcCircumference(3.0) }; // 现在可以编译
    
    std::cout << "Our circle has circumference " << circumference << "\n";

    return 0;    
}

因为 calcCircumference() 现在是 constexpr 函数，因此可以在常量表达式中使用，例如作为 circumference。

在课程 5.5 -- 常量表达式，我们注意到，在需要常量表达式的上下文中（例如 constexpr 变量的初始化），常量表达式必须在编译时求值。如果所需的常量表达式包含 constexpr 函数调用，那么该 constexpr 函数调用必须在编译时求值。

在上面的示例中，变量 circumference 是 constexpr，因此需要常量表达式初始化器。由于 calcCircumference() 是这个所需常量表达式的一部分， calcCircumference() 必须在编译时求值。

当函数调用在编译时求值时，编译器会在编译时计算函数调用的返回值，然后用返回值替换函数调用。

因此，在我们的示例中，对 calcCircumference(3.0) 的调用被替换为函数调用的结果，即 18.8496。换句话说，编译器将编译为：

#include <iostream>

constexpr double calcCircumference(double radius)
{
    constexpr double pi { 3.14159265359 };
    return 2.0 * pi * radius;
}

int main()
{
    constexpr double circumference { 18.8496 };
    
    std::cout << "Our circle has circumference " << circumference << "\n";

    return 0;    
}

要在编译时求值，还必须满足另外两个条件：

  • 对 constexpr 函数的调用必须具有在编译时已知的参数（例如，是常量表达式）。
  • constexpr 函数内的所有语句和表达式都必须在编译时可求值。

当 constexpr（或 consteval）函数在编译时求值时，它调用的任何其他函数也必须在编译时求值（否则初始函数无法在编译时返回结果）。

Constexpr 函数也可以在运行时求值

Constexpr 函数也可以在运行时求值，在这种情况下，它们将返回非 constexpr 结果。例如：

#include <iostream>

constexpr int greater(int x, int y)
{
    return (x > y ? x : y);
}

int main()
{
    int x{ 5 }; // 不是 constexpr
    int y{ 6 }; // 不是 constexpr

    std::cout << greater(x, y) << " is greater!\n"; // 将在运行时求值

    return 0;
}

在这个示例中，因为参数 x 和 y 不是常量表达式，所以函数无法在编译时解析。然而，该函数仍会在运行时解析，返回预期的值作为非 constexpr int。

关键提示

当一个 constexpr 函数在运行时求值，它的求值方式与普通（非 constexpr）函数相同。换句话说， constexpr 在这种情况下没有效果。

关键提示

允许具有 constexpr 返回类型的函数在编译时或运行时求值，是为了让单个函数能够同时服务于这两种情况。

否则，你需要两个独立的函数（一个具有 constexpr 返回类型，另一个具有非 constexpr 返回类型）。这不仅需要重复代码，而且这两个函数还需要有不同的名称！
