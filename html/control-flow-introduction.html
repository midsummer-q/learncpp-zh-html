8.1 — 控制流简介

● 机器译文 课程 8.1 查看英文原文

当程序运行时，CPU 从 main()的顶部开始执行，按顺序执行若干语句（默认情况下），然后在 main()的末尾终止程序。CPU 执行的特定语句序列称为程序的 执行路径 （或 路径，简称）。

考虑以下程序：

#include <iostream>

int main()
{
    std::cout << "Enter an integer: ";
    
    int x{};
    std::cin >> x;

    std::cout << "You entered " << x << '\n';

    return 0;
}

该程序的执行路径依次包括第 5、7、8、10 和 12 行。这是一个 直线程序的例子。直线程序每次运行时都走相同的路径（以相同顺序执行相同语句）。

然而，这通常不是我们想要的。例如，如果我们要求用户输入，而用户输入了无效内容，理想情况下我们希望让用户重新选择。这在直线程序中是不可能的。实际上，用户可能反复输入无效内容，因此我们需要让他们重新选择的次数在运行时才能知道。

幸运的是，C++ 提供了许多不同的 控制流语句 （也称为 流程控制语句），这些语句允许程序员改变程序的正常执行路径。你已经见过一个例子：if 语句（在课程 4.10 -- if 语句简介中介绍），它允许我们仅在条件表达式为真时执行一条语句。

当控制流语句导致执行点改变到非顺序语句时，这称为 分支。

类别含义在 C++ 中通过以下实现
条件语句仅当满足某个条件时才执行一段代码序列。if, else, switch
跳转告诉 CPU 开始在其他位置执行语句。goto, break, continue
函数调用跳转到其他位置并返回。函数调用, return
循环重复执行某段代码零次或多次，直到满足某个条件。while, do-while, for, 范围 for
终止终止程序。std::exit(), std::abort()
异常一种特殊的控制流结构，用于错误处理。try, throw, catch

我们将在本章详细涵盖所有这些类别，但异常除外（哈），我们将用一整章（第 27 章)。

在本章之前，你能让程序做的事情数量相当有限。能够控制程序的流程（特别是使用循环）使得无数有趣的事情成为可能！你将不再局限于玩具程序——你将能够编写具有实际用途的程序。
