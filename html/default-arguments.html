11.5 — 默认参数

● 机器译文 课程 11.5 查看英文原文

一个 默认参数 是为函数参数提供的默认值。例如：

void print(int x, int y=10) // 10 是默认参数
{
    std::cout << "x: " << x << '\n';
    std::cout << "y: " << y << '\n';
}

在调用函数时，调用者可以选择为任何具有默认参数的函数参数提供实参。如果调用者提供了实参，则使用函数调用中的实参值。如果调用者未提供实参，则使用默认参数的值。

考虑以下程序：

#include <iostream>

void print(int x, int y=4) // 4 是默认参数
{
    std::cout << "x: " << x << '\n';
    std::cout << "y: " << y << '\n';
}

int main()
{
    print(1, 2); // y 将使用用户提供的参数 2
    print(3); // y 将使用默认参数 4，就像我们调用了 print(3, 4) 一样

    return 0;
}

该程序产生如下输出：

x: 1
y: 2
x: 3
y: 4

在第一个函数调用中，调用者为两个参数都提供了显式实参，因此使用了这些实参值。在第二个函数调用中，调用者省略了第二个实参，因此使用了默认值 4

请注意，必须使用等号来指定默认参数。使用括号或花括号初始化是行不通的：

void foo(int x = 5);   // ok
void goo(int x ( 5 )); // 编译错误
void boo(int x { 5 }); // 编译错误

也许令人惊讶的是，默认参数由编译器在调用点处理。在上面的例子中，当编译器看到 print(3)时，它会将这个函数调用重写为 print(3, 4)，以便实参数量与形参数量匹配。然后重写后的函数调用照常工作。

关键提示

默认参数由编译器在函数调用点插入。

默认参数在 C++ 中经常使用，你会在遇到的代码（以及未来的课程）中经常看到它们。

何时使用默认参数

当函数需要一个具有合理默认值的值，但你又希望允许调用者根据需要覆盖它时，默认参数是一个很好的选择。

例如，以下是几个可能常用默认参数的函数原型：

int rollDie(int sides=6);
void openLogFile(std::string filename="default.log");

作者注

由于用户可以选择提供特定的实参值或使用默认值，因此具有默认值的参数有时被称为 可选参数。然而，术语 可选参数 也用于指代其他几种类型的参数（包括通过地址传递的参数和使用 std::optional的参数），因此我们建议避免使用这个术语。

默认参数在需要向现有函数添加新参数的情况下也很有用。如果我们添加一个没有默认参数的新参数，它将破坏所有现有的函数调用（这些调用没有为该参数提供实参）。这可能导致大量更新现有函数调用（如果你不拥有调用代码，甚至可能无法做到）。然而，如果我们改为添加一个带有默认参数的新参数，所有现有的函数调用仍然可以工作（因为它们将使用该参数的默认值），同时仍然允许新的函数调用在需要时指定显式实参。

多个默认参数

一个函数可以有多个带有默认参数的形参：

#include <iostream>

void print(int x=10, int y=20, int z=30)
{
    std::cout << "Values: " << x << " " << y << " " << z << '\n';
}

int main()
{
    print(1, 2, 3); // 所有显式参数
    print(1, 2); // 最右边的参数使用默认值
    print(1); // 最右边的两个参数使用默认值
    print(); // 所有参数使用默认值

    return 0;
}

产生以下输出：

Values: 1 2 3
Values: 1 2 30
Values: 1 20 30
Values: 10 20 30

C++（截至 C++23）不支持像 print(,,3) 这样的函数调用语法（作为一种为 z 提供显式值，同时为 x 和 y使用默认参数的方式）。这有三个主要后果：

  1. 在函数调用中，任何显式提供的实参必须是最左边的实参（不能跳过具有默认值的实参）。

例如：

void print(std::string_view sv="Hello", double d=10.0);

int main()
{
    print();           // okay：两个参数都使用默认值
    print("Macaroni"); // okay：d 默认为 10.0
    print(20.0);       // error：与上面的函数不匹配（不能跳过 sv 的参数）

    return 0;
}
  1. 如果某个形参被赋予了默认参数，那么所有后续形参（向右）也必须被赋予默认参数。

以下是不允许的：

void print(int x=10, int y); // 不允许

规则

如果某个形参被赋予了默认参数，那么所有后续形参（向右）也必须被赋予默认参数。

  1. 如果多个形参都有默认参数，最左边的形参应该是用户最可能显式设置的那个。

默认参数不能重复声明，并且必须在使用前声明

一旦声明，默认参数不能在同一个翻译单元中重复声明。这意味着对于具有前向声明和函数定义的函数，默认参数可以在前向声明或函数定义中声明，但不能同时声明。

#include <iostream>

void print(int x, int y=4); // // 前向声明

void print(int x, int y=4) // 编译错误：默认参数重定义
{
    std::cout << "x: " << x << '\n';
    std::cout << "y: " << y << '\n';
}

默认参数还必须在翻译单元中使用之前声明：

#include <iostream>

void print(int x, int y); // 前向声明，无默认参数

int main()
{
    print(3); // 编译错误：y 的默认参数尚未定义

    return 0;    
}

void print(int x, int y=4)
{
    std::cout << "x: " << x << '\n';
    std::cout << "y: " << y << '\n';
}

最佳实践是在前向声明中声明默认参数，而不是在函数定义中，因为前向声明更可能被其他文件看到并在使用前包含（特别是如果它在头文件中）。

在 foo.h 中：

#ifndef FOO_H
#define FOO_H
void print(int x, int y=4);
#endif

在 main.cpp 中：

#include "foo.h"
#include <iostream>

void print(int x, int y)
{
    std::cout << "x: " << x << '\n';
    std::cout << "y: " << y << '\n';
}

int main()
{
    print(5);

    return 0;
}

请注意，在上面的例子中，我们能够为函数 print() 使用默认参数，因为 main.cpp #includes foo.h，其中包含定义默认参数的前向声明。

最佳实践

如果函数有前向声明（尤其是在头文件中），则将默认参数放在那里。否则，将默认参数放在函数定义中。

默认参数与函数重载

带有默认参数的函数可以被重载。例如，以下是允许的：

#include <iostream>
#include <string_view>

void print(std::string_view s)
{
    std::cout << s << '\n';
}

void print(char c = ' ')
{
    std::cout << c << '\n';
}

int main()
{
    print("Hello, world"); // 解析为 print(std::string_view)
    print('a');            // 解析为 print(char)
    print();               // 解析为 print(char)

    return 0;
}

函数调用 print() 实际上调用 print(char)，其行为就像用户显式调用了 print(' ')。

现在考虑这种情况：

void print(int x);                  // 签名 print(int)
void print(int x, int y = 10);      // 签名 print(int, int)
void print(int x, double y = 20.5); // 签名 print(int, double)

默认值不是函数签名的一部分，因此这些函数声明是区分开的重载。

默认参数可能导致歧义匹配

默认参数很容易导致歧义的函数调用：

void foo(int x = 0)
{
}

void foo(double d = 0.0)
{
}

int main()
{
    foo(); // 歧义函数调用

    return 0;
}

在这个例子中，编译器无法判断 foo() 应该解析为 foo(0) 或 foo(0.0)。

这是一个稍微复杂的例子：

void print(int x);                  // 签名 print(int)
void print(int x, int y = 10);      // 签名 print(int, int)
void print(int x, double y = 20.5); // 签名 print(int, double) 

int main()
{
    print(1, 2);   // 将解析为 print(int, int)
    print(1, 2.5); // 将解析为 print(int, double) 
    print(1);      // 歧义函数调用

    return 0;
}

对于调用 print(1)，编译器无法判断这是解析为 print(int)， print(int, int)，或 print(int, double)。

如果我们想调用 print(int, int) 或 print(int, double) 我们总是可以显式指定第二个参数。但如果我们想调用 print(int)呢？如何做到这一点并不明显。

默认参数不适用于通过函数指针调用的函数 高级

我们在课程中讨论这个主题 20.1 -- 函数指针。由于使用此方法时不考虑默认参数，这也提供了一种变通方法，可以调用因默认参数而本来会产生歧义的函数。
