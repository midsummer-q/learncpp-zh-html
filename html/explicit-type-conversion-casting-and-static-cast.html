10.6 — 显式类型转换（强制转换）与 static_cast

● 机器译文 课程 10.6 查看英文原文

在课程 10.1 -- 隐式类型转换我们讨论了编译器可以使用隐式类型转换将值从一种数据类型转换为另一种数据类型。当你希望将值从一种数据类型数值提升到更宽的数据类型时，使用隐式类型转换是可以的。

许多 C++ 新手会尝试这样写：

double d = 10 / 4; // 进行整数除法，用值2.0初始化d

因为 10 和 4 都是 int类型，因此执行整数除法，表达式求值为 int 值 2。然后该值经过数值转换为 double 值 2.0 ，再用于初始化变量 d。很可能这不是预期的结果。

在使用字面量操作数的情况下，将一个或两个整数字面量替换为 double 字面量将导致浮点除法：

double d = 10.0 / 4.0; // 进行浮点数除法，用值2.5初始化d

但如果你使用的是变量而不是字面量呢？考虑这种情况：

int x { 10 };
int y { 4 };
double d = x / y; // 进行整数除法，用值2.0初始化d

由于这里使用了整数除法，变量 d 最终将得到值 2.0。我们如何告诉编译器在这种情况下我们想要使用浮点除法而不是整数除法？字面量后缀不能用于变量。我们需要某种方法将一个（或两个）变量操作数转换为浮点类型，以便使用浮点除法。

幸运的是，C++ 提供了许多不同的 类型转换运算符 （通常称为 强制转换），程序员可以使用它们让编译器执行类型转换。由于强制转换是程序员的显式请求，这种形式的类型转换通常称为 显式类型转换 （与隐式类型转换相对，隐式类型转换是编译器自动执行的类型转换）。

类型转换

C++ 支持 5 种不同类型的强制转换： static_cast， dynamic_cast， const_cast， reinterpret_cast和 C 风格强制转换。前四种有时被称为 命名强制转换。

C风格类型转换

在标准C编程中，类型转换通过 operator()完成，将要转换到的类型名称放在括号内，要转换的值紧跟在右括号右侧。在C++中，这种类型的转换称为 C风格类型转换。你可能仍然会在从C转换而来的代码中看到它们。

例如：

#include <iostream>

int main()
{
    int x { 10 };
    int y { 4 };

    std::cout << (double)x / y << '\n'; // C风格将x转换为double

    return 0;
}

在上面的程序中，我们使用C风格转换告诉编译器转换 x 转换为 double。因为左操作数 operator/ 现在求值为浮点值，右操作数也将被转换为浮点值，除法将使用浮点除法而不是整数除法。

C++还提供了C风格转换的另一种形式，称为 函数风格转换，它类似于函数调用：

    std::cout << double(x) / y << '\n'; //  // 函数风格将x转换为double

函数风格转换使得更容易看出正在转换什么（因为它看起来像一个标准函数参数）。

在现代C++中通常避免使用C风格转换有几个重要原因。

首先，尽管C风格转换看起来是一个单一的转换，但它实际上可以根据使用方式执行多种不同的转换。这可能包括静态转换、常量转换或重新解释转换（我们上面提到过你应该避免后两种）。C风格转换没有明确说明实际执行的是哪种转换，这不仅使你的代码更难理解，而且为无意中的误用打开了大门（你认为你在实现一个简单的转换，结果却做了危险的事情）。这通常会导致一个直到运行时才发现的错误。

此外，因为C风格转换只是一个类型名、括号和变量或值，它们既难以识别（使代码更难阅读），也更难搜索。

相比之下，命名转换易于发现和搜索，明确它们的作用，能力有限，并且如果你试图误用它们会产生编译错误。

最佳实践

避免使用C风格转换。

进阶读者

C风格转换尝试按顺序执行以下C++转换：

  • const_cast
  • static_cast
  • static_cast，然后是 const_cast

有一件事你可以用C风格转换做而C++转换不能：C风格转换可以将派生对象转换为不可访问的基类（例如，因为它是私有继承的）。

static_cast 应用于转换大多数值

C++中最常用的转换是 静态转换 运算符，通过 static_cast 关键字。 static_cast 用于当我们想要显式地将一个类型的值转换为另一个类型的值时。

你之前见过 static_cast 用于将 char 转换为 int 以便 std::cout 将其打印为整数而不是字符：

#include <iostream>

int main()
{
    char c { 'a' };
    std::cout << static_cast<int>(c) << '\n'; // 打印97而不是a

    return 0;
}

要执行静态转换，我们从 static_cast 关键字开始，然后将要转换到的类型放在尖括号内。然后在括号内，放置其值将被转换的表达式。注意语法看起来多么像对名为 static_cast<type>() 的函数调用，其值将被转换的表达式作为参数提供！将值静态转换为另一种类型的值会返回一个临时对象，该对象已用转换后的值直接初始化。

下面是我们如何使用 static_cast 来解决我们在本课引言中介绍的问题：

#include <iostream>

int main()
{
    int x { 10 };
    int y { 4 };

    // 将x静态转换为double，以便进行浮点数除法
    std::cout << static_cast<double>(x) / y << '\n'; // 打印2.5

    return 0;
}

static_cast<double>(x) 返回一个临时的 double 对象，包含转换后的值 10.0。这个临时对象然后被用作浮点除法的左操作数。

有两个重要的属性 static_cast。

首先， static_cast 提供编译时类型检查。如果我们尝试将一个值转换为一个类型，而编译器不知道如何执行该转换，我们将得到一个编译错误。

    // C风格字符串字面量不能转换为int，因此以下转换无效
    int x { static_cast<int>("Hello") }; // 无效：会产生编译错误

其次， static_cast （有意地）不如C风格转换强大，因为它会阻止某些危险的转换（例如那些需要重新解释或丢弃const的转换）。

最佳实践

推荐使用 static_cast 当你需要将一个值从一种类型转换为另一种类型时。

    return 0;

有一些简单的方法可以解决这个问题，最简单的是使用单字类型别名：

#include <iostream>

int main()
{
    unsigned char c { 'a' };
    using uint = unsigned int;
    std::cout << uint { c } << '\n';

    return 0;
}
