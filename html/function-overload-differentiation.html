11.2 — 函数重载的区分

● 机器译文 课程 11.2 查看英文原文

在上一课（11.1 -- 函数重载介绍我们引入了函数重载的概念，它允许我们创建多个同名函数，只要每个同名函数具有不同的参数类型（或者函数可以通过其他方式区分）。

在本课中，我们将更深入地了解重载函数是如何区分的。未正确区分的重载函数会导致编译器发出编译错误。

重载函数如何区分

函数属性用于区分备注
参数数量是
参数类型是排除 typedef、类型别名和值参数上的 const 限定符。包括省略号。
返回类型否

注意，函数的返回类型不用于区分重载函数。我们稍后会详细讨论这一点。

进阶读者

对于成员函数，还会考虑额外的函数级限定符：

函数级限定符用于重载
const 或 volatile是
引用限定符是

例如，const 成员函数可以与另一个相同的非 const 成员函数区分开来（即使它们共享相同的参数集）。

相关内容

基于参数数量的重载

只要每个重载函数具有不同数量的参数，重载函数就可以区分。例如：

int add(int x, int y)
{
    return x + y;
}

int add(int x, int y, int z)
{
    return x + y + z;
}

编译器可以轻松判断，带有两个整数参数的函数调用应转到 add(int, int) 而带有三个整数参数的函数调用应转到 add(int, int, int)。

基于参数类型的重载

只要每个重载函数的参数类型列表不同，函数也可以区分。例如，以下所有重载都是可区分的：

int add(int x, int y); // 整数版本
double add(double x, double y); // 浮点数版本
double add(int x, double y); // 混合版本
double add(double x, int y); // 混合版本

由于类型别名（或 typedef）不是不同的类型，使用类型别名的重载函数与使用被别名类型的重载函数无法区分。例如，以下所有重载都是不可区分的（并且会导致编译错误）：

typedef int Height; // typedef
using Age = int; // 类型别名

void print(int value);
void print(Age value); // 与print(int)无法区分
void print(Height value); // 与print(int)无法区分

对于按值传递的参数，const 限定符也不被考虑。因此，以下函数不被视为可区分：

void print(int);
void print(const int); // 与print(int)无法区分

进阶读者

我们还没有介绍省略号，但省略号参数被视为一种独特的参数类型：

void foo(int x, int y);
void foo(int x, ...); // 与foo(int, int)区分

因此，对 foo(4, 5) 的调用将匹配到 foo(int, int)，而不是 foo(int, ...)。

函数的返回类型不用于区分

函数的返回类型在区分重载函数时不被考虑。

考虑这样一种情况：你想编写一个返回随机数的函数，但需要一个返回 int 的版本和另一个返回 double 的版本。你可能会尝试这样做：

int getRandomValue();
double getRandomValue();

在 Visual Studio 2019 上，这会导致以下编译器错误：

error C2556: 'double getRandomValue(void)': overloaded function differs only by return type from 'int getRandomValue(void)'

这很合理。如果你是编译器，看到这个语句：

getRandomValue();

你会调用两个重载函数中的哪一个？这并不清楚。

顺便说一句……

这是一个有意为之的选择，因为它确保函数调用的行为可以独立于表达式的其余部分确定，从而使理解复杂表达式变得更加简单。换句话说，我们总是可以根据函数调用中的参数来确定将调用哪个版本的函数。如果使用返回值进行区分，那么我们将没有简单的语法方式来区分正在调用哪个重载函数——我们还需要理解返回值是如何使用的，这需要更多的分析。

解决这个问题的最佳方法是给函数起不同的名字：

int getRandomInt();
double getRandomDouble();

类型签名

函数的 类型签名 （通常称为 签名）定义为函数头中用于区分函数的部分。在C++中，这包括函数名、参数数量、参数类型和函数级限定符。它特别不 不是 包括返回类型。

名字修饰

顺便说一句……

当编译器编译函数时，它会执行 名字修饰，这意味着函数的编译名称会根据各种标准（如参数的数量和类型）被改变（“修饰”），以便链接器有唯一的名称可以使用。

例如，一个原型为 int fcn() 的函数可能会被编译成修饰后的名称 __fcn_v，而 int fcn(int) 的函数可能会被编译成修饰后的名称 __fcn_i。因此，虽然在源代码中两个重载函数共享名称 fcn()，但在编译后的代码中，修饰后的名称是唯一的（__fcn_v vs __fcn_i)。

对于名字如何修饰没有标准化，因此不同的编译器会产生不同的修饰名称。
