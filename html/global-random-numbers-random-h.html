8.15 — 全局随机数（Random.h）

● 机器译文 课程 8.15 查看英文原文

如果我们想在多个函数或文件中使用随机数生成器，会发生什么？一种方法是在我们的 main() 函数中创建（并播种）我们的PRNG，然后将其传递到任何需要的地方。但对于我们可能只是偶尔使用，并且在许多不同地方使用的东西来说，传递它需要大量的工作。传递这样一个对象会给我们的代码增加很多杂乱。

或者，你可以在每个需要它的函数中创建一个静态局部 std::mt19937 变量（静态的，这样它只会被播种一次）。然而，让每个使用随机数生成器的函数都定义并播种自己的局部生成器是过度的，而且每个生成器的调用量较低可能导致结果质量较低。

我们真正想要的是一个单一的PRNG对象，我们可以共享并在任何地方访问，跨越所有函数和文件。这里的最佳选择是创建一个全局随机数生成器对象（在命名空间内！）。还记得我们告诉你要避免非常量全局变量吗？这是一个例外。

这是一个简单的、仅头文件的解决方案，你可以将其 #include 到任何需要访问随机化、自播种的 std::mt19937：

Random.h：

#ifndef RANDOM_MT_H
#define RANDOM_MT_H

#include <chrono>
#include <random>

// // 这个仅头文件的 Random 命名空间实现了一个自播种的 Mersenne Twister。
// // 需要 C++17 或更新版本。
// // 它可以被 #include 到任意数量的代码文件中（inline 关键字避免了 ODR 违规）
// // 可自由再分发，由 learncpp.com 提供 (https://www.learncpp.com/cpp-tutorial/global-random-numbers-random-h/)
namespace Random
{
	// // 返回一个已播种的 Mersenne Twister
	// // 注意：我们更希望返回一个 std::seed_seq（用于初始化 std::mt19937），但 std::seed 不能被复制，因此不能按值返回。
	// 相反，我们将创建一个 std::mt19937，为其播种，然后返回该 std::mt19937（可以复制）。
	inline std::mt19937 generate()
	{
		std::random_device rd{};

		// 使用时钟和来自 std::random_device 的 7 个随机数创建 seed_seq
		std::seed_seq ss{
			static_cast<std::seed_seq::result_type>(std::chrono::steady_clock::now().time_since_epoch().count()),
				rd(), rd(), rd(), rd(), rd(), rd(), rd() };

		return std::mt19937{ ss };
	}

	// 这是我们的全局 std::mt19937 对象。
	// inline 关键字意味着整个程序只有一个全局实例。
	inline std::mt19937 mt{ generate() }; // 生成一个已播种的 std::mt19937 并将其复制到我们的全局对象中

	// 生成一个介于 [min, max] 之间的随机整数（包含边界）
        // * 也处理两个参数类型不同但可以转换为 int 的情况
	inline int get(int min, int max)
	{
		return std::uniform_int_distribution{min, max}(mt);
	}

	// 以下函数模板可用于在其他情况下生成随机数

	// 参见 https://www.learncpp.com/cpp-tutorial/function-template-instantiation/
	// 如果你不理解它们，可以忽略

	// 生成一个介于 [min, max] 之间的随机值（包含边界）
	// * min 和 max 必须具有相同的类型
	// * 返回值的类型与 min 和 max 相同
	// * 支持的类型：
	// *    short, int, long, long long
	// *    unsigned short, unsigned int, unsigned long, 或 unsigned long long
	// 示例调用：Random::get(1L, 6L);             // 返回 long
	// 示例调用：Random::get(1u, 6u);             // 返回 unsigned int
	template <typename T>
	T get(T min, T max)
	{
		return std::uniform_int_distribution<T>{min, max}(mt);
	}

	// 生成一个介于 [min, max] 之间的随机值（包含边界）
	// * min 和 max 可以有不同的类型
        // * 返回类型必须显式指定为模板参数
	// * min 和 max 将被转换为返回类型
	// 示例调用：Random::get<std::size_t>(0, 6);  // 返回 std::size_t
	// 示例调用：Random::get<std::size_t>(0, 6u); // 返回 std::size_t
	// 示例调用：Random::get<std::int>(0, 6u);    // 返回 int
	template <typename R, typename S, typename T>
	R get(S min, T max)
	{
		return get<R>(static_cast<R>(min), static_cast<R>(max));
	}
}

#endif

使用 Random.h

使用上述方法生成随机数只需遵循以下三个步骤：

  1. 将上述代码复制粘贴到一个名为 Random.h 的文件中，保存在你的项目目录中。可选地将 Random.h 添加到你的项目中。
  2. #include "Random.h" 从项目中任何需要生成随机数的 .cpp 文件中 #include
  3. 调用 Random::get(min, max) 来生成一个介于 min 和 max （包含）之间的随机数。无需初始化或设置。

这是一个示例程序，演示了 Random.h 的不同用法：

main.cpp:

#include "Random.h" // defines Random::mt, Random::get(), and Random::generate()
#include <cstddef> // for std::size_t
#include <iostream>

int main()
{
	// 我们可以调用 Random::get() 来生成随机整数值
	// 如果两个参数类型相同，返回值的类型也将相同。
	std::cout << Random::get(1, 6) << '\n';   // 返回 1 到 6 之间的 int
	std::cout << Random::get(1u, 6u) << '\n'; // 返回 1 到 6 之间的 unsigned int

        // 当两个参数类型不同时
        // 和/或我们希望返回类型与参数类型不同时
        // 我们必须使用模板类型参数（在尖括号之间）指定返回类型
	// 参见 https://www.learncpp.com/cpp-tutorial/function-template-instantiation/
	std::cout << Random::get<std::size_t>(1, 6u) << '\n'; // 返回 1 到 6 之间的 std::size_t

	// 如果我们有自己的分布，可以直接访问 Random::mt

	// 让我们创建一个可重用的随机数生成器，生成 1 到 6 之间的均匀数
	std::uniform_int_distribution die6{ 1, 6 }; // 对于C++14，使用 std::uniform_int_distribution<> die6{ 1, 6 };
	for (int count{ 1 }; count <= 10; ++count)
	{
		std::cout << die6(Random::mt) << '\t'; // 在这里生成一次掷骰子
	}

	std::cout << '\n';

	return 0;
}

关于 Random.h 实现的一些说明 可选

通常，在头文件中定义变量和函数会导致违反单一定义规则（ODR），当该头文件被包含到多个源文件中时。然而，我们已经将我们的 mt 变量和支持函数设为 inline内联，这允许我们有重复的定义而不违反ODR，只要这些定义完全相同。因为我们是从头文件中 #include 这些定义（而不是手动输入或复制粘贴），我们可以确保它们相同。内联函数和变量被添加到语言中，很大程度上是为了使这种仅头文件的功能成为可能。
