8.2 — If 语句和块

● 机器译文 课程 8.2 查看英文原文

我们要讨论的第一类控制流语句是条件语句。一个 条件语句 是一个指定某些关联语句是否应该被执行的语句。

C++ 支持两种基本的条件语句： if statements （我们在第 4.10 -- if 语句简介课中介绍过，这里将进一步讨论）和 switch statements （我们将在几节课后介绍）。

快速 if 语句回顾

C++ 中最基本的条件语句是 if statement一个 if statement 的形式为：

if (condition)
    true_statement;

或者带有一个可选的 else statement：

if (condition)
    true_statement;
else
    false_statement;

如果 condition 求值为 true， true_statement 执行。如果 condition 求值为 false 和可选的 else statement 存在，则 false_statement 执行。

这是一个使用 if statement 和可选 else statement：

#include <iostream>

int main()
{
    std::cout << "Enter a number: ";
    int x{};
    std::cin >> x;

    if (x > 10)
        std::cout << x << " is greater than 10\n";
    else
        std::cout << x << " is not greater than 10\n";

    return 0;
}

的简单程序： 这个程序的工作方式正如你所期望的那样：

Enter a number: 15
15 is greater than 10

Enter a number: 4
4 is not greater than 10

if 或 else 中的多条条件语句

新手程序员经常尝试这样写：

#include <iostream>

namespace constants
{
    constexpr int minRideHeightCM { 140 };
}

int main()
{
    std::cout << "Enter your height (in cm): ";
    int x{};
    std::cin >> x;

    if (x >= constants::minRideHeightCM)
        std::cout << "You are tall enough to ride.\n";
    else
        std::cout << "You are not tall enough to ride.\n";
        std::cout << "Too bad!\n"; // 关注这一行

    return 0;
}

然而，考虑以下程序运行情况：

Enter your height (in cm): 180
You are tall enough to ride.
Too bad!

这个程序没有按预期工作，因为 true_statement 和 false_statement 只能是一条语句。这里的缩进欺骗了我们——上面的程序实际上执行时等同于以下写法：

#include <iostream>

namespace constants
{
    constexpr int minRideHeightCM { 140 };
}

int main()
{
    std::cout << "Enter your height (in cm): ";
    int x{};
    std::cin >> x;

    if (x >= constants::minRideHeightCM)
        std::cout << "You are tall enough to ride.\n";
    else
        std::cout << "You are not tall enough to ride.\n";

    std::cout << "Too bad!\n"; // 关注这一行

    return 0;
}

这更清楚地表明“Too bad!”总是会执行。

然而，通常我们希望根据某个条件执行多条语句。为此，我们可以使用复合语句（块）：

#include <iostream>

namespace constants
{
    constexpr int minRideHeightCM { 140 };
}

int main()
{
    std::cout << "Enter your height (in cm): ";
    int x{};
    std::cin >> x;

    if (x >= constants::minRideHeightCM)
        std::cout << "You are tall enough to ride.\n";
    else
    { // 注意这里添加了块
        std::cout << "You are not tall enough to ride.\n";
        std::cout << "Too bad!\n";
    }

    return 0;
}

记住，块被视为一条语句，所以现在可以按预期工作：

Enter your height (in cm): 180
You are tall enough to ride.

Enter your height (in cm): 130
You are not tall enough to ride.
Too bad!

隐式块

如果程序员没有在 if statement 或 else statement的语句部分声明一个块，编译器会隐式地声明一个。因此：

if (condition)
    true_statement;
else
    false_statement;

实际上等同于：

if (condition)
{
    true_statement;
}
else
{
    false_statement;
}

大多数情况下，这无关紧要。然而，新手程序员有时会尝试在隐式块中定义变量，像这样：

#include <iostream>

int main()
{
    if (true)
        int x{ 5 };
    else
        int x{ 6 };

    std::cout << x << '\n';

    return 0;
}

这不会编译，编译器会生成一个错误，指出标识符 x 未定义。这是因为上面的例子等同于：

#include <iostream>

int main()
{
    if (true)
    {
        int x{ 5 };
    } // x 在这里销毁
    else
    {
        int x{ 6 };
    } // x 在这里销毁

    std::cout << x << '\n'; // x 在这里不在作用域内

    return 0;
}

在这种情况下，更清楚的是变量 x 具有块作用域，并在块结束时被销毁。当我们到达 std::cout 行时， x 已经不存在了。

单条语句是否应该使用块

程序员社区中存在争议：跟在 if 或 else 后面的单条语句是否应该显式地用块括起来。

使用块的理由有很多。

  1. 不使用块更容易无意中添加看似有条件但实际上没有的语句。考虑：
if (age >= minDrinkingAge)
    purchaseBeer();

现在假设我们很匆忙，修改这个程序以添加另一个能力：

if (age >= minDrinkingAge)
    purchaseBeer();
    gamble(); // 总是执行

哎呀，我们刚刚允许未成年人赌博了。去监狱里玩吧！

  1. 不使用块会使程序更难调试。假设我们有以下代码片段：
if (age >= minDrinkingAge)
    addBeerToCart(); // 有条件地执行

checkout(); // 总是执行

假设我们怀疑 addBeerToCart() 函数有问题，于是将其注释掉：

if (age >= minDrinkingAge)
//    addBeerToCart();

checkout(); // 现在有条件地执行

现在我们让 checkout() 变成了有条件的，这显然不是我们的本意。

如果你总是在 if 或 else。

  1. if constexpr （C++23 中新增的 if 语句变体）要求使用块。因此使用块可以确保 if 和 if constexpr。

反对在单条语句周围使用块的最佳理由是，添加块会使代码垂直间距变大，从而让你一次能看到的代码变少，这会降低代码的可读性，并可能导致其他更严重的错误。

社区似乎更倾向于总是使用块，尽管这个建议并非普遍适用。

最佳实践

考虑将关联的单个语句放在 if 或 else 的块中（尤其是在学习阶段）。更有经验的 C++ 开发者有时会忽略这种做法，而倾向于更紧凑的垂直间距。

一个合理的折中方案是将单行语句放在与 if 或 else：

if (age >= minDrinkingAge) purchaseBeer();
else std::cout << "No drinky for you\n".

这避免了上述两个缺点，但会稍微牺牲可读性。

对单行方法的一个合理批评是，它产生的代码更难调试：

  • 因为条件和关联语句作为同一个步骤执行，所以更难判断语句是否实际执行了还是被跳过了。
  • 因为条件和关联语句在同一行，所以无法仅对关联语句设置断点（仅在语句实际执行时停止执行）。

然而，如果上述任何一点在调试时造成阻碍，你可以在条件和语句之间插入换行（使它们位于不同行），进行调试，然后再移除换行。

if-else 与 if-if

新手程序员有时会疑惑何时应该使用 if-else（if 后跟一个或多个 else 语句）或 if-if（if 后跟一个或多个额外的 if 语句）。

  • 当你只想执行第一个 true 条件后的代码时，使用 if-else。
  • 当你想要执行所有 true 条件后的代码时，使用 if-if。

下面是一个演示此概念的程序：

#include <iostream>

void ifelse(bool a, bool b, bool c)
{
    if (a)      // 总是求值
        std::cout << "a";
    else if (b) // 仅当前面的 if 语句条件为假时求值
        std::cout << "b";
    else if (c) // 仅当前面的 if 语句条件为假时求值
        std::cout << "c";
    std::cout << '\n';
}

void ifif(bool a, bool b, bool c)
{
    if (a) // 总是求值
        std::cout << "a";
    if (b) // 总是求值
        std::cout << "b";
    if (c) // 总是求值
        std::cout << "c";
    std::cout << '\n';
}

int main()
{
    ifelse(false, true, true);
    ifif(false, true, true);

    return 0;
}

在调用 ifelse(false, true, true)， a 等于 false时，我们不执行关联的语句，而是执行关联的 else b 为真，所以我们打印 b。由于这个 if 条件为真，关联的 else 不会执行（紧随其后的任何其他 else 语句也不会执行）。注意，我们只执行了第一个 true 条件（b)。

在调用 ifif(false, true, true)， a 为假，所以我们不执行关联的语句，并移动到下一个 if。 b 为真，所以我们打印 b 并移动到下一个 if。 c 为真，所以我们打印 c。注意，我们执行了所有 true 条件（b 和 c)。

现在看看这个有点类似的函数：

char getFirstMatchingChar(bool a, bool b, bool c)
{
    if (a) // 总是求值
        return 'a';
    else if (b) // 仅当前面的 if 语句条件为假时求值
        return 'b';
    else if (c) // 仅当前面的 if 语句条件为假时求值
        return 'c';

    return 0;
}

由于我们使用了 if-else，很明显我们只想执行第一个条件之后的代码。 true 但是当每个关联的语句都返回一个值时，我们可以这样写：

char getFirstMatchingChar(bool a, bool b, bool c)
{
    if (a) // 总是求值
        return 'a'; // 当 if 语句为真时返回
    if (b) // 仅当前面的 if 语句条件为假时求值
        return 'b'; // 当 if 语句为真时返回
    if (c) // 仅当前面的 if 语句条件为假时求值
        return 'c'; // 当 if 语句为真时返回

    return 0;
}

虽然这表面上看起来我们想执行每个条件之后的代码， true 但一旦我们找到第一个条件， true 关联的语句就会导致函数返回。剩下的 if 语句永远没有机会求值。因此，这与之前的版本行为等价。当每个关联的语句都返回一个值时，许多程序员更喜欢省略 else 关键字，因为这样可以避免不必要的杂乱，并且条件对齐得更好。 else 当所有关联的语句都返回一个值时，你总是可以只使用 if-if，因为 else 没有提供任何价值。

关键提示

当所有关联的语句都返回一个值时，你总是可以只使用 if-if，因为 else 没有提供任何价值。
