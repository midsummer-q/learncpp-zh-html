10.1 — 隐式类型转换

● 机器译文 课程 10.1 查看英文原文

我们在课程 4.12 -- 类型转换与static_cast简介中介绍了类型转换。回顾该课程中最重要的几点：

  • 将数据从一种类型转换为另一种类型的过程称为“类型转换”。
  • 当需要一种数据类型但提供了另一种数据类型时，编译器会自动执行隐式类型转换。
  • 显式类型转换通过使用强制转换运算符（例如 static_cast。
  • 转换不会改变被转换的数据。相反，转换过程使用该数据作为输入，并产生转换后的结果。
  • 将值转换为另一种类型的值时，转换过程会生成一个目标类型的临时对象，该对象保存转换的结果。

在本章的前半部分，我们将更深入地探讨类型转换的工作原理。我们将从本课的隐式转换开始，然后在接下来的课程 10.6 -- 显式类型转换（强制转换）和 static_cast中介绍显式类型转换（强制转换）。由于类型转换无处不在，了解转换发生时底层发生了什么非常重要。这些知识对于理解重载函数（可以与其他函数同名的函数）的工作原理也很重要。

作者注

在本章中，我们将重点讨论值到其他类型值的转换。一旦我们介绍了先决主题（如指针、引用、继承等），我们将介绍其他类型的转换。

为什么需要转换

对象的值存储为一系列位，对象的数据类型告诉编译器如何将这些位解释为有意义的值。不同的数据类型可能以不同的方式表示“相同”的值。例如，整数值 3 可能存储为二进制 0000 0000 0000 0000 0000 0000 0000 0011，而浮点值 3.0 可能存储为二进制 0100 0000 0100 0000 0000 0000 0000 0000。

那么当我们做这样的事情时会发生什么？

float f{ 3 }; // 用 int 3 初始化浮点变量

在这种情况下，编译器不能简单地将用于表示 int 值 3 的位复制到分配给 float 变量 f的内存中。如果这样做，那么当 f （类型为 float）被求值时，这些位将被解释为 float 而不是 int，谁知道我们会得到什么 float 值！

顺便说一句……

以下程序实际上将 int 值 3 打印为 float：

#include <iostream>
#include <cstring>

int main()
{
    int n { 3 };                        // 这里是 int 值 3
    float f {};                         // 这里是我们的浮点变量
    std::memcpy(&f, &n, sizeof(float)); // 将 n 的位复制到 f 中
    std::cout << f << '\n';             // 打印 f（包含来自 n 的位）

    return 0;
}

这会产生以下结果：

4.2039e-45

相反，整数值 3 需要转换为等效的浮点值 3.0，然后可以将其存储在分配给 f 的内存中（使用 float 值 3.0) 。

隐式类型转换 （也称为 自动类型转换 或 强制转换）由编译器在某种类型的表达式被提供在需要其他类型的上下文中时自动执行。C++中的绝大多数类型转换都是隐式类型转换。例如，隐式类型转换发生在以下所有情况中：

当使用不同数据类型的值初始化（或赋值给）变量时：

double d{ 3 }; // int 值 3 隐式转换为 double 类型
d = 6; // int 值 6 隐式转换为 double 类型

当返回值的类型与函数声明的返回类型不同时：

float doSomething()
{
    return 3.0; // double 值 3.0 隐式转换为 float 类型
}

当使用某些二元运算符且操作数类型不同时：

double division{ 4.0 / 3 }; // int 值 3 隐式转换为 double 类型

当在if语句中使用非布尔值时：

if (5) // int 值 5 隐式转换为 bool 类型
{
}

当传递给函数的参数类型与函数参数类型不同时：

void doSomething(long l)
{
}

doSomething(3); // int 值 3 隐式转换为 long 类型

那么编译器究竟是如何知道如何将值转换为另一种类型的呢？

标准转换

作为核心语言的一部分，C++ 标准定义了一组转换规则，称为“标准转换”。 标准转换 规定了各种基本类型（以及某些复合类型，包括数组、引用、指针和枚举）如何在同一组内转换为其他类型。

截至 C++23，共有 14 种不同的标准转换。它们大致可以分为 5 个通用类别：

类型转换可能失败

当调用类型转换时（无论是隐式还是显式），编译器将确定是否可以将值从当前类型转换为所需类型。如果找到有效的转换，编译器将生成所需类型的新值。

如果编译器找不到可接受的转换，则编译将失败并出现编译错误。类型转换可能因多种原因失败。例如，编译器可能不知道如何在原始类型和所需类型之间转换值。

例如：

int main()
{
    int x { "14" };

    return 0;
}

因为从字符串字面量 "14" 到 int没有标准转换，编译器将产生错误。例如，GCC 产生错误： prog.cc:3:13: error: invalid conversion from 'const char*' to 'int' [-fpermissive]。

在其他情况下，特定功能可能禁止某些类别的转换。例如：

int x { 3.5 }; // 花括号初始化禁止导致数据丢失的转换

即使编译器知道如何将 double 值转换为 int 值，但在使用花括号初始化时禁止窄化转换。

还有一些情况，编译器可能无法确定几个可能的类型转换中哪一个是最佳选择。我们将在课程 11.3 -- 函数重载解析与歧义匹配。
