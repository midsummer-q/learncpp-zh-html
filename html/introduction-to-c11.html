B.1 — C++11 简介

什么是 C++11？

2011 年 8 月 12 日， ISO（国际标准化组织） 批准了一个新版本的 C++，称为 C++11。C++11 为 C++ 语言添加了一整套新特性！这些新特性的使用完全是可选的——但你无疑会发现其中一些很有用。之前的教程都已更新为符合 C++11 标准。

C++11 的目标和设计

Bjarne Stroustrup 将 C++11 的目标描述如下：

  • 建立在 C++ 的优势之上——而不是试图将 C++ 扩展到可能较弱的领域（例如，具有繁重 GUI 的 Windows 应用程序），专注于让它做得更好的事情做得更好。
  • 使 C++ 更易于学习、使用和教学——提供使语言更一致且更易于使用的功能。

为此，负责制定该语言的委员会试图遵循以下一般原则：

  • 尽可能保持与旧版本 C++ 和 C 的稳定性和兼容性。在 C++03 下工作的程序通常仍应在 C++11 下工作。
  • 将核心语言扩展的数量保持在最低限度，并将大部分更改放在标准库中（这个目标在此版本中并未很好地实现）
  • 专注于改进抽象机制（类、模板），而不是添加处理特定狭窄情况的机制。
  • 为新手和专家添加新功能。每个人都能得到一点东西！
  • 提高类型安全性，以防止无意的错误。
  • 提高性能并允许 C++ 直接与硬件一起工作。
  • 考虑可用性和生态系统问题。C++ 需要与其他工具良好配合，易于使用和教学等……

C++11 在主题上与 C++03 没有太大区别，但它确实添加了大量新功能。

C++11 的主要新特性

为了你的兴趣，这里列出了 C++11 添加的主要特性。请注意，此列表并不全面，而是旨在突出一些关键特性。

  • auto（10.8 -- 使用 auto 关键字进行对象的类型推导)
  • char16_t 和 char32_t 以及支持它们的新字面量（尚无教程）
  • constexpr（5.1 -- 常量变量（命名常量）)
  • decltype（在 16.7 -- 数组、循环和符号挑战解决方案)
  • default 说明符（14.11 -- 默认构造函数和默认参数)
  • 委托构造函数（14.12 -- 委托构造函数)
  • delete 说明符（11.4 -- 删除函数)
  • 枚举类（13.6 -- 作用域枚举（enum class）)
  • 外部模板（尚无教程）
  • Lambda 表达式（20.6 -- lambda（匿名函数）简介）和捕获（20.7 -- Lambda 捕获)
  • long long int（4.3 -- 对象大小和sizeof运算符)
  • 移动构造函数和赋值（22.3 -- 移动构造函数和移动赋值)
  • Noexcept 说明符（在 27.4 -- 未捕获的异常和捕获所有处理程序)
  • nullptr（12.8 -- 空指针)
  • override 和 final 说明符（25.3 -- override 和 final 说明符，以及协变返回类型)
  • 基于范围的 for 语句（16.8 -- 基于范围的 for 循环（for-each）)
  • 右值引用（22.2 -- 右值引用)
  • static_assert（9.6 -- Assert 和 static_assert)
  • std::initializer_list（23.7 -- std::initializer_list)
  • 尾随返回类型语法（10.8 -- 使用 auto 关键字进行对象的类型推导)
  • 类型别名（10.7课——Typedefs和类型别名)
  • typedef 现在可以对模板类进行 typedef
  • 统一初始化（4.1 -- 基本数据类型简介)
  • 用户自定义字面量（暂无教程）
  • 可变参数模板（暂无教程）
  • 两个 >> 符号之间没有空格现在会被正确解释为关闭模板对象

C++ 标准库中还有许多新类可供使用。

  • 更好地支持多线程和线程局部存储（暂无教程）
  • 哈希表（暂无教程）
  • 随机数生成改进（基础讨论在 8.14 -- 使用梅森旋转算法生成随机数)
  • 引用包装器（25.9 -- 对象切片)
  • 正则表达式（暂无教程）
  • std::auto_ptr 已被弃用（22.1 -- 智能指针和移动语义简介)
  • std::tuple（暂无教程）
  • std::unique_ptr（22.5 -- std::unique_ptr)
