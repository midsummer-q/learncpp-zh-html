14.9 — 构造函数简介

● 机器译文 课程 14.9 查看英文原文

当类类型是聚合体时，我们可以使用聚合初始化来直接初始化类类型：

struct Foo // Foo 是一个聚合体
{
    int x {};
    int y {};
};

int main()
{
    Foo foo { 6, 7 }; // 使用聚合初始化

    return 0;
}

聚合初始化按成员初始化（成员按照定义顺序初始化）。所以当 foo 在上面的例子中被实例化时， foo.x 被初始化为 6、和 foo.y 被初始化为 7。

相关内容

我们在课程中讨论了聚合体的定义和聚合初始化 13.8 -- 结构体聚合初始化。

然而，一旦我们将任何成员变量设为私有（以隐藏数据），我们的类类型就不再是聚合体（因为聚合体不能有私有成员）。这意味着我们不能再使用聚合初始化：

class Foo // Foo 不是聚合体（有私有成员）
{
    int m_x {};
    int m_y {};
};

int main()
{
    Foo foo { 6, 7 }; // 编译错误：不能使用聚合初始化

    return 0;
}

不允许具有私有成员的类类型通过聚合初始化进行初始化，这有几个原因：

  • 聚合初始化需要了解类的实现（因为必须知道成员是什么以及它们的定义顺序），而当我们隐藏数据成员时，我们有意避免这种情况。
  • 如果我们的类有某种不变性，我们将依赖用户以保持不变性的方式初始化类。

那么，我们如何初始化具有私有成员变量的类呢？前面示例中编译器给出的错误信息提供了线索：“error: no matching constructor for initialization of ‘Foo'”

我们必须需要一个匹配的构造函数。但那到底是什么？

构造函数

一个 构造函数 是一个特殊的成员函数，在非聚合类类型对象创建后自动调用。

当定义一个非聚合类类型对象时，编译器会查找是否存在一个可访问的构造函数，该构造函数与调用者提供的初始化值（如果有）匹配。

  • 如果找到可访问的匹配构造函数，则分配对象的内存，然后调用构造函数。
  • 如果找不到可访问的匹配构造函数，将产生编译错误。

关键提示

许多新手程序员对构造函数是否创建对象感到困惑。它们不创建对象——编译器在构造函数调用之前为对象设置内存分配。然后构造函数在未初始化的对象上调用。

然而，如果对于一组初始化器找不到匹配的构造函数，编译器将报错。因此，虽然构造函数不创建对象，但缺少匹配的构造函数会阻止对象的创建。

除了确定对象如何创建之外，构造函数通常执行两个功能：

  • 它们通常执行任何成员变量的初始化（通过成员初始化列表）
  • 它们可能执行其他设置功能（通过构造函数体中的语句）。这可能包括诸如检查初始化值的错误、打开文件或数据库等操作。

构造函数执行完毕后，我们说对象已被“构造”，并且对象现在应处于一致、可用的状态。

注意，聚合体不允许有构造函数——因此，如果你向聚合体添加构造函数，它就不再是聚合体。

命名构造函数

与普通成员函数不同，构造函数有特定的命名规则：

  • 构造函数必须与类同名（大小写相同）。对于模板类，此名称不包括模板参数。
  • 构造函数没有返回类型（甚至没有 void)。

因为构造函数通常是类接口的一部分，所以它们通常是公有的。

一个基本的构造函数示例

让我们向上面的示例添加一个基本构造函数：

#include <iostream>

class Foo
{
private:
    int m_x {};
    int m_y {};

public:
    Foo(int x, int y) // 这是我们的构造函数，接受两个初始化值
    {
        std::cout << "Foo(" << x << ", " << y << ") constructed\n";
    }

    void print() const
    {
        std::cout << "Foo(" << m_x << ", " << m_y << ")\n";
    }
};

int main()
{
    Foo foo{ 6, 7 }; // 调用 Foo(int, int) 构造函数
    foo.print();

    return 0;
}

这个程序现在将编译并产生结果：

Foo(6, 7) constructed
Foo(0, 0)

当编译器看到定义 Foo foo{ 6, 7 }时，它会寻找一个匹配的 Foo 构造函数，该构造函数接受两个 int 实参调用了该函数。 Foo(int, int) 是匹配的，因此编译器将允许该定义。

在运行时，当 foo 被实例化时，为 foo 分配内存，然后调用 Foo(int, int) 构造函数，参数为 x 初始化为 6 和参数 y 初始化为 7。然后构造函数体执行并打印 Foo(6, 7) constructed。

当我们调用 print() 成员函数时，你会注意到成员 m_x 和 m_y 的值为 0。这是因为虽然我们的 Foo(int, int) 构造函数被调用了，但它实际上并没有初始化这些成员。我们将在下一课中展示如何做到这一点。

构造函数的参数隐式转换

在课程 10.1 -- 隐式类型转换，我们注意到编译器会在函数调用中执行参数的隐式转换（如果需要），以匹配参数类型不同的函数定义：

void foo(int, int)
{
}

int main()
{
    foo('a', true); // 将匹配 foo(int, int)

    return 0;
}

对于构造函数也是如此： Foo(int, int) 构造函数将匹配任何参数可以隐式转换为 int：

class Foo
{
public:
    Foo(int x, int y)
    {
    }
};

int main()
{
    Foo foo{ 'a', true }; // 将匹配 Foo(int, int) 构造函数

    return 0;
}

构造函数不应为 const

构造函数需要能够初始化正在构造的对象——因此，构造函数不能是 const。

#include <iostream>

class Something
{
private:
    int m_x{};

public:
    Something() // 构造函数必须是非 const 的
    {
        m_x = 5; // 在非 const 构造函数中修改成员是可以的
    }

    int getX() const { return m_x; } // 常量
};

int main()
{
    const Something s{}; // const 对象，隐式调用（非 const）构造函数

    std::cout << s.getX(); // 打印 5
    
    return 0;
}

通常，非 const 成员函数不能在 const 对象上调用。然而，C++ 标准明确规定（参见 class.ctor.general#5）const 不适用于正在构造的对象，只有在构造函数结束后才生效。

构造函数与设置函数

构造函数旨在在实例化时初始化整个对象。设置函数旨在为现有对象的单个成员赋值。
