13.5 — I/O运算符重载简介

● 机器译文 课程 13.5 查看英文原文

在上一课（13.4 -- 枚举与字符串之间的转换），我们展示了一个例子，其中我们使用一个函数将枚举转换为等价的字符串：

#include <iostream>
#include <string_view>

enum Color
{
    black,
    red,
    blue,
};

constexpr std::string_view getColorName(Color color)
{
    switch (color)
    {
    case black: return "black";
    case red:   return "red";
    case blue:  return "blue";
    default:    return "???";
    }
}

int main()
{
    constexpr Color shirt{ blue };

    std::cout << "Your shirt is " << getColorName(shirt) << '\n';

    return 0;
}

尽管上述例子工作正常，但有两个缺点：

  1. 我们必须记住我们创建的函数名称才能获取枚举器名称。
  2. 调用这样的函数会给我们的输出语句增加杂乱。

理想情况下，如果我们能以某种方式教会 operator<< 输出一个枚举，这样我们就可以做类似这样的事情： std::cout << shirt 并且让它按我们期望的方式工作。

运算符重载简介

在课程 11.1 -- 函数重载介绍，我们介绍了函数重载，它允许我们创建多个同名函数，只要每个函数具有唯一的函数原型。使用函数重载，我们可以创建适用于不同数据类型的函数变体，而无需为每个变体想出一个独特的名称。

类似地，C++也支持 运算符重载，它允许我们定义现有运算符的重载，从而使这些运算符能够处理我们程序定义的数据类型。

基本的运算符重载相当直接：

  • 使用运算符的名称作为函数名定义一个函数。
  • 为每个操作数（按从左到右的顺序）添加一个适当类型的参数。其中一个参数必须是用户定义类型（类类型或枚举类型），否则编译器会报错。
  • 将返回类型设置为有意义的类型。
  • 使用返回语句返回操作的结果。

当编译器在表达式中遇到运算符的使用，并且其中一个或多个操作数是用户定义类型时，编译器会检查是否存在可以用于解析该调用的重载运算符函数。例如，给定某个表达式 x + y，编译器将使用函数重载解析来查看是否存在一个 operator+(x, y) 函数调用可以用来计算该操作。如果找到了一个非歧义的 operator+ 函数，它将被调用，并且操作的结果作为返回值返回。

重载 operator<< 以打印枚举器

在继续之前，让我们快速回顾一下 operator<< 在用于输出时是如何工作的。

考虑一个简单的表达式，比如 std::cout << 5。 std::cout 的类型为 std::ostream （它是标准库中的用户定义类型），而 5 是类型为 int。

的字面量。当这个表达式被求值时，编译器会寻找一个重载的 operator<< 函数，该函数可以处理类型为 std::ostream 和 int的参数。它会找到这样一个函数（也定义在标准I/O库中）并调用它。在该函数内部， std::cout 被用来将 x 输出到控制台（具体方式是实现定义的）。最后， operator<< 函数返回其左操作数（在这种情况下是 std::cout），以便后续对 operator<< 的调用可以链式进行。

基于以上考虑，让我们实现一个重载的 operator<< 来打印 Color：

#include <iostream>
#include <string_view>

enum Color
{
	black,
	red,
	blue,
};

constexpr std::string_view getColorName(Color color)
{
    switch (color)
    {
    case black: return "black";
    case red:   return "red";
    case blue:  return "blue";
    default:    return "???";
    }
}

// 教 operator<< 如何打印 Color
// std::ostream 是 std::cout、std::cerr 等的类型...
// 返回类型和参数类型是引用（以防止复制）
std::ostream& operator<<(std::ostream& out, Color color)
{
    out << getColorName(color); // 将我们的颜色名称打印到任何输出流 out 
    return out;                 // operator<< 通常返回其左操作数

    // 以上可以简化为以下一行：
    // return out << getColorName(color)
}

int main()
{
	Color shirt{ blue };
	std::cout << "Your shirt is " << shirt << '\n'; // 它起作用了！

	return 0;
}

这会打印：

Your shirt is blue

让我们稍微解析一下重载的运算符函数。首先，函数名是 operator<<，因为这是我们要重载的运算符的名称。 operator<< 有两个参数。左参数（将与左操作数匹配）是我们的输出流，其类型为 std::ostream。这里我们使用非const引用传递，因为我们不想在调用函数时复制一个 std::ostream 对象，但 std::ostream 对象需要被修改以进行输出。右参数（将与右操作数匹配）是我们的 Color 对象。由于 operator<< 惯例上返回其左操作数，返回类型与左操作数的类型匹配，即 std::ostream&。

现在让我们看看实现。一个 std::ostream 对象已经知道如何打印一个 std::string_view using operator<< （这是标准库的一部分）。所以 out << getColorName(color) 简单地获取我们颜色的名称作为 std::string_view ，然后将其打印到输出流。

注意，我们的实现使用参数 out 而不是 std::cout ，因为我们希望允许调用者决定输出到哪个输出流（例如， std::cerr << color 应该输出到 std::cerr，而不是 std::cout)。

返回左操作数也很容易。左操作数是参数 out，所以我们只需返回 out。

综上所述：当我们调用 std::cout << shirt时，编译器会看到我们已经重载了 operator<< 以处理类型为 Color的对象。然后我们的重载 operator<< 函数被调用，其中 std::cout 作为 out 参数，而我们的 shirt 变量（值为 blue）作为参数 color。因为 out 是对 std::cout、和 color 是枚举器 blue的一个副本，表达式 out << getColorName(color) 打印 "blue" 输出到控制台。最后 out 被返回给调用者，以便我们可以链式添加更多输出。

重载 operator>> 来输入一个枚举器

类似于我们教会 operator<< 输出枚举的方式，我们也可以教会 operator>> 如何输入一个枚举：

#include <iostream>
#include <limits>
#include <optional>
#include <string>
#include <string_view>

enum Pet
{
    cat,   // 0
    dog,   // 1
    pig,   // 2
    whale, // 3
};

constexpr std::string_view getPetName(Pet pet)
{
    switch (pet)
    {
    case cat:   return "cat";
    case dog:   return "dog";
    case pig:   return "pig";
    case whale: return "whale";
    default:    return "???";
    }
}

constexpr std::optional<Pet> getPetFromString(std::string_view sv)
{
    if (sv == "cat")   return cat;
    if (sv == "dog")   return dog;
    if (sv == "pig")   return pig;
    if (sv == "whale") return whale;

    return {};
}

// pet 是一个输入/输出参数
std::istream& operator>>(std::istream& in, Pet& pet)
{
    std::string s{};
    in >> s; // 从用户获取输入字符串

    std::optional<Pet> match { getPetFromString(s) };
    if (match) // 如果找到匹配
    {
        pet = *match; // 解引用 std::optional 以获取匹配的枚举器
        return in;
    }

    // 没有找到匹配，所以输入无效
    // 因此我们将输入流设置为失败状态
    in.setstate(std::ios_base::failbit);
    
    // 提取失败时，operator>> 将基本类型零初始化
    // 取消注释以下行以使此运算符执行相同操作
    // pet = {};

    return in;
}

int main()
{
    std::cout << "Enter a pet: cat, dog, pig, or whale: ";
    Pet pet{};
    std::cin >> pet;
        
    if (std::cin) // 如果找到匹配
        std::cout << "You chose: " << getPetName(pet) << '\n';
    else
    {
        std::cin.clear(); // 将输入流重置为良好状态
        std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
        std::cout << "Your pet was not valid\n";
    }

    return 0;
}

这里有几个与输出情况不同的值得注意的地方。首先， std::cin 的类型为 std::istream，所以我们使用 std::istream& 作为左参数和返回值的类型，而不是 std::ostream&。第二， pet 参数是一个非 const 引用。这允许我们的 operator>> 在提取结果匹配时修改传入的右操作数的值。

关键提示

我们的右操作数（pet）是一个输出参数。我们在第 12.13 -- 输入和输出参数。

如果 pet 是一个值参数而不是引用参数，那么我们的 operator>> 函数最终会将新值赋给右操作数的副本，而不是实际的右操作数。在这种情况下，我们希望修改右操作数。

在函数内部，我们使用 operator>> 来输入一个 std::string （它已经知道如何做）。如果用户输入的值与我们的某个宠物匹配，那么我们可以将 pet 适当的枚举器赋值，并返回左操作数（in)。

如果用户没有输入有效的宠物，那么我们通过将 std::cin 置于“失败模式”来处理这种情况。这是 std::cin 在提取失败时通常进入的状态。调用者可以检查 std::cin 以查看提取是成功还是失败。
