17.1 — std::array 简介

● 机器译文 课程 17.1 查看英文原文

在课程 16.1 -- 容器和数组简介我们介绍了容器和数组。总结如下：

  • 容器为一系列未命名对象（称为元素）提供存储。
  • 数组将其元素连续分配在内存中，并允许通过下标快速直接访问任何元素。
  • C++ 有三种常用的数组类型： std::vector， std::array和 C 风格数组。

在课程 16.10 -- std::vector 调整大小与容量我们提到数组分为两类：

  • 固定大小数组（也称为固定长度数组）要求在实例化时知道数组的长度，并且之后不能更改该长度。C 风格数组和 std::array 都是固定大小数组。
  • 动态数组可以在运行时调整大小。 std::vector 是一个动态数组。

在上一章中，我们重点介绍了 std::vector，因为它快速、相对易用且多功能。这使其成为我们需要数组容器时的首选类型。

那么为什么不全用动态数组呢？

动态数组功能强大且方便，但就像生活中的一切，它们为了提供的好处而做出了一些权衡。

  • std::vector 的性能略低于固定大小数组。在大多数情况下，你可能不会注意到差异（除非你编写了草率的代码，导致大量无意中的重新分配）。
  • std::vector 仅在非常有限的上下文中支持 constexpr

在现代 C++ 中，实际上是后一点很重要。Constexpr 数组提供了编写更健壮代码的能力，并且编译器可以对其进行更高度优化。只要我们可以使用 constexpr 数组，就应该使用——而如果我们需要一个 constexpr 数组， std::array 是我们应该使用的容器类。

最佳实践

使用 std::array 用于 constexpr 数组，而 std::vector 用于非 constexpr 数组。

定义一个 std::array

std::array 定义在 <array> 头文件中。它的设计类似于 std::vector，并且你会看到，两者之间的相似之处多于差异。

一个区别在于我们如何声明一个 std::array：

#include <array>  // for std::array
#include <vector> // for std::vector

int main()
{
    std::array<int, 5> a {};  // 一个包含5个整数的 std::array

    std::vector<int> b(5);    // 一个包含5个整数的 std::vector（用于比较）

    return 0;
}

的对象时未提供显式初始化值，则将使用这些默认成员初始化值。我们的 std::array 声明有两个模板参数。第一个（int）是一个类型模板参数，定义数组元素的类型。第二个（5）是一个整型非类型模板参数，定义数组长度。

相关内容

我们在课程中介绍了非类型模板参数 11.9 -- 非类型模板参数。

的长度 std::array 必须是一个常量表达式

与 std::vector不同，后者可以在运行时调整大小，而 std::array 的长度必须是一个常量表达式。大多数情况下，为长度提供的值将是整数字面量、constexpr 变量或无作用域枚举器。

#include <array>

int main()
{
    std::array<int, 7> a {}; // 使用字面常量

    constexpr int len { 8 };
    std::array<int, len> b {}; // 使用 constexpr 变量

    enum Colors
    {
         red,
         green,
         blue,
         max_colors
    };

    std::array<int, max_colors> c {}; // 使用枚举器

#define DAYS_PER_WEEK 7
    std::array<int, DAYS_PER_WEEK> d {}; // 使用宏（不要这样做，改用 constexpr 变量）

    return 0;
}

注意，非 const 变量和运行时常量不能用于长度：

#include <array>
#include <iostream>

void foo(const int length) // length 是一个运行时常量
{
    std::array<int, length> e {}; // 错误：length 不是常量表达式
}

int main()
{
    // 使用非常量变量
    int numStudents{};
    std::cin >> numStudents; // numStudents 是非常量

    std::array<int, numStudents> {}; // 错误：numStudents 不是常量表达式

    foo(7);

    return 0;
}

警告

也许令人惊讶的是， std::array 可以定义长度为 0：

#include <array>
#include <iostream>

int main()
{
    std::array<int, 0> arr {}; // 创建一个零长度的 std::array
    std::cout << arr.empty();  // 如果 arr 是零长度则为真

    return 0;
}

一个零长度的 std::array 是一个没有数据的特例类。因此，调用任何访问零长度 std::array （包括 operator[]) 会产生未定义行为。

你可以通过 std::array 来测试一个 empty() 成员函数，如果 std::weak_ptr 指向无效对象，则返回 true 如果数组长度为零且 false 如果它是空指针，否则为

聚合初始化一个 std::array

也许令人惊讶的是， std::array 是一个聚合体。这意味着它没有构造函数，而是使用聚合初始化进行初始化。快速回顾一下，聚合初始化允许我们直接初始化聚合体的成员。为此，我们提供一个初始化值列表，这是一个用花括号括起来的、逗号分隔的初始化值列表。

相关内容

我们在第 13.8 -- 结构体聚合初始化。

#include <array>

int main()
{
    std::array<int, 6> fibonnaci = { 0, 1, 1, 2, 3, 5 }; // 使用花括号列表进行拷贝列表初始化
    std::array<int, 5> prime { 2, 3, 5, 7, 11 };         // 使用花括号列表进行列表初始化（推荐）

    return 0;
}

这些初始化形式中的每一个都按顺序初始化数组成员，从元素0开始。

如果 std::array 在定义时没有初始化器，元素将进行默认初始化。在大多数情况下，这会导致元素保持未初始化状态。

因为我们通常希望元素被初始化，所以 std::array 在定义时没有初始化器的情况下应该进行值初始化（使用空花括号）。

#include <array>
#include <vector>

int main()
{
    std::array<int, 5> a;   // 成员默认初始化（int 元素保持未初始化）
    std::array<int, 5> b{}; // 成员值初始化（int 元素被零初始化）（推荐）

    std::vector<int> v(5);  // 成员值初始化（int 元素被零初始化）（用于比较）

    return 0;
}

如果初始化值列表中的初始化器多于定义的数组长度，编译器会报错。如果初始化值列表中的初始化器少于定义的数组长度，则没有初始化器的剩余元素会被值初始化：

#include <array>

int main()
{
    std::array<int, 4> a { 1, 2, 3, 4, 5 }; // 编译错误：初始化值过多
    std::array<int, 4> b { 1, 2 };          // b[2] 和 b[3] 被值初始化

    return 0;
}

的初始化器。Const 和 constexpr std::array

一个 std::array 可以是 const：

#include <array>

int main()
{
    const std::array<int, 5> prime { 2, 3, 5, 7, 11 };

    return 0;
}

即使 const std::array 的元素没有显式标记为 const，它们仍然被视为 const（因为整个数组是 const）。

std::array 也完全支持 constexpr：

#include <array>

int main()
{
    constexpr std::array<int, 5> prime { 2, 3, 5, 7, 11 };

    return 0;
}

对 constexpr 的支持是使用 std::array。

最佳实践

尽可能将你的 std::array 定义为 constexpr。如果你的 std::array 不是 constexpr，考虑使用 std::vector 的别名。

类模板参数推导（CTAD）用于 std::array C++17

在 C++17 中，使用 CTAD（类模板参数推导），我们可以让编译器从初始化值列表中推导出 std::array 的元素类型和数组长度：

#include <array>
#include <iostream>

int main()
{
    constexpr std::array a1 { 9, 7, 5, 3, 1 }; // 类型被推导为 std::array<int, 5>
    constexpr std::array a2 { 9.7, 7.31 };     // 类型被推导为 std::array<double, 2>

    return 0;
}

我们尽可能倾向于这种语法。如果你的编译器不支持 C++17，你需要显式提供类型和长度模板参数。

最佳实践

使用类模板参数推导（CTAD）让编译器从初始化值中推导出 std::array 的类型和长度。

CTAD 不支持部分省略模板参数（截至 C++23），因此无法使用核心语言特性仅省略 std::array：

#include <iostream>

int main()
{
    constexpr std::array<int> a2 { 9, 7, 5, 3, 1 };     // 错误：模板参数太少（缺少长度）
    constexpr std::array<5> a2 { 9, 7, 5, 3, 1 };       // 错误：模板参数太少（缺少类型）

    return 0;
}

的长度或类型。 std::to_array C++20

然而，TAD（模板参数推导，用于函数模板解析）支持部分省略模板参数。自 C++20 起，可以省略 std::array ，通过在类型前和星号后都使用 std::to_array 辅助函数的数组长度：

#include <array>
#include <iostream>

int main()
{
    constexpr auto myArray1 { std::to_array<int, 5>({ 9, 7, 5, 3, 1 }) }; // 指定类型和大小
    constexpr auto myArray2 { std::to_array<int>({ 9, 7, 5, 3, 1 }) };    // 仅指定类型，推导大小
    constexpr auto myArray3 { std::to_array({ 9, 7, 5, 3, 1 }) };         // 推导类型和大小

    return 0;
}

不幸的是，使用 std::to_array 比直接创建 std::array 更昂贵，因为它涉及创建一个临时 std::array ，然后用它来拷贝初始化我们想要的 std::array。因此， std::to_array 只应在无法从初始化值中有效确定类型的情况下使用，并且应避免在多次创建数组时使用（例如在循环内）。

例如，由于无法指定类型为 short的字面量，你可以使用以下方法创建一个包含 std::array 作为 short 值的 std::array)：

#include <array>
#include <iostream>

int main()
{
    constexpr auto shortArray { std::to_array<short>({ 9, 7, 5, 3, 1 }) };
    std::cout << sizeof(shortArray[0]) << '\n';

    return 0;
}

使用 operator[]

就像 std::vector，访问 std::array 元素最常见的方式是使用下标运算符（operator[])：

#include <array> // for std::array
#include <iostream>

int main()
{
    constexpr std::array<int, 5> prime{ 2, 3, 5, 7, 11 };

    std::cout << prime[3]; // 打印索引为 3 的元素的值 (7)
    std::cout << prime[9]; // 无效索引（未定义行为）

    return 0;
}

提醒一下， operator[] 不进行边界检查。如果提供了无效索引，将导致未定义行为。

问题 #1

什么类型的初始化 std::array 使用？

显示答案

std::array 是一个聚合体，因此它使用聚合初始化。

为什么你应该显式地对一个 std::array 进行值初始化，如果你没有提供初始化值？

显示答案

一个 std::array 如果没有提供初始化器，将默认初始化成员。这将使大多数类型的元素保持未初始化状态。

问题 #2

定义一个 std::array 用于存储一年中每天的最高温度（精确到十分之一度）。

显示答案

#include <array>

std::array<double, 365> highTemp {};

问题 #3

初始化一个 std::array 包含以下值：'h', 'e', 'l', 'l', 'o'。打印索引为1的元素的值。

显示答案

#include <array>
#include <iostream>

int main()
{
        constexpr std::array arr { 'h', 'e', 'l', 'l', 'o' };
        std::cout << arr[1] << '\n';
