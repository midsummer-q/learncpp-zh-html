5.7 — std::string 简介

● 机器译文 课程 5.7 查看英文原文

在课程 5.2 -- 字面量，我们介绍了 C 风格字符串字面量：

#include <iostream>
 
int main()
{
    std::cout << "Hello, world!"; // "Hello world!" 是一个 C 风格字符串字面量。
    return 0;
}

虽然 C 风格字符串字面量使用起来没问题，但 C 风格字符串变量的行为奇怪、难以操作（例如，不能使用赋值运算符将新值赋给 C 风格字符串变量），而且很危险（例如，如果将较大的 C 风格字符串复制到为较短 C 风格字符串分配的空间中，会导致未定义行为）。在现代 C++ 中，最好避免使用 C 风格字符串变量。

幸运的是，C++ 在语言中引入了两种额外的字符串类型，它们更易于使用且更安全： std::string 和 std::string_view （C++17）。与我们之前介绍的类型不同， std::string 和 std::string_view 不是基本类型（它们是类类型，我们将在未来介绍）。然而，每种类型的基本用法都很直接且足够有用，因此我们在这里介绍它们。

介绍 std::string

在 C++ 中处理字符串和字符串对象的最简单方法是通过 std::string 类型，它位于 <string> 头文件中。

我们可以创建类型为 std::string 的对象，就像其他对象一样：

#include <string> // allows use of std::string

int main()
{
    std::string name {}; // 空字符串

    return 0;
}

就像普通变量一样，你可以按预期初始化或给 std::string 对象赋值：

#include <string>

int main()
{
    std::string name { "Alex" }; // 用字符串字面量 "Alex" 初始化 name
    name = "John";               // 将 name 改为 "John"

    return 0;
}

注意，字符串也可以由数字字符组成：

std::string myID{ "45" }; // "45" 与整数 45 不同！

在字符串形式中，数字被视为文本，而不是数字，因此不能像数字一样操作它们（例如，不能将它们相乘）。C++ 不会自动将字符串转换为整数或浮点数值，反之亦然（尽管有方法可以做到，我们将在未来的课程中介绍）。

字符串输出与 std::cout

std::string 对象可以按预期使用 std::cout：

#include <iostream>
#include <string>

int main()
{
    std::string name { "Alex" };
    std::cout << "My name is: " << name << '\n';

    return 0;
}

这会打印：

My name is: Alex

空字符串将不打印任何内容：

#include <iostream>
#include <string>

int main()
{
    std::string empty{ };
    std::cout << '[' << empty << ']';

    return 0;
}

输出结果为：

[]

std::string 可以处理不同长度的字符串

最棒的事情之一是 std::string 可以存储不同长度的字符串：

#include <iostream>
#include <string>

int main()
{
    std::string name { "Alex" }; // 用字符串字面量 "Alex" 初始化 name
    std::cout << name << '\n';

    name = "Jason";              // 将 name 改为更长的字符串
    std::cout << name << '\n';

    name = "Jay";                // 将 name 改为更短的字符串
    std::cout << name << '\n';

    return 0;
}

这会打印：

Alex
Jason
Jay

在上面的例子中， name 用字符串 "Alex"初始化，该字符串包含五个字符（四个显式字符和一个空终止符）。然后我们将 name 设置为一个更大的字符串，然后是一个更小的字符串。 std::string 处理这些毫无问题！你甚至可以在 std::string。

中存储非常长的字符串。这是 std::string 如此强大的原因之一。

关键提示

如果 std::string 没有足够的内存来存储字符串时，它会使用一种称为动态内存分配的内存分配形式（在运行时）请求额外的内存。这种获取额外内存的能力是 std::string 如此灵活但也相对较慢的部分原因。

我们将在未来的章节中介绍动态内存分配。

字符串输入与 std::cin

使用 std::string 替换为 std::cin 可能会带来一些惊喜！考虑以下示例：

#include <iostream>
#include <string>

int main()
{
    std::cout << "Enter your full name: ";
    std::string name{};
    std::cin >> name; // 这不会按预期工作，因为 std::cin 会在空白处中断

    std::cout << "Enter your favorite color: ";
    std::string color{};
    std::cin >> color;

    std::cout << "Your name is " << name << " and your favorite color is " << color << '\n';

    return 0;
}

以下是该程序示例运行的结果：

Enter your full name: John Doe
Enter your favorite color: Your name is John and your favorite color is Doe

嗯，这不对！发生了什么？原来，当使用 operator>> 从 std::cin， operator>> 中提取字符串时，它只返回直到第一个空白字符的字符。任何其他字符都留在 std::cin中，等待下一次提取。

所以当我们使用 operator>> 将输入提取到变量 name中时，只有 "John" 被提取出来，留下 " Doe" 在 std::cin内部。当我们随后使用 operator>> 将输入提取到变量 color时，它提取了 "Doe" ，而不是等待我们输入颜色。然后程序结束。

使用 std::getline() 来输入文本

要读取一整行输入到字符串中，最好使用 std::getline() 函数。 std::getline() 需要两个参数：第一个是 std::cin，第二个是你的字符串变量。

下面是使用 std::getline()：

#include <iostream>
#include <string> // For std::string and std::getline

int main()
{
    std::cout << "Enter your full name: ";
    std::string name{};
    std::getline(std::cin >> std::ws, name); // 将一整行文本读入 name

    std::cout << "Enter your favorite color: ";
    std::string color{};
    std::getline(std::cin >> std::ws, color); // 将一整行文本读入 color

    std::cout << "Your name is " << name << " and your favorite color is " << color << '\n';

    return 0;
}

的相同程序：现在我们的程序按预期工作：

Enter your full name: John Doe
Enter your favorite color: blue
Your name is John Doe and your favorite color is blue

这到底是什么 std::ws？

在课程 4.8 -- 浮点数，我们讨论了输出操纵器，它们允许我们改变输出的显示方式。在那节课中，我们使用了输出操纵器函数 std::setprecision() 来改变 std::cout 显示的数字精度。

C++ 也支持 输入操纵器，它们改变输入被接受的方式。 std::ws 输入操纵器告诉 std::cin 在提取之前忽略任何前导空白。前导空白是指出现在字符串开头的任何空白字符（空格、制表符、换行符）。

让我们探讨为什么这很有用。考虑以下程序：

#include <iostream>
#include <string>

int main()
{
    std::cout << "Pick 1 or 2: ";
    int choice{};
    std::cin >> choice;

    std::cout << "Now enter your name: ";
    std::string name{};
    std::getline(std::cin, name); // 注意：这里没有 std::ws

    std::cout << "Hello, " << name << ", you picked " << choice << '\n';

    return 0;
}

以下是该程序的一些输出：

Pick 1 or 2: 2
Now enter your name: Hello, , you picked 2

这个程序首先要求你输入 1 或 2，并等待你输入。到目前为止一切正常。然后它会要求你输入你的名字。然而，它实际上不会等待你输入名字！相反，它会打印“Hello”字符串，然后退出。

当你使用 operator>>， std::cin 输入一个值时，它不仅捕获该值，还捕获你按下回车键时产生的换行符（'\n'）。所以当我们输入 2 然后按回车时， std::cin 捕获字符串 "2\n" 作为输入。然后它提取值 2 给变量 choice，留下换行符供以后使用。然后，当 std::getline() 要提取文本到 name时，它看到 "\n" 已经在 std::cin中等待，并认为我们之前一定输入了一个空字符串！这绝对不是预期的。

我们可以修改上面的程序，使用 std::ws 输入操纵器，告诉 std::getline() 忽略任何前导空白字符：

#include <iostream>
#include <string>

int main()
{
    std::cout << "Pick 1 or 2: ";
    int choice{};
    std::cin >> choice;

    std::cout << "Now enter your name: ";
    std::string name{};
    std::getline(std::cin >> std::ws, name); // 注意：这里添加了 std::ws

    std::cout << "Hello, " << name << ", you picked " << choice << '\n';

    return 0;
}

现在这个程序将按预期运行。

Pick 1 or 2: 2
Now enter your name: Alex
Hello, Alex, you picked 2

最佳实践

如果使用 std::getline() 读取字符串，请使用 std::cin >> std::ws 输入操纵器忽略前导空白。每次调用都需要这样做，因为 std::getline() 不会在调用之间保留。 std::ws 状态不会在调用之间保留。

关键提示

当提取到变量时，提取运算符（>>）会忽略前导空白。遇到非前导空白时停止提取。

std::getline() 不会忽略前导空白。如果你希望它忽略前导空白，请将 std::cin >> std::ws 作为第一个参数传递。遇到换行符时停止提取。

的长度 std::string

如果我们想知道一个 std::string中有多少个字符，我们可以询问一个 std::string 对象的长度。执行此操作的语法与您之前见过的不同，但相当直接：

#include <iostream>
#include <string>

int main()
{
    std::string name{ "Alex" };
    std::cout << name << " has " << name.length() << " characters\n";

    return 0;
}

这会打印：

Alex has 4 characters

尽管 std::string 必须以空字符结尾（自C++11起），返回的 std::string 长度不包括隐式的空终止符。

请注意，不是像 length(name)那样询问字符串长度，而是说 name.length()。这些 length() 函数不是一个普通的独立函数——它是一种特殊类型的函数，嵌套在 std::string 内部，称为 成员函数。因为 length() 成员函数声明在 std::string内部，所以在文档中有时写作 std::string::length()

我们将在后面更详细地介绍成员函数，包括如何编写自己的成员函数。

关键提示

对于普通函数，我们调用 function(object)。对于成员函数，我们调用 object.function()。

还要注意 std::string::length() 返回一个无符号整数值（很可能是 size_t类型）。如果你想将长度赋值给一个 int 变量，你应该 static_cast 它以避免关于有符号/无符号转换的编译器警告：

int length { static_cast<int>(name.length()) };

进阶读者

在C++20中，你还可以使用 std::ssize() 函数获取 std::string 的长度，作为大的有符号整数类型（通常是 std::ptrdiff_t)：

#include <iostream>
#include <string>

int main()
{
    std::string name{ "Alex" };
    std::cout << name << " has " << std::ssize(name) << " characters\n";

    return 0;
}

）。由于 ptrdiff_t 可能比 int大，如果你想将 std::ssize() 的结果存储在 int 变量，你应该 static_cast 中，请将结果转换为 int：

int len { static_cast<int>(std::ssize(name)) };

初始化一个 std::string 是昂贵的

每当一个 std::string 被初始化时，都会复制用于初始化它的字符串。复制字符串是昂贵的，因此应尽量减少复制的次数。

不要按值传递 std::string 按值传递

当一个 std::string 按值传递给函数时， std::string 函数参数必须用实参实例化并初始化。这会导致昂贵的复制。我们将讨论应该怎么做（使用 std::string_view） 5.8 -- std::string_view 简介。

最佳实践

不要按值传递 std::string 按值传递，因为它会进行昂贵的复制。

提示

在大多数情况下，使用 std::string_view 参数代替（在课程 5.8 -- std::string_view 简介)。

中进一步讨论。 std::string

双引号字符串字面量（如“Hello, world!”）默认是 C 风格字符串（因此具有奇怪的类型）。

我们可以通过使用 std::string 后缀在双引号字符串字面量之后创建类型为 s 的字符串字面量。 s 必须是小写。

#include <iostream>
#include <string> // for std::string

int main()
{
    using namespace std::string_literals; // 轻松访问 s 后缀

    std::cout << "foo\n";   // 无后缀是C风格字符串字面量
    std::cout << "goo\n"s;  // s后缀是std::string字面量

    return 0;
}

提示

“s”后缀位于命名空间 std::literals::string_literals。

中。访问字面量后缀最简洁的方式是通过 using 指令 using namespace std::literals。然而，这会将 所有 标准库字面量导入到 using 指令的作用域中，这会引入一堆你可能不会使用的东西。

我们建议 using namespace std::string_literals，它只导入字面量 std::string。

我们在课程 7.13 -- 使用声明和 using 指令中讨论 using 指令。这是一个例外情况， using 整个命名空间通常是可以的，因为其中定义的后缀不太可能与你的任何代码冲突。避免在头文件的函数外部使用此类 using 指令。

你可能不需要经常使用 std::string 字面量（因为用 C 风格字符串字面量初始化 std::string 对象是可以的），但在未来的课程中，我们会看到一些情况（涉及类型推导），使用 std::string 字面量而不是 C 风格字符串字面量会使事情更简单（参见 10.8 -- 使用 auto 关键字进行对象的类型推导 中的示例）。

进阶读者

"Hello"s 解析为 std::string { "Hello", 5 } 它创建一个临时的 std::string ，用 C 风格字符串字面量“Hello”初始化（长度为 5，不包括隐式的空终止符）。

Constexpr 字符串

如果你尝试定义一个 constexpr std::string，你的编译器可能会生成一个错误：

#include <iostream>
#include <string>

int main()
{
    using namespace std::string_literals;

    constexpr std::string name{ "Alex"s }; // 编译错误

    std::cout << "My name is: " << name;

    return 0;
}

这是因为 constexpr std::string 在 C++17 或更早版本中完全不支持，在 C++20/23 中仅在非常有限的情况下有效。如果你需要 constexpr 字符串，请使用 std::string_view 代替（在课程 5.8 -- std::string_view 简介)。

总结

std::string 很复杂，利用了许多我们尚未介绍的语言特性。幸运的是，你不需要理解这些复杂性就能使用 std::string 完成简单任务，比如基本的字符串输入和输出。我们鼓励你现在就开始尝试使用字符串，我们将在后面介绍更多的字符串功能。

小测验时间

问题 #1

编写一个程序，要求用户输入他们的全名和年龄。作为输出，告诉用户他们的年龄和名字中字符数的总和（使用 std::string::length() 成员函数获取字符串的长度）。为简单起见，将名字中的任何空格都计为一个字符。

示例输出：

Enter your full name: John Doe
Enter your age: 32
Your age + length of name is: 40

提醒：我们需要注意不要混合有符号和无符号值。 std::string::length() 返回一个无符号值。如果你能使用 C++20，请使用 std::ssize() 以有符号值获取长度。否则，将 std::string::length() 的返回值 static_cast 为 int。

显示答案

#include <iostream>
#include <string>

int main()
{
    std::cout << "Enter your full name: ";
    std::string name{};
    std::getline(std::cin >> std::ws, name); // 将一整行文本读入 name

    std::cout << "Enter your age: ";
    int age{}; // age需要是整数，而不是字符串，这样我们才能用它进行数学运算
    std::cin >> age;

    // age是有符号的，而name.length()是无符号的——我们不应该混用它们
    // 我们将把name.length()转换为有符号值
    int nameLen { static_cast<int>(name.length()) }; // 获取name中的字符数（包括空格）
    std::cout << "Your age + length of name is: " << age + nameLen << '\n';

    return 0;
}
