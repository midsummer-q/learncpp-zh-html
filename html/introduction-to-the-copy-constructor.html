14.14 — 拷贝构造函数简介

● 机器译文 课程 14.14 查看英文原文

考虑以下程序：

#include <iostream>
 
class Fraction
{
private:
    int m_numerator{ 0 };
    int m_denominator{ 1 };
 
public:
    // 默认构造函数
    Fraction(int numerator=0, int denominator=1)
        : m_numerator{numerator}, m_denominator{denominator}
    {
    }

    void print() const
    {
        std::cout << "Fraction(" << m_numerator << ", " << m_denominator << ")\n";
    }
};

int main()
{
    Fraction f { 5, 3 };  // 调用 Fraction(int, int) 构造函数
    Fraction fCopy { f }; // 这里使用了哪个构造函数？

    f.print();
    fCopy.print();

    return 0;
}

你可能会惊讶地发现这个程序编译完全正常，并产生如下结果：

Fraction(5, 3)
Fraction(5, 3)

让我们仔细看看这个程序是如何工作的。

变量 f 的初始化只是一个标准的列表初始化，它调用了 Fraction(int, int) 构造函数。

但下一行呢？变量 fCopy 的初始化显然也是一个初始化，而且你知道构造函数用于初始化类。那么这一行调用的是哪个构造函数呢？

答案是：拷贝构造函数。

拷贝构造函数

一个 拷贝构造函数 是一种构造函数，用于使用同类型的现有对象来初始化一个对象。拷贝构造函数执行后，新创建的对象应该是作为初始化器传入的对象的副本。

隐式拷贝构造函数

如果你没有为你的类提供拷贝构造函数，C++ 会为你创建一个公有的 隐式拷贝构造函数 在上面的例子中，语句 Fraction fCopy { f }; 调用了隐式拷贝构造函数来初始化 fCopy 替换为 f。

默认情况下，隐式拷贝构造函数会进行成员初始化。这意味着每个成员将使用传入的类对象的相应成员进行初始化。在上面的例子中， fCopy.m_numerator 使用 f.m_numerator （其值为 5），并且 fCopy.m_denominator 使用 f.m_denominator （其值为 3)。

进行初始化。拷贝构造函数执行后， f 和 fCopy 的成员具有相同的值，因此 fCopy 是 f。所以在任何一个对象上调用 print() 都会得到相同的结果。

定义你自己的拷贝构造函数

我们也可以显式定义自己的拷贝构造函数。在本课中，我们将让拷贝构造函数打印一条消息，以便向你展示它在进行拷贝时确实被执行。

拷贝构造函数看起来和你预期的一样：

#include <iostream>
 
class Fraction
{
private:
    int m_numerator{ 0 };
    int m_denominator{ 1 };
 
public:
    // 默认构造函数
    Fraction(int numerator=0, int denominator=1)
        : m_numerator{numerator}, m_denominator{denominator}
    {
    }

    // 拷贝构造函数
    Fraction(const Fraction& fraction)
        // 使用形参的对应成员初始化我们的成员
        : m_numerator{ fraction.m_numerator }
        , m_denominator{ fraction.m_denominator }
    {
        std::cout << "Copy constructor called\n"; // 只是为了证明它有效
    }

    void print() const
    {
        std::cout << "Fraction(" << m_numerator << ", " << m_denominator << ")\n";
    }
};

int main()
{
    Fraction f { 5, 3 };  // 调用 Fraction(int, int) 构造函数
    Fraction fCopy { f }; // 调用 Fraction(const Fraction&) 拷贝构造函数

    f.print();
    fCopy.print();

    return 0;
}

当这个程序运行时，你会得到：

Copy constructor called
Fraction(5, 3)
Fraction(5, 3)

我们上面定义的拷贝构造函数在功能上等同于默认的拷贝构造函数，只是我们添加了一个输出语句来证明拷贝构造函数确实被调用了。这个拷贝构造函数在 fCopy 用 f。

提醒

访问控制是基于类的（而不是基于对象的）。这意味着类的成员函数可以访问同一类型的任何类对象的私有成员（不仅仅是隐式对象）。

我们在上面的 Fraction 拷贝构造函数中利用了这一点，以便直接访问 fraction 参数的私有成员。否则，我们将无法直接访问这些成员（除非添加访问函数，而这可能不是我们想要的）。

拷贝构造函数除了复制对象外，不应做任何其他事情。这是因为编译器在某些情况下可能会优化掉拷贝构造函数。如果你依赖拷贝构造函数执行除复制之外的其他行为，那么该行为可能会也可能不会发生。我们将在课程 14.15 -- 类初始化与复制省略。

最佳实践

中进一步讨论这一点。拷贝构造函数除了复制之外不应有副作用。

优先使用隐式拷贝构造函数

与隐式默认构造函数不同（它什么都不做，因此很少是我们想要的），隐式拷贝构造函数执行的成员初始化通常正是我们想要的。因此，在大多数情况下，使用隐式拷贝构造函数是完全没问题的。

最佳实践

除非你有特定的理由创建自己的拷贝构造函数，否则优先使用隐式拷贝构造函数。

当我们讨论动态内存分配时，会看到需要重写拷贝构造函数的情况（21.13 -- 浅拷贝与深拷贝)。

拷贝构造函数的参数必须是引用

拷贝构造函数的参数必须是左值引用或 const 左值引用。由于拷贝构造函数不应修改参数，因此优先使用 const 左值引用。

最佳实践

如果你编写自己的拷贝构造函数，参数应为 const 左值引用。

按值传递与拷贝构造函数

当对象按值传递时，实参被复制到形参中。当实参和形参是相同的类类型时，复制通过隐式调用拷贝构造函数完成。

下面的例子说明了这一点：

#include <iostream>

class Fraction
{
private:
    int m_numerator{ 0 };
    int m_denominator{ 1 };

public:
    // 默认构造函数
    Fraction(int numerator = 0, int denominator = 1)
        : m_numerator{ numerator }, m_denominator{ denominator }
    {
    }

    // 拷贝构造函数
    Fraction(const Fraction& fraction)
        : m_numerator{ fraction.m_numerator }
        , m_denominator{ fraction.m_denominator }
    {
        std::cout << "Copy constructor called\n";
    }

    void print() const
    {
        std::cout << "Fraction(" << m_numerator << ", " << m_denominator << ")\n";
    }
};

void printFraction(Fraction f) // f 是按值传递
{
    f.print();
}

int main()
{
    Fraction f{ 5, 3 };

    printFraction(f); // f 通过拷贝构造函数被复制到函数形参中

    return 0;
}

在作者的机器上，这个例子输出：

Copy constructor called
Fraction(5, 3)

在上面的例子中，调用 printFraction(f) 是按值传递 f 拷贝构造函数被调用来复制 f 从 main 复制到 f 函数的形参 printFraction()。

按值返回与拷贝构造函数

在课程 2.5 -- 局部作用域简介，我们注意到按值返回会创建一个临时对象（包含返回值的副本）并返回给调用者。当返回类型和返回值是相同的类类型时，临时对象通过隐式调用拷贝构造函数初始化。

例如：

#include <iostream>

class Fraction
{
private:
    int m_numerator{ 0 };
    int m_denominator{ 1 };

public:
    // 默认构造函数
    Fraction(int numerator = 0, int denominator = 1)
        : m_numerator{ numerator }, m_denominator{ denominator }
    {
    }

    // 拷贝构造函数
    Fraction(const Fraction& fraction)
        : m_numerator{ fraction.m_numerator }
        , m_denominator{ fraction.m_denominator }
    {
        std::cout << "Copy constructor called\n";
    }

    void print() const
    {
        std::cout << "Fraction(" << m_numerator << ", " << m_denominator << ")\n";
    }
};

void printFraction(Fraction f) // f 是按值传递
{
    f.print();
}

Fraction generateFraction(int n, int d)
{
    Fraction f{ n, d };
    return f;
}

int main()
{
    Fraction f2 { generateFraction(1, 2) }; // Fraction 通过拷贝构造函数返回

    printFraction(f2); // f2 通过拷贝构造函数被复制到函数形参中

    return 0;
}

当 generateFraction 按值返回一个 Fraction 返回给 main时，会创建一个临时的 Fraction 对象并使用拷贝构造函数初始化。

由于这个临时对象用于初始化 Fraction f2，因此再次调用拷贝构造函数将临时对象复制到 f2。

中。而当 f2 被传递给 printFraction()时，拷贝构造函数被第三次调用。

因此，在作者的机器上，这个例子输出：

Copy constructor called
Copy constructor called
Copy constructor called
Fraction(1, 2)

如果你编译并执行上面的例子，可能会发现只调用了两次拷贝构造函数。这是一种编译器优化，称为 拷贝省略。我们将在第 14.15 -- 类初始化与复制省略。

生成默认拷贝构造函数 = default 语法来生成：

#include <iostream>
 
class Fraction
{
private:
    int m_numerator{ 0 };
    int m_denominator{ 1 };
 
public:
    // 默认构造函数
    Fraction(int numerator=0, int denominator=1)
        : m_numerator{numerator}, m_denominator{denominator}
    {
    }

    // 显式请求默认拷贝构造函数
    Fraction(const Fraction& fraction) = default;

    }

int main()
{
    Fraction f { 5, 3 };
    Fraction fCopy { f };

    f.print();
    fCopy.print();

    return 0;
}

#include <iostream>
 
class Fraction
{
private:
    int m_numerator{ 0 };
    int m_denominator{ 1 };

    Fraction(int numerator=0, int denominator=1)

    }

    // 删除拷贝构造函数，使得无法进行拷贝
    Fraction(const Fraction& fraction) = delete;

int main()
{
    Fraction f { 5, 3 };
    Fraction fCopy { f }; // 编译错误：拷贝构造函数已被删除

    return 0;
}

问题 #1

在上面的课程中，我们注意到拷贝构造函数的参数必须是（const）引用。为什么不允许使用按值传递？

显示提示

提示：思考一下当我们按值传递类类型参数时会发生什么。

显示答案

当我们按值传递类类型参数时，拷贝构造函数会被隐式调用，以将参数复制到形参中。

如果拷贝构造函数使用按值传递，那么拷贝构造函数需要调用自身来将初始化参数复制到拷贝构造函数的形参中。但那个对拷贝构造函数的调用也是按值传递，因此拷贝构造函数会再次被调用来将参数复制到函数形参中。这将导致对拷贝构造函数的无限调用链。
