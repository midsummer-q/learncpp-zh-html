20.7 — Lambda 捕获

● 机器译文 课程 20.7 查看英文原文


捕获子句与按值捕获

在前一课（20.6 -- lambda（匿名函数）简介)，我们介绍了这个例子：

#include <algorithm>
#include <array>
#include <iostream>
#include <string_view>

int main()
{
  std::array<std::string_view, 4> arr{ "apple", "banana", "walnut", "lemon" };

  auto found{ std::find_if(arr.begin(), arr.end(),
                           [](std::string_view str)
                           {
                             return str.find("nut") != std::string_view::npos;
                           }) };

  if (found == arr.end())
  {
    std::cout << "No nuts\n";
  }
  else
  {
    std::cout << "Found " << *found << '\n';
  }

  return 0;
}

现在，让我们修改坚果示例，让用户选择要搜索的子字符串。这并不像你想象的那么直观。

#include <algorithm>
#include <array>
#include <iostream>
#include <string_view>
#include <string>

int main()
{
  std::array<std::string_view, 4> arr{ "apple", "banana", "walnut", "lemon" };

  // 询问用户要搜索什么。
  std::cout << "search for: ";

  std::string search{};
  std::cin >> search;

  auto found{ std::find_if(arr.begin(), arr.end(), [](std::string_view str) {
    // 搜索 @search 而不是 "nut"。
    return str.find(search) != std::string_view::npos; // 错误：search 在此作用域中不可访问
  }) };

  if (found == arr.end())
  {
    std::cout << "Not found\n";
  }
  else
  {
    std::cout << "Found " << *found << '\n';
  }

  return 0;
}

这段代码无法编译。与嵌套块不同，在嵌套块中，外层块中可访问的任何标识符在内层块中也可访问，而 lambda 只能访问某些在 lambda 外部定义的对象。这包括：

  • 具有静态（或线程局部）存储持续时间的对象（包括全局变量和静态局部变量）
  • constexpr 对象（显式或隐式）

由于 search 不满足这些要求中的任何一个，lambda 就无法看到它。

提示

Lambda 只能访问某些在 lambda 外部定义的对象，包括具有静态存储持续时间的对象（例如全局变量和静态局部变量）以及 constexpr 对象。

要从 lambda 内部访问 search ，我们需要使用捕获子句。

捕获子句

浮点类型的 捕获子句 用于（间接）让 lambda 访问周围作用域中通常无法访问的变量。我们只需在捕获子句中列出要从 lambda 内部访问的实体即可。在这种情况下，我们希望让 lambda 访问变量 search的值，因此我们将其添加到捕获子句中：

#include <algorithm>
#include <array>
#include <iostream>
#include <string_view>
#include <string>

int main()
{
  std::array<std::string_view, 4> arr{ "apple", "banana", "walnut", "lemon" };

  std::cout << "search for: ";

  std::string search{};
  std::cin >> search;

  // 捕获 @search                                vvvvvv
  auto found{ std::find_if(arr.begin(), arr.end(), [search](std::string_view str) {
    return str.find(search) != std::string_view::npos;
  }) };

  if (found == arr.end())
  {
    std::cout << "Not found\n";
  }
  else
  {
    std::cout << "Found " << *found << '\n';
  }

  return 0;
}

用户现在可以搜索数组中的元素了。

输出

search for: nana
Found banana

那么捕获实际上是如何工作的呢？

虽然在上面的例子中，我们的 lambda 看起来是直接访问 main的 search 变量的值，但事实并非如此。Lambda 看起来像嵌套块，但它们的工作方式略有不同（这种区别很重要）。

当 lambda 定义被执行时，对于 lambda 捕获的每个变量，会在 lambda 内部创建一个该变量的副本（名称相同）。这些克隆变量在此时从同名的外部作用域变量初始化。

因此，在上面的例子中，当 lambda 对象被创建时，lambda 获得了自己的名为 search的克隆变量。这个克隆的 search 与 main的 search具有相同的值，所以它看起来就像我们在访问 main的 search，但实际上并不是。

虽然这些克隆变量具有相同的名称，但它们不一定与原始变量具有相同的类型。我们将在本课的后续部分探讨这一点。

关键提示

lambda 的捕获变量是 副本 ，而不是实际变量。

进阶读者

虽然 lambda 看起来像函数，但它们实际上是可像函数一样调用的对象（这被称为 仿函数 ——我们将在未来的课程中讨论如何从头创建自己的仿函数）。

当编译器遇到 lambda 定义时，它会为 lambda 创建一个自定义对象定义。每个捕获的变量成为对象的一个数据成员。

在运行时，当遇到 lambda 定义时，lambda 对象被实例化，并且 lambda 的成员在此时被初始化。

捕获默认被视为 const

当 lambda 被调用时， operator() 被调用。默认情况下，这个 operator() 将捕获视为 const，这意味着 lambda 不允许修改这些捕获。

在下面的例子中，我们捕获变量 ammo 并尝试递减它。

#include <iostream>

int main()
{
  int ammo{ 10 };

  // 定义一个 lambda 并将其存储在名为 "shoot" 的变量中。
  auto shoot{
    [ammo]() {
      // 非法，ammo 不能被修改。
      --ammo;

      std::cout << "Pew! " << ammo << " shot(s) left.\n";
    }
  };

  // 调用 lambda
  shoot();

  std::cout << ammo << " shot(s) left\n";

  return 0;
}

上述代码无法编译，因为 ammo 在 lambda 中被视为 const。

可变捕获

为了允许修改被捕获的变量，我们可以将 lambda 标记为 mutable：

#include <iostream>

int main()
{
  int ammo{ 10 };

  auto shoot{
    [ammo]() mutable { // 现在 mutable
      // 我们现在可以修改 ammo 了
      --ammo;

      std::cout << "Pew! " << ammo << " shot(s) left.\n";
    }
  };

  shoot();
  shoot();

  std::cout << ammo << " shot(s) left\n";

  return 0;
}

输出：

Pew! 9 shot(s) left.
Pew! 8 shot(s) left.
10 shot(s) left

虽然现在可以编译，但仍然存在逻辑错误。发生了什么？当 lambda 被调用时，lambda 捕获了 副本 作为 ammo。当 lambda 递减 ammo 从 10 切换到 9 切换到 8时，它递减的是自己的副本，而不是原始的 ammo 值在 main()。

注意， ammo 的值在 lambda 的多次调用之间得以保留！

警告

因为被捕获的变量是 lambda 对象的成员，它们的值在 lambda 的多次调用之间得以持久化！

按引用捕获

就像函数可以改变按引用传递的参数的值一样，我们也可以按引用捕获变量，从而让 lambda 影响参数的值。

要按引用捕获变量，我们在捕获中在变量名前加上一个 &（&）。与按值捕获的变量不同，按引用捕获的变量是非 const 的，除非它们捕获的变量是 const。当通常更倾向于按引用传递参数给函数时（例如对于非基本类型），应该优先选择按引用捕获而非按值捕获。

以下是上述代码将 ammo 按引用捕获的版本：

#include <iostream>

int main()
{
  int ammo{ 10 };

  auto shoot{
    // 我们不再需要 mutable
    [&ammo]() { // &ammo 表示 ammo 通过引用捕获
      // 对 ammo 的修改将影响 main 中的 ammo
      --ammo;

      std::cout << "Pew! " << ammo << " shot(s) left.\n";
    }
  };

  shoot();

  std::cout << ammo << " shot(s) left\n";

  return 0;
}

这产生了预期的答案：

Pew! 9 shot(s) left.
9 shot(s) left

现在，让我们使用引用捕获来统计 std::sort 在排序数组时进行了多少次比较。

#include <algorithm>
#include <array>
#include <iostream>
#include <string_view>

struct Car
{
  std::string_view make{};
  std::string_view model{};
};

int main()
{
  std::array<Car, 3> cars{ { { "Volkswagen", "Golf" },
                             { "Toyota", "Corolla" },
                             { "Honda", "Civic" } } };

  int comparisons{ 0 };

  std::sort(cars.begin(), cars.end(),
    // 通过引用捕获 @comparisons。
    [&comparisons](const auto& a, const auto& b) {
      // 我们通过引用捕获了 comparisons。无需 "mutable" 即可修改它。
      ++comparisons;

      // 按品牌对汽车进行排序。
      return a.make < b.make;
  });

  std::cout << "Comparisons: " << comparisons << '\n';

  for (const auto& car : cars)
  {
    std::cout << car.make << ' ' << car.model << '\n';
  }

  return 0;
}

可能的输出

Comparisons: 2
Honda Civic
Toyota Corolla
Volkswagen Golf

捕获多个变量

多个变量可以通过逗号分隔来捕获。这可以包括按值或按引用捕获的变量混合：

int health{ 33 };
int armor{ 100 };
std::vector<CEnemy> enemies{};

// 按值捕获 health 和 armor，按引用捕获 enemies。
[health, armor, &enemies](){};

默认捕获

显式列出要捕获的变量可能很繁琐。如果你修改了 lambda，可能会忘记添加或删除捕获的变量。幸运的是，我们可以借助编译器自动生成需要捕获的变量列表。

一个 默认捕获 （也称为 捕获默认值）捕获 lambda 中提到的所有变量。如果使用了默认捕获，则未在 lambda 中提到的变量不会被捕获。

要按值捕获所有使用的变量，使用捕获值 =。
要按引用捕获所有使用的变量，使用捕获值 &。

以下是使用按值默认捕获的示例：

#include <algorithm>
#include <array>
#include <iostream>

int main()
{
  std::array areas{ 100, 25, 121, 40, 56 };

  int width{};
  int height{};

  std::cout << "Enter width and height: ";
  std::cin >> width >> height;

  auto found{ std::find_if(areas.begin(), areas.end(),
                           [=](int knownArea) { // 将默认按值捕获 width 和 height
                             return width * height == knownArea; // 因为它们在这里被提及
                           }) };

  if (found == areas.end())
  {
    std::cout << "I don't know this area :(\n";
  }
  else
  {
    std::cout << "Area found :)\n";
  }

  return 0;
}

默认捕获可以与普通捕获混合使用。我们可以按值捕获一些变量，按引用捕获其他变量，但每个变量只能被捕获一次。

int health{ 33 };
int armor{ 100 };
std::vector<CEnemy> enemies{};

// 按值捕获 health 和 armor，按引用捕获 enemies。
[health, armor, &enemies](){};

// 按引用捕获 enemies，其他所有按值捕获。
[=, &enemies](){};

// 按值捕获 armor，其他所有按引用捕获。
[&, armor](){};

// 非法，我们已经说过要按引用捕获所有。
[&, &armor](){};

// 非法，我们已经说过要按值捕获所有。
[=, armor](){};

// 非法，armor 出现了两次。
[armor, &health, &armor](){};

// 非法，默认捕获必须是捕获组中的第一个元素。
[armor, &](){};

在 lambda 捕获中定义新变量

有时我们想捕获一个经过轻微修改的变量，或者声明一个仅在 lambda 作用域内可见的新变量。我们可以通过在 lambda 捕获中定义变量而不指定其类型来实现。

#include <array>
#include <iostream>
#include <algorithm>

int main()
{
  std::array areas{ 100, 25, 121, 40, 56 };

  int width{};
  int height{};

  std::cout << "Enter width and height: ";
  std::cin >> width >> height;

  // 我们存储面积，但用户输入的是宽度和高度。
  // 我们需要先计算面积，然后才能搜索它。
  auto found{ std::find_if(areas.begin(), areas.end(),
                           // 声明一个新变量，该变量仅对 lambda 可见。
                           // userArea 的类型自动推导为 int。
                           [userArea{ width * height }](int knownArea) {
                             return userArea == knownArea;
                           }) };

  if (found == areas.end())
  {
    std::cout << "I don't know this area :(\n";
  }
  else
  {
    std::cout << "Area found :)\n";
  }

  return 0;
}

userArea 只会在 lambda 定义时计算一次。计算出的面积存储在 lambda 对象中，并且每次调用都相同。如果 lambda 是可变的并且修改了捕获中定义的变量，原始值将被覆盖。

最佳实践

仅在变量的值简短且类型明显时，才在捕获中初始化变量。否则，最好在 lambda 外部定义变量并捕获它。

悬空捕获变量

变量在 lambda 定义时被捕获。如果按引用捕获的变量在 lambda 之前销毁，lambda 将持有悬空引用。

例如：

#include <iostream>
#include <string>

// 返回一个 lambda
auto makeWalrus(const std::string& name)
{
  // 按引用捕获 name 并返回 lambda。
  return [&]() {
    std::cout << "I am a walrus, my name is " << name << '\n'; // 未定义行为
  };
}

int main()
{
  // 创建一个名为 Roofus 的新海象。
  // sayName 是由 makeWalrus 返回的 lambda。
  auto sayName{ makeWalrus("Roofus") };

  // 调用 makeWalrus 返回的 lambda 函数。
  sayName();

  return 0;
}

对 makeWalrus() 创建一个临时的 std::string 的调用来自字符串字面量 "Roofus"。lambda 在 makeWalrus() 中通过引用捕获了临时字符串。临时字符串在包含对 makeWalrus()调用的完整表达式结束时销毁，但 lambda sayName 在那之后仍然引用它。因此，当我们调用 sayName时，访问了悬空引用，导致未定义行为。

注意，如果 "Roofus" 被传递给 makeWalrus() 按值传递，也会发生这种情况。参数 name 在 makeWalrus()结束时销毁，而 lambda 持有一个悬空引用。

警告

当通过引用捕获变量时，要格外小心，尤其是使用默认引用捕获时。被捕获的变量必须比 lambda 存活得更久。

如果我们希望被捕获的 name 在 lambda 使用时仍然有效，我们需要改为按值捕获（要么显式指定，要么使用默认按值捕获）。

可变 lambda 的意外副本

因为 lambda 是对象，所以它们可以被复制。在某些情况下，这可能会引起问题。考虑以下代码：

#include <iostream>

int main()
{
  int i{ 0 };

  // 创建一个名为 count 的新 lambda
  auto count{ [i]() mutable {
    std::cout << ++i << '\n';
  } };

  count(); // 调用 count

  auto otherCount{ count }; // 创建 count 的一个副本

  // 调用 count 和它的副本
  count();
  otherCount();

  return 0;
}

输出

1
2
2

代码没有打印 1, 2, 3，而是打印了两次 2。当我们创建 otherCount 作为 count的副本时，我们创建了 count 当前状态的副本。 count的 i 是 1，所以 otherCount的 i 也是 1。由于 otherCount 是 count，它们各自拥有自己的 i。

现在让我们看一个稍微不那么明显的例子：

#include <iostream>
#include <functional>

void myInvoke(const std::function<void()>& fn)
{
    fn();
}

int main()
{
    int i{ 0 };

    // 递增并打印其局部副本 @i。
    auto count{ [i]() mutable {
      std::cout << ++i << '\n';
    } };

    myInvoke(count);
    myInvoke(count);
    myInvoke(count);

    return 0;
}

输出：

1
1
1

这以更隐蔽的形式展示了与前一个例子相同的问题。

当我们调用 myInvoke(count)，编译器会发现 count （具有 lambda 类型）与引用参数类型（std::function<void()>）不匹配。它会将 lambda 转换为一个临时的 std::function ，以便引用参数可以绑定到它，这将生成 lambda 的一个副本。因此，我们对 fn() 的调用实际上是在作为临时 std::function一部分的 lambda 副本上执行的，而不是在真正的 lambda 上。

如果我们需要传递一个可变 lambda，并且希望避免意外副本的可能性，有两个选项。一个选项是改用非捕获 lambda——在上面的例子中，我们可以移除捕获，改用静态局部变量来跟踪状态。但静态局部变量可能难以跟踪，并使代码可读性降低。更好的选项是首先防止 lambda 被复制。但由于我们无法影响 std::function （或其他标准库函数或对象）的实现方式，我们该如何做到这一点呢？

一个选项（感谢读者 Dck）是立即将我们的 lambda 放入一个 std::function 中。这样，当我们调用 myInvoke()时，引用参数 fn 可以绑定到我们的 std::function，并且不会生成临时副本：

#include <iostream>
#include <functional>

void myInvoke(const std::function<void()>& fn)
{
    fn();
}

int main()
{
    int i{ 0 };

    // 递增并打印其局部副本 @i。
    std::function count{ [i]() mutable { // 存储在 std::function 中的 lambda 对象
      std::cout << ++i << '\n';
    } };

    myInvoke(count); // 调用时不创建副本
    myInvoke(count); // 调用时不创建副本
    myInvoke(count); // 调用时不创建副本

    return 0;
}

现在我们的输出符合预期：

1
2
3

另一种解决方案是使用引用包装器。C++ 提供了一个方便的类型（作为 <functional> 头文件的一部分），称为 std::reference_wrapper 它允许我们将普通类型当作引用传递。为了更加方便，可以使用 std::reference_wrapper 函数创建一个 std::ref() 通过将我们的 lambda 包装在 std::reference_wrapper中，每当有人试图复制我们的 lambda 时，他们实际上会复制一个 reference_wrapper（从而避免复制 lambda 本身）。

以下是使用 std::ref：

#include <iostream>
#include <functional> // includes std::reference_wrapper and std::ref

void myInvoke(const std::function<void()>& fn)
{
    fn();
}

int main()
{
    int i{ 0 };

    // 递增并打印其局部副本 @i。
    auto count{ [i]() mutable {
      std::cout << ++i << '\n';
    } };

    // std::ref(count) 确保 count 被视为引用
    // 因此，任何试图复制 count 的操作实际上都会复制引用
    // 确保只存在一个 count
    myInvoke(std::ref(count));
    myInvoke(std::ref(count));
    myInvoke(std::ref(count));

    return 0;
}

现在我们的输出符合预期：

1
2
3

更新后的代码。有趣的是，即使 myInvoke 按值（而不是按引用）接受 fn ，这种方法仍然有效！

规则

标准库函数可能会复制函数对象（提醒：lambda 是函数对象）。如果你想提供带有可变捕获变量的 lambda，请使用 std::ref。

最佳实践

通过引用传递它们。尽量避免使用可变 lambda。非可变 lambda 更容易理解，并且不会遇到上述问题，以及当你添加并行执行时出现的更危险的问题。

小测验时间

问题 #1

以下哪些变量可以被 lambda 在 main 中使用而不需要显式捕获？

int i{};
static int j{};

int getValue()
{
  return 0;
}

int main()
{
  int a{};
  constexpr int b{};
  static int c{};
  static constexpr int d{};
  const int e{};
  const int f{ getValue() };
  static const int g{}; 
  static const int h{ getValue() }; 

  [](){
    // 尝试使用变量而不显式捕获它们。
    a;
    b;
    c;
    d;
    e;
    f;
    g;
    h;
    i;
    j;
  }();

  return 0;
}

显示答案

变量无需显式捕获即可使用
a否。 a 具有自动存储期。
b是。 b 可以在常量表达式中使用。
c是。 c 具有静态存储期。
d是。
e是。 e 可以在常量表达式中使用。
f否。 f的值依赖于 getValue，这可能需要程序运行。
g是。
h是。 h 具有静态存储期。
i是。 i 是一个全局变量。
j是。 j 在整个文件中可访问。

问题 #2

以下代码会打印什么？不要运行代码，在脑中推算。

#include <iostream>
#include <string>

int main()
{
  std::string favoriteFruit{ "grapes" };

  auto printFavoriteFruit{
    [=]() {
      std::cout << "I like " << favoriteFruit << '\n';
    }
  };

  favoriteFruit = "bananas with chocolate";

  printFavoriteFruit();

  return 0;
}

显示答案

I like grapes

printFavoriteFruit 按值捕获了 favoriteFruit 修改 main的 favoriteFruit 不会影响 lambda 的 favoriteFruit。

问题 #3

我们将编写一个关于平方数（可以通过整数自乘得到的数：1, 4, 9, 16, 25, …）的小游戏。

设置游戏：

  • 要求用户输入一个起始数字（例如 3）。
  • 要求用户输入要生成多少个值。
  • 随机选择一个介于 2 和 4 之间的整数。这是乘数。
  • 生成用户指定数量的值。从起始数字开始，每个值应该是下一个平方数乘以乘数。

进行游戏：

  • 用户输入一个猜测。
  • 如果猜测匹配任何生成的值，则将该值从列表中移除，用户继续猜测。
  • 如果用户猜对了所有生成的值，则获胜。
  • 如果猜测不匹配任何生成的值，则用户失败，程序告诉用户最近的未猜中的值。

以下是一些示例会话，帮助你更好地理解游戏的工作原理：

Nice! 2 number(s) left.
> 126
126 is wrong! Try 128 next time.
  • 从 4 开始，程序生成接下来的 5 个平方数：16, 25, 36, 49, 64
  • 程序选择了 2 作为随机乘数，因此每个平方数乘以 2：32, 50, 72, 98, 128
  • 现在用户开始猜测。
  • 32 在列表中。
  • 72 在列表中。
  • 126 不在列表中，所以用户输了。最接近的未猜数字是 128。

  • 从 1 开始，程序生成接下来的 3 个平方数：1, 4, 9
  • 程序选择了 4 作为随机乘数，所以每个平方数乘以 4：4, 16, 36
  • 用户猜对了所有数字，赢得了游戏。

提示：

  • 使用 Random.h (8.15 -- 全局随机数 (Random.h)) 生成随机数。
  • 使用 std::find() (18.3 -- 标准库算法简介) 在列表中搜索数字。
  • 使用 std::vector::erase() 来移除一个元素，例如
auto found{ std::find(/* ... */) };

// 确保找到了该元素

myVector.erase(found);
  • 使用 std::min_element 和一个 lambda 来找到最接近用户猜测的数字。 std::min_element 的工作方式类似于 std::max_element 来自之前的测验。

显示提示

提示：使用 std::abs 来自 <cmath> 来计算两个数的正差。

int distance{ std::abs(3 - 5) }; // 2

显示答案

#include <algorithm> // std::find, std::min_element
#include <cmath> // std::abs
#include <cstddef> // std::size_t
#include <iostream>
#include <vector>
#include "Random.h"

using Numbers = std::vector<int>;

namespace config
{
    constexpr int multiplierMin{ 2 };
    constexpr int multiplierMax{ 6 };
}

// 生成 @count 个数字，从 @start*@start 开始，并将
// 每个平方数乘以 @multiplier。
Numbers generateNumbers(int start, int count, int multiplier)
{
    Numbers numbers(static_cast<std::size_t>(count));

    for (int index = 0; index < count; ++index)
    {
        std::size_t uindex{ static_cast<std::size_t>(index) };
        numbers[uindex] = (start + index) * (start + index) * multiplier;
    }

    return numbers;
}

// 要求用户输入起始数字，然后生成数字数组
Numbers setupGame()
{
    int start{};
    std::cout << "Start where? ";
    std::cin >> start;

    int count{};
    std::cout << "How many? ";
    std::cin >> count;

    int multiplier{ Random::get(config::multiplierMin, config::multiplierMax) };

    std::cout << "I generated " << count
        << " square numbers. Do you know what each number is after multiplying it by "
        << multiplier << "?\n";

    return generateNumbers(start, count, multiplier);
}

// 返回用户的猜测
int getUserGuess()
{
    int guess{};

    std::cout << "> ";
    std::cin >> guess;

    return guess;
}

// 在 @numbers 中搜索值 @guess 并将其移除。
// 如果找到该值则返回 true，否则返回 false。
bool findAndRemove(Numbers& numbers, int guess)
{
    auto found{ std::find(numbers.begin(), numbers.end(), guess) };

    if (found == numbers.end())
        return false;

    numbers.erase(found);
    return true;
}

// 在 @numbers 中找到最接近 @guess 的值。
int findClosestNumber(const Numbers& numbers, int guess)
{
    return *std::min_element(numbers.begin(), numbers.end(),
        [=](int a, int b)
        {
            return std::abs(a - guess) < std::abs(b - guess);
        });
}


// 当用户猜对一个数字时调用。
void printSuccess(const Numbers& numbers)
{
    std::cout << "Nice! ";

    if (numbers.size() == 0)
    {
        std::cout << "You found all numbers, good job!\n";
    }
    else
    {
        std::cout << numbers.size() << " number(s) left.\n";
    }
}

// 当用户猜了一个不在数字中的数字时调用。
void printFailure(const Numbers& numbers, int guess)
{
    int closest{ findClosestNumber(numbers, guess) };

    std::cout << guess << " is wrong!\n";

    std::cout << "Try " << closest << " next time.\n";
}

int main()
{
    Numbers numbers{ setupGame() };

    while (true)
    {
        int guess{ getUserGuess() };

        if (!findAndRemove(numbers, guess))
        {
            printFailure(numbers, guess);
            break;
        }
        
        printSuccess(numbers);
        if (numbers.size() == 0)
            break;
    }

    return 0;
}
