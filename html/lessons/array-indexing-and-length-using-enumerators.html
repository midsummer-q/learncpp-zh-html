16.9 — 使用枚举器进行数组索引和长度计算

● 机器译文 课程 16.9 查看英文原文

数组的一个较大的文档问题在于，整数索引没有向程序员提供任何关于索引含义的信息。

考虑一个包含5个测试分数的数组：

#include <vector>

int main()
{
    std::vector testScores { 78, 94, 66, 77, 14 };

    testScores[2] = 76; // 这代表谁？
}

由 testScores[2]代表的学生是谁？这并不清楚。

使用无作用域枚举器进行索引

在课程 16.3 -- std::vector 和无符号长度与下标问题，我们花了很多时间讨论 std::vector<T>::operator[] （以及其他可下标访问的C++容器类）的索引类型是 size_type，它通常是 std::size_t的别名。因此，我们的索引要么是 std::size_t类型，要么是可以转换为 std::size_t。

的类型。由于无作用域枚举会隐式转换为 std::size_t，这意味着我们可以使用无作用域枚举作为数组索引，以帮助记录索引的含义：

#include <vector>

namespace Students
{
    enum Names
    {
        kenny, // 0
        kyle, // 1
        stan, // 2
        butters, // 3
        cartman, // 4
        max_students // 5
    };
}

int main()
{
    std::vector testScores { 78, 94, 66, 77, 14 };

    testScores[Students::stan] = 76; // 我们现在正在更新属于 stan 的测试分数

    return 0;
}

通过这种方式，每个数组元素代表什么就更加清晰了。

因为枚举器是隐式constexpr的，将枚举器转换为无符号整型不被视为窄化转换，从而避免了有符号/无符号索引问题。

使用非constexpr的无作用域枚举进行索引

无作用域枚举的底层类型是由实现定义的（因此，可能是有符号或无符号整型）。由于枚举器是隐式constexpr的，只要我们坚持使用无作用域枚举器进行索引，就不会遇到符号转换问题。

然而，如果我们定义一个枚举类型的非constexpr变量，然后尝试用它来索引我们的 std::vector ，在默认将无作用域枚举设置为有符号类型的平台上，我们可能会收到符号转换警告：

#include <vector>

namespace Students
{
    enum Names
    {
        kenny, // 0
        kyle, // 1
        stan, // 2
        butters, // 3
        cartman, // 4
        max_students // 5
    };
}

int main()
{
    std::vector testScores { 78, 94, 66, 77, 14 };
    Students::Names name { Students::stan }; // 非 constexpr

    testScores[name] = 76; // 如果 Student::Names 默认使用有符号底层类型，可能会触发符号转换警告

    return 0;
}

在这种特定情况下，我们可以将 name constexpr（这样从constexpr有符号整型到 std::size_t 的转换是非窄化的）。但是，当我们的初始化器不是常量表达式时，这种方法就行不通了。

另一种选择是显式指定枚举的底层类型为unsigned int：

#include <vector>

namespace Students
{
    enum Names : unsigned int // 明确指定底层类型为 unsigned int
    {
        kenny, // 0
        kyle, // 1
        stan, // 2
        butters, // 3
        cartman, // 4
        max_students // 5
    };
}

int main()
{
    std::vector testScores { 78, 94, 66, 77, 14 };
    Students::Names name { Students::stan }; // 非 constexpr

    testScores[name] = 76; // 由于 name 是无符号的，因此不是符号转换

    return 0;
}

在上面的例子中，由于 name 现在保证是 unsigned int，它可以转换为 std::size_t 而不会出现符号转换问题。

使用计数枚举器

注意，我们在枚举器列表的末尾定义了一个额外的枚举器，名为 max_students。如果所有前面的枚举器都使用默认值（推荐这样做），那么这个枚举器的默认值将等于前面枚举器的数量。在上面的例子中， max_students 值为 5，因为前面定义了5个枚举器。非正式地，我们称其为 计数枚举器，因为它的值表示先前定义的枚举器的数量。

这个计数枚举器随后可以在任何需要前面枚举器数量的地方使用。例如：

#include <iostream>
#include <vector>

namespace Students
{
    enum Names
    {
        kenny, // 0
        kyle, // 1
        stan, // 2
        butters, // 3
        cartman, // 4
        // 在此处添加未来的枚举器
        max_students // 5
    };
}

int main()
{
    std::vector<int> testScores(Students::max_students); // 创建一个包含 5 个元素的 vector

    testScores[Students::stan] = 76; // 我们现在正在更新属于 stan 的测试分数

    std::cout << "The class has " << Students::max_students << " students\n";

    return 0;
}

我们使用 max_students 在两个地方：首先，我们创建一个长度为 std::vector 的 max_students，这样向量就为每个学生分配一个元素。我们还使用 max_students 来打印学生数量。

这种技术也很好，因为如果以后添加了另一个枚举器（就在 max_students之前），那么 max_students 将自动增加1，并且所有使用 max_students 将更新以使用新长度，无需进一步修改。

#include <vector>
#include <iostream>

namespace Students
{
    enum Names
    {
        kenny, // 0
        kyle, // 1
        stan, // 2
        butters, // 3
        cartman, // 4
        wendy, // 5（已添加）
        // 在此处添加未来的枚举器
        max_students // 现在是 6
    };
}

int main()
{
    std::vector<int> testScores(Students::max_students); // 现在将分配 6 个元素

    testScores[Students::stan] = 76; // 仍然有效

    std::cout << "The class has " << Students::max_students << " students\n";

    return 0;
}

使用计数枚举器断言数组长度

更常见的情况是，我们使用初始化值列表创建数组，并打算用枚举器索引该数组。在这种情况下，断言容器的大小等于我们的计数枚举器是有用的。如果此断言触发，那么要么我们的枚举器列表有误，要么我们提供了错误数量的初始化值。当向枚举中添加新枚举器但未向数组添加新初始化值时，很容易发生这种情况。

例如：

#include <cassert>
#include <iostream>
#include <vector>

enum StudentNames
{
    kenny, // 0
    kyle, // 1
    stan, // 2
    butters, // 3
    cartman, // 4
    max_students // 5
};

int main()
{
    std::vector testScores { 78, 94, 66, 77, 14 };

    // 确保测试分数的数量与学生数量相同
    assert(std::size(testScores) == max_students);

    return 0;
}

提示

如果你的数组是 constexpr，那么你应该 static_assert 的别名。 std::vector 不支持 constexpr，但 std::array （以及 C 风格数组）支持。

我们在课程 17.3 -- 传递和返回 std::array。

数组和枚举类

由于无作用域枚举会将其枚举器污染到定义它们的命名空间，因此在枚举未包含在其他作用域区域（例如命名空间或类）中的情况下，最好使用枚举类。

然而，由于枚举类没有到整数类型的隐式转换，当我们尝试将其枚举器用作数组索引时，会遇到问题：

#include <iostream>
#include <vector>

enum class StudentNames // 现在是一个枚举类
{
    kenny, // 0
    kyle, // 1
    stan, // 2
    butters, // 3
    cartman, // 4
    max_students // 5
};

int main()
{
    // 编译错误：无法从 StudentNames 转换为 std::size_t
    std::vector<int> testScores(StudentNames::max_students);

    // 编译错误：无法从 StudentNames 转换为 std::size_t
    testScores[StudentNames::stan] = 76;

    // 编译错误：无法从 StudentNames 转换为 operator<< 可以输出的任何类型
    std::cout << "The class has " << StudentNames::max_students << " students\n";

    return 0;
}

有几种方法可以解决这个问题。最明显的是，我们可以将枚举器 static_cast 转换为整数：

#include <iostream>
#include <vector>

enum class StudentNames
{
    kenny, // 0
    kyle, // 1
    stan, // 2
    butters, // 3
    cartman, // 4
    max_students // 5
};

int main()
{
    std::vector<int> testScores(static_cast<int>(StudentNames::max_students));

    testScores[static_cast<int>(StudentNames::stan)] = 76;

    std::cout << "The class has " << static_cast<int>(StudentNames::max_students) << " students\n";

    return 0;
}

然而，这不仅输入起来很麻烦，而且还会使代码变得杂乱。

更好的选择是使用我们在课程 13.6 -- 作用域枚举（enum class）中介绍的辅助函数，它允许我们使用一元 operator+。

#include <iostream>
#include <type_traits> // for std::underlying_type_t
#include <vector>

enum class StudentNames
{
    kenny, // 0
    kyle, // 1
    stan, // 2
    butters, // 3
    cartman, // 4
    max_students // 5
};

// 重载一元 + 运算符以将 StudentNames 转换为底层类型
constexpr auto operator+(StudentNames a) noexcept
{
    return static_cast<std::underlying_type_t<StudentNames>>(a);
}

int main()
{
    std::vector<int> testScores(+StudentNames::max_students);

    testScores[+StudentNames::stan] = 76;

    std::cout << "The class has " << +StudentNames::max_students << " students\n";

    return 0;
}

将枚举类的枚举器转换为整数值。然而，如果你要进行大量的枚举器到整数的转换，那么最好在命名空间（或类）内使用标准枚举。

小测验时间

问题 #1

创建一个程序定义的枚举（在命名空间内），包含以下动物的名称：chicken、dog、cat、elephant、duck 和 snake。定义一个数组，每个动物对应一个元素，并使用初始化列表将每个元素初始化为该动物的腿数。断言数组具有正确数量的初始化值。

编写一个 main() 函数，使用枚举器打印大象的腿数。

显示答案

#include <cassert>
#include <iostream>
#include <vector>

namespace Animals
{
    enum Animals
    {
        chicken,
        dog,
        cat,
        elephant,
        duck,
        snake,
        max_animals
    };

    const std::vector legs{ 2, 4, 4, 4, 2, 0 };
}

int main()
{
    // 确保腿的数量与动物的数量相同
    assert(std::size(Animals::legs) == Animals::max_animals);

    std::cout << "An elephant has " << Animals::legs[Animals::elephant] << " legs.\n";

    return 0;
}
