16.6 — 数组和循环

● 机器译文 课程 16.6 查看英文原文

在本章的入门课程（16.1 -- 容器和数组简介）中，我们介绍了当有许多相关的独立变量时出现的可扩展性挑战。在本课中，我们将重新介绍这个问题，然后讨论数组如何帮助我们优雅地解决这类问题。

变量可扩展性挑战，再探

考虑这样一个情况：我们想要计算一个班级学生的平均考试成绩。为了简洁起见，我们假设班级只有5名学生。

以下是使用独立变量解决此问题的方法：

#include <iostream>

int main()
{
    // 分配5个整型变量（每个变量名称不同）
    int testScore1{ 84 };
    int testScore2{ 92 };
    int testScore3{ 76 };
    int testScore4{ 81 };
    int testScore5{ 56 };

    int average { (testScore1 + testScore2 + testScore3 + testScore4 + testScore5) / 5 };

    std::cout << "The class average is: " << average << '\n';

    return 0;
}

这需要很多变量和大量输入。想象一下，如果我们要处理30名学生或600名学生，工作量会有多大。此外，如果添加了一个新的考试成绩，就必须声明、初始化一个新变量，并将其添加到平均计算中。而且你记得更新除数了吗？如果忘记了，现在就出现了一个语义错误。任何时候需要修改现有代码，都有引入错误的风险。

到现在，你应该知道当我们有一堆相关变量时，应该使用数组。所以让我们用 std::vector：

#include <iostream>
#include <vector>

int main()
{
    std::vector testScore { 84, 92, 76, 81, 56 };
    std::size_t length { testScore.size() };
    
    int average { (testScore[0] + testScore[1] + testScore[2] + testScore[3] + testScore[4])
        / static_cast<int>(length) };

    std::cout << "The class average is: " << average << '\n';

    return 0;
}

这更好——我们显著减少了定义的变量数量，并且平均计算的除数现在直接由数组长度决定。

但平均计算仍然是个问题，因为我们不得不手动列出每个元素。而且由于必须显式列出每个元素，我们的平均计算只适用于具有恰好列出那么多元素的数组。如果我们还想对其他长度的数组求平均值，就需要为每个不同的数组长度编写一个新的平均计算。

我们真正需要的是某种方式，无需显式列出每个数组元素就能访问它们。

数组和循环

在之前的课程中，我们注意到数组下标不必是常量表达式——它们可以是运行时表达式。这意味着我们可以使用变量的值作为索引。

还要注意，前面例子中平均计算使用的数组索引是一个递增序列：0, 1, 2, 3, 4。因此，如果我们有办法让一个变量依次取值为0, 1, 2, 3, 4，那么我们就可以用这个变量作为数组索引，而不是字面量。而我们已经知道如何做到这一点——使用for循环。

相关内容

我们在课程 8.10 -- For 语句。

中介绍了for循环。让我们用for循环重写上面的例子，其中循环变量用作数组索引：

#include <iostream>
#include <vector>

int main()
{
    std::vector testScore { 84, 92, 76, 81, 56 };
    std::size_t length { testScore.size() };

    int average { 0 };
    for (std::size_t index{ 0 }; index < length; ++index) // 索引从0到length-1
        average += testScore[index];                      // 添加索引为`index`的元素的值
    average /= static_cast<int>(length);                  // 计算平均值

    std::cout << "The class average is: " << average << '\n';

    return 0;
}

这应该相当简单。 index 从 0， testScore[0] 开始，将 average、和 index 递增到 1。 testScore[1] 开始，将 average、和 index 递增到 2。最终，当 index 递增到 5， index < length 为假时，循环终止。

此时，循环已经将 testScore[0]， testScore[1]， testScore[2]， testScore[3]、和 testScore[4] 切换到 average。

的值累加。最后，我们通过将累加值除以数组长度来计算平均值。

这个解决方案在可维护性方面是理想的。循环迭代的次数由数组长度决定，循环变量用于所有数组索引。我们不再需要手动列出每个数组元素。

如果我们想添加或删除一个考试成绩，只需修改数组初始化器的数量，其余代码无需进一步更改即可正常工作！

按某种顺序访问容器中的每个元素称为 遍历，或 遍历 容器。遍历通常被称为 迭代，或 迭代 或 迭代 容器。

作者注

由于容器类使用类型 size_t 作为长度和索引，在本课中，我们也这样做。我们将在接下来的课程 16.7 -- 数组、循环和符号挑战解决方案。

模板、数组和循环解锁可扩展性

数组提供了一种存储多个对象而无需命名每个元素的方法。

循环提供了一种遍历数组而无需显式列出每个元素的方法。

模板提供了一种参数化元素类型的方法。

模板、数组和循环共同使我们能够编写代码，这些代码可以操作一个元素容器，无论容器中的元素类型或元素数量如何！

为了进一步说明这一点，让我们重写上面的例子，将平均值计算重构为一个函数模板：

#include <iostream>
#include <vector>

// 函数模板，用于计算std::vector中值的平均值
template <typename T>
T calculateAverage(const std::vector<T>& arr)
{
    std::size_t length { arr.size() };
    
    T average { 0 };                                      // 如果我们的数组包含类型 T 的元素，那么平均值也应该是类型 T
    for (std::size_t index{ 0 }; index < length; ++index) // 遍历所有元素
        average += arr[index];                            // 对所有元素求和
    average /= static_cast<int>(length);                  // 除以元素个数（本质上是整数）
    
    return average;
}

int main()
{
    std::vector class1 { 84, 92, 76, 81, 56 };
    std::cout << "The class 1 average is: " << calculateAverage(class1) << '\n'; // 计算 5 个整数的平均值

    std::vector class2 { 93.2, 88.6, 64.2, 81.0 };
    std::cout << "The class 2 average is: " << calculateAverage(class2) << '\n'; // 计算 4 个双精度浮点数的平均值
    
    return 0;
}

这会打印：

The class 1 average is: 77
The class 2 average is: 81.75

在上面的例子中，我们创建了函数模板 calculateAverage()，它接受一个 std::vector ，元素类型和长度任意，并返回平均值。在 main()中，我们演示了这个函数在调用时，无论是包含5个 int 元素的数组还是包含4个 double 元素的数组，都能同样良好地工作！

calculateAverage() 适用于任何类型 T ，只要该类型支持函数内部使用的运算符（operator+=(T)， operator/=(int)）。如果你尝试使用一个 T 不支持这些运算符的类型，编译器在尝试编译实例化的函数模板时会报错。

你可能想知道为什么我们要将 length 到 int 而不是 T进行类型转换。当我们计算平均值时，我们将总和除以元素个数。元素个数是一个整数值。因此，从语义上讲，除以一个 int。

我们能对数组和循环做些什么

既然我们知道如何使用循环遍历容器中的元素，让我们看看容器遍历最常见的用途。我们通常遍历容器是为了做以下四件事之一：

  1. 根据现有元素的值计算新值（例如平均值、总和）。
  2. 搜索现有元素（例如精确匹配、统计匹配次数、查找最大值）。
  3. 对每个元素进行操作（例如输出每个元素、将所有元素乘以2）。
  4. 重新排列元素（例如按升序排序元素）。

前三种相当直接。我们可以使用单个循环遍历数组，根据需要检查或修改每个元素。

重新排列容器中的元素要复杂得多，因为这通常涉及在另一个循环内部使用循环。虽然我们可以手动完成，但通常最好使用标准库中的现有算法来实现。我们将在未来讨论算法时更详细地介绍这一点。

数组与差一错误

当使用索引遍历容器时，必须注意确保循环执行正确的次数。差一错误（循环体执行次数多一次或少一次）很容易发生。

通常，当使用索引遍历容器时，我们会将索引从 0 开始，循环直到 index < length。

新程序员有时会错误地使用 index <= length 作为循环条件。这会导致循环在 index == length时执行，从而导致下标越界和未定义行为。

template <typename T>
int findIndex(const std::vector<T>& arr, T val)
{
    for (std::size_t index{ 0 }; index < arr.size(); ++index)
    {
        if (arr[index] == val)
            return static_cast<int>(index);
    }    

    return -1; // -1 不是有效的索引，因此我们可以将其用作错误返回值

int getValidNumber()
{
    // 首先，从用户处读取有效输入
    int num {};
    do
    {
        std::cout << "Enter a number between 1 and 9: ";
        std::cin >> num;

        // 如果用户输入了无效字符
        if (!std::cin)

问题 #5

编写一个函数模板来查找 std::vector中的最大值。如果向量为空，则返回元素类型的默认值。

以下代码应该执行：

int main()
{
    std::vector data1 { 84, 92, 76, 81, 56 };
    std::cout << findMax(data1) << '\n';

    std::vector data2 { -13.0, -26.7, -105.5, -14.8 };
    std::cout << findMax(data2) << '\n';

    std::vector<int> data3 { };
    std::cout << findMax(data3) << '\n';
    
    return 0;
}

并打印以下结果：

92
-13
0

显示提示

提示：使用一个非循环变量来跟踪到目前为止看到的最高值。

显示答案

#include <iostream>
#include <vector>

template <typename T>
T findMax(const std::vector<T>& arr)
{
    std::size_t length { arr.size() };

    if (length==0)
        return T{};    

    T max { arr[0] }; // 将最大值设为第一个元素

    // 遍历剩余元素，寻找更大的值
    for (std::size_t index{ 1 }; index < length; ++index)
    {
        if (arr[index] > max)
            max = arr[index];
    }

    return max;
}

int main()
{
    std::vector data1 { 84, 92, 76, 81, 56 };
    std::cout << findMax(data1) << '\n';

    std::vector data2 { -13.0, -26.7, -105.5, -14.8 };
    std::cout << findMax(data2) << '\n';

    std::vector<int> data3 { };
    std::cout << findMax(data3) << '\n';
    
    return 0;
}

在这个例子中，我们使用一个名为 max 的非循环变量来跟踪我们见过的最高分数。我们将 max 初始化为第一个元素的值，这样它就从合法值开始。值初始化可能很诱人，但如果数组只包含负值，会导致函数返回错误的值。

然后我们遍历数组的每个元素，如果发现一个比之前见过的任何分数都高的分数，就将 max 设置为该值。因此， max 始终代表到目前为止我们搜索过的所有元素中的最高分数。当我们到达数组末尾时， max 保存整个数组中的最高分，然后我们可以将其返回给调用者。

// 感谢读者 Waldo 提出这个测验
#include <cassert>
#include <iostream>
#include <string_view>
#include <vector>

void fizzbuzz(int count)
{
	// 我们将这些设为 static，以便只初始化一次
	static const std::vector divisors                { 3, 5, 7, 11, 13, 17, 19 };
	static const std::vector<std::string_view> words { "fizz", "buzz", "pop", "bang", "jazz", "pow", "boom" };
	assert(std::size(divisors) == std::size(words) && "fizzbuzz: array sizes don't match");

	// 循环遍历 1 到 count（含）之间的每个数字
	for (int i{ 1 }; i <= count; ++i)
	{
		bool printed{ false };

		// 检查当前数字是否能被每个可能的除数整除
		for (std::size_t j{ 0 }; j < divisors.size(); ++j)
		{
			if (i % divisors[j] == 0)
			{
				std::cout << words[j];
				printed = true;
			}
		}

		// 如果没有除数
		if (!printed)
			std::cout << i;

		std::cout << '\n';
	}
}

int main()
{
	fizzbuzz(150);

	return 0;
}

提示

因为 divisors 和 words 是常量数组，最好将它们设为 constexpr ——但我们不能对 std::vector这样做。这里最好使用 constexpr std::array 我们将在 std::array 在课程 17.1 -- std::array简介。
