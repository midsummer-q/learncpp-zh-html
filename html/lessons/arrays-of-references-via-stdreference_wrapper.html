17.5 — 通过 std::reference_wrapper 实现引用数组

● 机器译文 课程 17.5 查看英文原文

在上一课中，我们提到数组可以包含任何对象类型的元素。这包括具有基本类型（例如 int）的对象和具有复合类型（例如指向 int 的指针）的对象。

#include <array>
#include <iostream>
#include <vector>

int main()
{
    int x { 1 };
    int y { 2 };

    [[maybe_unused]] std::array valarr { x, y };   // 一个 int 值数组
    [[maybe_unused]] std::vector ptrarr { &x, &y }; // 一个 int 指针的向量
    
    return 0;
}

然而，由于引用不是对象，因此不能创建引用数组。数组的元素必须是可赋值的，而引用不能被重新绑定。

#include <array>
#include <iostream>

int main()
{
    int x { 1 };
    int y { 2 };

    [[maybe_unused]] std::array<int&, 2> refarr { x, y }; // 编译错误：无法定义引用数组

    int& ref1 { x };
    int& ref2 { y };
    [[maybe_unused]] std::array valarr { ref1, ref2 }; // ok: 这实际上是一个 std::array<int, 2>，而不是引用数组

    return 0;
}

在本课中，我们将在示例中使用 std::array ，但这同样适用于所有数组类型。

但是，如果你想要一个引用数组，有一种变通方法。

std::reference_wrapper

std::reference_wrapper 是一个标准库类模板，位于 <functional> 头文件中。它接受一个类型模板参数 T，然后表现得像一个可修改的 T 左值引用。

关于 std::reference_wrapper：

  • Operator= 会重新绑定一个 std::reference_wrapper （更改所引用的对象）。
  • std::reference_wrapper<T> 会隐式转换为 T&。
  • 浮点类型的 get() 成员函数可用于获取一个 T&。当我们要更新所引用对象的值时，这很有用。

这是一个简单的例子：

#include <array>
#include <functional> // for std::reference_wrapper
#include <iostream>

int main()
{
    int x { 1 };
    int y { 2 };
    int z { 3 };

    std::array<std::reference_wrapper<int>, 3> arr { x, y, z };
    
    arr[1].get() = 5; // 修改数组元素1中的对象

    std::cout << arr[1] << y << '\n'; // 显示我们修改了 arr[1] 和 y，输出 55
    
    return 0;
}

此示例输出以下内容：

55

注意，我们必须使用 arr[1].get() = 5 而不是 arr[1] = 5。后者是有歧义的，因为编译器无法判断我们是打算将 std::reference_wrapper<int> 重新绑定到值 5（这本身是非法的）还是更改所引用的值。使用 get() 可以消除歧义。

当打印 arr[1]时，编译器会意识到它无法打印一个 std::reference_wrapper<int>，因此会将其隐式转换为 int&，然后就可以打印了。所以我们不需要使用 get()

std::ref 和 std::cref

在 C++17 之前，CTAD（类模板参数推导）不存在，因此类类型的所有模板参数都需要显式列出。因此，要创建一个 std::reference_wrapper<int>，你可以执行以下任一操作：

    int x { 5 };

    std::reference_wrapper<int> ref1 { x };        // C++11
    auto ref2 { std::reference_wrapper<int>{ x }}; // C++11

由于名称较长且必须显式列出模板参数，创建许多这样的引用包装器可能会很麻烦。

为了简化操作，提供了 std::ref() 和 std::cref() 函数作为快捷方式来创建 std::reference_wrapper 和 const std::reference_wrapper 包装的对象。注意，这些函数可以与 auto 一起使用，以避免显式指定模板参数。

    int x { 5 };
    auto ref { std::ref(x) };   // C++11，推导为 std::reference_wrapper<int>
    auto cref { std::cref(x) }; // C++11，推导为 std::reference_wrapper<const int>

当然，既然我们在 C++17 中有了 CTAD，我们也可以这样做：

    std::reference_wrapper ref1 { x };        // C++17
    auto ref2 { std::reference_wrapper{ x }}; // C++17

但由于 std::ref() 和 std::cref() 输入更短，它们仍然被广泛用于创建 std::reference_wrapper 对象。
