章节回顾

一个 语句 是一种指令，用于让程序执行某些操作。语句通常以分号结尾。

一个 函数 是一系列按顺序执行的语句的集合。每个C++程序都必须包含一个名为 main。当你运行程序时，执行从 main 函数的顶部开始。

在编程中，函数（或对象、类型、模板等）的名称称为其 标识符。

规定C++语言元素构建方式的规则称为 语法。一个 语法错误 当你违反语言的语法规则时发生。

注释 允许程序员在代码中留下注释。C++支持两种注释：行注释以 // 并持续到行尾。块注释以 /* 并直到配对的 */ 符号。不要嵌套块注释。

你可以使用注释临时禁用代码的行或部分。这称为注释掉代码。

数据 是任何可以由计算机移动、处理或存储的信息。单个数据称为 值。常见的值示例包括字母（例如 a）、数字（例如 5）和文本（例如 Hello)。

变量是一块命名的内存，我们可以用它来存储值。要创建变量，我们使用一种称为 定义语句。当程序运行时，每个定义的变量都会被 实例化，这意味着它被分配了一个内存地址。

一个 数据类型 告诉编译器如何将一段数据解释为有意义的值。一个 数 是可以不带小数部分书写的数字，例如4、27、0、-2或-12。

拷贝赋值 （通过 operator=）可用于给已创建的变量赋值。

为对象指定初始值的过程称为 初始化，而用于初始化对象的语法称为 初始化器。

简化来说，C++支持6种基本的初始化类型：

初始化类型示例备注
默认初始化int x;在大多数情况下，变量保留不确定的值
复制初始化int x = 5;
直接初始化int x ( 5 );
直接列表初始化int x { 5 };禁止窄化转换
拷贝列表初始化int x = { 5 };禁止窄化转换
值初始化int x {};通常执行零初始化

直接初始化有时被称为括号初始化，列表初始化（包括值初始化）有时被称为统一初始化或花括号初始化。你应该优先使用花括号初始化而非其他初始化形式，并优先使用初始化而非赋值。

虽然你可以在一条语句中定义多个变量，但最好在单独的语句中每行定义并初始化每个变量。

std::cout 和 operator<< 允许我们将表达式的结果输出到控制台。

std::endl 输出一个换行符，强制控制台光标移动到下一行，并刷新所有待输出的内容到控制台。 '\n' 字符也会输出一个换行符，但让系统决定何时刷新输出。注意不要使用 '/n' （正斜杠）。

std::cin 和 operator>> 允许我们从键盘获取一个值。

未赋值的变量称为 未初始化变量。尝试获取未初始化变量的值会导致 未定义行为，可能以多种方式表现出来。

C++ 保留了一组称为 关键字。这些名称在语言中具有特殊含义，不能用作变量名。

一个 字面常量 是一个直接插入到源代码中的固定值。例如 5 和 “Hello world!”。

一种 运算 是一个涉及零个或多个输入值的过程，这些输入值称为 操作数。要执行的具体操作由提供的 operator。操作的结果产生一个输出值。

一元 运算符需要一个操作数。 二元 运算符需要两个操作数，通常称为左操作数和右操作数。 三元 运算符需要三个操作数。 零元 运算符需要零个操作数。

一种 表达式 是一个由字面量、变量、运算符和函数调用组成的序列，经过求值产生一个输出值。这个输出值的计算称为 求值。产生的值就是 结果 表达式的结果。

一种 表达式语句 是一个表达式，通过在表达式末尾放置分号将其转换为语句。

编写程序时，添加几行代码或一个函数，编译，解决所有错误，并确保其正常工作。不要等到编写完整个程序才第一次编译！

专注于让代码正常工作。一旦确定要保留某段代码，就可以花时间删除（或注释掉）临时/调试代码、添加注释、处理错误情况、格式化代码、确保遵循最佳实践、删除冗余逻辑等……

初稿程序通常杂乱且不完美。大多数代码需要清理和优化才能变得优秀！

小测验时间

问题 #1

初始化和赋值有什么区别？一个变量可以被初始化或赋值多少次？

显示答案

初始化（在创建时）为变量提供初始值。赋值在变量定义后给变量一个新值。

由于变量只创建一次，它只能被初始化一次。变量可以按需赋值任意多次。

问题 #2

未定义行为何时发生？未定义行为的后果是什么？

显示答案

当程序员做了C++语言未明确指定的事情时，就会发生未定义行为。后果几乎可以是任何情况，从崩溃到产生错误答案，再到仍然正常工作。

问题 #3

编写一个程序，要求用户输入一个数字，然后输入第二个数字。程序应告诉用户这两个数字相加和相减的结果。

程序的输出应与以下内容匹配（假设输入为6和4）：

Enter an integer: 6
Enter another integer: 4
6 + 4 is 10.
6 - 4 is 2.

提示：若要打印句点和换行符，请使用 ".\n"，而不是 '.\n'。

显示答案

#include <iostream>

int main()
{
	std::cout << "Enter an integer: ";
	int x{};
	std::cin >> x;

	std::cout << "Enter another integer: ";
	int y{};
	std::cin >> y;

	std::cout << x << " + " << y << " is " << x + y << ".\n";
	std::cout << x << " - " << y << " is " << x - y << ".\n";

	return 0;
}
