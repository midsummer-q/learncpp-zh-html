章节回顾

将值从一种数据类型转换为另一种数据类型的过程称为 类型转换。

隐式类型转换 （也称为 自动类型转换 或 强制转换）在期望一种数据类型但提供了另一种数据类型时执行。如果编译器知道如何在两种类型之间进行转换，它就会进行转换。如果不知道，则会编译失败并报错。

C++语言在其基本类型之间定义了许多内置转换（以及一些更高级类型的转换），称为 标准转换。这些包括数值提升、数值转换和算术转换。

一个 数值提升 是将某些较小的数值类型转换为某些较大的数值类型（通常是 int 或 double），以便CPU可以操作与处理器自然数据大小匹配的数据。数值提升包括整型提升和浮点提升。数值提升是 保持值，意味着没有值或精度的损失。并非所有拓宽转换都是提升。

一个 数值转换 是不是数值提升的基本类型之间的类型转换。 窄化转换 是可能导致值或精度损失的数值转换。

在C++中，某些二元运算符要求其操作数具有相同类型。如果提供了不同类型的操作数，则一个或两个操作数将使用一组称为 常用算术转换。

显式类型转换 的规则隐式转换为匹配类型。当程序员通过强制转换显式请求转换时，执行 强制转换 表示程序员请求进行显式类型转换。C++支持5种类型的强制转换： C-style casts， static casts， const casts， dynamic casts、和 reinterpret casts。通常应避免 C-style casts， const casts、和 reinterpret casts。 static_cast 用于将值从一种类型转换为另一种类型的值，并且是C++中最常用的强制转换。

Typedefs 和 类型别名 允许程序员为数据类型创建别名。这些别名不是新类型，并且与被别名的类型行为相同。Typedef和类型别名不提供任何类型安全，需要注意不要假设别名与其别名的类型不同。

浮点类型的 auto 关键字有多种用途。首先，auto可用于 类型推导 （也称为 （有时也称为），它将从初始化器推导变量的类型。类型推导会丢弃const和引用，因此如果需要，请务必添加它们。

Auto也可以用作函数返回类型，让编译器从函数的返回语句推断函数的返回类型，但对于普通函数应避免这样做。Auto用作 尾随返回语法。

小测验时间

问题 #1

在以下每种情况下会发生什么类型的转换？有效答案：无需转换、数值提升、数值转换、因窄化转换无法编译。假设 int 和 long 都是4字节。

int main()
{
    int a { 5 }; // 1a
    int b { 'a' }; // 1b
    int c { 5.4 }; // 1c
    int d { true }; // 1d
    int e { static_cast<int>(5.4) }; // 1e

    double f { 5.0f }; // 1f
    double g { 5 }; // 1g

    // 额外加分部分
    long h { 5 }; // 1h

    float i { f }; // 1i（使用之前定义的变量 f）
    float j { 5.0 }; // 1j

}

1a) 显示答案

无需转换

1b) 显示答案

char 'a' 到 int 的数值提升

1c) 显示答案

因窄化转换无法编译

1d) 显示答案

bool true 到 int 的数值提升

1e) 显示答案

double 5.4 到 int 的数值转换

1f) 显示答案

float 到 double 的数值提升

1g) 显示答案

int 到 double 的数值转换

1h) 显示答案

int 到 long 的数值转换（此转换是平凡的，但仍然是一种转换）

1i) 显示答案

因 double 到 float 的窄化转换无法编译

1j) 显示答案

将 double 数值转换为 float（这是允许的，因为 5.0 是 constexpr 且在 float 的范围内）

问题 #2

2a) 更新以下程序，使用类型别名表示度和弧度值：

#include <iostream>

namespace constants
{
    constexpr double pi { 3.14159 };
}

double convertToRadians(double degrees)
{
    return degrees * constants::pi / 180;
}

int main()
{
    std::cout << "Enter a number of degrees: ";
    double degrees{};
    std::cin >> degrees;

    double radians { convertToRadians(degrees) };
    std::cout << degrees << " degrees is " << radians << " radians.\n";

    return 0;
}

显示答案

#include <iostream>

namespace constants
{
    constexpr double pi{ 3.14159 };
}

using Degrees = double;
using Radians = double;

Radians convertToRadians(Degrees degrees)
{
    return degrees * constants::pi / 180;
}

int main()
{
    std::cout << "Enter a number of degrees: ";
    Degrees degrees{};
    std::cin >> degrees;

    Radians radians{ convertToRadians(degrees) };
    std::cout << degrees << " degrees is " << radians << " radians.\n";

    return 0;
}

2b) 给定上一个测验解答中的 degrees 和 radians 定义，解释以下语句能否编译：

radians = degrees;

显示答案

它能编译。 radians 的类型为 Radians，它是 double。 degrees 的类型为 Degrees的类型别名，而 double也是 double 的类型别名。所以这只是一个 double。
