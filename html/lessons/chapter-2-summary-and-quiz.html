章节回顾

一个 函数 是一个可重用的语句序列，用于完成特定任务。你自己编写的函数称为 用户定义的 函数。

一个 函数调用 是一个告诉CPU执行函数的表达式。发起函数调用的函数是 调用者，而被调用的函数是 被调用者 或 调用 函数。进行函数调用时不要忘记包含圆括号。

函数定义中的花括号和语句称为 函数体。

返回值的函数被称为 返回值函数。这些 返回类型 函数的返回类型指示函数将返回的值的类型。该 return语句 决定具体的 返回值 返回给调用者的值。返回值从函数复制回调用者——这个过程称为 按值返回。如果非void函数未能返回值，将导致未定义行为。

函数的返回值 main 被称为 状态码，它告诉操作系统（以及任何调用你程序的其他程序）你的程序是否成功执行。按共识，返回值为0表示成功，非零返回值表示失败。

实践 DRY 编程——“不要重复自己”。利用变量和函数消除冗余代码。

返回类型为 void 的函数不会向调用者返回值。不返回值的函数称为 void函数 或 非返回值函数。void函数不能在需要值的地方被调用。

不是函数中最后一条语句的返回语句称为 提前返回。这样的语句会导致函数立即返回到调用者。

一个 函数参数 是函数中的一个变量，其值由函数的调用者提供。一个 实参 是从调用者传递给函数的具体值。当实参被复制到形参时，这称为 按值传递。

函数形参和函数体内定义的变量称为 局部变量。变量存在的时间称为其 生命周期。变量在 运行时时创建和销毁，即程序运行时。变量的 作用域 决定它在哪里可以被看到和使用。当一个变量可以被看到和使用时，我们说它处于 在作用域内。当它不能被看到时，就不能被使用，我们说它处于 超出作用域。作用域是一个 编译时 属性，意味着它在编译时强制执行。

空白字符 指用于格式化目的的字符。在C++中，这包括空格、制表符和换行符。

一个 前向声明 允许我们在实际定义标识符之前告诉编译器该标识符的存在。要编写函数的前向声明，我们使用 函数原型，它包括函数的返回类型、名称和形参，但没有函数体，后面跟一个分号。

一个 定义 实际上实现了（对于函数和类型）或实例化了（对于变量）一个标识符。一个 声明 是一条告诉编译器关于标识符存在的语句。在C++中，所有定义都兼作声明。 纯声明 是那些不是定义但仍是声明的声明（例如函数原型）。

大多数非平凡的程序都包含多个文件。

当两个标识符被引入同一程序，且编译器或链接器无法区分它们时，编译器或链接器会因为一个 名称碰撞。一个 命名空间 保证命名空间内的所有标识符都是唯一的。std 命名空间就是这样一个命名空间。

浮点类型的 预处理器 是在代码编译之前对其运行的一个过程。 指令 是给预处理器特殊的指令。指令以 # 符号开头，以换行结束。一个 宏 是一个定义如何将输入文本转换为替换输出文本的规则。

头文件 是设计用来将声明传播到代码文件的文件。当使用 #include 指令时， #include 指令会被所包含文件的内容替换。当包含头文件时，包含系统头文件（例如 C++ 标准库中的头文件）时使用尖括号，包含用户定义的头文件（你编写的那些）时使用双引号。包含系统头文件时，如果存在不带 .h 扩展名的版本，则使用这些版本。

头文件卫士 防止头文件的内容被多次包含到同一个代码文件中。它们不会阻止头文件的内容被包含到多个不同的代码文件中。

小测验时间

务必使用编辑器的自动格式化功能来保持格式一致，使代码更易读。

问题 #1

编写一个单文件程序（命名为 main.cpp），从用户处读取两个独立的整数，将它们相加，然后输出答案。该程序应使用三个函数：

  • 一个名为“readNumber”的函数应被用来从用户处获取（并返回）一个整数。
  • 一个名为“writeAnswer”的函数应被用来输出答案。该函数应接受一个参数且没有返回值。
  • 应使用一个 main() 函数将上述函数粘合在一起。

显示提示

提示：你不需要编写单独的函数来执行加法（直接使用 operator+ 即可）。

显示提示

提示：你需要调用 readNumber() 两次。

显示答案

main.cpp:

#include <iostream>

int readNumber()
{
    std::cout << "Enter a number to add: ";
    int x {};
    std::cin >> x;
    return x;
}

void writeAnswer(int x)
{
    std::cout << "The answer is " << x << '\n';
}

int main()
{
    int x { readNumber() };
    int y { readNumber() };
    writeAnswer(x + y); // 使用 operator+ 将 x 和 y 的和传递给 writeAnswer()
    return 0;
}

问题 #2

修改你在练习 #1 中编写的程序，使得 readNumber() 和 writeAnswer() 位于一个名为“io.cpp”的单独文件中。使用前向声明从 main() 中访问它们。

如果你遇到问题，请确保“io.cpp”已正确添加到你的项目中以便它被编译。

显示答案

io.cpp:

#include <iostream>

int readNumber()
{
    std::cout << "Enter a number to add: ";
    int x {};
    std::cin >> x;
    return x;
}

void writeAnswer(int x)
{
    std::cout << "The answer is " << x << '\n';
}

main.cpp:

// 我们不需要 #include <iostream>，因为 main.cpp 没有使用任何输入/输出功能

// 这些是 io.cpp 中函数的前向声明
int readNumber();
void writeAnswer(int x);

int main()
{
    int x { readNumber() };
    int y { readNumber() };
    writeAnswer(x+y);
    return 0;
}

问题 #3

修改你在第2题中编写的程序，使其使用头文件（名为io.h）来访问函数，而不是直接在代码（.cpp）文件中使用前向声明。确保你的头文件使用了头文件保护。

显示答案

io.h:

#ifndef IO_H
#define IO_H

int readNumber();
void writeAnswer(int x);

#endif

io.cpp:

#include "io.h"
#include <iostream>

int readNumber()
{
    std::cout << "Enter a number to add: ";
    int x {};
    std::cin >> x;
    return x;
}

void writeAnswer(int x)
{
    std::cout << "The answer is " << x << '\n';
}

main.cpp:

#include "io.h"

int main()
{
    int x { readNumber() };
    int y { readNumber() };
    writeAnswer(x+y);
    return 0;
}

虽然从技术上讲 io.cpp 不需要包含 io.h，但最佳实践是代码文件应包含其配对头文件。 2.11 -- 头文件。

如果你编译程序并得到类似以下的错误之一：

unresolved external symbol "int __cdecl readNumber(void)" (?readNumber@@YAHXZ)
undefined reference to `readNumber()'

那么你可能忘记包含 io.cpp 到你的项目中，所以定义 readNumber() （以及 writeAnswer()）没有被编译进你的项目。
