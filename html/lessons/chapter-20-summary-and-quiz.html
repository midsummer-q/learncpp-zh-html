章节回顾

又一章结束了！只剩下这个烦人的测验要过……

函数参数可以通过值、引用或地址传递。对于基本数据类型和枚举器，使用按值传递。对于结构体、类，或者当函数需要修改参数时，使用按引用传递。对于传递指针或内置数组，使用按地址传递。尽可能将按引用和按地址的参数设为 const。

值可以通过值、引用或地址返回。大多数情况下，按值返回就可以了，但当处理动态分配的数据、结构体或类时，按引用或地址返回可能很有用。如果按引用或地址返回，请记住确保不会返回即将超出作用域的内容。

函数指针允许我们将一个函数传递给另一个函数。这对于允许调用者自定义函数的行为（例如列表排序的方式）非常有用。

动态内存分配在堆上。

调用栈跟踪从程序开始到当前执行点所有活跃的函数（那些已被调用但尚未终止的函数）。局部变量分配在栈上。栈的大小有限。std::vector 可用于实现类似栈的行为。

递归函数是调用自身的函数。所有递归函数都需要一个终止条件。

命令行参数允许用户或其他程序在启动时将数据传入我们的程序。命令行参数始终是 C 风格字符串，如果需要数值，必须转换为数字。

省略号允许你向函数传递可变数量的参数。但是，省略号参数会暂停类型检查，并且不知道传递了多少个参数。由程序来跟踪这些细节。

Lambda 函数是可以嵌套在其他函数内部的函数。它们不需要名称，并且与算法库结合使用时非常有用。

显示答案

// 注意：在这种情况下，array 不能是 const，因为返回对 const 元素的非 const 引用将违反 const 规则。
int& getLargestElement(int* array, int length);

问题 #2

这些程序有什么问题？

a)

int& doSomething()
{
    int array[]{ 1, 2, 3, 4, 5 };
    return array[3];
}

显示答案

doSomething() 返回一个对局部变量的引用，该变量将在 doSomething 终止时被销毁。

b)

int sumTo(int value)
{
    return value + sumTo(value - 1);
}

显示答案

函数 sumTo() 没有终止条件。变量 value 最终会变为负数，函数将无限循环直到栈溢出。

c)

float divide(float x, float y)
{
    return x / y;
}

double divide(float x, float y)
{
    return x / y;
}

显示答案

两个 divide 函数没有区别，因为它们具有相同的名称和相同的参数。此外，还存在潜在的除以 0 的问题。

d)

#include <iostream>

int main()
{
    int array[100000000]{};

    for (auto x: array)
        std::cout << x << ' ';

    std::cout << '\n';

    return 0;
}

显示答案

数组太大，无法在栈上分配。应该动态分配。

e)

#include <iostream>

int main(int argc, char* argv[])
{
    int age{ argv[1] };
    std::cout << "The user's age is " << age << '\n';

    return 0;
}

显示答案

argv[1] 可能不存在。如果存在，argv[1] 是一个字符串参数，不能通过赋值转换为整数。

问题 #3

确定排序数组中是否存在某个值的最佳算法称为二分查找。

二分查找的工作原理如下：

  • 查看数组的中间元素（如果数组有偶数个元素，则向下取整）。
  • 如果中间元素大于目标元素，则丢弃数组的上半部分（或在下半部分上递归）。
  • 如果中间元素小于目标元素，则丢弃数组的下半部分（或在上半部分上递归）。
  • 如果中间元素等于目标元素，则返回中间元素的索引。
  • 如果丢弃了整个数组仍未找到目标元素，则返回一个表示“未找到”的标记（在本例中，我们使用 -1，因为它是一个无效的数组索引）。

因为每次迭代我们可以丢弃一半的数组，所以这个算法非常快。即使是一个包含一百万个元素的数组，最多也只需要 20 次迭代就能确定值是否存在！然而，它只适用于排序数组。

修改数组（例如丢弃数组的一半元素）代价高昂，因此通常我们不修改数组。相反，我们使用两个整数（min 和 max）来保存我们感兴趣检查的数组的最小和最大元素的索引。

让我们看一个该算法如何工作的示例，给定数组 { 3, 6, 7, 9, 12, 15, 18, 21, 24 }，目标值为 7。最初，min = 0，max = 8，因为我们搜索整个数组（数组长度为 9，所以最后一个元素的索引是 8）。

  • 第 1 轮）我们计算 min (0) 和 max (8) 的中点，即 4。元素 #4 的值为 12，大于我们的目标值。因为数组已排序，我们知道所有索引大于或等于中点 (4) 的元素都太大。所以我们保持 min 不变，并将 max 设为 3。
  • 第 2 轮）我们计算 min (0) 和 max (3) 的中点，即 1。元素 #1 的值为 6，小于我们的目标值。因为数组已排序，我们知道所有索引小于或等于中点 (1) 的元素都太小。所以我们设置 min 为 2，并保持 max 不变。
  • 第 3 轮）我们计算 min (2) 和 max (3) 的中点，即 2。元素 #2 的值为 7，正是我们的目标值。所以我们返回 2。

在 C++20 中，可以通过调用 std::midpoint来计算中点。在 C++20 之前，你需要自己计算中点——在这种情况下，你可以使用 min + ((max - min) / 2) 来避免溢出（当 min 和 max 都为正时）。

a) 编写 binarySearch 函数的迭代版本。

提示：当 min 索引大于 max 索引时，你可以安全地说目标元素不存在。

显示答案

#include <cassert>
#include <iostream>
#include <numeric> // for std::midpoint

// array 是要搜索的数组。
// target 是我们试图确定是否存在的值。
// min 是我们要搜索的数组的下界索引。
// max 是我们要搜索的数组的上界索引。
// binarySearch() 应返回目标元素的索引（如果找到目标），否则返回 -1
int binarySearch(const int* array, int target, int min, int max)
{
    assert(array); // 确保数组存在

    while (min <= max)
    {
        // 以迭代方式实现此功能
        int midpoint{ std::midpoint(min, max) };
        // C++20 之前
        // int midpoint{ min + ((max-min) / 2) }; // 这种计算中点的方法避免了溢出

        if (array[midpoint] > target)
        {
            // 如果 array[midpoint] > target，那么我们知道该数字一定在数组的下半部分
            // 我们可以使用 midpoint - 1 作为上界索引，因为下次迭代时无需重新测试中点
            max = midpoint - 1;
        }
        else if (array[midpoint] < target)
        {
            // 如果 array[midpoint] < target，那么我们知道该数字一定在数组的上半部分
            // 我们可以使用 midpoint + 1 作为下界索引，因为下次迭代时无需重新测试中点
            min = midpoint + 1;
        }
        else
        {
            return midpoint;
        }
    }
    
    return -1;
}

b) 编写 binarySearch 函数的递归版本。

显示答案

#include <cassert>
#include <numeric> // for std::midpoint

// array 是要搜索的数组。
// target 是我们试图确定是否存在的值。
// min 是我们要搜索的数组的下界索引。
// max 是我们要搜索的数组的上界索引。
// binarySearch() 应返回目标元素的索引（如果找到目标），否则返回 -1
int binarySearch(const int* array, int target, int min, int max)
{
    assert(array); // 确保数组存在

    // 以递归方式实现此功能

    if (min > max)
        return -1;

    int midpoint{ std::midpoint(min, max) };
    // C++20 之前
    // int midpoint{ min + ((max-min) / 2) }; // 这种计算中点的方法避免了溢出

    if (array[midpoint] > target)
    {
        return binarySearch(array, target, min, midpoint - 1);
    }
    else if (array[midpoint] < target)
    {
        return binarySearch(array, target, midpoint + 1, max);
    }

    return midpoint;
}

std::binary_search 如果值存在于已排序列表中，则返回 true。
std::equal_range 返回指向具有给定值的第一个和最后一个元素的迭代器。
