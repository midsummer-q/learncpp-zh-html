23.x — 第23章 总结与测验

● 机器译文 课程 23.x 查看英文原文

在本章中，我们学习了两个对象之间几种不同的关系。

总结

从简单对象构建复杂对象的过程称为 对象组合。对象组合有两种类型：组合和聚合。

组合 当类的成员与类具有部分-整体关系时，就存在 组合的条件，对象和部分必须具有以下关系：

  • 部分（成员）是对象（类）的一部分
  • 部分（成员）一次只能属于一个对象（类）
  • 部分（成员）的存在由对象（类）管理
  • 部分（成员）不知道对象（类）的存在

组合通常通过普通成员变量或指针实现，其中类管理所有内存分配和释放。如果可以将类实现为组合，就应该将其实现为组合。

聚合 当类与成员具有has-a关系时，就存在 聚合，一个对象及其部分必须具有以下关系：

  • 部分（成员）是对象（类）的一部分
  • 部分（成员）可以同时属于多个对象（类）
  • 部分（成员）的 不是 存在不由对象（类）管理
  • 部分（成员）不知道对象（类）的存在

聚合通常通过指针或引用实现。

关联 是一种更松散的关系，其中类使用一个其他无关的对象。要成为 关联，一个对象和一个关联对象必须具有以下关系：

  • 关联对象（成员）与对象（类）原本无关
  • 关联对象（成员）可以同时属于多个对象（类）
  • 关联对象（成员）的 不是 存在不由对象（类）管理
  • 关联对象（成员）可能知道也可能不知道对象（类）的存在

关联可以通过指针或引用实现，也可以通过更间接的方式（例如持有关联对象的索引或键）实现。

在 依赖关系中，一个类使用另一个类来执行任务。依赖类通常不是使用它的类的成员，而是临时创建、使用然后销毁，或者从外部源传入成员函数。

在 容器类 一个类提供容器来保存另一种类型的多个对象。 值容器 是一种组合，它存储所持有对象的副本。 引用容器 是一种聚合，它存储指向容器外部对象的指针或引用。

std::initializer_list 可用于实现构造函数、赋值运算符以及其他接受列表初始化参数的函数。std::initializer_list 位于 <initializer_list> 头文件中。

小测验时间

本章相当直接，比前几章更抽象一些，所以这个测验会简短而切中要点。

  1. 以下描述属于哪种关系（组合、聚合、关联或依赖）？

1a) 一个 Animal 类，包含动物类型（枚举）和名称（字符串）。
显示答案

组合——动物类型和名称在 Animal 之外没有用途。

1b) 一个文本编辑器类，其 save() 函数接受一个 File 对象作为参数。save() 函数将编辑器内容写入磁盘。
显示答案

依赖——文本编辑器类使用 File 对象执行保存到磁盘的任务。

1c) 一个 Adventurer 类，可以携带各种类型的物品，例如剑、魔杖、药水或法术书。这些物品可以被其他 Adventurer 丢弃和拾取。
显示答案

关联——Adventurer 和物品不是整体-部分关系，所以这不是聚合。Adventurer 使用物品，但不管理它们的存在。

1d) 玩家在神龛祈祷（以获得新能力）。
显示答案

依赖——玩家依赖神龛获得能力，但与其没有长期关联。

1e) 一个 Computer 类，包含一个 CPU 类。CPU 可以从 Computer 中取出并单独测试。
显示答案

聚合——计算机拥有 CPU，但不管理其存在。

1f) 一个铁匠有一个特定的铁砧，他用来做他的工作。
显示答案

关联——铁匠使用铁砧，但与它没有整体-部分关系。
