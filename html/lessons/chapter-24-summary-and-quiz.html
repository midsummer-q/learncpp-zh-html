总结

继承允许我们在两个对象之间建模一种“是一个”关系。被继承的对象称为父类、基类或超类。执行继承的对象称为子类、派生类或子类。

当派生类继承基类时，派生类获得基类的所有成员。

当派生类被构造时，类的基类部分首先被构造，然后派生部分被构造。更详细地说：

  1. 为派生类分配内存（足够容纳基类和派生类两部分）。
  2. 调用适当的派生类构造函数。
  3. 首先使用适当的基类构造函数构造基类对象。如果没有指定基类构造函数，将使用默认构造函数。
  4. 派生类的初始化列表初始化派生类的成员。
  5. 执行派生类构造函数的主体。
  6. 控制权返回给调用者。

销毁按相反顺序进行，从最派生类到最基类。

C++ 有 3 个访问说明符：public、private 和 protected。protected 访问说明符允许成员所属的类、友元和派生类访问 protected 成员，但不允许公开访问。

类可以公开、私有或受保护地继承另一个类。类几乎总是公开继承。

以下是所有访问说明符和继承类型组合的表格：

基类中的访问说明符公有继承时的访问说明符私有继承时的访问说明符保护继承时的访问说明符
公有公有私有受保护
私有不可访问不可访问不可访问
受保护受保护私有受保护

派生类可以添加新函数，改变基类中存在的函数在派生类中的工作方式，更改继承成员的访问级别，或隐藏功能。

多重继承使派生类能够从多个父类继承成员。通常应避免多重继承，除非替代方案会导致更复杂的情况。

问题 #2

a) 编写一个 Apple 类和一个 Banana 类，它们派生自一个共同的 Fruit 类。Fruit 应该有两个成员：名称和颜色。

以下程序应能运行：

int main()
{
	Apple a{ "red" };
	Banana b{};

	std::cout << "My " << a.getName() << " is " << a.getColor() << ".\n";
	std::cout << "My " << b.getName() << " is " << b.getColor() << ".\n";
	
	return 0;
}

并产生结果：

My apple is red.
My banana is yellow.

显示答案

#include <iostream>
#include <string>
#include <string_view>

class Fruit
{
private:
	std::string m_name;
	std::string m_color;

public:
	Fruit(std::string_view name, std::string_view color)
		: m_name{ name }, m_color{ color }
	{
	}

	const std::string& getName() const { return m_name; }
	const std::string& getColor() const { return m_color; }
};

class Apple: public Fruit
{
public:
	Apple(std::string_view color="red")
		: Fruit{ "apple", color }
	{
	}
};

class Banana : public Fruit
{
public:
	Banana()
		: Fruit{ "banana", "yellow" }
	{
	}
};

int main()
{
	Apple a{ "red" };
	Banana b;

	std::cout << "My " << a.getName() << " is " << a.getColor() << ".\n";
	std::cout << "My " << b.getName() << " is " << b.getColor() << ".\n";
	
	return 0;
}

#include <iostream>
#include <string>
#include <string_view>

class Fruit
{
private:
	std::string m_name;
	std::string m_color;

public:
	Fruit(std::string_view name, std::string_view color)
		: m_name{ name }, m_color{ color }
	{
	}

	const std::string& getName() const { return m_name; }
	const std::string& getColor() const { return m_color; }
};

class Apple: public Fruit
{
// 我们之前用于 Apple 的构造函数有一个固定的名称（"apple"）。
// 我们需要一个新的构造函数供 GrannySmith 使用，以设置水果的名称

	Apple(std::string_view name, std::string_view color)
		: Fruit{ name, color }
	{
	}

public:
	Apple(std::string_view color="red")
		: Fruit{ "apple", color }
	{
	}
};

class Banana : public Fruit
{
public:
	Banana()
		: Fruit{ "banana", "yellow" }
	{
	}
};

class GrannySmith : public Apple
{
public:
	GrannySmith()
		: Apple{ "granny smith apple", "green" }
	{
	}
};

int main()
{
	Apple a{ "red" };
	Banana b;
	GrannySmith c;

	std::cout << "My " << a.getName() << " is " << a.getColor() << ".\n";
	std::cout << "My " << b.getName() << " is " << b.getColor() << ".\n";
	std::cout << "My " << c.getName() << " is " << c.getColor() << ".\n";

问题 #3

挑战时间！以下测验问题更难且更长。我们将编写一个简单的游戏，你在其中与怪物战斗。游戏的目标是在你死亡或达到 20 级之前尽可能多地收集金币。

我们的程序将由 3 个类组成：Creature 类、Player 类和 Monster 类。Player 和 Monster 都继承自 Creature。

a) 首先创建 Creature 类。Creature 有 5 个属性：名称（std::string）、符号（char）、生命值（int）、每次攻击造成的伤害（int）和携带的金币数量（int）。将这些实现为类成员。编写一整套 getter（每个成员一个 get 函数）。添加另外三个函数：void reduceHealth(int) 将 Creature 的生命值减少一个整数。bool isDead() 当 Creature 的生命值为 0 或更少时返回 true。void addGold(int) 向 Creature 添加金币。

以下程序应能运行：

#include <iostream>
#include <string>

int main()
{
	Creature o{ "orc", 'o', 4, 2, 10 };
	o.addGold(5);
	o.reduceHealth(1);
	std::cout << "The " << o.getName() << " has " << o.getHealth() << " health and is carrying " << o.getGold() << " gold.\n";

	return 0;
}

并产生结果：

The orc has 3 health and is carrying 15 gold.

显示答案

#include <iostream>
#include <string>
#include <string_view> // Requires C++17

class Creature
{
protected:
	std::string m_name;
	char m_symbol {};
	int m_health {};
	int m_damage {};
	int m_gold {};

public:
	Creature(std::string_view name, char symbol, int health, int damage, int gold)
		: m_name{ name }
		, m_symbol{ symbol }
		, m_health{ health }
		, m_damage{ damage }
		, m_gold{ gold }
	{
	}

	const std::string& getName() const { return m_name; }
	char getSymbol() const { return m_symbol; }
	int getHealth() const { return m_health; }
	int getDamage() const { return m_damage; }
	int getGold() const { return m_gold; }

	void reduceHealth(int health) { m_health -= health; }
	bool isDead() const { return m_health <= 0; }
	void addGold(int gold) { m_gold += gold; }
};

int main()
{
	Creature o{ "orc", 'o', 4, 2, 10 };
	o.addGold(5);
	o.reduceHealth(1);
	std::cout << "The " << o.getName() << " has " << o.getHealth() << " health and is carrying " << o.getGold() << " gold.\n";

	return 0;
}

b) 现在我们将创建 Player 类。Player 类继承自 Creature。Player 有一个额外的成员，即玩家的等级，从 1 开始。玩家有一个自定义名称（由用户输入），使用符号 '@'，有 10 点生命值，初始造成 1 点伤害，没有金币。编写一个名为 levelUp() 的函数，将玩家的等级和伤害增加 1。还要为等级成员编写一个 getter。最后，编写一个名为 hasWon() 的函数，如果玩家达到 20 级则返回 true。

编写一个新的 main() 函数，询问用户姓名并产生如下输出：

Enter your name: Alex
Welcome, Alex.
You have 10 health and are carrying 0 gold.

#include <iostream>
#include <string>
#include <string_view> // std::string_view requires C++17

class Creature
{
protected:
	std::string m_name;
	char m_symbol {};
	int m_health {};
	int m_damage {};
	int m_gold {};

public:
	Creature(std::string_view name, char symbol, int health, int damage, int gold)
		: m_name{ name }
		, m_symbol{ symbol }
		, m_health{ health }
		, m_damage{ damage }
		, m_gold{ gold }
	{
	}

	const std::string& getName() const { return m_name; }
	char getSymbol() const { return m_symbol; }
	int getHealth() const { return m_health; }
	int getDamage() const { return m_damage; }
	int getGold() const { return m_gold; }

	void reduceHealth(int health) { m_health -= health; }
	bool isDead() const { return m_health <= 0; }
	void addGold(int gold) { m_gold += gold; }
};

class Player : public Creature
{
	int m_level{ 1 };

public:
	Player(std::string_view name)
		: Creature{ name, '@', 10, 1, 0 }
	{
	}

	void levelUp()
	{
		++m_level;
		++m_damage;
	}

	int getLevel() const { return m_level; }
	bool hasWon() const { return m_level >= 20; }
};

int main()
{
	std::cout << "Enter your name: ";
	std::string playerName;
	std::cin >> playerName;

	Player p{ playerName };
	std::cout << "Welcome, " << p.getName() << ".\n";

	std::cout << "You have " << p.getHealth() << " health and are carrying " << p.getGold() << " gold.\n";

	return 0;
}

c) 接下来是 Monster 类。Monster 也继承自 Creature。Monster 没有非继承的成员变量。

首先，编写一个空的 Monster 类继承自 Creature，然后在 Monster 类内部添加一个名为 Type 的枚举，其中包含我们将在游戏中拥有的 3 个怪物的枚举器： dragon， orc、和 slime （你还需要一个 max_types 枚举值，因为稍后会用到）。

下一步是编写一个 Monster 构造函数，以便我们可以创建怪物。Monster 构造函数应接受一个 Type 枚举作为参数，然后根据该怪物类型创建具有相应属性的 Monster。

有多种方法可以实现这一点（有些更好，有些更差）。但在本例中，由于我们所有的怪物属性都是预定义的（不是随机的或针对每个生物定制的），我们可以使用查找表。我们的查找表将是一个 Creature 的 C 风格数组，其中使用 Type 索引数组将返回该 Type 对应的 Creature。

由于这个 Creature 表是 Monster 特有的，我们可以将其定义在 Monster 类内部，作为 static inline Creature monsterData[] { }，并用我们的 Creature 元素初始化。

然后我们的 Monster 构造函数就很简单了：我们可以调用 Creature 拷贝构造函数，并将 monsterData 表中对应的 Creature 传递给它。

以下程序应该能够编译：

#include <iostream>
#include <string>

int main()
{
	Monster m{ Monster::Type::orc };
	std::cout << "A " << m.getName() << " (" << m.getSymbol() << ") was created.\n";

	return 0;
}

并打印：

A orc (o) was created.

e) 最后，向 Monster 添加一个 static 函数，命名为 getRandomMonster()。该函数应从 0 切换到 max_types-1 中随机选择一个数字，并返回一个具有该 Type 的怪物（按值返回）（你需要 static_cast 该 int 转换为 Type 以将其传递给 Monster 构造函数）。

#include "Random.h" // https://www.learncpp.com/cpp-tutorial/global-random-numbers-random-h/
#include <array>
#include <iostream>
#include <string>
#include <string_view>
 
class Creature
{
protected:
    std::string m_name;
    char m_symbol {};
    int m_health {};
    int m_damage {};
    int m_gold {};
 
public:
     Creature(std::string_view name, char symbol, int health, int damage, int gold)
        : m_name{ name }
        , m_symbol{ symbol }
        , m_health{ health }
        , m_damage{ damage }
        , m_gold{ gold }
    { }
 
    char getSymbol() const { return m_symbol; }
    const std::string& getName() const { return m_name; }
    bool isDead() const { return m_health <= 0; }
    int getGold() const { return m_gold; }
    void addGold(int gold) { m_gold += gold; }
    void reduceHealth(int health) { m_health -= health; }
    int getHealth() const { return m_health; }
    int getDamage() const { return m_damage; }
};
 
class Player : public Creature
{
    int m_level{ 1 };
 
public:
    Player(const std::string& name)
        : Creature{ name, '@', 10, 1, 0 }
    {
    }
 
    void levelUp()
    {
        ++m_level;
        ++m_damage;
    }
 
    int getLevel() const { return m_level; }
    bool hasWon() const { return m_level >= 20; }
};
 
class Monster : public Creature
{
public:
    enum Type
    {
        dragon,
        orc,
        slime,
        max_types
    };
 
private:
    inline static Creature monsterData[] {
        Creature { "dragon", 'D', 20, 4, 100 },
        Creature { "orc", 'o', 4, 2, 25 },
        Creature { "slime", 's', 1, 1, 10 }
        };

    static_assert(std::size(monsterData) == max_types);

public:
    Monster(Type type)
        : Creature{ monsterData[type] }
    {
    }
 
    static Monster getRandomMonster()
    {
        int num{ Random::get(0, max_types - 1) };
        return Monster{ static_cast<Type>(num) };
    }
};
 
int main()
{
    for (int i{ 0 }; i < 10; ++i)
    {
        Monster m{ Monster::getRandomMonster() };
        std::cout << "A " << m.getName() << " (" << m.getSymbol() << ") was created.\n";
    }
 
  return 0;
}

f) 我们终于可以编写游戏逻辑了！

以下是游戏规则：

玩家每次遇到一个随机生成的怪物。
对于每个怪物，玩家有两个选择：(R)逃跑或(F)战斗。
如果玩家决定逃跑，他们有50%的几率成功逃脱。
如果玩家逃脱，他们进入下一次遭遇，没有不良影响。
如果玩家没有逃脱，怪物获得一次免费攻击，然后玩家选择下一个行动。
如果玩家选择战斗，玩家先攻击。怪物的生命值减少玩家伤害值。
如果怪物死亡，玩家拿走怪物携带的所有金币。玩家还会升级，等级和伤害各增加1。
如果怪物没有死亡，怪物反击玩家。玩家的生命值减少怪物伤害值。
游戏在玩家死亡（失败）或达到20级（胜利）时结束。
如果玩家死亡，游戏应告诉玩家他们当时的等级和拥有的金币数量。
如果玩家获胜，游戏应告诉玩家他们赢了，以及拥有的金币数量。

提示：创建4个函数：

  • main()函数应处理游戏设置（创建玩家）和主游戏循环。
  • fightMonster()处理玩家与单个怪物之间的战斗，包括询问玩家想做什么，处理逃跑或战斗的情况。
  • attackMonster()处理玩家攻击怪物，包括升级。
  • attackPlayer()处理怪物攻击玩家。

#include "Random.h" // https://www.learncpp.com/cpp-tutorial/global-random-numbers-random-h/
#include <array>
#include <iostream>
#include <string>
#include <string_view>
 
class Creature
{
protected:
    std::string m_name;
    char m_symbol {};
    int m_health {};
    int m_damage {};
    int m_gold {};
 
public:
     Creature(std::string_view name, char symbol, int health, int damage, int gold)
        : m_name{ name }
        , m_symbol{ symbol }
        , m_health{ health }
        , m_damage{ damage }
        , m_gold{ gold }
    { }
 
    char getSymbol() const { return m_symbol; }
    const std::string& getName() const { return m_name; }
    bool isDead() const { return m_health <= 0; }
    int getGold() const { return m_gold; }
    void addGold(int gold) { m_gold += gold; }
    void reduceHealth(int health) { m_health -= health; }
    int getHealth() const { return m_health; }
    int getDamage() const { return m_damage; }
};
 
class Player : public Creature
{
    int m_level{ 1 };
 
public:
    Player(const std::string& name)
        : Creature{ name, '@', 10, 1, 0 }
    {
    }
 
    void levelUp()
    {
        ++m_level;
        ++m_damage;
    }
 
    int getLevel() const { return m_level; }
    bool hasWon() const { return m_level >= 20; }
};
 
class Monster : public Creature
{
public:
    enum Type
    {
        dragon,
        orc,
        slime,
        max_types
    };
 
private:
    inline static Creature monsterData[] {
        Creature { "dragon", 'D', 20, 4, 100 },
        Creature { "orc", 'o', 4, 2, 25 },
        Creature { "slime", 's', 1, 1, 10 }
        };

    static_assert(std::size(monsterData) == max_types);

public:
    Monster(Type type)
        : Creature{ monsterData[type] }
    {
    }
 
    static Monster getRandomMonster()
    {
        int num{ Random::get(0, max_types - 1) };
        return Monster{ static_cast<Type>(num) };
    }
};
 
// 此函数处理玩家攻击怪物
void attackMonster(Player& player, Monster& monster)
{
    // 如果玩家死亡，则无法攻击怪物
    if (player.isDead())
        return;

    std::cout << "You hit the " << monster.getName() << " for " << player.getDamage() << " damage.\n";

    // 减少怪物的生命值，减少量为玩家的伤害值
    monster.reduceHealth(player.getDamage());

    // 如果怪物现在死亡，则提升玩家等级
    if (monster.isDead())
    {
        std::cout << "You killed the " << monster.getName() << ".\n";
        player.levelUp();
        std::cout << "You are now level " << player.getLevel() << ".\n";
        std::cout << "You found " << monster.getGold() << " gold.\n";
        player.addGold(monster.getGold());
    }
}

// 此函数处理怪物攻击玩家
void attackPlayer(const Monster& monster, Player& player)
{
    // 如果怪物死亡，则无法攻击玩家
    if (monster.isDead())
        return;

    // 减少玩家的生命值，减少量为怪物的伤害值
    player.reduceHealth(monster.getDamage());
    std::cout << "The " << monster.getName() << " hit you for " << monster.getDamage() << " damage.\n";
}

// 此函数处理玩家与随机生成的怪物之间的整个战斗
void fightMonster(Player& player)
{
    // 首先随机生成一个怪物
    Monster monster{ Monster::getRandomMonster() };
    std::cout << "You have encountered a " << monster.getName() << " (" << monster.getSymbol() << ").\n";

    // 当怪物未死亡且玩家未死亡时，战斗继续
    while (!monster.isDead() && !player.isDead())
    {
        std::cout << "(R)un or (F)ight: ";
        char input{};
        std::cin >> input;
        if (input == 'R' || input == 'r')
        {
            // 50% 的概率成功逃跑
            if (Random::get(1, 2) == 1)
            {
                std::cout << "You successfully fled.\n";
                return; // 成功则结束遭遇
            }
            else
            {
                // 逃跑失败会使怪物获得一次免费攻击玩家的机会
                std::cout << "You failed to flee.\n";
                attackPlayer(monster, player);
                continue;
            }
        }

        if (input == 'F' || input == 'f')
        {
            // 玩家先攻击，怪物后攻击
            attackMonster(player, monster);
            attackPlayer(monster, player);
        }
    }
}

int main()
{
    std::cout << "Enter your name: ";
    std::string playerName;
    std::cin >> playerName;

    Player player{ playerName };
    std::cout << "Welcome, " << player.getName() << '\n';

    // 如果玩家未死亡且尚未获胜，则游戏继续
    while (!player.isDead() && !player.hasWon())
        fightMonster(player);

    // 此时，玩家要么死亡，要么获胜
    if (player.isDead())
    {
        std::cout << "You died at level " << player.getLevel() << " and with " << player.getGold() << " gold.\n";
        std::cout << "Too bad you can't take it with you!\n";
    }
    else
    {
        std::cout << "You won the game with " << player.getGold() << " gold!\n";
    }

  return 0;
}

类型效果（小）效果（中）效果（大）
生命值+2 生命值+2 生命值+5 生命值
力量+1 伤害+1 伤害+1 伤害
毒药-1 生命值-1 生命值-1 生命值

玩家在每次获胜战斗后有30%的几率找到一瓶药水，并可以选择喝或不喝。如果玩家不喝，药水就会消失。玩家在喝下药水之前不知道找到了什么类型的药水，喝下时药水的类型和大小会揭示，并应用效果。

提示：添加一个 Potion 类，该类具有 type 和 size 成员变量，以及一个返回其名称的成员函数和一个创建随机 Potion 的静态成员函数，类似于 getRandomMonster() 函数。
在 Player 类中，添加一个 drinkPotion() 成员函数，用于应用药水的效果。

显示答案

#include "Random.h" // https://www.learncpp.com/cpp-tutorial/global-random-numbers-random-h/
#include <array>
#include <iostream>
#include <sstream>
#include <string>
#include <string_view>

class Potion
{
public:
    // 所有可能的药水类型
    enum Type
    {
        health,
        strength,
        poison,

        // 用于随机生成药水
        max_type
    };

    enum Size
    {
        small,
        medium,
        large,

        max_size
    };


private:
    Type m_type{};
    Size m_size{};

public:
    Potion(Type type, Size size)
        : m_type{ type },
        m_size{ size }
    {
    }

    Type getType() const { return m_type; }
    Size getSize() const { return m_size; }

    // 药水的名称是编译时常量，我们可以
    // 返回一个 std::string_view。
    static std::string_view getPotionTypeName(Type type)
    {
        static constexpr std::string_view names[] {
          "Health",
          "Strength",
          "Poison"
        };

        return names[type];
    }

    static std::string_view getPotionSizeName(Size size)
    {
        static constexpr std::string_view names[] {
          "Small",
          "Medium",
          "Large"
        };

        return names[size];
    }

    std::string getName() const
    {
        // 我们使用 std::stringstream，但也可以使用
        // std::string 来解决。
        // 我们首次在课程 7.13 中使用 std::stringstream。
        std::stringstream result{};

        result << getPotionSizeName(getSize()) << " potion of " << getPotionTypeName(getType());

        // 我们可以通过使用 str() 成员函数从 std::stringstream 中提取字符串。
        // 成员函数。
        return result.str();
    }

    static Potion getRandomPotion()
    {
        return Potion{
          static_cast<Type>(Random::get(0, max_type - 1)),
          static_cast<Size>(Random::get(0, max_size - 1))
        };
    }
};

class Creature
{
protected:
    std::string m_name;
    char m_symbol {};
    int m_health {};
    int m_damage {};
    int m_gold {};
 
public:
     Creature(std::string_view name, char symbol, int health, int damage, int gold)
        : m_name{ name }
        , m_symbol{ symbol }
        , m_health{ health }
        , m_damage{ damage }
        , m_gold{ gold }
    { }
 
    char getSymbol() const { return m_symbol; }
    const std::string& getName() const { return m_name; }
    bool isDead() const { return m_health <= 0; }
    int getGold() const { return m_gold; }
    void addGold(int gold) { m_gold += gold; }
    void reduceHealth(int health) { m_health -= health; }
    int getHealth() const { return m_health; }
    int getDamage() const { return m_damage; }
};
 
class Player : public Creature
{
    int m_level{ 1 };
 
public:
    Player(const std::string& name)
        : Creature{ name, '@', 10, 1, 0 }
    {
    }
 
    void levelUp()
    {
        ++m_level;
        ++m_damage;
    }

    // 将药水的效果应用于玩家
    void drinkPotion(const Potion& potion)
    {
        switch (potion.getType())
        {
        case Potion::health:
            // 只有治疗药水的大小会影响其效力。所有其他
            // 药水与大小无关。
            m_health += ((potion.getSize() == Potion::large) ? 5 : 2);
            break;
        case Potion::strength:
            ++m_damage;
            break;
        case Potion::poison:
            reduceHealth(1);
            break;
            // 处理 max_type 以消除编译器警告。不要使用 default：
            // 因为我们希望编译器在我们添加新药水但
            // 忘记实现其效果时发出警告。
        case Potion::max_type:
            break;
        }
    }

    int getLevel() const { return m_level; }
    bool hasWon() const { return m_level >= 20; }
};
 
class Monster : public Creature
{
public:
    enum Type
    {
        dragon,
        orc,
        slime,
        max_types
    };
 
private:
    inline static Creature monsterData[] {
        Creature { "dragon", 'D', 20, 4, 100 },
        Creature { "orc", 'o', 4, 2, 25 },
        Creature { "slime", 's', 1, 1, 10 }
        };

    static_assert(std::size(monsterData) == max_types);

public:
    Monster(Type type)
        : Creature{ monsterData[type] }
    {
    }
 
    static Monster getRandomMonster()
    {
        int num{ Random::get(0, max_types - 1) };
        return Monster{ static_cast<Type>(num) };
    }
};

// 我们将其移出 attackMonster() 以保持函数更短。
void onMonsterKilled(Player& player, const Monster& monster)
{
    std::cout << "You killed the " << monster.getName() << ".\n";
    player.levelUp();
    std::cout << "You are now level " << player.getLevel() << ".\n";
    std::cout << "You found " << monster.getGold() << " gold.\n";
    player.addGold(monster.getGold());

    // 30% 几率找到药水
    constexpr int potionChance{ 30 };
    if (Random::get(1, 100) <= potionChance)
    {
        // 生成随机药水
        auto potion{ Potion::getRandomPotion() };

        std::cout << "You found a mythical potion! Do you want to drink it? [y/n]: ";
        char choice{};
        std::cin >> choice;

        if (choice == 'Y' || choice == 'y')
        {

        }
    }
}
