至此，我们关于C++继承和虚函数的旅程告一段落。亲爱的读者，请不要担心，前方还有众多C++的其他领域等待我们去探索。

章节总结

C++允许将基类指针和引用设置为指向派生类对象。当我们希望编写一个函数或数组，能够处理从基类派生的任何类型的对象时，这非常有用。

如果没有虚函数，指向派生类的基类指针和引用将只能访问基类的成员变量和函数版本。

虚函数是一种特殊类型的函数，它会解析为基类和派生类之间存在的派生程度最高的函数版本（称为覆盖）。要被视为覆盖，派生类函数必须与虚基类函数具有相同的签名和返回类型。协变返回类型是一个例外，它允许覆盖在基类函数返回指向基类的指针或引用时，返回指向派生类的指针或引用。

旨在成为覆盖的函数应使用 override 说明符，以确保它确实是覆盖。

final 说明符可用于防止对函数的覆盖或从类继承。

如果你打算使用继承，应将析构函数设为虚函数，这样当删除指向基类的指针时，会调用正确的析构函数。

你可以通过使用作用域解析运算符直接指定要使用的类的函数版本来忽略虚解析，例如： base.Base::getName()。

当编译器遇到直接函数调用时，会发生早期绑定。编译器或链接器可以直接解析这些函数调用。当调用函数指针时，会发生晚期绑定。在这些情况下，直到运行时才能确定调用哪个函数。虚函数使用晚期绑定和虚表来确定要调用的函数版本。

使用虚函数是有代价的：虚函数调用耗时更长，并且虚表的必要性使得每个包含虚函数的对象的大小增加一个指针。

虚函数可以通过在虚函数原型末尾添加“= 0”来成为纯虚函数/抽象函数。包含纯虚函数的类称为抽象类，并且不能被实例化。继承纯虚函数的类必须具体定义它们，否则也会被视为抽象类。纯虚函数可以有函数体，但它们仍然被认为是抽象的。

接口类是没有成员变量且所有函数都是纯虚函数的类。这些类通常以大写字母 I 开头命名。

虚基类是一个基类，无论被对象继承多少次，它只被包含一次。

当派生类被赋值给基类对象时，基类只接收派生类的基类部分的副本。这称为对象切片。

动态转换可用于将指向基类对象的指针转换为指向派生类对象的指针。这称为向下转换。失败的转换将返回空指针。

为继承类重载 operator<< 的最简单方法是为最基类编写重载的 operator<<，然后调用虚成员函数进行打印。

  1. 以下每个程序都有某种缺陷。检查每个程序（通过视觉检查，而不是编译）并确定程序的问题所在。每个程序的输出应该是“Derived”。

1a)

#include <iostream>

class Base
{
protected:
	int m_value;

public:
	Base(int value)
		: m_value{ value }
	{
	}

	const char* getName() const { return "Base"; }
};

class Derived : public Base
{
public:
	Derived(int value)
		: Base{ value }
	{
	}

	const char* getName() const { return "Derived"; }
};

int main()
{
	Derived d{ 5 };
	Base& b{ d };
	std::cout << b.getName() << '\n';

	return 0;
}

显示答案

Base::getName() 没有被设为虚函数，因此 b.getName() 不会解析为 Derived::getName()。

	Circle(const Point& center, int radius)
		: m_center{ center }, m_radius{ radius }

	}

// 感谢读者 Olivier 提供的这个更新后的解决方案
// 假设半径 >= 0
int getLargestRadius(const std::vector<Shape*>& v)
{
	int largestRadius{ 0 };

	// 遍历向量中的所有形状
	for (const auto* element : v)
	{
		// // 通过检查空指针结果确保动态转换成功
		if (auto* c { dynamic_cast<const Circle*>(element) })
		{
			largestRadius = std::max(largestRadius, c->getRadius());
		}
	}

	return largestRadius;
}
int main()
{
	std::vector<Shape*> v{
		  new Circle{Point{ 1, 2 }, 7},
		  new Triangle{Point{ 1, 2 }, Point{ 3, 4 }, Point{ 5, 6 }},
		  new Circle{Point{ 7, 8 }, 3}
	};

	for (const auto* element : v) // element 将是一个 Shape*
		std::cout << *element << '\n';

	std::cout << "The largest radius is: " << getLargestRadius(v) << '\n';

	for (const auto* element : v)
		delete element;

	return 0;
}

int getLargestRadius(const std::vector<std::unique_ptr<Shape>>& v)
{
	int largestRadius{ 0 };

	// 遍历向量中的所有形状
	for (const auto& element : v)
	{
		// // 通过检查空指针结果确保动态转换成功

{
	std::vector<std::unique_ptr<Shape>> v;
	v.reserve(3);
	v.push_back(std::make_unique<Circle>(Point{1, 2}, 7));
	v.push_back(std::make_unique<Triangle>(Point{1, 2}, Point{3, 4}, Point{5, 6}));
	v.push_back(std::make_unique<Circle>(Point{7, 8}, 3));

	for (const auto& element : v) std::cout << *element << '\n';
    
	std::cout << "The largest radius is: " << getLargestRadius(v) << '\n';
}
