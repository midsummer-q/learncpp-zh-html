章节回顾

一个 语法错误 是指当您编写的语句不符合C++语言语法时发生的错误。编译器会捕获这些错误。

一个 语义错误 发生在语句语法有效但未执行程序员预期操作的情况下。

从程序中查找并移除错误的过程称为 调试。

我们可以使用一个五步流程来进行调试：

  1. 找到根本原因。
  2. 理解问题。
  3. 确定修复方案。
  4. 修复问题。
  5. 重新测试。

找到错误通常是调试中最困难的部分。

静态分析工具 是分析代码并查找可能指示代码问题的语义问题的工具。

能够可靠地重现问题是调试中第一步也是最重要的一步。

我们可以使用多种策略来帮助查找问题：

  • 注释掉代码。
  • 使用输出语句验证代码流程。
  • 打印值。

当使用打印语句进行调试时，使用 std::cerr 而不是 std::cout但更好的做法是，避免使用打印语句进行调试。

一个 日志文件 是一个记录程序中发生的事件的文件。将信息写入日志文件的过程称为 日志记录。

在不改变代码行为的前提下重构代码的过程称为 重构这通常是为了使程序更有序、更模块化或性能更高。

单元测试 是一种软件测试方法，通过测试源代码的小单元来判断其是否正确。

防御性编程 是一种技术，程序员通过它试图预见软件可能被误用的所有方式。这些误用通常可以被检测并缓解。

程序中跟踪的所有信息（变量值、已调用的函数、当前执行点）都是 程序状态。

一个 调试器 是一种允许程序员控制程序执行方式并在程序运行时检查程序状态的工具。一个 集成调试器 是一个集成到代码编辑器中的调试器。

单步执行 是一组相关调试功能的名称，允许你逐语句地单步执行代码。

步入 执行程序正常执行路径中的下一个语句，然后暂停执行。如果该语句包含函数调用， 步入 使程序跳转到被调用函数的顶部。

Step over 执行程序正常执行路径中的下一个语句，然后暂停执行。如果该语句包含函数调用， step over 执行该函数，并在函数执行后将控制权返回给你。

单步跳出 执行当前正在执行的函数中的所有剩余代码，然后在函数返回时将控制权返回给你。

运行到光标处 执行程序，直到执行到达鼠标光标选中的语句。

继续 运行程序，直到程序终止或遇到断点。 启动 与继续相同，只是从程序开始处执行。

一个 断点 是一个特殊标记，告诉调试器在到达断点时停止程序执行。

浮点类型的 设置下一条语句 命令允许我们改变执行点到其他语句（有时非正式地称为跳转）。这可以用于向前跳转执行点以跳过本会执行的某些代码，或向后跳转让已经执行过的内容再次运行。

监视变量 允许您在调试模式下执行程序时检查变量的值。这个 监视窗口 允许您检查变量或表达式的值。

浮点类型的 调用堆栈 是已执行到当前执行点的所有活动函数的列表。这个 调用堆栈窗口 是一个显示调用堆栈的调试器窗口。

小测验时间

问题 #1

以下程序应相加两个数，但运行不正确。

使用集成调试器单步执行此程序并观察 x 的值。根据您获取的信息，修复以下程序：

#include <iostream>

int readNumber(int x)
{
	std::cout << "Please enter a number: ";
	std::cin >> x;
	return x;
}

void writeAnswer(int x)
{
	std::cout << "The sum is: " << x << '\n';
}

int main()
{
	int x {};
	readNumber(x);
	x = x + readNumber(x);
	writeAnswer(x);

	return 0;
}

显示答案

主要问题出现在函数的第二行 main ——readNumber 的返回值未赋值给任何东西，因此被丢弃。一个小问题是 readNumber 接受了一个参数，但应该有一个局部变量。

#include <iostream>

int readNumber()
{
	std::cout << "Please enter a number: ";
	int x {};
	std::cin >> x;
	return x;
}

void writeAnswer(int x)
{
	std::cout << "The sum is: " << x << '\n';
}

int main()
{
	int x { readNumber() };
	x = x + readNumber();
	writeAnswer(x);

	return 0;
}

问题 #2

以下程序应相除两个数，但运行不正确。

使用集成调试器单步执行此程序。输入 8 和 4。根据您获取的信息，修复以下程序：

#include <iostream>

int readNumber()
{
	std::cout << "Please enter a number: ";
	int x {};
	std::cin >> x;
	return x;
}

void writeAnswer(int x)
{
	std::cout << "The quotient is: " << x << '\n';
}

int main()
{
	int x{ };
	int y{ };
	x = readNumber();
	x = readNumber();
	writeAnswer(x/y);

	return 0;
}

显示答案

问题在于第二个调用 readNumber 意外地将它的值赋给了 x 而不是 y，导致除以0，这导致了未定义行为。

#include <iostream>

int readNumber()
{
	std::cout << "Please enter a number: ";
	int x {};
	std::cin >> x;
	return x;
}

void writeAnswer(int x)
{
	std::cout << "The quotient is: " << x << '\n';
}

int main()
{
	int x{ readNumber() };
	int y{ readNumber() };
	writeAnswer(x/y);

	return 0;
}

您可能会注意到，当第二个输入不能整除第一个时，该程序似乎产生错误答案。进行整数除法时，C++ 将丢弃商的所有小数部分。我们将在第节课中更详细地讨论这个问题 6.2 -- 算术运算符。

问题 #4

附加题：以下程序本应相加两个数字，但运行结果不正确。

使用集成调试器单步执行此程序。输入 8 和 4。根据您获取的信息，修复以下程序：

#include <iostream>

int readNumber()
{
    std::cout << "Please enter a number: ";
    char x{};
    std::cin >> x;
    
    return x;
}

void writeAnswer(int x)
{
    std::cout << "The sum is: " << x << '\n';
}

int main()
{
    int x { readNumber() };
    int y { readNumber() };
    writeAnswer(x + y);

    return 0;
}

显示答案

问题在于 char 第6行的数据类型。当我们输入数值8时，它并不会存储为值 8，而是存储为 56 当我们输入数值4时，它并不会存储为值 4，而是存储为 52 该 readNumber() 函数因此返回 56 和 52 而不是 8 和 4 如预期的那样。

解决方案是将第6行的数据类型从 char 切换到 int。
