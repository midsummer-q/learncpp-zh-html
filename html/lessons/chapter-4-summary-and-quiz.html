章节回顾

内存的最小单位是 二进制位，也称为 位。可以直接寻址（访问）的最小内存单元是 字节。现代标准规定一个字节等于8位。

一个 数据类型 告诉编译器如何以有意义的方式解释内存中的内容。

C++支持许多基本数据类型，包括浮点数、整数、布尔值、字符、空指针和void。

Void 用于表示无类型。它主要用于指示函数不返回值。

不同类型占用不同的内存量，且内存使用量可能因机器而异。

相关内容

参见 4.3 -- 对象大小和sizeof运算符 查看每种基本类型的最小尺寸表。

浮点类型的 大小 运算符可用于返回类型的大小（以字节为单位）。

有符号整数 用于保存正负整数，包括0。特定数据类型可以保存的值的集合称为其 范围。使用整数时，要注意溢出和整数除法问题。

无符号整数 只保存正数（和0），通常应避免使用，除非进行位级操作。

固定宽度整数 是具有保证大小的整数，但可能并非在所有架构上都存在。快速整数和最小整数是至少具有某个大小的最快和最小整数。 std::int8_t 和 std::uint8_t 通常应避免使用，因为它们往往像字符而不是整数。

size_t 是一种无符号整数类型，用于表示对象的大小或长度。

科学记数法 是书写长数字的简写方式。C++支持科学记数法与浮点数结合使用。有效数字（e之前的部分）中的数字称为 有效数字。

浮点型 是一组用于保存实数（包括带小数部分的数）的类型。 精度 定义了一个数字在不丢失信息的情况下可以表示的有效数字位数。 舍入误差 当太多有效数字存储在一个无法容纳如此高精度的浮点数中时，就会发生。舍入错误经常发生，即使是像0.1这样简单的数字也是如此。因此，不应直接比较浮点数。

浮点类型的 布尔型 类型用于存储 true 或 false 值。

If 语句 允许我们在某个条件为真时执行一行或多行代码。if语句的条件表达式被解释为布尔值。 else语句 可用于在先前的if语句条件评估为假时执行一条语句。

Char 用于存储被解释为ASCII字符的值。使用char时，注意不要混淆ASCII码值和数字。将char作为整数值打印需要使用 static_cast.

尖括号通常用于C++中表示需要参数化类型的东西。它与 static_cast 一起使用，以确定参数应转换为哪种数据类型（例如， static_cast<int>(x) 将返回 x 作为 int)。

编写以下程序：要求用户输入两个浮点数（使用 double）。然后要求用户输入以下数学符号之一：+、-、* 或 /。程序计算这两个数的结果并打印。如果用户输入无效符号，程序应不打印任何内容。

程序示例：

Enter +, -, *, or /: *
6.2 * 5 is 31

提示：编写三个函数：一个用于获取 double 值，一个用于获取算术符号，一个用于计算并打印答案。

显示提示

提示：使用 if 语句和 operator== 来比较用户输入与所需的算术符号。

显示提示

提示：考虑使用提前返回（在第 4.10 -- if 语句简介课中介绍），如果用户没有传入支持的操作。

显示答案

#include <iostream>

double getDouble()
{
    std::cout << "Enter a double value: ";
    double x{};
    std::cin >> x;
    return x;
}

char getOperator()
{
    std::cout << "Enter +, -, *, or /: ";
    char operation{};
    std::cin >> operation;
    return operation;
}

void printResult(double x, char operation, double y)
{
    double result{};

    if (operation == '+')
        result = x + y;
    else if (operation == '-')
        result = x - y;
    else if (operation == '*')
        result = x * y;
    else if (operation == '/')
        result = x / y;
    else        // 如果用户没有传入支持的操作
        return; // 提前返回

    std::cout << x << ' ' << operation << ' ' << y << " is " << result << '\n';
}

int main()
{
    double x { getDouble() };
    double y { getDouble() };

    char operation { getOperator() };

    printResult(x, operation, y);

    return 0;
}

显示答案

#include <iostream>

// 从用户获取塔高并返回
double getTowerHeight()
{
	std::cout << "Enter the height of the tower in meters: ";
	double towerHeight{};
	std::cin >> towerHeight;
	return towerHeight;
}

// 返回 "seconds" 秒后的当前球高
double calculateBallHeight(double towerHeight, int seconds)
{
	double gravity { 9.8 };
    
	// 使用公式：s = (u * t) + (a * t^2) / 2
	// 这里 u（初速度）= 0，所以 (u * t) = 0
	double fallDistance { gravity * (seconds * seconds) / 2.0 };
	double ballHeight { towerHeight - fallDistance };

	// 如果球会低于地面，将其放在地面上
	if (ballHeight < 0.0)
		return 0.0;
    
	return ballHeight;
}

// 打印球离地高度
void printBallHeight(double ballHeight, int seconds)
{
	if (ballHeight > 0.0)
		std::cout << "At " << seconds << " seconds, the ball is at height: " << ballHeight << " meters\n";
	else
		std::cout << "At " << seconds << " seconds, the ball is on the ground.\n";
}

// 计算当前球高并打印
// 这是一个辅助函数，使操作更简单
void calculateAndPrintBallHeight(double towerHeight, int seconds)
{
	double ballHeight{ calculateBallHeight(towerHeight, seconds) };
	printBallHeight(ballHeight, seconds);
}

int main()
{
	double towerHeight{ getTowerHeight() };

	calculateAndPrintBallHeight(towerHeight, 0);
	calculateAndPrintBallHeight(towerHeight, 1);
	calculateAndPrintBallHeight(towerHeight, 2);
	calculateAndPrintBallHeight(towerHeight, 3);
	calculateAndPrintBallHeight(towerHeight, 4);
	calculateAndPrintBallHeight(towerHeight, 5);
       
	return 0;
}
