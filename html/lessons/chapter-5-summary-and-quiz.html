5.x — 第5章 总结与测验

章节回顾

一个 常量 是在程序执行期间不能改变的值。C++ 支持两种类型的常量：命名常量和字面量。

一个 命名常量 是与标识符关联的常量值。 字面常量 是不与标识符关联的常量值。

值不能改变的变量称为 常量变量。这些 const 关键字可用于使变量成为常量。常量变量必须初始化。避免在按值传递或按值返回时使用 const

一个 类型限定符 是应用于类型以修改该类型行为的关键字。从 C++23 开始，C++ 只支持 const 和 volatile 作为类型限定符。

一个 常量表达式 是可以在编译时求值的表达式。不是常量表达式的表达式有时称为 运行时表达式。

一个 编译时常量 是其值在编译时已知的常量。 运行时常量 是其初始化值直到运行时才已知的常量。

一个 constexpr 变量必须是编译时常量，并用常量表达式初始化。函数参数不能是 constexpr。

字面量 是直接插入代码中的值。字面量有类型，字面量后缀可用于更改字面量的默认类型。

一个 魔法数字 是含义不明确或以后可能需要更改的字面量（通常是数字）。不要在代码中使用魔法数字。相反，使用符号常量。

在日常生活中，我们使用 十进制 数字，有10个数字。计算机使用 二进制，只有2个数字。C++ 也支持 八进制 （基数为8）和 十六进制 （基数为16）。这些都是 数制的例子，它们是用于表示数字的符号（数字）集合。

一个 字符串 是用于表示文本（如名称、单词和句子）的连续字符集合。字符串字面量总是放在双引号之间。C++ 中的字符串字面量是 C 风格字符串，其类型奇怪且难以处理。

std::string 提供了一种简单安全的方式来处理文本字符串。std::string 位于 <string> 头文件中。 std::string 初始化和复制（或赋值）的开销很大。

std::string_view 提供对现有字符串（C 风格字符串字面量、std::string 或字符数组）的只读访问，而不进行复制。 std::string_view 如果它正在查看一个已被销毁的字符串，有时称为 悬垂 视图。当 std::string 被修改时，所有指向该 std::string 是 失效，意味着这些视图现在无效。使用失效的视图（除了重新验证它）将导致未定义行为。

由于 C 风格字符串字面量在整个程序期间都存在，因此可以将 std::string_view 设置为 C 风格字符串字面量，甚至从函数返回这样的 std::string_view

一个 子串 是现有字符串中连续的一段字符序列。

小测验时间

问题 #1

为什么命名常量通常比字面常量更好？

显示答案

在程序中使用字面常量（即魔数）会使程序更难理解和修改。符号常量有助于说明数字的实际含义，并且在声明处修改符号常量会改变其所有使用位置的值。

为什么 const/constexpr 变量通常比 #defined 符号常量更好？

显示答案

#define 常量不会在调试器中显示，并且更容易出现命名冲突。

问题 #2

找出以下代码中的 3 个问题：

#include <cstdint> // for std::uint8_t
#include <iostream>

int main()
{
  std::cout << "How old are you?\n";

  std::uint8_t age{};
  std::cin >> age;

  std::cout << "Allowed to drive a car in Texas: ";

  if (age >= 16)
      std::cout << "Yes";
  else
      std::cout << "No";

  std::cout << '.\n';

  return 0;
}

示例期望输出：

How old are you?
6
Allowed to drive a car in Texas: No

How old are you?
19
Allowed to drive a car in Texas: Yes

显示答案

  1. 在第 8 行， age 被定义为 std::uint8_t。因为 std::uint8_t 通常被定义为 char 类型，在这里使用它会导致程序行为如同我们输入和输出一个 char 值而不是数值。例如，如果用户输入年龄为“18”，只会提取字符 '1' 因为 1 的 ASCII 值为 49，用户会被当作 49 岁。应该使用普通的 int 来存储年龄，因为年龄不需要特定的最小整数宽度。我们还可以移除 #include <cstdint>。
  2. 在第 13 行，我们使用了魔数 16。尽管 16 的含义在使用它的上下文中是清晰的，但最好使用一个值为 constexpr 的 16 变量。
  3. 在第 18 行， '.\n' 是一个多字符字面量，会打印错误的值。应该使用双引号（".\n")。

问题 #3

之间的主要区别是什么？ std::string 和 std::string_view？

使用 std::string_view？

显示答案

std::string 提供可修改的字符串。初始化和复制成本高。

std::string_view 提供对存在于别处的字符串的只读视图。初始化和复制成本低。 std::string_view 当被查看的字符串在 std::string_view 之前被销毁时，可能会很危险。

问题 #4

编写一个程序，询问两个人的姓名和年龄，然后打印出谁更年长。

以下是程序一次运行的示例输出：

Enter the name of person #1: John Bacon
Enter the age of John Bacon: 37
Enter the name of person #2: David Jenkins
Enter the age of David Jenkins: 44
David Jenkins (age 44) is older than John Bacon (age 37).

显示提示

提示：使用 std::getline()

显示答案

#include <iostream>
#include <string>
#include <string_view>

std::string getName(int num)
{
    std::cout << "Enter the name of person #" << num << ": ";
    std::string name{};
    std::getline(std::cin >> std::ws, name); // 将一整行文本读入 name

    return name;
}

int getAge(std::string_view sv)
{
    std::cout << "Enter the age of " << sv << ": ";
    int age{};
    std::cin >> age;

    return age;
}

void printOlder(std::string_view name1, int age1, std::string_view name2, int age2)
{
    if (age1 > age2)
        std::cout << name1 << " (age " << age1 <<") is older than " << name2 << " (age " << age2 <<").\n";
    else
        std::cout << name2 << " (age " << age2 <<") is older than " << name1 << " (age " << age1 <<").\n";
}

int main()
{
    const std::string name1{ getName(1) };
    const int age1 { getAge(name1) };
    
    const std::string name2{ getName(2) };
    const int age2 { getAge(name2) };

    printOlder(name1, age1, name2, age2);

    return 0;
}
