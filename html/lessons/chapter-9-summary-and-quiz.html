章节回顾

范围蔓延 发生在项目的能力超出项目或项目阶段最初预期时。

软件验证 是测试软件是否在所有情况下按预期工作的过程。 单元测试 是一种测试，旨在隔离测试一小部分代码（通常是函数或调用），以确保特定行为按预期发生。 单元测试框架 可以帮助你组织单元测试。 集成测试 测试多个单元集成在一起是否正常工作。

代码覆盖率 指测试时执行了多少源代码。 语句覆盖率 指程序中已被测试例程执行过的语句百分比。 分支覆盖率 指已被测试例程执行过的分支百分比。 因此，我们可以说这个函数通过3次调用得到了可靠的测试（这比18百亿亿次略好）。 （也称为 0、1、2测试意味着如果你有一个循环，你应该确保它在迭代0次、1次和2次时都能正常工作。

浮点类型的 快乐路径 是没有遇到错误时发生的执行路径。 悲伤路径 是发生错误或失败状态的路径。 不可恢复错误 （也称为 致命错误是一种严重到程序无法继续运行的错误。能够良好处理错误情况的程序称为 健壮的。

一个 缓冲区 是一块内存，用于在数据从一个地方移动到另一个地方时临时存储数据。

检查用户输入是否符合程序预期的过程称为 输入验证。

std::cerr 是一种输出流（如 std::cout），设计用于错误消息。

一个 前置条件 是在执行某段代码之前必须始终为真的任何条件。 不变量 是在某个组件执行时必须为真的条件。 后置条件 是在执行某些代码之后必须始终为真的任何条件。

一种 断言 是一个表达式，除非程序中有错误，否则为真。在C++中，运行时断言通常使用 assert 预处理器宏实现。断言通常在非调试代码中关闭。 静态断言 是在编译时评估的断言。

断言应用于记录逻辑上不可能的情况。错误处理应用于处理可能发生的情况。

小测验时间

问题 #1

在课程 8.x -- 第8章总结与测验的测验中，我们实现了一个Hi-Lo游戏。

更新你之前的解决方案，以处理无效猜测（例如'x'）、超出范围的猜测（例如 0 或 101），或包含多余字符的有效猜测（例如 43x）。同时处理用户在游戏询问是否想再玩一次时输入多余字符的情况。

提示：编写一个单独的函数来处理用户输入猜测（以及相关的错误处理）。

显示答案

#include <iostream>
#include <limits>   // for std::numeric_limits
#include "Random.h" // https://www.learncpp.com/cpp-tutorial/global-random-numbers-random-h/

int getGuess(int count, int min, int max)
{
	while (true) // 循环直到用户输入有效输入
	{
		std::cout << "Guess #" << count << ": ";

		int guess {};
		std::cin >> guess;

		bool success { std::cin };
		std::cin.clear(); // 将我们放回“正常”操作模式（如果需要）
		std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n'); // 移除任何额外输入

		// 如果我们没有提取任何内容或提取的猜测超出范围，则重试
		if (!success || guess < min || guess > max)
			continue;

		return guess;
	}
}

// 如果用户赢了返回true，输了返回false
bool playHiLo(int guesses, int min, int max)
{
	std::cout << "Let's play a game. I'm thinking of a number between " << min << " and " << max << ". You have " << guesses << " tries to guess what it is.\n";
	int number{ Random::get(min, max) }; // 这是用户需要猜测的数字

	// 遍历所有猜测
	for (int count{ 1 }; count <= guesses; ++count)
	{
		int guess{ getGuess(count, min, max) };

		if (guess > number)
			std::cout << "Your guess is too high.\n";
		else if (guess < number)
			std::cout << "Your guess is too low.\n";
		else // 猜测 == 数字，所以用户赢了
		{
			std::cout << "Correct! You win!\n";
			return true;
		}
	}

	// 用户输了
	std::cout << "Sorry, you lose. The correct number was " << number << '\n';
	return false; // 如果用户输了
}

bool playAgain()
{
	// 不断询问用户是否想再玩一次，直到他们选择 y 或 n。
	while (true)
	{
		char ch{};
		std::cout << "Would you like to play again (y/n)? ";
		std::cin >> ch;

		// 清除任何多余的输入
		std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
        
		switch (ch)
		{
		case 'y': return true;
		case 'n': return false;
		}
	}
}

int main()
{
	constexpr int guesses { 7 }; // 用户有这么多猜测次数
	constexpr int min     { 1 };
	constexpr int max     { 100 };

	do
	{
		playHiLo(guesses, min, max);
	} while (playAgain());

	std::cout << "Thank you for playing.\n";

	return 0;
}
