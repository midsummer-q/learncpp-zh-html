4.11 — 字符

● 机器译文 课程 4.11 查看英文原文

到目前为止，我们所学习的基本数据类型都用于存储数字（整数和浮点数）或真/假值（布尔值）。但如果我们想要存储字母或标点符号呢？

#include <iostream>

int main()
{
    std::cout << "Would you like a burrito? (y/n)";

    // 我们想要用户输入一个 'y' 或 'n' 字符
    // 我们怎么做？

    return 0;
}

浮点类型的 char 数据类型被设计用来存储单个 character。一个 字符 可以是单个字母、数字、符号或空白字符。

char数据类型是一种整数类型，意思是其底层值以整数形式存储。类似于布尔值 0 被解释为 false 而非零被解释为 true，由char char 变量被解释为一个 ASCII character。

ASCII 代表美国信息交换标准代码，它定义了一种特定方式，用0到127之间的数字表示英文字符（外加一些其他符号），这个数字称为 ASCII码 或 码点）。例如，ASCII码97被解释为字符‘a’。

字符字面量总是写在单引号之间（例如‘g’、‘1’、‘ ’）。

编码0-31和127被称为不可打印字符。这些编码最初用于控制外围设备，如打印机（例如通过指示打印机如何移动打印头）。现在它们大多已经过时。如果你尝试打印这些字符，结果将取决于你的操作系统（你可能会得到一些类似表情符号的字符）。

编码32-126被称为可打印字符，它们表示字母、数字和标点符号，大多数计算机使用这些字符来显示基本的英文文本。

如果你尝试打印一个值超出ASCII范围的字符，结果同样取决于你的操作系统。

初始化字符

你可以使用字符字面量来初始化char变量：

char ch2{ 'a' }; // 使用 'a' 的码点初始化（存储为整数 97）（首选）

你也可以使用整数来初始化char，但应尽量避免这样做

char ch1{ 97 }; // 使用整数 97 ('a') 初始化（不推荐）

警告

注意不要混淆字符数字和整数数字。以下两种初始化并不相同：

char ch{5}; // 使用整数 5 初始化（存储为整数 5）
char ch{'5'}; // 使用 '5' 的码点初始化（存储为整数 53）

当我们希望将数字表示为文本，而不是用于数学运算的数字时，应使用字符数字。

打印字符

使用 std::cout 打印 char 时，std::cout 会将该 char 变量输出为 ASCII 字符：

#include <iostream>

int main()
{
    char ch1{ 'a' }; // （首选）
    std::cout << ch1; // cout 打印字符 'a'

    char ch2{ 98 }; // 'b' 的码点（不推荐）
    std::cout << ch2; // cout 打印一个字符 ('b')


    return 0;
}

这会产生以下结果：

ab

我们也可以直接输出字符字面量：

std::cout << 'c';

这会产生以下结果：

c

输入字符

以下程序要求用户输入一个字符，然后打印该字符：

#include <iostream>

int main()
{
    std::cout << "Input a keyboard character: ";

    char ch{};
    std::cin >> ch;
    std::cout << "You entered: " << ch << '\n';

    return 0;
}

以下是某次运行时的输出：

Input a keyboard character: q
You entered: q

注意，std::cin 允许你输入多个字符。然而，变量 ch 只能容纳 1 个字符。因此，只有第一个输入字符被提取到变量 ch中。用户输入的其余部分保留在 std::cin 使用的输入缓冲区中，并可通过后续对 std::cin 的调用来提取。

你可以在以下示例中看到这种行为：

#include <iostream>

int main()
{
    std::cout << "Input a keyboard character: "; // 假设用户输入 "abcd"（不带引号）

    char ch{};
    std::cin >> ch; // ch = 'a'，"bcd" 留在队列中。
    std::cout << "You entered: " << ch << '\n';

    // 注意：下面的 cin 不会要求用户输入，它获取队列中的输入！
    std::cin >> ch; // ch = 'b'，"cd" 留在队列中。
    std::cout << "You entered: " << ch << '\n';
    
    return 0;
}

Input a keyboard character: abcd
You entered: a
You entered: b

如果你想一次读取多个字符（例如读取姓名、单词或句子），则应使用字符串（string）而不是字符（char）。字符串是连续字符的集合（因此字符串可以容纳多个符号）。我们将在接下来的课程中讨论这一点（5.7 -- std::string 简介)。

提取空白字符

由于输入提取会忽略前导空白，因此在尝试将空白字符提取到 char 变量时可能导致意外结果：

#include <iostream>

int main()
{
    std::cout << "Input a keyboard character: "; // 假设用户输入 "a b"（不含引号）

    char ch{};
    std::cin >> ch; // 提取 a，流中剩下 " b\n"
    std::cout << "You entered: " << ch << '\n';

    std::cin >> ch; // 跳过前导空白（空格），提取 b，流中剩下 "\n"
    std::cout << "You entered: " << ch << '\n';

    return 0;
}

Input a keyboard character: a b
You entered: a
You entered: b

在上面的示例中，我们可能期望提取空格，但由于前导空白被跳过，我们提取了 b 字符。

解决这个问题的一个简单方法是使用 std::cin.get() 函数来执行提取，因为该函数不会忽略前导空白：

#include <iostream>

int main()
{
    std::cout << "Input a keyboard character: "; // 假设用户输入 "a b"（不含引号）

    char ch{};
    std::cin.get(ch); // 提取 a，流中剩下 " b\n"
    std::cout << "You entered: " << ch << '\n';

    std::cin.get(ch); // 提取空格，流中剩下 "b\n"
    std::cout << "You entered: " << ch << '\n';

    return 0;
}

Input a keyboard character: a b
You entered: a
You entered:

字符的大小、范围和默认符号

C++规定char始终为1字节大小。默认情况下，char可以是有符号或无符号（虽然通常是有符号的）。如果你用char保存ASCII字符，则无需指定符号（因为signed char和unsigned char都能保存0到127之间的值）。

如果你用char保存小整数（除非你明确为了空间优化，否则不应这样做），则应始终指定它是有符号还是无符号。signed char可以保存-128到127之间的数，unsigned char可以保存0到255之间的数。

转义序列

C++中有一些字符序列具有特殊含义。这些字符被称为 转义序列转义序列以‘\’（反斜杠）字符开头，后跟一个字母或数字。

你已经见过最常见的转义序列： '\n'，它可用于打印换行：

#include <iostream>

int main()
{
    int x { 5 };
    std::cout << "The value of x is: " << x << '\n'; // 单独的 \n 放在单引号中
    std::cout << "First line\nSecond line\n";        // \n 可以嵌入双引号中
    return 0;
}

这会输出：

The value of x is: 5
First line
Second line

另一个常用的转义序列是 '\t'，它插入一个水平制表符：

#include <iostream>

int main()
{
    std::cout << "First part\tSecond part";
    return 0;
}

其输出为：

First part	Second part

其他三个值得注意的转义序列是：
\’ 打印单引号
\" 打印双引号
\\ 打印反斜杠

以下是所有转义序列的表格：

以下是一些示例：

#include <iostream>

int main()
{
    std::cout << "\"This is quoted text\"\n";
    std::cout << "This string contains a single backslash \\\n";
    std::cout << "6F in hex is char '\x6F'\n";
    return 0;
}

打印：

"This is quoted text"
This string contains a single backslash \
6F in hex is char 'o'

警告

转义序列以反斜杠（\\）开头，而不是正斜杠（/）。如果不小心使用了正斜杠，代码可能仍然会编译，但不会产生期望的结果。

换行符（\\n）与 std::endl

我们在课程中讨论这个主题 1.5 -- iostream入门：cout, cin和endl。

将符号放在单引号和双引号中有什么区别？

单引号之间的文本被视为一个 char 字面量，表示单个字符。例如， 'a' 表示字符 a， '+' 表示加号字符， '5' 表示字符 5 （而不是数字5），并且 '\n' 表示换行字符。

双引号之间的文本（例如“Hello, world!”）被视为C风格字符串字面量，可以包含多个字符。我们将在课程中讨论字符串 5.2 -- 字面量。

最佳实践

单个字符通常应使用单引号，而不是双引号（例如 't' 或 '\n'，而不是 "t" 或 "\n"）。一个可能的例外是在输出时，为了保持一致性可能倾向于使用双引号（参见课程 1.5 -- iostream入门：cout, cin和endl)。

避免多字符字面量

出于向后兼容的原因，许多C++编译器支持 多字符字面量，即包含多个字符的char字面量（例如 '56'）。如果支持，这些字面量具有由实现定义的值（意味着值因编译器而异）。由于它们不是C++标准的一部分，且其值没有严格定义，因此应避免使用多字符字面量。

最佳实践

避免多字符字面量（例如 '56')。

当新程序员忘记转义序列是使用正斜杠还是反斜杠时，多字符字面量支持经常导致问题：

#include <iostream>

int add(int x, int y)
{
	return x + y;
}

int main()
{
	std::cout << add(1, 2) << '/n'; // 这里我们用了正斜杠而不是反斜杠

	return 0;
}

程序员期望这个程序打印值 3 和一个换行。但相反，在作者的机器上，它输出以下内容：

312142

这里的问题是程序员意外使用了 '/n' （一个由正斜杠和一个 'n' 字符组成的多字符字面量）而不是 '\n' （换行转义序列）。程序首先打印 3 （的结果 add(1, 2)）正确。但随后它打印了多字符字面量 '/n'的值，在作者的机器上，其值是实现定义的 12142。

警告

确保你的换行符使用了转义序列 '\n' ，而不是多字符字面量 '/n'。

关键提示

注意，如果我们用双引号括起输出 "/n"，程序会打印 3/n，这仍然是错误的，但没那么令人困惑。

这是另一个示例。让我们从以下代码开始：

#include <iostream>

int main()
{
    int x { 5 };
    std::cout << "The value of x is " << x << '\n'; 

    return 0;
}

这个程序的输出正如你预期的那样：

The value of x is 5

但这个输出还不够刺激，所以我们决定在换行符前加一个感叹号：

#include <iostream>

int main()
{
    int x { 5 };
    std::cout << "The value of x is " << x << '!\n'; // 添加了感叹号

    return 0;
}

虽然我们期望它输出以下内容：

The value of x is 5!

因为 '!\n' 是一个多字符字面量，在作者的机器上，实际打印出了：

The value of x is 58458

这不仅不正确，而且可能难以调试，因为你可能会假设 x 有错误的值。

在输出字符字面量时使用双引号（而不是单引号）要么使这类问题更容易发现，要么完全避免它们。

其他字符类型呢， wchar_t， char8_t， char16_t、和 char32_t？

与ASCII将整数0-127映射到美式英语字符类似，还存在其他字符编码标准，用于将（不同大小的）整数映射到其他语言的字符。ASCII之外最著名的映射是Unicode标准，它将超过144,000个整数映射到许多不同语言的字符。由于Unicode包含如此多的码点，单个Unicode码点需要32位来表示一个字符（称为UTF-32）。然而，Unicode字符也可以使用多个16位或8位字符进行编码（分别称为UTF-16和UTF-8）。

char16_t 和 char32_t 被添加到C++11中，以提供对16位和32位Unicode字符的显式支持。这些字符类型与 std::uint_least16_t 和 std::uint_least32_t 分别具有相同的大小（但它们是不同的类型）。 char8_t 在 C++20 中被添加，以提供对 8 位 Unicode (UTF-8) 的支持。它是一种独特的类型，使用与……相同的表示方式 unsigned char。

你不需要使用 char8_t， char16_t，或 char32_t 除非你计划让你的程序支持 Unicode。 wchar_t 在几乎所有情况下都应避免使用（除非与 Windows API 交互），因为它的大小是由实现定义的。

Unicode 和本地化通常不在本教程的范围内，因此我们不会再进一步讨论。与此同时，在处理字符（和字符串）时，你应该只使用 ASCII 字符。使用其他字符集中的字符可能会导致你的字符显示不正确。
