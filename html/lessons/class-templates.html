13.13 — 类模板

● 机器译文 课程 13.13 查看英文原文

在课程 11.6 -- 函数模板，我们介绍了必须为每种要处理的类型集创建单独（重载）函数的挑战：

#include <iostream>

// 计算两个 int 值中较大者的函数
int max(int x, int y)
{
    return (x < y) ? y : x;
}

// 几乎相同的函数，用于计算两个 double 值中较大者
// 唯一的区别是类型信息
double max(double x, double y)
{
    return (x < y) ? y : x;
}

int main()
{
    std::cout << max(5, 6);     // 调用 max(int, int)
    std::cout << '\n';
    std::cout << max(1.2, 3.4); // 调用 max(double, double)

    return 0;
}

解决方案是创建一个函数模板，编译器可以用它为我们需要的任何类型集实例化普通函数：

#include <iostream>

// 一个用于 max 的函数模板
template <typename T>
T max(T x, T y)
{
    return (x < y) ? y : x;
}

int main()
{
    std::cout << max(5, 6);     // 实例化并调用 max<int>(int, int)
    std::cout << '\n';
    std::cout << max(1.2, 3.4); // 实例化并调用 max<double>(double, double)

    return 0;
}

聚合类型也有类似的挑战

我们在聚合类型（包括结构体/类/联合体和数组）上也遇到了类似的挑战。

例如，假设我们正在编写一个程序，需要处理成对的 int 值，并需要确定两个数字中哪个更大。我们可能会编写如下程序：

#include <iostream>

struct Pair
{
    int first{};
    int second{};
};

constexpr int max(Pair p) // 按值传递，因为 Pair 很小
{
    return (p.first < p.second ? p.second : p.first);
}

int main()
{
    Pair p1{ 5, 6 };
    std::cout << max(p1) << " is larger\n";

    return 0;
}

后来，我们发现还需要成对的 double 值。因此我们将程序更新为以下内容：

#include <iostream>

struct Pair
{
    int first{};
    int second{};
};

struct Pair // 编译错误：Pair 的错误重定义
{
    double first{};
    double second{};
};

constexpr int max(Pair p)
{
    return (p.first < p.second ? p.second : p.first);
}

constexpr double max(Pair p) // 编译错误：重载函数仅返回类型不同
{
    return (p.first < p.second ? p.second : p.first);
}

int main()
{
    Pair p1{ 5, 6 };
    std::cout << max(p1) << " is larger\n";

    Pair p2{ 1.2, 3.4 };
    std::cout << max(p2) << " is larger\n";

    return 0;
}

不幸的是，这个程序无法编译，并且存在许多需要解决的问题。

首先，与函数不同，类型定义不能重载。编译器会将第二个 double 类型的 Pair 视为第一个 Pair定义的错误重新声明。其次，虽然函数可以重载，但我们的 max(Pair) 函数仅返回类型不同，而重载函数不能仅通过返回类型区分。第三，这里存在大量冗余。每个 Pair 结构体都是相同的（除了数据类型），我们的 max(Pair) 函数也是如此（除了返回类型）。

我们可以通过给 Pair 结构体起不同的名称（例如 PairInt 和 PairDouble）来解决前两个问题。但这样我们既要记住命名方案，又要为每个额外的对类型克隆大量代码，这并没有解决冗余问题。

幸运的是，我们可以做得更好。

类模板

就像函数模板是用于实例化函数的模板定义一样， 类模板 是用于实例化类类型的模板定义。

提醒

“类类型”是结构体、类或联合体类型。虽然为了简单起见，我们将在结构体上演示“类模板”，但这里的所有内容同样适用于类。

提醒一下，这是我们的 int pair 结构体定义：

struct Pair
{
    int first{};
    int second{};
};

让我们将 pair 类重写为类模板：

#include <iostream>

template <typename T>
struct Pair
{
    T first{};
    T second{};
};

int main()
{
    Pair<int> p1{ 5, 6 };        // 实例化 Pair<int> 并创建对象 p1
    std::cout << p1.first << ' ' << p1.second << '\n';

    Pair<double> p2{ 1.2, 3.4 }; // 实例化 Pair<double> 并创建对象 p2
    std::cout << p2.first << ' ' << p2.second << '\n';

    Pair<double> p3{ 7.8, 9.0 }; // 使用之前 Pair<double> 的定义创建对象 p3
    std::cout << p3.first << ' ' << p3.second << '\n';

    return 0;
}

与函数模板一样，我们以模板参数声明开始类模板定义。我们从 template 关键字开始。接下来，我们在尖括号（<>）内指定类模板将使用的所有模板类型。对于需要的每个模板类型，我们使用关键字 typename （首选）或 class （不推荐），后跟模板类型的名称（例如 T）。在这种情况下，由于两个成员将是相同类型，我们只需要一个模板类型。

接下来，我们像往常一样定义结构体，只是我们可以在任何需要模板类型的地方使用模板类型（T），该类型稍后将被替换为实际类型。就这样！类模板定义完成了。

在 main 内部，我们可以使用任何想要的类型实例化 Pair 对象。首先，我们实例化一个类型为 Pair<int>的对象。由于 Pair<int> 的类型定义尚不存在，编译器使用类模板实例化一个名为 Pair<int>的结构体类型定义，其中所有出现的模板类型 T 都被替换为类型 int。

接下来，我们实例化一个类型为 Pair<double>的对象，这会实例化一个名为 Pair<double> 不进行任何清理。 T 的结构体类型定义，其中 double。对于 p3， Pair<double> 被替换为

已经被实例化，因此编译器将使用之前的类型定义。

#include <iostream>

// Pair 类模板的声明
// （我们不再需要定义，因为它没有被使用）
template <typename T>
struct Pair;

// 显式定义 Pair<int> 的样子
template <> // 告诉编译器这是一个没有模板参数的模板类型
struct Pair<int>
{
    int first{};
    int second{};
};

// 显式定义 Pair<double> 的样子
template <> // 告诉编译器这是一个没有模板参数的模板类型
struct Pair<double>
{
    double first{};
    double second{};
};

int main()
{
    Pair<int> p1{ 5, 6 };        // 实例化 Pair<int> 并创建对象 p1
    std::cout << p1.first << ' ' << p1.second << '\n';

    Pair<double> p2{ 1.2, 3.4 }; // 实例化 Pair<double> 并创建对象 p2
    std::cout << p2.first << ' ' << p2.second << '\n';

    Pair<double> p3{ 7.8, 9.0 }; // 使用之前 Pair<double> 的定义创建对象 p3
    std::cout << p3.first << ' ' << p3.second << '\n';

    return 0;
}

#include <iostream>

template <typename T>
struct Pair
{
    T first{};
    T second{};
};

template <typename T>
constexpr T max(Pair<T> p)
{
    return (p.first < p.second ? p.second : p.first);
}

int main()
{
    Pair<int> p1{ 5, 6 };
    std::cout << max<int>(p1) << " is larger\n"; // 显式调用 max<int>

    Pair<double> p2{ 1.2, 3.4 };
    std::cout << max(p2) << " is larger\n"; // 使用模板实参推导调用 max<double>（推荐此方式）

    return 0;
}

#include <iostream>

template <typename T, typename U>
struct Pair
{
    T first{};
    U second{};
};

template <typename T, typename U>
void print(Pair<T, U> p)
{
    std::cout << '[' << p.first << ", " << p.second << ']';
}

int main()
{
    Pair<int, double> p1{ 1, 2.3 }; // 一个持有 int 和 double 的 pair
    Pair<double, int> p2{ 4.5, 6 }; // 一个持有 double 和 int 的 pair
    Pair<int, int> p3{ 7, 8 };      // 一个持有两个 int 的 pair

    print(p2);

    return 0;
}

类模板也可以有多个模板类型。例如，如果我们希望 T类的两个成员可以具有不同的类型，我们可以定义带有两个模板类型的 U。实际的模板类型实参 T 和 U 可以不同（如 p1 和 p2 的情况）或相同（如 p3)。

使函数模板适用于多个类类型

考虑 print() 上面例子中的函数模板：

template <typename T, typename U>
void print(Pair<T, U> p)
{
    std::cout << '[' << p.first << ", " << p.second << ']';
}

因为我们显式地将函数参数定义为 Pair<T, U>，只有类型为 Pair<T, U> （或可以转换为 Pair<T, U>）的参数才会匹配。如果我们只想用 Pair<T, U> 参数调用函数，这是理想的。

在某些情况下，我们可能编写希望与任何能成功编译的类型一起使用的函数模板。为此，我们只需使用类型模板参数作为函数参数。

例如：

#include <iostream>

template <typename T, typename U>
struct Pair
{
    T first{};
    U second{};
};

struct Point
{
    int first{};
    int second{};
};

template <typename T>
void print(T p) // 类型模板参数将匹配任何内容
{
    std::cout << '[' << p.first << ", " << p.second << ']'; // 仅当类型具有 first 和 second 成员时才会编译
}

int main()
{
    Pair<double, int> p1{ 4.5, 6 };
    print(p1); // 匹配 print(Pair<double, int>)

    std::cout << '\n';

    Point p2 { 7, 8 };
    print(p2); // 匹配 print(Point)

    std::cout << '\n';
    
    return 0;
}

在上面的例子中，我们重写了 print() ，使其只有一个类型模板参数（T），它将匹配任何类型。对于任何具有 first 和 second 成员的类类型，函数体都能成功编译。我们通过用类型为 print() 的对象调用 Pair<double, int>，然后再用类型为 Point。

的对象调用它来演示这一点。有一种情况可能具有误导性。考虑以下版本的 print()：

template <typename T, typename U>
struct Pair // 定义一个名为 Pair 的类类型
{
    T first{};
    U second{};
};

template <typename Pair> // 定义一个名为 Pair 的类型模板参数（隐藏了 Pair 类类型）
void print(Pair p)       // 这指的是模板参数 Pair，而不是类类型 Pair
{
    std::cout << '[' << p.first << ", " << p.second << ']';
}

你可能期望这个函数只在用 Pair 类类型参数调用时匹配。但这个版本的 print() 在功能上与之前模板参数命名为 T的版本完全相同，并且会匹配 任何 类型。问题在于，当我们定义 Pair 作为类型模板参数时，它会遮蔽全局作用域中名称 Pair 的其他用途。因此在函数模板内部， Pair 指的是模板参数 Pair，而不是类类型 Pair。由于类型模板参数可以匹配任何类型，这个 Pair 匹配任何参数类型，而不仅仅是类类型 Pair！

这是坚持使用简单模板参数名称（如 T， U， N）的一个好理由，因为它们不太可能遮蔽类类型名称。

std::pair

由于处理数据对很常见，C++标准库包含一个名为 std::pair （位于 <utility> 头文件中）的类模板，其定义与上一节中具有多个模板类型的 Pair 类模板完全相同。事实上，我们可以将我们开发的 pair 结构体替换为 std::pair：

#include <iostream>
#include <utility>

template <typename T, typename U>
void print(std::pair<T, U> p)
{
    // std::pair 的成员有预定义名称 `first` 和 `second`
    std::cout << '[' << p.first << ", " << p.second << ']';
}

int main()
{
    std::pair<int, double> p1{ 1, 2.3 }; // 一个持有 int 和 double 的 pair
    std::pair<double, int> p2{ 4.5, 6 }; // 一个持有 double 和 int 的 pair
    std::pair<int, int> p3{ 7, 8 };      // 一个持有两个 int 的 pair

    print(p2);

    return 0;
}

我们在本课中开发了自己的 Pair 类来展示工作原理，但在实际代码中，你应该优先使用 std::pair 覆盖你自己的。

在多个文件中使用类模板

就像函数模板一样，类模板通常定义在头文件中，以便它们可以被包含到任何需要它们的代码文件中。模板定义和类型定义都免于单一定义规则，因此这不会引起问题：

pair.h：

#ifndef PAIR_H
#define PAIR_H

template <typename T>
struct Pair
{
    T first{};
    T second{};
};

template <typename T>
constexpr T max(Pair<T> p)
{
    return (p.first < p.second ? p.second : p.first);
}

#endif

foo.cpp：

#include "pair.h"
#include <iostream>

void foo()
{
    Pair<int> p1{ 1, 2 };
    std::cout << max(p1) << " is larger\n";
}

main.cpp:

#include "pair.h"
#include <iostream>

void foo(); // 函数 foo() 的前向声明

int main()
{
    Pair<double> p2 { 3.4, 5.6 };
    std::cout << max(p2) << " is larger\n";

    foo();

    return 0;
}
