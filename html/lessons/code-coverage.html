9.2 — 代码覆盖率

● 机器译文 课程 9.2 查看英文原文

在上一节课 9.1 -- Introduction to testing your code我们讨论了如何编写和保留简单测试。在本课中，我们将讨论哪些类型的测试有助于确保代码的正确性。

代码覆盖率

术语 代码覆盖率 用于描述测试过程中程序源代码被执行的程度。有许多不同的指标用于衡量代码覆盖率。在接下来的章节中，我们将介绍一些更有用和流行的指标。

语句覆盖率

术语 语句覆盖率 指的是代码中被测试例程执行过的语句的百分比。

考虑以下函数：

int foo(int x, int y)
{
    int z{ y };
    if (x > y)
    {
        z = x;
    }
    return z;
}

调用此函数为 foo(1, 0) 将获得该函数的完全语句覆盖率，因为函数中的每条语句都会被执行。

对于我们的 isLowerVowel() 函数：

bool isLowerVowel(char c)
{
    switch (c) // 语句1
    {
    case 'a':
    case 'e':
    case 'i':
    case 'o':
    case 'u':
        return true; // 语句2
    default:
        return false; // 语句3
    }
}

这个函数需要两次调用来测试所有语句，因为无法在同一次函数调用中到达语句2和3。

虽然追求100%的语句覆盖率是好的，但这通常不足以确保正确性。

分支覆盖率

分支覆盖率 指的是已执行分支的百分比，每个可能的分支单独计数。一个 if statement 有两个分支——一个分支在条件为 true时执行，另一个分支在条件为 false 时执行（即使没有对应的 else statement 要执行）。一个switch语句可以有多个分支。

int foo(int x, int y)
{
    int z{ y };
    if (x > y)
    {
        z = x;
    }
    return z;
}

之前对foo(1, 0)的调用给了我们100%的语句覆盖率，并测试了 x > y的情况，但这只给了我们50%的分支覆盖率。我们需要再调用一次， foo(0, 1)来测试 if statement 不执行的情况。

bool isLowerVowel(char c)
{
    switch (c)
    {
    case 'a':
    case 'e':
    case 'i':
    case 'o':
    case 'u':
        return true;
    default:
        return false;
    }
}

在isLowerVowel()函数中，需要两次调用才能获得100%的分支覆盖率：一次（例如 isLowerVowel('a')）测试前几个case，另一次（例如 isLowerVowel('q')）测试default case。多个case进入同一个代码体不需要单独测试——如果一个能工作，它们都应该能工作。

现在考虑以下函数：

void compare(int x, int y)
{
	if (x > y)
		std::cout << x << " is greater than " << y << '\n'; // // 情况1
	else if (x < y)
		std::cout << x << " is less than " << y << '\n'; // // 情况2
	else
		std::cout << x << " is equal to " << y << '\n'; // // 情况3
}

0, 1, 2测试

#include <iostream>

void spam(int timesToPrint)
{
    for (int count{ 0 }; count < timesToPrint; ++count)
         std::cout << "Spam! ";
}

要正确测试此函数内的循环，应调用它三次： spam(0) 测试零次迭代的情况， spam(1) 测试一次迭代的情况，以及 spam(2) 测试两次迭代的情况。如果 spam(2) 有效，那么 spam(n) 应该有效，其中 n > 2。

最佳实践

使用 0, 1, 2 test 以确保你的循环在不同迭代次数下正常工作。

测试不同类别的输入

在编写接受参数的函数或接受用户输入时，考虑不同类别的输入会发生什么。在这里，我们使用术语“类别”来表示具有相似特征的一组输入。

例如，如果我编写一个函数来计算整数的平方根，用哪些值来测试它才有意义？你可能从一些正常值开始，比如 4。但用 0和负数来测试也是一个好主意。

以下是类别测试的一些基本指南：

对于整数，确保你已考虑函数如何处理负值、零和正值。如果相关，还应检查溢出。

对于浮点数，确保你已考虑函数如何处理有精度问题的值（略大于或略小于预期的值）。好的 double 类型值测试包括 0.1 和 -0.1 （测试略大于预期的数字）和 0.7 和 -0.7 （测试略小于预期的数字）。

对于字符串，确保你已考虑函数如何处理空字符串、字母数字字符串、包含空白（前导、尾部和内部）的字符串以及全空白字符串。

如果你的函数接受指针，别忘了测试 nullptr （如果这没有意义，别担心，我们还没讲到）。

最佳实践

测试不同类别的输入值，以确保你的单元正确处理它们。

问题 #1

什么是分支覆盖率？

显示答案

分支覆盖率是已执行分支的百分比，肯定情况和否定情况分别计数。

问题 #2

以下函数至少需要多少次测试才能最小化地验证其工作？

bool isLowerVowel(char c, bool yIsVowel)
{
    switch (c)
    {
    case 'a':
    case 'e':
    case 'i':
    case 'o':
    case 'u':
        return true;
    case 'y':
        return yIsVowel;
    default:
        return false;
    }
}

显示答案

4次测试。一次测试a/e/i/o/u的情况。一次测试默认情况。一次测试 isLowerVowel('y', true)。以及一次测试 isLowerVowel('y', false)。
