7.1 — 复合语句（块）

● 机器译文 课程 7.1 查看英文原文

一个 复合语句 （也称为 块，或 块语句）是一组 零个或多个语句 ，编译器将其视为单个语句。

块以 { 符号开始，以 } 符号结束，中间放置要执行的语句。块可以在任何允许单个语句的地方使用。块末尾不需要分号。

在编写函数时，你已经见过块的例子，因为函数体就是一个块：

int add(int x, int y)
{ // 开始块
    return x + y;
} // 结束块（无分号）

int main()
{ // 开始块

    // 多个语句
    int value {}; // 这是初始化，不是块
    add(3, 4);

    return 0;

} // 结束块（无分号）

块内部的块

虽然函数不能嵌套在其他函数内部，但块 可以 嵌套在其他块内部：

int add(int x, int y)
{ // 块
    return x + y;
} // 结束块

int main()
{ // 外部块

    // 多个语句
    int value {};

    { // 内部/嵌套块
        add(3, 4);
    } // 结束内部/嵌套块

    return 0;

} // 结束外部块

当块嵌套时，外层的块通常称为 外层块 ，内层的块称为 内层块 或 嵌套块。

使用块有条件地执行多个语句

块最常见的用途之一是与 if statements结合使用。默认情况下， if statement 在条件求值为 true时执行单个语句。但是，如果我们希望在条件求值为 true。

例如：

#include <iostream>

int main()
{ // 外部块开始
    std::cout << "Enter an integer: ";
    int value {};
    std::cin >> value;
    
    if (value >= 0)
    { // 嵌套块开始
        std::cout << value << " is a positive integer (or zero)\n";
        std::cout << "Double this number is " << value * 2 << '\n';
    } // 嵌套块结束
    else
    { // 另一个嵌套块开始
        std::cout << value << " is a negative integer\n";
        std::cout << "The positive of this number is " << -value << '\n';
    } // 另一个嵌套块结束

    return 0;
} // 外部块结束

时执行多个语句，可以用一个语句块替换这个单个语句。

Enter an integer: 3
3 is a positive integer (or zero)
Double this number is 6

如果用户输入数字 3，该程序输出：

Enter an integer: -4
-4 is a negative integer
The positive of this number is 4

如果用户输入数字 -4，该程序输出：

块嵌套层级

#include <iostream>

int main()
{ // 块1，嵌套层级1
    std::cout << "Enter an integer: ";
    int value {};
    std::cin >> value;
    
    if (value >  0)
    { // 块2，嵌套层级2
        if ((value % 2) == 0)
        { // 块3，嵌套层级3
            std::cout << value << " is positive and even\n";
        }
        else
        { // 块4，也是嵌套层级3
            std::cout << value << " is positive and odd\n";
        }
    }

    return 0;
}

浮点类型的 嵌套层级 （也称为 嵌套深度）是函数中任何一点可以处于的最大嵌套块数量（包括外层块）。在上面的函数中，有 4 个块，但嵌套层级是 3，因为在该程序中，任何时候最多只能处于 3 个块内部。

C++ 标准规定 C++ 编译器应支持 256 层嵌套——但并非所有编译器都支持（例如，在撰写本文时，Visual Studio 支持更少）。

最好将嵌套层级保持在 3 或更少。正如过长的函数适合重构（拆分为更小的函数），过度嵌套的块难以阅读，也适合重构（将最内层的块变成独立的函数）。

最佳实践

将函数的嵌套层级保持在 3 或更少。如果函数需要更多嵌套层级，考虑将函数重构为子函数。
