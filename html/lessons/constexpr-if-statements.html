8.4 — Constexpr if 语句

● 机器译文 课程 8.4 查看英文原文

通常，if 语句的条件是在运行时求值的。

然而，考虑条件为常量表达式的情况，例如以下示例：

#include <iostream>

int main()
{
	constexpr double gravity{ 9.8 };

	// 提醒：相同类型的低精度浮点字面量可以测试相等性
	if (gravity == 9.8) // 常量表达式，始终为真
		std::cout << "Gravity is normal.\n";   // 将始终被执行
	else
		std::cout << "We are not on Earth.\n"; // 将永远不会被执行

	return 0;
}

因为 gravity 是 constexpr 且初始化为值 9.8，条件 gravity == 9.8 必须求值为 true。因此，else 语句永远不会被执行。

在运行时求值一个 constexpr 条件是浪费的（因为结果永远不会变化）。将永远不会执行的代码编译到可执行文件中也是浪费的。

Constexpr if 语句 C++17

C++17 引入了 constexpr if 语句，它要求条件为常量表达式。constexpr-if 语句的条件将在编译时求值。

如果 constexpr 条件求值为 true，则整个 if-else 将被替换为 true 语句。如果 constexpr 条件求值为 false，则整个 if-else 将被替换为 false 语句（如果存在）或什么也不替换（如果没有 else）。

要使用 constexpr-if 语句，我们在 constexpr 关键字后添加 if：

#include <iostream>

int main()
{
	constexpr double gravity{ 9.8 };

	if constexpr (gravity == 9.8) // 现在使用 constexpr if
		std::cout << "Gravity is normal.\n";
	else
		std::cout << "We are not on Earth.\n";

	return 0;
}

当上述代码被编译时，编译器将在编译时求值条件，发现它总是 true，并只保留单个语句 std::cout << "Gravity is normal.\n";。

换句话说，它将编译为：

int main()
{
	constexpr double gravity{ 9.8 };

	std::cout << "Gravity is normal.\n";

	return 0;
}

最佳实践

当条件为常量表达式时，优先使用 constexpr if 语句而非非 constexpr if 语句。

现代编译器与带 constexpr 条件的 if 语句 C++17

为了优化，现代编译器通常会将带有 constexpr 条件的非 constexpr if 语句视为 constexpr-if 语句。但它们并非必须这样做。

遇到带有 constexpr 条件的非 constexpr if 语句时，编译器可能会发出警告，建议你改用 if constexpr 这将确保编译时求值发生（即使优化被禁用）。
