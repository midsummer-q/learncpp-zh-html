13.4 — 将枚举转换为字符串以及从字符串转换回枚举

● 机器译文 课程 13.4 查看英文原文

在上一课（13.3 -- 无作用域枚举器整型转换），我们展示了一个这样的例子：

#include <iostream>

enum Color
{
    black, // 0
    red,   // 1
    blue,  // 2
};

int main()
{
    Color shirt{ blue };

    std::cout << "Your shirt is " << shirt << '\n';

    return 0;
}

这会打印：

Your shirt is 2

因为 operator<< 不知道如何打印 Color初始化时，编译器会隐式转换 Color 转换为整数值并打印它。

大多数情况下，将枚举打印为整数值（例如 2）并不是我们想要的。相反，我们通常希望打印枚举器所代表的名称（例如 blue）。C++ 没有提供现成的方法来实现这一点，所以我们必须自己找到解决方案。幸运的是，这并不难。

获取枚举器的名称

获取枚举器名称的典型方法是编写一个函数，允许我们传入一个枚举器并返回该枚举器的名称作为字符串。但这需要某种方法来确定对于给定的枚举器应返回哪个字符串。

有两种常见的方法可以实现这一点。

在课程 8.5 -- Switch语句基础，我们注意到 switch 语句可以切换整数值或枚举值。在下面的示例中，我们使用 switch 语句选择一个枚举器并返回该枚举器对应的颜色字符串字面量：

#include <iostream>
#include <string_view>

enum Color
{
    black,
    red,
    blue,
};

constexpr std::string_view getColorName(Color color)
{
    switch (color)
    {
    case black: return "black";
    case red:   return "red";
    case blue:  return "blue";
    default:    return "???";
    }
}

int main()
{
    constexpr Color shirt{ blue };

    std::cout << "Your shirt is " << getColorName(shirt) << '\n';

    return 0;
}

这会打印：

Your shirt is blue

在上面的例子中，我们切换 color，它保存了我们传入的枚举器。在 switch 内部，我们为每个枚举器设置了一个 case 标签 Color。每个 case 返回相应颜色的名称作为 C 风格字符串字面量。这个 C 风格字符串字面量会隐式转换为 std::string_view，并返回给调用者。我们还有一个 default case，返回 "???"，以防用户传入我们未预期的内容。

提醒

由于 C 风格字符串字面量在整个程序期间都存在，因此返回一个查看 C 风格字符串字面量的 std::string_view 是安全的。当 std::string_view 被复制回调用者时，被查看的 C 风格字符串字面量仍然存在。

该函数是 constexpr 的，这样我们可以在常量表达式中使用颜色的名称。

相关内容

Constexpr 函数在课程 F.1 -- Constexpr函数。

中介绍。虽然这让我们能够获取枚举器的名称，但如果想将其打印到控制台，必须使用 std::cout << getColorName(shirt) 并不像 std::cout << shirt那样方便。我们将在接下来的课程 std::cout 中教你如何打印枚举。 13.5 -- 重载 I/O 运算符简介。

中介绍。无作用域枚举的输入

现在让我们看一个输入的例子。在下面的示例中，我们定义了一个 Pet 枚举。由于 Pet 是程序定义的类型，语言不知道如何输入 Pet using std::cin：

#include <iostream>

enum Pet
{
    cat,   // 0
    dog,   // 1
    pig,   // 2
    whale, // 3
};

int main()
{
    Pet pet { pig };
    std::cin >> pet; // 编译错误：std::cin 不知道如何输入 Pet

    return 0;
}

一个简单的解决方法是读入一个整数，并使用 static_cast 将该整数转换为相应枚举类型的枚举器：

#include <iostream>
#include <string_view>

enum Pet
{
    cat,   // 0
    dog,   // 1
    pig,   // 2
    whale, // 3
};

constexpr std::string_view getPetName(Pet pet)
{
    switch (pet)
    {
    case cat:   return "cat";
    case dog:   return "dog";
    case pig:   return "pig";
    case whale: return "whale";
    default:    return "???";
    }
}

int main()
{
    std::cout << "Enter a pet (0=cat, 1=dog, 2=pig, 3=whale): ";

    int input{};
    std::cin >> input; // 输入一个整数

    if (input < 0 || input > 3)
        std::cout << "You entered an invalid pet\n";
    else
    {
        Pet pet{ static_cast<Pet>(input) }; // 将我们的整数 static_cast 为 Pet
        std::cout << "You entered: " << getPetName(pet) << '\n';
    }

    return 0;
}

虽然这可行，但有点笨拙。另外请注意，我们只应在知道 static_cast<Pet>(input) 在枚举器范围内时使用 input

从字符串获取枚举

与其输入数字，不如让用户输入一个表示枚举器的字符串（例如“pig”），然后我们可以将该字符串转换为相应的 Pet 枚举器。然而，这样做需要解决几个挑战。

首先，我们不能在字符串上使用 switch，所以需要使用其他方法来匹配用户传入的字符串。最简单的方法是使用一系列 if 语句。

第二，如果用户传入一个无效字符串，我们应该返回哪个 Pet 枚举值？一种选择是添加一个表示“无/无效”的枚举值，然后返回它。然而，更好的选择是使用 std::optional

相关内容

我们介绍 std::optional 在课程 12.15 -- std::optional。

#include <iostream>
#include <optional> // for std::optional
#include <string>
#include <string_view>

enum Pet
{
    cat,   // 0
    dog,   // 1
    pig,   // 2
    whale, // 3
};

constexpr std::string_view getPetName(Pet pet)
{
    switch (pet)
    {
    case cat:   return "cat";
    case dog:   return "dog";
    case pig:   return "pig";
    case whale: return "whale";
    default:    return "???";
    }
}

constexpr std::optional<Pet> getPetFromString(std::string_view sv)
{
    // 我们只能对整型值（或枚举）进行 switch，不能对字符串进行 switch
    // 所以这里我们必须使用 if 语句
    if (sv == "cat")   return cat;
    if (sv == "dog")   return dog;
    if (sv == "pig")   return pig;
    if (sv == "whale") return whale;
    
    return {};
}

int main()
{
    std::cout << "Enter a pet: cat, dog, pig, or whale: ";
    std::string s{};
    std::cin >> s;
        
    std::optional<Pet> pet { getPetFromString(s) };

    if (!pet)
        std::cout << "You entered an invalid pet\n";
    else
        std::cout << "You entered: " << getPetName(*pet) << '\n';

    return 0;
}

在上述解决方案中，我们使用一系列 if-else 语句进行字符串比较。如果用户的输入字符串匹配某个枚举字符串，我们就返回相应的枚举值。如果没有字符串匹配，我们就返回 {}，它表示“无值”。

进阶读者

注意，上述解决方案只匹配小写字母。如果你想匹配任何字母大小写，可以使用以下函数将用户输入转换为小写：

#include <algorithm> // for std::transform
#include <cctype>    // for std::tolower
#include <iterator>  // for std::back_inserter
#include <string>
#include <string_view>

// 此函数返回传入的 std::string_view 的小写版本 std::string。
// 此函数只能执行 1:1 的字符映射
std::string toASCIILowerCase(std::string_view sv)
{
    std::string lower{};
    std::transform(sv.begin(), sv.end(), std::back_inserter(lower),
        [](char c)
        { 
            return static_cast<char>(std::tolower(static_cast<unsigned char>(c)));
        });
    return lower;
}

该函数遍历 std::string_view sv中的每个字符，使用 std::tolower() （借助 lambda）将其转换为小写字符，然后将该小写字符追加到 lower。
