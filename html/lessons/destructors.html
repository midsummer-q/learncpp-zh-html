19.3 — 析构函数

● 机器译文 课程 19.3 查看英文原文

一个 析构函数 是另一种特殊的类成员函数，当该类的对象被销毁时执行。构造函数用于初始化类，而析构函数则用于帮助清理。

当对象正常超出作用域，或使用 delete 关键字显式删除动态分配的对象时，类的析构函数会自动调用（如果存在），以便在对象从内存中移除之前进行必要的清理。对于简单的类（仅初始化普通成员变量的值），不需要析构函数，因为 C++ 会自动为你清理内存。

然而，如果你的类对象持有任何资源（例如动态内存、文件或数据库句柄），或者需要在对象销毁前进行某种维护，析构函数是执行这些操作的理想位置，因为它通常是对象销毁前最后发生的事情。

析构函数命名

与构造函数一样，析构函数有特定的命名规则：

  1. 析构函数必须与类同名，前面加一个波浪号（~）。
  2. 析构函数不能接受参数。
  3. 析构函数没有返回类型。

一个类只能有一个析构函数。

通常你不应该显式调用析构函数（因为它会在对象销毁时自动调用），因为很少有需要多次清理对象的情况。不过，析构函数可以安全地调用其他成员函数，因为对象在析构函数执行完毕后才会被销毁。

析构函数示例

让我们看一个使用析构函数的简单类：

#include <iostream>
#include <cassert>
#include <cstddef>

class IntArray
{
private:
	int* m_array{};
	int m_length{};

public:
	IntArray(int length) // 构造函数
	{
		assert(length > 0);

		m_array = new int[static_cast<std::size_t>(length)]{};
		m_length = length;
	}

	~IntArray() // 析构函数
	{
		// 动态删除我们之前分配的数组
		delete[] m_array;
	}

	void setValue(int index, int value) { m_array[index] = value; }
	int getValue(int index) { return m_array[index]; }

	int getLength() { return m_length; }
};

int main()
{
	IntArray ar ( 10 ); // 分配 10 个整数
	for (int count{ 0 }; count < ar.getLength(); ++count)
		ar.setValue(count, count+1);

	std::cout << "The value of element 5 is: " << ar.getValue(5) << '\n';

	return 0;
} // ar 在此处销毁，因此调用 ~IntArray() 析构函数

提示

如果你编译上述示例并得到以下错误：

error: 'class IntArray' has pointer data members [-Werror=effc++]|
error:   but does not override 'IntArray(const IntArray&)' [-Werror=effc++]|
error:   or 'operator=(const IntArray&)' [-Werror=effc++]|

那么你可以从编译设置中移除“-Weffc++”标志，或者向类中添加以下两行：

	IntArray(const IntArray&) = delete;
	IntArray& operator=(const IntArray&) = delete;

我们在 =delete 用于课程中的成员 14.14 -- 拷贝构造函数简介

该程序产生结果：

The value of element 5 is: 6

在 main() 的第一行，我们实例化了一个名为 ar 的新 IntArray 类对象，并传入长度 10。这会调用构造函数，该函数为数组成员动态分配内存。我们必须在这里使用动态分配，因为在编译时我们不知道数组的长度（由调用者决定）。

在 main() 的末尾，ar 超出作用域。这会导致调用 ~IntArray() 析构函数，该函数删除我们在构造函数中分配的数组！

提醒

在课程 16.2 -- std::vector 与列表构造函数简介我们注意到，当使用长度（而非元素列表）初始化数组/容器/列表类时，应使用基于括号的初始化。因此，我们使用以下方式初始化 IntArray： IntArray ar ( 10 );。

构造函数和析构函数的时机

如前所述，构造函数在对象创建时调用，析构函数在对象销毁时调用。在下面的示例中，我们在构造函数和析构函数内部使用 cout 语句来展示这一点：

#include <iostream>

class Simple
{
private:
    int m_nID{};

public:
    Simple(int nID)
        : m_nID{ nID }
    {
        std::cout << "Constructing Simple " << nID << '\n';
    }

    ~Simple()
    {
        std::cout << "Destructing Simple" << m_nID << '\n';
    }

    int getID() { return m_nID; }
};

int main()
{
    // 在栈上分配一个 Simple 对象
    Simple simple{ 1 };
    std::cout << simple.getID() << '\n';

    // 动态分配一个 Simple 对象
    Simple* pSimple{ new Simple{ 2 } };
    
    std::cout << pSimple->getID() << '\n';

    // 我们动态分配了 pSimple，因此必须删除它。
    delete pSimple;

    return 0;
} // simple 在此处超出作用域

该程序产生以下结果：

Constructing Simple 1
1
Constructing Simple 2
2
Destructing Simple 2
Destructing Simple 1

注意，“Simple 1”在“Simple 2”之后销毁，因为我们在函数结束前删除了 pSimple，而 simple 直到 main() 结束时才被销毁。

全局变量在 main() 之前构造，在 main() 之后销毁。

RAII

RAII（资源获取即初始化）是一种编程技术，它将资源使用与具有自动生存期（例如非动态分配的对象）的对象的生命周期绑定。在 C++ 中，RAII 通过具有构造函数和析构函数的类来实现。资源（如内存、文件或数据库句柄等）通常在对象的构造函数中获取（尽管如果合理，也可以在对象创建后获取）。然后可以在对象存活期间使用该资源。资源在析构函数中释放，即对象销毁时。RAII 的主要优点是它有助于防止资源泄漏（例如内存未释放），因为所有持有资源的对象都会自动清理。

本课程顶部的 IntArray 类是一个实现 RAII 的类示例——在构造函数中分配，在析构函数中释放。std::string 和 std::vector 是标准库中遵循 RAII 的类示例——动态内存在初始化时获取，并在销毁时自动清理。

关于 std::exit() 函数的警告

请注意，如果你使用 std::exit() 函数，程序将终止，并且不会调用任何析构函数。如果你依赖析构函数进行必要的清理工作（例如在退出前写入日志文件或数据库），请务必小心。

总结

如你所见，当构造函数和析构函数一起使用时，你的类可以自行初始化和清理，而无需程序员执行任何特殊工作！这降低了出错的可能性，并使类更易于使用。
