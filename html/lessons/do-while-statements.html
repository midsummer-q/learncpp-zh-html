8.9 — do while 语句

● 机器译文 课程 8.9 查看英文原文

考虑这样一种情况：我们想向用户显示一个菜单，并让他们做出选择——如果用户选择了无效的选择，则再次询问他们。显然，菜单和选择应该放在某种循环中（这样我们可以不断询问用户，直到他们输入有效输入），但我们应该选择哪种循环呢？

由于 while 循环会预先评估条件，因此这是一个尴尬的选择。我们可以像这样解决问题：

#include <iostream>

int main()
{
    // selection 必须在 while 循环外部声明，以便我们稍后使用它
    int selection {}; // 值初始化为 0

    while (selection < 1 || selection > 4)
    {
        std::cout << "Please make a selection: \n";
        std::cout << "1) Addition\n";
        std::cout << "2) Subtraction\n";
        std::cout << "3) Multiplication\n";
        std::cout << "4) Division\n";
        std::cin >> selection;
    }

    // 在此处对 selection 进行操作
    // 例如 switch 语句

    std::cout << "You selected option #" << selection << '\n';

    return 0;
}

但这只有在我们的初始值 0 对于 selection 不在有效值集合中时才有效（1, 2, 3 or 4）。如果 0 是一个有效选择呢？我们必须选择一个不同的初始值来表示“无效”——而现在我们正在代码中引入魔法数字（5.2 -- 字面量）。

我们可以改为添加一个新变量来跟踪有效性，如下所示：

#include <iostream>

int main()
{
    int selection {};
    bool invalid { true }; // 新变量仅用于控制循环

    while (invalid)
    {
        std::cout << "Please make a selection: \n";
        std::cout << "1) Addition\n";
        std::cout << "2) Subtraction\n";
        std::cout << "3) Multiplication\n";
        std::cout << "4) Division\n";

        std::cin >> selection;
        invalid = (selection < 1 || selection > 4);
    }

    // 在此处对 selection 进行操作
    // 例如 switch 语句

    std::cout << "You selected option #" << selection << '\n';

    return 0;
}

虽然这避免了魔法数字，但它引入了一个新变量仅仅是为了确保循环执行一次，这增加了复杂性以及出现额外错误的可能性。

do while 语句

为了帮助解决上述问题，C++ 提供了 do-while 语句：

do
    statement; // can be a single statement or a compound statement
while (condition);

一个 do while 语句 是一种循环结构，其工作方式与 while 循环类似，只是语句总是至少执行一次。语句执行后，do-while 循环检查条件。如果条件求值为 true，则执行路径跳回到 do-while 循环的顶部并再次执行它。

以下是上面使用 do-while 循环而不是 while 循环的示例：

#include <iostream>

int main()
{
    // selection 必须在 do-while 循环外部声明，以便我们稍后使用它
    int selection {};

    do
    {
        std::cout << "Please make a selection: \n";
        std::cout << "1) Addition\n";
        std::cout << "2) Subtraction\n";
        std::cout << "3) Multiplication\n";
        std::cout << "4) Division\n";
        std::cin >> selection;
    }
    while (selection < 1 || selection > 4);

    // 在此处对 selection 进行操作
    // 例如 switch 语句

    std::cout << "You selected option #" << selection << '\n';

    return 0;
}

通过这种方式，我们既避免了魔法数字，也避免了额外的变量。

在上述示例中，值得讨论的一点是 selection 变量必须在 do 块外部声明。如果 selection 变量在 do 块内部声明，它将在 do 块终止时被销毁，而这发生在条件求值之前。但我们在 while 条件中需要该变量——因此， selection 变量必须在 do 块外部声明（即使它稍后在函数体中未被使用）。

在实践中，do-while 循环并不常用。将条件放在循环底部会掩盖循环条件，可能导致错误。因此，许多开发者建议完全避免使用 do-while 循环。我们将采取更温和的立场，主张在同等条件下优先使用 while 循环而非 do-while 循环。

最佳实践

在同等条件下，优先使用 while 循环而非 do-while 循环。
