10.2 — 浮点数和整型提升

● 机器译文 课程 10.2 查看英文原文

在课程 4.3 -- 对象大小和sizeof运算符我们注意到，C++ 对每种基本类型都有最小大小保证。然而，这些类型的实际大小可能因编译器和架构而异。

这种可变性是被允许的，以便 int 和 double 数据类型可以设置为在给定架构上最大化性能的大小。例如，一台 32 位计算机通常一次能处理 32 位数据。在这种情况下， int 可能被设置为 32 位宽度，因为这是 CPU 操作数据的“自然”大小（并且可能是性能最高的）。

提醒

数据类型使用的位数称为其宽度。更宽的数据类型使用更多位，而更窄的数据类型使用更少位。

但是，当我们希望 32 位 CPU 修改一个 8 位值（例如 char）或 16 位值时会发生什么？一些 32 位处理器（例如 32 位 x86 CPU）可以直接操作 8 位或 16 位值。然而，这样做通常比操作 32 位值更慢！其他 32 位 CPU（如 32 位 PowerPC CPU）只能操作 32 位值，必须采用额外的技巧来操作更窄的值。

数值提升

由于 C++ 被设计为在广泛的架构上可移植且高性能，语言设计者不希望假设给定的 CPU 能够高效地操作比该 CPU 自然数据大小更窄的值。

为了帮助解决这一挑战，C++ 定义了一类类型转换，非正式地称为 numeric promotions。一个 数值提升 是将某些较窄的数值类型（例如 char）转换为某些更宽的数值类型（通常是 int 或 double），以便能够高效处理。

所有数值提升都是值保持的。 值保持转换 （也称为 安全转换）是指每个可能的源值都可以转换为目标类型的相等值。

由于提升是安全的，编译器将根据需要自由使用数值提升，并且在这样做时不会发出警告。

数值提升减少冗余

数值提升还解决了另一个问题。考虑您想编写一个函数来打印类型为 int：

#include <iostream>

void printInt(int x)
{
    std::cout << x << '\n';
}

的值。虽然这很简单，但如果我们还想能够打印类型为 short或类型 char的值呢？如果类型转换不存在，我们就必须为 short 编写另一个打印函数，再为 char编写另一个。别忘了还有 unsigned char， signed char， unsigned short， wchar_t， char8_t， char16_t、和 char32_t的版本！您可以看到这很快就变得难以管理。

数值提升在这里派上了用场：我们可以编写具有 int 和/或 double 参数的函数（例如上面的 printInt() 函数）。相同的代码可以用于调用那些参数类型可以通过数值提升匹配函数参数类型的参数。

数值提升类别

数值提升规则分为两个子类别： integral promotions 和 floating point promotions。只有这些类别中列出的转换才被视为数值提升。

浮点提升

我们先从较简单的开始。

在局部变量上使用 浮点提升 规则中，类型为 float 的值可以转换为类型为 double。

的值。这意味着我们可以编写一个接受 double 然后用一个 double 变为 float 值调用它：

#include <iostream>

void printDouble(double d)
{
    std::cout << d << '\n';
}

int main()
{
    printDouble(5.0); // 无需转换
    printDouble(4.0f); // float 到 double 的数值提升

    return 0;
}

在第二次调用 printDouble()， float 字面量 4.0f 被提升为 double，使得参数类型与函数参数类型匹配。

整型提升

整型提升规则更复杂。

在局部变量上使用 整型提升 规则下，可以进行以下转换：

  • signed char 或 signed short 可以转换为 int。
  • unsigned char、char8_t 和 unsigned short 可以转换为 int（如果 int 能容纳该类型的全部范围），否则转换为 unsigned int。
  • 如果 char 默认是有符号的，则遵循上述 signed char 转换规则；如果默认是无符号的，则遵循上述 unsigned char 转换规则。
  • bool 可以转换为 int，false 变为 0，true 变为 1。

假设一个 8 位字节和 int 大小为 4 字节或更大（这在当今很典型），上述内容基本上意味着 bool， char， signed char， unsigned char， signed short、和 unsigned short 都会被提升为 int。

还有一些其他较少使用的整型提升规则。可以在 https://en.cppreference.com/w/cpp/language/implicit_conversion#Integral_promotion 找到。。

在大多数情况下，这让我们可以编写一个接受 int 参数的函数，然后将其与各种其他整型类型一起使用。例如：

#include <iostream>

void printInt(int x)
{
    std::cout << x << '\n';
}

int main()
{
    printInt(2);

    short s{ 3 }; // 没有 short 字面量后缀，所以我们用变量
    printInt(s); // short 到 int 的数值提升

    printInt('a'); // char 到 int 的数值提升
    printInt(true); // bool 到 int 的数值提升

    return 0;
}

这里有两件事值得注意。首先，在某些架构上（例如，2 字节 int），某些无符号整型类型可能会被提升为 unsigned int 对于这个程序，我们有 3 个任务：获取初始塔高，计算球的当前高度，以及打印球的当前高度。根据函数应只做一件事的最佳实践，我们为每个任务编写不同的函数。 int。

其次，一些较窄的无符号类型（例如 unsigned char）可能会被提升为较大的有符号类型（例如 int）。因此，虽然整型提升保留了值，但它不一定保留类型的符号性（有符号/无符号）。

并非所有加宽转换都是数值提升

某些加宽类型转换（例如 char 切换到 short，或 int 切换到 long）在 C++ 中不被视为数值提升（它们是 numeric conversions，我们将在课程 10.3 -- 数值转换中很快介绍）。这是因为此类转换无助于将较小类型转换为可以更高效处理的较大类型的目标。

这种区别主要是学术性的。然而，在某些情况下，编译器会优先选择数值提升而不是数值转换。当我们介绍函数重载解析时（在即将到来的课程 11.3 -- 函数重载解析与歧义匹配)。
