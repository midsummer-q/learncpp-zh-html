15.9 — 友元类和友元成员函数

● 机器译文 课程 15.9 查看英文原文

友元类

一个 友元类 是一个可以访问另一个类的私有成员和保护成员的类。

下面是一个例子：

#include <iostream>

class Storage
{
private:
    int m_nValue {};
    double m_dValue {};
public:
    Storage(int nValue, double dValue)
       : m_nValue { nValue }, m_dValue { dValue }
    { }

    // 引用限定符
    friend class Display;
};

class Display
{
private:
    bool m_displayIntFirst {};

public:
    Display(bool displayIntFirst)
         : m_displayIntFirst { displayIntFirst }
    {
    }

    // 因为 Display 是 Storage 的友元，所以 Display 的成员可以访问 Storage 的私有成员
    void displayStorage(const Storage& storage)
    {
        if (m_displayIntFirst)
            std::cout << storage.m_nValue << ' ' << storage.m_dValue << '\n';
        else // 先显示 double
            std::cout << storage.m_dValue << ' ' << storage.m_nValue << '\n';
    }

    void setDisplayIntFirst(bool b)
    {
         m_displayIntFirst = b;
    }
};

int main()
{
    Storage storage { 5, 6.7 };
    Display display { false };

    display.displayStorage(storage);

    display.setDisplayIntFirst(true);
    display.displayStorage(storage);

    return 0;
}

由于 Display 类是 Storage， Display 的友元，因此 Storage 的成员可以访问它们有权访问的任何

该程序产生以下结果：

6.7 5
5 6.7

关于友元类的一些额外说明。

首先，即使 Display 是 Storage， Display 的友元， *this 也无法访问 Storage 对象的 *this 指针（因为

实际上是一个函数参数）。其次，友元关系不是互惠的。仅仅因为 Display 是 Storage 并不意味着 Storage 也是 Display的友元。如果你希望两个类互为友元，两者都必须将对方声明为友元。

作者注

如果这一点让你感同身受，那抱歉了！

类友元关系也不具有传递性。如果类 A 是 B 的友元，而 B 是 C 的友元，这并不意味着 A 是 C 的友元。

进阶读者

友元关系也不会被继承。如果类 A 将 B 设为友元，那么从 B 派生的类并不是 A 的友元。

友元类声明同时充当了被设为友元的类的前向声明。这意味着我们不需要在将其设为友元之前前向声明该类。在上面的例子中， friend class Display 既充当了 Display 的前向声明，又充当了友元声明。

友元成员函数

与其将整个类设为友元，不如将单个成员函数设为友元。这类似于将非成员函数设为友元，只不过使用的是成员函数的名称。

然而，实际上这可能比预期的要棘手一些。让我们将前面的例子转换为将 Display::displayStorage 设为友元成员函数。你可能会尝试这样写：

#include <iostream>

class Display; // 类 Display 的前向声明

class Storage
{
private:
	int m_nValue {};
	double m_dValue {};
public:
	Storage(int nValue, double dValue)
		: m_nValue { nValue }, m_dValue { dValue }
	{
	}

	// 将 Display::displayStorage 成员函数设为 Storage 类的友元
	friend void Display::displayStorage(const Storage& storage); // 错误：Storage 尚未看到类 Display 的完整定义
};

class Display
{
private:
	bool m_displayIntFirst {};

public:
	Display(bool displayIntFirst)
		: m_displayIntFirst { displayIntFirst }
	{
	}

	void displayStorage(const Storage& storage)
	{
		if (m_displayIntFirst)
			std::cout << storage.m_nValue << ' ' << storage.m_dValue << '\n';
		else // 先显示 double
			std::cout << storage.m_dValue << ' ' << storage.m_nValue << '\n';
	}
};

int main()
{
    Storage storage { 5, 6.7 };
    Display display { false };
    display.displayStorage(storage);

    return 0;
}

但事实证明这行不通。为了将单个成员函数设为友元，编译器必须已经看到了该友元成员函数所属类的完整定义（而不仅仅是前向声明）。由于类 Storage 还没有看到类 Display 的完整定义，编译器会在我们尝试将该成员函数设为友元的地方报错。

幸运的是，这很容易解决，只需将类 Display 的定义移到类 Storage 的定义之前（要么在同一个文件中，要么将 Display 的定义移到头文件中，并在定义 Storage 之前 #include 它）。

#include <iostream>

class Display
{
private:
	bool m_displayIntFirst {};

public:
	Display(bool displayIntFirst)
		: m_displayIntFirst { displayIntFirst }
	{
	}

	void displayStorage(const Storage& storage) // 编译错误：编译器不知道 Storage 是什么
	{
		if (m_displayIntFirst)
			std::cout << storage.m_nValue << ' ' << storage.m_dValue << '\n';
		else // 先显示 double
			std::cout << storage.m_dValue << ' ' << storage.m_nValue << '\n';
	}
};

class Storage
{
private:
	int m_nValue {};
	double m_dValue {};
public:
	Storage(int nValue, double dValue)
		: m_nValue { nValue }, m_dValue { dValue }
	{
	}

	// 将 Display::displayStorage 成员函数设为 Storage 类的友元
	friend void Display::displayStorage(const Storage& storage); // 现在可以了
};

int main()
{
    Storage storage { 5, 6.7 };
    Display display { false };
    display.displayStorage(storage);

    return 0;
}

然而，我们现在遇到了另一个问题。因为成员函数 Display::displayStorage() 使用 Storage 将 Storage 作为引用参数，而我们刚刚将 Display，编译器会抱怨它不知道 Storage 是什么。我们不能通过重新排列定义顺序来修复这个问题，因为那样会撤销我们之前的修复。

幸运的是，这也可以通过几个简单的步骤来修复。首先，我们可以添加 class Storage 作为前向声明，这样编译器就能接受在尚未看到类的完整定义之前对 Storage 的引用。

其次，我们可以将 Display::displayStorage() 的定义移出类，放在 Storage 类。

的完整定义之后。

#include <iostream>

class Storage; // 类 Storage 的前向声明

class Display
{
private:
	bool m_displayIntFirst {};

public:
	Display(bool displayIntFirst)
		: m_displayIntFirst { displayIntFirst }
	{
	}

	void displayStorage(const Storage& storage); // 此处需要 Storage 的前向声明以供引用
};

class Storage // Storage 类的完整定义
{
private:
	int m_nValue {};
	double m_dValue {};
public:
	Storage(int nValue, double dValue)
		: m_nValue { nValue }, m_dValue { dValue }
	{
	}

	// 将 Display::displayStorage 成员函数设为 Storage 类的友元
	// 需要看到类 Display 的完整定义（因为 displayStorage 是一个成员）
	friend void Display::displayStorage(const Storage& storage);
};

// 现在我们可以定义 Display::displayStorage
// 需要看到类 Storage 的完整定义（因为我们访问 Storage 的成员）
void Display::displayStorage(const Storage& storage)
{
	if (m_displayIntFirst)
		std::cout << storage.m_nValue << ' ' << storage.m_dValue << '\n';
	else // 先显示 double
		std::cout << storage.m_dValue << ' ' << storage.m_nValue << '\n';
}

int main()
{
    Storage storage { 5, 6.7 };
    Display display { false };
    display.displayStorage(storage);

    return 0;
}

下面是它的样子： class Storage 现在一切都能正确编译： Display::displayStorage() 内部定义了友元非成员函数 Display 的前向声明足以满足 Display 类的声明。 Display::displayStorage() 的完整定义满足了将 Storage声明为 Storage 的友元。而类 Display::displayStorage()。
