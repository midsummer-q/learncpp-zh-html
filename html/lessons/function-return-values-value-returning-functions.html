2.2 — 函数返回值（有返回值的函数）

● 机器译文 课程 2.2 查看英文原文

考虑以下程序：

#include <iostream>

int main()
{
	// 从用户处获取一个值
	std::cout << "Enter an integer: ";
	int num{};
	std::cin >> num;

	// 打印数值的两倍
	std::cout << num << " doubled is: " << num * 2 << '\n';

	return 0;
}

该程序由两个概念部分构成：首先，我们从用户那里获取一个值。然后，我们告诉用户这个值的两倍是多少。

尽管这个程序足够简单，我们不需要将其拆分为多个函数，但如果我们想这样做呢？从用户那里获取一个整数值是一个定义明确的任务，我们希望程序完成它，因此它很适合作为一个函数。

那么，让我们编写一个程序来实现这个功能：

// 此程序无法正常工作
#include <iostream>

void getValueFromUser()
{
 	std::cout << "Enter an integer: ";
	int input{};
	std::cin >> input;  
}

int main()
{
	getValueFromUser(); // 请求用户输入

	int num{}; // 如何从getValueFromUser()获取值并用它来初始化这个变量？

	std::cout << num << " doubled is: " << num * 2 << '\n';

	return 0;
}

虽然这个程序是一个不错的尝试，但它并不能正常工作。

当函数 getValueFromUser 被调用时，用户会按预期被要求输入一个整数。但用户输入的值会在 getValueFromUser 终止并将控制权返回给 main变量 num 永远不会用用户输入的值进行初始化，因此程序总是输出答案 0。

我们缺少的是某种方式让 getValueFromUser 将用户输入的值返回给 main 以便 main 能够使用该数据。

返回值

当你编写一个自定义函数时，你可以决定函数是否向调用者返回一个值。要向调用者返回一个值，需要做两件事。

首先，函数必须指明将返回什么类型的值。这通过设置函数的 返回类型来实现，该类型定义在函数名之前。在上面的例子中，函数 getValueFromUser 的返回类型为 void (意味着不会向调用者返回值) main 的返回类型为 int (意味着类型为 int 将返回给调用者)。请注意，这并不决定返回哪个具体值——它只决定 类型 类型的值将被返回。

相关内容

我们探讨返回 void 的内容将在下一课中进一步探讨（2.3 -- Void functions (non-value returning functions))。

其次，在将要返回值的函数内部，我们使用一个 return语句 来指示要返回给调用者的具体值。return语句由 return 关键字后跟一个表达式（有时称为 返回表达式），以分号结尾。

当return语句被执行时：

  • 返回表达式被求值以产生一个值。
  • 由返回表达式产生的值被复制回调用者。这个副本被称为 返回值 函数的。
  • 函数退出，控制权返回给调用者。

将复制的值返回给调用者的过程被称为 按值返回。

术语

返回表达式生成要返回的值。返回值是该值的一个副本。

一个返回值函数每次被调用时都会返回一个值。

让我们来看一个返回整数值的简单函数，以及一个调用它的示例程序：

#include <iostream>

// int 是返回类型
// int 作为返回类型意味着该函数将向调用者返回一个整数值（具体值未在此指定）
int returnFive()
{
    // return 语句提供了将被返回的值
    return 5; // 将值 5 返回给调用者
}

int main()
{
    std::cout << returnFive() << '\n'; // 打印 5
    std::cout << returnFive() + 2 << '\n'; // 打印 7

    returnFive(); // 可以：返回了值 5，但由于 main() 未对其进行任何操作，因此被忽略

    return 0;
}

运行后，该程序输出：

5
7

执行从顶部开始 main。在第一个语句中，函数调用 returnFive() 被求值，这导致函数 returnFive() 被调用。返回表达式 5 被求值以产生值 5，该值被返回给调用者并通过 std::cout。

在第二次函数调用中，对 returnFive 被求值，这导致函数 returnFive 再次被调用。函数 returnFive 返回值 5 给调用者。表达式 5 + 2 被求值以产生结果 7，然后通过 std::cout。

在第三个语句中，函数 returnFive 再次被调用，导致值 5 被返回给调用者。然而，函数 main 对返回值不做任何操作，因此不会发生进一步的事情（返回值被忽略）。

注意：除非调用者通过 std::cout。在上面的最后一个案例中，返回值没有被发送到 std::cout，因此不会打印任何内容。

提示

当被调用的函数返回一个值时，调用者可以选择在表达式或语句中使用该值（例如，用它来初始化一个变量，或者将其发送给 std::cout）或忽略它（不做任何其他操作）。如果调用者忽略了返回值，则该返回值将被丢弃（不对其进行任何操作）。

修复我们的挑战程序

有了这个认识，我们可以修复在本课开头展示的程序：

#include <iostream>

int getValueFromUser() // 此函数现在返回一个整数值
{
 	std::cout << "Enter an integer: ";
	int input{};
	std::cin >> input;  

	return input; // 将用户输入的值返回给调用者
}

int main()
{
	int num { getValueFromUser() }; // 使用 getValueFromUser() 的返回值初始化 num

	std::cout << num << " doubled is: " << num * 2 << '\n';

	return 0;
}

当这个程序执行时，中的第一条语句 main 将创建一个 int 变量，名为 num。当程序要初始化 num时，它会发现有一个对 getValueFromUser()，因此它将会执行那个函数。函数 getValueFromUser要求用户输入一个值，然后将其返回给调用者（main()）。这个返回值被用作变量 num。 num 然后可以在中根据需要多次使用 main()。

提示

如果需要多次使用函数调用的返回值，请用该返回值初始化一个变量，然后根据需要多次使用该变量。

自己编译这个程序并运行几次，以向自己证明它是有效的。

重新审视main()

你现在已经具备了理解 main() 函数实际上是如何工作的。当程序执行时，操作系统会调用 main()执行随后跳转到顶部 main()中的语句 main() 被顺序执行。最后， main() 返回一个整数值（通常是 0），然后你的程序终止。

在C++中，对于有两个特殊要求 main()：

  • main() 被要求返回一个 int。
  • 显式函数调用 main() 是不允许的。
void foo()
{
    main(); // 编译错误：不允许显式调用 main
}

void main() // 编译错误：不允许 main 具有非 int 返回类型
{
    foo();
}

关键提示

C允许 main() 被显式调用，因此一些C++编译器出于兼容性原因会允许这样做。

目前，你也应该定义你的 main() 函数在代码文件的底部，在其他函数下面，并避免显式调用它。

进阶读者

一个常见的误解是 main 总是第一个执行的函数。

全局变量在执行的之前被初始化 main如果此类变量的初始化器调用了一个函数，那么该函数将在之前执行 main。我们在第课中讨论全局变量 7.4 -- 全局变量简介。

状态码

你可能想知道为什么我们从 main(), 以及何时返回其他值。

来自 main() 有时被称为 状态码 (或较少见的，一个 退出码，或很少见的，一个 返回码)。状态码用于指示程序是否成功运行。

按照惯例，状态码为 0 表示程序正常运行（即程序按预期执行和行为）。

最佳实践

你的 main 函数应返回值 0 如果程序正常运行。

非零状态码通常用于表示某种失败（虽然这在大多数操作系统上运行良好，但严格来说，不能保证可移植性）。

进阶读者

C++ 标准仅定义了3个状态码的含义： 0， EXIT_SUCCESS、和 EXIT_FAILURE。 0 和 EXIT_SUCCESS 都表示程序执行成功。 EXIT_FAILURE 表示程序未成功执行。

EXIT_SUCCESS 和 EXIT_FAILURE 是在<cstdlib>头文件中定义的预处理器宏：

#include <cstdlib> // for EXIT_SUCCESS and EXIT_FAILURE

int main()
{
    return EXIT_SUCCESS;
}

如果你想要最大化可移植性，你应该只使用 0 或 EXIT_SUCCESS 来表示成功终止，或 EXIT_FAILURE 来表示不成功终止。

我们在课程中涵盖了预处理器和预处理器宏 2.10 -- 预处理器简介。

顺便说一句……

状态码被传递回操作系统。操作系统通常会将状态码提供给启动返回状态码的那个程序的任何程序。这为任何启动另一个程序并判断被启动程序是否成功运行的程序提供了一种粗略机制。

一个不返回值的返回值函数将产生未定义行为

返回值的函数被称为 返回值函数。如果返回类型不是void，则该函数是返回值的。 void。

一个返回值函数 必须 必须返回该类型的值（使用return语句），否则将导致未定义行为。

相关内容

我们在课程中讨论了未定义行为 1.6 -- 未初始化的变量和未定义行为。

这是一个产生未定义行为的函数示例：

#include <iostream>

int getValueFromUserUB() // 此函数返回一个整数值
{
 	std::cout << "Enter an integer: ";
	int input{};
	std::cin >> input;

	// 注意：没有 return 语句
}

int main()
{
	int num { getValueFromUserUB() }; // 使用 getValueFromUserUB() 的返回值初始化 num

	std::cout << num << " doubled is: " << num * 2 << '\n';

	return 0;
}

现代编译器应该会生成一条警告，因为 getValueFromUserUB 被定义为返回一个 int 但未提供return语句。运行这样的程序将产生未定义行为，因为 getValueFromUserUB() 是一个不返回值的返回值函数。

在大多数情况下，编译器会检测到你是否忘记返回一个值。然而，在某些复杂情况下，编译器可能无法在所有情况下正确判断你的函数是否返回值，因此你不应依赖于此。

最佳实践

确保你的非void返回类型的函数在所有情况下都返回一个值。

未能从返回值函数返回值将导致未定义行为。

如果未提供返回语句，main 函数将隐式返回 0。

对于必须通过返回语句返回值的函数规则，唯一的例外是函数 main(). 函数 main() 将隐式返回值 0 如果未提供返回语句。话虽如此，最佳实践是显式地从 main返回值，既要表明你的意图，也要与其他函数保持一致（其他函数如果未指定返回值将表现出未定义行为）。

函数只能返回一个值

每次调用时，返回值函数只能向调用者返回一个值。

请注意，返回语句中提供的值不一定是字面量——它可以是任何有效表达式的结果，包括变量或甚至返回值的另一个函数调用。在 getValueFromUser() 上面的例子中，我们返回了一个变量 input，它保存了用户输入的数字。

有多种方法可以绕过函数只能返回一个值的限制，我们将在未来的课程中介绍。

函数作者可以决定返回值的含义

函数返回值的含义由函数的作者决定。有些函数使用返回值作为状态码，指示它们是成功还是失败。其他函数返回计算或选择的值。还有一些函数不返回任何值（我们将在下一课中看到这些例子）。

由于这里可能性多种多样，最好用注释记录函数的返回值含义。例如：

// 函数要求用户输入一个值
// 返回值是用户从键盘输入的整数
int getValueFromUser()
{
 	std::cout << "Enter an integer: ";
	int input{};
	std::cin >> input;  

	return input; // 将用户输入的值返回给调用者
}

重用函数

现在我们可以说明一个函数重用的好例子。考虑以下程序：

#include <iostream>

int main()
{
	int x{};
	std::cout << "Enter an integer: ";
	std::cin >> x; 

	int y{};
	std::cout << "Enter an integer: ";
	std::cin >> y; 

	std::cout << x << " + " << y << " = " << x + y << '\n';

	return 0;
}

虽然这个程序可以工作，但有点冗余。事实上，这个程序违反了优秀编程的核心原则之一： 不要重复自己 （通常缩写为 DRY)。

为什么重复代码不好？如果我们要将文本“Enter an integer:”改为其他内容，就必须在两个地方更新它。如果我们要初始化 10 个变量而不是 2 个呢？那将会有大量冗余代码（使程序更长、更难理解），并且很容易出现拼写错误。

让我们更新这个程序以使用我们的 getValueFromUser 上面开发的函数：

#include <iostream>

int getValueFromUser()
{
 	std::cout << "Enter an integer: ";
	int input{};
	std::cin >> input;  

	return input;
}

int main()
{
    int x{ getValueFromUser() }; // 首次调用 getValueFromUser
    int y{ getValueFromUser() }; // 第二次调用 getValueFromUser

    std::cout << x << " + " << y << " = " << x + y << '\n';

    return 0;
}

该程序产生如下输出：

Enter an integer: 5
Enter an integer: 7
5 + 7 = 12

在这个程序中，我们调用 getValueFromUser 两次，一次用于初始化变量 x，一次用于初始化变量 y。这使我们不必重复编写获取用户输入的代码，并降低了出错的可能性。一旦我们知道 getValueFromUser 可以正常工作，我们就可以根据需要多次调用它。

这就是模块化编程的精髓：能够编写一个函数，测试它，确保它能正常工作，然后知道我们可以随意重复使用它，它将继续正常工作（只要我们不修改该函数——一旦修改，我们就必须重新测试它）。

最佳实践

遵循 DRY 原则：“不要重复自己”。如果你需要多次做某件事，考虑如何修改代码以尽可能消除冗余。变量可以用来存储需要多次使用的结果（这样我们就不必重复计算）。函数可以用来定义我们想要多次执行的语句序列。而循环（我们将在后面的章节中介绍）可以用来多次执行一条语句。

像所有最佳实践一样，DRY 是一个指导方针，而非绝对规则。读者 Yariv 已经 指出 ，当代码被拆分得太细时，DRY 可能会损害整体理解。

顺便说一句……

DRY 的（讽刺性的）反面是 WET（“Write everything twice”）。

总结

返回值提供了一种方式，让函数可以向它的调用者返回单个值。

函数提供了一种在程序中最小化冗余的方法。

问题 #2

DRY代表什么？为什么这是一个值得遵循的有用做法？

显示答案

DRY代表“不要重复自己”。这是一种以最小化冗余的方式编写代码的做法。这使得程序更简洁、更不易出错、更易于维护。
