11.6 — 函数模板

● 机器译文 课程 11.6 查看英文原文

假设你想写一个函数来计算两个数的最大值。你可能会这样做：

int max(int x, int y)
{
    return (x < y) ? y : x;
    // 注意：我们使用 < 而不是 >，因为 std::max 使用 <
}

虽然调用者可以向函数传递不同的值，但参数的类型是固定的，因此调用者只能传入 int 值。这意味着这个函数实际上只对整数（以及可以提升为 int)。

那么当你后来想要找到两个 double 值的最大值时会发生什么？因为 C++ 要求我们指定所有函数参数的类型，解决方案是创建一个新的重载版本 max ，其参数类型为 double：

double max(double x, double y)
{
    return (x < y) ? y: x;
}

注意，double 版本的 max 的实现代码与 int 版本的 max完全相同！实际上，这个实现适用于许多不同的类型：包括 int， double， long， long double，甚至是你自己创建的新类型（我们将在以后的课程中介绍如何做到这一点）。

为每组想要支持的参数类型创建具有相同实现的重载函数是一种维护上的麻烦，是错误的根源，并且明显违反了 DRY（不要重复自己）原则。这里还有一个不那么明显的挑战：希望使用 max 函数的程序员可能希望用 max 的作者没有预料到的参数类型来调用它（因此没有为其编写重载函数）。

我们真正缺少的是某种方法，可以编写一个单一的 max 版本，能够处理任何类型的参数（甚至包括编写 max 代码时可能没有预料到的类型）。普通函数根本无法胜任这项任务。幸运的是，C++ 支持另一种专门为解决这类问题而设计的特性。

欢迎来到 C++ 模板的世界。

C++ 模板简介

在 C++ 中，模板系统旨在简化创建能够处理不同数据类型的函数（或类）的过程。

我们不是手动创建一堆几乎相同的函数或类（每组不同类型一个），而是创建一个单一的 模板。就像普通定义一样， 模板 定义描述了函数或类的样子。与普通定义（必须指定所有类型）不同，在模板中我们可以使用一个或多个占位符类型。占位符类型表示在定义模板时未知，但在使用模板时提供的某种类型。

一旦定义了模板，编译器就可以使用该模板生成所需数量的重载函数（或类），每个使用不同的实际类型！

最终结果是相同的——我们最终得到一堆几乎相同的函数或类（每组不同类型一个）。但我们只需要创建和维护一个模板，编译器会为我们完成所有艰苦的工作来创建其余部分。

关键提示

编译器可以使用单个模板生成一系列相关的函数或类，每个使用不同的实际类型集。

顺便说一句……

因为模板背后的概念很难用语言描述，让我们尝试一个类比。

如果你在字典中查找“模板”一词，你会找到类似于以下的定义：“模板是作为创建相似对象的模型的模式”。一种非常容易理解的模板是模板。模板是一块薄材料（例如一块纸板或塑料），上面刻有一个形状（例如一个笑脸）。通过将模板放在另一个物体上，然后通过孔喷涂颜料，你可以非常快速地复制出刻出的形状。模板本身只需要创建一次，然后可以根据需要重复使用多次，以创建任意多种不同颜色的刻出形状。更好的是，使用模板制作的形状的颜色不必在使用模板之前确定。

模板本质上是一个用于创建函数或类的模板。我们创建一次模板（我们的模板），然后可以根据需要多次使用它，为特定的实际类型集模板化出一个函数或类。这些实际类型不需要在使用模板之前确定。

因为实际类型直到模板在程序中使用时才确定（而不是在编写模板时），模板的作者不必尝试预测可能使用的所有实际类型。这意味着模板代码可以与编写模板时甚至不存在的类型一起使用！我们将在后面探索 C++ 标准库时看到这一点如何派上用场，标准库中充满了模板代码！

关键提示

模板可以与编写模板时甚至不存在的类型一起工作。这有助于使模板代码既灵活又面向未来！

在本课的其余部分，我们将介绍并探索如何创建函数模板，并更详细地描述它们的工作原理。我们将把类模板的讨论推迟到我们介绍完类之后。

函数模板

一个 函数模板 是一种类似函数的定义，用于生成一个或多个重载函数，每个函数具有不同的实际类型集。这将使我们能够创建可以处理许多不同类型的函数。用于生成其他函数的初始函数模板称为 主模板，而从主模板生成的函数称为 实例化函数。

当我们创建主函数模板时，我们使用 占位符类型 （技术上称为 类型模板参数，非正式地称为 模板类型）用于我们希望稍后由模板用户指定的任何参数类型、返回类型或函数体中使用的类型。

进阶读者

C++ 支持 3 种不同的模板参数：

  • 类型模板参数（模板参数代表一个类型）。
  • 非类型模板参数（模板参数代表一个 constexpr 值）。
  • 模板模板参数（模板参数代表一个模板）。

类型模板参数是最常见的，所以我们先关注它们。我们还将讨论非类型模板参数，它们在现代 C++ 中使用越来越多。

函数模板最好通过示例来教学，所以让我们将上面的普通 max(int, int) 函数转换为函数模板。这出奇地简单，我们会在过程中解释发生了什么。

创建一个 max() 函数模板

这是 int 版本的 max() 再次：

int max(int x, int y)
{
    return (x < y) ? y : x;
}

注意，我们在该函数中使用了类型 int 三次：一次用于参数 x，一次用于参数 y，一次用于函数的返回类型。

要为 max()创建一个函数模板，我们将做两件事。首先，我们将任何希望稍后指定的实际类型替换为类型模板参数。在这种情况下，因为我们只有一个需要替换的类型（int），所以我们只需要一个类型模板参数（我们称之为 T)：

这是我们的新函数，它使用一个模板类型，其中所有实际类型 int 的出现都被替换为类型模板参数 T ：

T max(T x, T y) // 无法编译，因为我们尚未定义 T
{
    return (x < y) ? y : x;
}

这是一个好的开始——然而，它无法编译，因为编译器不知道 T 是什么！而且这仍然是一个普通函数，而不是函数模板。

其次，我们将告诉编译器这是一个模板，并且 T 是一个类型模板参数，它是任何类型的占位符。这两件事都是通过使用 模板参数声明来完成的，它定义了随后将使用的任何模板参数。模板参数声明的作用域严格限于紧随其后的函数模板（或类模板）。因此，每个函数模板或类模板都需要自己的模板参数声明。

template <typename T> // 这是模板参数声明，将 T 定义为类型模板参数
T max(T x, T y) // 这是 max<T> 的函数模板定义
{
    return (x < y) ? y : x;
}

在我们的模板参数声明中，我们从关键字 template开始，它告诉编译器我们正在创建一个模板。接下来，我们在尖括号（<>）内指定模板将使用的所有模板参数。对于每个类型模板参数，我们使用关键字 typename （首选）或 class，后跟类型模板参数的名称（例如 T)。

中讨论如何创建具有多个模板类型的函数模板。 typename 和 class 在这个上下文中， class 关键字之间没有区别。你经常会看到人们使用 typename 关键字，因为它更早被引入语言。然而，我们更喜欢较新的

关键字，因为它更清楚地表明类型模板参数可以被任何类型（如基本类型）替换，而不仅仅是类类型。 max() 能够接受不同类型参数的函数。

在下一节课中，我们将了解如何使用我们的 max 函数模板来生成一个或多个 max() 具有不同类型参数的函数，并实际调用这些函数。

命名模板参数

就像我们在简单情况下经常使用单个字母作为变量名一样（例如 x），当模板参数用于简单或明显的情况时，习惯上使用单个大写字母（从 T开始）。例如，在我们的 max 函数模板中：

template <typename T>
T max(T x, T y)
{
    return (x < y) ? y : x;
}

我们不需要给 T 一个复杂的名称，因为它显然只是被比较值的占位类型，并且 T 可以是任何可以比较的类型（例如 int， double，或 char，但不能是 nullptr)。

我们的函数模板通常使用这种命名约定。

如果类型模板参数具有非明显的用法或必须满足的特定要求，则有两种常见的命名约定：

  • 以大写字母开头（例如 Allocator）。标准库使用这种命名约定。
  • 以 T为前缀，然后以大写字母开头（例如 TAllocator）。这更容易看出该类型是类型模板参数。

选择哪一种取决于个人偏好。

进阶读者

例如，标准库有一个重载的 std::max() ，声明如下：

template< class T, class Compare >
const T& max( const T& a, const T& b, Compare comp ); // 暂时忽略 &，我们将在以后的课程中介绍

因为 a 和 b 是类型 T，我们知道我们不关心 a 和 b 是什么类型——它们可以是任何类型。因为 comp 的类型为 Compare，我们知道 comp 必须是一个满足 Compare 要求的类型（无论是什么）。

当函数模板被实例化时，编译器用模板实参替换模板参数，然后编译生成的实例化函数。函数能否编译取决于函数中如何使用每种类型的对象。因此，给定模板参数的要求本质上是隐式定义的。

由于从类型对象的使用方式推断要求可能很困难，因此查阅技术文档是有用的，文档应明确说明要求。例如，如果我们想知道 Compare 的要求是什么，我们可以查找 std::max 的文档（例如，参见 https://en.cppreference.com/w/cpp/algorithm/max），那里应该会列出要求。

最佳实践

使用以 T 开头的单个大写字母（例如 T， U， V等）来命名用于简单或明显情况且代表“任何合理类型”的类型模板参数。

如果类型模板参数具有非明显的用法或必须满足的特定要求，则应该使用更具描述性的名称（例如 Allocator 或 TAllocator)。

问题 #1

描述为什么施工蓝图是一种模板。

显示答案

施工蓝图本身只是一张描述如何建造建筑物的纸。利用蓝图，施工队可以快速建造许多结构相同的建筑物。然而，每栋建筑使用的具体材料类型可能不同（例如，建筑外墙使用的材料类型），并且直到实际建造时才需要确定。
