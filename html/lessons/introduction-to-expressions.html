1.10 — 表达式简介

● 机器译文 课程 1.10 查看英文原文

表达式

考虑以下一系列语句，每个语句都定义并初始化了一个变量：

// five() 是返回值为5的函数
int five()
{
    return 5;
}

int main()
{
    int a{ 2 };             // 用字面量值2初始化变量a
    int b{ 2 + 3 };         // 用计算值5初始化变量b
    int c{ (2 * 3) + 4 };   // 用计算值10初始化变量c
    int d{ b };             // 用变量值5初始化变量d
    int e{ five() };        // 用函数返回值5初始化变量e

    return 0;
}

注意，上面的初始化器使用了多种不同的实体：字面量、变量、运算符和函数调用。不知何故，C++ 正在将所有这些不同的东西转换为一个单一的值，然后可以用作变量的初始值。

所有这些初始化器有什么共同点？它们都使用了一个表达式。

在一般编程中，一个 表达式 是由字面量、变量、运算符和函数调用组成的计算一个值的非空序列。执行表达式的过程称为 求值，所产生的结果值称为 结果 （有时也称为 返回值)。

进阶读者

在 C++ 中，表达式的结果是以下之一：

  • 一个值（最常见）
  • 一个对象或函数。我们在课程 12.2 -- Value categories (lvalues and rvalues)。
  • 无。这些是无返回值函数调用的结果（在课程 2.3 -- Void functions (non-value returning functions)中介绍），这些调用仅为了其副作用

目前，为简单起见，我们假设表达式被求值以产生值。

当一个表达式被求值时，表达式中的每个项都会被求值，直到剩下单个值。以下是一些不同类型表达式的示例，注释说明了它们如何求值：

2               // 2 是一个求值为2的字面量
"Hello world!"  // "Hello world!" 是一个求值为文本"Hello world!"的字面量
x               // x 是一个求值为变量x所持值的变量
2 + 3           // operator+ 使用操作数 2 和 3 求值为值 5
five()          // 求值为函数 five() 的返回值

如您所见，字面量求值为自身的值。变量求值为变量的值。运算符（例如 operator+) 使用它们的操作数求值为其他值。我们还没有介绍函数调用，但在表达式的上下文中，函数调用求值为函数返回的任何值。

进阶读者

涉及带有副作用的运算符的表达式稍微复杂一些：

x = 5           // x = 5 有副作用：将 5 赋值给 x，求值为 x
x = 2 + 3       // 有副作用：将 5 赋值给 x，求值为 x
std::cout << x  // 有副作用：将 x 的值打印到控制台，求值为 std::cout

关键提示

在 C++ 中，任何期望单个值的地方，您都可以使用一个产生值的表达式代替，并且该表达式会被求值以产生一个单个值。

表达式不以分号结尾，且不能单独编译。例如，如果您尝试编译表达式 x = 5，编译器会报错（很可能提示缺少分号）。相反，表达式总是作为语句的一部分进行求值。

例如，考虑这条语句：

int x{ 2 + 3 }; // 2 + 3 是一个没有分号的表达式——分号在包含该表达式的语句末尾

如果将此语句分解为语法结构，它将如下所示：

type identifier { expression };

类型 可以是任何有效类型（我们选择了 int)。 标识符 可以是任何有效名称（我们选择了 x）。而 表达式 可以是任何有效表达式（我们选择了 2 + 3，它使用了两个字面量和一个运算符）。

表达式语句

某些表达式（例如 x = 5）主要用于它们的副作用（在这种情况下，将值 5 赋给变量 x），而不是它们产生的值。

相关内容

然而，我们上面提到表达式不能单独执行——它们必须作为语句的一部分存在。幸运的是，将任何表达式转换为等效语句是轻而易举的。一个 表达式语句 是由一个表达式后跟一个分号组成的语句。当执行表达式语句时，该表达式会被求值。

因此，我们可以取任意表达式（例如 x = 5），并将其转换为表达式语句（x = 5;），这样就能编译通过。

当表达式用于表达式语句时，表达式生成的任何结果都会被丢弃（因为它未被使用）。例如，当表达式 x = 5 求值时，函数 operator= 的返回值被丢弃。这没问题，因为我们只是想将 5 切换到 x 反正。

无用的表达式语句

我们还可以编写能编译但无效果的表达式语句。例如，表达式语句（2 * 3;）是一个表达式语句，其表达式求值为 6的结果值，然后被丢弃。虽然语法有效，但此类表达式语句是无用的。某些编译器（如 gcc 和 Clang）如果检测到表达式语句无用，会生成警告。

子表达式、完整表达式和复合表达式

我们偶尔需要讨论特定类型的表达式。为此，我们将定义一些相关术语。

考虑以下表达式：

2               // 2 是一个求值为2的字面量
2 + 3           // 2 + 3 使用 operator+ 求值为值 5
x = 4 + 5       // 4 + 5 求值为值 9，然后赋值给变量 x

简化一点， 子表达式 是用作操作数的表达式。例如， x = 4 + 5 是 x 和 4 + 5的子表达式。 4 + 5 是 4 和 5。

一个 完整表达式 是一个不是子表达式的表达式。上面的三个表达式（2， 2 + 3、和 x = 4 + 5）都是完整表达式。

通俗地说，一个 复合表达式 是一个包含两个或更多运算符使用的表达式。 x = 4 + 5 是一个复合表达式，因为它包含两个运算符的使用（operator= 和 operator+)。 2 和 2 + 3 不是复合表达式。

小测验时间

问题 #1


语句和表达式之间的区别是什么？

显示答案

当我们希望程序执行一个动作时使用语句。当我们希望程序计算一个值时使用表达式。

问题 #2

指出以下几行是 不包含表达式的语句， 包含表达式的语句，或者是 表达式语句。

a)

int x;

显示答案

语句不包含表达式。这是一个变量定义语句。 x 在此上下文中不是一个表达式，因为它正在被定义，而不是被求值。

b)

int x = 5;

显示答案

语句包含一个表达式。 int x 是一个变量定义。 = 是复制初始化语法的一部分。等号右侧的初始化器是一个表达式。

c)

x = 5;

显示答案

表达式语句。 x = 5 是调用 operator= 带两个操作数： x 和 5。分号使其成为表达式语句。

d) 附加题：

foo(); // foo 是一个函数

显示答案

函数调用是表达式的一部分，因此这是一个表达式语句。

e) 额外加分：

std::cout << x; // 提示：operator<< 是一个二元运算符。

显示答案

operator<< 是二元运算符，所以 std::cout 必须是左操作数，而 x 必须是右操作数。由于那已是整个语句，这一定是一个表达式语句。
