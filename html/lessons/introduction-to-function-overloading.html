11.1 — 函数重载简介

● 机器译文 课程 11.1 查看英文原文

考虑以下函数：

int add(int x, int y)
{
    return x + y;
}

这个简单的函数将两个整数相加并返回一个整数结果。但是，如果我们还想要一个可以相加两个浮点数的函数呢？这个 add() 函数并不适用，因为任何浮点参数都会被转换为整数，导致浮点参数丢失其小数部分。

解决这个问题的一种方法是定义多个名称略有不同的函数：

int addInteger(int x, int y)
{
    return x + y;
}

double addDouble(double x, double y)
{
    return x + y;
}

然而，为了达到最佳效果，这要求你为具有不同类型参数的相似函数定义一致的函数命名标准，记住这些函数的名称，并实际调用正确的那个。

那么当我们想要一个类似但能相加3个整数而不是2个的函数时，会发生什么？为每个函数管理唯一的名称很快就会变得繁琐。

函数重载简介

幸运的是，C++ 有一个优雅的解决方案来处理这种情况。 函数重载 允许我们创建多个同名函数，只要每个同名函数具有不同的参数类型（或者函数可以以其他方式区分）。共享一个名称（在同一作用域内）的每个函数称为 重载函数 （有时称为 重载 （简称）。

要重载我们的 add() 函数，我们可以简单地声明另一个接受 double 参数的 add() 函数：

double add(double x, double y)
{
    return x + y;
}

现在我们有两个版本的 add() 在同一作用域中：

int add(int x, int y) // 整数版本
{
    return x + y;
}

double add(double x, double y) // 浮点数版本
{
    return x + y;
}

int main()
{
    return 0;
}

上面的程序可以编译。尽管你可能期望这些函数会导致命名冲突，但这里并非如此。由于这些函数的参数类型不同，编译器能够区分它们，并将它们视为恰好共享名称的独立函数。

关键提示

只要每个重载函数可以被编译器区分，函数就可以被重载。如果重载函数无法被区分，将导致编译错误。

相关内容

运算符也可以以类似的方式重载。我们将在 21.1 -- 运算符重载简介。

重载解析简介

此外，当调用一个已被重载的函数时，编译器将尝试根据函数调用中使用的参数将函数调用匹配到适当的重载。这称为 重载解析。

下面是一个简单的例子演示这一点：

#include <iostream>

int add(int x, int y)
{
    return x + y;
}

double add(double x, double y)
{
    return x + y;
}

int main()
{
    std::cout << add(1, 2); // 调用 add(int, int)
    std::cout << '\n';
    std::cout << add(1.2, 3.4); // 调用 add(double, double)

    return 0;
}

上面的程序编译并产生结果：

3
4.6

当我们在调用 add(1, 2)时提供整数参数，编译器将确定我们正在尝试调用 add(int, int)。而当我们在调用 add(1.2, 3.4)时提供整数参数，编译器将确定我们正在尝试调用 add(double, double)。

使其编译

为了使使用重载函数的程序能够编译，必须满足两个条件：

  1. 每个重载函数必须与其他函数区分开来。我们在课程 11.2 -- 函数重载区分。
  2. 每个对重载函数的调用必须解析为一个重载函数。我们在课程 11.3 -- 函数重载解析与歧义匹配。

如果重载函数未被区分，或者对重载函数的函数调用无法解析为重载函数，则将导致编译错误。

在下一课中，我们将探讨如何区分重载函数。然后，在接下来的课程中，我们将探讨编译器如何将函数调用解析为重载函数。

总结

函数重载提供了一种很好的方式来减少程序的复杂性，因为它减少了你需要记住的函数名称数量。它可以并且应该被广泛使用。

最佳实践

使用函数重载来简化你的程序。
