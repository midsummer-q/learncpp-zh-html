2.4 — 函数参数与实参简介

● 机器译文 课程 2.4 查看英文原文

在上一课中，我们学习了如何让函数向调用者返回值。我们利用这一点创建了一个模块化的 getValueFromUser 函数，并在本程序中使用：

#include <iostream>

int getValueFromUser()
{
 	std::cout << "Enter an integer: ";
	int input{};
	std::cin >> input;  

	return input;
}

int main()
{
	int num { getValueFromUser() };

	std::cout << num << " doubled is: " << num * 2 << '\n';

	return 0;
}

但是，如果我们想将输出行也放入它自己的函数中呢？你可能会尝试像这样写：

#include <iostream>

int getValueFromUser()
{
 	std::cout << "Enter an integer: ";
	int input{};
	std::cin >> input;  

	return input;
}

// 该函数无法编译
void printDouble()
{
	std::cout << num << " doubled is: " << num * 2 << '\n';
}

int main()
{
	int num { getValueFromUser() };

	printDouble();

	return 0;
}

这无法编译，因为函数 printDouble 不知道标识符 num 是什么。你可能会尝试在函数 printDouble() 内部将 num 定义为一个变量：

void printDouble()
{
	int num{}; // 我们添加了这一行
	std::cout << num << " doubled is: " << num * 2 << '\n';
}

虽然这解决了编译器错误并使程序可以编译，但程序仍然无法正常工作（它总是输出“0 doubled is: 0”）。这里问题的核心在于函数 printDouble 无法访问用户输入的值。

我们需要某种方式将变量 num 的值传递给函数 printDouble 以便 printDouble 以便在函数体中使用该值。

函数参数与实参

在许多情况下，能够传递信息 切换到 给被调用的函数，这样函数就有数据可以处理。例如，如果我们想编写一个函数来将两个数字相加，我们需要某种方式来告诉函数在调用时应该相加哪两个数字。否则，函数怎么知道要相加什么？我们通过函数参数和实参来实现这一点。

一个 函数参数 是在函数头中使用的变量。函数参数的工作方式与函数内部定义的变量几乎完全相同，但有一个区别：它们由函数的调用者提供的值进行初始化。

函数参数在函数头中定义，放在函数名后面的括号内，多个参数之间用逗号分隔。

以下是一些具有不同数量参数的函数的示例：

// 该函数不接受参数
// 它不依赖调用者提供任何东西
void doPrint()
{
    std::cout << "In doPrint()\n";
}

// 该函数接受一个名为 x 的整数参数
// 调用者将提供 x 的值
void printValue(int x)
{
    std::cout << x << '\n';
}

// 该函数有两个整型参数，一个名为 x，一个名为 y
// 调用者将提供 x 和 y 的值
int add(int x, int y)
{
    return x + y;
}

一种 实参 是调用者 从 传递 切换到 给函数的值，当进行函数调用时：

doPrint(); // 此调用没有实参
printValue(6); // 6 是传递给函数 printValue() 的实参
add(2, 3); // 2 和 3 是传递给函数 add() 的实参

注意多个实参之间也用逗号分隔。

参数和实参如何协同工作

当调用函数时，函数的所有参数都会作为变量被创建，并且每个实参的值会被 复制 到匹配的参数中（使用复制初始化）。这个过程称为 按值传递。使用按值传递的函数参数称为 值参数。

例如：

#include <iostream>

// 该函数有两个整型参数，一个名为 x，一个名为 y
// x 和 y 的值由调用者传入
void printValues(int x, int y)
{
    std::cout << x << '\n';
    std::cout << y << '\n';
}

int main()
{
    printValues(6, 7); // 此函数调用有两个实参：6 和 7

    return 0;
}

当函数 printValues 被调用时，实参 6 和 7， printValues的参数 x 会被创建并用 6、和 printValues的参数 y 会被创建并用 7。

这会产生输出：

6
7

请注意，参数的数量通常必须与函数参数的数量匹配，否则编译器会抛出错误。传递给函数的实参可以是任何有效的表达式（因为实参本质上只是形参的初始化器，而初始化器可以是任何有效的表达式）。

修复我们的挑战程序

现在我们有必要的工具来修复课程开头展示的程序：

#include <iostream>

int getValueFromUser()
{
 	std::cout << "Enter an integer: ";
	int input{};
	std::cin >> input;  

	return input;
}

void printDouble(int value) // 该函数现在有一个整型参数
{
	std::cout << value << " doubled is: " << value * 2 << '\n';
}

int main()
{
	int num { getValueFromUser() };

	printDouble(num);

	return 0;
}

在这个程序中，变量 num 首先通过用户输入的值进行初始化。然后，函数 printDouble 被调用，实参 num 的值被复制到 值 函数的形参 printDouble。函数 printDouble 然后使用形参的值 值。

将返回值用作实参

在上面的问题中，我们可以看到变量 num 仅使用一次，用于将函数 getValueFromUser 的返回值传递给函数调用的实参 printDouble。

我们可以将上面的例子稍微简化如下：

#include <iostream>

int getValueFromUser()
{
 	std::cout << "Enter an integer: ";
	int input{};
	std::cin >> input;  

	return input;
}

void printDouble(int value)
{
	std::cout << value << " doubled is: " << value * 2 << '\n';
}

int main()
{
	printDouble(getValueFromUser());

	return 0;
}

现在，我们将函数 getValueFromUser 的返回值直接用作函数 printDouble！

虽然这个程序更简洁（并且清楚地表明用户读取的值将不会用于其他任何目的），但您可能也会觉得这种“紧凑语法”有点难以阅读。如果您更习惯使用变量的版本，那也没问题。

参数和返回值如何协同工作

通过同时使用参数和返回值，我们可以创建函数，这些函数将数据作为输入，对其进行一些计算，然后将值返回给调用者。

这是一个非常简单的函数示例，它将两个数相加并将结果返回给调用者。

#include <iostream>

// add() 接受两个整数作为参数，并返回它们的和
// x 和 y 的值由调用 add() 的函数决定
int add(int x, int y)
{
    return x + y;
}

// main 没有参数
int main()
{
    std::cout << add(4, 5) << '\n'; // 实参 4 和 5 被传递给函数 add()
    return 0;
}

执行从顶部开始 main。当 add(4, 5) 被求值时，函数 add 被调用，参数 x 被初始化为值 4， y 被初始化为值 5。

浮点类型的 return语句 在函数 add 求值 x + y 得到值 9，然后返回给 main。这个 9 的值随后被发送到 std::cout 在控制台上打印。

输出：

9

更多示例

让我们看更多的函数调用：

#include <iostream>

int add(int x, int y)
{
    return x + y;
}

int multiply(int z, int w)
{
    return z * w;
}

int main()
{
    std::cout << add(4, 5) << '\n'; // 在 add() 内部 x=4, y=5，因此 x+y=9
    std::cout << add(1 + 2, 3 * 4) << '\n'; // 在 add() 内部 x=3, y=12，因此 x+y=15

    int a{ 5 };
    std::cout << add(a, a) << '\n'; // 求值 (5 + 5)

    std::cout << add(1, multiply(2, 3)) << '\n'; // 求值 1 + (2 * 3)
    std::cout << add(1, add(2, 3)) << '\n'; // 求值 1 + (2 + 3)

    return 0;
}

该程序产生输出：

9
15
10
7
6

第一条语句很直接。

在第二条语句中，参数是表达式，在传递之前会被求值。在这种情况下， 1 + 2 求值为 3，所以 3 被复制到参数 x。 3 * 4 求值为 12，所以 12 被复制到参数 y。 add(3, 12) 解析为 15。

下一对语句也相对简单：

    int a{ 5 };
    std::cout << add(a, a) << '\n'; // 求值 (5 + 5)

在这种情况下， add() 被调用时，其中变量 a 的值被复制到两个参数中 x 和 y。因为 a 值为 5， add(a, a) = add(5, 5)，其解析为值 10。

我们来看看这一组中第一个棘手的语句：

    std::cout << add(1, multiply(2, 3)) << '\n'; // 求值 1 + (2 * 3)

当函数 add 被执行时，程序需要确定参数 x 和 y 的值。 x 很简单，因为我们只是传递了整数 1。要获取参数 y，它需要求值 multiply(2, 3) 首先。程序调用 multiply 并初始化 z = 2 和 w = 3，所以 multiply(2, 3) 返回整数值 6。该返回值 6 现在可以用来初始化 y 的参数 add 函数的顶部开始。 add(1, 6) 返回整数 7，然后传递给 std::cout 进行打印。

更简洁地说：
add(1, multiply(2, 3)) 求值为 add(1, 6) 求值为 7

以下语句看起来很棘手，因为传递给 add 是另一个对 add。

    std::cout << add(1, add(2, 3)) << '\n'; // 求值 1 + (2 + 3)

但这种情况与之前的情况完全相同。add(2, 3) 首先求值，得到返回值 5。现在它可以求值 add(1, 5)，计算结果为值 6，它被传递给 std::cout 进行打印。

更简洁地说：
add(1, add(2, 3)) 求值为 add(1, 5) => 求值为 6

未引用参数和未命名参数

在某些情况下，你会遇到函数拥有在函数体内未使用的参数。这些参数被称为 未引用参数。

举一个简单的例子：

void doSomething(int count) // 警告：未引用的参数 count
{
    // 该函数过去曾用 count 做点什么，但现在不再使用了
}

int main()
{
    doSomething(4);

    return 0;
}

就像未使用的局部变量一样，你的编译器可能会警告变量 count 已被定义但未使用。

在函数定义中，函数参数的名称是可选的。因此，在需要函数参数存在但未在函数体内使用的情况下，你可以直接省略名称。没有名称的参数被称为 未命名参数：

void doSomething(int) // 好：未命名参数将不会生成警告
{
}

Google C++ 风格指南建议使用注释来说明该未命名参数原本是什么：

void doSomething(int /*计数*/)
{
}

作者注

你可能想知道为什么我们要编写一个拥有未使用参数值的函数。这种情况最常见于类似以下的场景：

  1. 假设我们有一个带单个参数的函数。后来，函数以某种方式更新，参数的数值不再需要。如果直接删除现在未使用的函数参数，那么所有现有对该函数的调用都会出错（因为函数调用提供的实参数量超过了函数所能接受的数量）。这要求我们找到所有对该函数的调用并移除不需要的实参。这可能是大量的工作（并且需要大量重新测试）。甚至可能不可能做到（在我们无法控制所有调用该函数的代码的情况下）。因此，我们可能保持参数不变，只是让它不起作用。

进阶读者

其他出现这种情况的场景：

  1. 运算符 ++ 和 -- 有前缀和后缀变体（例如 ++foo vs foo++）。未引用的函数参数用于区分此类运算符的重载是前缀还是后缀情况。我们在课程 21.8 -- 重载自增和自减运算符。
  2. 当我们需要从类型模板参数的类型（而非值）中确定某些内容时。

作者注

如果未命名参数对你来说仍然没有意义，请不要担心。我们将在未来的课程中再次遇到它们，届时会有更多上下文来解释它们的用途。

最佳实践

当函数参数存在但未在函数体中使用时，不要给它命名。你可以选择在注释中放置一个名称。

总结

函数参数和返回值是函数以可重用方式编写的主要机制，因为它们允许我们编写能够执行任务并将获取或计算的结果返回给调用者的函数，而无需事先知道具体的输入或输出。

小测验时间

问题 #1

这个程序片段有什么问题？

#include <iostream>

void multiply(int x, int y)
{
    return x * y;
}

int main()
{
    std::cout << multiply(4, 5) << '\n';

    return 0;
}

显示答案

multiply() 的返回类型为 void，意味着它是一个不返回值的函数。由于该函数试图通过 return 语句返回值，因此会产生编译器错误。返回类型应为 int。

问题 #2

这个程序片段有哪些两个错误？

#include <iostream>

int multiply(int x, int y)
{
    int product { x * y };
}

int main()
{
    std::cout << multiply(4) << '\n';

    return 0;
}

显示答案

问题1：main() 向 multiply() 传递了一个参数，但 multiply() 需要两个参数。问题2：multiply() 没有 return 语句。

问题 #3

以下程序打印什么值？

#include <iostream>

int add(int x, int y, int z)
{
    return x + y + z;
}

int multiply(int x, int y)
{
    return x * y;
}

int main()
{
    std::cout << multiply(add(1, 2, 3), 4) << '\n';

    return 0;
}

显示答案

调用 multiply 时，x = add(1, 2, 3) 且 y = 4。首先，CPU 解析 x = add(1, 2, 3)，返回 1 + 2 + 3，即 x = 6。multiply(6, 4) = 24，这就是答案。

问题 #4

编写一个名为 doubleNumber() 的函数，该函数接受一个整数参数。函数应返回参数值的两倍。

显示答案

int doubleNumber(int x)
{
    return 2 * x;
}

问题 #5

  1. 编写一个完整程序，从用户处读取一个整数，使用你在上一道测验题中编写的 doubleNumber() 函数将其加倍，然后将加倍后的值打印到控制台。

显示答案

#include <iostream>

int doubleNumber(int x)
{
    return 2 * x;
}

int main()
{
    std::cout << "Enter an integer value: ";
    int x{};
    std::cin >> x;
    std::cout << doubleNumber(x) << '\n';

    return 0;
}

注意：你可能会有其他（类似的）解决方案。在 C++ 中，通常有多种方式来完成相同的事情。
