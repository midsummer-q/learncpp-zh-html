1.5 — iostream简介：cout、cin和endl

● 机器译文 课程 1.5 查看英文原文

在本课中，我们将进一步讨论std::cout，我们曾在 Hello world! 程序中使用它来输出文本 Hello world! 到控制台。我们还将探索如何从用户获取输入，这将用于使程序更具交互性。

输入/输出库

浮点类型的 输入/输出库 （io库）是C++标准库的一部分，负责处理基本的输入和输出。我们将使用这个库中的功能来从键盘获取输入并将数据输出到控制台。 io 部分 iostream 代表 输入/输出。

要使用定义在 iostream 库中的功能，我们需要在代码文件顶部包含 iostream 头文件，该头文件包含了定义在 iostream中的内容，如下所示：

#include <iostream>

// 其他使用 iostream 功能的代码在此处

std::cout

浮点类型的 iostream 库中包含了一些预定义的变量供我们使用。其中最有用的之一是 std::cout，它允许我们向控制台发送数据并以文本形式打印。 cout 代表“字符输出”。

提醒一下，这是我们的 Hello world 程序：

#include <iostream> // for std::cout

int main()
{
    std::cout << "Hello world!"; // 向控制台打印 Hello world!

    return 0;
}

在这个程序中，我们包含了 iostream 以便我们能够使用 std::cout。在我们的 main 函数中，我们使用 std::cout，以及 插入运算符（<<)，将文本 Hello world! 发送到控制台进行打印。

std::cout 不仅可以打印文本，还可以打印数字：

#include <iostream> // for std::cout

int main()
{
    std::cout << 4; // 向控制台打印 4

    return 0;
}

这会产生以下结果：

4

它还可以用于打印变量的值：

#include <iostream> // for std::cout

int main()
{
    int x{ 5 }; // 定义整型变量 x，并用值 5 初始化
    std::cout << x; // 向控制台打印 x 的值（5）
    return 0;
}

这会产生以下结果：

5

要在同一行打印多个内容，插入运算符（<<）可以在单个语句中多次使用，以连接多个输出片段。例如：

#include <iostream> // for std::cout

int main()
{
    std::cout << "Hello" << " world!";
    return 0;
}

这使用了 << 运算符两次，首先输出 Hello 然后输出 world。

因此，该程序打印出：

Hello world!

提示

不妨将 << 运算符（以及 >> 运算符）视为一条按指示方向移动数据的传送带。在这种情况下，当内容被传送到 std::cout，它就会被输出。

下面是另一个示例，我们在同一语句中同时打印文本和变量的值：

#include <iostream> // for std::cout

int main()
{
    int x{ 5 };
    std::cout << "x is equal to: " << x;
    return 0;
}

该程序打印出：

x is equal to: 5

相关内容

我们讨论 std:: 前缀的实际作用，在课程 2.9 -- 命名冲突和命名空间简介。

使用 std::endl 输出换行符

您认为这个程序会打印出什么？

#include <iostream> // for std::cout

int main()
{
    std::cout << "Hi!";
    std::cout << "My name is Alex.";
    return 0;
}

您可能会对结果感到惊讶：

Hi!My name is Alex.

独立的输出语句并不会在控制台上产生独立的输出行。

如果我们想在控制台上打印独立的输出行，就需要告诉控制台将光标移动到下一行。我们可以通过输出换行符来实现这一点。一个 换行符 是一个特定于操作系统的字符或字符序列，用于将光标移动到下一行的开头。

输出新行的一种方法是输出 std::endl （代表“end line”）：

#include <iostream> // for std::cout and std::endl

int main()
{
    std::cout << "Hi!" << std::endl; // std::endl 会使光标移到下一行
    std::cout << "My name is Alex." << std::endl;

    return 0;
}

这会打印：

Hi!
My name is Alex.

提示

在上述程序中，第二个 std::endl 从技术上讲并不是必需的，因为程序随后立即结束。然而，它有几个有用的目的。

首先，它有助于表明输出的这一行是一个“完整的思想”（与后面代码中某处完成的局部输出相对）。在这个意义上，它的功能类似于在标准英语中使用句号。

其次，它将光标定位到下一行，这样如果我们以后添加额外的输出行（例如让程序说“再见！”），这些行将出现在我们期望的位置（而不是附加到前一行输出的末尾）。

第三，从命令行运行可执行文件后，某些操作系统在再次显示命令提示符之前不会输出新行。如果我们的程序结束时光标不在新行上，命令提示符可能会附加到前一行输出的末尾，而不是像用户期望的那样出现在新行的开头。

最佳实践

每当一行输出完成时输出一个新行。

std::cout 是缓冲的

设想一下你最喜欢的游乐园里的过山车。乘客以某种变化率到达并排队。每隔一段时间，一列火车到达并让乘客上车（直到火车最大容量）。当火车满员，或者经过足够长的时间后，火车载着一批乘客出发，旅程开始。任何无法登上当前火车的乘客等待下一列。

这个类比类似于发送到 std::cout 的输出通常是如何在C++中处理的。我们程序中的语句请求将输出发送到控制台。然而，该输出通常不会立即发送到控制台。相反，请求的输出“排队”，并存储在专门收集此类请求的内存区域中（称为 缓冲区）。每隔一段时间，缓冲区被 刷新，意味着缓冲区中收集的所有数据被传输到其目的地（在这种情况下是控制台）。

作者注

再用一个类比，刷新缓冲区有点像冲厕所。你所有收集的“输出”被转移到……无论它下一步去哪里。咦。

这也意味着，如果在缓冲区被刷新之前，你的程序崩溃、中止或暂停（例如用于调试），任何仍在缓冲区中等待的输出都不会显示。

关键提示

缓冲输出的对立面是无缓冲输出。对于无缓冲输出，每个单独的输出请求直接发送到输出设备。

将数据写入缓冲区通常很快，而将一批数据传输到输出设备则相对较慢。通过将多个输出请求一起批处理，缓冲可以显著提高性能，从而最小化必须将输出发送到输出设备的次数。

std::endl vs \n

使用 std::endl 通常效率低下，因为它实际上做了两件事：它输出一个换行符（将光标移动到控制台的下一行），并刷新缓冲区（这很慢）。 std::endl，我们将得到多次刷新，这很慢且可能不必要。

当向控制台输出文本时，我们通常不需要显式地自己刷新缓冲区。C++的输出系统被设计为定期自动刷新，让它自己刷新既简单又高效。

要输出换行符而不刷新输出缓冲区，我们使用 \n （在单引号或双引号内），这是一个特殊符号，编译器将其解释为换行字符。 \n 将光标移动到控制台的下一行而不引起刷新，因此通常性能更好。 \n 也更简洁易输入，并且可以嵌入到现有的双引号文本中。

下面是一个使用 \n 的几种不同方式的例子：

#include <iostream> // for std::cout

int main()
{
    int x{ 5 };
    std::cout << "x is equal to: " << x << '\n'; // 单独使用单引号（常规做法）
    std::cout << "Yep." << "\n";                 // 单独使用双引号（非常规但可行）
    std::cout << "And that's all, folks!\n";     // 在现有文本的双引号之间（常规做法）
    return 0;
}

这会打印：

x is equal to: 5
Yep.
And that's all, folks!

当 \n 没有被嵌入到现有的双引号文本行中时（例如 "hello\n")，它通常使用单引号（'\n')。

进阶读者

在C++中，我们使用单引号表示单个字符（例如 'a' 或 '$'），双引号表示文本（零个或多个字符）。

即使‘\n’在源代码中表示为两个符号，但编译器将其视为单个换行（LF）字符（ASCII值为10），因此通常使用单引号（除非嵌入到现有的双引号文本中）。我们将在课程中进一步讨论 4.11 -- 字符。

当输出‘\n’时，执行输出的库负责将这个单个LF字符转换为给定操作系统的适当换行序列。参见 维基百科 以获取有关操作系统换行约定的更多信息。

作者注

虽然非传统，但我们认为使用（甚至更喜欢）双引号是可以的 "\n" 在标准输出语句中。

这有两个主要好处：

  1. 对所有输出的文本使用双引号比决定哪些应该用单引号、哪些用双引号更简单。
  2. 更重要的是，它有助于避免无意中创建多字符字面量。我们在课程中介绍了多字符字面量及其可能导致的意外输出 4.11 -- 字符。

在非输出情况下应优先使用单引号。

当我们讲到关于字符的课程时，会更详细地介绍‘\n’是什么（4.11 -- 字符)。

最佳实践

优先使用 \n 而不是 std::endl 当向控制台输出文本时。

警告

'\n' 使用反斜杠（C++中所有特殊字符都是如此），而不是正斜杠。

使用正斜杠（例如 '/n'）或在单引号内包含其他字符（例如 ' \n' 或 '.\n'）将导致意外行为。例如， std::cout << '/n'; 通常会打印为 12142，这可能不是你期望的结果。

std::cin

std::cin 是另一个预定义变量，位于 iostream 库中。而 std::cout 将数据打印到控制台（使用插入运算符 << 来提供数据）， std::cin （代表“字符输入”）从键盘读取输入。我们通常使用提取运算符 >> 将输入数据放入变量中（然后可以在后续语句中使用）。

#include <iostream>  // for std::cout and std::cin

int main()
{
    std::cout << "Enter a number: "; // 向用户询问一个数字

    int x{};       // 定义变量 x 来保存用户输入（并进行值初始化）
    std::cin >> x; // 从键盘获取数字并存储到变量 x 中

    std::cout << "You entered " << x << '\n';
    return 0;
}

尝试自己编译并运行这个程序。当你运行程序时，第5行会打印“Enter a number: ”。当代码执行到第8行时，你的程序将等待你输入。一旦你输入一个数字（并按下回车），你输入的数字将被赋值给变量 x。最后，在第10行，程序将打印“You entered ”后面跟上你刚才输入的数字。

例如（输入数值4）：

Enter a number: 4
You entered 4

这是一种从用户获取键盘输入的简单方法，我们将在后续的许多示例中使用它。

提示

注意，你不需要输出 '\n' 当接受一行输入时，因为用户需要按下 enter 键来让输入被接受，并且这会将光标移动到控制台的下一行。

  • 如果你的屏幕在输入数字后立即关闭，请参阅课程 0.8 -- 一些常见的C++问题 以获取解决方案。
  • 如果你使用的是CLion，并且“You entered”前面有一个空格，这是CLion的一个bug。参见 CLion bug追踪器 以了解解决方法。

就像可以在同一行输出多个文本一样，也可以在同一行输入多个值：

#include <iostream>  // for std::cout and std::cin

int main()
{
    std::cout << "Enter two numbers separated by a space: ";

    int x{}; // 定义变量 x 来保存用户输入（并进行值初始化）
    int y{}; // 定义变量 y 来保存用户输入（并进行值初始化）
    std::cin >> x >> y; // 获取两个数字并分别存储到变量 x 和 y 中

    std::cout << "You entered " << x << " and " << y << '\n';

    return 0;
}

这将产生输出：

Enter two numbers separated by a space: 5 6
You entered 5 and 6

输入的值应该用空白（空格、制表符或换行符）分隔。

关键提示

对于是否需要在通过其他来源（例如 std::cin）将用户提供的值赋给变量之前立即初始化该变量，存在一些争议，因为用户提供的值只会覆盖初始化值。根据我们之前关于变量应始终初始化的建议，最佳实践是先初始化变量。

进阶读者

C++ I/O库没有提供一种无需用户按下即可接受键盘输入的方法 enter。如果你想要这个功能，就必须使用第三方库。对于控制台应用程序，我们推荐 pdcurses， FXTUI， cpp-terminal，或 notcurses。许多图形用户界面库都有自己的函数来实现这类功能。

std::cin 是缓冲的

在前一节中，我们提到输出数据实际上是一个两阶段的过程：

  • 每个输出请求的数据被添加到输出缓冲区的末尾。
  • 随后，输出缓冲区前端的数据被刷新到输出设备（控制台）。

关键提示

将数据添加到缓冲区末尾并从缓冲区前端移除，确保数据按添加的顺序处理。这有时被称为FIFO（先进先出）。

类似地，输入数据也是一个两阶段的过程：

  • 你输入的每个字符都被添加到输入缓冲区的末尾（在 std::cin）。回车键（用于提交数据）也会被存储为一个 '\n' 字符。
  • 提取操作符‘>>’从输入缓冲区前端移除字符，并将其转换为一个值，该值（通过复制赋值）被赋给相应的变量。然后可以在此后的语句中使用该变量。

关键提示

输入缓冲区中的每一行输入数据都以一个 '\n' 字符。

我们将使用以下程序来演示这一点：

#include <iostream>  // for std::cout and std::cin

int main()
{
    std::cout << "Enter two numbers: ";

    int x{};
    std::cin >> x;

    int y{};
    std::cin >> y;

    std::cout << "You entered " << x << " and " << y << '\n';

    return 0;
}

该程序将输入到两个变量（这次作为单独的语句）。我们将运行该程序两次。

运行 #1：当 std::cin >> x; 被遇到时，程序将等待输入。输入值 4. 输入 4\n 进入输入缓冲区，并且值 4 被提取到变量 x。

当 std::cin >> y; 被遇到时，程序将再次等待输入。输入值 5. 输入 5\n 进入输入缓冲区，并且值 5 被提取到变量 y. 最后，程序将输出 You entered 4 and 5。

这次运行不应该有任何令人惊讶的地方。

运行 #2：当 std::cin >> x 被遇到时，程序将等待输入。输入 4 5. 输入 4 5\n 进入输入缓冲区，但只有 4 被提取到变量 x （提取在空格处停止）。

当 std::cin >> y 被遇到时，程序将 不是 等待输入。相反， 5 仍在输入缓冲区中的内容被提取到变量 y。程序随后输出 You entered 4 and 5。

请注意，在运行 2 中，程序在提取到变量时没有等待用户输入额外的输入 y 因为输入缓冲区中已经有了可以使用的先前输入。

关键提示

std::cin 被缓冲是因为它允许我们将输入的输入与输入的提取分离开来。我们可以输入一次输入，然后对其执行多次提取请求。

基本提取过程

以下是如何操作符 >> 对输入起作用。

  1. 如果 std::cin 处于不良状态（例如，先前的提取失败且 std::cin 尚未被清除），则不会尝试提取，提取过程立即中止。
  2. 输入缓冲区的前导空白字符（空格、制表符和位于缓冲区开头的换行符）会被丢弃。这将丢弃之前输入行中遗留的未提取换行符。
  3. 如果输入缓冲区现在为空，operator >> 将等待用户输入更多数据。任何前导空白字符都会从输入的数据中丢弃。
  4. operator >> 然后尽可能多地提取连续字符，直到遇到换行符（表示输入行结束）或对于正在提取的变量无效的字符为止。

提取过程的结果如下：

  • 如果提取在步骤1中止，则未发生任何提取尝试。不会发生其他事情。
  • 如果在上述步骤4中提取了任何字符，则提取成功。提取的字符被转换为一个值，然后复制赋值给变量。
  • 如果在上述步骤4中无法提取任何字符，则提取失败。正在提取的目标对象被复制赋值为值 0 （自C++11起），并且任何未来的提取都会立即失败（直到 std::cin 被清除）。

任何未提取的字符（包括换行符）将保留给下一次提取尝试。

相关内容

我们将在课程中讨论如何检测和处理提取失败、处理无关输入以及清除 std::cin 在课程 9.5 -- std::cin与处理无效输入。

例如，给定以下代码片段：

int x{};
std::cin >> x;

以下是在三种不同输入情况下发生的情况：

  • 如果用户输入 5a 并按下回车， 5a\n 将会被添加到缓冲区。 5 会被提取、转换为整数并赋值给变量 x。 a\n 会留在输入缓冲区中供下一次提取使用。
  • 如果用户输入 ‘b’ 并按下回车， b\n 将会被添加到缓冲区。因为 b 不是一个有效的整数，无法提取任何字符，因此这是一次提取失败。变量 x 会被设置为 0，并且后续的提取操作会一直失败，直到输入流被清除。
  • 如果 std::cin 由于之前的提取失败而处于不良状态，这里不会发生任何操作。变量 x 的值不会被改变。

我们将在下面的测验中探讨更多情况。

operator<< vs operator>>

新手程序员经常混淆 std::cin， std::cout，插入运算符（<<）和提取运算符（>>）。这里有一个简单的记忆方法：

  • std::cin 和 std::cout 总是放在运算符的左侧。
  • std::cout 用于输出值（cout = 字符输出）。
  • std::cin 用于获取输入值（cin = 字符输入）。
  • << 与...一起使用 std::cout，并显示数据的移动方向。 std::cout << 4 将值移动 4 到控制台。
  • >> 与...一起使用 std::cin，并显示数据的移动方向。 std::cin >> x 将用户从键盘输入的值移动到变量 x。

我们将在课程中进一步讨论运算符 1.9 -- 字面量和运算符简介。

顺便说一句……

如果你想知道为什么C++使用 std::cout 和 std::cin 而不是其他符号，请参阅 https://en.wikipedia.org/wiki/Standard_streams。

小测验时间

问题 #1

考虑我们上面使用的以下程序：

#include <iostream>  // for std::cout and std::cin

int main()
{
    std::cout << "Enter a number: "; // 向用户询问一个数字
    int x{}; // 定义变量 x 来保存用户输入
    std::cin >> x; // 从键盘获取数字并存储到变量 x 中
    std::cout << "You entered " << x << '\n';

    return 0;
}

程序要求你输入一个整数值，因为变量 x 用户输入将被放入的是一个整数变量。

多次运行此程序，并描述当你输入以下类型的输入时产生的输出：

a) 一个字母，例如 h。

显示答案

结果：总是打印0。
发生了什么：整数不能存储字母，因此提取完全失败。 x 被赋值为0。

b) 一个带有小数部分的数字（例如 3.2）。尝试小数部分小于0.5和大于0.5的数字（例如 3.2 和 3.7)。

显示答案

结果：小数部分被丢弃（而不是四舍五入）。
发生了什么：给定数字 3.2， 3 被提取出来，但 . 是一个无效字符，所以提取在此停止。 .2 保留供下次提取尝试。

如果你想知道为什么这不是被禁止的窄化转换，窄化转换仅在列表初始化期间被禁止（发生在第6行）。提取发生在第7行。

c) 一个小的负整数，例如 -3。

显示答案

结果：输入的数字被输出。
发生了什么：数字开头的负号是可接受的，因此它被提取。其余数字也被提取。

d) 一个单词，例如 Hello。

显示答案

结果：总是打印0。
发生了什么：整数不能存储字母，因此提取完全失败。 x 被赋值为0。

e) 一个非常大的数字（至少30亿）。

显示答案

结果：你很可能会得到数字 2147483647。
发生了什么： x 只能容纳一定范围内的数字。如果你输入的值大于最大数字 x 能容纳的值，它会被设置为 x 能容纳的最大值（很可能是 2147483647，但在你的系统上可能不同）。我们将在课程 4.4 -- 有符号整数。

f) 一个小数后面跟着一些字母，例如 123abc。

显示答案

结果：数值被打印出来（例如 123）。
发生了什么： 123 被提取后，剩余字符（例如 abc）留给后续提取。

g) 几个字母后跟一个小数字，例如 abc123。

显示答案

h) +5 （三个空格，后跟加号和数字 5）。

显示答案

问题 #2

要求用户输入三个值。程序随后应打印这些值。在函数上方添加适当的注释 main()。

程序应与以下输出匹配（当使用输入值运行时 4， 5、和 6)：

Enter three numbers: 4 5 6
You entered 4, 5, and 6.

显示提示

提示：函数上方的注释应描述 什么 函数的功能。

显示提示

提示：确保输出使用双引号。

显示答案

#include <iostream>

// 要求用户输入三个值，然后将这些值打印成一个句子。
int main()
{
    std::cout << "Enter three numbers: ";

    int x{};
    int y{};
    int z{};
    std::cin >> x >> y >> z;

    std::cout << "You entered " << x << ", " << y << ", and " << z << ".\n";

    return 0;
}

注意 ".\n" 必须使用双引号，因为我们要输出多个字符。
