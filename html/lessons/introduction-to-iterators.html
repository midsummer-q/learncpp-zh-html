18.2 — 迭代器简介

● 机器译文 课程 18.2 查看英文原文

遍历数组（或其他结构）中的数据是编程中非常常见的操作。到目前为止，我们已经介绍了很多不同的方法：使用循环和索引（for-loops 和 while loops），使用指针和指针算术，以及使用 range-based for-loops：

#include <array>
#include <cstddef>
#include <iostream>

int main()
{
    // 在C++17中，变量arr的类型被推导为std::array<int, 7>
    // 如果编译此示例时出错，请参阅下面的警告
    std::array arr{ 0, 1, 2, 3, 4, 5, 6 };
    std::size_t length{ std::size(arr) };

    // 使用显式索引的while循环
    std::size_t index{ 0 };
    while (index < length)
    {
        std::cout << arr[index] << ' ';
        ++index;
    }
    std::cout << '\n';

    // 使用显式索引的for循环
    for (index = 0; index < length; ++index)
    {
        std::cout << arr[index] << ' ';
    }
    std::cout << '\n';

    // 使用指针的for循环（注意：ptr不能是const，因为我们递增它）
    for (auto ptr{ &arr[0] }; ptr != (&arr[0] + length); ++ptr)
    {
        std::cout << *ptr << ' ';
    }
    std::cout << '\n';

    // 基于范围的for循环
    for (int i : arr)
    {
        std::cout << i << ' ';
    }
    std::cout << '\n';

    return 0;
}

警告

本课中的示例使用了一个称为 class template argument deduction 的 C++17 特性，从初始化器中推导模板变量的模板参数。在上面的例子中，当编译器看到 std::array arr{ 0, 1, 2, 3, 4, 5, 6 };时，它会推导出我们想要 std::array<int, 7> arr { 0, 1, 2, 3, 4, 5, 6 };。

如果你的编译器未启用 C++17，你会得到一个类似“missing template arguments before ‘arr’”的错误。在这种情况下，最好的办法是启用 C++17，如课程 0.12 -- 配置你的编译器：选择语言标准所述。如果无法做到，你可以将使用类模板参数推导的行替换为显式模板参数的行（例如，将 std::array arr{ 0, 1, 2, 3, 4, 5, 6 }; 替换为 std::array<int, 7> arr { 0, 1, 2, 3, 4, 5, 6 };

如果我们只使用索引来访问元素，使用索引循环会输入过多。而且它只在容器（例如数组）提供对元素的直接访问时才有效（数组可以，但其他类型的容器，如列表，则不行）。

使用指针和指针算术循环冗长，并且可能让不了解指针算术规则的读者感到困惑。指针算术也仅在元素在内存中连续时才有效（数组如此，但其他类型的容器，如列表、树和映射，则不然）。

进阶读者

指针（不带指针算术）也可以用于遍历某些非顺序结构。在链表中，每个元素通过指针与前一个元素相连。我们可以通过跟随指针链来遍历列表。

基于范围的 for 循环更有趣一些，因为遍历容器的机制是隐藏的——然而，它们仍然适用于各种不同的结构（数组、列表、树、映射等）。它们是如何工作的？它们使用迭代器。

迭代器

一种 迭代器 是一个设计用于遍历容器（例如数组中的值，或字符串中的字符）的对象，沿途提供对每个元素的访问。

一个容器可能提供不同种类的迭代器。例如，数组容器可能提供一个正向迭代器，按正向顺序遍历数组，以及一个反向迭代器，按反向顺序遍历数组。

一旦创建了适当类型的迭代器，程序员就可以使用迭代器提供的接口来遍历和访问元素，而无需担心遍历的类型或数据在容器中的存储方式。而且，由于 C++ 迭代器通常使用相同的接口进行遍历（operator++ 移动到下一个元素）和访问（operator* 访问当前元素），我们可以使用一致的方法遍历各种不同的容器类型。

指针作为迭代器

最简单的迭代器是指针，它（使用指针算术）适用于顺序存储在内存中的数据。让我们重新审视一个使用指针和指针算术的简单数组遍历：

#include <array>
#include <iostream>

int main()
{
    std::array arr{ 0, 1, 2, 3, 4, 5, 6 };

    auto begin{ &arr[0] };
    // 注意，这指向最后一个元素之后的一个位置
    auto end{ begin + std::size(arr) };

    // 使用指针的for循环
    for (auto ptr{ begin }; ptr != end; ++ptr) // ++移动到下一个元素
    {
        std::cout << *ptr << ' '; // 解引用获取当前元素的值
    }
    std::cout << '\n';

    return 0;
}

输出：

0 1 2 3 4 5 6

在上面的代码中，我们定义了两个变量： begin （指向容器的开头），以及 end （标记结束点）。对于数组，结束标记通常是如果容器再多一个元素时最后一个元素所在的内存位置。

指针在 begin 和 end之间迭代，当前元素可以通过解引用指针来访问。

警告

你可能会想使用取地址运算符和数组语法来计算结束标记，如下所示：

int* end{ &arr[std::size(arr)] };

但这会导致未定义行为，因为 arr[std::size(arr)] 隐式解引用了数组末尾之外的元素。

相反，请使用：

int* end{ arr.data() + std::size(arr) }; // data() 返回指向第一个元素的指针

标准库迭代器

迭代是如此常见的操作，以至于所有标准库容器都直接支持迭代。我们可以不自己计算开始和结束点，而是通过名为 begin() 和 end()：

#include <array>
#include <iostream>

int main()
{
    std::array array{ 1, 2, 3 };

    // 通过 begin 和 end 成员函数获取数组的起始点和结束点。
    auto begin{ array.begin() };
    auto end{ array.end() };

    for (auto p{ begin }; p != end; ++p) // ++ 移动到下一个元素。
    {
        std::cout << *p << ' '; // 解引用获取当前元素的值。
    }
    std::cout << '\n';

    return 0;
}

这会打印：

1 2 3

浮点类型的 iterator 头文件还包含两个通用函数（std::begin 和 std::end）可以使用。

提示

std::begin 和 std::end 对于 C 风格数组，定义在 <iterator> 头文件中。

std::begin 和 std::end 对于支持迭代器的容器，定义在相应容器的头文件中（例如 <array>、<vector>）。

#include <array>    // includes <iterator>
#include <iostream>

int main()
{
    std::array array{ 1, 2, 3 };

    // 使用 std::begin 和 std::end 获取起始点和结束点。
    auto begin{ std::begin(array) };
    auto end{ std::end(array) };

    for (auto p{ begin }; p != end; ++p) // ++移动到下一个元素
    {
        std::cout << *p << ' '; // 解引用获取当前元素的值
    }
    std::cout << '\n';

    return 0;
}

这也输出：

1 2 3

现在不必担心迭代器的类型，我们将在后面的章节中重新讨论迭代器。重要的是迭代器负责遍历容器的细节。我们只需要四样东西：起始点、结束点、operator++ 将迭代器移动到下一个元素（或结束），以及 operator* 获取当前元素的值。

operator< vs operator!= 对于迭代器

在课程 8.10 -- For 语句，我们注意到在循环条件中进行数值比较时，使用 operator< 比 operator!= 更可取：

    for (index = 0; index < length; ++index)

使用迭代器时，通常用 operator!= 来测试迭代器是否到达末尾元素：

    for (auto p{ begin }; p != end; ++p)

这是因为某些迭代器类型不支持关系比较。 operator!= 适用于所有迭代器类型。

回到基于范围的for循环

所有同时具有 begin() 和 end() 成员函数，或者可以与 std::begin() 和 std::end()一起使用的类型，都可以在基于范围的for循环中使用。

#include <array>
#include <iostream>

int main()
{
    std::array array{ 1, 2, 3 };

    // 这与我们之前使用的循环完全相同。
    for (int i : array)
    {
        std::cout << i << ' ';
    }
    std::cout << '\n';

    return 0;
}

在幕后，基于范围的for循环会调用 begin() 和 end() 成员函数来遍历类型。 std::array has begin 和 end 成员函数，因此我们可以在基于范围的循环中使用它。C风格固定数组可以与 std::begin 和 std::end 函数一起使用，因此我们也可以使用基于范围的循环遍历它们。但动态C风格数组（或退化的C风格数组）不行，因为没有 std::end 函数（因为类型信息不包含数组的长度）。

稍后你将学习如何将这些函数添加到你的类型中，以便它们也可以与基于范围的for循环一起使用。

基于范围的for循环并不是唯一使用迭代器的功能。它们还用于 std::sort 和其他算法。既然你已经知道它们是什么，你会注意到它们在标准库中被广泛使用。

迭代器失效（悬空迭代器）

与指针和引用类似，如果被迭代的元素改变地址或被销毁，迭代器可能会变得“悬空”。当这种情况发生时，我们说迭代器已经 失效。访问失效的迭代器会导致未定义行为。

某些修改容器的操作（例如向 std::vector添加元素）可能会产生副作用，导致容器中的元素改变地址。当这种情况发生时，指向这些元素的现有迭代器将失效。好的C++参考文档应该注明哪些容器操作可能或将会使迭代器失效。例如，请参见 “迭代器失效”部分 std::vector 在cppreference上。

由于基于范围的for循环在幕后使用迭代器，我们必须小心不要做任何会使我们正在遍历的容器的迭代器失效的事情：

#include <vector>

int main()
{
    std::vector v { 0, 1, 2, 3 };

    for (auto num : v) // 隐式遍历 v
    {
        if (num % 2 == 0)
            v.push_back(num + 1); // 当这使 v 的迭代器失效时，会导致未定义行为
    }

    return 0;
}

这是迭代器失效的另一个例子：

#include <iostream>
#include <vector>

int main()
{
	std::vector v{ 1, 2, 3, 4, 5, 6, 7 };

	auto it{ v.begin() };

	++it; // 移动到第二个元素
	std::cout << *it << '\n'; // ok: 打印 2

	v.erase(it); // 删除当前正在迭代的元素

	// erase() 会使指向被删除元素（及后续元素）的迭代器失效
	// 因此迭代器 "it" 现在已失效

	++it; // 未定义行为
	std::cout << *it << '\n'; // 未定义行为

	return 0;
}

失效的迭代器可以通过为其分配一个有效的迭代器来重新生效（例如 begin()， end()，或其他返回迭代器的函数的返回值）。

浮点类型的 erase() 函数返回指向被删除元素下一个元素的迭代器（如果删除了最后一个元素，则返回 end() ）。因此，我们可以像这样修复上面的代码：

#include <iostream>
#include <vector>

int main()
{
	std::vector v{ 1, 2, 3, 4, 5, 6, 7 };

	auto it{ v.begin() };

	++it; // 移动到第二个元素
	std::cout << *it << '\n';

	it = v.erase(it); // 删除当前正在迭代的元素，并将 `it` 设置为下一个元素

	std::cout << *it << '\n'; // 现在 ok，打印 3

	return 0;
}
