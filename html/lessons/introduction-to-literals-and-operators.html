1.9 — 字面量和运算符简介

● 机器译文 课程 1.9 查看英文原文

字面量

考虑以下两个语句：

std::cout << "Hello world!";
int x { 5 };

什么是“Hello world!”和“5”？它们是字面量。一个 字面量 （也称为一个 字面常量）是一个直接插入到源代码中的固定值。

字面量和变量都有值（和类型）。与变量不同（变量的值可以通过初始化和赋值分别设置和改变），字面量的值是固定的，不能改变。字面量 5 的值始终是 5。这就是为什么字面量被称为常量。

为了进一步突出字面量和变量之间的区别，我们来看这个简短的程序：

#include <iostream>

int main()
{
    std::cout << 5 << '\n'; // 输出字面量的值

    int x { 5 };
    std::cout << x << '\n'; // 输出变量的值
    return 0;
}

在第5行，我们打印值 5 到控制台。当编译器编译这段代码时，它会生成代码，使得 std::cout 打印值 5。这个值 5 被编译到可执行文件中，可以直接使用。

在第7行，我们创建一个名为 x的变量，并用值 5初始化它。编译器会生成代码，将字面值 5 放入任意给定的内存位置 x。在第8行，当我们打印 x时，编译器会生成代码，使得 std::cout 打印位于...的内存位置的值 x （其值为 5)。

因此，两个输出语句执行相同的操作（打印值5）。但对于字面量来说，该值 5 可以直接打印。对于变量来说，该值 5 必须从变量所代表的内存中取出。

这也解释了为什么字面量是常量而变量可以被改变。字面量的值被直接放在可执行文件中，可执行文件创建后自身无法被修改。变量的值被放在内存中，内存的值可以在可执行文件运行时被改变。

关键提示

字面量是直接插入到源代码中的值。这些值通常直接出现在可执行代码中（除非被优化掉）。

对象和变量代表存放值的内存位置。这些值可以按需获取。

运算符

在数学中，一个 运算 是一个涉及零个或多个输入值（称为 操作数）并产生一个新值（称为一个 输出值）。具体要执行的操作由一个符号表示，这个符号称为 operator。

例如，我们在孩提时都学过 2 + 3 等于 5。在这种情况下，字面量 2 和 3 是操作数，而符号 + 是运算符，它告诉我们对操作数应用数学加法以产生新值 5。

在C++中，操作与你预期的一样。例如：

#include <iostream>

int main()
{
    std::cout << 1 + 2 << '\n';

    return 0;
}

在此程序中，字面量 1 和 2 是 plus ( 的操作数+) 运算符，它产生输出值 3。然后这个输出值被打印到控制台。在C++中，操作的输出值通常被称为 返回值。

你可能已经非常熟悉标准算术运算符，这些运算符在数学中常用，包括加法（+），减法（-），乘法（*），和除法（/）。在C++中，赋值（=）也是一个运算符，同样还有插入（<<），提取（>>），和相等（==）。虽然大多数运算符使用符号作为名称（例如 +，或 ==），还有一些运算符是关键字（例如 new， delete、和 throw)。

作者注

原因在我们更详细地讨论运算符时会变得清楚，对于符号形式的运算符，通常将运算符的符号附加到单词 operator。

例如，加法运算符会被写作 operator+，而提取运算符会被写作 operator>>。

一个运算符接受的操作数的数量称为该运算符的 arityarity。很少有人知道这个词的意思，所以不要在对话中随意使用并期望别人明白你在说什么。C++中的运算符有四种不同的arity：

一元 运算符作用于一个操作数。一元运算符的一个例子是 - 运算符。例如，给定 -5， operator- 将字面量操作数 5 并翻转其符号以产生新的输出值 -5。

二元 运算符作用于两个操作数（通常称为 左 和 右，因为左操作数出现在运算符左侧，右操作数出现在运算符右侧）。二元运算符的一个例子是 + 运算符。例如，给定 3 + 4， operator+ 将左操作数 3 和右操作数 4 并应用数学加法以产生新的输出值 7. 插入（<<）和提取（>>）运算符是二元运算符，接受 std::cout 或 std::cin 在左侧接受，并在右侧接受要输出的值或要输入的变量。

三元 运算符作用于三个操作数。C++中只有一个这样的运算符（条件运算符），我们稍后会介绍。

零元 运算符作用于零个操作数。C++中也只有一个这样的运算符（throw运算符），我们稍后也会介绍。

注意，某些运算符根据使用方式不同具有多种含义。例如， operator- 有两种上下文。它可以作为一元运算符用于反转数字的符号（例如，将 5 切换到 -5，反之亦然），也可以作为二元运算符进行减法运算（例如， 4 - 3)。

运算符链

运算符可以链式组合，使得一个运算符的输出可以作为另一个运算符的输入。例如，给定以下代码： 2 * 3 + 4，乘法运算符首先执行，将左操作数 2 和右操作数 3 转换为返回值 6 （成为加法运算符的左操作数）。接下来，加法运算符执行，将左操作数 6 和右操作数 4 转换为新值 10。

我们将在深入探讨运算符主题时更详细地讨论运算符的执行顺序。目前，只要知道算术运算符的执行顺序与标准数学相同即可：括号优先，然后是指数，然后是乘除，最后是加减。这种顺序有时缩写为 PEMDAS，或扩展为助记词“Please Excuse My Dear Aunt Sally”。

作者注

在某些国家，PEMDAS被教授为PEDMAS、BEDMAS、BODMAS或BIDMAS。

返回值和副作用

C++中的大多数运算符只是使用其操作数来计算返回值。例如， -5 产生返回值 -5 和 2 + 3 产生返回值 5。有一些运算符不产生返回值（例如 delete 和 throw）。我们将在后面介绍它们的作用。

一些运算符具有额外的行为。一个运算符（或函数）如果除了产生返回值之外还有某种可观察到的效果，则称其具有 副作用。例如， x = 5 具有赋值的副作用，将值 5 给变量 x。改变后的值 x 是可观察的（例如，通过打印 x的值），即使在运算符执行完毕后也是如此。 std::cout << 5 具有打印 5 到控制台的副作用。我们可以观察到 5 已被打印到控制台，即使在 std::cout << 5 执行完毕后也是如此。

术语

在日常用语中，“side effect”一词通常用来指某个其他事情（例如服药）产生的次要（通常是负面或意外的）结果。例如，服用口服抗生素的一个常见副作用是腹泻。因此，我们经常将副作用视为我们想要避免的事情，或者是对主要目标而言附带的事情。

在C++中，“副作用”一词有不同的含义：它是指运算符或函数在产生返回值之外的一种可观察效果。

由于赋值具有改变对象值的可观察效果，因此被视为副作用。我们主要为了其副作用（而非这些运算符产生的返回值）而使用某些运算符（例如赋值运算符）。在这种情况下，副作用既有益又可预测（而返回值往往是附带的）。

进阶读者

对于主要为了其返回值而调用的运算符（例如 operator+ 或 operator*），它们的返回值通常显而易见（例如操作数的和或积）。

对于主要为了其副作用而调用的运算符（例如 operator= 或 operator<<），它们产生什么返回值（如果有的话）并不总是显而易见。例如，你期望 x = 5 有什么返回值？

两者都 operator= 和 operator<< （当用于向控制台输出值时）都返回其左操作数。因此， x = 5 返回 x、和 std::cout << 5 返回 std::cout。这样做是为了使这些运算符可以链式调用。

例如， x = y = 5 求值结果为 x = (y = 5)。首先 y = 5 赋值 5 切换到 y。此操作随后返回 y，然后可以赋值给 x。

std::cout << "Hello " << "world!" 求值结果为 (std::cout << "Hello ") << "world!"。这首先输出 "Hello " 到控制台。此操作返回 std::cout，然后可用于输出 "world!" 也输出到控制台。
