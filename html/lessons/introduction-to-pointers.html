12.7 — 指针入门

● 机器译文 课程 12.7 查看英文原文

指针是C++历史上令人恐惧的概念之一，也是许多有抱负的C++学习者卡住的地方。然而，你很快就会看到，指针并不可怕。

事实上，指针的行为很像左值引用。但在进一步解释之前，让我们做一些准备工作。

相关内容

如果你对左值引用不熟悉或有些生疏，现在正是复习它们的好时机。我们在以下课程中介绍了左值引用： 12.3 -- 左值引用， 12.4 -- 对 const 的左值引用、和 12.5 -- 通过左值引用传递。

考虑一个普通变量，比如这个：

char x {}; // char 占用 1 字节内存

简化一点，当执行此定义生成的代码时，RAM中的一块内存将被分配给这个对象。为了举例，假设变量 x 被分配了内存地址 140。每当我们使用变量 x 在表达式或语句中时，程序将前往内存地址 140 以访问存储在那里的值。

变量的好处在于我们不需要担心分配了哪些具体的内存地址，或者存储对象值需要多少字节。我们只需通过给定的标识符引用变量，编译器将这个名称转换为适当分配的内存地址。编译器处理所有寻址工作。

引用也是如此：

int main()
{
    char x {}; // 假设分配的内存地址为 140
    char& ref { x }; // ref 是 x 的左值引用（当与类型一起使用时，& 表示左值引用）

    return 0;
}

因为 ref 作为 x的别名，每当我们使用 ref时，程序将前往内存地址 140 以访问该值。同样，编译器处理寻址，所以我们不必考虑它。

取地址运算符 (&)

尽管变量使用的内存地址默认不暴露给我们，但我们确实可以访问这些信息。 取地址运算符 (&) 返回其操作数的内存地址。这非常简单：

#include <iostream>

int main()
{
    int x{ 5 };
    std::cout << x << '\n';  // 打印变量 x 的值
    std::cout << &x << '\n'; // 打印变量 x 的内存地址

    return 0;
}

在作者的机器上，上述程序打印了：

5
0027FEA0

在上面的例子中，我们使用取地址运算符 (&) 获取分配给变量 x 的地址，并将该地址打印到控制台。内存地址通常以十六进制值打印（我们在课程 5.3 -- 数字系统（十进制、二进制、十六进制和八进制）中介绍了十六进制），通常不带 0x 前缀。

对于使用多个字节内存的对象，取地址将返回对象使用的第一个字节的内存地址。

提示

& 符号容易引起混淆，因为它在不同上下文中有不同含义：

  • 当跟在类型名后面时，& 表示左值引用： int& ref。
  • 当在表达式中用作一元运算符时，& 是取地址运算符： std::cout << &x。
  • 当在表达式中用作二元运算符时，& 是按位与运算符： std::cout << x & y。

解引用运算符 (*)

获取变量的地址本身并不是很有用。

我们能用地址做的最有用的事情是访问存储在该地址的值。 解引用运算符 (*)（有时也称为 间接运算符）以左值形式返回给定内存地址的值：

#include <iostream>

int main()
{
    int x{ 5 };
    std::cout << x << '\n';  // 打印变量 x 的值
    std::cout << &x << '\n'; // 打印变量 x 的内存地址

    std::cout << *(&x) << '\n'; // 打印变量 x 内存地址处的值（括号非必需，但更易读）

    return 0;
}

在作者的机器上，上述程序打印了：

5
0027FEA0
5

这个程序很简单。首先我们声明一个变量 x 并打印它的值。然后我们打印变量 x的地址。最后，我们使用解引用运算符获取变量 x 的内存地址处的值（也就是 x)，我们将其打印到控制台。

关键提示

给定一个内存地址，我们可以使用解引用运算符（*）来获取该地址处的值（作为左值）。

取地址运算符（&）和解引用运算符（*）互为逆操作：取地址获取对象的地址，解引用获取地址处的对象。

提示

尽管解引用运算符看起来与乘法运算符相同，但可以通过解引用运算符是一元运算符而乘法运算符是二元运算符来区分它们。

获取变量的内存地址然后立即解引用该地址以获取值并不是很有用（毕竟，我们可以直接使用变量来访问值）。

但现在我们已经将取地址运算符（&）和解引用运算符（*）添加到工具箱中，我们准备讨论指针。

指针

一个 指针 是一个对象，它持有 内存地址 （通常是另一个变量的地址）作为其值。这允许我们存储某个其他对象的地址以供以后使用。

顺便说一句……

在现代C++中，我们这里讨论的指针有时被称为“原始指针”或“笨指针”，以区别于语言中后来引入的“智能指针”。我们在 第 22 章。

指定指针的类型（例如 int*int& 指针类型。就像引用类型使用&符号声明一样，指针类型使用星号（*）声明：

int;  // 一个普通的 int
int&; // 一个 int 值的左值引用

int*; // 一个指向 int 值的指针（保存整数值的地址）

要创建指针变量，我们只需定义一个指针类型的变量：

int main()
{
    int x { 5 };    // 普通变量
    int& ref { x }; // 一个整数的引用（绑定到 x）

    int* ptr;       // 一个指向整数的指针

    return 0;
}

注意，这个星号是指针声明语法的一部分，而不是解引用运算符的使用。

最佳实践

声明指针类型时，将星号放在类型名称旁边。

警告

尽管通常不应在一行上声明多个变量，但如果这样做，星号必须包含在每个变量中。

int* ptr1, ptr2;   // 错误：ptr1 是指向 int 的指针，但 ptr2 只是普通的 int！
int* ptr3, * ptr4; // 正确：ptr3 和 ptr4 都是指向 int 的指针

尽管这有时被用作不将星号放在类型名称旁边（而是放在变量名称旁边）的论据，但更好的论据是避免在同一语句中定义多个变量。

指针初始化

像普通变量一样，指针是 不是 默认初始化的。未初始化的指针有时被称为 野指针。野指针包含一个垃圾地址，解引用野指针将导致未定义行为。因此，应始终将指针初始化为已知值。

最佳实践

始终初始化你的指针。

int main()
{
    int x{ 5 };

    int* ptr;        // 一个未初始化的指针（持有垃圾地址）
    int* ptr2{};     // 一个空指针（我们将在下一课中讨论）
    int* ptr3{ &x }; // 一个初始化为变量 x 地址的指针

    return 0;
}

由于指针持有地址，当我们初始化或给指针赋值时，该值必须是地址。通常，指针用于持有另一个变量的地址（我们可以使用取地址运算符（&）获取）。

一旦我们有了一个持有另一个对象地址的指针，我们就可以使用解引用运算符（*）来访问该地址处的值。例如：

#include <iostream>

int main()
{
    int x{ 5 };
    std::cout << x << '\n'; // 打印变量 x 的值

    int* ptr{ &x }; // ptr 持有 x 的地址
    std::cout << *ptr << '\n'; // 使用解引用运算符打印 ptr 所持地址处的值（即 x 的地址）

    return 0;
}

这会打印：

5
5

从概念上讲，你可以将上面的代码片段想象成这样：

这就是指针名称的由来—— ptr 持有 x的地址，所以我们说 ptr “指向” x。

作者注

关于指针命名法的说明：“X指针”（其中X是某种类型）是“指向X的指针”的常用简写。所以当我们说“整数指针”时，我们实际上是指“指向整数的指针”。当我们讨论const指针时，这种理解将很有价值。

就像引用的类型必须与所引用对象的类型匹配一样，指针的类型必须与所指向对象的类型匹配：

int main()
{
    int i{ 5 };
    double d{ 7.0 };

    int* iPtr{ &i };     // 可以：指向 int 的指针可以指向 int 对象
    int* iPtr2 { &d };   // 不可以：指向 int 的指针不能指向 double 对象
    double* dPtr{ &d };  // 可以：指向 double 的指针可以指向 double 对象
    double* dPtr2{ &i }; // 不可以：指向 double 的指针不能指向 int 对象

    return 0;
}

除了下一课将讨论的一个例外，用字面量值初始化指针是不允许的：

int* ptr{ 5 }; // 不可以
int* ptr{ 0x0012FF7C }; // 不可以，0x0012FF7C 被视为整数字面量

指针与赋值

我们可以通过两种不同的方式使用赋值与指针：

  1. 改变指针指向的内容（通过给指针赋一个新地址）
  2. 改变所指向的值（通过给解引用的指针赋一个新值）

首先，我们来看一个指针被改变指向不同对象的情况：

#include <iostream>

int main()
{
    int x{ 5 };
    int* ptr{ &x }; // ptr 初始化为指向 x

    std::cout << *ptr << '\n'; // 打印所指向地址处的值（x 的地址）

    int y{ 6 };
    ptr = &y; // 将 ptr 改为指向 y

    std::cout << *ptr << '\n'; // 打印所指向地址处的值（y 的地址）

    return 0;
}

上述代码打印：

5
6

在上面的例子中，我们定义指针 ptr，用 x的地址初始化它，并解引用指针以打印所指向的值（5）。然后我们使用赋值运算符将 ptr 持有的地址改为 y的地址。接着我们再次解引用指针以打印所指向的值（现在是 6)。

现在让我们看看如何用指针改变所指向的值：

#include <iostream>

int main()
{
    int x{ 5 };
    int* ptr{ &x }; // 用变量 x 的地址初始化 ptr

    std::cout << x << '\n';    // 打印 x 的值
    std::cout << *ptr << '\n'; // 打印 ptr 所持地址处的值（x 的地址）

    *ptr = 6; // ptr 所持地址处的对象（x）被赋值为 6（注意此处对 ptr 解引用）

    std::cout << x << '\n';
    std::cout << *ptr << '\n'; // 打印 ptr 所持地址处的值（x 的地址）

    return 0;
}

该程序打印出：

5
5
6
6

在这个例子中，我们定义指针 ptr，用 x，然后打印 x 和 *ptr (5的值。因为 *ptr 返回一个左值，我们可以将其放在赋值语句的左侧，从而改变 ptr 切换到 6所指向的值。然后我们再次打印 x 和 *ptr 的值，以显示值已按预期更新。

关键提示

当我们使用不带解引用的指针（ptr）时，我们访问的是指针持有的地址。修改它（ptr = &y）会改变指针所指向的对象。

当我们解引用指针（*ptr）时，我们访问的是所指向的对象。修改它（*ptr = 6;）会改变所指向对象的值。

指针的行为很像左值引用

指针和左值引用行为相似。考虑以下程序：

#include <iostream>

int main()
{
    int x{ 5 };
    int& ref { x };  // 获取 x 的引用
    int* ptr { &x }; // 获取 x 的指针

    std::cout << x;
    std::cout << ref;  // 使用引用打印 x 的值（5）
    std::cout << *ptr << '\n'; // 使用指针打印 x 的值（5）

    ref = 6; // 使用引用改变 x 的值
    std::cout << x;
    std::cout << ref;  // 使用引用打印 x 的值（6）
    std::cout << *ptr << '\n'; // 使用指针打印 x 的值（6）

    *ptr = 7; // 使用指针改变 x 的值
    std::cout << x;
    std::cout << ref;  // 使用引用打印 x 的值 (7)
    std::cout << *ptr << '\n'; // 使用指针打印 x 的值 (7)

    return 0;
}

该程序打印出：

555
666
777

在上面的程序中，我们创建了一个普通变量 x 、值为 5，然后创建了一个左值引用和一个指向 x的指针。接着，我们使用左值引用将值从 5 切换到 6，并显示我们可以通过所有三种方法访问更新后的值。最后，我们使用解引用的指针将值从 6 切换到 7，并再次显示我们可以通过所有三种方法访问更新后的值。

因此，指针和引用都提供了间接访问另一个对象的方式。主要区别在于，使用指针时，我们需要显式获取要指向的地址，并且必须显式解引用指针以获取值。而使用引用时，取地址和解引用是隐式发生的。

指针和引用之间还有一些其他值得注意的区别：

  • 引用必须初始化，指针不要求初始化（但应该初始化）。
  • 引用不是对象，指针是对象。
  • 引用不能重新绑定（改变引用的对象），指针可以改变指向的对象。
  • 引用必须始终绑定到一个对象，指针可以指向空（我们将在下一课中看到这样的例子）。
  • 引用是“安全的”（除了悬空引用），指针本质上是危险的（我们将在下一课中讨论这一点）。

取地址运算符返回一个指针

值得注意的是，取地址运算符（&）返回的不是其操作数的地址字面量（因为C++不支持地址字面量）。相反，它返回一个指向操作数的指针（其值就是操作数的地址）。换句话说，给定变量 int x， &x 返回一个 int* ，其中包含 x。

的地址。我们可以在下面的例子中看到这一点：

#include <iostream>
#include <typeinfo>

int main()
{
	int x{ 4 };
	std::cout << typeid(x).name() << '\n';  // 打印 x 的类型
	std::cout << typeid(&x).name() << '\n'; // 打印 &x 的类型

	return 0;
}

在Visual Studio上，打印结果为：

int
int *

使用 gcc 时，这打印了 i (int) 和 pi (指向 int 的指针)。因为 typeid().name() 的结果依赖于编译器，你的编译器可能会打印不同的内容，但含义相同。

指针的大小

指针的大小取决于可执行文件编译所针对的架构——32 位可执行文件使用 32 位内存地址——因此，32 位机器上的指针是 32 位（4 字节）。对于 64 位可执行文件，指针将是 64 位（8 字节）。注意，无论被指向对象的大小如何，这一点都成立：

#include <iostream>

int main() // 假设是 32 位应用程序
{
    char* chPtr{};        // char 是 1 字节
    int* iPtr{};          // int 通常是 4 字节
    long double* ldPtr{}; // long double 通常是 8 或 12 字节

    std::cout << sizeof(chPtr) << '\n'; // 打印 4
    std::cout << sizeof(iPtr) << '\n';  // 打印 4
    std::cout << sizeof(ldPtr) << '\n'; // 打印 4

    return 0;
}

指针的大小总是相同的。这是因为指针只是一个内存地址，而访问内存地址所需的位数是恒定的。

悬空指针

与悬空引用非常相似， 悬空指针 是指向不再有效（例如，因为它已被销毁）的对象的指针。

解引用悬空指针（例如，为了打印被指向的值）将导致未定义行为，因为你试图访问一个不再有效的对象。

也许令人惊讶的是，标准规定“对无效指针的任何其他使用 值 具有实现定义的行为”。这意味着你可以为无效指针赋予一个新值，例如 nullptr（因为这没有使用无效指针的值）。然而，任何其他使用无效指针值的操作（例如复制或递增无效指针）将产生实现定义的行为。

关键提示

解引用无效指针将导致未定义行为。对无效指针值的任何其他使用都是实现定义的。

下面是一个创建悬空指针的例子：

#include <iostream>

int main()
{
    int x{ 5 };
    int* ptr{ &x };

    std::cout << *ptr << '\n'; // 有效

    {
        int y{ 6 };
        ptr = &y;

        std::cout << *ptr << '\n'; // 有效
    } // y 离开作用域，ptr 现在悬空

    std::cout << *ptr << '\n'; // 解引用悬空指针导致未定义行为

    return 0;
}

上面的程序可能会打印：

5
6
6

但也可能不会，因为 ptr 所指向的对象在内部块结束时离开了作用域并被销毁，使得 ptr 悬空。

总结

指针是保存内存地址的变量。可以使用解引用运算符 (*) 解引用它们，以获取它们所保存地址处的值。解引用野指针、悬空指针（或空指针）将导致未定义行为，并可能导致应用程序崩溃。

指针比引用更灵活，也更危险。我们将在接下来的课程中继续探讨这一点。

问题 #1

#include <iostream>

int main()

	std::cout << '\n';

关于 4 和 2 的简要说明。32 位机器意味着指针长度为 32 位，但 sizeof() 总是以字节为单位打印大小。32 位是 4 字节。因此 sizeof(ptr) 是 4。因为 ptr 是指向 short 的指针， *ptr 是一个 short。在这个例子中，short 的大小是 2 字节。因此 sizeof(*ptr) 是 2。

问题 #2

这段代码片段有什么问题？

int v1{ 45 };
int* ptr{ &v1 }; // 用 v1 的地址初始化 ptr

int v2 { 78 };
*ptr = &v2;     // 将 ptr 赋值为 v2 的地址

显示答案

上面片段的最后一行无法编译。

让我们更详细地检查这个程序。

第一行和第四行包含标准变量定义以及初始化值。这里没什么特别的。

在第二行，星号是指针声明语法的一部分（不是解引用）。所以这一行说的是“将 v1 切换到 ptr的地址赋值给”。这没问题，因为指针保存地址。

在第五行，星号表示解引用，用于获取指针指向的值。所以这一行说的是“将 v2 的地址赋值给 ptr指向的值”。 ptr 指向的值是一个整数。所以这个赋值没有意义——你不能将地址赋值给整数！

第五行应该是：

ptr = &v2;

这正确地将 v2 的地址赋值给了指针。
