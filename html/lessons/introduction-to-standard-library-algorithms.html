18.3 — 标准库算法简介

● 机器译文 课程 18.3 查看英文原文

新程序员通常会花费大量时间编写自定义循环来执行相对简单的任务，例如排序、计数或搜索数组。这些循环可能存在问题，既容易出错，又难以维护，因为循环可能难以理解。

由于搜索、计数和排序是非常常见的操作，C++ 标准库提供了一组函数，只需几行代码即可完成这些操作。此外，这些标准库函数经过预测试，效率高，适用于各种不同的容器类型，并且许多支持并行化（将多个 CPU 线程用于同一任务以更快完成的能力）。

算法库提供的功能通常分为三类：

  • 检查器（Inspectors） ——用于查看（但不修改）容器中的数据。示例包括搜索和计数。
  • 修改器（Mutators） ——用于修改容器中的数据。示例包括排序和打乱。
  • 辅助器（Facilitators） ——用于根据数据成员的值生成结果。示例包括对值进行相乘的对象，或确定元素对排序顺序的对象。

这些算法位于 algorithms 库中。在本课中，我们将探讨一些更常见的算法——但还有更多，我们鼓励您阅读链接的参考资料以查看所有可用的内容！

注意：所有这些都使用迭代器，因此如果您不熟悉基本迭代器，请复习课程 18.2 -- 迭代器简介。

使用 std::find 按值查找元素

std::find std::find 搜索容器中某个值的第一次出现。 std::find std::find 接受 3 个参数：指向序列中起始元素的迭代器、指向序列中结束元素的迭代器以及要搜索的值。它返回一个指向该元素的迭代器（如果找到）或容器的末尾（如果未找到元素）。

例如：

#include <algorithm>
#include <array>
#include <iostream>

int main()
{
    std::array arr{ 13, 90, 99, 5, 40, 80 };

    std::cout << "Enter a value to search for and replace with: ";
    int search{};
    int replace{};
    std::cin >> search >> replace;

    // 输入验证已省略

    // std::find 返回一个指向找到的元素的迭代器（或容器的末尾）
    // 我们将其存储在一个变量中，使用类型推断来推导
    // 迭代器的类型（因为我们不关心）
    auto found{ std::find(arr.begin(), arr.end(), search) };

    // 没有找到所需内容的算法会返回末尾迭代器。
    // 我们可以通过使用 end() 成员函数来访问它。
    if (found == arr.end())
    {
        std::cout << "Could not find " << search << '\n';
    }
    else
    {
        // 覆盖找到的元素。
        *found = replace;
    }

    for (int i : arr)
    {
        std::cout << i << ' ';
    }

    std::cout << '\n';

    return 0;
}

找到元素时的示例运行

Enter a value to search for and replace with: 5 234
13 90 99 234 40 80

未找到元素时的示例运行

Enter a value to search for and replace with: 0 234
Could not find 0
13 90 99 5 40 80

使用 std::find_if 查找满足某个条件的元素

有时我们想查看容器中是否存在满足某个条件的值（例如，包含特定子字符串的字符串），而不是精确值。在这种情况下， std::find_if std::find_if 是完美的。

浮点类型的 std::find_if std::find_if 函数的工作方式类似于 std::findstd::find，但不是传入要搜索的特定值，而是传入一个可调用对象，例如函数指针（或 lambda，我们稍后会介绍）。对于每个被迭代的元素， std::find_if std::find_if 将调用此函数（将元素作为参数传递给函数），如果找到匹配项，函数可以返回 true true，否则返回 false 如果它是空指针，否则为

false。下面是一个示例，我们使用 std::find_if std::find_if 检查是否有任何元素包含子字符串“nut”：

#include <algorithm>
#include <array>
#include <iostream>
#include <string_view>

// // 如果元素匹配，我们的函数将返回 true
bool containsNut(std::string_view str)
{
    // // std::string_view::find 如果没有找到则返回 std::string_view::npos
    // // 子字符串。否则返回子字符串在 str 中出现的索引
    // // 在 str 中。
    return str.find("nut") != std::string_view::npos;
}

int main()
{
    std::array<std::string_view, 4> arr{ "apple", "banana", "walnut", "lemon" };

    // // 扫描我们的数组，查看是否有任何元素包含 "nut" 子字符串
    auto found{ std::find_if(arr.begin(), arr.end(), containsNut) };

    if (found == arr.end())
    {
        std::cout << "No nuts\n";
    }
    else
    {
        std::cout << "Found " << *found << '\n';
    }

    return 0;
}

输出

Found walnut

如果您手动编写上述示例，至少需要三个循环（一个用于遍历数组，两个用于匹配子字符串）。标准库函数让我们只需几行代码就能完成同样的事情！

使用 std::count 和 std::count_if 计算出现次数

std::count 和 std::count_if std::count 和 std::count_if 搜索元素或满足条件的元素的所有出现。

在以下示例中，我们将计算包含子字符串“nut”的元素数量：

#include <algorithm>
#include <array>
#include <iostream>
#include <string_view>

bool containsNut(std::string_view str)
{
	return str.find("nut") != std::string_view::npos;
}

int main()
{
	std::array<std::string_view, 5> arr{ "apple", "banana", "walnut", "lemon", "peanut" };

	auto nuts{ std::count_if(arr.begin(), arr.end(), containsNut) };

	std::cout << "Counted " << nuts << " nut(s)\n";

	return 0;
}

输出

Counted 2 nut(s)

使用 std::sort 进行自定义排序

我们之前使用过 std::sort std::sort 对数组进行升序排序，但 std::sort 可以做得更多。有一个版本的 std::sort std::sort 接受一个函数作为其第三个参数，允许我们按自己喜欢的方式排序。该函数接受两个参数进行比较，如果第一个参数应排在第二个参数之前，则返回 true。默认情况下， std::sort std::sort 按升序对元素进行排序。

让我们使用 std::sort std::sort 通过一个名为 greater 的自定义比较函数对数组进行降序排序： greater：

#include <algorithm>
#include <array>
#include <iostream>

bool greater(int a, int b)
{
    // 如果 @a 大于 @b，则将 @a 排在 @b 之前。
    return (a > b);
}

int main()
{
    std::array arr{ 13, 90, 99, 5, 40, 80 };

    // 将 greater 传递给 std::sort
    std::sort(arr.begin(), arr.end(), greater);

    for (int i : arr)
    {
        std::cout << i << ' ';
    }

    std::cout << '\n';

    return 0;
}

输出

99 90 80 40 13 5

再次强调，我们不需要编写自己的自定义循环函数，只需几行代码就可以按自己喜欢的方式对数组进行排序！

的对象时未提供显式初始化值，则将使用这些默认成员初始化值。我们的 greater 函数需要2个参数，但我们没有传递任何参数，那么它们从哪里来？当我们使用不带括号()的函数时，它只是一个函数指针，而不是函数调用。你可能还记得，当我们尝试打印一个不带括号的函数时， std::cout 打印了“1”。 std::sort 使用这个指针并调用实际的 greater 函数，传入数组中的任意2个元素。我们不知道 greater 会调用哪些元素，因为底层使用哪种排序算法并未定义。 std::sort 我们将在后面的章节中详细讨论函数指针。

提示

由于降序排序非常常见，C++也为此提供了一个自定义类型（名为 std::greater）（它属于 functional 头文件）。在上面的例子中，我们可以替换：

  std::sort(arr.begin(), arr.end(), greater); // 调用我们自定义的 greater 函数

一起使用的类：

  std::sort(arr.begin(), arr.end(), std::greater{}); // 使用标准库的 greater 比较
  // 在 C++17 之前，我们在创建 std::greater 时必须指定元素类型
  std::sort(arr.begin(), arr.end(), std::greater<int>{}); // 使用标准库的 greater 比较

中使用它的值。 std::greater{} 需要花括号，因为它不是一个可调用的函数。它是一个类型，为了使用它，我们需要实例化该类型的对象。花括号实例化了一个该类型的匿名对象（然后将其作为参数传递给std::sort）。

进阶读者

为了进一步解释 std::sort 如何使用比较函数，我们需要回到课程 18.1 -- 使用选择排序对数组进行排序。

#include <iostream>
#include <iterator>
#include <utility>

void sort(int* begin, int* end)
{
    for (auto startElement{ begin }; startElement != end-1; ++startElement)
    {
        auto smallestElement{ startElement };

        // std::next 返回指向下一个元素的指针，就像 (startElement + 1) 一样。
        for (auto currentElement{ std::next(startElement) }; currentElement != end; ++currentElement)
        {
            if (*currentElement < *smallestElement)
            {
                smallestElement = currentElement;
            }
        }

        std::swap(*startElement, *smallestElement);
    }
}

int main()
{
    int array[]{ 2, 1, 9, 4, 5 };

    sort(std::begin(array), std::end(array));

    for (auto i : array)
    {
        std::cout << i << ' ';
    }

    std::cout << '\n';

    return 0;
}

中的选择排序示例的修改版本。到目前为止，这并不新鲜， sort 总是将元素从低到高排序。为了添加比较函数，我们必须使用一个新类型， std::function<bool(int, int)>，用于存储一个接受2个int参数并返回bool的函数。暂时将这个类型视为魔法，我们将在 第20章。

void sort(int* begin, int* end, std::function<bool(int, int)> compare)

中解释它。现在我们可以传递一个比较函数，比如 greater 切换到 sort，但是 sort 如何使用它？我们只需要替换这一行

if (*currentElement < *smallestElement)

替换为

if (compare(*currentElement, *smallestElement))

现在 sort 的调用者可以选择如何比较两个元素。

#include <functional> // std::function
#include <iostream>
#include <iterator>
#include <utility>

// sort 接受一个比较函数
void sort(int* begin, int* end, std::function<bool(int, int)> compare)
{
    for (auto startElement{ begin }; startElement != end-1; ++startElement)
    {
        auto smallestElement{ startElement };

        for (auto currentElement{ std::next(startElement) }; currentElement != end; ++currentElement)
        {
            // 比较函数用于检查当前元素是否应该排在
            // 当前“最小”元素之前。
            if (compare(*currentElement, *smallestElement))
            {
                smallestElement = currentElement;
            }
        }

        std::swap(*startElement, *smallestElement);
    }
}

int main()
{
    int array[]{ 2, 1, 9, 4, 5 };

    // 使用 std::greater 按降序排序
    // （我们必须使用全局命名空间选择器以防止
    // 我们的 sort 函数与 std::sort 冲突。）
    ::sort(std::begin(array), std::end(array), std::greater{});

    for (auto i : array)
    {
        std::cout << i << ' ';
    }

    std::cout << '\n';

    return 0;
}

使用std::for_each对容器中的所有元素执行操作

std::for_each 接受一个列表作为输入，并对每个元素应用自定义函数。当我们希望对列表中的每个元素执行相同操作时，这很有用。

false。下面是一个示例，我们使用 std::for_each 将数组中的所有数字加倍：

#include <algorithm>
#include <array>
#include <iostream>

void doubleNumber(int& i)
{
    i *= 2;
}

int main()
{
    std::array arr{ 1, 2, 3, 4 };

    std::for_each(arr.begin(), arr.end(), doubleNumber);

    for (int i : arr)
    {
        std::cout << i << ' ';
    }

    std::cout << '\n';

    return 0;
}

输出

2 4 6 8

对于新开发者来说，这通常看起来是最不必要的算法，因为使用基于范围的for循环的等效代码更短且更容易。但使用 std::for_each有好处。让我们比较 std::for_each 和基于范围的for循环。

std::ranges::for_each(arr, doubleNumber); // 从 C++20 开始，我们不必使用 begin() 和 end()。
// std::for_each(arr.begin(), arr.end(), doubleNumber); // C++20 之前

for (auto& i : arr)
{
    doubleNumber(i);
}

使用 std::for_each，我们的意图很明确。对 doubleNumber 的每个元素调用 arr。在基于范围的for循环中，我们必须添加一个新变量， i。这会导致程序员在疲劳或注意力不集中时可能犯的几个错误。首先，如果我们不使用 auto，可能会发生隐式转换。我们可能忘记取地址符，导致 doubleNumber 不会影响数组。我们可能意外地传递了除 i 切换到 doubleNumber之外的变量。这些错误在使用 std::for_each。

课中讨论了返回值可以在常量表达式中使用的函数。 std::for_each 时可以跳过容器开头或结尾的元素，例如跳过 arr， std::next 的第一个元素。可以使用

std::for_each(std::next(arr.begin()), arr.end(), doubleNumber);
// 现在 arr 是 [1, 4, 6, 8]。第一个元素没有被加倍。

将begin推进到下一个元素。这在基于范围的for循环中是不可能的。

像许多算法一样， std::for_each 可以并行化以实现更快的处理，使其比基于范围的for循环更适合大型项目和大数据。

性能与执行顺序

算法库中的许多算法都会对它们的执行方式做出某种保证。通常这些保证要么是性能保证，要么是关于执行顺序的保证。例如， std::for_each 保证每个元素只被访问一次，并且元素按正向顺序访问。

虽然大多数算法都提供某种性能保证，但很少有算法提供执行顺序保证。对于这类算法，我们需要小心，不要对元素被访问或处理的顺序做出假设。

例如，如果我们使用标准库算法将第一个值乘以1，第二个值乘以2，第三个值乘以3，等等……我们应避免使用任何不保证正向顺序执行的算法！

以下算法保证顺序执行： std::for_each， std::copy， std::copy_backward， std::move、和 std::move_backward。许多其他算法（特别是那些使用前向迭代器的算法）由于前向迭代器的要求而隐式地按顺序执行。

最佳实践

在使用特定算法之前，请确保性能和执行顺序保证适用于您的特定用例。

C++20 中的范围

必须显式传递 arr.begin() 和 arr.end() 给每个算法有点烦人。但别担心——C++20 添加了 范围，它允许我们只传递 arr。这将使我们的代码更短、更易读。
