5.8 — std::string_view 简介

● 机器译文 课程 5.8 查看英文原文

考虑以下程序：

#include <iostream>

int main()
{
    int x { 5 }; // x 复制其初始化器
    std::cout << x << '\n';

    return 0;
}

当执行 x 的定义时，初始化值 5 被复制到为变量 int x分配的内存中。对于基本类型，初始化和复制变量很快。

现在考虑这个类似的程序：

#include <iostream>
#include <string>

int main()
{
    std::string s{ "Hello, world!" }; // s 复制其初始化器
    std::cout << s << '\n';

    return 0;
}

当 s 被初始化时，C风格字符串字面量 "Hello, world!" 被复制到为 std::string s分配的内存中。与基本类型不同，初始化和复制一个 std::string 很慢。

在上面的程序中，我们对 s 所做的只是将值打印到控制台，然后 s 被销毁。我们实际上复制了“Hello, world!”只是为了打印然后销毁那个副本。这效率低下。

在这个例子中我们也看到类似的情况：

#include <iostream>
#include <string>

void printString(std::string str) // str 复制其初始化器
{
    std::cout << str << '\n';
}

int main()
{
    std::string s{ "Hello, world!" }; // s 复制其初始化器
    printString(s);

    return 0;
}

这个例子复制了C风格字符串“Hello, world!”两次：一次在初始化 s 在 main()时，另一次在初始化参数 str 在 printString()时。仅仅为了打印一个字符串就进行了大量不必要的复制！

std::string_view C++17

为了解决 std::string 初始化（或复制）代价高昂的问题，C++17引入了 std::string_view （位于 <string_view> 头文件中）。 std::string_view 提供对 现有 字符串（C风格字符串、 std::string或另一个 std::string_view）的只读访问，而不进行复制。 只读 意味着我们可以访问和使用被查看的值，但不能修改它。

下面的例子与之前的相同，只是我们将 std::string 替换为 std::string_view。

#include <iostream>
#include <string_view> // C++17

// str 提供对传入参数的只读访问
void printSV(std::string_view str) // 现在是一个 std::string_view
{
    std::cout << str << '\n';
}

int main()
{
    std::string_view s{ "Hello, world!" }; // 现在是一个 std::string_view
    printSV(s);

    return 0;
}

这个程序产生与之前相同的输出，但没有复制字符串“Hello, world!”。

当我们用C风格字符串字面量 std::string_view s 初始化 "Hello, world!"， s 时， s 切换到 printSV()提供对“Hello, world!”的只读访问，而不复制字符串。当我们传递 str 时，参数 s从 str初始化。这使我们能够通过

最佳实践

优先使用 std::string_view 而不是 std::string 访问“Hello, world!”，同样不复制字符串。

std::string_view 当你需要一个只读字符串时，尤其是作为函数参数。

可以用许多不同类型的字符串初始化 std::string_view 的一个巧妙之处在于它的灵活性。一个 std::string_view 对象可以用C风格字符串、 std::string或另一个 std::string_view：

#include <iostream>
#include <string>
#include <string_view>

int main()
{
    std::string_view s1 { "Hello, world!" }; // 用 C 风格字符串字面量初始化
    std::cout << s1 << '\n';

    std::string s{ "Hello, world!" };
    std::string_view s2 { s };  // 用 std::string 初始化
    std::cout << s2 << '\n';

    std::string_view s3 { s2 }; // 用 std::string_view 初始化
    std::cout << s3 << '\n';
       
    return 0;
}

std::string_view 参数可以接受多种不同类型的字符串参数

C风格字符串和 std::string 都会隐式转换为 std::string_view。因此， std::string_view 参数可以接受C风格字符串、 std::string，或 std::string_view：

#include <iostream>
#include <string>
#include <string_view>

void printSV(std::string_view str)
{
    std::cout << str << '\n';
}

int main()
{
    printSV("Hello, world!"); // 使用C风格字符串字面量调用

    std::string s2{ "Hello, world!" };
    printSV(s2); // 使用 std::string 调用

    std::string_view s3 { s2 };
    printSV(s3); // 使用 std::string_view 调用
       
    return 0;
}

std::string_view 不会隐式转换为 std::string

因为 std::string 会复制其初始化器（这很昂贵），C++不允许将 std::string_view 转换为 std::string隐式转换为 std::string_view 参数转换为 std::string 参数，从而在可能不需要的情况下意外进行昂贵的复制。

但是，如果需要这样做，我们有两种选择：

  1. 显式创建一个 std::string 字面量初始化 std::string_view 初始化器（这是允许的，因为很少会无意中这样做）
  2. 将现有的 std::string_view 转换为 std::string using static_cast

以下示例展示了这两种选择：

#include <iostream>
#include <string>
#include <string_view>

void printString(std::string str)
{
	std::cout << str << '\n';
}

int main()
{
	std::string_view sv{ "Hello, world!" };

	// printString(sv);   // 编译错误：不会隐式将 std::string_view 转换为 std::string

	std::string s{ sv }; // 可以：我们可以使用 std::string_view 初始化器创建 std::string
	printString(s);      // 并用该 std::string 调用函数

	printString(static_cast<std::string>(sv)); // 可以：我们可以显式地将 std::string_view 转换为 std::string

	return 0;
}

赋值会改变 std::string_view 所查看的内容

将新字符串赋值给 std::string_view 会导致 std::string_view 查看新字符串。它不会以任何方式修改之前被查看的字符串。

以下示例说明了这一点：

#include <iostream>
#include <string>
#include <string_view>

int main()
{
    std::string name { "Alex" };
    std::string_view sv { name }; // sv 现在正在查看 name
    std::cout << sv << '\n'; // 打印 Alex

    sv = "John"; // sv 现在正在查看 "John"（不改变 name）
    std::cout << sv << '\n'; // 打印 John

    std::cout << name << '\n'; // 打印 Alex

    return 0;
}

在上面的例子中， sv = "John" 导致 sv 现在查看字符串 "John"。它不会改变 name 持有的值（仍然是 "Alex")。

中进一步讨论。 std::string_view

双引号字符串字面量默认是C风格字符串字面量。我们可以创建类型为 std::string_view 后缀在双引号字符串字面量之后创建类型为 sv 的字符串字面量。 sv 必须是小写。

#include <iostream>
#include <string>      // for std::string
#include <string_view> // for std::string_view

int main()
{
    using namespace std::string_literals;      // 访问 s 后缀
    using namespace std::string_view_literals; // 访问 sv 后缀

    std::cout << "foo\n";   // 无后缀是C风格字符串字面量
    std::cout << "goo\n"s;  // s后缀是std::string字面量
    std::cout << "moo\n"sv; // sv 后缀是一个 std::string_view 字面量

    return 0;
}

相关内容

我们讨论这种用法 using namespace 在课程 5.7 -- std::string 简介。同样的建议也适用于此。

用C风格字符串字面量初始化 std::string_view 对象是可以的（你不需要用 std::string_view 字面量来初始化它）。

也就是说，用 std::string_view 列表初始化一个类型为 std::string_view 字面量初始化不会引起问题（因为这样的字面量实际上是伪装的C风格字符串字面量）。

constexpr std::string_view

与 std::string， std::string_view 完全支持constexpr：

#include <iostream>
#include <string_view>

int main()
{
    constexpr std::string_view s{ "Hello, world!" }; // s 是一个字符串符号常量
    std::cout << s << '\n'; // s 将在编译时被替换为 "Hello, world!"

    return 0;
}

这使得 constexpr std::string_view 成为需要字符串符号常量时的首选。
