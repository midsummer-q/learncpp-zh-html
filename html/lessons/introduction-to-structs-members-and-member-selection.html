13.7 — 结构体、成员和成员选择简介

● 机器译文 课程 13.7 查看英文原文

在编程中，有很多情况下我们需要多个变量来表示某个感兴趣的事物。正如我们在前一章的引言中所讨论的（12.1 -- 复合数据类型简介），分数有分子和分母，它们连接在一起形成一个单一的数学对象。

或者，假设我们想编写一个程序，需要存储公司员工的信息。我们可能希望跟踪员工的姓名、职位、年龄、员工ID、经理ID、工资、生日、入职日期等属性。

如果我们使用独立的变量来跟踪所有这些信息，可能会像这样：

std::string name;
std::string title;
int age;
int id;
int managerId;
double wage;
int birthdayYear;
int birthdayMonth;
int birthdayDay;
int hireYear;
int hireMonth;
int hireDay;

然而，这种方法存在许多问题。首先，这些变量是否真正相关并不明显（你必须阅读注释，或者查看它们在上下文中的使用方式）。其次，现在有12个变量需要管理。如果我们想将这个员工传递给一个函数，我们必须传递12个参数（并且按正确的顺序），这将使我们的函数原型和函数调用变得混乱。而且，由于函数只能返回一个值，函数如何返回一个员工呢？

如果我们想要多个员工，我们需要为每个额外的员工定义另外12个变量（每个变量都需要一个唯一的名称！）。这显然根本无法扩展。我们真正需要的是某种方式将所有相关的数据组织在一起，使它们更易于管理。

幸运的是，C++提供了两种复合类型来解决这类挑战：结构体（我们现在介绍）和类（我们很快会探讨）。 结构体 （是 结构）是一种程序定义的数据类型（13.1 -- 程序定义（用户定义）类型简介），它允许我们将多个变量捆绑成一个单一的类型。正如你很快会看到的，这使得管理相关变量集变得更加简单！

提醒

结构体是一种类类型（类和联合体也是）。因此，适用于类类型的一切也适用于结构体。

定义结构体

由于结构体是程序定义的类型，我们必须先告诉编译器结构体类型的外观，然后才能开始使用它。下面是一个简化版员工的结构体定义示例：

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

浮点类型的 struct 关键字用于告诉编译器我们正在定义一个结构体，我们将其命名为 Employee （因为程序定义的类型通常以大写字母开头命名）。

然后，在一对花括号内，我们定义每个 Employee 对象将包含的变量。在这个例子中，每个 Employee 我们将创建的对象将有 3 个变量：一个 int id，一个 int age，和一个 double wage。结构体中的变量称为 数据成员 （或 成员变量)。

提示

在日常用语中，一个 成员 是某个群体中的一员。例如，你可能是篮球队的成员，而你的妹妹可能是合唱团的成员。

在C++中， 成员 是一个属于结构体（或类）的变量、函数或类型。所有成员都必须在结构体（或类）定义中声明。

我们将使用术语 成员 在未来的课程中会经常出现，所以请务必记住它的含义。

就像我们使用一对空花括号进行值初始化（1.4 -- Variable assignment and initialization) 普通变量，每个成员变量后的空花括号确保我们内部的成员变量 Employee 在对象被值初始化时 Employee 被创建。我们将在几节课后讨论默认成员初始化时进一步探讨这个问题（13.9 -- 默认成员初始化)。

最后，我们以分号结束类型定义。

提醒一下， Employee 只是一个类型定义——此时并未实际创建任何对象。

定义结构体对象

为了使用 Employee 类型，我们只需定义一个类型为 Employee：

Employee joe {}; // Employee 是类型，joe 是变量名

这定义了一个类型为 Employee 的变量，名为 joe。当代码执行时，会实例化一个包含3个数据成员的Employee对象。空花括号确保我们的对象被值初始化。

就像任何其他类型一样，可以定义同一结构体类型的多个变量：

Employee joe {}; // 为Joe创建一个Employee结构体
Employee frank {}; // 为Frank创建一个Employee结构体

访问成员

考虑以下示例：

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

int main()
{
    Employee joe {};

    return 0;
}

在上面的例子中，名称 joe 指的是整个结构体对象（包含成员变量）。要访问特定的成员变量，我们使用 成员选择运算符 (operator.) 放在结构体变量名和成员名之间。例如，要访问 Joe 的 age 成员，我们会使用 joe.age。

结构体成员变量与普通变量一样，可以对它们进行常规操作，包括赋值、算术运算、比较等……

#include <iostream>

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

int main()
{
    Employee joe {};

    joe.age = 32;  // 使用成员选择运算符 (.) 选择变量 joe 的 age 成员

    std::cout << joe.age << '\n'; // 打印乔的年龄

    return 0;
}

这会打印：

32

结构体最大的优势之一是，每个结构体变量只需要创建一个新名称（成员名称作为结构体类型定义的一部分是固定的）。在下面的示例中，我们实例化两个 Employee 对象： joe 和 frank。

#include <iostream>

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

int main()
{
    Employee joe {};
    joe.id = 14;
    joe.age = 32;
    joe.wage = 60000.0;

    Employee frank {};
    frank.id = 15;
    frank.age = 28;
    frank.wage = 45000.0;

    int totalAge { joe.age + frank.age };
    std::cout << "Joe and Frank have lived " << totalAge << " total years\n";

    if (joe.wage > frank.wage)
        std::cout << "Joe makes more than Frank\n";
    else if (joe.wage < frank.wage)
        std::cout << "Joe makes less than Frank\n";
    else
        std::cout << "Joe and Frank make the same amount\n";

    // Frank 得到了晋升
    frank.wage += 5000.0;

    // 今天是乔的生日
    ++joe.age; // 使用前置递增将Joe的年龄增加1

    return 0;
}

在上面的例子中，很容易分辨哪些成员变量属于Joe，哪些属于Frank。这比单独的变量提供了更高的组织性。此外，由于Joe和Frank的成员具有相同的名称，当你有多个相同结构体类型的变量时，这提供了一致性。
