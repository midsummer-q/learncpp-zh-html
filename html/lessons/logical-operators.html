6.8 — 逻辑运算符

● 机器译文 课程 6.8 查看英文原文

虽然关系（比较）运算符可用于测试特定条件是否为真或假，但它们一次只能测试一个条件。通常我们需要知道多个条件是否同时为真。例如，要检查我们是否中了彩票，我们必须比较我们选择的多个数字是否都与中奖号码匹配。在6个数字的彩票中，这将涉及6次比较， 所有 所有这些都必须为真。在其他情况下，我们需要知道多个条件中是否有任何一个为真。例如，如果我们生病了，或者太累了，或者在前面的例子中中了彩票，我们可能决定今天不去上班。这将涉及检查 任何 3个比较中是否有任何一个为真。

逻辑运算符为我们提供了测试多个条件的能力。

C++有3个逻辑运算符：

运算符符号用法示例操作
逻辑非！!x如果x为假则为真，如果x为真则为假
逻辑与&&x && y如果x和y都为真则为真，否则为假
逻辑或||x || y如果x或y（或两者）为真则为真，否则为假

逻辑非

你已经在课程中遇到过逻辑非一元运算符 4.9 -- 布尔值。我们可以将逻辑非的效果总结如下：

逻辑非（operator !）
操作数结果
真假
假真

如果 逻辑非的 操作数求值为真， 逻辑非 求值为假。如果 逻辑非的 操作数求值为假， 逻辑非 求值为真。换句话说， 逻辑非 将布尔值从真翻转为假，反之亦然。

逻辑非常用于条件语句中：

bool tooLarge { x > 100 }; // // tooLarge 为 true 如果 x > 100
if (!tooLarge)
    // // 对 x 进行某些操作
else
    // // 打印错误

需要注意的一点是， 逻辑非 具有非常高的优先级。新手程序员常犯以下错误：

#include <iostream>

int main()
{
    int x{ 5 };
    int y{ 7 };

    if (!x > y)
        std::cout << x << " is not greater than " << y << '\n';
    else
        std::cout << x << " is greater than " << y << '\n';

    return 0;
}

该程序打印出：

5 is greater than 7

但是 x 并不大于 y，那么这怎么可能呢？答案是，因为 逻辑非 运算符的优先级高于 大于 运算符，表达式 ! x > y 实际上被求值为 (!x) > y。因为 x 是5，!x求值为 0、和 0 > y 为假，所以 else 语句执行了！

编写上述代码段的正确方式是：

#include <iostream>

int main()
{
    int x{ 5 };
    int y{ 7 };

    if (!(x > y))
        std::cout << x << " is not greater than " << y << '\n';
    else
        std::cout << x << " is greater than " << y << '\n';

    return 0;
}

这样， x > y 会先被求值，然后逻辑非会翻转布尔结果。

最佳实践

如果 逻辑非 旨在作用于其他运算符的结果，因此其他运算符及其操作数需要括在括号中。

简单使用 逻辑非，例如 if (!value) 不需要括号，因为优先级不发挥作用。

逻辑或

浮点类型的 逻辑或 运算符用于测试两个条件中是否有一个为真。如果左操作数为真，或右操作数为真，或两者都为真，则 逻辑或 运算符返回真。否则返回假。

逻辑或（运算符 ||）
左操作数右操作数结果
假假假
假真真
真假真
真真真

例如，考虑以下程序：

#include <iostream>

int main()
{
    std::cout << "Enter a number: ";
    int value {};
    std::cin >> value;

    if (value == 0 || value == 1)
        std::cout << "You picked 0 or 1\n";
    else
        std::cout << "You did not pick 0 or 1\n";
    return 0;
}

在这种情况下，我们使用逻辑或运算符来测试左条件（value == 0）或右条件（value == 1）是否为真。如果其中一个（或两个）为真，则 逻辑或 运算符求值为真，这意味着 if 语句 执行。如果两者都不为真，则 逻辑或 运算符求值为假，这意味着 else语句 执行。

警告

新手程序员有时会尝试这样写：

    if (value == 0 || 1) // // 错误：如果 value 为 0，或如果 1

当 1 被求值时，会隐式转换为 bool true。因此这个条件将始终求值为 true。

如果你想将一个变量与多个值比较，你需要多次比较该变量：

    if (value == 0 || value == 1) // // 正确：如果 value 为 0，或如果 value 为 1

你可以将多个 逻辑或 语句串联起来：

if (value == 0 || value == 1 || value == 2 || value == 3)
     std::cout << "You picked 0, 1, 2, or 3\n";

新手程序员有时会混淆 逻辑或 运算符（||）与 按位或 运算符（|）（在课程 O.2 -- 位运算符中介绍）。尽管它们名称中都带有 或 ，但它们执行不同的功能。混淆它们可能会导致错误的结果。

逻辑与

浮点类型的 逻辑与 运算符用于测试两个操作数是否都为真。如果两个操作数都为真， 逻辑与 返回真。否则返回假。

逻辑与（运算符 &&）
左操作数右操作数结果
假假假
假真假
真假假
真真真

例如，我们可能想知道变量 x 的值是否在 10 和 20之间。这实际上是两个条件：我们需要知道 x 是否大于 10，以及 x 是否小于 20。

#include <iostream>

int main()
{
    std::cout << "Enter a number: ";
    int value {};
    std::cin >> value;

    if (value > 10 && value < 20)
        std::cout << "Your value is between 10 and 20\n";
    else
        std::cout << "Your value is not between 10 and 20\n";
    return 0;
}

在这种情况下，我们使用 逻辑与 运算符来测试左侧条件（value > 10）和右侧条件（value < 20）是否都为真。如果两者都为真，则 逻辑与 运算符求值为真，并且 if 语句 执行。如果两者都不为真，或者只有一个为真，则 逻辑与 运算符求值为假，并且 else语句 执行。

与 逻辑或类似，你可以将多个 逻辑与 语句串联起来：

if (value > 10 && value < 20 && value != 16)
    // // 执行某些操作
else
    // // 执行其他操作

如果所有这些条件都为真，则 if 语句 将执行。如果其中任何一个条件为假，则 else语句 将执行。

与逻辑或和按位或类似，新手程序员有时会混淆 逻辑与 运算符（&&）与 按位与 运算符（&）。

短路求值

为了使 逻辑与 返回真，两个操作数都必须求值为真。如果左操作数求值为假， 逻辑与 知道无论右操作数求值为真还是假，它都必须返回假。在这种情况下， 逻辑与 运算符将直接返回假，甚至不计算右操作数！这被称为 短路求值，这主要是为了优化目的。

类似地，如果 逻辑或 的左操作数为真，那么整个或条件必须求值为真，并且右操作数将不会被求值。

短路求值提供了另一个机会来展示为什么导致副作用的运算符不应在复合表达式中使用。考虑以下代码片段：

if (x == 1 && ++y == 2)
    // // 执行某些操作

如果 x 不等于 1，整个条件必须为假，因此 ++y 永远不会被求值！因此， y 只有在 x 求值为 1 时才会递增，这可能不是程序员想要的！

警告

短路求值可能导致 逻辑或 和 逻辑与 不计算右操作数。避免在这些运算符中使用带有副作用的表达式。

关键提示

逻辑或和逻辑与运算符是操作数可能以任意顺序求值规则的一个例外，因为标准明确规定左操作数必须首先求值。

进阶读者

只有这些运算符的内置版本执行短路求值。如果你重载这些运算符以使其适用于你自己的类型，这些重载的运算符将不会执行短路求值。

混合使用 AND 和 OR

在同一个表达式中混合使用 逻辑与 和 逻辑或 运算符通常无法避免，但这是一个充满潜在危险的领域。

因为 逻辑与 和 逻辑或 看起来像一对，许多程序员认为它们具有相同的优先级（就像加法/减法和乘法/除法一样）。然而， 逻辑与 的优先级高于 逻辑或，因此 逻辑与 运算符将在 逻辑或 运算符之前被求值（除非它们被括号括起来）。

新手程序员经常编写诸如 value1 || value2 && value3。因为 逻辑与 具有更高的优先级，因此该表达式被求值为 value1 || (value2 && value3)，而不是 (value1 || value2) && value3。希望这正是程序员想要的！如果程序员假设从左到右结合（就像加法/减法或乘法/除法那样），那么程序员将得到他或她意想不到的结果！

当在同一个表达式中混合使用 逻辑与 和 逻辑或 时，最好为每个运算符及其操作数显式添加括号。这有助于避免优先级错误，使代码更易读，并清晰定义你希望表达式如何求值。例如，与其写 value1 && value2 || value3 && value4，不如写 (value1 && value2) || (value3 && value4)。

最佳实践

当在同一个表达式中混合使用 逻辑与 和 逻辑或 在单个表达式中时，显式地为每个操作加上括号，以确保它们按你的意图求值。

德摩根定律

许多程序员也错误地认为 !(x && y) 等同于 !x && !y。不幸的是，你不能以那种方式“分配” 逻辑非

德摩根定律 告诉我们如何在这些情况下分配 逻辑非 ：

!(x && y) 等价于 !x || !y
!(x || y) 等价于 !x && !y

换句话说，当你分配 逻辑非时，还需要翻转 逻辑与 切换到 逻辑或，反之亦然！

这在试图使复杂表达式更易读时有时会很有用。

进阶读者

我们可以通过证明 !(x && y) 等于 !x || !y 对于每一个可能的 x 和 y值都成立，来展示德摩根定律的第一部分是正确的。为此，我们将使用一个称为真值表的数学概念：

xy!x!y!(x && y)!x || !y

假真真假真真
真假假真真真
真真假假假假

在这个表中，第一列和第二列代表我们的 x 和 y 变量。表中的每一行显示 x 和 y。因为 x 和 y 是布尔值，我们只需要4行来覆盖 x 和 y 所能容纳的最大值。

可能取值的所有组合。表中的其余列代表我们想要基于 x 和 y的初始值求值的表达式。第三列和第四列分别计算 !x 和 !y 的值。第五列计算 !(x && y)的值。最后，第六列计算 !x || !y。

我们可以对德摩根定律的第二部分做同样的操作：

类似地，对于每一个可能的 x 和 y值，我们可以看到 !(x || y) 的值等于 !x && !y的值。因此，它们是等价的。

逻辑异或（XOR）运算符在哪里？

逻辑异或 是一些语言中提供的逻辑运算符，用于测试奇数个条件是否为真：

逻辑异或
左操作数右操作数结果
假假假
假真真
真假真
真真假

C++ 没有提供显式的 逻辑异或 运算符（operator^ 是按位异或，不是逻辑异或）。与 逻辑或 或 逻辑与， 逻辑异或 不同，它不能短路求值。因此，用 逻辑异或 运算符构造 逻辑或 和 逻辑与 运算符具有挑战性。

然而， operator!= 在给定 bool 操作数时产生与逻辑异或相同的结果：

左操作数右操作数逻辑异或运算符!=
假假假假
假真真真
真假真真
真真假假

因此，逻辑异或可以如下实现：

if (a != b) ... // // a XOR b，假设 a 和 b 是 bool

这可以扩展到多个操作数，如下所示：

if (a != b != c) ... // // a XOR b XOR c，假设 a、b 和 c 是 bool

如果奇数个操作数（ true ）求值为a， b、和 c，则结果为 true。

如果操作数不是 bool类型，使用 operator!= 实现逻辑异或将无法按预期工作。

进阶读者

如果你需要一种 逻辑异或 形式来处理非布尔操作数，可以将操作数 static_cast 为 bool：

if (static_cast<bool>(a) != static_cast<bool>(b) != static_cast<bool>(c)) ... // a XOR b XOR c，适用于任何可以转换为 bool 的类型

然而，这有点冗长。以下技巧也有效，并且更简洁：

if (!!a != !!b != !!c) // a XOR b XOR c，适用于任何可以转换为 bool 的类型

这利用了 operator! （逻辑非运算符）隐式将其操作数转换为 bool的事实。然而， operator! 也会反转 bool 从 true 切换到 false 或反之。因此，我们需要应用 operator! 两次。第一次进行隐式转换为 bool 并反转 bool。第二次将 bool 反转回其原始值。这种双重反转在多个操作数的异或具有奇数个操作数时是必要的，否则异或将产生反转的结果。

这两种方法都不太直观，所以如果使用它们，请做好文档记录。

替代运算符表示

C++ 中的许多运算符（如 operator ||）只有符号名称。历史上，并非所有键盘和语言标准都支持输入这些运算符所需的所有符号。因此，C++ 支持一组替代的关键字，这些关键字使用单词而不是符号。例如，你可以使用关键字 ||代替 or。

完整列表可以在 这里找到。特别值得注意的是以下三个：

运算符名称关键字替代名称
&&和
||或
！不是

这意味着以下写法是相同的：

std::cout << !a && (b || c);
std::cout << not a and (b or c);

虽然这些替代名称现在看起来可能更容易理解，但大多数有经验的 C++ 开发者更喜欢使用符号名称而非关键字名称。因此，我们建议学习并使用符号名称，因为这是你在现有代码中常见的写法。

问题 #2

在课程 6.3 课 -- 余数和幂运算，我们编写了一个函数来判断一个数是否为偶数，如下所示：

#include <iostream>

bool isEven(int x)
{
    // 如果 x % 2 == 0，则 2 能整除我们的数字，这意味着它必须是偶数
    return (x % 2) == 0;
}

int main()
{
    std::cout << "Enter an integer: ";
    int x{};
    std::cin >> x;

    if (isEven(x))
        std::cout << x << " is even\n";
    else
        std::cout << x << " is odd\n";

    return 0;
}

使用 operator! 而不是 operator==。

显示答案

#include <iostream>

bool isEven(int x)
{
    return !(x % 2);
}

int main()
{
    std::cout << "Enter an integer: ";
    int x{};
    std::cin >> x;

    if (isEven(x))
        std::cout << x << " is even\n";
    else
        std::cout << x << " is odd\n";

    return 0;
}
