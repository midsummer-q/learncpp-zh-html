28.3 — 使用 ostream 和 ios 进行输出

● 机器译文 课程 28.3 查看英文原文

在本节中，我们将探讨 iostream 输出类（ostream）的各个方面。

插入运算符

插入运算符（<<）用于将信息放入输出流。C++ 为所有内置数据类型预定义了插入操作，并且你已经看到如何 重载插入运算符 用于你自己的类。

在关于 流，你看到 istream 和 ostream 都派生自一个名为 ios 的类。ios（以及 ios_base）的任务之一是控制输出的格式化选项。

格式化

有两种方法可以更改格式化选项：标志和操纵器。你可以将 标志 视为可以打开和关闭的布尔变量。 操纵器 是放置在流中影响输入和输出方式的对象。

要打开一个标志，使用 setf() 函数，并将适当的标志作为参数。例如，默认情况下，C++ 不会在正数前面打印 + 号。但是，通过使用 std::ios::showpos 标志，我们可以改变这种行为：

std::cout.setf(std::ios::showpos); // 打开 std::ios::showpos 标志
std::cout << 27 << '\n';

这将产生以下输出：

+27

可以使用按位或（|）运算符一次打开多个 ios 标志：

std::cout.setf(std::ios::showpos | std::ios::uppercase); // 打开 std::ios::showpos 和 std::ios::uppercase 标志
std::cout << 1234567.89f << '\n';

这会输出：

+1.23457E+06

要关闭一个标志，使用 unsetf() 函数：

std::cout.setf(std::ios::showpos); // 打开 std::ios::showpos 标志
std::cout << 27 << '\n';
std::cout.unsetf(std::ios::showpos); // 关闭 std::ios::showpos 标志
std::cout << 28 << '\n';

这将产生以下输出：

+27
28

使用 setf() 时还有另一个需要提及的棘手问题。许多标志属于称为格式组的组。一个 格式组 是一组执行相似（有时互斥）格式化选项的标志。例如，一个名为“basefield”的格式组包含标志“oct”、“dec”和“hex”，它们控制整数值的进制。默认情况下，“dec”标志被设置。因此，如果我们这样做：

std::cout.setf(std::ios::hex); // 尝试打开十六进制输出
std::cout << 27 << '\n';

我们得到以下输出：

27

它没有起作用！原因在于 setf() 只打开标志——它不够智能，无法关闭互斥的标志。因此，当我们打开 std::hex 时，std::ios::dec 仍然打开，并且 std::ios::dec 显然具有优先权。有两种方法可以解决这个问题。

首先，我们可以关闭 std::ios::dec，以便只设置 std::hex：

std::cout.unsetf(std::ios::dec); // 关闭十进制输出
std::cout.setf(std::ios::hex); // 打开十六进制输出
std::cout << 27 << '\n';

现在我们得到预期的输出：

1b

第二种方法是使用另一种形式的 setf()，它接受两个参数：第一个参数是要设置的标志，第二个是它所属的格式组。使用这种形式的 setf() 时，属于该组的所有标志都被关闭，只有传入的标志被打开。例如：

// 将 std::ios::hex 设置为唯一的 std::ios::basefield 标志
std::cout.setf(std::ios::hex, std::ios::basefield);
std::cout << 27 << '\n';

这也产生了预期的输出：

1b

使用 setf() 和 unsetf() 往往很笨拙，因此 C++ 提供了第二种更改格式化选项的方法：操纵器。操纵器的好处在于它们足够智能，可以打开和关闭适当的标志。以下是一个使用一些操纵器更改进制的示例：

std::cout << std::hex << 27 << '\n'; // 以十六进制打印 27
std::cout << 28 << '\n'; // 我们仍然在十六进制模式
std::cout << std::dec << 29 << '\n'; // 回到十进制

该程序产生输出：

1b
1c
29

一般来说，使用操纵器比设置和取消设置标志容易得多。许多选项可以通过标志和操纵器两种方式使用（例如更改进制），然而，其他选项只能通过标志或只能通过操纵器使用，因此了解如何使用两者很重要。

精度、记数法和小数点

使用操纵器（或标志），可以改变浮点数显示的精度和格式。有几个格式化选项以相当复杂的方式组合，因此我们将更仔细地研究这一点。

宽度、填充字符和对齐

通常打印数字时，数字的打印不考虑周围的空格。然而，可以左对齐或右对齐数字的打印。为此，我们首先需要定义一个字段宽度，它定义了一个值将占用的输出空格数。如果实际打印的数字小于字段宽度，它将按指定方式左对齐或右对齐。如果实际数字大于字段宽度，它不会被截断——而是会溢出字段。

组标志含义
std::ios::adjustfieldstd::ios::internal左对齐数字的符号，右对齐数值
std::ios::adjustfieldstd::ios::left左对齐符号和数值
std::ios::adjustfieldstd::ios::right右对齐符号和数值（默认）

操纵器含义
std::internal左对齐数字的符号，右对齐数值
std::left左对齐符号和数值
std::right右对齐符号和数值
std::setfill(char)将参数设置为填充字符（定义在 iomanip 头文件中）
std::setw(int)将输入和输出的字段宽度设置为参数（定义在 iomanip 头文件中）

成员函数含义
std::basic_ostream::fill()返回当前填充字符
std::basic_ostream::fill(char)设置填充字符并返回旧的填充字符
std::ios_base::width()返回当前字段宽度
std::ios_base::width(int)设置当前字段宽度并返回旧的字段宽度

为了使用这些格式化器中的任何一个，我们首先必须设置一个字段宽度。这可以通过 width(int) 成员函数或 setw() 操纵器来完成。注意右对齐是默认的。

std::cout << -12345 << '\n'; // 打印默认值，无字段宽度
std::cout << std::setw(10) << -12345 << '\n'; // 打印默认值，带字段宽度
std::cout << std::setw(10) << std::left << -12345 << '\n'; // 打印左对齐
std::cout << std::setw(10) << std::right << -12345 << '\n'; // 打印右对齐
std::cout << std::setw(10) << std::internal << -12345 << '\n'; // 内部对齐打印

这会产生以下结果：

-12345
    -12345
-12345
    -12345
-    12345

需要注意的一点是，setw() 和 width() 只影响下一个输出语句。它们不像其他一些标志/操纵器那样持久。

现在，让我们设置一个填充字符并做同样的例子：

std::cout.fill('*');
std::cout << -12345 << '\n'; // 打印默认值，无字段宽度
std::cout << std::setw(10) << -12345 << '\n'; // 打印默认值，带字段宽度
std::cout << std::setw(10) << std::left << -12345 << '\n'; // 打印左对齐
std::cout << std::setw(10) << std::right << -12345 << '\n'; // 打印右对齐
std::cout << std::setw(10) << std::internal << -12345 << '\n'; // 内部对齐打印

这将产生输出：

-12345
****-12345
-12345****
****-12345
-****12345

注意字段中的所有空白都被填充字符填满了。

ostream 类和 iostream 库包含其他可能有用的输出函数、标志和操纵器，具体取决于你需要做什么。与 istream 类一样，这些主题更适合专注于标准库的教程或书籍。
