21.2 — 使用友元函数重载算术运算符

● 机器译文 课程 21.2 查看英文原文

C++ 中最常用的运算符之一是算术运算符——即加号运算符 (+)、减号运算符 (-)、乘号运算符 (*) 和除号运算符 (/)。注意，所有算术运算符都是二元运算符——意味着它们接受两个操作数——运算符两侧各一个。这四个运算符的重载方式完全相同。

事实证明，重载运算符有三种不同的方式：成员函数方式、友元函数方式和普通函数方式。在本课中，我们将介绍友元函数方式（因为它对于大多数二元运算符更直观）。下一课，我们将讨论普通函数方式。最后，在本章后面的一课中，我们将介绍成员函数方式。当然，我们还会更详细地总结每种方式的使用时机。

使用友元函数重载运算符

考虑以下类：

class Cents
{
private:
	int m_cents {};

public:
	Cents(int cents) : m_cents{ cents } { }
	int getCents() const { return m_cents; }
};

以下示例展示了如何重载加号运算符 (+) 以将两个“Cents”对象相加：

#include <iostream>

class Cents
{
private:
	int m_cents {};

public:
	Cents(int cents) : m_cents{ cents } { }

	// 使用友元函数实现 Cents + Cents
	friend Cents operator+(const Cents& c1, const Cents& c2);

	int getCents() const { return m_cents; }
};

// 注意：这个函数不是成员函数！
Cents operator+(const Cents& c1, const Cents& c2)
{
	// 使用 Cents 构造函数和 operator+(int, int)
	// 我们可以直接访问 m_cents，因为这是一个友元函数
	return c1.m_cents + c2.m_cents;
}

int main()
{
	Cents cents1{ 6 };
	Cents cents2{ 8 };
	Cents centsSum{ cents1 + cents2 };
	std::cout << "I have " << centsSum.getCents() << " cents.\n";

	return 0;
}

这会产生以下结果：

I have 14 cents.

重载加号运算符 (+) 就像声明一个名为 operator+ 的函数一样简单，为其提供两个我们想要相加的操作数类型的参数，选择合适的返回类型，然后编写函数体。

对于我们的 Cents 对象，实现 operator+() 函数非常简单。首先，参数类型：在这个版本的 operator+ 中，我们将两个 Cents 对象相加，所以函数将接受两个 Cents 类型的对象。其次，返回类型：我们的 operator+ 将返回一个 Cents 类型的结果，所以这就是我们的返回类型。

最后，实现：要将两个 Cents 对象相加，我们实际上需要将每个 Cents 对象的 m_cents 成员相加。因为我们的重载 operator+() 函数是类的友元，我们可以直接访问参数的 m_cents 成员。此外，由于 m_cents 是整数，并且 C++ 知道如何使用适用于整数操作数的内置加号运算符来相加整数，我们可以简单地使用 + 运算符进行相加。

重载减法运算符 (-) 也很简单：

#include <iostream>

class Cents
{
private:
	int m_cents {};

public:
	explicit Cents(int cents) : m_cents{ cents } { }

	// 使用友元函数实现 Cents + Cents
	friend Cents operator+(const Cents& c1, const Cents& c2);

	// 使用友元函数实现 Cents - Cents
	friend Cents operator-(const Cents& c1, const Cents& c2);

	int getCents() const { return m_cents; }
};

// 注意：这个函数不是成员函数！
Cents operator+(const Cents& c1, const Cents& c2)
{
	// 使用 Cents 构造函数和 operator+(int, int)
	// 我们可以直接访问 m_cents，因为这是一个友元函数
	return Cents { c1.m_cents + c2.m_cents };
}

// 注意：这个函数不是成员函数！
Cents operator-(const Cents& c1, const Cents& c2)
{
	// 使用 Cents 构造函数和 operator-(int, int)
	// 我们可以直接访问 m_cents，因为这是一个友元函数
	return Cents { c1.m_cents - c2.m_cents };
}

int main()
{
	Cents cents1{ 6 };
	Cents cents2{ 2 };
	Cents centsSum{ cents1 - cents2 };
	std::cout << "I have " << centsSum.getCents() << " cents.\n";

	return 0;
}

友元函数可以在类内部定义

尽管友元函数不是类的成员，但如果需要，它们仍然可以在类内部定义：

#include <iostream>

class Cents
{
private:
	int m_cents {};

public:
	explicit Cents(int cents) : m_cents{ cents } { }

	// 使用友元函数实现 Cents + Cents
        // 这个函数不被视为类的成员，即使定义在类内部
	friend Cents operator+(const Cents& c1, const Cents& c2)
	{
		// 使用 Cents 构造函数和 operator+(int, int)
		// 我们可以直接访问 m_cents，因为这是一个友元函数
		return Cents { c1.m_cents + c2.m_cents };
	}

	int getCents() const { return m_cents; }
};

int main()
{
	Cents cents1{ 6 };
	Cents cents2{ 8 };
	Cents centsSum{ cents1 + cents2 };
	std::cout << "I have " << centsSum.getCents() << " cents.\n";

	return 0;
}

对于实现简单的重载运算符，这样做是可以的。

为不同类型的操作数重载运算符

通常，您希望重载的运算符能够处理不同类型的操作数。例如，如果我们有 Cents(4)，我们可能想将整数 6 加到它上面，得到结果 Cents(10)。

当 C++ 计算表达式 x + y时，x 成为第一个参数，y 成为第二个参数。当 x 和 y 类型相同时，x + y 或 y + x 没有区别——无论哪种方式，都会调用相同版本的 operator+。然而，当操作数类型不同时，x + y 调用的函数与 y + x 不同。

例如， Cents(4) + 6 会调用 operator+(Cents, int)，而 6 + Cents(4) 会调用 operator+(int, Cents)。因此，每当我们为不同类型的操作数重载二元运算符时，实际上需要编写两个函数——每种情况一个。以下是一个示例：

#include <iostream>

class Cents
{
private:
	int m_cents {};

public:
	explicit Cents(int cents) : m_cents{ cents } { }

	// 使用友元函数实现 Cents + int
	friend Cents operator+(const Cents& c1, int value);

	// 使用友元函数实现 int + Cents
	friend Cents operator+(int value, const Cents& c1);


	int getCents() const { return m_cents; }
};

// 注意：这个函数不是成员函数！
Cents operator+(const Cents& c1, int value)
{
	// 使用 Cents 构造函数和 operator+(int, int)
	// 我们可以直接访问 m_cents，因为这是一个友元函数
	return Cents { c1.m_cents + value };
}

// 注意：这个函数不是成员函数！
Cents operator+(int value, const Cents& c1)
{
	// 使用 Cents 构造函数和 operator+(int, int)
	// 我们可以直接访问 m_cents，因为这是一个友元函数
	return Cents { c1.m_cents + value };
}

int main()
{
	Cents c1{ Cents{ 4 } + 6 };
	Cents c2{ 6 + Cents{ 4 } };

	std::cout << "I have " << c1.getCents() << " cents.\n";
	std::cout << "I have " << c2.getCents() << " cents.\n";

	return 0;
}

注意，两个重载函数具有相同的实现——这是因为它们做同样的事情，只是参数的顺序不同。

另一个示例

让我们看另一个例子：

#include <iostream>

class MinMax
{
private:
	int m_min {}; // 到目前为止看到的最小值
	int m_max {}; // 到目前为止看到的最大值

public:
	MinMax(int min, int max)
		: m_min { min }, m_max { max }
	{ }

	int getMin() const { return m_min; }
	int getMax() const { return m_max; }

	friend MinMax operator+(const MinMax& m1, const MinMax& m2);
	friend MinMax operator+(const MinMax& m, int value);
	friend MinMax operator+(int value, const MinMax& m);
};

MinMax operator+(const MinMax& m1, const MinMax& m2)
{
	// 获取 m1 和 m2 中看到的最小值
	int min{ m1.m_min < m2.m_min ? m1.m_min : m2.m_min };

	// 获取 m1 和 m2 中看到的最大值
	int max{ m1.m_max > m2.m_max ? m1.m_max : m2.m_max };

	return MinMax { min, max };
}

MinMax operator+(const MinMax& m, int value)
{
	// 获取 m 和 value 中看到的最小值
	int min{ m.m_min < value ? m.m_min : value };

	// 获取 m 和 value 中看到的最大值
	int max{ m.m_max > value ? m.m_max : value };

	return MinMax { min, max };
}

MinMax operator+(int value, const MinMax& m)
{
	// 调用 operator+(MinMax, int)
	return m + value;
}

int main()
{
	MinMax m1{ 10, 15 };
	MinMax m2{ 8, 11 };
	MinMax m3{ 3, 12 };

	MinMax mFinal{ m1 + m2 + 5 + 8 + m3 + 16 };

	std::cout << "Result: (" << mFinal.getMin() << ", " <<
		mFinal.getMax() << ")\n";

	return 0;
}

MinMax 类跟踪到目前为止它看到的最小值和最大值。我们重载了 + 运算符 3 次，以便可以将两个 MinMax 对象相加，或者将整数加到 MinMax 对象上。

此示例产生结果：

Result: (3, 16)

您会注意到，这是添加到 mFinal 中的最小值和最大值。

让我们更详细地讨论一下“MinMax mFinal { m1 + m2 + 5 + 8 + m3 + 16 }”是如何计算的。记住 operator+ 从左到右计算，所以 m1 + m2 首先计算。这变成对 operator+(m1, m2) 的调用，产生返回值 MinMax(8, 15)。然后 MinMax(8, 15) + 5 接下来计算。这变成对 operator+(MinMax(8, 15), 5) 的调用，产生返回值 MinMax(5, 15)。然后 MinMax(5, 15) + 8 以相同方式计算，产生 MinMax(5, 15)。然后 MinMax(5, 15) + m3 计算产生 MinMax(3, 15)。最后，MinMax(3, 15) + 16 计算为 MinMax(3, 16)。这个最终结果然后用于初始化 mFinal。

换句话说，这个表达式计算为“MinMax mFinal = (((((m1 + m2) + 5) + 8) + m3) + 16)”，每个连续操作返回一个 MinMax 对象，该对象成为下一个运算符的左操作数。

使用其他运算符实现运算符

在上面的示例中，注意我们通过调用 operator+(MinMax, int)（产生相同结果）来定义 operator+(int, MinMax)。这使我们能够将 operator+(int, MinMax) 的实现减少到一行，通过最小化冗余并使函数更易于理解，从而使我们的代码更易于维护。

通常可以通过调用其他重载运算符来定义重载运算符。如果这样做能产生更简单的代码，您就应该这样做。在实现很简单的情况下（例如一行），这样做可能值得也可能不值得。

class Fraction

		: m_numerator{numerator}, m_denominator{denominator}

e) 附加题：分数 2/4 与 1/2 相同，但 2/4 没有约分到最简形式。我们可以通过找到分子和分母的最大公约数（GCD），然后将分子和分母都除以 GCD 来将任何给定分数约分到最简形式。

std::gcd() 在 C++17 中被添加到标准库（在 <numeric> 头文件中）。

如果你使用的是较旧的编译器，可以使用这个函数来求 GCD：

#include <cmath> // for std::abs

int gcd(int a, int b) {
    return (b == 0) ? std::abs(a) : gcd(b, a % b);
}

#include <iostream>
#include <numeric> // for std::gcd

// 这个版本的 Fraction 类自动约分分数
class Fraction
{
private:
	int m_numerator{ 0 };
	int m_denominator{ 1 };

public:
	explicit Fraction(int numerator, int denominator = 1)
		: m_numerator{ numerator }, m_denominator{ denominator }
	{
		// 我们将 reduce() 放在构造函数中，以确保我们创建的任何分数都被约分！
		// 由于所有重载运算符都创建新的 Fraction，我们可以保证这里会被调用
		reduce();
	}

	void reduce()
	{
		int gcd{ std::gcd(m_numerator, m_denominator) };
		if (gcd) // 确保我们不会尝试除以 0
		{
			m_numerator /= gcd;
			m_denominator /= gcd;
		}
	}

	friend Fraction operator*(const Fraction& f1, const Fraction& f2);
	friend Fraction operator*(const Fraction& f1, int value);
	friend Fraction operator*(int value, const Fraction& f1);

	void print() const
	{
		std::cout << m_numerator << '/' << m_denominator << '\n';
	}
};

Fraction operator*(const Fraction& f1, const Fraction& f2)
{
	return Fraction { f1.m_numerator * f2.m_numerator, f1.m_denominator * f2.m_denominator };
}

Fraction operator*(const Fraction& f1, int value)
{
	return Fraction { f1.m_numerator * value, f1.m_denominator };
}

Fraction operator*(int value, const Fraction& f1)
{
	return Fraction { f1 * value };
}

int main()
{
	Fraction f1{ 2, 5 };
	f1.print();

	Fraction f2{ 3, 8 };
	f2.print();

	Fraction f3{ f1 * f2 };
	f3.print();

	Fraction f4{ f1 * 2 };
	f4.print();

	Fraction f5{ 2 * f2 };
	f5.print();

	Fraction f6{ Fraction{1, 2} * Fraction{2, 3} * Fraction{3, 4} };
	f6.print();

	Fraction f7{ 0, 6 };
	f7.print();

	return 0;
}
