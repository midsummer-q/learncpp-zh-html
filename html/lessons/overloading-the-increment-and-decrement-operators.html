21.8 — 重载自增和自减运算符

● 机器译文 课程 21.8 查看英文原文

重载自增（++）和递减（--）运算符相当直接，但有一个小例外。实际上自增和自减运算符有两个版本：前缀自增和自减（例如 ++x; --y;）和后缀自增和自减（例如 x++; y--;)。

由于自增和自减运算符都是单目运算符，并且它们修改操作数，因此最好将它们重载为成员函数。我们先处理前缀版本，因为它们最直接。

重载前缀自增和自减

前缀自增和自减的重载方式与任何普通单目运算符完全相同。我们通过示例来说明：

#include <iostream>

class Digit
{
private:
    int m_digit{};
public:
    Digit(int digit=0)
        : m_digit{digit}
    {
    }

    Digit& operator++();
    Digit& operator--();

    friend std::ostream& operator<< (std::ostream& out, const Digit& d);
};

Digit& Digit::operator++()
{
    // 如果我们的数字已经是 9，则回绕到 0
    if (m_digit == 9)
        m_digit = 0;
    // 否则只需递增到下一个数字
    else
        ++m_digit;

    return *this;
}

Digit& Digit::operator--()
{
    // 如果我们的数字已经是 0，则回绕到 9
    if (m_digit == 0)
        m_digit = 9;
    // 否则只需递减到下一个数字
    else
        --m_digit;

    return *this;
}

std::ostream& operator<< (std::ostream& out, const Digit& d)
{
	out << d.m_digit;
	return out;
}

int main()
{
    Digit digit { 8 };

    std::cout << digit;
    std::cout << ++digit;
    std::cout << ++digit;
    std::cout << --digit;
    std::cout << --digit;

    return 0;
}

我们的 Digit 类保存一个介于 0 和 9 之间的数字。我们重载了自增和自减，以便它们递增/递减数字，如果数字超出范围则进行回绕。

此示例输出：

89098

注意我们返回 *this。重载的自增和自减运算符返回当前隐式对象，以便多个运算符可以“链式”使用。

重载后缀自增和自减

通常，函数可以通过具有相同名称但不同数量和/或不同类型的参数来重载。然而，考虑前缀和后缀自增和自减运算符的情况。它们具有相同的名称（例如 operator++），都是单目运算符，并且接受一个相同类型的参数。那么，在重载时如何区分它们呢？

C++ 语言规范提供了一个特殊情况来回答这个问题：编译器查看重载的运算符是否有一个 int 参数。如果重载的运算符有一个 int 参数，则该运算符是后缀重载。如果重载的运算符没有参数，则该运算符是前缀重载。

以下是上述 Digit 类同时包含前缀和后缀重载的版本：

class Digit
{
private:
    int m_digit{};
public:
    Digit(int digit=0)
        : m_digit{digit}
    {
    }

    Digit& operator++(); // 前缀没有参数
    Digit& operator--(); // 前缀没有参数

    Digit operator++(int); // 后缀有一个 int 参数
    Digit operator--(int); // 后缀有一个 int 参数

    friend std::ostream& operator<< (std::ostream& out, const Digit& d);
};

// 无参数表示这是前缀 operator++
Digit& Digit::operator++()
{
    // 如果我们的数字已经是 9，则回绕到 0
    if (m_digit == 9)
        m_digit = 0;
    // 否则只需递增到下一个数字
    else
        ++m_digit;

    return *this;
}

// 无参数表示这是前缀 operator--
Digit& Digit::operator--()
{
    // 如果我们的数字已经是 0，则回绕到 9
    if (m_digit == 0)
        m_digit = 9;
    // 否则只需递减到下一个数字
    else
        --m_digit;

    return *this;
}

// int 参数表示这是后缀 operator++
Digit Digit::operator++(int)
{
    // 创建一个临时变量，保存当前数字
    Digit temp{*this};

    // 使用前缀运算符递增此数字
    ++(*this); // 应用运算符

    // 返回临时结果
    return temp; // 返回保存的状态
}

// int 参数表示这是后缀 operator--
Digit Digit::operator--(int)
{
    // 创建一个临时变量，保存当前数字
    Digit temp{*this};

    // 使用前缀运算符递减此数字
    --(*this); // 应用运算符

    // 返回临时结果
    return temp; // 返回保存的状态
}

std::ostream& operator<< (std::ostream& out, const Digit& d)
{
	out << d.m_digit;
	return out;
}

int main()
{
    Digit digit { 5 };

    std::cout << digit;
    std::cout << ++digit; // 调用 Digit::operator++();
    std::cout << digit++; // 调用 Digit::operator++(int);
    std::cout << digit;
    std::cout << --digit; // 调用 Digit::operator--();
    std::cout << digit--; // 调用 Digit::operator--(int);
    std::cout << digit;

    return 0;
}

这会打印

5667665

这里有一些有趣的事情。首先，注意我们通过在后缀版本中提供一个整数虚拟参数来区分前缀和后缀运算符。其次，由于虚拟参数在函数实现中未使用，我们甚至没有给它命名。这告诉编译器将此变量视为占位符，这样它就不会警告我们声明了变量但从未使用。

第三，注意前缀和后缀运算符执行相同的工作——它们都递增或递减对象。两者的区别在于它们返回的值。重载的前缀运算符在对象递增或递减后返回该对象。因此，重载这些运算符相当直接。我们只需递增或递减成员变量，然后返回 *this。

另一方面，后缀运算符需要返回对象在 在 递增或递减之前的状态。这导致了一个难题——如果我们递增或递减对象，我们将无法返回对象在递增或递减之前的状态。另一方面，如果我们在递增或递减对象之前返回其状态，则递增或递减将永远不会被调用。

解决这个问题的典型方法是使用一个临时变量来保存对象在递增或递减之前的值。然后对象本身可以被递增或递减。最后，临时变量被返回给调用者。这样，调用者接收到对象在递增或递减之前的副本，但对象本身被递增或递减。注意，这意味着重载运算符的返回值必须是非引用，因为我们不能返回一个在函数退出时将被销毁的局部变量的引用。还要注意，这意味着后缀运算符通常比前缀运算符效率低，因为实例化临时变量和按值返回而不是按引用返回带来了额外开销。

最后，注意我们编写后置自增和后置自减的方式是调用前置自增和前置自减来完成大部分工作。这减少了重复代码，并使我们的类将来更容易修改。
