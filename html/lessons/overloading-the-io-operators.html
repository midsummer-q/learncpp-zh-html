21.4 — 重载 I/O 运算符

● 机器译文 课程 21.4 查看英文原文

对于具有多个成员变量的类，逐个在屏幕上打印每个变量很快就会变得繁琐。例如，考虑以下类：

class Point
{
private:
    double m_x{};
    double m_y{};
    double m_z{};

public:
    Point(double x=0.0, double y=0.0, double z=0.0)
      : m_x{x}, m_y{y}, m_z{z}
    {
    }

    double getX() const { return m_x; }
    double getY() const { return m_y; }
    double getZ() const { return m_z; }
};

如果你想将这个类的实例打印到屏幕上，你必须这样做：

Point point { 5.0, 6.0, 7.0 };

std::cout << "Point(" << point.getX() << ", " <<
    point.getY() << ", " <<
    point.getZ() << ')';

当然，将其作为一个可重用的函数更有意义。在之前的例子中，你已经看到我们创建了 print() 像这样工作的函数：

class Point
{
private:
    double m_x{};
    double m_y{};
    double m_z{};

public:
    Point(double x=0.0, double y=0.0, double z=0.0)
      : m_x{x}, m_y{y}, m_z{z}
    {
    }

    double getX() const { return m_x; }
    double getY() const { return m_y; }
    double getZ() const { return m_z; }

    void print() const
    {
        std::cout << "Point(" << m_x << ", " << m_y << ", " << m_z << ')';
    }
};

虽然这好多了，但它仍然有一些缺点。因为 print() 返回 void，它不能在输出语句中间调用。相反，你必须这样做：

int main()
{
    const Point point { 5.0, 6.0, 7.0 };

    std::cout << "My point is: ";
    point.print();
    std::cout << " in Cartesian space.\n";
}

如果你能简单地输入：

Point point{5.0, 6.0, 7.0};
cout << "My point is: " << point << " in Cartesian space.\n";

并得到相同的结果，那会容易得多。这样就不需要将输出拆分成多个语句，也不需要记住你给打印函数起的名字。

幸运的是，通过重载 operator<<，你可以做到！

重载 operator<<

重载 operator<< 类似于重载 operator+（它们都是二元运算符），只是参数类型不同。

考虑表达式 std::cout << point。如果运算符是 <<，操作数是什么？左操作数是 std::cout 对象，右操作数是你的 Point 类对象。 std::cout 实际上是一个类型为 std::ostream的对象。因此，我们的重载函数将如下所示：

// std::ostream 是对象 std::cout 的类型
friend std::ostream& operator<< (std::ostream& out, const Point& point);

的实现 operator<< 对于我们的 Point 类相当简单——因为 C++ 已经知道如何使用 operator<<输出 double，并且我们的成员都是 double，我们可以简单地使用 operator<< 来输出我们的 Point的数据成员。以下是上述 Point 类及其重载的 operator<<。

#include <iostream>

class Point
{
private:
    double m_x{};
    double m_y{};
    double m_z{};

public:
    Point(double x=0.0, double y=0.0, double z=0.0)
      : m_x{x}, m_y{y}, m_z{z}
    {
    }

    friend std::ostream& operator<< (std::ostream& out, const Point& point);
};

std::ostream& operator<< (std::ostream& out, const Point& point)
{
    // 由于 operator<< 是 Point 类的友元，我们可以直接访问 Point 的成员。
    out << "Point(" << point.m_x << ", " << point.m_y << ", " << point.m_z << ')'; // 实际输出在此完成

    return out; // 返回 std::ostream 以便我们可以链式调用 operator<<
}

int main()
{
    const Point point1 { 2.0, 3.0, 4.0 };

    std::cout << point1 << '\n';

    return 0;
}

这相当简单——注意我们的输出行与我们之前编写的 print() 函数中的行有多么相似。最显著的区别是 std::cout 变成了参数 out （当函数被调用时，它将是 std::cout 的引用）。

这里最棘手的部分是返回类型。对于算术运算符，我们计算并通过值返回单个答案（因为我们创建并返回一个新结果）。但是，如果你尝试通过值返回 std::ostream ，你会得到一个编译器错误。这是因为 std::ostream 明确禁止被复制。

在这种情况下，我们返回左参数作为引用。这不仅防止了 std::ostream 的副本被创建，还允许我们“链式”输出命令，例如 std::cout << point << '\n'。

考虑一下如果我们的 operator<< 返回 void 会怎样。当编译器评估 std::cout << point << '\n'时，根据优先级/结合性规则，它将此表达式评估为 (std::cout << point) << '\n';。 std::cout << point 会调用我们返回 void 的重载 operator<< 函数，该函数返回 void。然后部分求值的表达式变为： void << '\n';，这毫无意义！

通过返回 out 参数作为返回类型， (std::cout << point) 返回 std::cout。然后我们的部分求值表达式变为： std::cout << '\n';，然后它自身被求值！

每当我们希望重载的二元运算符能够以这种方式链式调用时，应该返回左操作数（通过引用）。在这种情况下，返回左操作数的引用是安全的——因为左操作数是由调用函数传入的，当被调用函数返回时，它必须仍然存在。因此，我们不必担心引用一个会在运算符返回时超出作用域并被销毁的对象。

为了证明它有效，考虑以下示例，它使用了带有我们上面编写的重载 operator<< 的 Point 类：

#include <iostream>

class Point
{
private:
    double m_x{};
    double m_y{};
    double m_z{};

public:
    Point(double x=0.0, double y=0.0, double z=0.0)
      : m_x{x}, m_y{y}, m_z{z}
    {
    }

    friend std::ostream& operator<< (std::ostream& out, const Point& point);
};

std::ostream& operator<< (std::ostream& out, const Point& point)
{
    // 由于 operator<< 是 Point 类的友元，我们可以直接访问 Point 的成员。
    out << "Point(" << point.m_x << ", " << point.m_y << ", " << point.m_z << ')';

    return out;
}

int main()
{
    Point point1 { 2.0, 3.5, 4.0 };
    Point point2 { 6.0, 7.5, 8.0 };

    std::cout << point1 << ' ' << point2 << '\n';

    return 0;
}

这会产生以下结果：

Point(2, 3.5, 4) Point(6, 7.5, 8)

在上面的例子中， operator<< 是友元，因为它需要直接访问 Point的成员。但是，如果成员可以通过 getter 访问，那么 operator<< 可以作为非友元实现。

重载 operator>>

也可以重载输入运算符。这以类似于重载输出运算符的方式进行。你需要知道的关键是 std::cin 是类型为 std::istream。这是我们的 Point 类，添加了重载的 operator>> ：

#include <iostream>

class Point
{
private:
    double m_x{};
    double m_y{};
    double m_z{};

public:
    Point(double x=0.0, double y=0.0, double z=0.0)
      : m_x{x}, m_y{y}, m_z{z}
    {
    }

    friend std::ostream& operator<< (std::ostream& out, const Point& point);
    friend std::istream& operator>> (std::istream& out, Point& point);
};

std::ostream& operator<< (std::ostream& out, const Point& point)
{
    // 由于 operator<< 是 Point 类的友元，我们可以直接访问 Point 的成员。
    out << "Point(" << point.m_x << ", " << point.m_y << ", " << point.m_z << ')';

    return out;
}

// 注意 point 必须是非 const 的，这样我们才能修改对象
std::istream& operator>> (std::istream& in, Point& point)
{
    // 此版本存在部分提取问题（见下文）
    in >> point.m_x >> point.m_y >> point.m_z;

    return in;
}

int main()
{
    std::cout << "Enter a point: ";

    Point point{ 1.0, 2.0, 3.0 }; // 非零测试数据
    std::cin >> point;

    std::cout << "You entered: " << point << '\n';

    return 0;
}

假设用户输入 4.0 5.6 7.26 作为输入，程序产生以下结果：

You entered: Point(4, 5.6, 7.26)

现在让我们看看当用户输入 4.0b 5.6 7.26 作为输入时会发生什么（注意 b 在 4.0)：

You entered: Point(4, 0, 3)

之后）。我们的点现在是一个奇怪的混合体，包含一个来自用户输入的值（4.0），一个被零初始化的值（0.0），以及一个未被输入函数触及的值（3.0）。这……不太好！

防止部分提取

当我们提取单个值时，只有两种可能的结果：提取失败或成功。然而，当我们在一次输入操作中提取多个值时，情况会变得稍微复杂一些。

上述 operator>> 的实现可能导致部分提取。这正是我们在输入 4.0b 5.6 7.26时看到的情况。提取到 x_y 成功地从用户输入中提取了 4.0 ，将 b 5.6 7.26 留在输入流中。提取到 m_y 失败，无法提取 b，所以 m_y 被拷贝赋值为值 0.0 ，并且输入流被设置为失败模式。由于我们没有清除失败模式，提取到 m_z 立即中止，并且 m_z 在提取尝试之前的值保持不变（3.0)。

）。在任何情况下，这都不是一个理想的结果。在某些情况下，它甚至可能非常危险。想象一下，我们正在为一个 operator>> 编写一个 Fraction 对象。成功提取分子后，对分母的提取失败会将分母设置为 0.0，这可能导致后续除以零，使应用程序崩溃。

那么如何避免这种情况呢？一种方法是使我们的操作具有事务性。 事务性操作 必须要么完全成功，要么完全失败——不允许部分成功或失败。这有时被称为“全有或全无”。如果在事务过程中任何一点发生失败，则必须撤销操作之前所做的更改。

关键提示

事务在现实生活中经常发生。考虑我要从一个银行账户向另一个账户转账的情况。这需要两个步骤：首先必须从一个账户中扣除资金，然后必须将其存入另一个账户。在执行此操作时，有三种可能：

  • 扣除步骤失败（例如，资金不足）。事务失败，两个账户余额均不反映转账。
  • 存入步骤失败（例如，由于技术问题）。在这种情况下，必须撤销已成功的扣除。事务失败，两个账户余额均不反映转账。
  • 两个步骤都成功。事务成功，两个账户余额都反映转账。

最终结果只有两种可能：转账完全失败，账户余额不变；或者转账成功，两个账户余额都发生变化。

让我们将重载的 Point operator>> 重新实现为事务性操作：

// 注意 point 必须是非 const 的，这样我们才能修改对象
// 注意此实现是非友元的
std::istream& operator>> (std::istream& in, Point& point)
{
    double x{};
    double y{};
    double z{};
    
    if (in >> x >> y >> z)      // 如果所有提取都成功
        point = Point{x, y, z}; // 覆盖我们现有的 point
        
    return in;
}

在这个实现中，我们不是直接用用户的输入覆盖数据成员。相反，我们将用户的输入提取到临时变量（x， y、和 z）。一旦所有提取尝试完成，我们检查所有提取是否成功。如果成功，则一起更新 Point 的所有成员。否则，我们不更新任何成员。

提示

if (in >> x >> y >> z) 等价于 in >> x >> y >> z; if (in)。记住，每次提取返回 in ，以便多个提取可以链式调用。单语句版本使用最后一次提取返回的 in 作为if语句的条件，而多语句版本显式使用 in

提示

事务性操作可以通过多种不同的策略实现。例如：

  • 成功时更改：存储每个子操作的结果。如果所有子操作成功，则用存储的结果替换相关数据。这是我们在上面的 Point 示例中使用的策略。
  • 失败时恢复：复制任何可能被更改的数据。如果任何子操作失败，可以使用副本中的数据撤销先前子操作所做的更改。
  • 失败时回滚：如果任何子操作失败，则反转每个先前的子操作（使用相反的子操作）。这种策略常用于数据库，其中数据太大无法备份，且子操作的结果无法存储。

虽然上述 operator>> 防止了部分提取，但它与 operator>> 对基本类型的工作方式不一致。当对基本类型对象的提取失败时，该对象并非保持不变——它会被拷贝赋值为值 0 （这确保对象具有某个一致的值，以防在提取尝试之前未初始化）。因此，为了保持一致性，您可能希望失败的提取将对象重置为其默认状态（至少在存在此类状态的情况下）。

这是 operator>> 的另一个版本，如果任何提取失败，它将 Point 重置为其默认状态：

// 注意 point 必须是非 const 的，这样我们才能修改对象
// 注意此实现是非友元的
std::istream& operator>> (std::istream& in, Point& point)
{
    double x{};
    double y{};
    double z{};
    
    in >> x >> y >> z;
    point = in ? Point{x, y, z} : Point{};
        
    return in;
}

作者注

这样的操作在技术上不再是事务性的（因为失败并非“什么都不做”）。似乎没有一个通用术语来描述保证没有部分结果的操作。也许是“不可分割的操作”。

处理语义上无效的输入

提取可能以不同方式失败。

将值转换为整数。 operator>> 只是无法将任何内容提取到变量中， std::cin 将自动进入失败模式（我们在课程 9.5 -- std::cin与处理无效输入中讨论）。此函数的调用者可以检查 std::cin 以查看是否失败，并适当处理该情况。

但是，如果用户输入的值是可提取但语义上无效的（例如，一个 Fraction 的分母为 0)? 因为 std::cin 确实提取了某些内容，它不会自动进入失败模式。然后调用者可能不会意识到出了问题。

为了解决这个问题，我们可以让重载的 operator>> 判断提取的任何值在语义上是否无效，如果是，则手动将输入流置于失败模式。这可以通过调用 std::cin.setstate(std::ios_base::failbit);。

下面是一个事务性重载的 operator>> 对于 Point 示例，如果用户输入一个可提取的负值，它将导致输入流进入失败模式：

std::istream& operator>> (std::istream& in, Point& point)
{
    double x{};
    double y{};
    double z{};
    
    in >> x >> y >> z;
    if (x < 0.0 || y < 0.0 || z < 0.0)       // 如果任何可提取的输入是负数
        in.setstate(std::ios_base::failbit); // 手动设置失败模式
    point = in ? Point{x, y, z} : Point{};
       
    return in;
}

总结

重载 operator<< 和 operator>> 使你的类易于输出到屏幕并从控制台接受用户输入。

问题 #1

取下面的 Fraction 类，并为其添加一个重载的 operator<< 和 operator>> 你的 operator>> 应避免部分提取，并在用户输入分母为 0时失败。它不应在失败时将 Fraction 重置为默认值。

以下程序应该能够编译：

int main()
{
	Fraction f1{};
	std::cout << "Enter fraction 1: ";
	std::cin >> f1;

	Fraction f2{};
	std::cout << "Enter fraction 2: ";
	std::cin >> f2;

	std::cout << f1 << " * " << f2 << " is " << f1 * f2 << '\n'; // 注意：f1 * f2 的结果是一个右值

	return 0;
}

并产生结果：

Enter fraction 1: 2/3
Enter fraction 2: 3/8
2/3 * 3/8 is 1/4

这是 Fraction 类：

#include <iostream>
#include <numeric> // for std::gcd
 
class Fraction
{
private:
	int m_numerator{};
	int m_denominator{};
 
public:
	Fraction(int numerator=0, int denominator=1):
		m_numerator{numerator}, m_denominator{denominator}
	{
		// 我们将 reduce() 放在构造函数中，以确保我们创建的任何新分数都被约分！
		// 任何被覆盖的分数都需要重新约分
		reduce();
	}

	void reduce()
	{
		int gcd{ std::gcd(m_numerator, m_denominator) };
		if (gcd)
		{
			m_numerator /= gcd;
			m_denominator /= gcd;
		}
	}
 
	friend Fraction operator*(const Fraction& f1, const Fraction& f2);
	friend Fraction operator*(const Fraction& f1, int value);
	friend Fraction operator*(int value, const Fraction& f1);
 
	void print() const
	{
		std::cout << m_numerator << '/' << m_denominator << '\n';
	}
};
 
Fraction operator*(const Fraction& f1, const Fraction& f2)
{
	return Fraction { f1.m_numerator * f2.m_numerator, f1.m_denominator * f2.m_denominator };
}
 
Fraction operator*(const Fraction& f1, int value)
{
	return Fraction { f1.m_numerator * value, f1.m_denominator };
}
 
Fraction operator*(int value, const Fraction& f1)
{
	return Fraction { f1.m_numerator * value, f1.m_denominator };
}

#include <cmath>
 
int gcd(int a, int b) {
    return (b == 0) ? std::abs(a) : gcd(b, a % b);

#include <iostream>
#include <limits>
#include <numeric> // for std::gcd

class Fraction
{
private:
    int m_numerator{ 0 };
    int m_denominator{ 1 };

public:
    Fraction(int numerator=0, int denominator = 1) :
        m_numerator{ numerator }, m_denominator{ denominator }
    {
        // 我们将 reduce() 放在构造函数中，以确保我们创建的任何新分数都被约分！
        // 任何被覆盖的分数都需要重新约分
        reduce();
    }

    void reduce()
    {
        int gcd{ std::gcd(m_numerator, m_denominator) };
        if (gcd)
        {
            m_numerator /= gcd;
            m_denominator /= gcd;
        }
    }

    friend Fraction operator*(const Fraction& f1, const Fraction& f2);
    friend Fraction operator*(const Fraction& f1, int value);
    friend Fraction operator*(int value, const Fraction& f1);

    friend std::ostream& operator<<(std::ostream& out, const Fraction& f1);

    void print() const
    {
        std::cout << m_numerator << '/' << m_denominator << '\n';
    }
};

Fraction operator*(const Fraction& f1, const Fraction& f2)
{
    return Fraction { f1.m_numerator * f2.m_numerator, f1.m_denominator * f2.m_denominator };
}

Fraction operator*(const Fraction& f1, int value)
{
    return Fraction { f1.m_numerator * value, f1.m_denominator };
}

Fraction operator*(int value, const Fraction& f1)
{
    return Fraction { f1.m_numerator * value, f1.m_denominator };
}

std::ostream& operator<<(std::ostream& out, const Fraction& f1)
{
    out << f1.m_numerator << '/' << f1.m_denominator;
    return out;
}

std::istream& operator>>(std::istream& in, Fraction& f1)
{
    int numerator {};
    char ignore {};
    int denominator {};
    
    in >> numerator >> ignore >> denominator;
    if (denominator == 0)                       // 如果我们的分母在语义上无效
        in.setstate(std::ios_base::failbit);    // 手动设置失败模式
    if (in)                                     // 如果我们不在失败模式
        f1 = Fraction {numerator, denominator}; // 将我们的对象更新为提取的值

    return in;
}

{
    Fraction f1{};
    std::cout << "Enter fraction 1: ";
    std::cin >> f1;

    Fraction f2{};
    std::cout << "Enter fraction 2: ";
    std::cin >> f2;

    std::cout << f1 << " * " << f2 << " is " << f1 * f2 << '\n'; // 注意：f1 * f2 的结果是一个右值

    return 0;
}
