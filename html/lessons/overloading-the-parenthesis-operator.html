21.10 — 重载括号运算符

● 机器译文 课程 21.10 查看英文原文

到目前为止，你看到的所有重载运算符都允许你定义运算符参数的类型，但不能定义参数的数量（参数数量基于运算符类型固定）。例如，operator== 总是接受两个参数，而 operator! 总是接受一个。括号运算符 (operator()) 是一个特别有趣的运算符，因为它允许你同时改变它接受的参数类型和数量。

有两件事要记住：首先，括号运算符必须作为成员函数实现。其次，在非面向对象的 C++ 中，() 运算符用于调用函数。对于类来说，operator() 只是一个普通的运算符，它像其他重载运算符一样调用一个名为 operator() 的函数。

一个例子

让我们看一个适合重载此运算符的例子：

class Matrix
{
private:
    double data[4][4]{};
};

矩阵是线性代数的关键组成部分，常用于几何建模和 3D 计算机图形学工作。在这种情况下，你只需要认识到 Matrix 类是一个 4x4 的 double 二维数组。

在关于 重载下标运算符的课程中，你学到了我们可以重载 operator[] 来直接访问私有的一维数组。然而，在这种情况下，我们想要访问私有的二维数组。在 C++23 之前，operator[] 仅限于单个参数，因此不足以让我们直接索引二维数组。

然而，由于 () 运算符可以接受任意数量的参数，我们可以声明一个接受两个整数索引参数的 operator() 版本，并用它来访问我们的二维数组。下面是一个例子：

#include <cassert> // for assert()

class Matrix
{
private:
    double m_data[4][4]{};

public:
    double& operator()(int row, int col);
    double operator()(int row, int col) const; // 对于 const 对象
};

double& Matrix::operator()(int row, int col)
{
    assert(row >= 0 && row < 4);
    assert(col >= 0 && col < 4);

    return m_data[row][col];
}

double Matrix::operator()(int row, int col) const
{
    assert(row >= 0 && row < 4);
    assert(col >= 0 && col < 4);

    return m_data[row][col];
}

现在我们可以声明一个 Matrix 并像这样访问它的元素：

#include <iostream>

int main()
{
    Matrix matrix;
    matrix(1, 2) = 4.5;
    std::cout << matrix(1, 2) << '\n';

    return 0;
}

产生结果：

4.5

现在，让我们再次重载 () 运算符，这次以不接受任何参数的方式：

#include <cassert> // for assert()
class Matrix
{
private:
    double m_data[4][4]{};

public:
    double& operator()(int row, int col);
    double operator()(int row, int col) const;
    void operator()();
};

double& Matrix::operator()(int row, int col)
{
    assert(row >= 0 && row < 4);
    assert(col >= 0 && col < 4);

    return m_data[row][col];
}

double Matrix::operator()(int row, int col) const
{
    assert(row >= 0 && row < 4);
    assert(col >= 0 && col < 4);

    return m_data[row][col];
}

void Matrix::operator()()
{
    // 将矩阵的所有元素重置为 0.0
    for (int row{ 0 }; row < 4; ++row)
    {
        for (int col{ 0 }; col < 4; ++col)
        {
            m_data[row][col] = 0.0;
        }
    }
}

这是我们的新例子：

#include <iostream>

int main()
{
    Matrix matrix{};
    matrix(1, 2) = 4.5;
    matrix(); // 擦除矩阵
    std::cout << matrix(1, 2) << '\n';

    return 0;
}

产生结果：

0

由于 () 运算符非常灵活，很容易被用于许多不同的目的。然而，强烈不鼓励这样做，因为 () 符号并不能真正指示运算符在做什么。在上面的例子中，最好将擦除功能写成一个名为 clear() 或 erase() 的函数，因为 matrix.erase() 比 matrix() （可能做任何事情！）更容易理解。

注意：从 C++23 开始，你可以使用 operator[] 配合多个索引。这就像上面的 operator() 一样工作。

使用仿函数（Functor）的乐趣

Operator() 也常被重载以实现 仿函数 （或 函数对象），即像函数一样运作的类。仿函数相对于普通函数的优势在于，仿函数可以在成员变量中存储数据（因为它们是类）。

这是一个简单的仿函数：

#include <iostream>

class Accumulator
{
private:
    int m_counter{ 0 };

public:
    int operator() (int i) { return (m_counter += i); }

    void reset() { m_counter = 0; } // 可选 
};

int main()
{
    Accumulator acc{};
    std::cout << acc(1) << '\n'; // 打印 1
    std::cout << acc(3) << '\n'; // 打印 4

    Accumulator acc2{};
    std::cout << acc2(10) << '\n'; // 打印 10
    std::cout << acc2(20) << '\n'; // 打印 30
    
    return 0;
}

注意，使用我们的 Accumulator 看起来就像进行普通的函数调用，但我们的 Accumulator 对象存储了一个累积值。

仿函数的好处在于，我们可以实例化任意多个独立的仿函数对象，并同时使用它们。仿函数还可以有其他成员函数（例如 reset()）来做方便的事情。

总结

Operator() 有时会用两个参数重载来索引多维数组，或者检索一维数组的子集（两个参数定义要返回的子集）。其他任何用途最好写成具有更具描述性名称的成员函数。

Operator() 也常被重载来创建仿函数。虽然简单的仿函数（如上例）相当容易理解，但仿函数通常用于更高级的编程主题，值得单独一课。

问题 #1

编写一个名为 MyString 的类，它持有一个 std::string。重载 operator<< 以输出字符串。重载 operator() 以返回从第一个参数的索引开始的子串（作为 MyString）。子串的长度由第二个参数定义。

以下代码应该能运行：

int main()
{
    MyString s { "Hello, world!" };
    std::cout << s(7, 5) << '\n'; // 从索引 7 开始并返回 5 个字符

    return 0;
}

这将打印

world

提示：你可以使用 std::string::substr 来获取 std::string 的子串。

显示答案

#include <cassert>
#include <iostream>
#include <string>
#include <string_view>

class MyString
{
private:
	std::string m_string{};

public:
	MyString(std::string_view string = {})
		:m_string{ string }
	{
	}

	MyString operator()(int start, int length)
	{
		assert(start >= 0);
		assert(start + length <= static_cast<int>(m_string.length()) && "MyString::operator(int, int): Substring is out of range");

		return MyString { m_string.substr(
			static_cast<std::string::size_type>(start),
			static_cast<std::string::size_type>(length)
			)};
	}

	friend std::ostream& operator<<(std::ostream& out, const MyString& s)
	{
		out << s.m_string;

		return out;
	}
};

int main()
{
	MyString s{ "Hello, world!" };
	std::cout << s(7, 5) << '\n'; // 从索引 7 开始并返回 5 个字符

	return 0;
}

显示答案

在我们的 operator()， std::string::substr 按值返回一个 std::string内部，这意味着当我们调用它时，我们正在复制源字符串的一部分。我们的重载 operator() 使用这个来构造一个新的 MyString，它包含一个 std::string 成员，这又进行了一次复制。然后我们将这个 MyString 返回给调用者，这进行了第三次复制。编译器可能会优化掉其中一些复制，但至少有一个 std::string （包含结果子串）必须保留。

我们只需要在打算修改子串，或者子串的生命周期超过原始字符串的情况下才需要子串的副本。通常情况并非如此，因此我们进行了通常不需要的昂贵复制。

#include <cassert>
#include <iostream>
#include <string>
#include <string_view>

class MyString
{
private:
	std::string m_string{};

public:
	MyString(std::string_view string = {})
		:m_string{ string }
	{
	}

	std::string_view operator()(int start, int length)
	{
		assert(start >= 0);
		assert(start + length <= static_cast<int>(m_string.length()) && "MyString::operator(int, int): Substring is out of range");

		// 创建 m_string 的 std::string_view，以便使用 std::string_view::substr() 而非 std::string::substr()
		return std::string_view{ m_string }.substr(
			static_cast<std::string_view::size_type>(start),
			static_cast<std::string_view::size_type>(length)
		);
	}

	friend std::ostream& operator<<(std::ostream& out, const MyString& s)
	{
		out << s.m_string;

		return out;
	}
};

int main()
{
	MyString s{ "Hello, world!" };
	std::cout << s(7, 5) << '\n'; // 从索引 7 开始并返回 5 个字符

	return 0;
}
