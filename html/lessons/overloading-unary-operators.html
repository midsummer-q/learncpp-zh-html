21.6 — 重载一元运算符 +、- 和 !

● 机器译文 课程 21.6 查看英文原文

重载一元运算符

与之前看到的运算符不同，正号 (+)、负号 (-) 和逻辑非 (!) 运算符都是一元运算符，这意味着它们只操作一个操作数。由于它们只作用于所应用的对象，通常一元运算符重载被实现为成员函数。这三个运算符的实现方式完全相同。

让我们看看如何在前一个示例中使用的 Cents 类上实现 operator-：

#include <iostream>

class Cents
{
private:
    int m_cents {};
 
public:
    Cents(int cents): m_cents{cents} {}
 
    // 重载 -Cents 作为成员函数
    Cents operator-() const;

    int getCents() const { return m_cents; }
};
 
// 注意：此函数是成员函数！
Cents Cents::operator-() const
{
    return -m_cents; // 由于返回类型是 Cents，这使用 Cents(int) 构造函数从 int 隐式转换为 Cents
}

int main()
{
    const Cents nickle{ 5 };
    std::cout << "A nickle of debt is worth " << (-nickle).getCents() << " cents\n";

    return 0;
}

这应该很直接。我们重载的负号运算符 (-) 是一个一元运算符，作为成员函数实现，因此它不接受参数（它操作 *this 对象）。它返回一个 Cents 对象，该对象是原始 Cents 值的相反数。由于 operator- 不修改 Cents 对象，我们可以（并且应该）将其设为 const 函数（以便可以在 const Cents 对象上调用）。

注意，负号 operator- 和减号 operator- 之间没有混淆，因为它们具有不同的参数数量。

另一个例子。! 运算符是逻辑非运算符——如果表达式求值为“true”，operator! 将返回 false，反之亦然。我们通常将其应用于布尔变量以测试它们是否为真：

if (!isHappy)
    std::cout << "I am not happy!\n";
else
    std::cout << "I am so happy!\n";

对于整数，0 求值为 false，其他任何值求值为 true，因此应用于整数的 operator! 对于整数值 0 将返回 true，否则返回 false。

扩展这个概念，我们可以说，如果对象的状态是“false”、“零”或任何默认初始化状态，operator! 应该求值为 true。

以下示例展示了用户定义的 Point 类的 operator- 和 operator! 的重载：

#include <iostream>

class Point
{
private:
    double m_x {};
    double m_y {};
    double m_z {};
 
public:
    Point(double x=0.0, double y=0.0, double z=0.0):
        m_x{x}, m_y{y}, m_z{z}
    {
    }
 
    // 将 Point 转换为其负等价
    Point operator- () const;

    // 如果点位于原点则返回 true
    bool operator! () const;
 
    double getX() const { return m_x; }
    double getY() const { return m_y; }
    double getZ() const { return m_z; }
};

// 将 Point 转换为其负等价 
Point Point::operator- () const
{
    return { -m_x, -m_y, -m_z };
}

// 如果点位于原点则返回 true，否则返回 false
bool Point::operator! () const
{
    return (m_x == 0.0 && m_y == 0.0 && m_z == 0.0);
}

int main()
{
    Point point{}; // 使用默认构造函数设置为 (0.0, 0.0, 0.0)

    if (!point)
        std::cout << "point is set at the origin.\n";
    else
        std::cout << "point is not set at the origin.\n";

    return 0;
}

这个类的重载 operator! 如果 Point 被设置为默认值 (0.0, 0.0, 0.0)，则返回布尔值“true”。因此，上述代码产生结果：

point is set at the origin.

小测验时间

  1. 为 Point 类实现重载的一元 operator+ 一元 operator+ 只返回其操作数（它不会将负值变为正值）。

显示答案

这是显而易见的解决方案：

Point Point::operator+ () const
{
    return { m_x, m_y, m_z };
}

但由于我们返回的 Point 与操作的对象完全相同，以下方法也有效：

Point Point::operator+ () const
{
    return *this;
}

注意，我们在这里按值返回副本而不是 const 引用。这是因为此函数的用户可能期望返回的对象是可修改的。
