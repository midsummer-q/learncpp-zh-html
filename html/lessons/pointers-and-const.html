12.9 — 指针与 const

● 机器译文 课程 12.9 查看英文原文

考虑以下代码片段：

int main()
{
    int x { 5 };
    int* ptr { &x }; // ptr 是一个普通（非常量）指针

    int y { 6 };
    ptr = &y; // 我们可以指向另一个值

    *ptr = 7; // 我们可以更改所持有地址处的值

    return 0;
}

对于普通（非 const）指针，我们既可以改变指针所指的对象（通过给指针赋一个新地址），也可以改变所存地址处的值（通过解引用指针赋新值）。

然而，如果我们要指向的值是 const 的，会发生什么？

int main()
{
    const int x { 5 }; // x 现在是 const
    int* ptr { &x };   // 编译错误：无法从 const int* 转换为 int*

    return 0;
}

上面的代码片段无法编译——我们不能将普通指针指向 const 变量。这很合理：const 变量的值不能被改变。允许程序员将非 const 指针指向 const 值，会使程序员能够解引用指针并改变该值，这将违反变量的 const 性质。

指向 const 值的指针

一个 指向 const 值的指针 （有时称为 pointer to const （简称）是一个指向常量的（非 const）指针。

要声明指向 const 值的指针，请在指针的数据类型前使用 const 关键字：

int main()
{
    const int x{ 5 };
    const int* ptr { &x }; // 可以：ptr 指向一个 "const int"

    *ptr = 6; // 不允许：我们不能更改 const 值

    return 0;
}

在上面的例子中， ptr 指向一个 const int。由于指向的数据类型是 const 的，因此所指向的值不能被改变。

然而，因为指向 const 的指针本身不是 const（它只是指向一个 const 值），我们可以通过给指针赋一个新地址来改变指针所指的对象：

int main()
{
    const int x{ 5 };
    const int* ptr { &x }; // ptr 指向 const int x

    const int y{ 6 };
    ptr = &y; // 可以：ptr 现在指向 const int y

    return 0;
}

就像 const 引用一样，指向 const 的指针也可以指向非 const 变量。指向 const 的指针将所指向的值视为常量，无论该地址处的对象最初是否定义为 const：

int main()
{
    int x{ 5 }; // 非常量
    const int* ptr { &x }; // ptr 指向一个 "const int"

    *ptr = 6;  // 不允许：ptr 指向一个 "const int"，所以我们不能通过 ptr 更改值
    x = 6; // 允许：通过非常量标识符 x 访问时，值仍然是非常量

    return 0;
}

const 指针

我们也可以使指针本身成为常量。 const 指针 是一个初始化后地址不能被改变的指针。

要声明 const 指针，请在指针声明中的星号后使用 const 关键字：

int main()
{
    int x{ 5 };
    int* const ptr { &x }; // 星号后的 const 表示这是一个常量指针

    return 0;
}

在上述情况下， ptr 是一个指向（非 const）int 值的 const 指针。

就像普通的 const 变量一样，const 指针必须在定义时初始化，并且该值不能通过赋值改变：

int main()
{
    int x{ 5 };
    int y{ 6 };

    int* const ptr { &x }; // 可以：常量指针被初始化为 x 的地址
    ptr = &y; // 错误：一旦初始化，常量指针不能被更改。

    return 0;
}

然而，因为 值 所指向的值是非 const 的，所以可以通过解引用 const 指针来改变所指向的值：

int main()
{
    int x{ 5 };
    int* const ptr { &x }; // ptr 将始终指向 x

    *ptr = 6; // 可以：所指向的值是非常量

    return 0;
}

指向 const 值的 const 指针

最后，可以声明一个 指向 const 值的 const 指针 ，通过在类型前和星号后都使用 const 关键字：

int main()
{
    int value { 5 };
    const int* const ptr { &value }; // 一个指向常量的常量指针

    return 0;
}

指向 const 值的 const 指针既不能改变其地址，也不能通过指针改变所指向的值。它只能被解引用以获取所指向的值。

指针与 const 总结

总结一下，你只需要记住 4 条规则，而且它们非常合乎逻辑：

  • 非 const 指针（例如 int* ptr）可以被赋予另一个地址来改变它所指的对象。
  • const 指针（例如 int* const ptr）始终指向同一个地址，且该地址不能被改变。

  • 指向非 const 值的指针（例如 int* ptr）可以改变它所指向的值。这些指针不能指向 const 值。
  • 指向 const 值的指针（例如 const int* ptr）在通过指针访问时将值视为 const，因此不能改变它所指向的值。这些指针可以指向 const 或非 const 的左值（但不能指向右值，因为右值没有地址）。

保持声明语法清晰可能有点挑战性：

  • 一个 const 在星号之前（例如 const int* ptr）与所指向的类型相关联。因此，这是一个指向常量的指针，不能通过该指针修改值。
  • 一个 const 在星号之后（例如 int* const ptr）与指针本身相关联。因此，这个指针不能被赋予新地址。
int main()
{
    int v{ 5 };
   
    int* ptr0 { &v };             // 指向一个 "int"，但本身不是常量。我们可以修改值或地址。
    const int* ptr1 { &v };       // 指向一个 "const int"，但本身不是常量。我们只能修改地址。
    int* const ptr2 { &v };       // 指向一个 "int"，并且本身是常量。我们只能修改值。
    const int* const ptr3 { &v }; // 指向一个 "const int"，并且本身是常量。我们不能修改值或地址。

    // 如果 const 在 * 的左侧，则 const 属于值
    // 如果 const 在 * 的右侧，则 const 属于指针

    return 0;
}
