19.4 — 指向指针的指针与动态多维数组

● 机器译文 课程 19.4 查看英文原文

本课为选修内容，面向希望深入学习C++的高级读者。后续课程不依赖本课内容。

指向指针的指针正如你所料：一个存储另一个指针地址的指针。

指向指针的指针

一个普通的指向int的指针使用单个星号声明：

int* ptr; // 指向 int 的指针，一个星号

一个指向int的指针的指针使用两个星号声明

int** ptrptr; // 指向 int 指针的指针，两个星号

指向指针的指针的工作方式与普通指针相同——你可以解引用它以获取所指向的值。由于该值本身也是一个指针，你可以再次解引用它来获取底层值。这些解引用操作可以连续进行：

int value { 5 };

int* ptr { &value };
std::cout << *ptr << '\n'; // 解引用指向 int 的指针以获取 int 值

int** ptrptr { &ptr };
std::cout << **ptrptr << '\n'; // 解引用得到指向 int 的指针，再次解引用得到 int 值

上面的程序打印：

5
5

注意，你不能直接将指向指针的指针设置为一个值：

int value { 5 };
int** ptrptr { &&value }; // 无效

这是因为取地址运算符（operator&）需要一个左值，而&value是一个右值。

然而，指向指针的指针可以设置为空：

int** ptrptr { nullptr };

指针数组

指向指针的指针有几个用途。最常见的用途是动态分配一个指针数组：

int** array { new int*[10] }; // 分配一个包含 10 个 int 指针的数组

这就像一个标准的动态分配数组，只是数组元素的类型是“指向整数的指针”而不是整数。

二维动态分配数组

指向指针的指针的另一个常见用途是便于动态分配多维数组（参见 17.12 -- 多维 C 风格数组 以复习多维数组）。

与可以轻松声明为这样的二维固定数组不同：

int array[10][5];

动态分配二维数组稍微更具挑战性。你可能会尝试这样做：

int** array { new int[10][5] }; // 行不通！

但这样行不通。

这里有两种可能的解决方案。如果最右侧的数组维度是constexpr，你可以这样做：

int x { 7 }; // 非常量
int (*array)[5] { new int[x][5] }; // 最右边的维度必须是 constexpr

括号是必需的，以便编译器知道我们希望 array 是一个指向包含5个int的数组的指针 int （在这种情况下，这是一个7行多维数组的第一行）。没有括号，编译器会将其解释为 int* array[5]，这是一个包含5个int指针的数组 int*。

这是使用自动类型推导的好地方：

int x { 7 }; // 非常量
auto array { new int[x][5] }; // 简单多了！

不幸的是，如果最右侧的数组维度不是编译时常量，这个相对简单的解决方案就不起作用了。在这种情况下，我们必须稍微复杂一些。首先，我们分配一个指针数组（如上所述）。然后，我们遍历指针数组，并为每个数组元素分配一个动态数组。我们的动态二维数组是一个由动态一维数组组成的动态一维数组！

int** array { new int*[10] }; // 分配一个包含 10 个 int 指针的数组——这些是我们的行
for (int count { 0 }; count < 10; ++count)
    array[count] = new int[5]; // 这些是我们的列

然后我们可以像往常一样访问我们的数组：

array[9][4] = 3; // 这与 (array[9])[4] = 3; 相同

使用这种方法，由于每个数组列是独立动态分配的，因此可以创建非矩形的动态分配二维数组。例如，我们可以创建一个三角形数组：

int** array { new int*[10] }; // 分配一个包含 10 个 int 指针的数组——这些是我们的行
for (int count { 0 }; count < 10; ++count)
    array[count] = new int[count+1]; // 这些是我们的列

在上面的例子中，注意array[0]是一个长度为1的数组，array[1]是一个长度为2的数组，等等……

使用这种方法释放动态分配的二维数组也需要一个循环：

for (int count { 0 }; count < 10; ++count)
    delete[] array[count];
delete[] array; // 这需要最后做

注意，我们以与创建数组相反的顺序删除数组（先删除元素，再删除数组本身）。如果我们在数组列之前删除array，那么我们将不得不访问已释放的内存来删除数组列。这将导致未定义行为。

由于分配和释放二维数组很复杂且容易出错，通常更容易将二维数组（大小为x乘y）“扁平化”为大小为x * y的一维数组：

// 不要这样：
int** array { new int*[10] }; // 分配一个包含 10 个 int 指针的数组——这些是我们的行
for (int count { 0 }; count < 10; ++count)
    array[count] = new int[5]; // 这些是我们的列

// 这样做
int *array { new int[50] }; // 一个 10x5 的数组展平为单个数组

然后可以使用简单的数学运算将矩形二维数组的行和列索引转换为一位数组的单个索引：

int getSingleIndex(int row, int col, int numberOfColumnsInArray)
{
     return (row * numberOfColumnsInArray) + col;
}

// 使用展平数组将 array[9,4] 设置为 3
array[getSingleIndex(9, 4, 5)] = 3;

通过地址传递指针

就像我们可以使用指针参数来更改传入的底层参数的实际值一样，我们可以将指向指针的指针传递给函数，并使用该指针来更改它所指向的指针的值（现在糊涂了吗？）。

然而，如果我们希望函数能够修改指针参数所指向的内容，通常更好的方法是使用对指针的引用。这在课程 12.11 -- 按地址传递（第 2 部分）。

指向指针的指针的指针……

也可以声明指向指针的指针的指针：

int*** ptrx3;

这可用于动态分配三维数组。然而，这样做需要一个循环嵌套在另一个循环中，并且正确实现极其复杂。

你甚至可以声明指向指针的指针的指针的指针：

int**** ptrx4;

或者更高，如果你愿意的话。

然而，实际上它们并不常用，因为你很少需要这么多层间接引用。

总结

我们建议避免使用指向指针的指针，除非没有其他选择，因为它们使用起来复杂且有潜在危险。普通指针解引用空指针或悬空指针已经很容易出错——指向指针的指针则更容易，因为你需要双重解引用才能到达底层值！
