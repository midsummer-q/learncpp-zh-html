7.12 — 作用域、生存期和链接性总结

● 机器译文 课程 7.12 查看英文原文

作用域、生存期和链接性的概念经常引起混淆，因此我们额外用一节课来总结所有内容。其中一些内容我们尚未涉及，放在这里只是为了完整性和日后参考。

作用域总结

标识符的 作用域 决定了标识符在源代码中可以被访问的位置。

  • 具有 块（局部）作用域 的变量只能从声明点开始访问，直到它们所在块的结束（包括嵌套块）。这包括：
    • 局部变量
    • 函数参数
    • 在块内声明的程序定义类型（如枚举和类）
  • 具有 全局作用域 的变量和函数可以从声明点开始访问，直到文件结束。这包括：
    • 全局变量
    • 函数
    • 在命名空间或全局作用域内声明的程序定义类型（如枚举和类）

生存期总结

变量的 生存期 决定了变量何时创建和销毁。

  • 具有 自动生存期 的变量在定义点创建，在退出它们所属的块时销毁。这包括：
    • 局部变量
    • 函数参数
  • 具有 静态存储期 的变量在程序开始时创建，在程序结束时销毁。这包括：
    • 全局变量
    • 静态局部变量
  • 具有 动态生存期 的变量由程序员请求创建和销毁。这包括：
    • 动态分配的变量

链接性总结

标识符的 链接性 决定了同一标识符在不同作用域中的声明是否引用同一个实体（对象、函数、引用等）。

局部变量没有链接性。每个没有链接性的标识符的声明都引用一个唯一的对象或函数。

  • 具有 无链接性 意味着同一标识符的另一个声明引用一个唯一的实体。标识符无链接性的实体包括：
    • 局部变量
    • 在块内声明的程序定义类型标识符（如枚举和类）
  • 具有 内部链接 意味着同一翻译单元内同一标识符的声明引用同一个对象或函数。标识符具有内部链接性的实体包括：
    • 静态全局变量（已初始化或未初始化）
    • 静态函数
    • 常量全局变量
    • 未命名命名空间及其内部定义的任何内容
  • 具有 外部链接 意味着整个程序中同一标识符的声明引用同一个对象或函数。标识符具有外部链接性的实体包括：
    • 非静态函数
    • 非常量全局变量（已初始化或未初始化）
    • 外部常量全局变量
    • 内联常量全局变量
    • 命名空间

如果定义被编译到多个 .cpp 文件中，具有外部链接性的标识符通常会导致重复定义链接器错误（由于违反单一定义规则）。此规则有一些例外（对于类型、模板以及内联函数和变量）——我们将在后续课程中讨论这些主题时进一步介绍。

另请注意，函数默认具有外部链接性。可以通过使用 static 关键字使其成为内部链接性。

由于变量具有作用域、生存期和链接性，让我们用图表总结：

前向声明总结

你可以使用前向声明来访问另一个文件中的函数或变量。声明变量的作用域与通常相同（全局变量为全局作用域，局部变量为块作用域）。

类型示例备注
函数前向声明void foo(int x);仅原型，无函数体
非常量变量前向声明extern int g_x;必须未初始化
const 变量前向声明extern const int g_x;必须未初始化
constexpr 变量的前向声明extern constexpr int g_x;不允许，constexpr 不能被前向声明

constexpr 变量（隐式 const）可以使用 const 变量的前向声明进行前向声明。通过前向声明访问时，该变量将被视为 const（而非 constexpr）。

存储类说明符到底是什么？

当用作标识符声明的一部分时， static 和 extern 关键字被称为 存储类说明符。在此上下文中，它们设置标识符的存储持续时间和链接性。

C++ 支持 4 个活跃的存储类说明符：

说明符含义备注
外部static（或 thread_local）存储持续时间和外部链接性
静态static（或 thread_local）存储持续时间和内部链接性
线程局部线程存储持续时间
可变允许对象被修改，即使包含类为 const
auto自动存储期在 C++11 中弃用
寄存器自动存储持续时间，并提示编译器将其放入寄存器在 C++17 中弃用

术语 存储类说明符 通常仅在正式文档中使用。
