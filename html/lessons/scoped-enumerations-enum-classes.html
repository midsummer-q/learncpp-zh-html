13.6 — 作用域枚举（enum class）

● 机器译文 课程 13.6 查看英文原文

虽然无作用域枚举在 C++ 中是不同的类型，但它们不是类型安全的，并且在某些情况下会允许你做没有意义的事情。考虑以下情况：

#include <iostream>

int main()
{
    enum Color
    {
        red,
        blue,
    };

    enum Fruit
    {
        banana,
        apple,
    };
	
    Color color { red };
    Fruit fruit { banana };

    if (color == fruit) // 编译器会将color和fruit作为整数比较
        std::cout << "color and fruit are equal\n"; // 并发现它们相等！
    else
        std::cout << "color and fruit are not equal\n";

    return 0;
}

这会打印：

color and fruit are equal

当 color 和 fruit 进行比较时，编译器会查看它是否知道如何比较 Color ，我们需要几个辅助对象（一个 Fruit。它不知道。接下来，它会尝试将 Color 和/或 Fruit 转换为整数，看看是否能找到匹配。最终编译器会确定，如果两者都转换为整数，就可以进行比较。由于 color 和 fruit 都设置为转换为整数值的枚举项 0， color 将等于 fruit。

这在语义上没有意义，因为 color 和 fruit 来自不同的枚举，并且不打算进行比较。使用标准枚举项，没有简单的方法来防止这种情况。

由于这些挑战，以及命名空间污染问题（在全局作用域中定义的无作用域枚举会将其枚举项放入全局命名空间），C++ 设计者认为需要一种更干净的枚举解决方案。

有作用域枚举

这个解决方案就是 作用域枚举 （通常称为 enum class ，原因很快就会明了）。

作用域枚举的工作方式与无作用域枚举类似（13.2 -- 无作用域枚举），但有两个主要区别：它们不会隐式转换为整数，并且枚举项被 时，只有 放置在枚举的作用域区域中（而不是枚举定义所在的作用域区域）。

要创建作用域枚举，我们使用关键字 enum class。作用域枚举定义的其余部分与无作用域枚举定义相同。下面是一个例子：

#include <iostream>
int main()
{
    enum class Color // "enum class" 将此定义为作用域枚举而非无作用域枚举
    {
        red, // red被视为Color作用域区域的一部分
        blue,
    };

    enum class Fruit
    {
        banana, // banana被视为Fruit作用域区域的一部分
        apple,
    };

    Color color { Color::red }; // 注意：red不能直接访问，必须使用Color::red
    Fruit fruit { Fruit::banana }; // 注意：banana不能直接访问，必须使用Fruit::banana
	
    if (color == fruit) // 编译错误：编译器不知道如何比较不同类型Color和Fruit
        std::cout << "color and fruit are equal\n";
    else
        std::cout << "color and fruit are not equal\n";

    return 0;
}

该程序在第 19 行产生编译错误，因为作用域枚举不会转换为任何可以与其他类型比较的类型。

顺便说一句……

浮点类型的 class 关键字（连同 static 关键字）是 C++ 语言中重载最多的关键字之一，并且可以根据上下文具有不同的含义。尽管作用域枚举使用了 class 关键字，但它们不被视为“类类型”（类类型保留给 struct、class 和 union）。

enum struct 在这种上下文中也可以工作，并且行为与 enum class相同。然而，使用 enum struct 不符合惯用法，因此应避免使用。

作用域枚举定义自己的作用域区域

与将枚举项放在枚举本身相同作用域中的无作用域枚举不同，作用域枚举将其枚举项 时，只有 放在枚举的作用域区域中。换句话说，作用域枚举为其枚举项充当命名空间。这种内置的命名空间有助于减少全局命名空间污染以及当作用域枚举在全局作用域中使用时可能出现的名称冲突。

要访问作用域枚举项，我们就像访问与作用域枚举同名的命名空间中的项一样：

#include <iostream>

int main()
{
    enum class Color // "enum class" 将此定义为作用域枚举而非无作用域枚举
    {
        red, // red被视为Color作用域区域的一部分
        blue,
    };

    std::cout << red << '\n';        // 编译错误：red未在此作用域区域中定义
    std::cout << Color::red << '\n'; // 编译错误：std::cout不知道如何打印此内容（不会隐式转换为int）

    Color color { Color::blue }; // 好的

    return 0;
}

由于作用域枚举为其枚举项提供了自己的隐式命名空间，因此没有必要将作用域枚举放在另一个作用域区域（如命名空间）中，除非有其他令人信服的理由这样做，因为这样做是多余的。

作用域枚举不会隐式转换为整数

与无作用域枚举项不同，作用域枚举项不会隐式转换为整数。在大多数情况下，这是一件好事，因为这样做很少有意义，并且有助于防止语义错误，例如比较来自不同枚举的枚举项，或类似 red + 5。

请注意，你仍然可以比较同一作用域枚举中的枚举项（因为它们属于同一类型）：

#include <iostream>
int main()
{
    enum class Color
    {
        red,
        blue,
    };

    Color shirt { Color::red };

    if (shirt == Color::red) // 这个Color与Color的比较是可以的
        std::cout << "The shirt is red!\n";
    else if (shirt == Color::blue)
        std::cout << "The shirt is blue!\n";

    return 0;
}

有时，将作用域枚举项视为整数值是有用的。在这些情况下，你可以通过使用 static_cast显式地将作用域枚举项转换为整数。在 C++23 中更好的选择是使用 std::to_underlying() （定义在 <utility> 头文件中），它将枚举项转换为枚举底层类型的值。

#include <iostream>
#include <utility> // for std::to_underlying() (C++23)

int main()
{
    enum class Color
    {
        red,
        blue,
    };

    Color color { Color::blue };

    std::cout << color << '\n'; // 不行，因为没有隐式转换为int
    std::cout << static_cast<int>(color) << '\n';   // 显式转换为int，将打印1
    std::cout << std::to_underlying(color) << '\n'; // 转换为底层类型，将打印1（C++23）

    return 0;
}

相反，你也可以将整数 static_cast 转换为作用域枚举项，这在从用户输入时很有用：

#include <iostream>

int main()
{
    enum class Pet
    {
        cat, // 赋值为 0
        dog, // 赋值为 1
        pig, // 赋值为 2
        whale, // 赋值为 3
    };

    std::cout << "Enter a pet (0=cat, 1=dog, 2=pig, 3=whale): ";

    int input{};
    std::cin >> input; // 输入一个整数

    Pet pet{ static_cast<Pet>(input) }; // 将我们的整数 static_cast 为 Pet

    return 0;
}

从C++17开始，你可以使用整数值对作用域枚举进行列表初始化，而无需static_cast（与无作用域枚举不同，你不需要指定底层类型）：

   // 使用前面示例中的enum class Pet
   Pet pet { 1 }; // 好的

最佳实践

除非有令人信服的理由，否则优先使用作用域枚举而非无作用域枚举。

尽管作用域枚举有诸多好处，但无作用域枚举在C++中仍然常用，因为有些情况下我们需要隐式转换为int（大量使用static_cast会很烦人），而且不需要额外的命名空间。

简化作用域枚举到整数的转换（高级）

作用域枚举很好，但缺乏到整数的隐式转换有时会带来麻烦。如果我们需要频繁地将作用域枚举转换为整数（例如，想用作用域枚举作为数组索引），每次转换都使用static_cast会严重使代码变得杂乱。

如果你发现自己处于需要简化作用域枚举到整数转换的情况，一个有用的技巧是重载一元 operator+ 来执行此转换：

#include <iostream>
#include <type_traits> // for std::underlying_type_t

enum class Animals
{
    chicken, // 0
    dog, // 1
    cat, // 2
    elephant, // 3
    duck, // 4
    snake, // 5

    maxAnimals,
};

// 重载一元+运算符以将枚举转换为底层类型
// 改编自https://stackoverflow.com/a/42198760，感谢Pixelchemist提供思路
// 在C++23中，你可以#include <utility>并返回std::to_underlying(a)代替
template <typename T>
constexpr auto operator+(T a) noexcept
{
    return static_cast<std::underlying_type_t<T>>(a);
}

int main()
{
    std::cout << +Animals::elephant << '\n'; // 使用一元+运算符将Animals::elephant转换为整数

    return 0;
}

这会打印：

3

这种方法防止了意外的隐式转换为整数类型，但提供了一种方便的方式在需要时显式请求此类转换。

using enum using语句 C++20

C++20引入了一个 using enum 语句，它将枚举中的所有枚举器导入当前作用域。当与enum class类型一起使用时，这允许我们访问枚举类的枚举器，而无需在每个枚举器前加上枚举类的名称。

这在某些情况下很有用，比如当我们有许多相同、重复的前缀时，例如在switch语句中：

#include <iostream>
#include <string_view>

enum class Color
{
    black,
    red,
    blue,
};

constexpr std::string_view getColor(Color color)
{
    using enum Color; // 将所有Color枚举器引入当前作用域（C++20）
    // 现在我们可以直接访问Color的枚举项，无需使用Color::前缀

    switch (color)
    {
    case black: return "black"; // 注意：black 而非 Color::black
    case red:   return "red";
    case blue:  return "blue";
    default:    return "???";
    }
}

int main()
{
    Color shirt{ Color::blue };

    std::cout << "Your shirt is " << getColor(shirt) << '\n';

    return 0;
}

在上面的例子中， Color 是一个enum class，所以我们通常使用完全限定名称访问枚举器（例如 Color::blue）。然而，在函数 getColor()中，我们添加了语句 using enum Color;，这允许我们访问这些枚举器而无需 Color:: 前缀的简写类型。

这使我们在switch语句中避免了多个冗余、明显的前缀。

小测验时间

问题 #1

定义一个名为Animal的枚举类，包含以下动物：pig, chicken, goat, cat, dog, duck。编写一个名为getAnimalName()的函数，它接受一个Animal参数，并使用switch语句返回该动物的名称作为std::string_view（如果使用C++14，则返回std::string）。编写另一个名为printNumberOfLegs()的函数，使用switch语句打印每种动物行走的腿数。确保两个函数都有一个默认情况，打印错误消息。在main()中调用printNumberOfLegs()，参数为cat和chicken。你的输出应该如下所示：

A cat has 4 legs.
A chicken has 2 legs.

显示答案

#include <iostream>
#include <string_view> // C++17
//#include <string> // 用于 C++14

enum class Animal
{
    pig,
    chicken,
    goat,
    cat,
    dog,
    duck,
};

constexpr std::string_view getAnimalName(Animal animal) // C++17
// const std::string getAnimalName(Animal animal) // C++14
{
    // 如果支持C++20，可以在此处使用`using enum Animal`来减少Animal前缀的冗余
    switch (animal)
    {
        case Animal::chicken:
            return "chicken";
        case Animal::duck:
            return "duck";
        case Animal::pig:
            return "pig";
        case Animal::goat:
            return "goat";
        case Animal::cat:
            return "cat";
        case Animal::dog:
            return "dog";

        default:
            return "???";
    }
}

void printNumberOfLegs(Animal animal)
{
    std::cout << "A " << getAnimalName(animal) << " has ";

    // 如果支持C++20，可以在此处使用`using enum Animal`来减少Animal前缀的冗余
    switch (animal)
    {
        case Animal::chicken:
        case Animal::duck:
            std::cout << 2;
            break;

        case Animal::pig:
        case Animal::goat:
        case Animal::cat:
        case Animal::dog:
            std::cout << 4;
            break;

        default:
            std::cout << "???";
            break;
    }

    std::cout << " legs.\n";
}

int main()
{
    printNumberOfLegs(Animal::cat);
    printNumberOfLegs(Animal::chicken);

    return 0;
}
