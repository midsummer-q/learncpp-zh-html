18.1 — 使用选择排序对数组进行排序

● 机器译文 课程 18.1 查看英文原文

排序的案例

对数组进行排序是将数组中的所有元素按特定顺序排列的过程。在许多不同的情况下，对数组进行排序可能很有用。例如，您的电子邮件程序通常按接收时间顺序显示电子邮件，因为较新的电子邮件通常被认为更相关。当您查看联系人列表时，姓名通常按字母顺序排列，因为这样更容易找到您要查找的姓名。这两种呈现方式都涉及在呈现之前对数据进行排序。

对数组进行排序可以使搜索数组更高效，不仅对人类如此，对计算机也是如此。例如，考虑我们想知道一个名字是否出现在名字列表中的情况。为了查看一个名字是否在列表中，我们必须检查数组中的每个元素，看该名字是否出现。对于包含许多元素的数组，逐个搜索可能代价高昂。

然而，现在假设我们的名字数组是按字母顺序排序的。在这种情况下，我们只需要搜索到遇到一个按字母顺序大于我们要查找的名字的位置。此时，如果我们还没有找到该名字，我们就知道它在数组的其余部分中不存在，因为我们尚未查看的数组中的所有名字都保证按字母顺序更大！

事实证明，有更好的算法来搜索已排序的数组。使用一个简单的算法，我们可以在包含1,000,000个元素的已排序数组中仅用20次比较就能搜索到！缺点是，当然，对数组进行排序相对昂贵，并且除非您要多次搜索，否则通常不值得为了加快搜索速度而对数组进行排序。

在某些情况下，对数组进行排序可以使搜索变得不必要。考虑另一个例子，我们想要找到最佳测试分数。如果数组未排序，我们必须查看数组中的每个元素才能找到最高测试分数。如果列表已排序，最佳测试分数将位于第一个或最后一个位置（取决于我们是按升序还是降序排序），因此我们根本不需要搜索！

排序的工作原理

排序通常通过重复比较数组元素对，并在它们满足某些预定义条件时交换它们来执行。这些元素进行比较的顺序取决于所使用的排序算法。条件取决于列表将如何排序（例如，按升序或降序）。

要交换两个元素，我们可以使用C++标准库中的std::swap()函数，该函数在utility头文件中定义。

#include <iostream>
#include <utility>

int main()
{
    int x{ 2 };
    int y{ 4 };
    std::cout << "Before swap: x = " << x << ", y = " << y << '\n';
    std::swap(x, y); // 交换 x 和 y 的值
    std::cout << "After swap:  x = " << x << ", y = " << y << '\n';

    return 0;
}

该程序打印出：

Before swap: x = 2, y = 4
After swap:  x = 4, y = 2

注意，交换后，x和y的值已经互换！

选择排序

有很多方法可以对数组进行排序。选择排序可能是最容易理解的排序，这使其成为教学的良好候选，尽管它是较慢的排序之一。

选择排序执行以下步骤将数组从小到大排序：

  1. 从数组索引0开始，搜索整个数组以找到最小值
  2. 将数组中找到的最小值与索引0处的值交换
  3. 从下一个索引开始重复步骤1和2

换句话说，我们将找到数组中最小的元素，并将其交换到第一个位置。然后我们将找到下一个最小的元素，并将其交换到第二个位置。这个过程将重复进行，直到我们用完所有元素。

以下是该算法在5个元素上工作的示例。让我们从一个示例数组开始：

{ 30, 50, 20, 10, 40 }

首先，我们从索引0开始找到最小的元素：

{ 30, 50, 20, 10, 40 }

然后我们将其与索引0处的元素交换：

{ 10, 50, 20, 30, 40 }

现在第一个元素已排序，我们可以忽略它。现在，我们从索引1开始找到最小的元素：

{ 10, 50, 20, 30, 40 }

并将其与索引1处的元素交换：

{ 10， 20， 50, 30, 40 }

现在我们可以忽略前两个元素。从索引2开始找到最小的元素：

{ 10， 20, 50, 30, 40 }

并将其与索引2处的元素交换：

{ 10， 20， 30， 50, 40 }

从索引3开始找到最小的元素：

{ 10， 20， 30, 50, 40 }

并将其与索引3处的元素交换：

{ 10， 20， 30， 40， 50 }

最后，从索引4开始找到最小的元素：

{ 10， 20， 30， 40， 50 }

并将其与索引4处的元素交换（这没有效果）：

{ 10， 20， 30， 40， 50 }

完成！

{ 10, 20, 30, 40, 50 }

注意，最后一次比较总是与自身（这是多余的），因此我们实际上可以在数组结束前一个元素处停止。

C++中的选择排序

以下是在C++中实现该算法的方式：

#include <iostream>
#include <iterator>
#include <utility>

int main()
{
	int array[]{ 30, 50, 20, 10, 40 };
	constexpr int length{ static_cast<int>(std::size(array)) };

	// 遍历数组的每个元素
	// （除了最后一个，因为当我们到达它时它已经排序好了）
	for (int startIndex{ 0 }; startIndex < length - 1; ++startIndex)
	{
		// smallestIndex 是本次迭代中遇到的最小元素的索引
		// 首先假设最小元素是本次迭代的第一个元素
		int smallestIndex{ startIndex };

		// 然后在数组的其余部分寻找更小的元素
		for (int currentIndex{ startIndex + 1 }; currentIndex < length; ++currentIndex)
		{
			// 如果我们找到了一个比之前找到的最小元素还小的元素
			if (array[currentIndex] < array[smallestIndex])
				// 则记录它
				smallestIndex = currentIndex;
		}

		// smallestIndex 现在是剩余数组中最小的元素的索引
                // 将起始元素与最小元素交换（这将其排序到正确的位置）
		std::swap(array[startIndex], array[smallestIndex]);
	}

	// 现在整个数组已排序，打印排序后的数组以证明其工作
	for (int index{ 0 }; index < length; ++index)
		std::cout << array[index] << ' ';

	std::cout << '\n';

	return 0;
}

该算法最令人困惑的部分是循环内部的另一个循环（称为 嵌套循环）。外部循环（startIndex）逐个遍历每个元素。对于外部循环的每次迭代，内部循环（currentIndex）用于在剩余数组（从startIndex+1开始）中找到最小的元素。smallestIndex跟踪内部循环找到的最小元素的索引。然后将smallestIndex与startIndex交换。最后，外部循环（startIndex）前进一个元素，并重复该过程。

提示：如果您在理解上述程序如何工作方面遇到困难，在纸上逐步处理一个示例案例可能会有所帮助。在纸张顶部水平写出起始（未排序）数组元素。绘制箭头指示startIndex、currentIndex和smallestIndex正在索引哪些元素。手动跟踪程序，并在索引更改时重新绘制箭头。对于外部循环的每次迭代，开始新的一行显示数组的当前状态。

对名字进行排序使用相同的算法。只需将数组类型从int更改为std::string，并使用适当的值进行初始化。

std::sort

由于对数组进行排序非常常见，C++标准库包含一个名为std::sort的排序函数。 std::sort。 std::sort 位于 <algorithm> 头文件中，可以像这样在数组上调用：

#include <algorithm> // for std::sort
#include <iostream>
#include <iterator> // for std::size

int main()
{
	int array[]{ 30, 50, 20, 10, 40 };

	std::sort(std::begin(array), std::end(array));

	for (int i{ 0 }; i < static_cast<int>(std::size(array)); ++i)
		std::cout << array[i] << ' ';

	std::cout << '\n';

	return 0;
}

默认情况下，std::sort 使用 operator< 比较元素对，并在必要时交换它们（就像我们上面的选择排序示例一样），按升序排序。

我们将在下一课中进一步讨论 std::sort 在未来的章节中。

问题 #2

将上面的选择排序代码重写为按降序排序（最大的数字在前）。虽然这可能看起来很复杂，但实际上非常简单。

显示答案

只需将：

        if (array[currentIndex] < array[smallestIndex])

改为：

        if (array[currentIndex] > array[smallestIndex])

smallestIndex 可能也应该重命名为 largestIndex。

#include <iostream>
#include <iterator> // for std::size
#include <utility>

int main()
{
    int array[]{ 30, 50, 20, 10, 40 };
    constexpr int length{ static_cast<int>(std::size(array)) }; // C++17
//  constexpr int length{ sizeof(array) / sizeof(array[0]) }; // 如果不支持 C++17，则使用此方法

    // 遍历数组的每个元素，除了最后一个
    for (int startIndex{ 0 }; startIndex < length - 1; ++startIndex)
    {
        // largestIndex 是到目前为止遇到的最大元素的索引。
        int largestIndex{ startIndex };

        // 从 startIndex + 1 开始搜索每个元素
        for (int currentIndex{ startIndex + 1 }; currentIndex < length; ++currentIndex)
        {
            // 如果当前元素大于之前找到的最大元素
            if (array[currentIndex] > array[largestIndex])
                // 这是本次迭代中新的最大数
                largestIndex = currentIndex;
        }

        // 将起始元素与最大元素交换
        std::swap(array[startIndex], array[largestIndex]);
    }

    // 现在打印排序后的数组以证明其正确性
    for (int index{ 0 }; index < length; ++index)
        std::cout << array[index] << ' ';

    std::cout << '\n';

    return 0;
}

问题 #3

这个会很难，所以打起精神来。

另一种简单的排序叫做“冒泡排序”。冒泡排序通过比较相邻的元素对，如果满足条件则交换它们，使元素“冒泡”到数组的末尾。虽然有很多方法可以优化冒泡排序，但在这个测验中，我们将坚持使用未优化的版本，因为它最简单。

未优化的冒泡排序执行以下步骤将数组从小到大排序：
A) 比较数组元素 0 和元素 1。如果元素 0 更大，则将其与元素 1 交换。
B) 现在对元素 1 和 2，以及每一对后续元素执行相同操作，直到到达数组末尾。此时，数组中的最后一个元素将被排序。
C) 重复前两个步骤，直到数组排序完成。

编写代码，根据上述规则对以下数组进行冒泡排序：

int array[]{ 6, 3, 2, 9, 7, 1, 5, 4, 8 };

在程序结束时打印排序后的数组元素。

提示：如果我们每次迭代能排序一个元素，那么我们需要迭代的次数大致等于数组中的数字个数，以确保整个数组被排序。
提示：在比较元素对时，注意数组的范围。

显示答案

#include <iostream>
#include <iterator> // for std::size
#include <utility>

int main()
{
    int array[]{ 6, 3, 2, 9, 7, 1, 5, 4, 8 };
    constexpr int length{ static_cast<int>(std::size(array)) }; // C++17
//  constexpr int length{ sizeof(array) / sizeof(array[0]) }; // 如果不支持 C++17，则使用此方法

    // 遍历数组的每个元素（最后一个除外，因为当我们处理到它时它已经排好序了）
    for (int iteration{ 0 }; iteration < length-1; ++iteration)
    {
        // 搜索直到数组末尾 - 1 的所有元素
        // 最后一个元素没有可以比较的对
        for (int currentIndex{ 0 }; currentIndex < length - 1; ++currentIndex)
        {
            // 如果当前元素大于它后面的元素，则交换它们
            if (array[currentIndex] > array[currentIndex+1])
                std::swap(array[currentIndex], array[currentIndex + 1]);
        }
    }

    // 现在打印排序后的数组以证明其正确性
    for (int index{ 0 }; index < length; ++index)
        std::cout << array[index] << ' ';

    std::cout << '\n';

    return 0;
}

问题 #4

为你在上一个测验问题中编写的冒泡排序算法添加两个优化：

  • 注意，在冒泡排序的每次迭代中，剩余的最大数字会冒泡到数组的末尾。第一次迭代后，最后一个数组元素已排序。第二次迭代后，倒数第二个数组元素也已排序。依此类推……每次迭代，我们不需要重新检查已知已排序的元素。修改你的循环，使其不重新检查已排序的元素。
  • 如果我们在整个迭代过程中没有进行任何交换，那么我们知道数组一定已经排序好了。实现一个检查，判断本次迭代是否进行了任何交换，如果没有，则提前终止循环。如果循环提前终止，打印排序在哪次迭代提前结束。

你的输出应该匹配以下内容：

Early termination on iteration 6
1 2 3 4 5 6 7 8 9

显示答案

#include <iostream>
#include <iterator> // for std::size
#include <utility>

int main()
{
    int array[]{ 6, 3, 2, 9, 7, 1, 5, 4, 8 };
    constexpr int length{ static_cast<int>(std::size(array)) }; // C++17
//  constexpr int length{ sizeof(array) / sizeof(array[0]) }; // 如果不支持 C++17，则使用此方法

    // 遍历数组的每个元素，除了最后一个
    for (int iteration{ 0 }; iteration < length-1; ++iteration)
    {
        // 考虑到每次后续迭代后最后一个元素已经排好序
        // 所以我们的数组“结束”位置提前一个元素
        int endOfArrayIndex{ length - iteration };

        bool swapped{ false }; // 记录本次迭代中是否有任何元素被交换

        // 搜索直到数组末尾 - 1 的所有元素
        // 最后一个元素没有可以比较的对
        for (int currentIndex{ 0 }; currentIndex < endOfArrayIndex - 1; ++currentIndex)
        {
            // 如果当前元素大于它后面的元素
            if (array[currentIndex] > array[currentIndex + 1])
            {
                // 交换它们
                std::swap(array[currentIndex], array[currentIndex + 1]);
                swapped = true;
            }
        }

        // 如果本次迭代中没有交换任何元素，则提前结束
        if (!swapped)
        {
            // 迭代从0开始，但计数迭代从1开始。所以这里加1进行调整。
            std::cout << "Early termination on iteration: " << iteration+1 << '\n';
            break;
        }
    }

    // 现在打印排序后的数组以证明其正确性
    for (int index{ 0 }; index < length; ++index)
        std::cout << array[index] << ' ';

    std::cout << '\n';

    return 0;
}
