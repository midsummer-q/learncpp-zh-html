1.1 — 语句和程序的结构

语句

计算机程序是一系列告诉计算机该做什么的指令。一条 语句 是一种指令类型，它使程序 执行某个操作。

语句是C++程序中最常见的指令类型。这是因为它们是C++语言中最小的独立计算单元。在这方面，它们的作用很像自然语言中的句子。当我们想向他人传达一个想法时，我们通常用句子（而不是随机单词或音节）来书写或说话。在C++中，当我们想让程序执行某些操作时，我们通常会编写语句。

C++中的大多数（但不是所有）语句都以分号结尾。如果你看到一行以分号结尾，那很可能是一条语句。

在像C++这样的高级语言中，一条语句可能会编译成多条机器语言指令。

进阶读者

C++中有多种不同类型的语句：

  • 声明语句
  • 跳转语句
  • 表达式语句
  • 复合语句
  • 选择语句（条件语句）
  • 迭代语句（循环）
  • try 块

当你完成本系列教程时，你就会明白所有这些是什么！

函数和 main 函数

在C++中，语句通常被分组为称为函数的单元。一个 函数 是一个按顺序（从上到下）依次执行的语句集合。当你学习编写自己的程序时，你将能够创建自己的函数，并以任何你喜欢的方式混合搭配语句（我们将在后续课程中展示如何操作）。

规则

每个C++程序都必须有一个名为 main （全部小写字母）。

程序运行时， main 按顺序执行。

程序通常在函数 main 内部的最后一条语句执行后终止（结束运行）（尽管在某些情况下程序可能会提前中止，或之后进行一些清理工作）。

函数通常被编写来完成特定任务或执行某些有用的操作。例如，一个名为 max 的函数可能包含判断两个数字哪个更大的语句。一个名为 calculateGrade 的函数可能根据一组测试分数计算学生的成绩。一个名为 printEmployee 的函数可能将员工信息打印到控制台。我们很快就会详细讨论函数，因为它们是程序中最常用的组织工具。

术语

讨论函数时，通常在函数名末尾加一对括号作为简写。例如，如果你看到术语 main() 或 doSomething()这分别是名为函数 main 或 doSomething 的简写形式。这样有助于将函数与其它有名称的事物（如变量）区分开来，而无需每次都写出“函数”一词。

在编程中，函数（或对象、类型、模板等）的名称称为其 标识符。

字符与文本

最早的计算机主要用于数学计算和数据处理。随着硬件改进、网络可用和消费软件发展，计算机也成为书面交流的有价值工具。

在书面语言中，最基本的交流单位是字符。简单来说， 字符 是一种书写符号或标记，如字母、数字、标点符号或数学符号。当我们按下键盘上的字母或数字键时，就会产生一个字符，然后可以显示在屏幕上。以下都是字符： a， 2， $、和 =。

在许多情况下，例如书写单词或句子时，我们需要使用多个字符。字符序列称为 文本 （也称为 字符串 在编程语境中）。

术语

通常，“文本”一词也用来指代 纯文本，即只包含标准键盘上出现的字符，没有任何特殊格式或样式的文本。例如，纯文本无法表示粗体字，因为这需要样式设置。

我们的C++程序都是以纯文本形式编写的。

进阶读者

计算机还有一种额外的字符类型，称为“控制字符”。这些字符对计算机系统有特殊含义，但要么不打算显示，要么显示为不同于单个可见符号的内容。已知控制字符的例子包括“escape”（不显示任何内容）、“tab”（显示为若干空格）和“backspace”（删除前一个字符）。

剖析Hello world!

既然你已经对语句和函数有了初步理解，让我们回到“Hello world”程序，从高层次更详细地看看每行代码的作用。

#include <iostream>

int main()
{
   std::cout << "Hello world!";
   return 0;
}

第1行是一种特殊类型的行，称为预处理器指令。这个 #include 预处理器指令表示我们希望使用 iostream 库的内容，该库是C++标准库的一部分，允许我们从控制台读写文本。我们需要这一行才能在第5行使用 std::cout 省略这一行将导致第5行编译错误，因为编译器否则不知道 std::cout 是什么。

第2行为空，被编译器忽略。这一行仅用于帮助人类提高程序的可读性（通过分隔 #include 预处理器指令和程序的后续部分）。

第3行告诉编译器我们将要编写（定义）一个函数，其名称（标识符）是 main。正如你之前所学，每个C++程序都必须有一个 main 函数，否则将无法链接。这个函数将产生一个类型为 int （整数）的值。

第4行和第7行告诉编译器哪些行属于 main 函数。第4行的左花括号和第7行的右花括号之间的所有内容都被视为 main 函数的一部分。这被称为函数体。

第5行是函数 main中的第一条语句，也是我们运行程序时将执行的第一条语句。 std::cout （代表“字符输出”）和 << 运算符允许我们在控制台上显示信息。在这种情况下，我们显示文本 Hello world!。这条语句产生了程序的可见输出。

第6行是一条返回语句。当可执行程序运行完毕时，程序会向操作系统发送一个值，以指示其是否成功运行。这个特定的返回语句将整数值 0 返回给操作系统，意思是“一切正常！”。这是程序中执行的最后一条语句。

我们将编写的所有程序都将遵循这个通用模板或其变体。

语法与语法错误

在英语中，句子的构造遵循特定的语法规则，这些规则你可能在学校英语课上学过。例如，在书写中，正常的句子以句号结尾。描述特定单词（和标点符号）如何排列以构成语言中有效句子的规则集称为 语法。例如，“My house painted is blue”就是一个语法错误，因为单词的顺序不符合常规。“All your base are belong to us!”是另一个著名的例子。

C++编程语言也有自己的语法，它描述了程序的元素必须如何编写和排列才能使程序被视为有效。当你编译程序时，编译器负责确保你的程序遵循这些语法规则。如果你的程序做了任何偏离语言语法的事情，编译器将停止编译并发出一个 语法错误。

与英语允许大量歧义不同，C++的语法规则是严格定义并执行的。语法错误很常见。幸运的是，这类错误通常很容易找到和修复，因为编译器一般会直接指出它们。程序只有在所有语法错误都解决后才会完成编译。

由于大多数语句的语法要求这些语句以分号结尾，让我们看看如果在“Hello world”程序的第5行省略分号会发生什么，如下所示：

#include <iostream>

int main()
{
   std::cout << "Hello world!"
   return 0;
}

请自行编译这个格式不正确的程序。

当使用Clang编译时，会生成以下错误信息：

prog.cc:5:31: error: expected ';' after expression

Clang告诉我们，在第5行的第31个字符处，语法规则需要一个分号，但我们没有提供。因此，编译因错误而停止。

而使用Visual Studio编译时，编译器会产生如下编译错误：

c:\vcprojects\hello.cpp(6): error C2143: syntax error : missing ';' before 'return'

注意Visual Studio指出错误出现在第6行（而不是第5行）。那么谁是正确的？从某种意义上说，两者都是正确的。

Clang知道我们通常将分号放在语句末尾，因此它基于我们会这样做的假设报告错误在第5行。Visual Studio则选择报告它确定发生错误时所编译的行（在第6行，当它遇到 return 而不是预期的分号时）。

关键提示

编译器有时会报告错误发生在传统上我们会修复问题的下一行。如果你在指示的行上找不到错误，请检查前一行。

要查看其他不同的错误信息，可以尝试从“Hello world”程序中删除字符甚至整行。还可以尝试恢复第5行末尾缺失的分号，然后删除第1、3或4行，看看会发生什么。
