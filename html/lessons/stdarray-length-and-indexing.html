17.2 — std::array 的长度和索引

● 机器译文 课程 17.2 查看英文原文

在课程 16.3 -- std::vector 和无符号长度与下标问题，我们讨论了标准库容器类使用无符号值表示长度和索引这一不幸的决定。由于 std::array 是一个标准库容器类，它也面临同样的问题。

在本课中，我们将回顾索引和获取 std::array。因为 std::vector 和 std::array 具有相似的接口，这将与我们之前为 std::vector介绍的内容类似。但由于只有 std::array 完全支持 constexpr，我们将更多地关注这一点。

在继续之前，现在是时候回顾一下“符号转换是窄化转换，除非是 constexpr”（参见 16.3 -- std::vector 和无符号长度与下标问题)。

的长度 std::array 的类型为 std::size_t

std::array 实现为一个模板结构体，其声明如下：

template<typename T, std::size_t N> // N 是一个非类型模板参数
struct array;

如您所见，表示数组长度的非类型模板参数（N）的类型是 std::size_t。而且您可能已经知道， std::size_t 是一个大的无符号整数类型。

相关内容

我们在第 13.13 -- 类模板 课中介绍了类模板（包括结构体模板），并在第 11.9 -- 非类型模板参数。

课中介绍了非类型模板参数。因此，当我们定义一个 std::array时，长度非类型模板参数必须具有类型 std::size_t，或者可以转换为类型 std::size_t的值。由于这个值必须是 constexpr，当我们使用有符号整数值时不会遇到符号转换问题，因为编译器会在编译时愉快地将有符号整数值转换为 std::size_t ，而不被视为窄化转换。

获取 std::array

有三种常见的方法来获取 std::array 播种），我们将其用作全局

首先，我们可以通过 std::array 对象的 size() 成员函数询问容器类对象的长度（该函数返回无符号 size_type)：

#include <array>
#include <iostream>

int main()
{
    constexpr std::array arr { 9.0, 7.2, 5.4, 3.6, 1.8 };
    std::cout << "length: " << arr.size() << '\n'; // 返回类型为 `size_type`（`std::size_t` 的别名）的长度
    return 0;
}

这会打印：

length: 5

与 std::string 和 std::string_view不同，它们既有 length() ，我们需要几个辅助对象（一个 size() 成员函数（做相同的事情）， std::array （以及 C++ 中的大多数其他容器类型）只有 size()。

其次，在 C++17 中，我们可以使用 std::size() 非成员函数（对于 std::array ，它只是调用 size() 成员函数，因此返回无符号的长度） size_type)。

#include <array>
#include <iostream>

int main()
{
    constexpr std::array arr{ 9, 7, 5, 3, 1 };
    std::cout << "length: " << std::size(arr); // C++17，返回类型为 `size_type`（`std::size_t` 的别名）的长度

    return 0;
}

最后，在 C++20 中，我们可以使用 std::ssize() 非成员函数，它返回长度作为一个大的 有符号 整型（通常std::ptrdiff_t)：

#include <array>
#include <iostream>

int main()
{
    constexpr std::array arr { 9, 7, 5, 3, 1 };
    std::cout << "length: " << std::ssize(arr); // C++20，返回一个大符号整数类型的长度

    return 0;
}

这是三个函数中唯一一个返回有符号类型长度的函数。

获取 std::array 作为 constexpr 值

因为 std::array 的长度是 constexpr，上述每个函数都会返回 std::array 的长度作为 constexpr 值（即使在非 constexpr 的 std::array 对象上调用）！这意味着我们可以在常量表达式中使用这些函数中的任何一个，并且返回的长度可以隐式转换为 int ，而不会被视为窄化转换：

#include <array>
#include <iostream>

int main()
{
    std::array arr { 9, 7, 5, 3, 1 }; // 注意：此示例中不是 constexpr
    constexpr int length{ std::size(arr) }; // ok：返回值是 constexpr std::size_t，可以转换为 int，不是窄化转换

    std::cout << "length: " << length << '\n';

    return 0;
}

警告

由于语言缺陷，当在通过（const）引用传递的 std::array 函数参数上调用时，上述函数将返回非 constexpr 值：

#include <array>
#include <iostream>

void printLength(const std::array<int, 5> &arr)
{
    constexpr int length{ std::size(arr) }; // 编译错误！
    std::cout << "length: " << length << '\n';
}

int main()
{
    std::array arr { 9, 7, 5, 3, 1 };
    constexpr int length{ std::size(arr) }; // 正常工作
    std::cout << "length: " << length << '\n';

    printLength(arr);

    return 0;
}

该缺陷已在 C++23 中通过 P2280解决。在撰写本文时，很少有编译器 支持 此功能。

一种解决方法是使 foo() 成为一个函数模板，其中数组长度是一个非类型模板参数。这个非类型模板参数可以在函数内部使用。我们将在课程 17.3 -- 传递和返回 std::array。

template <auto Length>
void printLength(const std::array<int, Length> &arr)
{
    std::cout << "length: " << Length << '\n';
}

中进一步讨论。 std::array using operator[] 还是我们定义的 at() 成员函数

在上一课中 17.1 -- std::array简介中，我们介绍了索引 std::array 的最常见方法是使用下标运算符（operator[]）。在这种情况下不进行边界检查，传入无效索引将导致未定义行为。

中介绍异常及其处理方法。 std::vector， std::array 还有一个 at() 成员函数，它执行带有运行时边界检查的下标操作。我们建议避免使用此函数，因为我们通常希望在索引之前进行边界检查，或者希望进行编译时边界检查。

这两个函数都期望索引的类型为 size_type (std::size_t)。

如果这两个函数中的任何一个使用 constexpr 值调用，编译器将执行到 std::size_t的 constexpr 转换。这不被视为窄化转换，因此您不会遇到符号问题。

但是，如果这两个函数中的任何一个使用非 constexpr 的有符号整数值调用，则转换为 std::size_t 被视为窄化，您的编译器可能会发出警告。我们进一步讨论这种情况（使用 std::vector） 16.3 -- std::vector 和无符号长度与下标问题。

std::get() 对 constexpr 索引进行编译时边界检查）

由于 std::array 的长度是 constexpr，如果我们的索引也是 constexpr 值，那么编译器应该能够在编译时验证我们的 constexpr 索引是否在数组边界内（如果 constexpr 索引越界，则停止编译）。

然而， operator[] 按定义不进行边界检查，而 at() 成员函数仅进行运行时边界检查。而且函数参数不能是 constexpr（即使对于 constexpr 或 consteval 函数也是如此），那么我们如何传递一个 constexpr 索引呢？

为了在拥有 constexpr 索引时获得编译时边界检查，我们可以使用 std::get() 函数模板，它将索引作为非类型模板参数：

#include <array>
#include <iostream>

int main()
{
    constexpr std::array prime{ 2, 3, 5, 7, 11 };

    std::cout << std::get<3>(prime); // 打印索引为 3 的元素的值
    std::cout << std::get<9>(prime); // 无效索引（编译错误）

    return 0;
}

在 std::get()的实现内部，有一个 static_assert 检查以确保非类型模板参数小于数组长度。如果不是，则 static_assert 将停止编译过程并产生编译错误。

由于模板参数必须是 constexpr， std::get() 只能使用 constexpr 索引调用。

小测验时间

问题 #1

初始化一个 std::array ，包含以下值：'h', 'e', 'l', 'l', 'o'。打印数组的长度，然后使用 operator[]， at() 和 std::get() 打印索引为 1 的元素的值。

程序应输出：

The length is 5
eee

显示答案

#include <array>
#include <iostream>

int main()
{
    constexpr std::array arr { 'h', 'e', 'l', 'l', 'o' };
    std::cout << "The length is " << std::size(arr) << '\n';
    std::cout << arr[1] << arr.at(1) << std::get<1>(arr) << '\n';

    return 0;
}
