23.7 — std::initializer_list

● 机器译文 课程 23.7 查看英文原文

考虑 C++ 中的一个固定整数数组：

int array[5];

如果我们想用值初始化这个数组，可以直接通过初始化列表语法来实现：

#include <iostream>

int main()
{
	int array[] { 5, 4, 3, 2, 1 }; // 初始化列表
	for (auto i : array)
		std::cout << i << ' ';

	return 0;
}

这会打印：

5 4 3 2 1

这也适用于动态分配的数组：

#include <iostream>

int main()
{
	auto* array{ new int[5]{ 5, 4, 3, 2, 1 } }; // 初始化列表
	for (int count{ 0 }; count < 5; ++count)
		std::cout << array[count] << ' ';
	delete[] array;

	return 0;
}

在上一课中，我们介绍了容器类的概念，并展示了一个 IntArray 类的示例，它持有一个整数数组：

#include <cassert> // for assert()
#include <iostream>
 
class IntArray
{
private:
    int m_length{};
    int* m_data{};
 
public:
    IntArray() = default;
 
    IntArray(int length)
        : m_length{ length }
	, m_data{ new int[static_cast<std::size_t>(length)] {} }
    {
    }
 
    ~IntArray()
    {
        delete[] m_data;
        // 我们不需要在此处将 m_data 设置为 null 或将 m_length 设置为 0，因为该函数执行后对象将立即被销毁
    }
 
    int& operator[](int index)
    {
        assert(index >= 0 && index < m_length);
        return m_data[index];
    }
 
    int getLength() const { return m_length; }
};

int main()
{
	// 如果我们尝试对这个容器类使用初始化列表会发生什么？
	IntArray array { 5, 4, 3, 2, 1 }; // 这一行无法编译
	for (int count{ 0 }; count < 5; ++count)
		std::cout << array[count] << ' ';

	return 0;
}

这段代码无法编译，因为 IntArray 类没有一个知道如何处理初始化列表的构造函数。因此，我们只能逐个初始化数组元素：

int main()
{
	IntArray array(5);
	array[0] = 5;
	array[1] = 4;
	array[2] = 3;
	array[3] = 2;
	array[4] = 1;

	for (int count{ 0 }; count < 5; ++count)
		std::cout << array[count] << ' ';

	return 0;
}

这不太理想。

使用 std::initializer_list 进行类初始化

当编译器看到初始化列表时，它会自动将其转换为 std::initializer_list 类型的对象。因此，如果我们创建一个接受 std::initializer_list 参数的构造函数，就可以使用初始化列表作为输入来创建对象。

std::initializer_list 位于 <initializer_list> 头文件中。

关于 std::initializer_list 有几点需要了解。与 std::array 或 std::vector 类似，你必须使用尖括号告诉 std::initializer_list 列表持有的数据类型，除非你立即初始化 std::initializer_list。因此，你几乎不会看到普通的 std::initializer_list，而是会看到类似 std::initializer_list<int> 或 std::initializer_list<std::string>。

其次，std::initializer_list 有一个（命名不当的）size() 函数，返回列表中的元素数量。当我们需要知道传入列表的长度时，这很有用。

第三，std::initializer_list 通常按值传递。与 std::string_view 类似，std::initializer_list 是一个视图。复制 std::initializer_list 不会复制列表中的元素。

让我们看看如何更新 IntArray 类，添加一个接受 std::initializer_list 的构造函数。

#include <algorithm> // for std::copy
#include <cassert> // for assert()
#include <initializer_list> // for std::initializer_list
#include <iostream>

class IntArray
{
private:
	int m_length {};
	int* m_data{};

public:
	IntArray() = default;

	IntArray(int length)
		: m_length{ length }
		, m_data{ new int[static_cast<std::size_t>(length)] {} }
	{

	}

	IntArray(std::initializer_list<int> list) // 允许 IntArray 通过列表初始化进行初始化
		: IntArray(static_cast<int>(list.size())) // 使用委托构造函数设置初始数组
	{
		// 现在从列表中初始化我们的数组
		std::copy(list.begin(), list.end(), m_data);
	}

	~IntArray()
	{
		delete[] m_data;
		// 我们不需要在此处将 m_data 设置为 null 或将 m_length 设置为 0，因为该函数执行后对象将立即被销毁
	}

	IntArray(const IntArray&) = delete; // 为了避免浅拷贝
	IntArray& operator=(const IntArray& list) = delete; // 为了避免浅拷贝

	int& operator[](int index)
	{
		assert(index >= 0 && index < m_length);
		return m_data[index];
	}

	int getLength() const { return m_length; }
};

int main()
{
	IntArray array{ 5, 4, 3, 2, 1 }; // 初始化列表
	for (int count{ 0 }; count < array.getLength(); ++count)
		std::cout << array[count] << ' ';

	return 0;
}

这会输出预期的结果：

5 4 3 2 1

成功了！现在，让我们更详细地探讨一下。

这是我们的 IntArray 构造函数，它接受一个 std::initializer_list<int>。

	IntArray(std::initializer_list<int> list) // 允许 IntArray 通过列表初始化进行初始化
		: IntArray(static_cast<int>(list.size())) // 使用委托构造函数设置初始数组
	{
		// 现在从列表中初始化我们的数组
		std::copy(list.begin(), list.end(), m_data);
	}

在第 1 行：如上所述，我们必须使用尖括号来指定列表中期望的元素类型。在这种情况下，因为这是一个 IntArray，我们期望列表填充的是 int。注意，我们没有通过 const 引用传递列表。与 std::string_view 类似，std::initializer_list 非常轻量，复制通常比间接访问更便宜。

在第 2 行：我们通过委托构造函数将 IntArray 的内存分配委托给另一个构造函数（以减少冗余代码）。这个另一个构造函数需要知道数组的长度，所以我们传递 list.size()，它包含列表中的元素数量。注意，list.size() 返回 size_t（无符号类型），所以这里需要转换为有符号 int。

构造函数的主体用于将元素从列表复制到我们的 IntArray 类中。最简单的方法是使用 std::copy()，它位于 <algorithm> 头文件中。

访问 std::initializer_list 的元素

在某些情况下，你可能希望在将 std::initializer_list 的元素复制到内部数组之前访问每个元素（例如，进行合理性检查或以某种方式修改这些值）。

由于某些无法解释的原因，std::initializer_list 不提供通过下标（operator[]）访问列表元素的功能。这个遗漏已经多次向标准委员会提出，但从未得到解决。

然而，有几种简单的变通方法：

  1. 你可以使用基于范围的 for 循环来遍历列表的元素。
  2. 另一种方法是使用 begin() 成员函数获取指向 std::initializer_list的迭代器。由于这个迭代器是随机访问迭代器，迭代器可以被索引：
	IntArray(std::initializer_list<int> list) // 允许 IntArray 通过列表初始化进行初始化
		: IntArray(static_cast<int>(list.size())) // 使用委托构造函数设置初始数组
	{
		// 现在从列表中初始化我们的数组
		for (std::size_t count{}; count < list.size(); ++count)
		{
			m_data[count] = list.begin()[count];
		}
	}

列表初始化优先选择列表构造函数而非非列表构造函数

非空的初始化列表总是优先选择匹配的 initializer_list 构造函数，而不是其他可能匹配的构造函数。考虑：

IntArray a1(5);   // 使用 IntArray(int)，分配一个大小为5的数组
IntArray a2{ 5 }; // 使用 IntArray<std::initializer_list<int>>，分配一个大小为1的数组

浮点类型的 a1 情况使用直接初始化（不考虑列表构造函数），所以这个定义将调用 IntArray(int)，分配一个大小为 5 的数组。

浮点类型的 a2 情况使用列表初始化（优先选择列表构造函数）。这里 IntArray(int) 和 IntArray(std::initializer_list<int>) 都是可能的匹配，但由于列表构造函数优先， IntArray(std::initializer_list<int>) 将被调用，分配一个大小为 1 的数组（该元素的值为 5）

这就是为什么上面的委托构造函数在委托时使用直接初始化：

	IntArray(std::initializer_list<int> list)
		: IntArray(static_cast<int>(list.size())) // 使用直接初始化

这确保我们委托给 IntArray(int) 版本。如果我们改用列表初始化进行委托，构造函数会尝试委托给自身，这将导致编译错误。

同样的情况也发生在 std::vector 和其他同时具有列表构造函数和类似参数类型构造函数的容器类上。

std::vector<int> array(5); // 调用 std::vector::vector(std::vector::size_type)，5个值初始化的元素：0 0 0 0 0
std::vector<int> array{ 5 }; // 调用 std::vector::vector(std::initializer_list<int>)，1个元素：5

关键提示

列表初始化优先选择匹配的列表构造函数，而不是匹配的非列表构造函数。

最佳实践

当初始化一个具有列表构造函数的容器时：

  • 当意图调用列表构造函数时（例如，因为你的初始化器是元素值），使用花括号初始化。
  • 当意图调用非列表构造函数时（例如，因为你的初始化器不是元素值），使用直接初始化。

向现有类添加列表构造函数是危险的

因为列表初始化优先选择列表构造函数，向一个之前没有列表构造函数的现有类添加列表构造函数可能导致现有程序静默改变行为。

考虑以下程序：

#include <initializer_list> // for std::initializer_list
#include <iostream>

class Foo
{
public:
	Foo(int, int)
	{
		std::cout << "Foo(int, int)" << '\n';
	}
};

int main()
{
	Foo f1{ 1, 2 }; // 调用 Foo(int, int)

	return 0;
}

这会打印：

Foo(int, int)

现在让我们向这个类添加一个列表构造函数：

#include <initializer_list> // for std::initializer_list
#include <iostream>

class Foo
{
public:
	Foo(int, int)
	{
		std::cout << "Foo(int, int)" << '\n';
	}

	// 我们添加了一个列表构造函数
	Foo(std::initializer_list<int>)
	{
		std::cout << "Foo(std::initializer_list<int>)" << '\n';
	}

};

int main()
{
	// 注意以下语句没有改变
	Foo f1{ 1, 2 }; // 现在调用 Foo(std::initializer_list<int>)

	return 0;
}

尽管我们没有对程序做其他更改，但这个程序现在输出：

Foo(std::initializer_list<int>)

警告

向一个之前没有列表构造函数的现有类添加列表构造函数可能会破坏现有程序。

使用 std::initializer_list 的类赋值

你也可以通过重载赋值运算符以接受 std::initializer_list 参数，使用 std::initializer_list 为类赋予新值。这与上述类似。我们将在下面的测验解决方案中展示如何做到这一点。

注意，如果你实现了一个接受 std::initializer_list 的构造函数，你应该确保至少执行以下操作之一：

  1. 提供一个重载的列表赋值运算符
  2. 提供一个适当的深拷贝复制赋值运算符
  3. 删除复制赋值运算符

原因如下：考虑以下类（它没有这些中的任何一个），以及一个列表赋值语句：

#include <algorithm> // for std::copy()
#include <cassert>   // for assert()
#include <initializer_list> // for std::initializer_list
#include <iostream>

class IntArray
{
private:
	int m_length{};
	int* m_data{};

public:
	IntArray() = default;

	IntArray(int length)
		: m_length{ length }
		, m_data{ new int[static_cast<std::size_t>(length)] {} }
	{

	}

	IntArray(std::initializer_list<int> list) // 允许 IntArray 通过列表初始化进行初始化
		: IntArray(static_cast<int>(list.size())) // 使用委托构造函数设置初始数组
	{
		// 现在从列表中初始化我们的数组
		std::copy(list.begin(), list.end(), m_data);
	}

	~IntArray()
	{
		delete[] m_data;
	}

//	IntArray(const IntArray&) = delete; // 为了避免浅拷贝
//	IntArray& operator=(const IntArray& list) = delete; // 避免浅拷贝

	int& operator[](int index)
	{
		assert(index >= 0 && index < m_length);
		return m_data[index];
	}

	int getLength() const { return m_length; }
};

int main()
{
	IntArray array{};
	array = { 1, 3, 5, 7, 9, 11 }; // 这是我们的列表赋值语句

	for (int count{ 0 }; count < array.getLength(); ++count)
		std::cout << array[count] << ' '; // 未定义行为

	return 0;
}

首先，编译器会注意到一个接受 std::initializer_list 的赋值函数不存在。接下来它会寻找其他可以使用的赋值函数，并发现隐式提供的复制赋值运算符。然而，这个函数只有在能够将初始化列表转换为 IntArray 时才能使用。因为 { 1, 3, 5, 7, 9, 11 } 是一个 std::initializer_list，编译器将使用列表构造函数将初始化列表转换为一个临时的 IntArray。然后它会调用隐式赋值运算符，该运算符将临时 IntArray 浅拷贝到我们的数组对象中。

此时，临时 IntArray 的 m_data 和 array->m_data 指向同一个地址（由于浅拷贝）。你已经可以看到这将导致什么。

在赋值语句结束时，临时 IntArray 被销毁。这会调用析构函数，删除临时 IntArray 的 m_data。这使得 array->m_data 成为一个悬空指针。当你尝试使用 array->m_data 进行任何操作时（包括当 array 离开作用域且析构函数要删除 m_data 时），你将得到未定义行为。

最佳实践

如果你提供了列表构造，最好也提供列表赋值。

总结

实现一个接受 std::initializer_list 参数的构造函数允许我们使用列表初始化自定义类。我们也可以使用 std::initializer_list 来实现其他需要使用初始化列表的函数，例如赋值运算符。

小测验时间

问题 #1

使用上面的 IntArray 类，实现一个接受初始化列表的重载赋值运算符。

以下代码应该能运行：

int main()
{
	IntArray array { 5, 4, 3, 2, 1 }; // 初始化列表
	for (int count{ 0 }; count < array.getLength(); ++count)
		std::cout << array[count] << ' ';

	std::cout << '\n';

	array = { 1, 3, 5, 7, 9, 11 };

	for (int count{ 0 }; count < array.getLength(); ++count)
		std::cout << array[count] << ' ';

	std::cout << '\n';

	return 0;
}

这应打印：

5 4 3 2 1 
1 3 5 7 9 11

显示答案

#include <algorithm> // for std::copy()
#include <cassert>   // for assert()
#include <initializer_list> // for std::initializer_list
#include <iostream>

class IntArray
{
private:
	int m_length {};
	int* m_data {};

public:
	IntArray() = default;

	IntArray(int length)
		: m_length{ length }
		, m_data{ new int[static_cast<std::size_t>(length)] {} }
	{

	}

	IntArray(std::initializer_list<int> list) : // 允许 IntArray 通过列表初始化进行初始化
		IntArray(static_cast<int>(list.size())) // 使用委托构造函数设置初始数组
	{
		// 现在从列表中初始化我们的数组
		std::copy(list.begin(), list.end(), m_data);
	}

	~IntArray()
	{
		delete[] m_data;
		// 我们不需要在此处将 m_data 设置为 null 或将 m_length 设置为 0，因为该函数执行后对象将立即被销毁
	}

	IntArray(const IntArray&) = delete; // 为了避免浅拷贝
	IntArray& operator=(const IntArray& list) = delete; // 为了避免浅拷贝

	IntArray& operator=(std::initializer_list<int> list)
	{
		// 如果新列表大小不同，则重新分配
		int length { static_cast<int>(list.size()) };
		if (length != m_length)
		{
			delete[] m_data;
			m_length = length;
			m_data = new int[list.size()]{};
		}

		// 现在从列表中初始化我们的数组
		std::copy(list.begin(), list.end(), m_data);

		return *this;
	}

	int& operator[](int index)
	{
		assert(index >= 0 && index < m_length);
		return m_data[index];
	}

	int getLength() const { return m_length; }
};

int main()
{
	IntArray array { 5, 4, 3, 2, 1 }; // 初始化列表
	for (int count{ 0 }; count < array.getLength(); ++count)
		std::cout << array[count] << ' ';

	std::cout << '\n';

	array = { 1, 3, 5, 7, 9, 11 };

	for (int count{ 0 }; count < array.getLength(); ++count)
		std::cout << array[count] << ' ';

	std::cout << '\n';

	return 0;
}
