16.3 — std::vector 与无符号长度和下标问题

● 机器译文 课程 16.3 查看英文原文

在上一课中 16.2 -- std::vector 与列表构造函数简介中，我们介绍了 operator[]，可用于对数组进行下标操作以访问元素。

在本课中，我们将探讨访问数组元素的其他方式，以及获取容器类长度（当前容器类中的元素数量）的几种不同方法。

但在那之前，我们需要讨论 C++ 设计者犯下的一个重大错误，以及它如何影响 C++ 标准库中的所有容器类。

容器长度符号问题

让我们从一个断言开始：用于对数组进行下标操作的数据类型应与用于存储数组长度的数据类型匹配。这样，最长可能数组中的所有元素都可以被索引，且不会超出范围。

正如 Bjarne Stroustrup 回忆，当 C++ 标准库中的容器类被设计时（大约 1997 年），设计者必须选择使长度（和数组下标）有符号还是无符号。他们选择了无符号。

给出的理由：标准库数组类型的下标不能为负，使用无符号类型允许数组具有更大的长度（由于额外的位，这在 16 位时代很重要），并且下标范围检查只需要一个条件检查而不是两个（因为不需要检查索引是否小于 0）。

事后看来，这通常被认为是错误的选择。我们现在理解，使用无符号值试图强制非负性由于隐式转换规则而无效（因为负的有符号整数只会隐式转换为大的无符号整数，产生垃圾结果），额外的位范围在 32 位或 64 位系统上通常不需要（因为你可能不会创建超过 20 亿个元素的数组），并且常用的 operator[] 无论如何都不进行范围检查。

在课程 4.5 -- 无符号整数，以及为什么要避免使用它们，我们讨论了为什么我们更喜欢使用有符号值来保存数量。我们还指出，混合有符号和无符号值是意外行为的根源。因此，标准库容器类使用无符号值表示长度（和索引）是有问题的，因为它使得在使用这些类型时无法避免无符号值。

目前，我们只能接受这个选择及其带来的不必要的复杂性。

回顾：符号转换是窄化转换，除非是 constexpr

在进一步讨论之前，让我们快速回顾一下课程 10.4 -- 窄化转换、列表初始化和 constexpr 初始化器 中关于符号转换（从有符号到无符号或反之的整数转换）的内容，因为我们在本章中会经常讨论这些。

符号转换被认为是窄化转换，因为有符号或无符号类型无法保存对立类型范围内的所有值。当这种转换在运行时执行时，编译器会在禁止窄化转换的上下文中（例如列表初始化）发出错误，并在执行此类转换的其他上下文中可能发出也可能不发出警告。

例如：

#include <iostream>

void foo(unsigned int)
{
}

int main()
{
    int s { 5 };
    
    [[maybe_unused]] unsigned int u { s }; // 编译错误：列表初始化禁止窄化转换
    foo(s);                                // 可能警告：拷贝初始化允许窄化转换

    return 0;
}

在上面的例子中，变量 u 的初始化产生编译错误，因为列表初始化禁止窄化转换。对 foo() 的调用执行复制初始化，它允许窄化转换，并且根据编译器产生符号转换警告的激进程度，可能会也可能不会产生警告。例如，当使用编译器标志 -Wsign-conversion 时，GCC 和 Clang 都会在这种情况下产生警告。

然而，如果要进行符号转换的值是 constexpr 并且可以转换为对立类型中的等效值，则符号转换 不是 不被认为是窄化的。这是因为编译器可以保证转换是安全的，或者停止编译过程。

#include <iostream>

void foo(unsigned int)
{
}

int main()
{
    constexpr int s { 5 };                 // 现在是 constexpr
    [[maybe_unused]] unsigned int u { s }; // ok：s 是 constexpr，可以安全转换，不是窄化转换
    foo(s);                                // ok：s 是 constexpr，可以安全转换，不是窄化转换

    return 0;
}

在这种情况下，由于 s 是 constexpr 并且要转换的值（5）可以表示为无符号值，因此该转换不被认为是窄化的，可以隐式执行而不会出现问题。

这种非窄化的 constexpr 转换（从 constexpr int 切换到 constexpr std::size_t）将是我们要大量使用的东西。

的长度和索引具有类型 std::vector ，我们提到 typedef 和类型别名通常用于需要为可能变化的类型（例如，因为它是实现定义的）提供名称的情况。例如 size_type

在课程 10.7课——Typedefs和类型别名是某个大无符号整数类型的 typedef，通常是 std::size_t unsigned long 或 unsigned long long。

每个标准库容器类都定义了一个名为 size_type （有时写作 T::size_type）的嵌套 typedef 成员，它是用于容器长度（和索引，如果支持）的类型的别名。

你通常会在文档和编译器警告/错误消息中看到 size_type 例如，这个 文档中 size() 成员函数 作为 std::vector 表示 size() 返回一个 size_type。

相关内容

我们在课程中介绍了嵌套的 typedef 15.3 -- 嵌套类型（成员类型）。

size_type 几乎总是 std::size_t的别名，但可以（在罕见情况下）被覆盖以使用不同的类型。

关键提示

size_type 是标准库容器类中定义的一个嵌套 typedef，用作容器类的长度（以及索引，如果支持）的类型。

size_type 默认为 std::size_t，并且由于这几乎从不更改，我们可以合理地假设 size_type 是 std::size_t。

进阶读者

所有标准库容器除了 std::array 都使用 std::allocator 来分配内存。对于这些容器， T::size_type 派生自所使用的分配器的 size_type 由于 std::allocator 最多可以分配 std::size_t 字节的内存， std::allocator<T>::size_type 定义为 std::size_t。因此， T::size_type 默认为 std::size_t。

只有在自定义分配器的 T::size_type 被定义为不同于 std::size_t 的情况下，容器的 T::size_type 才会是不同于 std::size_t的值。这种情况很少见，并且是在每个应用程序的基础上完成的，因此通常可以安全地假设 T::size_type 推导出的类型将是 std::size_t ，除非你的应用程序使用了这样的自定义分配器（你会知道是否是这种情况）。

当访问容器类的 size_type 成员时，我们必须使用容器类的完全模板化名称进行作用域限定。例如， std::vector<int>::size_type。

获取 std::vector 对象，使用 size() 成员函数或 std::size()

我们可以使用 size() 成员函数询问容器类对象的长度（该函数返回无符号 size_type)：

#include <iostream>
#include <vector>

int main()
{
    std::vector prime { 2, 3, 5, 7, 11 };
    std::cout << "length: " << prime.size() << '\n'; // 返回类型为 `size_type`（`std::size_t` 的别名）的长度
    return 0;
}

这会打印：

length: 5

与 std::string 和 std::string_view不同，它们既有 length() ，我们需要几个辅助对象（一个 size() 成员函数（做相同的事情）， std::vector （以及 C++ 中大多数其他容器类型）只有 size()。现在你明白了为什么容器的长度有时被含糊地称为其大小。

在 C++17 中，我们还可以使用 std::size() 非成员函数（对于容器类，它只是调用 size() 成员函数）。

#include <iostream>
#include <vector>

int main()
{
    std::vector prime { 2, 3, 5, 7, 11 };
    std::cout << "length: " << std::size(prime); // C++17，返回类型为 `size_type`（`std::size_t` 的别名）的长度

    return 0;
}

进阶读者

因为 std::size() 也可以用于未退化的 C 风格数组，因此这种方法有时比使用 size() 成员函数更受青睐（特别是在编写可以接受容器类或未退化的 C 风格数组参数的函数模板时）。

我们在课程中讨论了 C 风格数组退化 17.8 -- C 风格数组退化。

如果我们想使用上述任一方法将长度存储在有符号类型的变量中，这很可能会导致有符号/无符号转换警告或错误。这里最简单的方法是将结果 static_cast 到所需的类型：

#include <iostream>
#include <vector>

int main()
{
    std::vector prime { 2, 3, 5, 7, 11 };
    int length { static_cast<int>(prime.size()) }; // 将返回值 static_cast 为 int
    std::cout << "length: " << length ;

    return 0;
}

获取 std::vector using std::ssize() C++20

C++20 引入了 std::ssize() 非成员函数，它返回长度作为一个大的 有符号 整型（通常 std::ptrdiff_t，这是通常用作有符号对应类型的类型 std::size_t)：

#include <iostream>
#include <vector>

int main()
{
    std::vector prime{ 2, 3, 5, 7, 11 };
    std::cout << "length: " << std::ssize(prime); // C++20，返回一个大符号整数类型的长度

    return 0;
}

这是三个函数中唯一一个返回有符号类型长度的函数。

如果你想用这个方法将长度存储到有符号类型的变量中，你有几个选择。

首先，因为 int 类型可能比 std::ssize()返回的有符号类型更小，如果你要将长度赋值给一个 int 变量，你应该将结果 static_cast 为 int 以明确任何此类转换（否则你可能会收到窄化转换警告或错误）：

#include <iostream>
#include <vector>

int main()
{
    std::vector prime{ 2, 3, 5, 7, 11 };
    int length { static_cast<int>(std::ssize(prime)) }; // 将返回值 static_cast 为 int
    std::cout << "length: " << length;

    return 0;
}

或者，你可以使用 auto 让编译器推导出用于变量的正确有符号类型：

#include <iostream>
#include <vector>

int main()
{
    std::vector prime{ 2, 3, 5, 7, 11 };
    auto length { std::ssize(prime) }; // 使用 auto 推导有符号类型，如 std::ssize() 返回
    std::cout << "length: " << length;

    return 0;
}

使用 operator[] 访问数组元素不进行边界检查

在之前的课程中，我们介绍了下标运算符（operator[])：

#include <iostream>
#include <vector>

int main()
{
    std::vector prime{ 2, 3, 5, 7, 11 };

    std::cout << prime[3];  // 打印索引为 3 的元素的值 (7)
    std::cout << prime[9]; // 无效索引（未定义行为）

    return 0;
}

operator[] 不进行边界检查。operator[] 的索引可以是非常量。我们将在后面的章节中进一步讨论这一点。

使用 at() 成员函数访问数组元素会进行运行时边界检查

数组容器类支持另一种访问数组的方法。 at() 成员函数可用于进行带运行时边界检查的数组访问：

#include <iostream>
#include <vector>

int main()
{
    std::vector prime{ 2, 3, 5, 7, 11 };

    std::cout << prime.at(3); // 打印索引为 3 的元素的值
    std::cout << prime.at(9); // 无效索引（抛出异常）

    return 0;
}

在上面的例子中，调用 prime.at(3) 检查索引 3 是否有效，由于有效，它返回对数组元素 3 的引用。然后我们可以打印这个值。然而，调用 prime.at(9) 失败（在运行时），因为 9 不是该数组的有效索引。 at() 函数不会返回引用，而是生成一个错误并终止程序。

当 at() 成员函数遇到越界索引时，实际上会抛出一个类型为 std::out_of_range的异常。如果异常未被处理，程序将被终止。我们在 第 27 章。

更常用，主要是因为最好在索引之前进行边界检查，这样我们一开始就不会尝试使用无效索引。 std::vector 使用 constexpr 有符号 int 索引

当使用 constexpr（有符号）int 索引 std::vector 时，我们可以让编译器将其隐式转换为 std::size_t ，而不会被视为窄化转换：

#include <iostream>
#include <vector>

int main()
{
    std::vector prime{ 2, 3, 5, 7, 11 };

    std::cout << prime[3] << '\n';     // okay: 3 从 int 转换为 std::size_t，不是窄化转换
 
    constexpr int index { 3 };         // constexpr
    std::cout << prime[index] << '\n'; // okay: constexpr 索引隐式转换为 std::size_t，不是窄化转换
   
    return 0;
}

更常用，主要是因为最好在索引之前进行边界检查，这样我们一开始就不会尝试使用无效索引。 std::vector 使用非常量值索引

用于索引数组的下标可以是非常量：

#include <iostream>
#include <vector>

int main()
{
    std::vector prime{ 2, 3, 5, 7, 11 };

    std::size_t index { 3 };           // 非 constexpr
    std::cout << prime[index] << '\n'; // operator[] 期望 std::size_t 类型的索引，无需转换
   
    return 0;
}

然而，根据我们的最佳实践（4.5 -- 无符号整数，以及为什么要避免使用它们），我们通常希望避免使用无符号类型来保存数量。

当下标是非常量表达式的有符号值时，我们会遇到问题：

#include <iostream>
#include <vector>

int main()
{
    std::vector prime{ 2, 3, 5, 7, 11 };

    int index { 3 };                   // 非 constexpr
    std::cout << prime[index] << '\n'; // 可能的警告：索引隐式转换为 std::size_t，窄化转换
   
    return 0;
}

在这个例子中， index 是非常量表达式的有符号 int。 operator[] 的下标定义为 std::vector 的类型为 size_type （ std::size_t的别名）。因此，当我们调用 prime[index]时，我们的有符号 int 必须转换为 std::size_t。

这种转换本不应危险（因为 std::vector 的索引预期为非负，非负有符号值可以安全转换为无符号值）。但在运行时执行时，这被视为窄化转换，编译器应产生关于此不安全转换的警告（如果没有，应考虑修改警告设置以使其产生）。

由于数组下标操作很常见，每次这样的转换都会产生警告，这很容易用虚假警告弄乱编译日志。或者，如果启用了“将警告视为错误”，则会停止编译。

有许多可能的方法来避免这个问题（例如，每次索引数组时 static_cast 你的 int 转换为 std::size_t ），但所有方法最终都会以某种方式使代码变得杂乱或复杂。在这种情况下，最简单的方法是使用 std::size_t 类型的变量作为索引，并且只将此变量用于索引。这样，你从一开始就避免了任何非常量表达式的转换。

提示

另一个好的替代方案是，不直接索引 std::vector 本身，而是索引 data() 成员函数的结果：

#include <iostream>
#include <vector>

int main()
{
    std::vector prime{ 2, 3, 5, 7, 11 };

    int index { 3 };                          // 非 constexpr 有符号值
    std::cout << prime.data()[index] << '\n'; // okay：无符号转换警告
   
    return 0;
}

在底层， std::vector 将其元素保存在 C 风格数组中。 data() 成员函数返回指向此底层 C 风格数组的指针，然后我们可以对其进行索引。由于 C 风格数组允许使用有符号和无符号类型进行索引，我们不会遇到符号转换问题。我们将在课程中进一步讨论 C 风格数组 17.7 -- C风格数组简介 和 17.8 -- C 风格数组退化。

问题 #1

初始化一个 std::vector ，其值为：'h', 'e', 'l', 'l', 'o'。然后打印数组的长度（使用 std::size()）。最后，使用下标运算符和 at() 成员函数。

程序应输出以下内容：

The array has 5 elements.
ee

显示答案

#include <iostream>
#include <vector>

int main()
{
    std::vector arr { 'h', 'e', 'l', 'l', 'o' };
    std::cout << "The array has " << std::size(arr) << " elements.\n";
    std::cout << arr[1] << arr.at(1) << '\n';

    return 0;
}

问题 #2

a) 什么是 size_type ，它有什么用途？

显示答案

size_type 是一个嵌套类型定义，是用于存储标准库容器长度（以及索引，如果支持）的类型的别名。

b) size_type 默认是什么类型？是有符号还是无符号？

显示答案

std::size_t，这是一个无符号类型。

c) 哪些获取容器长度的函数返回 size_type？

显示答案

浮点类型的 size() 成员函数和 std::size 都返回 size_type。
