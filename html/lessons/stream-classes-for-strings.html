28.4 — 字符串流类

● 机器译文 课程 28.4 查看英文原文

到目前为止，你看到的所有 I/O 示例都是写入 cout 或从 cin 读取。然而，还有另一组称为字符串流类的类，它们允许你使用熟悉的插入（<<）和提取（>>）运算符来处理字符串。与 istream 和 ostream 类似，字符串流提供了一个缓冲区来保存数据。但与 cin 和 cout 不同，这些流没有连接到 I/O 通道（如键盘、显示器等）。字符串流的主要用途之一是缓冲输出以便稍后显示，或者逐行处理输入。

有六个字符串流类：istringstream（派生自 istream）、ostringstream（派生自 ostream）和 stringstream（派生自 iostream）用于读写普通字符宽度的字符串。wistringstream、wostringstream 和 wstringstream 用于读写宽字符字符串。要使用字符串流，你需要 #include <sstream> 头文件。

有两种方法可以将数据放入字符串流：

  1. 使用插入（<<）运算符：
std::stringstream os {};
os << "en garde!\n"; // 将 "en garde!" 插入字符串流
  1. 使用 str(string) 函数设置缓冲区的值：
std::stringstream os {};
os.str("en garde!"); // 将字符串流缓冲区设置为 "en garde!"

同样有两种方法可以从字符串流中取出数据：

  1. 使用 str() 函数检索缓冲区的结果：
std::stringstream os {};
os << "12345 67.89\n";
std::cout << os.str();

这会打印：

12345 67.89
  1. 使用提取（>>）运算符：
std::stringstream os {};
os << "12345 67.89"; // 将一串数字插入流中

std::string strValue {};
os >> strValue;

std::string strValue2 {};
os >> strValue2;

// 用破折号分隔打印数字
std::cout << strValue << " - " << strValue2 << '\n';

该程序打印出：

12345 - 67.89

注意，>> 运算符会遍历字符串——每次连续使用 >> 都会返回流中下一个可提取的值。另一方面，str() 返回流的整个值，即使 >> 已经在流上使用过。

字符串与数字之间的转换

由于插入和提取运算符知道如何处理所有基本数据类型，我们可以使用它们将字符串转换为数字，反之亦然。

首先，让我们看看如何将数字转换为字符串：

std::stringstream os {};

constexpr int nValue { 12345 };
constexpr double dValue { 67.89 };
os << nValue << ' ' << dValue;

std::string strValue1, strValue2;
os >> strValue1 >> strValue2;

std::cout << strValue1 << ' ' << strValue2 << '\n';

这段代码输出：

12345 67.89

现在让我们将数字字符串转换为数字：

std::stringstream os {};
os << "12345 67.89"; // 将一串数字插入流中
int nValue {};
double dValue {};

os >> nValue >> dValue;

std::cout << nValue << ' ' << dValue << '\n';

该程序打印出：

12345 67.89

清空字符串流以便重用

有几种方法可以清空字符串流的缓冲区。

  1. 使用 str() 并传入空 C 风格字符串将其设置为空字符串：
std::stringstream os {};
os << "Hello ";

os.str(""); // 清空缓冲区

os << "World!";
std::cout << os.str();
  1. 使用 str() 并传入空的 std::string 对象将其设置为空字符串：
std::stringstream os {};
os << "Hello ";

os.str(std::string{}); // 清空缓冲区

os << "World!";
std::cout << os.str();

这两个程序都产生以下结果：

World!

在清空字符串流时，通常也建议调用 clear() 函数：

std::stringstream os {};
os << "Hello ";

os.str(""); // 清空缓冲区
os.clear(); // 重置错误标志

os << "World!";
std::cout << os.str();

clear() 重置可能已设置的任何错误标志，并将流返回到正常状态。我们将在下一课中详细讨论流状态和错误标志。
