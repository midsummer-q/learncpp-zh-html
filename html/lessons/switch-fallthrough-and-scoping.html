8.6 — Switch 的穿透与作用域

● 机器译文 课程 8.6 查看英文原文

本课继续我们在上一课中开始的 switch 语句的探索。 8.5 -- Switch语句基础在上一课中，我们提到每个标签下的语句集应该以 break statement 变为 return statement。

在本课中，我们将探讨原因，并讨论一些有时会困扰新程序员的 switch 作用域问题。

穿透

当 switch 表达式匹配某个 case 标签或可选的 default 标签时，执行从匹配标签后的第一条语句开始。然后执行将顺序继续，直到满足以下终止条件之一：

  • 到达 switch 块的末尾。
  • 另一个控制流语句（通常是 break 或 return）导致 switch 块或函数退出。
  • 其他中断程序正常流程的情况（例如操作系统关闭程序、宇宙坍缩等……）

注意，另一个 case 标签的存在 不是 不是这些终止条件之一——因此，如果没有 break 或 return，执行将溢出到后续的 case。

下面是一个展示此行为的程序：

#include <iostream>

int main()
{
    switch (2)
    {
    case 1: // 不匹配
        std::cout << 1 << '\n'; // 跳过
    case 2: // 匹配！
        std::cout << 2 << '\n'; // 执行从这里开始
    case 3:
        std::cout << 3 << '\n'; // 这也被执行
    case 4:
        std::cout << 4 << '\n'; // 这也被执行
    default:
        std::cout << 5 << '\n'; // 这也被执行
    }

    return 0;
}

该程序输出以下内容：

2
3
4
5

这可能不是我们想要的！当执行从一个标签下的语句流到后续标签下的语句时，这被称为 穿透。

警告

一旦 case 或 default 标签下的语句开始执行，它们将溢出（穿透）到后续的 case。通常使用 break 或 return 语句来防止这种情况。

由于穿透很少是期望的或故意的，许多编译器和代码分析工具会将穿透标记为警告。

[[fallthrough]] 属性

注释有意的穿透是一种常见的约定，告诉其他开发者穿透是故意的。虽然这对其他开发者有效，但编译器和代码分析工具不知道如何解释注释，因此它不会消除警告。

为了解决这个问题，C++17 添加了一个名为 [[fallthrough]]。

的新属性。 属性是现代 C++ 的一个特性，允许程序员向编译器提供一些关于代码的额外数据。要指定一个属性，属性名放在双括号之间。属性不是语句——相反，它们几乎可以在任何上下文相关的地方使用。

浮点类型的 [[fallthrough]] 属性修改一个 null statement 以指示穿透是故意的（并且不应触发警告）：

#include <iostream>

int main()
{
    switch (2)
    {
    case 1:
        std::cout << 1 << '\n';
        break;
    case 2:
        std::cout << 2 << '\n'; // 执行从这里开始
        [[fallthrough]]; // 故意穿透 -- 注意分号表示空语句
    case 3:
        std::cout << 3 << '\n'; // 这也被执行
        break;
    }

    return 0;
}

该程序打印出：

2
3

并且它不应生成任何关于穿透的警告。

最佳实践

使用 [[fallthrough]] 属性（以及一个空语句）来指示有意的穿透。

顺序 case 标签

你可以使用逻辑或运算符将多个测试组合成一个语句：

bool isVowel(char c)
{
    return (c=='a' || c=='e' || c=='i' || c=='o' || c=='u' ||
        c=='A' || c=='E' || c=='I' || c=='O' || c=='U');
}

这存在我们在 switch 语句介绍中提出的相同挑战： c 被多次求值，读者必须确保每次求值的是 c

你可以通过将多个 case 标签按顺序放置来使用 switch 语句实现类似功能：

bool isVowel(char c)
{
    switch (c)
    {
    case 'a': // 如果 c 是 'a'
    case 'e': // 或如果 c 是 'e'
    case 'i': // 或如果 c 是 'i'
    case 'o': // 或如果 c 是 'o'
    case 'u': // 或如果 c 是 'u'
    case 'A': // 或如果 c 是 'A'
    case 'E': // 或如果 c 是 'E'
    case 'I': // 或如果 c 是 'I'
    case 'O': // 或如果 c 是 'O'
    case 'U': // 或如果 c 是 'U'
        return true;
    default:
        return false;
    }
}

记住，执行从匹配的 case 标签后的第一条语句开始。Case 标签不是语句（它们是标签），所以它们不计入。

上述程序中所有 case 语句后的第一条语句是 所有 ，所以如果任何 case 标签匹配，函数将返回 return true。 true。

因此，我们可以“堆叠”case 标签，使所有这些 case 标签共享后面相同的语句集。这不被视为穿透行为，因此不需要使用注释或 [[fallthrough]]

标签不定义新作用域

使用 if statements时，if 条件后只能有一条语句，且该语句被视为隐式位于一个块内：

if (x > 10)
    std::cout << x << " is greater than 10\n"; // 这一行隐式被视为位于一个块内

然而，对于 switch 语句，标签后的所有语句都作用域于 switch 块。不会创建隐式块。

switch (1)
{
case 1: // 不创建隐式块
    foo(); // 这是 switch 作用域的一部分，而不是 case 1 的隐式块
    break; // 这是 switch 作用域的一部分，而不是 case 1 的隐式块
default:
    std::cout << "default case\n";
    break;
}

在上例中， case 1 和 default 标签之间的两条语句作用域为 switch 块的一部分，而不是 case 1。

的隐式块。

你可以在 switch 内部声明或定义（但不能初始化）变量，既可以在 case 标签之前，也可以在之后：

switch (1)
{
    int a; // 允许：在 case 标签之前允许定义
    int b{ 5 }; // 非法：在 case 标签之前不允许初始化

case 1:
    int y; // 可以但不好：在 case 内允许定义
    y = 4; // 可以：允许赋值
    break;

case 2:
    int z{ 4 }; // 非法：如果存在后续 case，则不允许初始化
    y = 5; // 可以：y 已在上面声明，所以这里也可以使用它
    break;

case 3:
    break;
}

尽管变量 y 定义在 case 1中，但它也在 case 2 中被使用。switch 内的所有语句都被视为同一作用域的一部分。因此，在一个 case 中声明或定义的变量可以在后续的 case 中使用，即使定义该变量的 case 从未执行（因为 switch 跳过了它）！

然而，变量的初始化 确实 需要定义被执行。变量的初始化在非最后一个 case 中是不允许的（因为如果后续有 case 定义，switch 可能跳过初始化器，此时变量将是未定义的，访问它会导致未定义行为）。在第一个 case 之前也不允许初始化，因为这些语句永远不会被执行，因为 switch 无法到达它们。

如果某个 case 需要定义和/或初始化一个新变量，最佳实践是在 case 语句下的显式块内进行：

switch (1)
{
case 1:
{ // 注意这里添加了显式块
    int x{ 4 }; // 可以，变量可以在 case 内的块中初始化
    std::cout << x;
    break;
}

default:
    std::cout << "default case\n";
    break;
}

最佳实践

如果在 case 语句中定义变量，请在 case 内的块中进行。

小测验时间

问题 #1

编写一个名为 calculate() 的函数，它接受两个整数和一个表示以下数学运算之一的字符：+、-、*、/ 或 %（取余）。使用 switch 语句对整数执行相应的数学运算，并返回结果。如果向函数传递了无效运算符，函数应打印一条错误消息。对于除法运算符，执行整数除法，不必担心除以零的情况。

提示：“operator”是一个关键字，变量不能命名为“operator”。

显示答案

#include <iostream>

int calculate(int x, int y, char op)
{
    switch (op)
    {
    case '+':
        return x + y;
    case '-':
        return x - y;
    case '*':
        return x * y;
    case '/':
        return x / y;
    case '%':
        return x % y;
    default:
        std::cout << "calculate(): Unhandled case\n";
        return 0;
    }
}

int main()
{
    std::cout << "Enter an integer: ";
    int x{};
    std::cin >> x;

    std::cout << "Enter another integer: ";
    int y{};
    std::cin >> y;

    std::cout << "Enter a mathematical operator (+, -, *, /, or %): ";
    char op{};
    std::cin >> op;

    // 我们将先调用 calculate，以便无效运算符在其自己的行上打印错误消息
    int result{ calculate(x, y, op) };
    std::cout << x << ' ' << op << ' ' << y << " is " << result << '\n';

    return 0;
}
