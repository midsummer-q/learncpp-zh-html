8.5 — Switch 语句基础

● 机器译文 课程 8.5 查看英文原文

虽然可以将许多 if-else 语句串联起来，但这既难以阅读又效率低下。考虑以下程序：

#include <iostream>

void printDigitName(int x)
{
    if (x == 1)
        std::cout << "One";
    else if (x == 2)
        std::cout << "Two";
    else if (x == 3)
        std::cout << "Three";
    else
        std::cout << "Unknown";
}

int main()
{
    printDigitName(2);
    std::cout << '\n';

    return 0;
}

变量 x 在 printDigitName() 根据传入的值最多会被求值三次（这效率低下），并且读者必须确保每次求值的是同一个变量（而不是其他变量）。 x 根据传入的值最多会被求值三次（这效率低下），并且读者必须确保每次求值的是同一个变量（而不是其他变量）。

由于针对一组不同的值测试变量或表达式的相等性很常见，C++ 提供了一种替代的条件语句，称为 switch 语句，专门用于此目的。以下是使用 switch 的相同程序：

#include <iostream>

void printDigitName(int x)
{
    switch (x)
    {
    case 1:
        std::cout << "One";
        return;
    case 2:
        std::cout << "Two";
        return;
    case 3:
        std::cout << "Three";
        return;
    default:
        std::cout << "Unknown";
        return;
    }
}

int main()
{
    printDigitName(2);
    std::cout << '\n';

    return 0;
}

switch 语句的思想很简单： switch 语句 的思想很简单：一个表达式（有时称为条件）被求值以产生一个值。

然后发生以下情况之一：

  • 如果表达式的值等于某个 case 标签后的值，则执行匹配的 case 标签后的语句。
  • 如果找不到匹配的值且存在 default 标签，则执行 default 标签后的语句。
  • 如果找不到匹配的值且没有 default 标签，则跳过 switch。

让我们更详细地检查这些概念。

开始一个 switch

我们通过使用 switch 关键字开始一个 switch 语句，后面跟着括号，括号内是我们想要求值的条件表达式。通常表达式只是一个变量，但可以是任何有效的表达式。 switch 我们通过使用 switch 关键字开始一个 switch 语句，后面跟着括号，括号内是我们想要求值的条件表达式。通常表达式只是一个变量，但可以是任何有效的表达式。

switch 中的条件必须求值为整型（参见课程 4.1 -- 基本数据类型简介 如果你需要提醒哪些基本类型被认为是整型）或枚举类型（在未来的课程中介绍 13.2 -- 无作用域枚举 和 13.6 -- 作用域枚举（enum class）），或者可转换为这些类型。求值为浮点类型、字符串和大多数其他非整型的表达式不能在此使用。

进阶读者

为什么 switch 类型只允许整型（或枚举）类型？答案是因为 switch 语句被设计为高度优化。历史上，编译器实现 switch 语句最常见的方式是通过 跳转表 ——而跳转表只适用于整型值。

对于已经熟悉数组的人来说，跳转表的工作方式类似于数组，整型值被用作数组索引来“跳转”到结果。这比进行一系列顺序比较要高效得多。

当然，编译器不必使用跳转表来实现 switch，有时它们也不会。从技术上讲，C++ 没有理由不能放宽限制，以便其他类型也可以使用，只是他们还没有这样做（截至 C++23）。

在条件表达式之后，我们声明一个块。在块内部，我们使用标签来定义所有我们想要测试相等性的值。switch 语句使用两种标签，我们将在后面讨论。

Case 标签

第一种标签是 case 标签，使用 case 关键字声明，后跟一个常量表达式。常量表达式必须与条件的类型匹配，或者可转换为该类型。 case ，使用 case 关键字声明，后跟一个常量表达式。常量表达式必须与条件的类型匹配，或者可转换为该类型。

如果条件表达式的值等于 case 后的表达式，则从该 case 后的第一个语句开始执行， case label如果条件表达式的值等于 case 后的表达式，则从该 case 后的第一个语句开始执行， case label 然后继续顺序执行。

以下是一个条件匹配 case 的例子： case label：

#include <iostream>

void printDigitName(int x)
{
    switch (x) // x 被求值得到值 2
    {
    case 1:
        std::cout << "One";
        return;
    case 2: // 匹配此处的 case 语句
        std::cout << "Two"; // 因此执行从这里开始
        return; // 然后返回调用者
    case 3:
        std::cout << "Three";
        return;
    default:
        std::cout << "Unknown";
        return;
    }
}

int main()
{
    printDigitName(2);
    std::cout << '\n';

    return 0;
}

这段代码打印：

Two

在上面的程序中， x 被求值产生值 2。因为有一个值为 2 的 case 标签， 2执行跳转到该匹配 case 标签下的语句。程序打印 Two，然后 return statement 被执行，然后返回到调用者。

case标签的数量没有实际限制，但switch中的所有case标签必须是唯一的。也就是说，你不能这样做：

switch (x)
{
case 54:
case 54:  // 错误：已使用值 54！
case '6': // 错误：'6' 转换为整数值 54，该值已被使用
}

如果条件表达式不匹配任何case标签，则不会执行任何case。我们稍后会展示一个例子。

default标签

第二种标签是 default标签 （通常称为 default case），使用 default 关键字声明。如果条件表达式不匹配任何case标签且存在default标签，则从default标签后的第一条语句开始执行。

下面是一个条件匹配default标签的例子：

#include <iostream>

void printDigitName(int x)
{
    switch (x) // x 被求值得到值 5
    {
    case 1:
        std::cout << "One";
        return;
    case 2:
        std::cout << "Two";
        return;
    case 3:
        std::cout << "Three";
        return;
    default: // 不匹配任何 case 标签
        std::cout << "Unknown"; // 因此执行从这里开始
        return; // 然后返回调用者
    }
}

int main()
{
    printDigitName(5);
    std::cout << '\n';

    return 0;
}

这段代码打印：

Unknown

default标签是可选的，每个switch语句中只能有一个default标签。按照惯例，default case放在switch块的末尾。

最佳实践

将default case放在switch块的末尾。

没有匹配的case标签且没有default case

如果条件表达式的值不匹配任何case标签，并且没有提供default case，则不会执行switch内的任何case。执行继续从switch块之后开始。

#include <iostream>

void printDigitName(int x)
{
    switch (x) // x 被求值得到值 5
    {
    case 1:
        std::cout << "One";
        return;
    case 2:
        std::cout << "Two";
        return;
    case 3:
        std::cout << "Three";
        return;
    // 没有匹配的 case 且没有 default case
    }

    // 因此执行从这里继续
    std::cout << "Hello";
}

int main()
{
    printDigitName(5);
    std::cout << '\n';

    return 0;
}

在上面的例子中， x 求值为 5，但没有匹配 5的case标签，也没有default case。因此，没有case被执行。执行继续从switch块之后开始，打印 Hello。

Taking a break

在上面的例子中，我们使用了return语句来停止标签后语句的执行。然而，这也会退出整个函数。

一个 break语句 （使用 break 关键字声明）告诉编译器我们已经完成了switch内语句的执行，执行应该从switch块之后的语句继续。这允许我们退出switch语句而不退出整个函数。

下面是一个稍作修改的例子，使用 break 而不是 return：

#include <iostream>

void printDigitName(int x)
{
    switch (x) // x 求值为 3
    {
    case 1:
        std::cout << "One";
        break;
    case 2:
        std::cout << "Two";
        break;
    case 3:
        std::cout << "Three"; // 执行从这里开始
        break; // 跳转到 switch 块的末尾
    default:
        std::cout << "Unknown";
        break;
    }

    // 执行从这里继续
    std::cout << " Ah-Ah-Ah!";
}

int main()
{
    printDigitName(3);
    std::cout << '\n';

    return 0;
}

上面的示例输出：

Three Ah-Ah-Ah!

最佳实践

每个标签下的语句集应以break语句或return语句结束。这包括switch中最后一个标签下的语句。

那么，如果你没有用 break 或 return结束标签下的语句集，会发生什么？我们将在下一课中探讨这个主题以及其他内容。

标签通常不缩进

在课程 2.9 -- 命名冲突和命名空间简介，我们注意到代码通常缩进一级以帮助识别它是嵌套作用域区域的一部分。由于switch的花括号定义了一个新的作用域区域，我们通常会将花括号内的所有内容缩进一级。

另一方面，标签并不定义嵌套作用域。因此，标签后的代码通常不缩进。

然而，如果我们将标签和后续语句缩进到同一级别，最终会得到类似这样的结果：

// 不可读的版本
void printDigitName(int x)
{
    switch (x)
    {
        case 1:
        std::cout << "One";
        return;
        case 2:
        std::cout << "Two";
        return;
        case 3:
        std::cout << "Three";
        return;
        default:
        std::cout << "Unknown";
        return;
    }
}

这使得很难确定每个case从哪里开始和结束。

我们有两个选择。首先，我们可以将标签后的语句缩进：

// 可接受但不推荐的版本
void printDigitName(int x)
{
    switch (x)
    {
        case 1: // 从 switch 块缩进
            std::cout << "One"; // 从标签缩进（误导）
            return;
        case 2:
            std::cout << "Two";
            return;
        case 3:
            std::cout << "Three";
            return;
        default:
            std::cout << "Unknown";
            return;
    }
}

虽然这肯定比之前的版本更易读，但它暗示每个标签下的语句位于嵌套作用域中，而事实并非如此（我们将在下一课中看到例子，一个case中定义的变量可以在另一个case中使用）。这种格式被认为是可以接受的（因为它可读），但不是首选。

按照惯例，标签根本不缩进：

// 推荐的版本
void printDigitName(int x)
{
    switch (x)
    {
    case 1: // 不从 switch 语句缩进
        std::cout << "One";
        return;
    case 2:
        std::cout << "Two";
        return;
    case 3:
        std::cout << "Three";
        return;
    default:
        std::cout << "Unknown";
        return;
    }
}

这使得每个标签易于识别。而且由于语句只从switch块缩进一级，它正确地暗示了所有语句都是switch块作用域的一部分。

在未来的课程中，我们会遇到其他类型的标签——出于同样的原因，它们通常也不缩进。

最佳实践

优先选择不缩进标签。这使它们从周围代码中脱颖而出，而不暗示它们定义了嵌套作用域区域。

Switch vs if-else

当有一个单一表达式（非布尔整型或枚举类型）我们想要与少量值进行相等性比较时，最好使用switch语句。如果case标签数量过多，switch可能难以阅读。

与等价的 if-else 语句相比，switch 语句可读性更强，能更清晰地表明每次比较的是同一个表达式，并且具有只计算一次表达式的优势（从而更高效）。

然而，if-else 更加灵活。以下情况通常更适合使用 if 或 if-else：

  • 测试表达式是否满足非相等比较（例如 x > 5)
  • 测试多个条件（例如 x == 5 && y == 6)
  • 判断值是否在某个范围内（例如 x >= 5 && x <= 10)
  • 表达式的类型是 switch 不支持的（例如 d == 4.0)。
  • 表达式求值结果为 bool。

最佳实践

当测试单个表达式（具有非布尔整型或枚举类型）是否等于一小部分值时，优先使用 switch 语句而非 if-else 语句。
