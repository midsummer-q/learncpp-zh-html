3.1 — 语法错误和语义错误

● 机器译文 课程 3.1 查看英文原文

软件错误很常见。我们很容易犯错误，也很难找到它们。在本章中，我们将探讨与在 C++ 程序中查找和消除错误相关的主题，包括学习如何使用 IDE 中集成的调试器。

尽管调试工具和技术不属于 C++ 标准的一部分，但学会在编写的程序中查找并消除错误是成为一名成功程序员极为重要的一环。因此，我们会花一些时间涵盖这些主题，这样随着你编写的程序变得更为复杂，诊断和解决问题的能力也能同步提升。

如果你在其他编程语言中有调试程序的经验，那么这部分内容对你来说会相当熟悉。

语法错误

编程可能具有挑战性，而 C++ 是一种有些独特的语言。两者结合，出错的方式就有很多种。错误通常分为两类：语法错误和语义错误（逻辑错误）。

一个 语法错误 当你编写的语句不符合 C++ 语言的语法规则时，就会发生语法错误。这包括缺少分号、括号或花括号不匹配等错误。例如，以下程序包含不少语法错误：

#include <iostream>

int main( // 缺少闭合大括号
{
    int 1x; // 变量名不能以数字开头
    std::cout << "Hi there"; << x +++ << '\n'; // 多余的分号，运算符+++不存在
    return 0 // 语句末尾缺少分号
}

幸运的是，编译器会检测到语法错误并发出编译警告或错误，让你可以轻松识别并修复问题。然后只需反复编译，直到消除所有错误即可。

语义错误

一个 语义错误 指的是含义上的错误。当一条语句在语法上有效，但违反了语言的其他规则，或者没有达到程序员的预期时，就会发生这种错误。

某些类型的语义错误可以被编译器捕获。常见的例子包括使用未声明的变量、类型不匹配（在某个地方以错误的类型使用对象）等。

例如，以下程序包含几个编译时的语义错误：

int main()
{
    5 = x; // x未声明，无法对5赋值
    return "hello"; // "hello"无法转换为整数
}

其他语义错误仅在运行时显现。有时它们会导致程序崩溃，例如除以零的情况：

#include <iostream>

int main()
{
    int a { 10 };
    int b { 0 };
    std::cout << a << " / " << b << " = " << a / b << '\n'; // 数学中除以0是未定义的
    return 0;
}

更多时候，它们只是产生错误的值或行为：

#include <iostream>

int main()
{
    int x; // 未提供初始化器
    std::cout << x << '\n'; // 使用未初始化的变量会导致未定义行为

    return 0;
}

或

#include <iostream>

int add(int x, int y) // 此函数本应执行加法运算
{
    return x - y; // 但由于使用了错误的运算符而未实现
}

int main()
{
    std::cout << "5 + 3 = " << add(5, 3) << '\n'; // 本应产生8，但实际产生了2

    return 0;
}

或

#include <iostream>

int main()
{
    return 0; // 函数在此返回

    std::cout << "Hello, world!\n"; // 因此这部分从未执行
}

在上面的例子中，错误相当容易发现。但在大多数非平凡的程序中，运行时语义错误很难通过肉眼审查代码来发现。这时调试技术就可以派上用场了。
