6.5 — 逗号运算符

● 机器译文 课程 6.5 查看英文原文

运算符符号形式操作
逗号，x, y先求值 x 再求值 y，返回 y 的值

浮点类型的 逗号运算符 (,) 允许你在任何允许单个表达式的地方求值多个表达式。逗号运算符先求值左操作数，然后求值右操作数，最后返回右操作数的结果。

例如：

#include <iostream>

int main()
{
    int x{ 1 };
    int y{ 2 };

    std::cout << (++x, ++y) << '\n'; // 递增 x 和 y，求值为右操作数

    return 0;
}

首先，逗号运算符的左操作数被求值，这会使 x 从 1 切换到 2递增。接着，右操作数被求值，这会使 y 从 2 切换到 3递增。逗号运算符返回右操作数的结果（3），随后该结果被打印到控制台。

注意，逗号在所有运算符中优先级最低，甚至低于赋值。因此，下面两行代码执行不同的操作：

z = (a, b); // 先求值 (a, b) 得到 b 的结果，然后将该值赋给变量 z。
z = a, b; // 被求值为 "(z = a), b"，因此 z 被赋值为 a 的值，b 被求值并丢弃。

这使得逗号运算符使用起来有些危险。

几乎在所有情况下，使用逗号运算符编写的语句最好写成单独的语句。例如，上面的代码可以写成：

#include <iostream>

int main()
{
    int x{ 1 };
    int y{ 2 };

    ++x;
    std::cout << ++y << '\n';

    return 0;
}

大多数程序员根本不使用逗号运算符，唯一的例外是在 for 循环中，它的使用相当常见。我们将在未来的课程中讨论 for 循环 8.10 -- For 语句。

最佳实践

避免使用逗号运算符，除非在 for 循环。

逗号作为分隔符

在 C++ 中，逗号符号经常用作分隔符，这些用法不会调用逗号运算符。分隔逗号的一些示例：

void foo(int x, int y) // 分隔逗号用于分隔函数定义中的参数
{
    add(x, y); // 分隔逗号用于分隔函数调用中的实参
    constexpr int z{ 3 }, w{ 5 }; // 分隔逗号用于分隔同一行上定义的多个变量（不要这样做）
}

没有必要避免使用分隔逗号（除非在声明多个变量时，你不应该这样做）。
