6.6 — 条件运算符

● 机器译文 课程 6.6 查看英文原文
运算符符号形式含义
条件？：c ? x : y如果条件 c 等于 true 则求值 x，否则求值 y

浮点类型的 条件运算符 (?:）（有时也称为 算术 if 运算符）是一个三元运算符（接受 3 个操作数的运算符）。由于它历来是 C++ 中唯一的三元运算符，有时也被称为“三元运算符”。

浮点类型的 ?: 运算符为执行特定类型的 if-else 语句提供了一种简写方法。

相关内容

我们在第 4.10 -- if 语句简介。

课中介绍了 if-else 语句。回顾一下，if-else 语句的形式如下：

if (condition)
    statement1;
else
    statement2;

如果 condition 求值为 true，那么 statement1 被执行，否则 statement2 被执行。 else 和 statement2 是可选的。

浮点类型的 ?: 运算符的形式如下：

condition ? expression1 : expression2;

如果 condition 求值为 true，那么 expression1 被求值，否则 expression2 被评估。 : 和 expression2 不是可选的。

考虑一个如下所示的 if-else 语句：

if (x > y)
    max = x;
else
    max = y;

这可以重写为：

max = ((x > y) ? x : y);

在这种情况下，条件运算符有助于压缩代码而不损失可读性。

一个例子

考虑以下示例：

#include <iostream>

int getValue()
{
    std::cout << "Enter a number: ";
    int x{};
    std::cin >> x;
    return x;
}

int main()
{
    int x { getValue() };
    int y { getValue() };
    int max { (x > y) ? x : y };
    std::cout << "The max of " << x <<" and " << y << " is " << max << ".\n";

    return 0;
}

首先，让我们输入 5 和 7 作为输入（所以 x 等于 5、和 y 等于 7）。当 max 被初始化时，表达式 (5 > 7) ? 5 : 7 被求值。由于 5 > 7 为假，这产生 false ? 5 : 7，计算结果为 7。程序输出：

The max of 5 and 7 is 7.

现在让我们输入 7 和 5 作为输入（所以 x 等于 7、和 y 等于 5）。在这种情况下，我们得到 (7 > 5) ? 7 : 5，即 true ? 7 : 5，计算结果为 7。程序输出：

The max of 7 and 5 is 7.

条件运算符作为表达式的一部分求值

由于条件运算符作为表达式的一部分求值，它可以在任何接受表达式的地方使用。如果条件运算符的操作数是常量表达式，则条件运算符可以在常量表达式中使用。

这使得条件运算符可以在不能使用语句的地方使用。

例如，在初始化变量时：

#include <iostream>

int main()
{
    constexpr bool inBigClassroom { false };
    constexpr int classSize { inBigClassroom ? 30 : 20 };
    std::cout << "The class size is: " << classSize << '\n';

    return 0;
}

对此没有直接的 if-else 替代方案。

你可能会想尝试这样的写法：

#include <iostream>

int main()
{
    constexpr bool inBigClassroom { false };

    if (inBigClassroom)
        constexpr int classSize { 30 };
    else
        constexpr int classSize { 20 }; 

    std::cout << "The class size is: " << classSize << '\n'; // 编译错误：classSize未定义

    return 0;
}

然而，这无法编译，你会得到一条错误消息，说 classSize 未定义。就像在函数内部定义的变量在函数结束时消亡一样，在 if 语句或 else 语句内部定义的变量在 if 语句或 else 语句结束时消亡。因此， classSize 在我们尝试打印它时已经被销毁。

如果你想使用 if-else，你必须这样做：

#include <iostream>

int getClassSize(bool inBigClassroom)
{
    if (inBigClassroom)
        return 30;
    else
        return 20;
}

int main()
{
    const int classSize { getClassSize(false) };
    std::cout << "The class size is: " << classSize << '\n';

    return 0;
}

这个能工作是因为 getClassSize(false) 是一个表达式，而 if-else 逻辑位于一个函数内部（在那里我们可以使用语句）。但这需要大量额外的代码，而我们本可以使用条件运算符。

给条件运算符加括号

因为 C++ 优先评估大多数运算符，而不是条件运算符，所以很容易写出使用条件运算符但评估结果不符合预期的表达式。

相关内容

我们将在未来的课程中介绍 C++ 如何优先评估运算符。 6.1 -- 运算符优先级和结合性。

例如：

#include <iostream>

int main()
{
    int x { 2 };
    int y { 1 };
    int z { 10 - x > y ? x : y };
    std::cout << z;
    
    return 0;
}

你可能期望它评估为 10 - (x > y ? x : y) （这将评估为 8）但实际上它评估为 (10 - x) > y ? x : y （评估为 2)。

这是另一个展示常见错误的例子：

#include <iostream>

int main()
{
    int x { 2 };
    std::cout << (x < 0) ? "negative" : "non-negative";

    return 0;
}

你可能期望它打印 non-negative，但实际上它打印 0。

可选阅读

以上例子中发生了什么。首先， x < 0 求值为 false。部分评估的表达式现在是 std::cout << false ? "negative" : "non-negative"。因为 operator<< 的优先级高于 operator?:，这个表达式评估起来就像写成 (std::cout << false) ? "negative" : "non-negative"。因此 std::cout << false 被评估，打印 0 （并返回 std::cout)。

部分评估的表达式现在是 std::cout ? "negative" : "non-negative"。因为 std::cout 是条件中剩下的全部内容，编译器会尝试将其转换为 bool 以便条件可以被解析。也许令人惊讶的是， std::cout 有一个定义好的转换为 bool，这很可能返回 false。假设它返回 false，我们现在有 false ? "negative" : "non-negative"，计算结果为 "non-negative"。所以我们完全评估的语句是 "non-negative";。一个仅包含字面量（这里是字符串字面量）的表达式语句没有效果，所以我们就完成了。

为了避免这种评估优先级问题，条件运算符应该如下加括号：

  • 当在复合表达式（包含其他运算符的表达式）中使用时，将整个条件运算（包括操作数）括起来。
  • 为了可读性，如果条件包含任何运算符（除了函数调用运算符），考虑将其括起来。

条件运算符的操作数不需要加括号。

让我们看一些包含条件运算符的语句以及它们应该如何加括号：

return isStunned ? 0 : movesLeft;           // 未在复合表达式中使用，条件不包含运算符
int z { (x > y) ? x : y };                  // 未在复合表达式中使用，条件包含运算符
std::cout << (isAfternoon() ? "PM" : "AM"); // 在复合表达式中使用，条件不包含运算符（函数调用运算符除外）
std::cout << ((x > y) ? x : y);             // 在复合表达式中使用，条件包含运算符

最佳实践

当在复合表达式中使用时，将整个条件运算（包括操作数）括起来。

为了可读性，如果条件包含任何运算符（除了函数调用运算符），考虑将其括起来。

表达式的类型必须匹配或可转换

为了符合 C++ 的类型检查规则，以下之一必须为真：

  • 第二个和第三个操作数的类型必须匹配。
  • 编译器必须能够找到一种方法将一个或两个第二和第三操作数转换为匹配的类型。编译器使用的转换规则相当复杂，在某些情况下可能会产生令人惊讶的结果。

进阶读者

或者，允许第二和第三操作数中的一个或两个是 throw 表达式。我们将在 throw 在课程 27.2 -- 基本异常处理。

例如：

#include <iostream>

int main()
{
    std::cout << (true ? 1 : 2) << '\n';    // 可以：两个操作数都是int类型，匹配

    std::cout << (false ? 1 : 2.2) << '\n'; // 可以：int值1转换为double

    std::cout << (true ? -1 : 2u) << '\n';  // 令人惊讶的结果：-1转换为unsigned int，结果超出范围

    return 0;
}

假设整数为4字节，上述代码输出：

1
2.2
4294967295

一般来说，混合使用基本类型的操作数是可以的（排除混合有符号和无符号值的情况）。如果任一操作数不是基本类型，通常最好自己显式地将一个或两个操作数转换为匹配的类型，这样你就能确切知道结果。

相关内容

上述关于混合有符号和无符号值的令人惊讶的情况是由于算术转换规则造成的，我们将在课程中介绍 10.5 -- 算术转换。

如果编译器无法找到将第二和第三操作数转换为匹配类型的方法，则会导致编译错误：

#include <iostream>

int main()
{
    constexpr int x{ 5 };
    std::cout << ((x != 5) ? x : "x is 5"); // 编译错误：编译器无法为constexpr int和C风格字符串字面量找到公共类型

    return 0;
}

在上面的例子中，其中一个表达式是整数，另一个是C风格字符串字面量。编译器无法自行找到匹配的类型，因此会导致编译错误。

在这种情况下，你可以进行显式转换，或者使用if-else语句：

#include <iostream>
#include <string>

int main()
{
    int x{ 5 }; // 此示例中特意设为非constexpr

    // 我们可以显式转换类型以匹配
    std::cout << ((x != 5) ? std::to_string(x) : std::string{"x is 5"}) << '\n';

    // 或者使用if-else语句
    if (x != 5)
        std::cout << x << '\n';
    else
        std::cout << "x is 5" << '\n';
    
    return 0;
}

进阶读者

如果 x 是constexpr，那么条件 x != 5 是一个常量表达式。在这种情况下，使用 if constexpr 应该优先于 if，并且你的编译器可能会生成一个警告（如果你将警告视为错误，则会升级为错误）。

由于我们还没有介绍 if constexpr （我们将在课程 8.4 -- Constexpr if 语句)， x 在此示例中是非constexpr的，以避免潜在的编译器警告。

那么什么时候应该使用条件运算符？

条件运算符在以下情况中最有用：

  • 用两个值之一初始化对象。
  • 将两个值之一赋值给对象。
  • 将两个值之一传递给函数。
  • 从函数返回两个值之一。
  • 打印两个值之一。

复杂的表达式通常应避免使用条件运算符，因为它们容易出错且难以阅读。

最佳实践

在复杂表达式中优先避免使用条件运算符。
