25.8 — 虚基类

● 机器译文 课程 25.8 查看英文原文

上一章，在课程 24.9 -- 多重继承中，我们谈到了“菱形问题”。在本节中，我们将继续讨论这个话题。

注意：本节是一个高级主题，如果需要可以跳过或略读。

菱形问题

以下是上一课中的示例（带有一些构造函数），说明了菱形问题：

#include <iostream>

class PoweredDevice
{
public:
    PoweredDevice(int power)
    {
		std::cout << "PoweredDevice: " << power << '\n';
    }
};

class Scanner: public PoweredDevice
{
public:
    Scanner(int scanner, int power)
        : PoweredDevice{ power }
    {
		std::cout << "Scanner: " << scanner << '\n';
    }
};

class Printer: public PoweredDevice
{
public:
    Printer(int printer, int power)
        : PoweredDevice{ power }
    {
		std::cout << "Printer: " << printer << '\n';
    }
};

class Copier: public Scanner, public Printer
{
public:
    Copier(int scanner, int printer, int power)
        : Scanner{ scanner, power }, Printer{ printer, power }
    {
    }
};

如你所见，PoweredDevice 被构造了两次。

虽然这通常是期望的，但有时你可能希望 Scanner 和 Printer 共享同一个 PoweredDevice 副本。

虚基类

要共享基类，只需在派生类的继承列表中插入“virtual”关键字。这将创建一个所谓的 虚基类，这意味着只有一个基类对象。该基类对象在继承树中的所有对象之间共享，并且只构造一次。以下是一个示例（为简单起见，没有构造函数），展示了如何使用 virtual 关键字创建共享基类：

class PoweredDevice
{
};

class Scanner: virtual public PoweredDevice
{
};

class Printer: virtual public PoweredDevice
{
};

class Copier: public Scanner, public Printer
{
};

现在，当你创建一个 Copier 类对象时，每个 Copier 只会得到一个 PoweredDevice 副本，由 Scanner 和 Printer 共享。

然而，这又引出了另一个问题：如果 Scanner 和 Printer 共享一个 PoweredDevice 基类，那么谁负责创建它？答案，事实证明，是 Copier。Copier 构造函数负责创建 PoweredDevice。因此，这是 Copier 被允许直接调用非直接父类构造函数的唯一情况：

#include <iostream>

class PoweredDevice
{
public:
    PoweredDevice(int power)
    {
		std::cout << "PoweredDevice: " << power << '\n';
    }
};

class Scanner: virtual public PoweredDevice // 注意：PoweredDevice 现在是一个虚基类
{
public:
    Scanner(int scanner, int power)
        : PoweredDevice{ power } // 这一行是创建 Scanner 对象所必需的，但在此情况下被忽略
    {
		std::cout << "Scanner: " << scanner << '\n';
    }
};

class Printer: virtual public PoweredDevice // 注意：PoweredDevice 现在是一个虚基类
{
public:
    Printer(int printer, int power)
        : PoweredDevice{ power } // 这一行是创建 Printer 对象所必需的，但在此情况下被忽略
    {
		std::cout << "Printer: " << printer << '\n';
    }
};

class Copier: public Scanner, public Printer
{
public:
    Copier(int scanner, int printer, int power)
        : PoweredDevice{ power }, // PoweredDevice 在这里构造
        Scanner{ scanner, power }, Printer{ printer, power }
    {
    }
};

这一次，我们之前的示例：

int main()
{
    Copier copier{ 1, 2, 3 };

    return 0;
}

产生结果：

PoweredDevice: 3
Scanner: 1
Printer: 2

如你所见，PoweredDevice 只被构造了一次。

还有一些细节我们不得不提。

首先，对于最派生类的构造函数，虚基类总是在非虚基类之前创建，这确保了所有基类在其派生类之前被创建。

其次，注意 Scanner 和 Printer 的构造函数仍然有对 PoweredDevice 构造函数的调用。当创建 Copier 的实例时，这些构造函数调用会被忽略，因为 Copier 负责创建 PoweredDevice，而不是 Scanner 或 Printer。然而，如果我们创建 Scanner 或 Printer 的实例，这些构造函数调用将被使用，并且正常的继承规则适用。

第三，如果一个类继承了一个或多个具有虚基类的类，那么 最 派生类负责构造虚基类。在这种情况下，Copier 继承自 Printer 和 Scanner，两者都有一个 PoweredDevice 虚基类。Copier，作为最派生类，负责创建 PoweredDevice。注意，即使在单继承情况下也是如此：如果 Copier 单继承自 Printer，并且 Printer 虚继承自 PoweredDevice，Copier 仍然负责创建 PoweredDevice。

第四，所有继承虚基类的类都会有一个虚表，即使它们通常不会有，因此类的实例会因一个指针而变大。

由于 Scanner 和 Printer 虚继承自 PoweredDevice，Copier 将只有一个 PoweredDevice 子对象。Scanner 和 Printer 都需要知道如何找到那个单一的 PoweredDevice 子对象，以便访问其成员（因为它们派生自它）。这通常通过一些虚表魔法来实现（它本质上存储了从每个子类到 PoweredDevice 子对象的偏移量）。
