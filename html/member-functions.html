14.3 — 成员函数

● 机器译文 课程 14.3 查看英文原文

在课程 13.7 课——结构体、成员和成员选择简介中介绍结构体。，我们介绍了结构体程序定义类型，它可以包含成员变量。下面是一个用于保存日期的结构体示例：

struct Date
{
    int year {};
    int month {};
    int day {};
};

现在，如果我们想将日期打印到屏幕上（这可能是我们经常要做的事情），编写一个函数来实现这个功能是合理的。下面是一个完整的程序：

#include <iostream>

struct Date
{
    // 这里是我们的成员变量
    int year {};
    int month {};
    int day {};
};

void print(const Date& date)
{
    // 使用成员选择运算符 (.) 访问成员变量
    std::cout << date.year << '/' << date.month << '/' << date.day;
}

int main()
{
    Date today { 2020, 10, 14 }; // 聚合初始化我们的结构体

    today.day = 16; // 使用成员选择运算符 (.) 访问成员变量
    print(today);   // 使用普通调用约定访问非成员函数

    return 0;
}

该程序打印出：

2020/10/16

属性与行为的分离

环顾四周——你看到的到处都是对象：书籍、建筑、食物，甚至你自己。现实生活中的对象有两个主要组成部分：1）一些可观察的属性（例如重量、颜色、大小、坚固性、形状等），以及2）基于这些属性可以执行或对其执行的一些行为（例如被打开、损坏其他东西等）。这些属性和行为是不可分割的。

在编程中，我们用变量表示属性，用函数表示行为。

在 Date 上面的例子中，注意我们分别定义了属性（ Date的成员变量）和使用这些属性执行的行为（函数 print()）。我们只能通过 Date 和 print() 的参数 const Date& 来推断 print()。

之间的联系。虽然我们可以将 Date 和 print() 都放入一个命名空间（以更清楚地表明两者是打包在一起的），但这会在程序中增加更多的名称和命名空间前缀，使代码变得杂乱。

如果能有一种方法将我们的属性和行为定义在一起，作为一个单独的包，那就太好了。

成员函数

除了拥有成员变量之外，类类型（包括结构体、类和联合体）也可以拥有自己的函数！属于类类型的函数称为 成员函数。

顺便说一句……

在其他面向对象语言（如Java和C#）中，这些被称为 方法。虽然C++中不使用“方法”这个术语，但先学习其他语言的程序员可能仍会使用这个术语。

不是成员函数的函数称为 非成员函数 （有时也称为 自由函数），以区别于成员函数。上面的 print() 函数是一个非成员函数。

作者注

在本课中，我们将使用结构体来展示成员函数的示例——但我们在这里展示的所有内容同样适用于类。出于某些原因，我们将在接下来的课程（14.5 -- 公有和私有成员及访问说明符)。

）中展示带有成员函数的类的示例。成员函数必须在类类型定义内部声明，并且可以在类类型定义内部或外部定义。提醒一下，定义也是一种声明，所以如果在类内部定义成员函数，那也算作声明。

为了简单起见，我们现在将在类类型定义内部定义成员函数。

相关内容

我们将在课程 15.2 -- 类和头文件。

中展示如何在类类型定义外部定义成员函数。

一个成员函数示例 Date 让我们重写本课开头的 print() 示例，将

// 成员函数版本
#include <iostream>

struct Date
{
    int year {};
    int month {};
    int day {};

    void print() // 定义了一个名为 print 的成员函数
    {
        std::cout << year << '/' << month << '/' << day;
    }
};

int main()
{
    Date today { 2020, 10, 14 }; // 聚合初始化我们的结构体

    today.day = 16; // 使用成员选择运算符 (.) 访问成员变量
    today.print();  // 成员函数也使用成员选择运算符 (.) 访问

    return 0;
}

  1. 非成员和成员示例之间有三个关键区别： print() 函数
  2. 我们声明（和定义） print() 函数
  3. 我们调用 print() 函数

让我们逐一探讨这些内容。

成员函数在类类型定义内部声明

在非成员示例中， print() 非成员函数定义在 Date struct 外部，位于全局命名空间中。默认情况下，它具有外部链接，因此可以从其他源文件调用（通过适当的前向声明）。

在成员示例中， print() 成员函数声明（并在本例中定义）在 Date struct 定义内部。因为 print() 被声明为 Date的一部分，这告诉编译器 print() 是一个成员函数。

在类类型定义内部定义的成员函数是隐式内联的，因此如果类类型定义被包含到多个代码文件中，它们不会违反单一定义规则。

相关内容

成员函数也可以在类定义内部进行（前向）声明，并在类定义之后定义。我们在课程 15.2 -- 类和头文件。

调用成员函数（以及隐式对象）

在非成员示例中，我们调用 print(today)，其中 today 被（显式地）作为参数传递。

在成员示例中，我们调用 today.print()。这种语法使用成员选择运算符 (.) 来选择要调用的成员函数，与我们访问成员变量的方式一致（例如 today.day = 16;)。

所有（非静态）成员函数必须使用该类的对象来调用。在这种情况下， today 是 print() 被调用的对象。

注意，在成员函数的情况下，我们不需要将 today 作为参数传递。成员函数被调用的对象是 隐式地 传递给成员函数的。因此，成员函数被调用的对象通常被称为 隐式对象。

换句话说，当我们调用 today.print()， today 是隐式对象，它被隐式传递给 print() 成员函数。

相关内容

我们在课程 15.1 -- 隐藏的“this”指针和成员函数链式调用。

在成员函数内部访问成员使用隐式对象

这是非成员版本的 print() 再次：

// print 的非成员版本
void print(const Date& date)
{
    // 使用成员选择运算符 (.) 访问成员变量
    std::cout << date.year << '/' << date.month << '/' << date.day;
}

这个版本的 print() 具有引用参数 const Date& date。在函数内部，我们通过这个引用参数访问成员，如 date.year， date.month、和 date.day。当 print(today) 被调用， date 引用参数绑定到参数 today、和 date.year， date.month、和 date.day 求值为 today.year， today.month、和 today.day

现在让我们看看 print() 成员函数的定义：

    void print() // 定义了一个名为 print() 的成员函数
    {
        std::cout << year << '/' << month << '/' << day;
    }

在成员示例中，我们访问成员为 year， month, 和 day。

在成员函数内部，任何没有用成员选择运算符（.）前缀的成员标识符都与隐式对象相关联。

换句话说，当 today.print() 被调用时， today 是我们的隐式对象，而 year， month、和 day （没有前缀）求值为 today.year， today.month、和 today.day

关键提示

对于非成员函数，我们必须显式地将一个对象传递给函数来操作，并且成员通过该对象显式访问。

对于成员函数，我们隐式地将一个对象传递给函数来操作，并且成员通过该对象隐式访问。

另一个成员函数示例

这是一个稍微复杂一点的成员函数的例子：

#include <iostream>
#include <string>

struct Person
{
    std::string name{};
    int age{};

    void kisses(const Person& person)
    {
        std::cout << name << " kisses " << person.name << '\n';
    }
};

int main()
{
    Person joe{ "Joe", 29 };
    Person kate{ "Kate", 27 };

    joe.kisses(kate);

    return 0;
}

这将产生输出：

Joe kisses Kate

让我们看看这是如何工作的。首先，我们定义两个 Person 结构体， joe 和 kate。接下来，我们调用 joe.kisses(kate)。 joe 是这里的隐式对象，而 kate 作为显式参数传递。

当 kisses() 成员函数执行时，标识符 name 没有使用成员选择运算符（.），所以它引用隐式对象，即 joe。因此这解析为 joe.name。 person.name 使用了成员选择运算符，所以它不引用隐式对象。由于 person 是 kate的引用，这解析为 kate.name。

关键提示

如果没有成员函数，我们会写成 kisses(joe, kate)。有了成员函数，我们写成 joe.kisses(kate)。注意后者读起来好得多，并且清楚地表明了哪个对象是发起动作的，哪个是辅助的。

成员变量和函数可以按任意顺序定义

C++ 编译器通常从上到下编译代码。对于遇到的每个名称，编译器确定它是否已经看到该名称的声明，以便进行正确的类型检查。

非成员必须在使用前声明，否则编译器会报错：

int x()
{
    return y(); // 错误：y 尚未声明，因此编译器不知道它是什么
}
 
int y()
{
    return 5;
}

为了解决这个问题，我们通常要么按使用的大致顺序定义非成员（这需要在我们需要改变顺序时进行工作），要么使用前向声明（这需要额外的工作来添加）。

然而，在类定义内部，这个限制不适用：你可以在成员变量和成员函数声明之前访问它们。这意味着你可以按任意顺序定义成员变量和成员函数！

例如：

struct Foo
{
    int z() { return m_data; } // 我们可以在数据成员定义之前访问它们
    int x() { return y(); }    // 我们可以在成员函数定义之前访问它们

    int m_data { y() };        // 这甚至在默认成员初始化器中也能工作（参见下面的警告）
    int y() { return 5; }
};

我们在接下来的课程中讨论成员定义的推荐顺序 14.8 -- 数据隐藏（封装）的好处。

警告

数据成员按声明顺序初始化。如果数据成员的初始化访问了另一个尚未声明（因此尚未初始化）的数据成员，则初始化将导致未定义行为。

struct Bad
{
    int m_bad1 { m_data }; // 未定义行为：m_bad1 在 m_data 之前初始化
    int m_bad2 { fcn() };  // 未定义行为：m_bad2 在 m_data 之前初始化（通过 fcn() 访问）

    int m_data { 5 };
    int fcn() { return m_data; }
};

因此，通常最好避免在默认成员初始化器中使用其他成员。

进阶读者

为了允许按任意顺序定义数据成员和成员函数，编译器采用了一个巧妙的技巧。当编译器遇到在类定义内部定义的成员函数时：

  • 该成员函数被隐式前向声明。
  • 该成员函数定义被立即移动到类定义结束之后。

这样，当编译器实际编译成员函数定义时，它已经看到了完整的类定义（包含所有成员的声明！）

例如，当编译器遇到这个：

struct Foo
{
    int z() { return m_data; } // m_data 尚未声明
    int x() { return y(); }    // y 尚未声明
    int y() { return 5; }

    int m_data{};
};

它将编译等效于这个：

struct Foo
{
    int z(); // Foo::z() 的前向声明
    int x(); // Foo::x() 的前向声明
    int y(); // Foo::y() 的前向声明

    int m_data{};
};

int Foo::z() { return m_data; } // m_data 已在上面声明
int Foo::x() { return y(); }    // y 已在上面声明
int Foo::y() { return 5; }

成员函数可以被重载

就像非成员函数一样，成员函数可以被重载，只要每个成员函数可以被区分。

相关内容

我们在课程中介绍函数重载的区分 11.2 -- 函数重载区分。

以下是一个带有重载 Date 成员函数的 print() struct 示例：

#include <iostream>
#include <string_view>

struct Date
{
    int year {};
    int month {};
    int day {};

    void print()
    {
        std::cout << year << '/' << month << '/' << day;
    }

    void print(std::string_view prefix)
    {
        std::cout << prefix << year << '/' << month << '/' << day;
    }
};

int main()
{
    Date today { 2020, 10, 14 };

    today.print(); // 调用 Date::print()
    std::cout << '\n';

    today.print("The date is: "); // 调用 Date::print(std::string_view)
    std::cout << '\n';

    return 0;
}

这会打印：

2020/10/14
The date is: 2020/10/14

结构体与成员函数

在 C 语言中，结构体只有数据成员，没有成员函数。

在 C++ 中，设计类时，Bjarne Stroustrup 花了一些时间考虑是否应该允许结构体（继承自 C）拥有成员函数。经过思考，他决定应该允许。

顺便说一句……

这个决定引发了一系列关于结构体还应具备哪些其他新 C++ 能力的问题。Bjarne 担心，如果只给结构体有限的能力子集，会增加语言的复杂性和边界情况。为了简化，他最终决定结构体和类使用统一的规则集（意味着结构体可以做类能做的一切，反之亦然），而约定俗成的用法可以决定结构体实际如何使用。

在现代 C++ 中，结构体拥有成员函数是完全可以的。但这不包括构造函数，构造函数是一种特殊的成员函数，我们将在后续课程中介绍 14.9 -- 构造函数简介。带有构造函数的类类型不再是聚合体，而我们希望结构体保持为聚合体。

最佳实践

成员函数可以用于结构体和类。

然而，结构体应避免定义构造函数成员函数，因为这样做会使它们成为非聚合体。

没有数据成员的类类型

可以创建没有数据成员的类类型（例如，只有成员函数的类类型）。也可以实例化这种类类型的对象：

#include <iostream>

struct Foo
{
    void printHi() { std::cout << "Hi!\n"; }
};

int main()
{
    Foo f{};
    f.printHi(); // 需要对象才能调用

    return 0;
}

然而，如果类类型没有任何数据成员，那么使用类类型可能有些过度。在这种情况下，考虑使用命名空间（包含非成员函数）代替。这样可以让读者更清楚地知道没有数据被管理（并且不需要实例化对象来调用函数）。

#include <iostream>

namespace Foo
{
    void printHi() { std::cout << "Hi!\n"; }
};

int main()
{
    Foo::printHi(); // 不需要对象

    return 0;
}

最佳实践

如果你的类类型没有数据成员，优先使用命名空间。

问题 #1

创建一个名为 IntPair 的结构体，包含两个整数。添加一个名为 print 的成员函数，用于打印这两个整数的值。

以下程序函数应能编译：

#include <iostream>

// 在此处提供 IntPair 和 print() 成员函数的定义

int main()
{
	IntPair p1 {1, 2};
	IntPair p2 {3, 4};

	std::cout << "p1: ";
	p1.print();

	std::cout << "p2: ";
	p2.print();

并产生输出：

p1: Pair(1, 2)

显示答案

#include <iostream>

struct IntPair
{
	int first{};
	int second{};

	void print()
	{
		std::cout << "Pair(" << first << ", " << second << ")\n";
	}

int main()
{
	IntPair p1 {1, 2};
	IntPair p2 {3, 4};

	std::cout << "p1: ";
	p1.print();

	std::cout << "p2: ";
	p2.print();

	return 0;

问题 #2

向 IntPair 的变量，名为 isEqual 添加一个新的成员函数，返回一个布尔值，指示一个 IntPair 是否等于另一个。

以下程序函数应能编译：

#include <iostream>

// 在此处提供 IntPair 和成员函数的定义

int main()
{
	IntPair p1 {1, 2};
	IntPair p2 {3, 4};

	std::cout << "p1: ";
	p1.print();

	std::cout << "p2: ";
	p2.print();

	std::cout << "p1 and p1 " << (p1.isEqual(p1) ? "are equal\n" : "are not equal\n");
	std::cout << "p1 and p2 " << (p1.isEqual(p2) ? "are equal\n" : "are not equal\n");

	return 0;
}

并产生输出：

p1: Pair(1, 2)
p2: Pair(3, 4)
p1 and p1 are equal
p1 and p2 are not equal

显示答案

#include <iostream>

struct IntPair
{
	int first{};
	int second{};

	void print()
	{
		std::cout << "Pair(" << first << ", " << second << ")\n";
	}

	bool isEqual(IntPair a)
	{
		return (first == a.first) && (second == a.second);
	}
};

int main()
{
	IntPair p1 {1, 2};
	IntPair p2 {3, 4};

	std::cout << "p1: ";
	p1.print();

	std::cout << "p2: ";
	p2.print();

	std::cout << "p1 and p1 " << (p1.isEqual(p1) ? "are equal\n" : "are not equal\n");
	std::cout << "p1 and p2 " << (p1.isEqual(p2) ? "are equal\n" : "are not equal\n");

	return 0;
}
