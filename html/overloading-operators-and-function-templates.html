21.14 — 重载运算符和函数模板

● 机器译文 课程 21.14 查看英文原文

在课程 11.7 -- 函数模板实例化我们讨论了编译器如何使用函数模板实例化函数，然后进行编译。我们还指出，如果函数模板中的代码试图执行实际类型不支持的操作（例如添加整数值），这些函数可能无法编译。 1 转换为 std::string)。

在本课中，我们将看几个例子，其中实例化的函数无法编译，因为我们的实际类类型不支持这些运算符，并展示如何定义这些运算符，以便实例化的函数能够编译。

运算符、函数调用和函数模板

首先，让我们创建一个简单的类：

class Cents
{
private:
    int m_cents{};
public:
    Cents(int cents)
        : m_cents { cents }
    {
    }

    friend std::ostream& operator<< (std::ostream& ostr, const Cents& c)
    {
        ostr << c.m_cents;
        return ostr;
    }
};

并定义一个 max 函数模板中：

template <typename T>
const T& max(const T& x, const T& y)
{
    return (x < y) ? y : x;
}

现在，让我们看看当我们尝试调用 max() 使用类型为 Cents：

#include <iostream>

class Cents
{
private:
    int m_cents{};
public:
    Cents(int cents)
        : m_cents { cents }
    {
    }

    friend std::ostream& operator<< (std::ostream& ostr, const Cents& c)
    {
        ostr << c.m_cents;
        return ostr;
    }
};

template <typename T>
const T& max(const T& x, const T& y)
{
    return (x < y) ? y : x;
}

int main()
{
    Cents nickel{ 5 };
    Cents dime{ 10 };

    Cents bigger { max(nickel, dime) };
    std::cout << bigger << " is bigger\n";

    return 0;
}

的对象时会发生什么。C++ 将为 max() 创建一个模板实例，如下所示：

template <>
const Cents& max(const Cents& x, const Cents& y)
{
    return (x < y) ? y : x;
}

然后它将尝试编译这个函数。看到问题了吗？C++ 不知道如何计算 x < y 当 x 和 y 是类型 Cents！因此，这将产生编译错误。

为了解决这个问题，只需重载 operator< 对于任何我们希望与 max 一起使用的类：

#include <iostream>

class Cents
{
private:
    int m_cents {};
public:
    Cents(int cents)
        : m_cents { cents }
    {
    }
    
    friend bool operator< (const Cents& c1, const Cents& c2)
    {
        return (c1.m_cents < c2.m_cents);
    }

    friend std::ostream& operator<< (std::ostream& ostr, const Cents& c)
    {
        ostr << c.m_cents;
        return ostr;
    }
};

template <typename T>
const T& max(const T& x, const T& y)
{
    return (x < y) ? y : x;
}

int main()
{
    Cents nickel{ 5 };
    Cents dime { 10 };

    Cents bigger { max(nickel, dime) };
    std::cout << bigger << " is bigger\n";

    return 0;
}

这按预期工作，并打印：

10 is bigger

另一个示例

让我们再看一个由于缺少重载运算符而导致函数模板无法工作的例子。

以下函数模板将计算数组中多个对象的平均值：

#include <iostream>

template <typename T>
T average(const T* myArray, int numValues)
{
    T sum { 0 };
    for (int count { 0 }; count < numValues; ++count)
        sum += myArray[count];

    sum /= numValues;
    return sum;
}

int main()
{
    int intArray[] { 5, 3, 2, 1, 4 };
    std::cout << average(intArray, 5) << '\n';

    double doubleArray[] { 3.12, 3.45, 9.23, 6.34 };
    std::cout << average(doubleArray, 4) << '\n';

    return 0;
}

这产生值：

3
5.535

如您所见，它对内置类型非常有效！

现在让我们看看当我们对 Cents 类：

#include <iostream>

template <typename T>
T average(const T* myArray, int numValues)
{
    T sum { 0 };
    for (int count { 0 }; count < numValues; ++count)
        sum += myArray[count];

    sum /= numValues;
    return sum;
}

class Cents
{
private:
    int m_cents {};
public:
    Cents(int cents)
        : m_cents { cents }

    }

int main()
{
    Cents centsArray[] { Cents { 5 }, Cents { 10 }, Cents { 15 }, Cents { 14 } };

调用此函数时会发生什么。编译器会发疯并产生大量错误消息！第一条错误消息将类似于：

error C2679: binary << : no operator found which takes a right-hand operand of type Cents (or there is no acceptable conversion)

请记住， average() 按值返回一个 Cents 对象，并且我们试图将该对象流式传输到 std::cout using operator<<。但是，我们还没有为 operator<< 对于我们的 Cents 类定义。让我们这样做：

#include <iostream>

template <typename T>
T average(const T* myArray, int numValues)
{
    T sum { 0 };
    for (int count { 0 }; count < numValues; ++count)
        sum += myArray[count];

    sum /= numValues;
    return sum;
}

class Cents
{
private:
    int m_cents {};
public:
    Cents(int cents)
        : m_cents { cents }
    {
    }

    friend std::ostream& operator<< (std::ostream& out, const Cents& cents)
    {
        out << cents.m_cents << " cents ";
        return out;
    }
};

int main()
{
    Cents centsArray[] { Cents { 5 }, Cents { 10 }, Cents { 15 }, Cents { 14 } };
    std::cout << average(centsArray, 4) << '\n';

    return 0;
}

如果我们再次编译，我们将得到另一个错误：

error C2676: binary += : Cents does not define this operator or a conversion to a type acceptable to the predefined operator

这个错误实际上是由调用 average(const Cents*, int)时创建的函数模板实例引起的。请记住，当我们调用模板函数时，编译器会“模板化”出函数的一个副本，其中模板类型参数（占位符类型）已被函数调用中的实际类型替换。以下是 average() 当 T 我们还调用了 Cents 对象的函数模板实例：

template <>
Cents average(const Cents* myArray, int numValues)
{
    Cents sum { 0 };
    for (int count { 0 }; count < numValues; ++count)
        sum += myArray[count];

    sum /= numValues;
    return sum;
}

我们收到错误消息的原因是以下行：

        sum += myArray[count];

在这种情况下， sum 我们还调用了 Cents 对象，但我们还没有定义 operator+= 对于 Cents 对象！我们需要定义这个函数，以便 average() 能够与 Cents一起工作。展望未来，我们可以看到 average() 也使用了 operator/=，所以我们也将定义它：

#include <iostream>

template <typename T>
T average(const T* myArray, int numValues)
{
    T sum { 0 };
    for (int count { 0 }; count < numValues; ++count)
        sum += myArray[count];

    sum /= numValues;
    return sum;
}

class Cents
{
private:
    int m_cents {};
public:
    Cents(int cents)
        : m_cents { cents }
    {
    }

    friend std::ostream& operator<< (std::ostream& out, const Cents& cents)
    {
        out << cents.m_cents << " cents ";
        return out;
    }

    Cents& operator+= (const Cents &cents)
    {
        m_cents += cents.m_cents;
        return *this;
    }

    Cents& operator/= (int x)
    {
        m_cents /= x;
        return *this;
    }
};

int main()
{
    Cents centsArray[] { Cents { 5 }, Cents { 10 }, Cents { 15 }, Cents { 14 } };
    std::cout << average(centsArray, 4) << '\n';

    return 0;
}

最后，我们的代码将编译并运行！这是结果：

11 cents

请注意，我们不必修改 average() 以使其与类型为 Cents的对象一起工作。我们只需要定义用于实现 average() 对于 Cents 类，编译器处理了其余部分！
