26.5 — 部分模板特化

● 机器译文 课程 26.5 查看英文原文

本课及下一课是为那些希望深入了解C++模板的读者提供的可选阅读内容。部分模板特化并不常用（但在特定情况下可能很有用）。

在课程 26.2 -- 模板非类型参数中，你学习了如何使用表达式参数来参数化模板类。

让我们再看一下之前示例中使用的Static Array类：

template <typename T, int size> // size 是表达式参数
class StaticArray
{
private:
    // 表达式参数控制数组的大小
    T m_array[size]{};
 
public:
    T* getArray() { return m_array; }
	
    const T& operator[](int index) const { return m_array[index]; }
    T& operator[](int index) { return m_array[index]; }
};

这个类有两个模板参数：一个类型参数和一个表达式参数。

现在，假设我们想编写一个函数来打印整个数组。虽然我们可以将其实现为成员函数，但我们将以非成员函数的形式实现，因为这样会使后续示例更容易理解。

使用模板，我们可能会这样写：

template <typename T, int size>
void print(const StaticArray<T, size>& array)
{
    for (int count{ 0 }; count < size; ++count)
        std::cout << array[count] << ' ';
}

这将允许我们执行以下操作：

#include <iostream>

template <typename T, int size> // size 是一个模板非类型参数
class StaticArray
{
private:
	T m_array[size]{};

public:
	T* getArray() { return m_array; }

	const T& operator[](int index) const { return m_array[index]; }
	T& operator[](int index) { return m_array[index]; }
};

template <typename T, int size>
void print(const StaticArray<T, size>& array)
{
	for (int count{ 0 }; count < size; ++count)
		std::cout << array[count] << ' ';
}

int main()
{
	// 声明一个 int 数组
	StaticArray<int, 4> int4{};
	int4[0] = 0;
	int4[1] = 1;
	int4[2] = 2;
	int4[3] = 3;

	// 打印数组
	print(int4);

	return 0;
}

并得到以下结果：

0 1 2 3

虽然这可行，但存在一个设计缺陷。考虑以下情况：

#include <algorithm>
#include <iostream>
#include <string_view>

int main()
{
    // 声明一个 char 数组
    StaticArray<char, 14> char14{};

    // 向其中复制一些数据
    constexpr std::string_view hello{ "Hello, world!" };
    std::copy_n(hello.begin(), hello.size(), char14.getArray());

    // 打印数组
    print(char14);

    return 0;
}

（我们在第 17.10 -- C 风格字符串）中有更多关于指针算术的测验问题。 课中介绍了std::strcpy，如果需要复习的话）

该程序将编译、执行，并产生以下值（或类似的值）：

H e l l o ,   w o r l d !

对于非char类型，在每个数组元素之间加一个空格是有意义的，这样它们就不会连在一起。然而，对于char类型，将所有内容连在一起作为C风格字符串打印更有意义，而我们的print()函数并没有这样做。

那么如何解决这个问题呢？

模板特化来救场？

人们可能首先想到使用模板特化。完全模板特化的问题在于所有模板参数都必须显式定义。

0, 1, 2测试

#include <algorithm>
#include <iostream>
#include <string_view>

template <typename T, int size> // size 是表达式参数
class StaticArray
{
private:
	// 表达式参数控制数组的大小
	T m_array[size]{};

public:
	T* getArray() { return m_array; }

	const T& operator[](int index) const { return m_array[index]; }
	T& operator[](int index) { return m_array[index]; }
};

template <typename T, int size>
void print(const StaticArray<T, size>& array)
{
	for (int count{ 0 }; count < size; ++count)
		std::cout << array[count] << ' ';
}

// 覆盖完全特化的 StaticArray<char, 14> 的 print()
template <>
void print(const StaticArray<char, 14>& array)
{
	for (int count{ 0 }; count < 14; ++count)
		std::cout << array[count];
}

int main()
{
    // 声明一个 char 数组
    StaticArray<char, 14> char14{};

    // 向其中复制一些数据
    constexpr std::string_view hello{ "Hello, world!" };
    std::copy_n(hello.begin(), hello.size(), char14.getArray());

    // 打印数组
    print(char14);

    return 0;
}

如你所见，我们现在为完全特化的 StaticArray<char, 14>提供了一个重载的print函数。确实，这会打印：

Hello, world!

虽然这解决了确保print()可以调用 StaticArray<char, 14>的问题，但它带来了另一个问题：使用完全模板特化意味着我们必须显式定义该函数将接受的数组长度！考虑以下示例：

int main()
{
    // 声明一个 char 数组
    StaticArray<char, 12> char12{};

    // 向其中复制一些数据
    constexpr std::string_view hello{ "Hello, mom!" };
    std::copy_n(hello.begin(), hello.size(), char12.getArray());

    // 打印数组
    print(char12);

    return 0;
}

调用 print() 替换为 char12 将调用接受 print() 的 StaticArray<T, size>，因为 char12 的类型是 StaticArray<char, 12>版本，而我们的重载print()仅在传递 StaticArray<char, 14>。

时被调用。虽然我们可以为 StaticArray<char, 12>制作一个print()的副本，但当我们想用数组大小为5或22调用print()时会发生什么？我们必须为每个不同的数组大小复制该函数。这很冗余。

显然，完全模板特化在这里过于严格。我们需要的解决方案是部分模板特化。

部分模板特化

部分模板特化允许我们对类（但不能对单个函数！）进行特化，其中部分（但不是全部）模板参数已被显式定义。对于上面的挑战，理想的解决方案是让我们的重载print函数适用于类型为char的StaticArray，但保留长度表达式参数为模板化，以便它可以根据需要变化。部分模板特化正是让我们做到这一点！

下面是一个示例，其中包含一个重载的print函数，它接受一个部分特化的StaticArray：

// 为部分特化的 StaticArray<char, size> 重载 print() 函数
template <int size> // size 仍然是一个模板非类型参数
void print(const StaticArray<char, size>& array) // 我们在这里显式定义了类型 char
{
	for (int count{ 0 }; count < size; ++count)
		std::cout << array[count];
}

如你所见，我们显式声明了这个函数仅适用于类型为char的StaticArray，但size仍然是一个模板化的表达式参数，因此它适用于任何大小的char数组。仅此而已！

以下是使用此功能的完整程序：

#include <algorithm>
#include <iostream>
#include <string_view>

template <typename T, int size> // size 是表达式参数
class StaticArray
{
private:
	// 表达式参数控制数组的大小
	T m_array[size]{};

public:
	T* getArray() { return m_array; }

	const T& operator[](int index) const { return m_array[index]; }
	T& operator[](int index) { return m_array[index]; }
};

template <typename T, int size>
void print(const StaticArray<T, size>& array)
{
	for (int count{ 0 }; count < size; ++count)
		std::cout << array[count] << ' ';
}

// 为部分特化的 StaticArray<char, size> 重载 print() 函数
template <int size>
void print(const StaticArray<char, size>& array)
{
	for (int count{ 0 }; count < size; ++count)
		std::cout << array[count];
}

int main()
{
	// 声明一个大小为 14 的 char 数组
	StaticArray<char, 14> char14{};

	// 向其中复制一些数据
	constexpr std::string_view hello14{ "Hello, world!" };
	std::copy_n(hello14.begin(), hello14.size(), char14.getArray());

	// 打印数组
	print(char14);

	std::cout << ' ';

	// 现在声明一个大小为 12 的 char 数组
	StaticArray<char, 12> char12{};

	// 向其中复制一些数据
	constexpr std::string_view hello12{ "Hello, mom!" };
	std::copy_n(hello12.begin(), hello12.size(), char12.getArray());

	// 打印数组
	print(char12);

	return 0;
}

这会打印：

Hello, world! Hello, mom!

正如我们所期望的。

部分模板特化只能用于类，不能用于模板函数（函数必须完全特化）。我们的 void print(StaticArray<char, size> &array) 示例之所以有效，是因为print函数没有被部分特化（它只是一个重载的模板函数，恰好有一个部分特化的类参数）。

成员函数的部分模板特化

函数部分特化的限制可能导致处理成员函数时遇到一些挑战。例如，如果我们这样定义StaticArray会怎样？

template <typename T, int size>
class StaticArray
{
private:
    T m_array[size]{};
 
public:
    T* getArray() { return m_array; }
	
    const T& operator[](int index) const { return m_array[index]; }
    T& operator[](int index) { return m_array[index]; }

    void print() const;
};

template <typename T, int size> 
void StaticArray<T, size>::print() const
{
    for (int i{ 0 }; i < size; ++i)
        std::cout << m_array[i] << ' ';
    std::cout << '\n';
}

print()现在是类 StaticArray<T, int>的成员函数。那么，当我们想部分特化print()使其以不同方式工作时会发生什么？你可能会尝试这样：

// 不行，不能部分特化函数
template <int size>
void StaticArray<double, size>::print() const
{
	for (int i{ 0 }; i < size; ++i)
		std::cout << std::scientific << m_array[i] << ' ';
	std::cout << '\n';
}

不幸的是，这行不通，因为我们试图部分特化一个函数，这是不允许的。

那么如何解决这个问题呢？一个显而易见的方法是部分特化整个类：

#include <iostream>

template <typename T, int size>
class StaticArray
{
private:
	T m_array[size]{};

public:
	T* getArray() { return m_array; }

	const T& operator[](int index) const { return m_array[index]; }
	T& operator[](int index) { return m_array[index]; }

	void print() const;
};

template <typename T, int size> 
void StaticArray<T, size>::print() const
{
	for (int i{ 0 }; i < size; ++i)
		std::cout << m_array[i] << ' ';
	std::cout << '\n';
}

// 部分特化的类
template <int size>
class StaticArray<double, size>
{
private:
	double m_array[size]{};

public:
	double* getArray() { return m_array; }

	const double& operator[](int index) const { return m_array[index]; }
	double& operator[](int index) { return m_array[index]; }

	void print() const;
};

// 部分特化类的成员函数
template <int size>
void StaticArray<double, size>::print() const
{
	for (int i{ 0 }; i < size; ++i)
		std::cout << std::scientific << m_array[i] << ' ';
	std::cout << '\n';
}

int main()
{
	// 声明一个整数数组，可容纳 6 个整数
	StaticArray<int, 6> intArray{};

	// 按顺序填充，然后打印
	for (int count{ 0 }; count < 6; ++count)
		intArray[count] = count;

	intArray.print();

	// 声明一个可以容纳 4 个双精度数的双精度缓冲区
	StaticArray<double, 4> doubleArray{};

	for (int count{ 0 }; count < 4; ++count)
		doubleArray[count] = (4.0 + 0.1 * count);

	doubleArray.print();

	return 0;
}

这会打印：

0 1 2 3 4 5
4.000000e+00 4.100000e+00 4.200000e+00 4.300000e+00

这之所以有效，是因为 StaticArray<double, size>::print() 不再是一个部分特化的函数——它是部分特化类的一个非特化成员 StaticArray<double, size>。

然而，这并不是一个很好的解决方案，因为我们必须从 StaticArray<T, size> 切换到 StaticArray<double, size>。

中复制大量代码。 StaticArray<T, size> 在 StaticArray<double, size>。听起来像是继承的任务！

你可能会开始尝试这样编写代码：

template <int size> // size 是表达式参数
class StaticArray<double, size>: public StaticArray<T, size>

但这行不通，因为我们使用了 T 而没有定义它。没有语法允许我们以这种方式继承。

顺便说一句……

即使我们能够将 T 定义为一个类型模板参数，当 StaticArray<double, size> 被实例化时，编译器需要将 T 在 StaticArray<T, size> 替换为实际类型。它会使用什么实际类型呢？唯一合理的类型是 T=double，但这会导致 StaticArray<double, size> 继承自自身！

幸运的是，有一个变通方法，通过使用一个公共基类：

#include <iostream>

template <typename T, int size>
class StaticArray_Base
{
protected:
	T m_array[size]{};

public:
	T* getArray() { return m_array; }

	const T& operator[](int index) const { return m_array[index]; }
	T& operator[](int index) { return m_array[index]; }

	void print() const
	{
		for (int i{ 0 }; i < size; ++i)
			std::cout << m_array[i] << ' ';
		std::cout << '\n';
	}

	// 如果打算使用虚函数解析，别忘了虚析构函数
};

template <typename T, int size>
class StaticArray: public StaticArray_Base<T, size>
{
};

template <int size>
class StaticArray<double, size>: public StaticArray_Base<double, size>
{
public:

	void print() const
	{
		for (int i{ 0 }; i < size; ++i)
			std::cout << std::scientific << this->m_array[i] << ' ';
// 注意：上面一行中的 this-> 前缀是必需的。
// 有关原因，请参阅 https://stackoverflow.com/a/6592617 或 https://isocpp.org/wiki/faq/templates#nondependent-name-lookup-members 了解更多信息。
		std::cout << '\n';
	}
};

int main()
{
	// 声明一个整数数组，可容纳 6 个整数
	StaticArray<int, 6> intArray{};

	// 按顺序填充，然后打印
	for (int count{ 0 }; count < 6; ++count)
		intArray[count] = count;

	intArray.print();

	// 声明一个可以容纳 4 个双精度数的双精度缓冲区
	StaticArray<double, 4> doubleArray{};

	for (int count{ 0 }; count < 4; ++count)
		doubleArray[count] = (4.0 + 0.1 * count);

	doubleArray.print();

	return 0;
}

这会输出与上面相同的结果，但重复的代码显著减少。
