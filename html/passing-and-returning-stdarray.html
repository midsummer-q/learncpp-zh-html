17.3 — 传递和返回 std::array

● 机器译文 课程 17.3 查看英文原文

类型为 std::array 的对象可以像任何其他对象一样传递给函数。这意味着如果我们按值传递 std::array ，将会产生昂贵的拷贝。因此，我们通常通过（const）引用传递 std::array 以避免这种拷贝。

对于 std::array，元素类型和数组长度都是对象类型信息的一部分。因此，当我们使用 std::array 作为函数参数时，我们必须显式指定元素类型和数组长度：

#include <array>
#include <iostream>

void passByRef(const std::array<int, 5>& arr) // 我们必须在此处显式指定 <int, 5>
{
    std::cout << arr[0] << '\n';
}

int main()
{
    std::array arr{ 9, 7, 5, 3, 1 }; // CTAD 推导类型 std::array<int, 5>
    passByRef(arr);

    return 0;
}

CTAD（目前）不适用于函数参数，因此我们不能只指定 std::array 并让编译器推导模板参数。

使用函数模板传递 std::array 不同元素类型或长度的

要编写一个可以接受 std::array 任意元素类型或长度的函数，我们可以创建一个函数模板，将元素类型和长度都参数化 std::array，然后 C++ 将使用该函数模板实例化具有实际类型和长度的实际函数。

相关内容

我们在课程 11.6 -- 函数模板。

由于 std::array 定义如下：

template<typename T, std::size_t N> // N 是一个非类型模板参数
struct array;

我们可以创建一个使用相同模板参数声明的函数模板：

#include <array>
#include <iostream>

template <typename T, std::size_t N> // 注意，此模板参数声明与 std::array 的匹配
void passByRef(const std::array<T, N>& arr)
{
    static_assert(N != 0); // 如果这是零长度的 std::array，则失败

    std::cout << arr[0] << '\n';
}

int main()
{
    std::array arr{ 9, 7, 5, 3, 1 }; // 使用 CTAD 推断 std::array<int, 5>
    passByRef(arr);  // ok：编译器将实例化 passByRef(const std::array<int, 5>& arr)

    std::array arr2{ 1, 2, 3, 4, 5, 6 }; // 使用 CTAD 推断 std::array<int, 6>
    passByRef(arr2); // ok：编译器将实例化 passByRef(const std::array<int, 6>& arr)

    std::array arr3{ 1.2, 3.4, 5.6, 7.8, 9.9 }; // 使用 CTAD 推断 std::array<double, 5>
    passByRef(arr3); // ok：编译器将实例化 passByRef(const std::array<double, 5>& arr)

    return 0;
}

在上面的例子中，我们创建了一个名为 passByRef() 的函数模板，其参数类型为 std::array<T, N>。 T 和 N 在前一行的模板参数声明中定义： template <typename T, std::size_t N>。 T 是一个标准类型模板参数，允许调用者指定元素类型。 N 是一个类型为 std::size_t 的非类型模板参数，允许调用者指定数组长度。

警告

注意，用于 std::array 的非类型模板参数的类型应为 std::size_t，而不是 int！这是因为 std::array 定义为 template<class T, std::size_t N> struct array;。如果你使用 int 作为非类型模板参数的类型，编译器将无法将类型为 std::array<T, std::size_t> 的参数与类型为 std::array<T, int> 的参数匹配（模板不会进行转换）。

因此，当我们调用 passByRef(arr) 从 main() （其中 arr 被定义为 std::array<int, 5>），编译器将实例化并调用 void passByRef(const std::array<int, 5>& arr)。类似的过程也适用于 arr2 和 arr3。

因此，我们创建了一个单一的函数模板，它可以实例化函数来处理 std::array 任何元素类型和长度的参数！

如果需要，也可以只模板化两个模板参数中的一个。在以下示例中，我们只参数化 std::array的长度，但元素类型显式定义为 int：

#include <array>
#include <iostream>

template <std::size_t N> // 注意：这里只对长度进行了模板化
void passByRef(const std::array<int, N>& arr) // 我们将元素类型定义为 int
{
    static_assert(N != 0); // 如果这是零长度的 std::array，则失败

    std::cout << arr[0] << '\n';
}

int main()
{
    std::array arr{ 9, 7, 5, 3, 1 }; // 使用 CTAD 推断 std::array<int, 5>
    passByRef(arr);  // ok：编译器将实例化 passByRef(const std::array<int, 5>& arr)

    std::array arr2{ 1, 2, 3, 4, 5, 6 }; // 使用 CTAD 推断 std::array<int, 6>
    passByRef(arr2); // ok：编译器将实例化 passByRef(const std::array<int, 6>& arr)

    std::array arr3{ 1.2, 3.4, 5.6, 7.8, 9.9 }; // 使用 CTAD 推断 std::array<double, 5>
    passByRef(arr3); // 错误：编译器找不到匹配的函数

    return 0;
}

自动非类型模板参数 C++20

必须记住（或查找）非类型模板参数的类型，以便在自己的函数模板的模板参数声明中使用它，这很麻烦。

在 C++20 中，我们可以在模板参数声明中使用 auto ，让非类型模板参数从参数中推导其类型：

#include <array>
#include <iostream>

template <typename T, auto N> // 现在使用 auto 推导 N 的类型
void passByRef(const std::array<T, N>& arr)
{
    static_assert(N != 0); // 如果这是零长度的 std::array，则失败

    std::cout << arr[0] << '\n';
}

int main()
{
    std::array arr{ 9, 7, 5, 3, 1 }; // 使用 CTAD 推断 std::array<int, 5>
    passByRef(arr);  // ok：编译器将实例化 passByRef(const std::array<int, 5>& arr)

    std::array arr2{ 1, 2, 3, 4, 5, 6 }; // 使用 CTAD 推断 std::array<int, 6>
    passByRef(arr2); // ok：编译器将实例化 passByRef(const std::array<int, 6>& arr)

    std::array arr3{ 1.2, 3.4, 5.6, 7.8, 9.9 }; // 使用 CTAD 推断 std::array<double, 5>
    passByRef(arr3); // ok：编译器将实例化 passByRef(const std::array<double, 5>& arr)

    return 0;
}

如果你的编译器支持 C++20，这可以放心使用。

对数组长度进行静态断言

考虑以下模板函数，它与上面展示的类似：

#include <array>
#include <iostream>

template <typename T, std::size_t N>
void printElement3(const std::array<T, N>& arr)
{
    std::cout << arr[3] << '\n';
}

int main()
{
    std::array arr{ 9, 7, 5, 3, 1 };
    printElement3(arr);

    return 0;
}

虽然 printElement3() 在这种情况下工作正常，但程序中存在一个粗心的程序员可能遇到的潜在错误。看到了吗？

上面的程序打印了索引为 3 的数组元素的值。只要数组有一个有效的索引为 3 的元素，这就没问题。然而，编译器会愉快地允许你传入索引 3 越界的数组。例如：

#include <array>
#include <iostream>

template <typename T, std::size_t N>
void printElement3(const std::array<T, N>& arr)
{
    std::cout << arr[3] << '\n'; // 无效索引
}

int main()
{
    std::array arr{ 9, 7 }; // 一个包含2个元素的数组（有效索引0和1）
    printElement3(arr);

    return 0;
}

这会导致未定义行为。理想情况下，我们希望编译器在我们尝试这样做时发出警告！

模板参数相对于函数参数的一个优点是模板参数是编译时常量。这意味着我们可以利用需要常量表达式的能力。

因此，一种解决方案是使用 std::get() （它进行编译时边界检查）而不是 operator[] （它不进行边界检查）：

#include <array>
#include <iostream>

template <typename T, std::size_t N>
void printElement3(const std::array<T, N>& arr)
{
    std::cout << std::get<3>(arr) << '\n'; // 在编译时检查索引 3 是否有效
}

int main()
{
    std::array arr{ 9, 7, 5, 3, 1 };
    printElement3(arr); // 好的

    std::array arr2{ 9, 7 };
    printElement3(arr2); // 编译错误

    return 0;
}

当编译器到达对 printElement3(arr2)的调用时，它将实例化函数 printElement3(const std::array<int, 2>&)。在该函数体内，有这一行 std::get<3>(arr)。由于数组参数的长度为 2，这是一个无效访问，编译器将发出错误。

另一种解决方案是使用 static_assert 自己验证数组长度的前置条件：

相关内容

我们在课程中介绍了前置条件 9.6 -- Assert 和 static_assert。

#include <array>
#include <iostream>

template <typename T, std::size_t N>
void printElement3(const std::array<T, N>& arr)
{
    // 前置条件：数组长度必须大于 3，以便元素 3 存在
    static_assert (N > 3);

    // 我们可以假设数组长度在此之后大于 3

    std::cout << arr[3] << '\n';
}

int main()
{
    std::array arr{ 9, 7, 5, 3, 1 };
    printElement3(arr); // 好的

    std::array arr2{ 9, 7 };
    printElement3(arr2); // 编译错误

    return 0;
}

当编译器到达对 printElement3(arr2)的调用时，它将实例化函数 printElement3(const std::array<int, 2>&)。在该函数体内，有这一行 static_assert (N > 3)。由于 N 模板非类型参数的值 2、和 2 > 3 为 false，编译器将发出错误。

关键提示

在上面的例子中，你可能想知道为什么我们使用 static_assert (N > 3); 而不是 static_assert (std::size(arr) > 3)。后者在 C++23 之前无法编译，因为前一课中提到的语言缺陷（17.2 -- std::array 长度和索引)。

返回一个 std::array

抛开语法不谈，将 std::array 传递给函数在概念上很简单——通过（const）引用传递。但如果有一个函数需要返回一个 std::array呢？事情就有点复杂了。与 std::vector， std::array 不同，它不支持移动，因此按值返回 std::array 会复制数组。数组中的元素如果支持移动则会被移动，否则会被复制。

这里有两种常规选择，选择哪一种取决于具体情况。

返回一个 std::array 按值传递

当满足以下所有条件时，按值返回 std:array 是可以的：

  • 数组不大。
  • 元素类型复制（或移动）成本低。
  • 代码不在性能敏感的环境中使用。

在这种情况下，会复制一份 std::array ，但如果以上条件都满足，性能影响很小，坚持使用最常规的方式将数据返回给调用者可能是最佳选择。

#include <array>
#include <iostream>
#include <limits>

// 按值返回
template <typename T, std::size_t N>
std::array<T, N> inputArray() // 按值返回
{
	std::array<T, N> arr{};
	std::size_t index { 0 };
	while (index < N)
	{
		std::cout << "Enter value #" << index << ": ";
		std::cin >> arr[index];

		if (!std::cin) // 处理错误输入
		{
			std::cin.clear();
			std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
			continue;
		}
		++index;
	}

	return arr;
}

int main()
{
	std::array<int, 5> arr { inputArray<int, 5>() };

	std::cout << "The value of element 2 is " << arr[2] << '\n';

	return 0;
}

这种方法有几个好处：

  • 它使用最常规的方式将数据返回给调用者。
  • 很明显函数正在返回一个值。
  • 我们可以定义一个数组，并用该函数在单个语句中初始化它。

也有一些缺点：

  • 函数返回数组及其所有元素的副本，这并不便宜。
  • 当我们调用函数时，必须显式提供模板参数，因为没有参数可以推导它们。

返回一个 std::array 通过输出参数

在按值返回成本过高的情况下，我们可以改用输出参数。在这种情况下，调用者负责通过非 const 引用（或地址）传入 std::array ，然后函数可以修改这个数组。

#include <array>
#include <limits>
#include <iostream>

template <typename T, std::size_t N>
void inputArray(std::array<T, N>& arr) // 通过非 const 引用传递
{
	std::size_t index { 0 };
	while (index < N)
	{
		std::cout << "Enter value #" << index << ": ";
		std::cin >> arr[index];

		if (!std::cin) // 处理错误输入
		{
			std::cin.clear();
			std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
			continue;
		}
		++index;
	}

}

int main()
{
	std::array<int, 5> arr {};
	inputArray(arr);

	std::cout << "The value of element 2 is " << arr[2] << '\n';

	return 0;
}

这种方法的主要优点是从不复制数组，因此效率高。

也有一些缺点：

  • 这种返回数据的方法非常规，不容易看出函数正在修改参数。
  • 我们只能使用这种方法为数组赋值，而不能初始化它。
  • 这样的函数不能用于生成临时对象。

返回一个 std::vector 代替

std::vector 支持移动，可以按值返回而无需进行昂贵的复制。如果你按值返回 std::array ，你的 std::array 可能不是 constexpr，你应该考虑使用（并返回） std::vector 的别名。

小测验时间

问题 #1

完成以下程序：

#include <array>
#include <iostream>

int main()
{
    constexpr std::array arr1 { 1, 4, 9, 16 };
    printArray(arr1);

    constexpr std::array arr2 { 'h', 'e', 'l', 'l', 'o' };
    printArray(arr2);
    
    return 0;
}

运行时，它应该打印：

The array (1, 4, 9, 16) has length 4
The array (h, e, l, l, o) has length 5

显示答案

#include <array>
#include <iostream>

template <typename T, std::size_t N>
void printArray(const std::array<T, N>& arr)
{
    std::cout << "The array (";

    auto separator {""};
    for (const auto& e: arr)
    {
        std::cout << separator << e;
        separator = ", ";
    }
    
    std::cout << ") has length " << N << '\n';
}

int main()
{
    constexpr std::array arr1 { 1, 4, 9, 16 };
    printArray(arr1);

    constexpr std::array arr2 { 'h', 'e', 'l', 'l', 'o' };
    printArray(arr2);
    
    return 0;
}
