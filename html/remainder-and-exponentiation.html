6.3 — 取余与幂运算

● 机器译文 课程 6.3 查看英文原文

取余运算符（operator%)

浮点类型的 取余运算符 （也常称为 模运算符 或 模运算符）是一种返回整数除法余数的运算符。例如，7 / 4 = 1 余 3，因此 7 % 4 = 3。另一个例子，25 / 7 = 3 余 4，所以 25 % 7 = 4。取余运算符仅适用于整数操作数。

这在测试一个数是否能被另一个数整除（即除法后没有余数）时最为有用：如果 x % y 等于 0，那么我们就知道 x 能被 y。

#include <iostream>

int main()
{
	std::cout << "Enter an integer: ";
	int x{};
	std::cin >> x;

	std::cout << "Enter another integer: ";
	int y{};
	std::cin >> y;

	std::cout << "The remainder is: " << x % y << '\n';

	if ((x % y) == 0)
		std::cout << x << " is evenly divisible by " << y << '\n';
	else
		std::cout << x << " is not evenly divisible by " << y << '\n';

	return 0;
}

以下是该程序的几次运行结果：

Enter an integer: 6
Enter another integer: 3
The remainder is: 0
6 is evenly divisible by 3

Enter an integer: 6
Enter another integer: 4
The remainder is: 2
6 is not evenly divisible by 4

现在让我们尝试一个第二个数比第一个数大的例子：

Enter an integer: 2
Enter another integer: 4
The remainder is: 2
2 is not evenly divisible by 4

余数为 2 一开始可能不太明显，但其实很简单：2 / 4 等于 0（使用整数除法）余 2。每当第二个数大于第一个数时，第二个数除第一个数 0 次，所以第一个数就是余数。

负数取余

取余运算符也可以用于负数操作数。 x % y 总是返回与 x。

运行上述程序：

Enter an integer: -6
Enter another integer: 4
The remainder is: -2
-6 is not evenly divisible by 4

Enter an integer: 6
Enter another integer: -4
The remainder is: 2
6 is not evenly divisible by -4

在这两种情况下，你可以看到余数取第一个操作数的符号。

术语

C++ 标准实际上并没有给 operator%命名。然而，C++20 标准确实指出，“二元 % 运算符返回第一个表达式除以第二个表达式的余数”。

尽管 operator% 通常被称为“取模”或“模”运算符，但这可能会造成混淆，因为数学中的模通常定义方式会产生与 operator% 在C++中，当一个（且仅有一个）操作数为负数时产生的结果。

例如，在数学中：
-21 模 4 = 3
-21 余 4 = -1

因此，我们认为“余数”这个名称对于 operator% 而非“取模”。

当第一个操作数可能为负数时，必须注意余数也可能为负数。例如，你可能会想编写一个函数来判断一个数是否为奇数，像这样：

bool isOdd(int x)
{
    return (x % 2) == 1; // 当 x 为 -5 时失败
}

然而，当 x 是负奇数时，这将失败，例如 -5，因为 -5 % 2 是 -1，且 -1 != 1。

因此，如果要比较取余运算的结果，最好与0比较，因为0没有正负数问题：

bool isOdd(int x)
{
    return (x % 2) != 0; // 也可以写成 return (x % 2)
}

最佳实践

优先比较取模运算符的结果（operator%) 与 0 进行比较（如果可能）。

指数运算符在哪里？

你会注意到 ^ 运算符（在数学中通常用于表示乘方）是一个 按位异或 C++ 中的操作（在课程 O.3 -- 使用位运算符和位掩码进行位操作)。C++ 不包含指数运算符。

要在C++中进行指数运算，请包含<cmath>头文件，并使用pow()函数：

#include <cmath>

double x{ std::pow(3.0, 4.0) }; // 3 的 4 次方

注意，函数 pow() 的参数（和返回值）类型是 double。由于浮点数的舍入误差，pow() 的结果可能不精确（即使你传入整数或整数值也是如此）。

如果你想要进行整数幂运算，最好使用自己的函数来实现。下面的函数实现了整数幂运算（使用非直观的“快速幂”算法以提高效率）：

#include <cassert> // for assert
#include <cstdint> // for std::int64_t
#include <iostream>

// 注意：exp 必须为非负数
// 注意：不执行范围/溢出检查，请谨慎使用
constexpr std::int64_t powint(std::int64_t base, int exp)
{
	assert(exp >= 0 && "powint: exp parameter has negative value");

	// 处理0的情况
	if (base == 0)
		return (exp == 0) ? 1 : 0;

	std::int64_t result{ 1 };
	while (exp > 0)
	{
		if (exp & 1)  // 如果 exp 是奇数
			result *= base;
		exp /= 2;
		base *= base;
	}

	return result;
}

int main()
{
	std::cout << powint(7, 12) << '\n'; // 7的12次方

	return 0;
}

输出：

13841287201

如果你不理解这个函数是如何工作的，不用担心——你不需要理解它就能调用它。

相关内容

我们在课程中介绍断言 9.6 -- Assert 和 static_assert，以及第 F.1 -- Constexpr函数。

进阶读者

浮点类型的 constexpr 说明符允许函数在常量表达式中在编译时求值；否则，它像普通函数一样在运行时求值。

警告

在绝大多数情况下，整数幂运算会导致整型溢出。这很可能就是标准库最初没有包含此类函数的原因。

下面是一个更安全的指数函数版本，它会检查溢出：

#include <cassert> // for assert
#include <cstdint> // for std::int64_t
#include <iostream>
#include <limits> // for std::numeric_limits

// 一个更安全（但更慢）的 powint() 版本，用于检查溢出
// 注意：exp 必须为非负数
// 如果发生溢出，返回 std::numeric_limits<std::int64_t>::max()
constexpr std::int64_t powint_safe(std::int64_t base, int exp)
{
    assert(exp >= 0 && "powint_safe: exp parameter has negative value");

    // 处理0的情况
    if (base == 0)
        return (exp == 0) ? 1 : 0;

    std::int64_t result { 1 };

    // 为了简化范围检查，我们将确保 base 为正数
    // 如果需要，我们会在最后翻转结果
    bool negativeResult{ false };

    if (base < 0)
    {
        base = -base;
        negativeResult = (exp & 1);
    }

    while (exp > 0)
    {
        if (exp & 1) // 如果 exp 是奇数
        {
            // 检查结果乘以基数时是否会溢出
            if (result > std::numeric_limits<std::int64_t>::max() / base)
            {
                std::cerr << "powint_safe(): result overflowed\n";
                return std::numeric_limits<std::int64_t>::max();
            }

            result *= base;
        }

        exp /= 2;

        // 如果完成了，就离开这里
        if (exp <= 0)
            break;

        // 以下仅当我们要再次迭代时才需要执行

        // 检查 base 乘以自身时是否会溢出
        if (base > std::numeric_limits<std::int64_t>::max() / base)
        {
            std::cerr << "powint_safe(): base overflowed\n";
            return std::numeric_limits<std::int64_t>::max();
        }

        base *= base;
    }

    if (negativeResult)
        return -result;

    return result;
}

int main()
{
	std::cout << powint_safe(7, 12) << '\n'; // 7的12次方
	std::cout << powint_safe(70, 12) << '\n'; // 70 的 12 次方（将返回最大 64 位整数值）

	return 0;
}

小测验时间

问题 #1

以下表达式的结果是什么？ 6 + 5 * 4 % 3

显示答案

因为 * 和 % 的优先级高于 +，所以 + 最后求值。我们可以将表达式重写为 6 + (5 * 4 % 3)。运算符 * 和 % 具有相同的优先级，因此我们必须查看结合性来解决它们。运算符 * 和 % 的结合性是从左到右，所以我们先解析左边的运算符。我们可以这样重写表达式：6 + ((5 * 4) % 3)。

6 + ((5 * 4) % 3) = 6 + (20 % 3) = 6 + 2 = 8

问题 #2

编写一个程序，要求用户输入一个整数，并告知用户该数字是偶数还是奇数。编写一个名为 isEven() 如果传递给它的整数是偶数则返回true，否则返回false。使用取余运算符来测试整数参数是否为偶数。确保 isEven() 适用于正数和负数。

显示提示

提示：你可能需要在此程序中使用 if 语句和比较运算符 (==)。请参阅课程 4.9 -- 布尔值 如果你需要复习如何做到这一点。

您的程序应匹配以下输出：

Enter an integer: 5
5 is odd

显示答案

#include <iostream>

constexpr bool isEven(int x)
{
    // 如果 x % 2 == 0，则 2 能整除我们的数字，这意味着它必须是偶数
    return (x % 2) == 0;
}

int main()
{
    std::cout << "Enter an integer: ";
    int x{};
    std::cin >> x;

    if (isEven(x))
        std::cout << x << " is even\n";
    else
        std::cout << x << " is odd\n";

    return 0;
}

注意：你可能曾想这样编写 isEven() 函数：

constexpr bool isEven(int x)
{
    if ((x % 2) == 0)
        return true;
    else
        return false;
}

虽然这样可行，但比实际需要的更复杂。让我们看看如何简化它。首先，把 if 语句的条件提取出来，赋给一个单独的布尔变量：

constexpr bool isEven(int x)
{
    bool isEven = (x % 2) == 0;
    if (isEven) // isEven 为真
        return true;
    else // isEven 为 false
        return false;
}

现在，注意上面的 if 语句本质上是在说“如果 isEven 为真，则返回真，否则如果 isEven 为假，则返回假”。如果是这样，我们可以直接返回 isEven：

constexpr bool isEven(int x)
{
    bool isEven = (x % 2) == 0;
    return isEven;
}

在这种情况下，由于我们只使用一次变量 isEven，我们不妨消除这个变量：

constexpr bool isEven(int x)
{
    return (x % 2) == 0;
}
