9.5 — std::cin 与处理无效输入

● 机器译文 课程 9.5 查看英文原文

大多数具有某种用户界面的程序都需要处理用户输入。在你编写的程序中，你一直使用 std::cin 来要求用户输入文本。由于文本输入非常自由（用户可以输入任何内容），用户很容易输入不符合预期的内容。

在编写程序时，你应该始终考虑用户将如何（无意或其他方式）误用你的程序。一个编写良好的程序会预测用户如何误用它，并优雅地处理这些情况，或者从一开始就防止它们发生（如果可能）。能够良好处理错误情况的程序被称为 健壮的。

在本课中，我们将专门研究用户通过 std::cin 输入无效文本的方式，并向你展示处理这些情况的一些不同方法。

在我们讨论 std::cin 和 operator>> 如何失败之前，让我们回顾一下它们的工作原理。我们在课程 1.5 -- iostream入门：cout, cin和endl。

中讨论过这些内容。以下是 operator>> 输入工作的简化视图：

  1. 首先，前导空白字符（缓冲区开头的空格、制表符和换行符）会从输入缓冲区中被丢弃。这将丢弃前一行输入中未提取的换行符。
  2. 如果输入缓冲区现在为空， operator>> 将等待用户输入更多数据。再次丢弃前导空白字符。
  3. operator>> 然后尽可能多地提取连续字符，直到遇到换行符（表示输入行结束）或对于正在提取的变量无效的字符为止。

提取的结果如下：

  • 如果在上述步骤3中提取了任何字符，则提取成功。提取的字符被转换为一个值，然后赋值给变量。
  • 如果在上述步骤3中未能提取任何字符，则提取失败。被提取的对象被赋值为 0 （自C++11起），并且任何未来的提取都会立即失败（直到 std::cin 被清除）。

验证输入

检查用户输入是否符合程序预期的过程称为 输入验证。

有三种基本方法进行输入验证：

内联（用户输入时）：

  1. 首先阻止用户输入无效输入。

输入后（用户输入后）：

  1. 让用户将任何内容输入到字符串中，然后验证字符串是否正确，如果正确，则将字符串转换为最终的变量格式。
  2. 让用户输入任何内容，让 std::cin 和 operator>> 尝试提取它，并处理错误情况。

一些图形用户界面和高级文本界面允许你在用户输入时（逐字符）验证输入。通常，程序员提供一个验证函数，该函数接受用户到目前为止输入的输入，如果输入有效则返回 true，否则返回 false。每次用户按键时都会调用此函数。如果验证函数返回 true，则接受用户刚刚按下的键。如果验证函数返回 false，则丢弃用户刚刚输入的字符（并且不显示在屏幕上）。使用这种方法，你可以确保用户输入的任何输入都保证有效，因为任何无效的按键都会被立即发现并丢弃。不幸的是，std::cin 不支持这种验证方式。

由于字符串对可以输入的字符没有任何限制，提取保证成功（尽管请记住 std::cin 在第一个非前导空白字符处停止提取）。一旦输入了字符串，程序就可以解析该字符串以查看它是否有效。然而，解析字符串并将字符串输入转换为其他类型（例如数字）可能具有挑战性，因此仅在少数情况下这样做。

大多数情况下，我们让 std::cin 和提取运算符来完成繁重的工作。在这种方法下，我们让用户输入他们想要的任何内容，让 std::cin 和 operator>> 尝试提取它，并在失败时处理后果。这是最简单的方法，也是我们下面将要更多讨论的方法。

示例程序

考虑以下没有错误处理的计算器程序：

#include <iostream>
 
double getDouble()
{
    std::cout << "Enter a decimal number: ";
    double x{};
    std::cin >> x;
    return x;
}
 
char getOperator()
{
    std::cout << "Enter one of the following: +, -, *, or /: ";
    char op{};
    std::cin >> op;
    return op;
}
 
void printResult(double x, char operation, double y)
{
    std::cout << x << ' ' << operation << ' ' << y << " is ";

    switch (operation)
    {
    case '+':
        std::cout << x + y << '\n';
        return;
    case '-':
        std::cout << x - y << '\n';
        return;
    case '*':
        std::cout << x * y << '\n';
        return;
    case '/':
        std::cout << x / y << '\n';
        return;
    }
}
 
int main()
{
    double x{ getDouble() };
    char operation{ getOperator() };
    double y{ getDouble() };

    printResult(x, operation, y);
 
    return 0;
}

这个简单的程序要求用户输入两个数字和一个数学运算符。

Enter a decimal number: 5
Enter one of the following: +, -, *, or /: *
Enter a decimal number: 7
5 * 7 is 35

现在，考虑无效的用户输入可能在哪里破坏这个程序。

首先，我们要求用户输入一些数字。如果他们输入了数字以外的内容（例如 'q'）怎么办？在这种情况下，提取将失败。

其次，我们要求用户输入四个可能的符号之一。如果他们输入了我们期望的符号以外的字符怎么办？我们将能够提取输入，但我们目前没有处理之后发生的事情。

第三，如果我们要求用户输入一个符号，而他们输入了一个像 "*q hello"这样的字符串。虽然我们可以提取我们需要的 '*' 字符，但缓冲区中还有额外的输入，这可能会在以后引起问题。

无效文本输入的类型

我们通常可以将输入文本错误分为四种类型：

  • 输入提取成功，但输入对程序无意义（例如，输入 'k' 作为数学运算符）。
  • 输入提取成功，但用户输入了额外的输入（例如，输入 '*q hello' 作为数学运算符）。
  • 输入提取失败（例如，尝试在数字输入中输入‘q’）。
  • 输入提取成功，但用户溢出了一个数值。

因此，为了使我们的程序健壮，每当我们要求用户输入时，理想情况下我们应该确定上述每种情况是否可能发生，如果可能，编写代码来处理这些情况。

让我们深入探讨每种情况，以及如何使用 std::cin 处理它们。

错误情况 1：提取成功但输入无意义

这是最简单的情况。考虑上述程序的以下执行：

Enter a decimal number: 5
Enter one of the following: +, -, *, or /: k
Enter a decimal number: 7

在这种情况下，我们要求用户输入四个符号之一，但他们输入了‘k’。‘k’是一个有效字符，因此 std::cin 愉快地将其提取到变量 op中，然后返回给 main。但我们的程序没有预料到这种情况，因此没有正确处理。结果，它输出：

5 k 7 is

解决方案很简单：进行输入验证。这通常包括三个步骤：

  1. 检查用户的输入是否是你期望的。
  2. 如果是，将值返回给调用者。
  3. 如果不是，告诉用户出了问题，让他们重试。

这是一个更新后的 getOperator() 函数，它执行输入验证。

char getOperator()
{
    while (true) // 循环直到用户输入有效输入
    {
        std::cout << "Enter one of the following: +, -, *, or /: ";
        char operation{};
        std::cin >> operation;

        // 检查用户是否输入了有意义的内容
        switch (operation)
        {
        case '+':
        case '-':
        case '*':
        case '/':
            return operation; // 将其返回给调用者
        default: // 否则告诉用户哪里出了问题
            std::cout << "Oops, that input is invalid.  Please try again.\n";
        }
    } // 并重试
}

如你所见，我们使用 while 循环不断循环，直到用户提供有效输入。如果他们不提供，我们要求他们重试，直到他们给出有效输入、关闭程序或摧毁他们的计算机。

错误情况 2：提取成功但有多余输入

考虑上述程序的以下执行：

Enter a decimal number: 5*7

你认为接下来会发生什么？

Enter a decimal number: 5*7
Enter one of the following: +, -, *, or /: Enter a decimal number: 5 * 7 is 35

程序打印了正确答案，但格式全乱了。让我们仔细看看原因。

当用户输入 5*7 作为输入，该输入进入缓冲区。然后 operator>> 将 5 提取到变量 x，留下 *7\n 在缓冲区中。接下来，程序打印“Enter one of the following: +, -, *, or /:”。然而，当调用提取运算符时，它看到 *7\n 在缓冲区中等待提取，因此它使用该字符而不是要求用户输入更多。结果，它提取了‘*’字符，留下 7\n 在缓冲区中。

在要求用户输入另一个十进制数后， 7 缓冲区中的被提取出来，而没有询问用户。由于用户没有机会输入额外数据并按下回车（导致换行），所有输出提示都挤在同一行上。

尽管上述程序可以工作，但执行过程很混乱。最好忽略任何输入的多余字符。幸运的是，忽略字符很容易：

std::cin.ignore(100, '\n');  // 清除缓冲区中最多 100 个字符，或直到移除 '\n' 字符

这个调用会移除最多 100 个字符，但如果用户输入了超过 100 个字符，我们又会得到混乱的输出。要忽略直到下一个‘\n’的所有字符，我们可以传递 std::numeric_limits<std::streamsize>::max() 切换到 >std::cin.ignore()。 std::numeric_limits<std::streamsize>::max() 返回可以存储在类型为 std::streamsize的变量中的最大值。将此值传递给 std::cin.ignore() 会使其禁用计数检查。

要忽略直到并包括下一个‘\n’字符的所有内容，我们调用

std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');

因为这行代码对于它所做的事情来说相当长，所以将其包装在一个函数中很方便，该函数可以代替 std::cin.ignore()。

#include <limits> // for std::numeric_limits

void ignoreLine()
{
    std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
}

由于用户输入的最后一个字符通常是‘\n’，我们可以告诉 std::cin 忽略缓冲的字符，直到找到换行符（该换行符也会被移除）。

让我们更新我们的 getDouble() 函数以忽略任何多余输入：

double getDouble()
{
    std::cout << "Enter a decimal number: ";
    double x{};
    std::cin >> x;

    ignoreLine();
    return x;
}

现在我们的程序将按预期工作，即使我们输入 5*7 作为第一个输入——5 将被提取，其余字符将从输入缓冲区中移除。由于输入缓冲区现在为空，下次执行提取操作时，用户将被正确要求输入！

提示

在某些情况下，将多余输入视为失败情况（而不是仅仅忽略它）可能更好。然后我们可以要求用户重新输入。

这是 getDouble() 的一个变体，要求用户在输入多余内容时重新输入：

// 如果 std::cin 在当前行有未提取的输入则返回 true，否则返回 false
bool hasUnextractedInput()
{
    return !std::cin.eof() && std::cin.peek() != '\n';
}

double getDouble()
{
    while (true) // 循环直到用户输入有效输入
    {
        std::cout << "Enter a decimal number: ";
        double x{};
        std::cin >> x;

        // 注意：你应该在此处检查提取是否失败（参见下面的章节）

        // 如果存在多余输入，则视为失败情况
        if (hasUnextractedInput())
        {
            ignoreLine(); // 移除多余输入
            continue;
        }
    
        return x;
    }
}

上面的代码片段使用了两个我们之前没见过的函数：

  • 浮点类型的 std::cin.eof() 函数返回 true 如果最后一次输入操作（这里是对 x的提取）到达了输入流的末尾。
  • 浮点类型的 std::cin.peek() 函数允许我们查看输入流中的下一个字符而不提取它。

这个函数的工作原理如下。在用户的输入被提取到 x之后， std::cin。

中可能还有额外的（未提取的）字符。首先，我们调用 std::cin.eof() 来检查对 x 的提取是否到达了输入流的末尾。如果是，那么我们知道所有字符都被提取了，这是一个成功的情况。

否则， std::cin 中一定还有额外的字符等待提取。在这种情况下，我们调用 std::cin.peek() 来查看下一个等待提取的字符，而不实际提取它。如果下一个字符是 '\n'，这意味着我们已经将这一行输入中的所有字符都提取到了 x。这也是一个成功的情况。

然而，如果下一个字符不是 '\n'，那么用户一定输入了未被提取到 x的多余输入。这就是我们的失败情况。我们清除所有多余输入，然后 continue 回到循环顶部重试。

如果你在理解 hasUnextractedInput() 中的布尔表达式如何求值时遇到困难，这并不奇怪——带有否定的布尔表达式可能难以理解。在这种情况下，使用德摩根定律会有所帮助。一个等价的语句是 return !(std::cin.eof() || std::cin.peek() == '\n');。这更清楚地表明我们正在测试 EOF 或换行符。如果两者之一为真，那么我们已经提取了所有输入。然后我们应用 operator! 来告诉我们是否还没有提取所有输入，这意味着还有未提取的输入。

错误情况 3：提取失败

当无法将输入提取到指定变量时，提取失败。

现在考虑我们更新后的计算器程序的以下执行：

Enter a decimal number: a

你不应该对程序没有按预期执行感到惊讶，但它的失败方式很有趣：

Enter a decimal number: a
Enter one of the following: +, -, *, or /: Oops, that input is invalid.  Please try again.
Enter one of the following: +, -, *, or /: Oops, that input is invalid.  Please try again.
Enter one of the following: +, -, *, or /: Oops, that input is invalid.  Please try again.

并且最后一行不断打印，直到程序关闭。

这看起来与多余输入的情况非常相似，但略有不同。让我们仔细看看。

当用户输入 'a' 时，该字符被放入缓冲区。然后 operator>> 尝试将 'a' 提取到类型为 double 的变量 x 中。由于 'a' 无法转换为 double， operator>> 无法进行提取。此时会发生两件事：'a' 留在缓冲区中，并且 std::cin 进入“失败模式”。

一旦进入“失败模式”，后续的输入提取请求将静默失败。因此，在我们的计算器程序中，输出提示仍然打印，但任何进一步的提取请求都被忽略。这意味着我们不会等待输入操作，而是跳过输入提示，并陷入无限循环，因为无法到达任何有效情况。

为了让 std::cin 恢复正常工作，我们通常需要做三件事：

  • 检测先前的提取是否失败。
  • 将 std::cin 恢复到正常操作模式。
  • 移除导致失败的输入（这样下一个提取请求就不会以相同的方式失败）。

这是它的样子：

if (std::cin.fail()) // 如果之前的提取失败
{
    // 让我们处理失败
    std::cin.clear(); // 将我们恢复到“正常”操作模式
    ignoreLine();     // 并移除错误的输入
}

因为 std::cin 有一个布尔转换，指示上一次输入是否成功，更地道的写法是将上述代码写成如下形式：

if (!std::cin) // 如果之前的提取失败
{
    // 让我们处理失败
    std::cin.clear(); // 将我们恢复到“正常”操作模式
    ignoreLine();     // 并移除错误的输入
}

关键提示

一旦提取失败，后续的输入提取请求（包括调用 ignore()）将静默失败，直到调用 clear() 函数。因此，在检测到提取失败后，调用 clear() 通常是你应该做的第一件事。

让我们将其整合到我们的 getDouble() 函数中：

double getDouble()
{
    while (true) // 循环直到用户输入有效输入
    {
        std::cout << "Enter a decimal number: ";
        double x{};
        std::cin >> x;

        if (!std::cin) // 如果之前的提取失败
        {
            // 让我们处理失败
            std::cin.clear(); // 将我们恢复到“正常”操作模式
            ignoreLine();     // 并移除错误的输入
            continue;
        }

        // 我们的提取成功
        ignoreLine(); // 忽略该行上的任何额外输入
        return x;     // 返回我们提取的值
    }
}

对于基本类型，由于无效输入导致的提取失败会使变量被赋值为 0 （或任何 0 在变量类型中转换成的值）。

即使提取没有失败，调用 clear() 也是可以的——它不会做任何事情。在我们无论成功还是失败都要调用 ignoreLine() 的情况下，我们可以将两种情况合并：

double getDouble()
{
    while (true) // 循环直到用户输入有效输入
    {
        std::cout << "Enter a decimal number: ";
        double x{};
        std::cin >> x;

        bool success { std::cin }; // 记住我们是否成功提取
        std::cin.clear();          // 将我们恢复到“正常”操作模式（以防我们失败）
        ignoreLine();              // 忽略该行上的任何额外输入（无论是否成功）

        if (success)               // 如果我们确实提取了一个值
            return x;              // 返回它（否则，我们回到循环顶部）
    }
}

检查 EOF

还有另一种情况需要处理。

文件结束符（EOF）是一种特殊的错误状态，表示“没有更多数据可用”。这通常是在 之后 输入操作因没有可用数据而失败时产生的。例如，如果你正在读取磁盘文件的内容，并且在已经到达文件末尾后尝试读取更多数据，就会产生 EOF 来告诉你没有更多数据了。对于文件输入来说，这没问题——我们可以直接关闭文件并继续。

现在考虑 std::cin。如果我们尝试从 std::cin 提取输入但没有输入，按照设计它不会产生 EOF——它只会等待用户输入更多内容。然而， std::cin 在某些情况下可以产生 EOF——最常见的是用户输入了其操作系统的特殊组合键。Unix（通过 ctrl-D）和 Windows（通过 ctrl-Z + ENTER）都支持从键盘输入“EOF 字符”。

关键提示

在 C++ 中，EOF 是一种错误状态，而不是一个字符。不同的操作系统有特殊的字符组合，被视为“用户输入的 EOF 请求”。这些有时被称为“EOF 字符”。

当提取数据到 std::cin 并且用户输入了 EOF 字符时，行为是操作系统特定的。以下是通常发生的情况：

  • 如果 EOF 不是输入的第一个字符：EOF 之前的所有输入将被刷新，EOF 字符被忽略。在 Windows 上，EOF 之后输入的任何字符（换行符除外）都会被忽略。
  • 如果 EOF 是输入的第一个字符：将设置 EOF 错误。输入流可能会（也可能不会）断开。

尽管 std::cin.clear() 会清除 EOF 错误，但如果输入流已断开，下一次输入请求将产生另一个 EOF 错误。当我们的输入位于 while(true) 循环中时，这就有问题了，因为我们会陷入 EOF 错误的无限循环。

由于键盘输入的 EOF 字符的目的是终止输入流，最好的做法是检测 EOF（通过 std::cin.eof()）然后终止程序。

因为清除失败的输入流是我们经常需要检查的事情，所以这是一个很好的可重用函数候选：

#include <limits> // for std::numeric_limits

void ignoreLine()
{
    std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
}

// 如果提取失败则返回 true，否则返回 false
bool clearFailedExtraction()
{
    // 检查提取是否失败
    if (!std::cin) // 如果之前的提取失败
    {
        if (std::cin.eof()) // 如果用户输入了 EOF
        {
            std::exit(0); // 立即关闭程序
        }

        // 让我们处理失败
        std::cin.clear(); // 将我们恢复到“正常”操作模式
        ignoreLine();     // 并移除错误的输入

        return true;
    }
    
    return false;
}

错误情况 4：提取成功但用户溢出了数值

考虑以下简单示例：

#include <cstdint>
#include <iostream>

int main()
{
    std::int16_t x{}; // x 是 16 位，范围从 -32768 到 32767
    std::cout << "Enter a number between -32768 and 32767: ";
    std::cin >> x;

    std::int16_t y{}; // y 是 16 位，范围从 -32768 到 32767
    std::cout << "Enter another number between -32768 and 32767: ";
    std::cin >> y;

    std::cout << "The sum is: " << x + y << '\n';
    return 0;
}

如果用户输入了一个太大的数字（例如 40000）会发生什么？

Enter a number between -32768 and 32767: 40000
Enter another number between -32768 and 32767: The sum is: 32767

在上述情况下， std::cin 立即进入“失败模式”，但也会将最接近范围内的值赋给变量。当输入的值大于该类型可能的最大值时，最接近范围内的值就是该类型的最大值。因此， x 被赋值为 32767。后续输入被跳过，使得 y 保持初始化的值 0我们可以用与处理提取失败相同的方式来处理这种错误。

综合运用

下面是我们更新后的计算器示例，增加了一些额外的错误检查：

#include <cstdlib> // for std::exit
#include <iostream>
#include <limits> // for std::numeric_limits

void ignoreLine()
{
    std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
}

// 如果提取失败则返回 true，否则返回 false
bool clearFailedExtraction()
{
    // 检查提取是否失败
    if (!std::cin) // 如果之前的提取失败
    {
        if (std::cin.eof()) // 如果流已关闭
        {
            std::exit(0); // 立即关闭程序
        }

        // 让我们处理失败
        std::cin.clear(); // 将我们恢复到“正常”操作模式
        ignoreLine();     // 并移除错误的输入

        return true;
    }
    
    return false;
}

double getDouble()
{
    while (true) // 循环直到用户输入有效输入
    {
        std::cout << "Enter a decimal number: ";
        double x{};
        std::cin >> x;

        if (clearFailedExtraction())
        {
            std::cout << "Oops, that input is invalid.  Please try again.\n";
            continue;
        }

        ignoreLine(); // 移除任何无关输入
        return x;     // 返回我们提取的值
    }
}

char getOperator()
{
    while (true) // 循环直到用户输入有效输入
    {
        std::cout << "Enter one of the following: +, -, *, or /: ";
        char operation{};
        std::cin >> operation;

        if (!clearFailedExtraction()) // 如果提取失败，我们将在下面处理错误消息
             ignoreLine(); // 移除任何无关输入（仅在提取成功时）

        // 检查用户是否输入了有意义的内容
        switch (operation)
        {
        case '+':
        case '-':
        case '*':
        case '/':
            return operation; // 将输入的字符返回给调用者
        default: // 否则告诉用户哪里出错了
            std::cout << "Oops, that input is invalid.  Please try again.\n";
        }
    }
}
 
void printResult(double x, char operation, double y)
{
    std::cout << x << ' ' << operation << ' ' << y << " is ";

    switch (operation)
    {
    case '+':
        std::cout << x + y << '\n';
        return;
    case '-':
        std::cout << x - y << '\n';
        return;
    case '*':
        std::cout << x * y << '\n';
        return;
    case '/':
        if (y == 0.0)
            break;

        std::cout << x / y << '\n';
        return;
    }

    std::cout << "???";  // 健壮性意味着也要处理意外的参数，即使 getOperator() 在此特定程序中保证操作有效
}
 
int main()
{
    double x{ getDouble() };
    char operation{ getOperator() };
    double y{ getDouble() };

    // 处理除以 0 的情况
    while (operation == '/' && y == 0.0) 
    {
        std::cout << "The denominator cannot be zero.  Try again.\n";
        y = getDouble();
    }
 
    printResult(x, operation, y);
 
    return 0;
}

总结

在编写程序时，请考虑用户会如何误用你的程序，尤其是在文本输入方面。对于每个文本输入点，请考虑：

  • 提取是否会失败？
  • 用户是否会输入超出预期的内容？
  • 用户是否会输入无意义的内容？
  • 用户是否会导致输入溢出？

你可以使用 if 语句和布尔逻辑来测试输入是否符合预期且有意义。

以下代码将清除任何多余的输入：

#include <limits> // for std::numeric_limits

void ignoreLine()
{
    std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
}

以下代码将测试并修复提取失败或溢出（并移除多余输入）：

// 如果提取失败则返回 true，否则返回 false
bool clearFailedExtraction()
{
    // 检查提取是否失败
    if (!std::cin) // 如果之前的提取失败
    {
        if (std::cin.eof()) // 如果流已关闭
        {
            std::exit(0); // 立即关闭程序
        }

        // 让我们处理失败
        std::cin.clear(); // 将我们恢复到“正常”操作模式
        ignoreLine();     // 并移除错误的输入

        return true;
    }
    
    return false;
}

我们可以通过以下方式测试是否存在未提取的输入（换行符除外）：

// 如果 std::cin 在当前行有未提取的输入则返回 true，否则返回 false
bool hasUnextractedInput()
{
    return !std::cin.eof() && std::cin.peek() != '\n';
}

最后，使用循环让用户在原始输入无效时重新输入。
