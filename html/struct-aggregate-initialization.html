13.8 — 结构体聚合初始化

● 机器译文 课程 13.8 查看英文原文

在前一课（13.7 课——结构体、成员和成员选择简介中介绍结构体。我们讨论了如何定义结构体、实例化结构体对象以及访问其成员。在本课中，我们将讨论结构体如何初始化。

数据成员默认不初始化

与普通变量非常相似，数据成员默认不初始化。考虑以下结构体：

#include <iostream>

struct Employee
{
    int id; // 注意：这里没有初始化器
    int age;
    double wage;
};

int main()
{
    Employee joe; // 注意：这里也没有初始化器
    std::cout << joe.id << '\n';

    return 0;
}

由于我们没有提供任何初始化器，当 joe 被实例化时， joe.id， joe.age、和 joe.wage 都将未初始化。当我们尝试打印 joe.id。

的值时，将导致未定义行为。然而，在展示如何初始化结构体之前，我们先简短地绕个弯。

什么是聚合？

在一般编程中，一个 聚合数据类型 （也称为一个 聚合是任何可以包含多个数据成员的类型。某些聚合允许成员具有不同的类型（例如结构体），而其他聚合要求所有成员必须是单一类型（例如数组）。

在C++中，聚合的定义更窄且相当复杂。

作者注

在本教程系列中，当我们使用术语“聚合”（或“非聚合”）时，我们指的是C++对聚合的定义。

进阶读者

简单来说，C++中的聚合要么是C风格数组（17.7 -- C风格数组简介），要么是类类型（结构体、类或联合体），且满足：

  • 没有用户声明的构造函数（14.9 -- 构造函数简介)
  • 没有私有或受保护的非静态数据成员（14.5 -- 公有和私有成员及访问说明符)
  • 没有虚函数（25.2 -- 虚函数和多态)

流行的类型 std::array (17.1 -- std::array简介也是聚合。

你可以在 这里。

找到C++聚合的精确定义。此时需要理解的关键点是，只有数据成员的结构体是聚合。

结构体的聚合初始化

因为普通变量只能保存单个值，我们只需要提供一个初始化器：

int x { 5 };

然而，结构体可以有多个成员：

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

当我们定义结构体类型的对象时，需要某种方式在初始化时初始化多个成员：

Employee joe; // 我们如何初始化 joe.id、joe.age 和 joe.wage？

聚合使用一种称为 聚合初始化的初始化形式，它允许我们直接初始化聚合的成员。为此，我们提供一个 初始化器列表 作为初始化器，它只是一个用花括号括起来的逗号分隔值列表。

聚合初始化有两种主要形式：

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

int main()
{
    Employee frank = { 1, 32, 60000.0 }; // 使用花括号列表进行拷贝列表初始化
    Employee joe { 2, 28, 45000.0 };     // 使用花括号列表进行列表初始化（推荐）

    return 0;
}

每种初始化形式都执行 成员式初始化，这意味着结构体中的每个成员按声明顺序初始化。因此， Employee joe { 2, 28, 45000.0 }; 首先初始化 joe.id 、值为 2，那么 joe.age 、值为 28、和 joe.wage 、值为 45000.0 最后。

最佳实践

初始化聚合体时，优先使用（非拷贝）花括号列表形式。

在 C++20 中，我们也可以使用带括号的值列表来初始化（某些）聚合体：

    Employee robert ( 3, 45, 62500.0 );  // 使用括号列表的直接初始化（C++20）

我们建议尽可能避免使用最后这种形式，因为它目前不适用于使用花括号省略的聚合体（特别是 std::array)。

初始化列表中的缺失初始化器

如果聚合体被初始化，但初始化值的数量少于成员数量，那么每个没有显式初始化器的成员将按如下方式初始化：

  • 如果成员有默认成员初始化器，则使用该初始化器。
  • 否则，该成员将从空初始化列表进行拷贝初始化。在大多数情况下，这将对那些成员进行值初始化（对于类类型，即使存在列表构造函数，也会调用默认构造函数）。
struct Employee
{
    int id {};
    int age {};
    double wage { 76000.0 };
    double whatever;
};

int main()
{
    Employee joe { 2, 28 }; // joe.whatever 将被值初始化为 0.0

    return 0;
}

在上面的例子中， joe.id 将使用值进行初始化 2 和 joe.age 将使用值进行初始化 28。因为 joe.wage 没有显式初始化器，但有默认成员初始化器， joe.wage 将被初始化为 76000.0。最后，因为 joe.whatever 没有显式初始化器， joe.whatever 被值初始化为 0.0。

提示

这意味着我们通常可以使用空初始化列表来对结构体的所有成员进行值初始化：

Employee joe {}; // 值初始化所有成员

重载 operator<< 来打印结构体

在课程 13.5 -- 重载 I/O 运算符简介，我们展示了如何重载 operator<< 来打印枚举。重载 operator<< 对于结构体也很有用。

以下是上一节中的相同示例，现在带有一个重载的 operator<<：

#include <iostream>

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

std::ostream& operator<<(std::ostream& out, const Employee& e)
{
    out << e.id << ' ' << e.age << ' ' << e.wage;
    return out;
}

int main()
{
    Employee joe { 2, 28 }; // joe.wage 将被值初始化为 0.0
    std::cout << joe << '\n';

    return 0;
}

这会打印：

2 28 0

我们可以看到 joe.wage 确实被值初始化为 0.0 （打印为 0)。

与枚举不同，结构体可以包含多个值。如何格式化输出（例如，分隔值）完全取决于你。

上面我们重载的 operator<< 输出的三个值并不直观，因为没有指示这些值的含义。让我们做同样的例子，但更新我们的输出函数使其更具描述性：

#include <iostream>

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

std::ostream& operator<<(std::ostream& out, const Employee& e)
{
    out << "id: " << e.id << " age: " << e.age << " wage: " << e.wage;
    return out;
}

int main()
{
    Employee joe { 2, 28 }; // joe.wage 将被值初始化为 0.0
    std::cout << joe << '\n';

    return 0;
}

现在打印：

id: 2 age: 28 wage: 0

这样更容易理解一些。

Const 结构体

结构体类型的变量可以是 const（或 constexpr），并且像所有 const 变量一样，它们必须被初始化。

struct Rectangle
{
    double length {};
    double width {};
};

int main()
{
    const Rectangle unit { 1.0, 1.0 };
    const Rectangle zero { }; // 值初始化所有成员

    return 0;
}

指定初始化器 C++20

当从值列表初始化结构体时，初始化器按声明顺序应用于成员。

struct Foo
{
    int a {};
    int c {};
};

int main()
{
    Foo f { 1, 3 }; // f.a = 1, f.c = 3

    return 0;
}

现在考虑如果你更新这个结构体定义，添加一个不是最后一个成员的新成员会发生什么：

struct Foo
{
    int a {};
    int b {}; // 刚刚添加
    int c {};
};

int main()
{
    Foo f { 1, 3 }; // 现在，f.a = 1, f.b = 3, f.c = 0

    return 0;
}

现在你所有的初始化值都移位了，更糟糕的是，编译器可能不会将其检测为错误（毕竟语法仍然有效）。

为了帮助避免这种情况，C++20 添加了一种初始化结构体成员的新方法，称为 指定初始化器。指定初始化器允许你显式定义哪些初始化值映射到哪些成员。成员可以使用列表初始化或拷贝初始化进行初始化，并且必须按照它们在结构体中声明的相同顺序进行初始化，否则会产生警告或错误。未指定初始化器的成员将被值初始化。

struct Foo
{
    int a{ };
    int b{ };
    int c{ };
};

int main()
{
    Foo f1{ .a{ 1 }, .c{ 3 } }; // ok: f1.a = 1, f1.b = 0（值初始化）, f1.c = 3
    Foo f2{ .a = 1, .c = 3 };   // ok: f2.a = 1, f2.b = 0（值初始化）, f2.c = 3
    Foo f3{ .b{ 2 }, .a{ 1 } }; // 错误：初始化顺序与结构体中声明的顺序不匹配

    return 0;
}

对于 Clang 用户

当使用花括号对单个值进行指定初始化时，Clang 会错误地发出警告“花括号包围标量初始化器”。希望这能很快得到修复。

指定初始化器很好，因为它们提供了一定程度的自文档化，并有助于确保你不会无意中混淆初始化值的顺序。然而，指定初始化器也会显著地使初始化列表变得杂乱，因此我们目前不推荐将其作为最佳实践。

此外，由于没有强制要求在初始化聚合体时一致地使用指定初始化器，因此最好避免在现有聚合体定义的中间添加新成员，以避免初始化器移位的风险。

最佳实践

当向聚合体添加新成员时，最安全的方法是将其添加到定义列表的底部，这样其他成员的初始化器就不会移位。

使用初始化列表赋值

如前一课所示，我们可以单独为结构体的成员赋值：

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

int main()
{
    Employee joe { 1, 32, 60000.0 };

    joe.age  = 33;      // Joe 过生日了
    joe.wage = 66000.0; // 并且涨了工资

    return 0;
}

对于单个成员来说这没问题，但当我们要更新多个成员时就不太好了。类似于用初始化列表初始化结构体，你也可以使用初始化列表为结构体赋值（这会执行成员逐一赋值）：

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

int main()
{
    Employee joe { 1, 32, 60000.0 };
    joe = { joe.id, 33, 66000.0 }; // Joe 过了一个生日并且涨了工资

    return 0;
}

注意，因为我们不想改变 joe.id，所以需要在列表中提供 joe.id 的当前值作为占位符，这样成员逐一赋值才能将 joe.id 切换到 joe.id赋值。这有点丑陋。

使用指定初始化器赋值 C++20

指定初始化器也可以用于列表赋值：

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

int main()
{
    Employee joe { 1, 32, 60000.0 };
    joe = { .id = joe.id, .age = 33, .wage = 66000.0 }; // Joe 过了一个生日并且涨了工资

    return 0;
}

在这种赋值中，任何未指定的成员将被赋予值初始化所使用的值。如果我们没有为 joe.id， joe.id 指定初始化器，那么它将被赋值为 0。

用同类型的另一个结构体初始化结构体

结构体也可以使用同类型的另一个结构体来初始化：

#include <iostream>

struct Foo
{
    int a{};
    int b{};
    int c{};
};

std::ostream& operator<<(std::ostream& out, const Foo& f)
{
    out << f.a << ' ' << f.b << ' ' << f.c;
    return out;
}

int main()
{
    Foo foo { 1, 2, 3 };

    Foo x = foo; // 复制初始化
    Foo y(foo);  // 直接初始化
    Foo z {foo}; // 直接列表初始化

    std::cout << x << '\n';
    std::cout << y << '\n';
    std::cout << z << '\n';

    return 0;
}

上述代码打印：

1 2 3
1 2 3
1 2 3

注意，这里使用的是我们熟悉的标准初始化形式（拷贝初始化、直接初始化或直接列表初始化），而不是聚合初始化。

这种情况最常见于用返回同类型结构体的函数的返回值来初始化结构体。我们将在第 13.10 —— 传递和返回结构体。
