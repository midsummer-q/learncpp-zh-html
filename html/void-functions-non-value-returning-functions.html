2.3 — void函数（不返回值的函数）

● 机器译文 课程 2.3 查看英文原文

在之前的课程（2.1 -- 函数简介）中，我们提到函数定义的语法如下：

returnType identifier() // identifier replaced with the name of your function
{
// Your code here
}

虽然我们展示了返回类型为 void的函数示例，但没有讨论这意味着什么。在本课中，我们将探讨返回类型为 void。

void返回值

函数不一定需要向调用者返回值。为了告诉编译器函数不返回值，使用返回类型 void 例如：

#include <iostream>

// void 表示该函数不向调用者返回值
void printHi()
{
    std::cout << "Hi" << '\n';

    // 该函数不返回值，因此不需要 return 语句
}

int main()
{
    printHi(); // 可以：调用了函数 printHi()，没有返回值

    return 0;
}

在上面的例子中， printHi 函数有一个有用的行为（打印“Hi”），但它不需要向调用者返回任何东西。因此， printHi 被赋予 void 返回类型。

当 main 调用 printHi时， printHi 中的代码执行，并打印“Hi”。在 printHi结束时，控制权返回 main ，程序继续执行。

不返回值的函数称为 非返回值函数 (或一个 void函数)。

Void函数不需要return语句

void函数会在函数末尾自动返回到调用者。不需要return语句。

可以在void函数中使用不带返回值的return语句——这样的语句会导致函数在执行return语句处返回到调用者。这实际上与函数末尾发生的情况相同。因此，在void函数末尾放一个空的return语句是多余的：

#include <iostream>

// void 表示该函数不向调用者返回值
void printHi()
{
    std::cout << "Hi" << '\n';

    return; // 告诉编译器返回到调用者——这是多余的，因为无论如何函数结束时都会返回！
} // 函数将在此处返回到调用者

int main()
{
    printHi();

    return 0;
}

最佳实践

不要在非值返回函数末尾放置return语句。

Void函数不能用于需要值的表达式中

某些类型的表达式需要值。例如：

#include <iostream>

int main()
{
    std::cout << 5; // 可以：5 是一个字面值，我们将其发送到控制台进行打印
    std::cout << ;  // 编译错误：未提供值

    return 0;
}

在上面的程序中，要打印的值需要提供在 std::cout <<的右侧。如果没有提供值，编译器会产生语法错误。由于第二个对 std::cout 的调用没有提供要打印的值，这会导致错误。

现在考虑以下程序：

#include <iostream>

// void 表示该函数不向调用者返回值
void printHi()
{
    std::cout << "Hi" << '\n';
}

int main()
{
    printHi(); // 可以：调用了函数 printHi()，没有返回值

    std::cout << printHi(); // 编译错误

    return 0;
}

第一个对 printHi() 的调用是在不需要值的上下文中进行的。由于函数不返回值，所以没问题。

第二个对函数 printHi() 的调用甚至无法编译。函数 printHi 有一个 void 返回类型，意味着它不返回值。然而，这个语句试图将 printHi 切换到 std::cout 以进行打印。 std::cout 不知道如何处理这个（它应该输出什么值？）。因此，编译器会将其标记为错误。你需要注释掉这行代码才能使代码编译通过。

提示

有些语句需要提供值，有些则不需要。

当我们有一个仅包含函数调用的语句（例如，第一个 printHi() 在上面的示例中），我们调用函数是为了其行为，而不是其返回值。在这种情况下，我们可以调用不返回值的函数，或者调用返回值函数并忽略其返回值。

当我们在需要值的上下文中调用函数时（例如， std::cout），必须提供一个值。在这种上下文中，我们只能调用返回值函数。

#include <iostream>

// 不返回值的函数
void returnNothing()
{
}

// 返回值的函数
int returnFive()
{
    return 5;
}

int main()
{
    // 单独调用函数时，不需要值
    returnNothing(); // ok：我们可以调用不返回值的函数
    returnFive();    // ok：我们可以调用返回值的函数，并忽略该返回值

    // 在需要值的上下文中调用函数时（如 std::cout）
    std::cout << returnFive();    // ok：我们可以调用返回值的函数，该值将被使用
    std::cout << returnNothing(); // 编译错误：我们无法在此上下文中调用返回 void 的函数

    return 0;
}

从 void 函数中返回值是编译错误

尝试从不返回值的函数中返回值会导致编译错误：

void printHi() // 此函数不返回值
{
    std::cout << "In printHi()" << '\n';

    return 5; // 编译错误：我们正在尝试返回一个值
}

小测验时间

问题 #1

检查以下程序并说明它们输出什么，或者它们是否不会编译。

1a)

#include <iostream>

void printA()
{
    std::cout << "A\n";
}

void printB()
{
    std::cout << "B\n";
}

int main()
{
    printA();
    printB();

    return 0;
}

显示答案

该程序将字母 A 和 B 打印在不同的行上。

1b)

#include <iostream>

void printA()
{
    std::cout << "A\n";
}

int main()
{
    std::cout << printA() << '\n';

    return 0;
}

显示答案

该程序不会编译。函数 printA() 返回 void，它不能被发送到 std::cout 进行打印。这将产生编译错误。
