19.5 — Void指针

● 机器译文 课程 19.5 查看英文原文

浮点类型的 void指针，也称为泛型指针，是一种特殊类型的指针，可以指向任何数据类型的对象！void指针的声明方式与普通指针类似，使用void关键字作为指针的类型：

void* ptr {}; // ptr是一个void指针

void指针可以指向任何数据类型的对象：

int nValue {};
float fValue {};

struct Something
{
    int n;
    float f;
};

Something sValue {};

void* ptr {};
ptr = &nValue; // 有效
ptr = &fValue; // 有效
ptr = &sValue; // 有效

然而，由于void指针不知道它指向的对象类型，解引用void指针是非法的。相反，必须先将其转换为另一种指针类型，然后才能执行解引用。

int value{ 5 };
void* voidPtr{ &value };

// std::cout << *voidPtr << '\n'; // 非法：解引用void指针

int* intPtr{ static_cast<int*>(voidPtr) }; // 然而，如果我们将void指针转换为int指针...

std::cout << *intPtr << '\n'; // 那么我们就可以解引用结果

这会打印：

5

下一个显而易见的问题是：如果void指针不知道它指向什么，我们怎么知道要将其转换为哪种类型？最终，这需要你自己来跟踪。

下面是一个使用void指针的例子：

#include <cassert>
#include <iostream>

enum class Type
{
    tInt, // 注意：我们不能在这里使用"int"，因为它是一个关键字，所以我们将使用"tInt"代替
    tFloat,
    tCString
};

void printValue(void* ptr, Type type)
{
    switch (type)
    {
    case Type::tInt:
        std::cout << *static_cast<int*>(ptr) << '\n'; // 转换为int指针并执行间接访问
        break;
    case Type::tFloat:
        std::cout << *static_cast<float*>(ptr) << '\n'; // 转换为float指针并执行间接访问
        break;
    case Type::tCString:
        std::cout << static_cast<char*>(ptr) << '\n'; // 转换为char指针（无间接访问）
        // std::cout会将char*视为C风格字符串
        // 如果我们对结果执行间接访问，那么只会打印ptr指向的单个字符
        break;
    default:
        std::cerr << "printValue(): invalid type provided\n"; 
        assert(false && "type not found");
        break;
    }
}

int main()
{
    int nValue{ 5 };
    float fValue{ 7.5f };
    char szValue[]{ "Mollie" };

    printValue(&nValue, Type::tInt);
    printValue(&fValue, Type::tFloat);
    printValue(szValue, Type::tCString);

    return 0;
}

该程序打印出：

5
7.5
Mollie

void指针杂项

void指针可以设置为空值：

void* ptr{ nullptr }; // ptr是一个当前为空指针的void指针

由于void指针不知道它指向的对象类型，删除void指针会导致未定义行为。如果你需要删除void指针， static_cast 首先将其转换回适当的类型。

无法对void指针进行指针算术运算。这是因为指针算术要求指针知道它指向的对象的大小，以便适当地递增或递减指针。

注意，不存在void引用这种东西。这是因为void引用的类型将是void &，并且不知道它引用的值的类型。

总结

一般来说，除非绝对必要，否则最好避免使用void指针，因为它们实际上允许你绕过类型检查。这可能会让你无意中做出毫无意义的事情，而编译器不会对此提出警告。例如，以下代码是有效的：

    int nValue{ 5 };
    printValue(&nValue, Type::tCString);

但谁知道结果会是什么呢！

尽管上述函数看起来是一种让单个函数处理多种数据类型的巧妙方法，但C++实际上提供了一种更好的方式来实现同样的功能（通过函数重载），它保留了类型检查以防止误用。许多曾经使用void指针处理多种数据类型的地方，现在更适合使用模板，模板也提供了强类型检查。

然而，偶尔你仍然可能找到void指针的合理用途。只是要确保没有其他更好（更安全）的方式使用其他语言机制来实现同样的功能！

小测验时间

问题 #1

void指针和空指针有什么区别？

显示答案

void指针是一种可以指向任何类型对象的指针，但不知道它指向的对象类型。void指针必须显式转换为另一种类型的指针才能执行间接访问。空指针是一种不指向任何地址的指针。void指针可以是空指针。

因此，void指针指的是指针的类型，而空指针指的是指针的值（地址）。
