28.2 — 使用istream进行输入

● 机器译文 课程 28.2 查看英文原文

iostream库相当复杂——因此我们无法在这些教程中完整地介绍它。不过，我们会向你展示最常用的功能。在本节中，我们将探讨输入类（istream）的各个方面。

提取运算符

正如在许多课程中已经看到的，我们可以使用提取运算符（>>）从输入流中读取信息。C++为所有内置数据类型预定义了提取操作，并且你已经看到如何 重载提取运算符 用于你自己的类。

在读取字符串时，提取运算符的一个常见问题是如何防止输入溢出缓冲区。考虑以下示例：

char buf[10]{};
std::cin >> buf;

如果用户输入了18个字符会发生什么？缓冲区溢出，然后糟糕的事情发生。一般来说，对用户将输入多少个字符做任何假设都是不明智的。

处理这个问题的一种方法是使用操纵器。一个 操纵器 是一个对象，当与提取（>>）或插入（<<）运算符一起使用时，用于修改流。你已经使用过的一个操纵器是"std::endl"，它既打印换行符又刷新任何缓冲的输出。 C++提供了一个名为 setw （在iomanip头文件中）的操纵器，可用于限制从流中读取的字符数。要使用setw()，只需将要读取的最大字符数作为参数提供，并将其插入到输入语句中，如下所示：

#include <iomanip>
char buf[10]{};
std::cin >> std::setw(10) >> buf;

这个程序现在只会从流中读取前9个字符（为终止符留出空间）。任何剩余的字符将留在流中，直到下一次提取。

提取与空白字符

提醒一下，提取运算符会跳过空白字符（空格、制表符和换行符）。

看看下面的程序：

int main()
{
    char ch{};
    while (std::cin >> ch)
        std::cout << ch;

    return 0;
}

当用户输入以下内容时：

Hello my name is Alex

提取运算符会跳过空格和换行符。因此，输出是：

HellomynameisAlex

通常，你可能希望获取用户输入但不丢弃空白字符。为此，istream类提供了许多可用于此目的的函数。

其中最有用的一个是 get() 函数，它只是从输入流中获取一个字符。下面是使用get()的相同程序：

int main()
{
    char ch{};
    while (std::cin.get(ch))
        std::cout << ch;

    return 0;
}

现在当我们使用输入：

Hello my name is Alex

输出是：

Hello my name is Alex

get()还有一个字符串版本，它接受要读取的最大字符数：

int main()
{
    char strBuf[11]{};
    std::cin.get(strBuf, 11);
    std::cout << strBuf << '\n';

    return 0;
}

如果我们输入：

Hello my name is Alex

输出是：

Hello my n

注意，我们只读取了前10个字符（必须留一个字符给终止符）。剩余的字符留在了输入流中。

关于get()需要注意的一点是，它不会读取换行符！这可能会导致一些意想不到的结果：

int main()
{
    char strBuf[11]{};
    // 读取最多 10 个字符
    std::cin.get(strBuf, 11);
    std::cout << strBuf << '\n';

    // 再读取最多 10 个字符
    std::cin.get(strBuf, 11);
    std::cout << strBuf << '\n';
    return 0;
}

如果用户输入：

Hello!

程序将输出：

Hello!

然后终止！为什么它没有要求再输入10个字符？答案是第一个get()读取到换行符然后停止。第二个get()看到cin流中仍有输入并尝试读取它。但第一个字符是换行符，所以它立即停止。

因此，还有另一个名为 getline() 的函数，其工作方式类似于get()，但会提取（并丢弃）分隔符。

int main()
{
    char strBuf[11]{};
    // 读取最多 10 个字符
    std::cin.getline(strBuf, 11);
    std::cout << strBuf << '\n';

    // 再读取最多 10 个字符
    std::cin.getline(strBuf, 11);
    std::cout << strBuf << '\n';
    return 0;
}

这段代码将按预期执行，即使用户输入了包含换行符的字符串。

如果你需要知道上一次调用getline()提取了多少个字符，请使用 gcount()：

int main()
{
    char strBuf[100]{};
    std::cin.getline(strBuf, 100);
    std::cout << strBuf << '\n';
    std::cout << std::cin.gcount() << " characters were read" << '\n';

    return 0;
}

gcount()包括任何被提取并丢弃的分隔符。

用于std::string的getline()特殊版本

有一个特殊版本的 getline() 存在于 istream 类之外，用于读取 std::string 类型的变量。这个特殊版本不是 ostream 或 istream 的成员，包含在 string 头文件中。以下是其使用示例：

#include <string>
#include <iostream>

int main()
{
    std::string strBuf{};
    std::getline(std::cin, strBuf);
    std::cout << strBuf << '\n';

    return 0;
}

更多有用的 istream 函数

还有一些你可能想使用的有用输入函数：

ignore() 丢弃流中的第一个字符。
ignore(int nCount) 丢弃前 nCount 个字符。
peek() 允许你从流中读取一个字符而不将其从流中移除。
unget() 将最后读取的字符返回流中，以便下一次调用可以再次读取。
putback(char ch) 允许你将选择的字符放回流中，以便下一次调用读取。

istream 包含许多其他函数以及上述函数的变体，根据你的需求可能有用。你可以在参考网站上找到这些内容，例如 https://en.cppreference.com/w/cpp/io/basic_istream。
