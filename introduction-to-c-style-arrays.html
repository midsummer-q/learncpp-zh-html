17.7 — C风格数组简介

● 机器译文 课程 17.7 查看英文原文

现在我们已经介绍了 std::vector 和 std::array，我们将通过介绍最后一种数组类型：C风格数组，来完成对数组的讲解。

正如课程 16.1 -- 容器和数组简介中提到的，C风格数组继承自C语言，是C++核心语言的内置部分（不像其他数组类型是标准库容器类）。这意味着我们不需要#include头文件来使用它们。

顺便说一句……

因为它们是语言原生支持的唯一数组类型，标准库的数组容器类型（例如 std::array 和 std::vector）通常使用C风格数组实现。

声明C风格数组

由于它们是核心语言的一部分，C风格数组有自己特殊的声明语法。在C风格数组声明中，我们使用方括号（[]）来告诉编译器声明的对象是一个C风格数组。在方括号内，我们可以选择提供数组的长度，这是一个类型为 std::size_t 的整数值，告诉编译器数组中有多少个元素。

下面的定义创建了一个名为 testScore 的C风格数组变量，它包含30个类型为 int：

int main()
{
    int testScore[30] {};      // 定义一个名为testScore的C风格数组，包含30个值初始化的int元素（无需包含头文件）

//  std::array<int, 30> arr{}; // 作为对比，这是一个包含30个值初始化int元素的std::array（需要包含<array>）

    return 0;
}

的元素。C风格数组的长度必须至少为1。如果数组长度为零、负数或非整数值，编译器会报错。

进阶读者

在堆上动态分配的C风格数组允许长度为0。

C风格数组的长度必须是常量表达式

中介绍异常及其处理方法。 std::array，在声明C风格数组时，数组的长度必须是常量表达式（类型为 std::size_t，尽管这通常不重要）。

提示

某些编译器可能允许创建具有非常量表达式长度的数组，以兼容C99的一个称为变长数组（VLA）的特性。

变长数组在C++中无效，不应在C++程序中使用。如果你的编译器允许这些数组，你可能忘记禁用编译器扩展（参见 0.10 -- 配置你的编译器：编译器扩展)。

对C风格数组进行下标操作

就像 std::array一样，C风格数组可以使用下标运算符（operator[])：

#include <iostream>

int main()
{
    int arr[5]; // 定义一个包含5个int值的数组

    arr[1] = 7; // 使用下标运算符索引数组元素1
    std::cout << arr[1]; // 打印 7

    return 0;
}

与标准库容器类（仅使用类型为 std::size_t 的无符号索引）不同，C风格数组的索引可以是任何整数类型（有符号或无符号）的值或未限定作用域的枚举。这意味着C风格数组不会受到标准库容器类所具有的所有符号转换索引问题的影响！

#include <iostream>

int main()
{
    const int arr[] { 9, 8, 7, 6, 5 };

    int s { 2 };
    std::cout << arr[s] << '\n'; // 可以使用有符号索引

    unsigned int u { 2 };
    std::cout << arr[u] << '\n'; // 可以使用无符号索引

    return 0;
}

提示

C风格数组接受有符号或无符号索引（或未限定作用域的枚举）。

operator[] 不进行任何边界检查，传入越界索引将导致未定义行为。

顺便说一句……

当声明数组时（例如 int arr[5]），使用 [] 是声明语法的一部分，而不是调用下标运算符 operator[]。

C风格数组的聚合初始化

中介绍异常及其处理方法。 std::array，C风格数组是聚合体，这意味着它们可以使用聚合初始化进行初始化。

快速回顾一下，聚合初始化允许我们直接初始化聚合体的成员。为此，我们提供一个初始化值列表，这是一个用大括号括起来的逗号分隔的初始化值列表。

int main()
{
    int fibonnaci[6] = { 0, 1, 1, 2, 3, 5 }; // 使用花括号列表进行拷贝列表初始化
    int prime[5] { 2, 3, 5, 7, 11 };         // 使用花括号列表进行列表初始化（推荐）

    return 0;
}

这些初始化形式中的每一个都按顺序初始化数组成员，从元素0开始。

如果你没有为C风格数组提供初始化器，元素将被默认初始化。在大多数情况下，这将导致元素保持未初始化。因为我们通常希望元素被初始化，所以在定义没有初始化器的C风格数组时，应该使用值初始化（使用空大括号）。

int main()
{
    int arr1[5];    // 成员默认初始化：int元素保持未初始化
    int arr2[5] {}; // 成员值初始化：int元素被零初始化（推荐）

    return 0;
}

如果初始化值列表中的初始化器多于定义的数组长度，编译器会报错。如果初始化值列表中的初始化器少于定义的数组长度，则没有初始化器的剩余元素会被值初始化：

int main()
{
    int a[4] { 1, 2, 3, 4, 5 }; // 编译错误：初始化值过多
    int b[4] { 1, 2 };          // arr[2]和arr[3]被值初始化

    return 0;
}

使用C风格数组的一个缺点是必须显式指定元素的类型。CTAD不起作用，因为C风格数组不是类模板。而使用 auto 尝试从初始化器列表推导数组的元素类型也不起作用：

int main()
{
    auto squares[5] { 1, 4, 9, 16, 25 }; // 编译错误：不能对C风格数组使用类型推导

    return 0;
}

省略长度

下面的数组定义中存在一个微妙的冗余。看到了吗？

int main()
{
    const int prime[5] { 2, 3, 5, 7, 11 }; // prime的长度为5

    return 0;
}

我们明确告诉编译器数组长度为5，然后也用5个元素初始化它。当我们用初始化值列表初始化C风格数组时，可以省略长度（在数组定义中），让编译器从初始化值的数量推导出数组的长度。

以下数组定义行为相同：

int main()
{
    const int prime1[5] { 2, 3, 5, 7, 11 }; // prime1显式定义长度为5
    const int prime2[] { 2, 3, 5, 7, 11 };  // prime2由编译器推导出长度为5

    return 0;
}

这仅在显式为所有数组成员提供初始化值时有效。

int main()
{
    int bad[] {}; // 错误：编译器会将其推导为零长度数组，这是不允许的！

    return 0;
}

当使用初始化值列表初始化C风格数组的所有元素时，最好省略长度，让编译器计算数组的长度。这样，如果添加或删除初始化值，数组长度会自动调整，我们不会面临定义的数组长度与提供的初始化值数量不匹配的风险。

最佳实践

当显式用值初始化每个数组元素时，优先省略C风格数组的长度。

const和constexpr C风格数组

中介绍异常及其处理方法。 std::array，C风格数组可以是 const 或 constexpr。就像其他const变量一样，const数组必须初始化，之后元素的值不能更改。

#include <iostream>

namespace ProgramData
{
    constexpr int squares[5] { 1, 4, 9, 16, 25 }; // 一个constexpr int数组
}

int main()
{
    const int prime[5] { 2, 3, 5, 7, 11 }; // 一个const int数组
    prime[0] = 17; // 编译错误：不能修改const int

    return 0;
}

C风格数组的sizeof

在之前的课程中，我们使用 sizeof() 运算符获取对象或类型的大小（以字节为单位）。应用于C风格数组， sizeof() 返回整个数组使用的字节数：

#include <iostream>

int main()
{
    const int prime[] { 2, 3, 5, 7, 11 }; // 编译器将推导出 prime 的长度为 5
    
    std::cout << sizeof(prime); // 打印 20（假设 int 为 4 字节）

    return 0;
}

假设int为4字节，上述程序打印 20。这些 prime 数组包含5个 int 元素，每个4字节，所以5 * 4 = 20字节。

注意这里没有开销。C风格数组对象只包含其元素，没有其他内容。

获取C风格数组的长度

在C++17中，我们可以使用 std::size() （定义在<iterator>头文件中），它返回数组长度作为无符号整数值（类型为 std::size_t）。在C++20中，我们也可以使用 std::ssize()，它返回数组长度作为有符号整数值（类型为较大的有符号整数类型，可能是 std::ptrdiff_t)。

#include <iostream>
#include <iterator> // for std::size and std::ssize

int main()
{
    const int prime[] { 2, 3, 5, 7, 11 };   // 编译器将推导出 prime 的长度为 5

    std::cout << std::size(prime) << '\n';  // C++17，返回无符号整数值 5
    std::cout << std::ssize(prime) << '\n'; // C++20，返回有符号整数值 5

    return 0;
}

提示

定义 std::size() 和 std::ssize() 的标准头文件是<iterator>。然而，由于这些函数非常有用，许多其他头文件也提供了它们，包括<array>和<vector>。当在C风格数组上使用 std::size() 或 std::ssize() 时，我们可能尚未包含其他头文件。在这种情况下，通常包含<iterator>头文件。

你可以在 cppreference上size函数的文档。

中查看定义这些函数的完整头文件列表。获取C风格数组的长度（C++14或更早）

在C++17之前，没有标准库函数可以获取C风格数组的长度。

如果你使用C++11或C++14，可以使用以下函数代替：

#include <cstddef> // for std::size_t
#include <iostream>

template <typename T, std::size_t N>
constexpr std::size_t length(const T(&)[N]) noexcept
{
	return N;
}

int main() {

	int array[]{ 1, 1, 2, 3, 5, 8, 13, 21 };
	std::cout << "The array has: " << length(array) << " elements\n";

	return 0;
}

这使用了一个函数模板，它通过引用接受C风格数组，然后返回表示数组长度的非类型模板参数。

在更旧的代码库中，你可能会看到通过将整个数组的大小除以一个数组元素的大小来确定C风格数组的长度：

#include <iostream>

int main()
{
    int array[8] {};
    std::cout << "The array has: " << sizeof(array) / sizeof(array[0]) << " elements\n";

    return 0;
}

这会打印：

The array has: 8 elements

这是如何工作的？首先，注意整个数组的大小等于数组的长度乘以一个元素的大小。更简洁地说： array size = length * element size。

使用代数，我们可以重新排列这个方程： length = array size / element size。我们通常使用 sizeof(array[0]) 表示元素大小。因此，长度 = sizeof(array) / sizeof(array[0])。你可能偶尔也会看到写成 sizeof(array) / sizeof(*array)，效果相同。

C风格数组不支持赋值

也许令人惊讶的是，C++数组不支持赋值：

int main()
{
    int arr[] { 1, 2, 3 }; // 可以：初始化没问题
    arr[0] = 4;            // 对单个元素赋值没问题
    arr = { 5, 6, 7 };     // 编译错误：数组赋值无效

    return 0;
}

从技术上讲，这行不通，因为赋值要求左操作数是可修改的左值，而C风格数组不被视为可修改的左值。

如果需要向C风格数组赋一组新值，最好使用 std::vector 或者，可以逐个元素地给C风格数组赋新值，或者使用 std::copy 复制现有的C风格数组：

#include <algorithm> // for std::copy

int main()
{
    int arr[] { 1, 2, 3 };
    int src[] { 5, 6, 7 };

    // 将 src 复制到 arr
    std::copy(std::begin(src), std::end(src), std::begin(arr));

    return 0;
}

问题 #1

将以下 std::array 定义转换为等价的constexpr C风格数组定义：

constexpr std::array<int, 3> a{}; // 分配 3 个 int

显示答案

	constexpr int a[3] {}; // 分配 3 个 int

问题 #2

以下程序存在哪三个问题？

#include <iostream>

int main()
{
    int length{ 5 };
    const int arr[length] { 9, 7, 5, 3, 1 };
    
    std::cout << arr[length];
    arr[0] = 4;
    
    return 0;
}

显示答案

  1. 定义数组时，长度必须是编译时常量。在上述程序中， length 不是const，因此定义 const int arr[length] 是不允许的。
  2. 数组索引从0到length-1。因此， arr[length] 是越界索引，将导致未定义行为。
  3. 数组元素的类型是“const int”，因此 arr[0] 不能通过赋值修改。

问题 #3

“完全平方数”是指平方根为整数的自然数。我们可以通过将自然数（包括零）乘以自身来得到完全平方数。前4个完全平方数是：0, 1, 4, 9。

使用全局constexpr C风格数组保存0到9（含）之间的完全平方数。反复要求用户输入一个单个数字整数，或输入-1退出。打印用户输入的数字是否为完全平方数。

输出应与以下内容匹配：

Enter a single digit integer, or -1 to quit: 4
4 is a perfect square

Enter a single digit integer, or -1 to quit: 5
5 is not a perfect square

Enter a single digit integer, or -1 to quit: -1
Bye

提示：使用基于范围的for循环遍历C风格数组以查找匹配项。

显示答案

#include <iostream>

namespace ProgramData
{
    constexpr int squares[] { 0, 1, 4, 9 };
}

bool matchSquare(int input)
{
    for (const auto& e : ProgramData::squares)
    {
        if (input == e)
            return true;
    }

    return false;
}

int main()
{
    while (true)
    {
        std::cout << "Enter a single digit integer, or -1 to quit: ";
        int input{};
        std::cin >> input;

        if (input == -1)
            break;

        if (matchSquare(input))
            std::cout << input << " is a perfect square\n";
        else
            std::cout << input << " is not a perfect square\n";
    }

    std::cout << "Bye\n";

    return 0;
}
