12.1 — 复合数据类型简介

● 机器译文 课程 12.1 查看英文原文

在课程 4.1 -- 基本数据类型简介我们介绍了基本数据类型，它们是 C++ 作为核心语言提供的基本数据类型。

到目前为止，我们在程序中大量使用了这些基本类型，尤其是 int 数据类型。虽然这些基本类型对于简单的用途非常有用，但当我们开始做更复杂的事情时，它们并不能满足我们的全部需求。

例如，假设你正在编写一个数学程序来计算两个分数的乘积。你如何在程序中表示一个分数？你可能会使用一对整数（一个作为分子，一个作为分母），像这样：

#include <iostream>

int main()
{
    // 我们的第一个分数
    int num1 {};
    int den1 {};

    // 我们的第二个分数
    int num2 {};
    int den2 {};

    // 用于吃掉（移除）分子和分母之间的斜杠
    char ignore {};

    std::cout << "Enter a fraction: ";
    std::cin >> num1 >> ignore >> den1;

    std::cout << "Enter a fraction: ";
    std::cin >> num2 >> ignore >> den2;

    std::cout << "The two fractions multiplied: "
        << num1 * num2 << '/' << den1 * den2 << '\n';

    return 0;
}

这个程序的运行结果：

Enter a fraction: 1/2
Enter a fraction: 3/4
The two fractions multiplied: 3/8

虽然这个程序可以工作，但它带来了一些我们需要改进的挑战。首先，每对整数之间的关联很松散——除了注释和它们在代码中的使用上下文之外，几乎没有迹象表明每个分子和分母对是相关的。其次，遵循 DRY（不要重复自己）原则，我们应该创建一个函数来处理用户输入分数（以及一些错误处理）。然而，函数只能返回一个值，那么我们如何将分子和分母返回给调用者呢？

现在想象另一个场景，你正在编写一个需要保存员工 ID 列表的程序。你会怎么做？你可能会尝试这样：

int main()
{
    int id1 { 42 };
    int id2 { 57 };
    int id3 { 162 };
    // 等等
}

但如果你有 100 个员工呢？首先，你需要输入 100 个变量名。而且如果你需要全部打印出来呢？或者将它们传递给一个函数？我们将面临大量的输入工作。这根本无法扩展。

显然，基本类型只能带我们走到这里。

复合数据类型

幸运的是，C++ 支持第二组数据类型： 复合数据类型 类型推导 （也称为组合数据类型）是根据其他现有数据类型定义的类型。复合数据类型具有额外的属性和行为，使它们对于解决某些类型的问题非常有用。

关键提示

每种数据类型要么是基本类型，要么是复合类型。C++ 语言标准明确规定了每种类型属于哪个类别。

正如我们将在本章和后续章节中展示的那样，我们可以使用复合数据类型优雅地解决我们上面提出的所有挑战。

C++ 支持以下复合类型：

  • 函数
  • C 风格数组
  • 指针类型：
    • 指向对象的指针
    • 指向函数的指针
  • 指向成员的指针类型：
    • 指向数据成员的指针
    • 指向成员函数的指针
  • 引用类型：
    • 左值引用
    • 右值引用
  • 枚举类型：
    • 无作用域枚举
    • 有作用域枚举
  • 类类型：
    • 结构体
    • 类
    • 联合体

你已经经常使用一种复合类型：函数。例如，考虑这个函数：

void doSomething(int x, double y)
{
}

这个函数的类型是 void(int, double)。注意，这个类型由基本类型组成，因此它是一个复合类型。当然，函数也有其特殊的行为（例如，可调用）。

由于这里要涵盖的内容很多，我们将分多个章节进行讲解。在本章中，我们将介绍一些更简单的复合类型，包括 l-value references、和 pointers。下一章，我们将介绍 unscoped enumerations， scoped enumerations，以及我们的第一个类类型： structs。然后，在之后的章节中，我们将介绍类并深入探讨一些更有用的 array 类型。这包括 std::string （在课程中引入 5.7 -- std::string 简介），它实际上是一个类类型！

术语

一个 类类型 是结构体、类或联合体的一种类型。在未来的课程中，我们会经常使用这个术语。
