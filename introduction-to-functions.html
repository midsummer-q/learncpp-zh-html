2.1 — 函数简介

● 机器译文 课程 2.1 查看英文原文

在上一章中，我们将函数定义为按顺序执行的语句集合。虽然这确实没错，但这个定义并没有充分说明函数的用处。让我们更新一下定义：一个 函数 是一个可重复使用的语句序列，旨在完成特定的任务。

你已经知道每个可执行程序都必须有一个名为 main() （即程序运行时开始执行的地方）的函数。然而，随着程序变得越来越长，将所有代码都放在 main() 函数中变得难以管理。函数提供了一种将程序拆分为更小、更模块化的块的方法，这些块更容易组织、测试和使用。大多数程序使用许多函数。C++标准库提供了大量现成的函数供你使用——不过，自己编写函数也同样常见。你自己编写的函数称为 用户自定义函数。

考虑现实生活中可能发生的情况：你正在读书，突然想起需要打个电话。你在书中放一个书签，打完电话后，你回到书签标记的地方，从刚才停下的地方精确地继续阅读。

C++程序也可以这样工作（并且借用了一些相同的术语）。当程序在一个函数中顺序执行语句时，遇到一个函数调用。一个 函数调用 告诉CPU中断当前函数并执行另一个函数。CPU本质上是“在当前执行点放一个书签”，执行函数调用中指定的函数，然后 返回 返回书签标记的点并继续执行。

术语

发起函数调用的函数是 调用者，而被 调用 （执行）的函数是 被调用者。函数调用有时也称为 调用由调用者 调用 被调用者。

一个用户自定义函数的示例

首先，让我们从定义用户自定义函数最基本的语法开始。在接下来的几节课中，所有用户自定义函数都将采用以下形式：

returnType functionName() // 这是函数头（告诉编译器该函数的存在）
{
    // 这是函数体（告诉编译器该函数做什么）
}

第一行非正式地称为 函数头，它告诉编译器有关函数的存在、函数的名称以及一些我们将在未来课程中介绍的其他信息（如返回类型）。

  • 在本课中，我们将使用 returnType 作为 int （对于函数 main()）或 void （其他情况）。目前，请不要担心这些，因为我们将在下一课（2.2 -- 函数返回值（有返回值的函数）)。
  • 就像变量有名称一样，用户自定义函数也有名称。 functionName 是您的用户自定义函数的名称（标识符）。
  • 标识符后面的括号告诉编译器我们正在定义一个函数。

花括号以及之间的语句称为 函数体. 这里是放置决定函数功能的语句的地方。

要调用函数，我们使用函数名后跟一对括号（例如 functionName() 调用名为 functionName）。通常，括号紧邻函数名放置（中间没有空格）。

目前，函数必须先定义才能调用。我们将在第 2.7 -- 前向声明和定义。

以下示例程序演示了用户定义函数的定义和调用：

#include <iostream> // for std::cout

// 用户自定义函数 doPrint() 的定义
// 在此示例中，doPrint() 是被调用的函数
void doPrint()
{
    std::cout << "In doPrint()\n";
}

// 用户自定义函数 main() 的定义
int main()
{
    std::cout << "Starting main()\n";
    doPrint();                        // 通过调用 doPrint() 来中断 main()。main() 是调用者。
    std::cout << "Ending main()\n";   // 该语句在 doPrint() 结束后执行

    return 0;
}

该程序产生如下输出：

Starting main()
In doPrint()
Ending main()

程序从函数 main()的顶部开始执行，执行的第一行打印 Starting main()。

中的第二行 main() 是对函数的调用 doPrint()。由于末尾有括号，我们知道这是一个函数调用。

警告

调用函数时，不要忘记函数名后的括号 () 如果忘记括号，程序可能无法编译（即使编译成功，函数也不会被调用）。

由于进行了函数调用，中的语句执行 main() 被暂停，执行跳转到被调用函数的顶部 doPrint()。中的第一行（也是唯一的一行） doPrint() 打印 In doPrint()。当 doPrint() 终止时，执行返回给调用者（main())，并从函数调用之后的那个点继续执行。因此，下一个执行的语句在 main() 打印 Ending main()。

多次调用函数

函数的一个有用特性是它们可以被多次调用。下面是一个演示此特性的程序：

#include <iostream> // for std::cout

void doPrint()
{
    std::cout << "In doPrint()\n";
}

// 函数 main() 的定义
int main()
{
    std::cout << "Starting main()\n";
    doPrint(); // 第一次调用 doPrint()
    doPrint(); // 第二次调用 doPrint()
    std::cout << "Ending main()\n";

    return 0;
}

该程序产生如下输出：

Starting main()
In doPrint()
In doPrint()
Ending main()

由于 doPrint() 被调用了两次，由 main()， doPrint() 执行了两次，并且 In doPrint() 被打印了两次（每次调用各一次）。

函数可以调用那些调用其他函数的函数

你已经看到函数 main() 可以调用其他函数（例如函数 doPrint() 在上面的例子中）。由 main() 调用的函数也可以调用其他函数（而那些函数也可以调用其他函数，等等…）。在下面的程序中，函数 main() 调用函数 doA()，而该函数又调用函数 doB()：

#include <iostream> // for std::cout

void doB()
{
    std::cout << "In doB()\n";
}


void doA()
{
    std::cout << "Starting doA()\n";

    doB();

    std::cout << "Ending doA()\n";
}

// 函数 main() 的定义
int main()
{
    std::cout << "Starting main()\n";

    doA();

    std::cout << "Ending main()\n";

    return 0;
}

该程序产生如下输出：

Starting main()
Starting doA()
In doB()
Ending doA()
Ending main()

不支持嵌套函数

定义在其他函数内部的函数称为 嵌套函数。与其他一些编程语言不同，在C++中，函数不能嵌套。下面的程序是非法的：

#include <iostream>

int main()
{
    void foo() // 非法：此函数嵌套在函数 main() 内部
    {
        std::cout << "foo!\n";
    }

    foo(); // 对foo()的函数调用

    return 0;
}

编写上述程序的正确方式是：

#include <iostream>

void foo() // 不再在main()内部
{
    std::cout << "foo!\n";
}

int main()
{
    foo();

    return 0;
}

术语

“foo”是一个无意义的词，当名称对某概念的演示不重要时，常被用作函数或变量的占位名称。这样的词被称为 元句法变量 （尽管在常用语言中它们通常被称为“占位符名称”，因为没人记得“元句法变量”这个术语）。C++中其他常见的元句法变量包括“bar”、“baz”，以及以“oo”结尾的三个字母的词，如“goo”、“moo”和“boo”。

对于那些对词源学（词语如何演变）感兴趣的人， RFC 3092 是一篇有趣的读物。
