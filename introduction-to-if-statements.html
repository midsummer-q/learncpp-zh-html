4.10 — if 语句简介

● 机器译文 课程 4.10 查看英文原文

考虑这样一个场景：你要去市场，你的室友告诉你，“如果草莓在打折，就买一些”。这是一个条件语句，意思是只有当条件（“草莓在打折”）为真时，你才会执行某个动作（“买一些”）。

这样的条件在编程中很常见，因为它们允许我们在程序中实现条件行为。C++中最简单的条件语句被称为 if 语句一个 if 语句 允许我们仅当某个条件为真时才执行一行（或多行）代码。

最简单的 if 语句 采用如下形式：

if (condition) true_statement;

为了可读性，更常写成如下形式：

if (condition)
    true_statement;

一个 条件 （也称为 条件表达式）是一个求值为布尔值的表达式。

如果 条件 一个 if 语句 求值为布尔值 真，那么 true_statement 被执行。如果 条件 求值为布尔值 假，那么 true_statement 则被跳过。

使用 if 语句的示例程序

给定以下程序：

#include <iostream>

int main()
{
    std::cout << "Enter an integer: ";
    int x {};
    std::cin >> x;

    if (x == 0)
        std::cout << "The value is zero\n";

    return 0;
}

以下是该程序一次运行的输出：

Enter an integer: 0
The value is zero

让我们更详细地研究一下这是如何工作的。

首先，用户输入一个整数。然后条件 x == 0 被评估。 相等运算符 (==) 用于测试两个值是否相等。Operator== 返回 真 如果操作数相等，且 假 如果不相等。由于 x 的值为 0，且 0 == 0 为 true，该表达式求值为 真。

因为条件求值为 真，后续语句执行，打印 The value is zero。

以下是该程序的另一次运行：

Enter an integer: 5

在这种情况下， x == 0 求值为 假。后续语句被跳过，程序结束，没有其他内容被打印。

警告

If 语句 仅条件执行单个语句。我们将在第 8.2 -- If statements and blocks。

If-else

鉴于上面的例子，如果我们想告诉用户他们输入的数字是非零的，该怎么办？

我们可以这样写：

#include <iostream>

int main()
{
    std::cout << "Enter an integer: ";
    int x {};
    std::cin >> x;

    if (x == 0)
        std::cout << "The value is zero\n";
    if (x != 0)
        std::cout << "The value is non-zero\n";

    return 0;
}

或者这样：

#include <iostream>

int main()
{
    std::cout << "Enter an integer: ";
    int x {};
    std::cin >> x;

    bool zero { (x == 0) };
    if (zero)
        std::cout << "The value is zero\n";
    if (!zero)
        std::cout << "The value is non-zero\n";

    return 0;
}

这两个程序都比实际需要更复杂。相反，我们可以使用另一种形式的 if 语句 调用 if-else。 If-else 采用如下形式：

if (condition)
    true_statement;
else
    false_statement;

如果 条件 的求值结果为布尔值 true， true_statement 则执行。否则 false_statement 执行。

让我们修改之前的程序，使用 if-else。

#include <iostream>

int main()
{
    std::cout << "Enter an integer: ";
    int x {};
    std::cin >> x;

    if (x == 0)
        std::cout << "The value is zero\n";
    else
        std::cout << "The value is non-zero\n";

    return 0;
}

现在我们的程序将产生以下输出：

Enter an integer: 0
The value is zero

Enter an integer: 5
The value is non-zero

链式 if 语句

有时我们想按顺序检查几个条件是否成立。我们可以通过将一个 if 语句 （或 if-else）链接到前面的 if-else中的内容，如下所示：

#include <iostream>

int main()
{
    std::cout << "Enter an integer: ";
    int x {};
    std::cin >> x;

    if (x > 0)
        std::cout << "The value is positive\n";
    else if (x < 0)
        std::cout << "The value is negative\n";
    else 
        std::cout << "The value is zero\n";

    return 0;
}

浮点类型的 小于运算符 （<）用于测试一个值是否小于另一个值。类似地， 大于运算符 （>）用于测试一个值是否大于另一个值。这两个运算符都返回布尔值。

以下是几次运行此程序的输出：

Enter an integer: 4
The value is positive

Enter an integer: -3
The value is negative

Enter an integer: 0
The value is zero

注意，你可以链式 if 语句 只要你有需要评估的条件，就可以多次使用。我们将在测验中看到一个有用的例子。

布尔返回值和 if 语句

在前一课（4.9 -- 布尔值)，我们编写了一个使用返回布尔值的函数的程序：

#include <iostream>
 
// 如果 x 和 y 相等则返回 true，否则返回 false
bool isEqual(int x, int y)
{
    return x == y; // operator== 如果 x 等于 y 则返回 true，否则返回 false
}
 
int main()
{
    std::cout << "Enter an integer: ";
    int x {};
    std::cin >> x;
 
    std::cout << "Enter another integer: ";
    int y {};
    std::cin >> y;
 
    std::cout << std::boolalpha; // 将布尔值打印为 true 或 false
    
    std::cout << x << " and " << y << " are equal? ";
    std::cout << isEqual(x, y); // 将返回 true 或 false

    std::cout << '\n';
 
    return 0;
}

让我们使用一个来改进这个程序 if 语句：

#include <iostream>
 
// 如果 x 和 y 相等则返回 true，否则返回 false
bool isEqual(int x, int y)
{
    return x == y; // operator== 如果 x 等于 y 则返回 true，否则返回 false
}
 
int main()
{
    std::cout << "Enter an integer: ";
    int x {};
    std::cin >> x;
 
    std::cout << "Enter another integer: ";
    int y {};
    std::cin >> y;
    
    if (isEqual(x, y))
        std::cout << x << " and " << y << " are equal\n";
    else
        std::cout << x << " and " << y << " are not equal\n";

    return 0;
}

该程序的两次运行：

Enter an integer: 5
Enter another integer: 5
5 and 5 are equal

Enter an integer: 6
Enter another integer: 4
6 and 4 are not equal

在这种情况下，我们的条件表达式只是对函数的调用 isEqual，它返回一个布尔值。

非布尔条件

在上述所有示例中，我们的条件要么是布尔值（true 或 false），要么是布尔变量，要么是返回布尔值的函数。如果你的条件是一个不计算为布尔值的表达式，会发生什么？

在这种情况下，条件表达式的结果会被转换为布尔值：非零值被转换为布尔 true，零值被转换为布尔 false。

因此，如果我们这样做：

#include <iostream>

int main()
{
    int x { 4 };
    if (x) // 无意义，但为了举例……
        std::cout << "hi\n";
    else
        std::cout << "bye\n";

    return 0;
}

这将打印 hi，因为 x 值为 4、和 4 是一个非零值，被转换为布尔 true，导致条件后的语句执行。

关键提示

if (x) 表示“如果 x 非零/非空”。

If 语句与提前返回

函数中不是最后一条语句的 return 语句称为 提前返回。这样的语句会导致函数在执行 return 语句时（在函数原本返回给调用者之前，即“提前”）返回给调用者。

无条件的提前返回是没有用的：

void print()
{
    std::cout << "A" << '\n';

    return; // 该函数将始终在这里返回给调用者

    std::cout << "B" << '\n'; // 这永远不会被打印
}

由于 std::cout << "B" << '\n'; 永远不会被执行，我们不妨移除它，然后我们的 return 语句就不再是提前的了。

然而，当与 if 语句结合使用时，提前返回提供了一种将函数返回值条件化的方式。

#include <iostream>

// 返回 x 的绝对值
int abs(int x) 
{
    if (x < 0)
        return -x; // 提前返回（仅在 x < 0 时）

    return x;
}

int main()
{
    std::cout << abs(4) << '\n'; // 打印 4
    std::cout << abs(-3) << '\n'; // 打印 3

    return 0;
}

当 abs(4) 被调用时， x 值为 4。 if (x < 0) 为 false，因此提前返回不会执行。函数返回 x （值 4）在函数末尾返回给调用者。

当 abs(-3) 被调用时， x 值为 -3。 if (x < 0) 为 true，因此提前返回执行。函数返回 -x （值 3）此时返回给调用者。

历史上，提前返回曾不受欢迎。然而，在现代编程中它们被更多地接受，尤其是当它们可以使函数更简单，或者用于由于某些错误条件而提前终止函数时。

问题 #1

什么是提前返回，它的行为是什么？

显示答案

提前返回是发生在函数最后一行之前的 return 语句。它会导致函数立即返回给调用者。

问题 #2

质数是大于1的整数，只能被1和自身整除。编写一个程序，要求用户输入一个0到9（含）的数字。如果用户输入的数字在此范围内且是质数（2、3、5或7），则打印“该数字是质数”。否则，打印“该数字不是质数”。

显示提示

提示：使用一连串的 if-else语句 将用户输入的数字与质数进行比较，看是否匹配。

显示答案

#include <iostream>

bool isPrime(int x)
{
    if (x == 2) // 如果用户输入了 2，该数字是质数
        return true;
    else if (x == 3) // 如果用户输入了 3，该数字是质数
        return true;
    else if (x == 5) // 如果用户输入了 5，该数字是质数
        return true;
    else if (x == 7) // 如果用户输入了 7，该数字是质数
        return true;

    return false; // 如果用户没有输入 2、3、5、7，则该数字必不是质数
}

int main()
{
    std::cout << "Enter a number 0 through 9: ";
    int x {};
    std::cin >> x;

    if ( isPrime(x) )
        std::cout << "The digit is prime\n";
    else
        std::cout << "The digit is not prime\n";

    return 0;
}

进阶读者

如果 isPrime() 上述函数看起来有点冗长/重复——确实如此。我们可以编写 isPrime() 更简洁高效地，使用一些我们将在未来课程中解释的概念。

使用逻辑或 (||) 运算符（6.8 -- 逻辑运算符)：

bool isPrime(int x)
{
    return x == 2 || x == 3 || x == 5 || x == 7; // 如果用户输入了 2 或 3 或 5 或 7，该数字是质数
}

使用switch语句（8.5 -- Switch语句基础)：

bool isPrime(int x)
{
    switch (x)
    {
        case 2: // 如果用户输入了 2
        case 3: // 或者如果用户输入了 3
        case 5: // 或者如果用户输入了 5
        case 7: // 或者如果用户输入了 7
            return true; // 那么该数字是质数
    }

    return false; // 否则该数字必不是质数
}

问题 #3

如何在不改变格式的情况下减少以下代码的长度？

#include <iostream>

bool isAllowedToTakeFunRide()
{
  std::cout << "How tall are you? (cm)\n";

  double height{};
  std::cin >> height;

  if (height >= 140.0)
    return true;
  else
    return false;
}

int main()
{
  if (isAllowedToTakeFunRide())
    std::cout << "Have fun!\n";
  else
    std::cout << "Sorry, you're too short.\n";

  return 0;
}

显示答案

我们不需要其中的if语句 isAllowedToTakeFunRide(). 表达式 height >= 140.0 求值为一个 bool，可以直接返回。

bool isAllowedToTakeFunRide()
{
  std::cout << "How tall are you? (cm)\n";

  double height{};
  std::cin >> height;

  return height >= 140.0;
}

你永远不需要形如以下的if语句：

if (condition)
  return true;
else
  return false;

这可以被单个语句替换 return condition。
