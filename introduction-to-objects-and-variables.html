1.3 — 对象和变量简介

● 机器译文 课程 1.3 查看英文原文

数据与值

在课程 1.1 -- Statements and the structure of a program，你了解到程序中的大部分指令都是语句，而函数是按顺序执行的一组语句。函数内部的语句执行操作，这些操作（希望）能产生程序设计要生成的任何结果。

但程序是如何实际产生结果的？它们通过操作（读取、更改和写入）数据来实现。在计算中， 数据 是任何可以由计算机移动、处理或存储的信息。

关键提示

程序是操作数据以产生期望结果的指令集合。

计算机程序（无论是源代码格式还是编译后的格式）在技术上也是数据，因为它们可以被移动、处理和存储。然而，在计算机程序的语境中，我们通常使用术语“代码”来指代程序本身，而“数据”则指代程序用来产生结果的信息。

程序可以通过多种方式获取要处理的数据：从文件或数据库、通过网络、由用户通过键盘提供输入，或者由程序员将数据直接放入程序的源代码中。在上述课程的“Hello world”程序中，文本“Hello world!”被直接插入到程序的源代码中，为程序提供了要使用的数据。然后程序通过将此数据发送到显示器进行显示来操作它。

在编程中，单个数据称为 值 （有时称为 数据值）。常见的值的例子包括：

  • 数字（例如 5 或 -6.7)。
  • 字符，放在单引号之间（例如 'H' 或 '$'）。只能使用单个符号。
  • 文本，必须放在双引号之间（例如 "Hello" 或 "H"）。文本可以包含0个或多个字符。

关键提示

放在单引号中的值会被编译器解释为字符值。
放在双引号中的值会被编译器解释为文本值。
数值不加引号。

直接放在源代码中的值被称为 字面量。我们在课程 5.2 -- 字面量。

中详细介绍了字面量。对值最常见的操作之一是将它们打印到屏幕上。例如：

#include <iostream> // for std::cout

int main()
{
    std::cout << 5;       // 打印字面量数字 `5`
    std::cout << -6.7;    // 打印字面量数字 `-6.7`
    std::cout << 'H';     // 打印字面量字符 `H`
    std::cout << "Hello"; // 打印字面量文本 `Hello`

    return 0;
}

如果字符值或文本值没有正确加引号，编译器会尝试将该值解释为 C++ 代码。这几乎总会导致编译错误。

字面量为程序提供值是最简单的方式，但它们有一些缺点。字面量是只读值，因此它们的值不能被修改。因此，如果我们想要在内存中存储数据，就需要其他方式来实现。

随机存取存储器

计算机中的主存储器称为 随机存取存储器 （通常称为 RAM （简称）。当我们运行程序时，操作系统会将程序加载到 RAM 中。程序中硬编码的任何数据（例如“Hello, world!”这样的文本）都会在此刻被加载。

操作系统还会为程序预留一些额外的 RAM，供其在运行时使用。这些内存的常见用途包括：存储用户输入的值、存储从文件或网络读取的数据，或者存储程序运行时计算出的值（例如两个值的和），以便之后再次使用。

你可以将 RAM 想象成一系列编号的盒子，用于在程序运行时存储数据。

在一些较老的编程语言（如 Applesoft BASIC）中，你可以直接访问这些盒子（例如，编写一条语句“去取出内存盒 7532 中存储的值”）。

对象和变量

在 C++ 中，不鼓励直接访问内存。相反，我们通过对象间接访问内存。一个 对象 表示一块可以保存值的存储区域（通常是 RAM 或 CPU 寄存器）。对象还具有相关的属性（我们将在后续课程中介绍）。

编译器和操作系统如何为对象分配内存超出了本课的范围。但这里的关键点是，我们不必说“去获取邮箱号 7532 中存储的值”，而是可以说“去获取此对象存储的值”，然后让编译器弄清楚在哪里以及如何检索该值。这意味着我们可以专注于使用对象来存储和检索值，而不必担心这些对象实际上被放置在内存中的哪个位置。

虽然 C++ 中的对象可以是未命名的（匿名），但更常见的是我们使用标识符来命名我们的对象。有名称的对象称为 变量。

关键提示

对象用于在内存中存储一个值。变量是具有名称（标识符）的对象。

命名我们的对象使我们能够在程序中稍后再次引用这些对象。

术语

在一般编程中，术语 对象 通常指内存中的未命名对象、变量或函数。在 C++ 中，术语 对象 具有更窄的定义，排除了函数。在本教程系列中使用术语对象时，我们指的是这个更窄的 C++ 定义。

变量定义

为了在程序中使用变量，我们需要告诉编译器我们想要一个变量。最常见的方式是使用一种特殊的声明语句，称为 定义 （我们将在课程 2.7 -- 前向声明和定义)。

关键提示

中明确声明和定义之间的区别）。定义语句可用于告诉编译器我们想要在程序中使用一个变量。

下面是一个定义名为 x：

int x; // 定义一个名为 x 的变量（类型为 int）

的变量的示例。在 编译时 （当程序被编译时），遇到此语句时，编译器会记下我们想要一个名为 x的变量，并且该变量具有数据类型 int (关于数据类型，稍后会详细说明)。从那时起（有一些限制，我们将在未来的课程中讨论），每当我们使用这个标识符 x 在我们的代码中，编译器就会知道我们指的是这个变量。

编译器为我们处理关于这个变量的所有其他细节，包括确定对象需要多少内存、对象将被放置在何种存储中（例如在RAM或CPU寄存器中）、相对于其他对象它将放在哪里、何时创建和销毁等等……

通过定义语句创建的变量被称为 定义 在定义语句所在的位置。目前，你的变量应该定义在函数内部（例如在 main())。

下面是一个包含变量定义语句的完整程序：

int main()
{
    int x; // 变量 x 的定义

    return 0;
}

变量创建

的变量的示例。在 运行时 （当程序被加载到内存并运行时），每个对象都会被分配一个实际的存储位置（如RAM或CPU寄存器），用于存储值。为对象预留存储空间的过程称为 分配。一旦分配完成，对象就被创建并可被使用。

为了举例说明，假设变量 x 在内存位置140处被实例化。每当程序使用变量 x，它就会访问内存位置140处的值。

关键提示

一旦为对象预留了实际存储空间，对象就被“创建”了。

当上述程序运行时，执行从 main()的顶部开始。为 x 分配内存。然后程序结束。

数据类型

到目前为止，我们已经介绍了对象是存储区域，可以存储数据值（数据具体如何存储是未来课程的主题）。一个 数据类型 （更常简称为 类型）决定了对象将存储哪种类型的值（例如数字、字母、文本等）。

在上面的示例中，我们的变量 x 被赋予了类型 int，这意味着变量 x 将存储一个整数值。整 数 是可以不写小数部分的数字，例如 4， 27， 0， -2，或 -12。简而言之，我们可以说 x 是一个 integer variable。

在C++中，对象的类型必须在编译时已知，并且如果不重新编译程序，该类型不能被更改。这意味着整数变量只能保存整数值。如果你想存储其他类型的值，就需要使用不同的类型。

关键提示

对象的数据类型必须在编译时已知（这样编译器才知道该对象需要多少内存）。

整数只是C++原生支持的众多类型之一。为了说明，这里是使用数据类型定义变量的另一个例子 double：

double width; // 定义一个名为 width 的变量，类型为 double

C++还允许你创建自己的自定义类型。这是我们在未来课程中经常要做的事情，也是C++强大的一部分原因。

在这些介绍性章节中，我们将坚持使用整数变量，因为它们在概念上很简单，但我们将很快探索C++提供的许多其他类型（包括 double）很快。

定义多个变量

可以定义多个变量 相同类型的 通过逗号分隔名称，写在一个语句中。以下代码片段：

int a;
int b;

实际上等同于以下代码：

int a, b;

通过这种方式定义多个变量时，新手程序员容易犯三个常见错误（都不严重，因为编译器会捕获并提醒你修复）：

第一个错误是在顺序定义变量时为每个变量都指定类型。

int a, int b; // 错误（编译器报错）

int a, b; // 正确

第二个错误是试图在同一语句中定义不同类型的变量，这是不允许的。不同类型的变量必须在单独的语句中定义。

int a, double b; // 错误（编译器报错）

int a; double b; // 正确（但不推荐）

// 正确且推荐（更易阅读）
int a;
double b;

我们将在下一课关于变量初始化时讨论第三个问题。

最佳实践

尽管语言允许你这样做，但应避免在一条语句中定义多个相同类型的变量。相反，每个变量单独一行定义（然后使用单行注释说明其用途）。

总结

在C++中，我们使用对象来访问内存。命名对象称为变量。每个变量都有标识符、类型和值（以及一些此处不相关的其他属性）。变量的类型用于确定应如何解释内存中的值。

变量实际上是在运行时创建的，此时会分配内存供其使用。

在下一课中，我们将学习如何给变量赋值以及如何实际使用它们。
