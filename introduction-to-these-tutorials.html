课程结构

本入门章节的课程旨在为您提供一些背景知识，包括 C++ 是什么、它是如何产生的、程序是如何工作的，以及您需要安装哪些软件来创建自己的程序。您甚至还会编写自己的第一个程序。

后续章节将探索 C++ 语言的不同部分。在第一章（第 1 章）中，您将广泛但浅显地了解许多基本的 C++ 概念，这样我们就可以开始编写一些简单的程序。后续章节将深入探讨这些概念，或者引入新的概念。

每章都有一个主题，其下的大多数课程一般都与该主题相关。对于每节课或每章，没有建议的学习时间；请按照您感到舒适的速度学习这些内容。

目标

在开始之前，让我们先明确这些教程的几个重要目标：

  • 涵盖通用编程主题以及 C++ 相关内容。传统教科书在教授特定编程语言的基础知识方面做得很好，但它们通常不涵盖与该语言相关的其他编程主题。例如，书籍会省略关于编程风格、常见陷阱、调试、良好/不良编程实践和测试的部分。结果，当您读完这本书时，您可能知道如何用一种语言编程，但您也可能养成了以后会带来麻烦的坏习惯！这些教程的目标之一是确保所有这些附带主题在学习过程中、在自然适合讨论它们的章节中得到涵盖。当您完成学习时，您不仅会知道如何用 C++ 编程，还会知道如何不用 C++ 编程——这可以说同样重要。

  • 提供大量示例。大多数人通过跟随示例学到的内容与通过阅读文本学到的内容一样多，甚至更多。这些教程将努力提供大量清晰、简洁的示例，以展示您正在学习的概念的应用。我们还将（尽可能）避免两个常见的弊端： 省略号 （也称为 …），即为了节省篇幅而省略示例中必要或不明显的部分，以及 未解释的新概念，其中介绍了一个对示例至关重要的新概念，但没有提及它是什么或如何工作。这两种情况通常会导致卡住。

  • 提供练习程序。许多课程和章节的末尾会包含一些练习题，你可以尝试自己解答，并附有解答。你可以将自己的解答与我们的进行比较，看看我们有何不同，或者如果卡住了，看看我们是如何解决问题的。然后你可以回过头来，重新专注于需要更多练习的领域。

  • 最重要的是：享受乐趣。编程可以非常有趣，如果你总体上不觉得有趣，那么你的心态就不适合编程。疲劳或不快乐的程序员容易犯错，而调试代码往往比一开始就正确编写要花更多时间！通常，你可以通过上床睡觉、好好睡一晚，然后早上再回来处理问题来节省一些时间。

充分利用这些教程

在浏览这些教程时，我们推荐一些做法来最大化你的学习体验：

  • 亲自输入示例 用手。这将帮助你了解自己常犯错误的地方，并熟悉由拼写错误导致的各种诊断信息。在输入每一行时，思考它的作用以及它如何为整个程序做出贡献。如果你遇到任何不理解的内容，那就是需要进一步探究的地方。

  • 当你犯错或在程序中发现错误时，修复它们。在向他人求助之前，尝试自己解决问题。学会发现和修复错误是成功编程的关键技能。不要忽视学习如何使用调试器（我们将在未来的章节中解释如何操作）——它是找出程序出错位置的关键工具。

  • 尝试修改示例。更改数字和文本，看看会发生什么。修改程序以执行额外的操作（例如，如果一个程序对两个数求和，让它对三个数求和）。尝试不同的方法来破坏程序（例如，如果一个程序要求你输入一个数字，尝试输入一个字母，看看会发生什么）。通过修改示例，你学到的东西会比简单地遵从它们更多。

  • 计划花一些时间做测验。如果你是编程新手，你可能会觉得这些有挑战性（这很正常，因为你的大脑正在适应编程思维）。如果第一次没有答对，不要气馁。在找到成功之路之前，你可能需要尝试几种不同的方法。如果实在卡住了，看看答案是可以的。只要确保在继续之前理解提供的答案是如何工作的。

  • 使用你学过的概念编写自己的简短程序。这将巩固你的学习并提高记忆力。

问：如果我对某个概念卡住了，该怎么办？

如果你不理解某件事或感到卡住了：

  • 仔细阅读评论。其他读者可能遇到过类似的挑战。
  • 浏览教程系列中的下一两课——你的问题可能在那里得到解答。
  • 使用搜索引擎查看你的问题（或错误信息）是否已在其他地方得到解决。
  • 向人工智能寻求解释。请注意，人工智能提供的信息可能完全或部分不正确。
  • 在专门用于编程问答的网站上提问，例如 Stack Overflow。

如果其他方法都无效，跳过你不理解的内容，稍后再回来。你可能会发现，有了其他文章提供的额外知识和上下文，原本难以理解的东西会变得更容易。
