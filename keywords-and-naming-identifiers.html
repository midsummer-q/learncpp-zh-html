标识符命名规则

提醒一下，变量（或函数、类型或其他种类的项）的名称称为标识符。C++赋予您很大的灵活性，可以随意命名标识符。然而，在命名标识符时，必须遵循一些规则：

  • 标识符不能是关键字。关键字是保留的。
  • 标识符只能由字母（大写或小写）、数字和下划线字符组成。这意味着名称不能包含符号（下划线除外）或空白字符（空格或制表符）。
  • 标识符必须以字母（大写或小写）或下划线开头。不能以数字开头。
  • C++是区分大小写的，因此区分小写和大写字母。 nvalue 与...不同 nValue 与...不同 NVALUE。

标识符命名最佳实践

既然您知道了您如何 可以 命名一个变量，让我们谈谈您如何 应该 命名一个变量（或函数）。

  1. C++中约定变量名应以小写字母开头。如果变量名是单个单词或首字母缩写，整个名称应使用小写字母。
int value; // 常规的

int Value; // 不符合惯例的（应以小写字母开头）
int VALUE; // 不符合惯例的（应以小写字母开头且全部小写）
int VaLuE; // 不符合惯例的（看看你的心理医生）;)

大多数情况下，函数名也以小写字母开头（尽管这一点存在一些争议）。我们将遵循这一约定，因为函数 main （所有程序都必须有）以小写字母开头，C++标准库中的所有函数也是如此。

以大写字母开头的标识符名称通常用于用户定义的类型（例如结构体、类和枚举，这些我们将在后面介绍）。

如果变量名或函数名由多个单词组成，有两种常见的约定：单词之间用下划线分隔（有时称为蛇形命名法），或采用中间大写（有时称为驼峰命名法，因为大写字母像骆驼的驼峰一样突出）。

int my_variable_name;   // 常规的（用下划线分隔/snake_case）
int my_function_name(); // 常规的（用下划线分隔/snake_case）

int myVariableName;     // 常规的（交错大小写/camelCase）
int myFunctionName();   // 常规的（交错大小写/camelCase）

int my variable name;   // 无效的（不允许空白）
int my function name(); // 无效的（不允许空白） 

int MyVariableName;     // 不符合惯例的（应以小写字母开头）
int MyFunctionName();   // 不符合惯例的（应以小写字母开头）

在本教程中，我们将主要使用中间大写的方式，因为它更容易阅读（在密集的代码块中，下划线容易被误认为是空格）。但两种方式都很常见——C++标准库对变量和函数都使用下划线方法。有时您会看到两者的混合：变量使用下划线，函数使用中间大写。

值得注意的是，如果你在别人的代码中工作，通常认为匹配你所使用的代码风格比严格遵循上述命名约定更好。

最佳实践

在现有程序中工作时，使用该程序的约定（即使它们不符合现代最佳实践）。编写新程序时，使用现代最佳实践。

  1. 避免以开下划线命名标识符。虽然语法上合法，但这些名称通常保留给操作系统、库和/或编译器使用。
  2. 标识符的名称应明确其持有的值是什么意思（特别是当单位不明确时）。标识符的命名应能帮助一个完全不了解你代码的人尽快理解。三个月后，当你再次查看你的程序时，你会忘记它是如何工作的，到时你会感谢自己选择了有意义的变量名。

然而，给一个简单的标识符起一个过于复杂的名称，几乎与给一个非平凡的标识符起一个不恰当的名称一样，会妨碍对程序整体理解。一个好的经验法则是使标识符的长度与其具体性和可访问性成正比。这意味着：

  • 仅存在于少数语句中的标识符（例如在短函数体内）可以有一个较短的名称。
  • 可从任何地方访问的标识符可能受益于较长的名称。
  • 代表非特定数字的标识符（例如用户提供的任何内容）可以有一个较短的名称。
  • 代表特定值的标识符（例如内缝长度（毫米））应该有一个较长的名称。

int ccount差“count”前面的c代表什么？
int customerCount好清楚我们在计数什么
int i皆可若使用简单则还行，否则差
int index皆可若索引对象明确则还行

关键提示

代码被阅读的次数远多于被编写的次数，因此编写代码时节省的任何时间，都会被每个阅读者（包括未来的你）在阅读时浪费掉。如果你想更快地编写代码，请使用编辑器的自动补全功能。

  1. 对于变量声明，使用注释来说明变量的用途，或解释任何其他可能不明显的内容，可能会很有用。例如，假设我们声明了一个变量，用于存储一段文本中的字符数。文本“Hello World!”有10、11还是12个字符？这取决于我们是否包含空白或标点符号。与其将变量命名为 numCharsIncludingWhitespaceAndPunctuation，这相当冗长，在声明行上或上方放置一个合适的注释，可以帮助用户理解：
// 一段文本中字符数的计数，包括空白和标点符号
int numChars {};
