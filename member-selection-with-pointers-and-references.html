13.12 — 使用指针和引用进行成员选择

● 机器译文 课程 13.12 查看英文原文

结构体和结构体引用的成员选择

在课程 13.7 课——结构体、成员和成员选择简介中介绍结构体。中，我们展示了可以使用成员选择运算符（.）从结构体对象中选择成员：

#include <iostream>

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

int main()
{
    Employee joe { 1, 34, 65000.0 };

    // 使用成员选择运算符（.）从结构体对象中选择成员
    ++joe.age; // Joe 过生日了
    joe.wage = 68000.0; // Joe 升职了
    
    return 0;
}

由于对象的引用行为与对象本身完全相同，我们也可以使用成员选择运算符（.）从结构体引用中选择成员：

#include <iostream>

struct Employee
{
    int id{};
    int age{};
    double wage{};
};

void printEmployee(const Employee& e)
{
    // 使用成员选择运算符（.）从结构体引用中选择成员
    std::cout << "Id: " << e.id << '\n';
    std::cout << "Age: " << e.age << '\n';
    std::cout << "Wage: " << e.wage << '\n';
}

int main()
{
    Employee joe{ 1, 34, 65000.0 };

    ++joe.age;
    joe.wage = 68000.0;

    printEmployee(joe);

    return 0;
}

指向结构体的指针的成员选择

然而，成员选择运算符（.）不能直接用于指向结构体的指针：

#include <iostream>

struct Employee
{
    int id{};
    int age{};
    double wage{};
};

int main()
{
    Employee joe{ 1, 34, 65000.0 };

    ++joe.age;
    joe.wage = 68000.0;

    Employee* ptr{ &joe };
    std::cout << ptr.id << '\n'; // 编译错误：不能对指针使用运算符.

    return 0;
}

对于普通变量或引用，我们可以直接访问对象。但是，由于指针保存的是地址，我们首先需要解引用指针以获取对象，然后才能对其进行操作。因此，从指向结构体的指针访问成员的一种方法如下：

#include <iostream>

struct Employee
{
    int id{};
    int age{};
    double wage{};
};

int main()
{
    Employee joe{ 1, 34, 65000.0 };

    ++joe.age;
    joe.wage = 68000.0;

    Employee* ptr{ &joe };
    std::cout << (*ptr).id << '\n'; // 不太好但可行：先解引用 ptr，然后使用成员选择

    return 0;
}

然而，这有点丑陋，特别是因为我们需要将解引用操作括起来，以便它优先于成员选择操作。

为了提供更简洁的语法，C++ 提供了 指针成员选择运算符（->） （有时也称为 箭头运算符），可用于从指向对象的指针中选择成员：

#include <iostream>

struct Employee
{
    int id{};
    int age{};
    double wage{};
};

int main()
{
    Employee joe{ 1, 34, 65000.0 };

    ++joe.age;
    joe.wage = 68000.0;

    Employee* ptr{ &joe };
    std::cout << ptr->id << '\n'; // 更好：使用 -> 从指向对象的指针中选择成员

    return 0;
}

这个指针成员选择运算符（->）的工作方式与成员选择运算符（.）完全相同，但在选择成员之前隐式解引用指针对象。因此 ptr->id 等价于 (*ptr).id。

这个箭头运算符不仅更容易输入，而且更不容易出错，因为间接引用是隐式完成的，所以没有优先级问题需要担心。因此，当通过指针访问成员时，始终使用 -> 运算符而不是 . 运算符。

最佳实践

当使用指针访问成员时，使用指针成员选择运算符（->）而不是成员选择运算符（.）。

链式访问 operator->

如果通过 operator-> 访问的成员是指向类类型的指针， operator-> 可以在同一表达式中再次应用以访问该类类型的成员。

以下示例说明了这一点（由读者 Luna 提供）：

#include <iostream>

struct Point
{
    double x {};
    double y {};
};

struct Triangle
{
    Point* a {};
    Point* b {};
    Point* c {};
};

int main()
{
    Point a {1,2};
    Point b {3,7};
    Point c {10,2};

    Triangle tr { &a, &b, &c };
    Triangle* ptr {&tr};

    // ptr 是指向 Triangle 的指针，Triangle 包含指向 Point 的成员
    // 要访问ptr指向的Triangle的Point c的成员y，以下两种方式等价：

    // 通过operator.访问
    std::cout << (*(*ptr).c).y << '\n'; // 丑陋！

    // 通过operator->访问
    std::cout << ptr -> c -> y << '\n'; // 好多了
}

当连续使用多个 operator-> 时（例如 ptr->c->y），表达式可能难以阅读。在成员和 operator-> 开头的单个大写字母（例如 ptr -> c -> y之间添加空格）可以使被访问的成员与运算符更容易区分。

混合使用指针和非指针成员

成员选择运算符始终应用于当前选定的变量。如果你混合使用指针和普通成员变量，你会看到 . 和 -> 在序列中同时使用的成员选择：

#include <iostream>
#include <string>

struct Paw
{
    int claws{};
};
 
struct Animal
{
    std::string name{};
    Paw paw{};
};
 
int main()
{
    Animal puma{ "Puma", { 5 } };
 
    Animal* ptr{ &puma };
 
    // ptr是指针，使用->
    // paw不是指针，使用.

    std::cout << (ptr->paw).claws << '\n';
 
    return 0;
}

注意，在 (ptr->paw).claws的情况下，括号不是必需的，因为 operator-> 和 operator. 都是从左到右求值，但它稍微有助于可读性。
