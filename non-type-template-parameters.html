11.9 — 非类型模板参数

● 机器译文 课程 11.9 查看英文原文

在前面的课程中，我们讨论了如何创建使用类型模板参数的函数模板。类型模板参数作为实际类型的占位符，该实际类型作为模板实参传入。

虽然类型模板参数是目前最常用的模板参数类型，但还有另一种值得了解的模板参数：非类型模板参数。

非类型模板参数

一个 非类型模板参数 是一种具有固定类型的模板参数，作为传入的 constexpr 值的占位符。

非类型模板参数可以是以下任意类型：

  • 整型
  • 枚举类型
  • std::nullptr_t
  • 浮点类型（自 C++20 起）
  • 指向对象的指针或引用
  • 指向函数的指针或引用
  • 指向成员函数的指针或引用
  • 字面类类型（自 C++20 起）

我们在讨论 std::bitset 在课程 O.1 -- 位标志和通过std::bitset进行位操作：

#include <bitset>

int main()
{
    std::bitset<8> bits{ 0b0000'0101 }; // <8> 是一个非类型模板参数

    return 0;
}

在 std::bitset时看到了第一个非类型模板参数的例子，非类型模板参数用于告诉 std::bitset 要存储多少位。

定义我们自己的非类型模板参数

下面是一个使用 int 非类型模板参数的简单函数示例：

#include <iostream>

template <int N> // 声明一个类型为 int 的非类型模板参数，名为 N
void print()
{
    std::cout << N << '\n'; // 在此处使用 N 的值
}

int main()
{
    print<5>(); // 5 是我们的非类型模板实参

    return 0;
}

此示例输出：

5

在第 3 行，我们有模板参数声明。在尖括号内，我们定义了一个名为 N 的非类型模板参数，它将作为类型为 int的值的占位符。在 print() 函数内部，我们使用 N。

的值。在第 11 行，我们调用了函数 print()，它使用 int 值 5 作为非类型模板实参。当编译器看到这个调用时，它会实例化一个类似这样的函数：

template <>
void print<5>()
{
    std::cout << 5 << '\n';
}

在运行时，当这个函数从 main()，它会打印 5。

被调用时，然后程序结束。很简单，对吧？

就像 T 通常用作第一个类型模板参数的名称一样， N 通常用作 int 非类型模板参数的名称。

最佳实践

使用 N 作为 int 非类型模板参数的名称。

非类型模板参数有什么用处？

自 C++20 起，函数参数不能是 constexpr。这对于普通函数、constexpr 函数（这很合理，因为它们必须能够在运行时运行），甚至可能令人惊讶的是，consteval 函数也是如此。

假设我们有一个像这样的函数：

#include <cassert>
#include <cmath> // for std::sqrt
#include <iostream>

double getSqrt(double d)
{
    assert(d >= 0.0 && "getSqrt(): d must be non-negative");

    // 上面的断言在非调试构建中可能会被编译掉
    if (d >= 0)
        return std::sqrt(d);

    return 0.0;
}

int main()
{
    std::cout << getSqrt(5.0) << '\n';
    std::cout << getSqrt(-5.0) << '\n';

    return 0;
}

运行时，对 getSqrt(-5.0) 的调用将触发运行时断言。虽然这比没有好，但因为 -5.0 是字面量（且隐式 constexpr），如果我们可以使用 static_assert 以便在编译时捕获此类错误会更好。然而，static_assert 需要常量表达式，而函数参数不能是 constexpr……

但是，如果我们将函数参数改为非类型模板参数，那么我们就可以实现我们想要的效果：

#include <cmath> // for std::sqrt
#include <iostream>

template <double D> // 需要 C++20 以支持浮点非类型参数
double getSqrt()
{
    static_assert(D >= 0.0, "getSqrt(): D must be non-negative");

    if constexpr (D >= 0) // 忽略此示例中的 constexpr
        return std::sqrt(D); // 奇怪的是，std::sqrt 不是 constexpr 函数（直到 C++26）

    return 0.0;
}

int main()
{
    std::cout << getSqrt<5.0>() << '\n';
    std::cout << getSqrt<-5.0>() << '\n';

    return 0;
}

这个版本无法编译。当编译器遇到 getSqrt<-5.0>()时，它将实例化并调用一个类似这样的函数：

template <>
double getSqrt<-5.0>()
{
    static_assert(-5.0 >= 0.0, "getSqrt(): D must be non-negative");

    if constexpr (-5.0 >= 0) // 忽略此示例中的 constexpr
        return std::sqrt(-5.0);

    return 0.0;
}

static_assert 条件为假，因此编译器断言失败。

关键提示

非类型模板参数主要用于需要将 constexpr 值传递给函数（或类类型），以便在需要常量表达式的上下文中使用它们。

类类型 std::bitset 使用非类型模板参数来定义要存储的位数，因为位数必须是 constexpr 值。

作者注

不得不使用非类型模板参数来规避函数参数不能是 constexpr 的限制并不理想。目前正在评估许多不同的提案来解决这类情况。我预计在未来的 C++ 语言标准中可能会看到更好的解决方案。

非类型模板参数的隐式转换 可选

某些非类型模板参数可以隐式转换，以匹配不同类型的非类型模板参数。例如：

#include <iostream>

template <int N> // int 非类型模板参数
void print()
{
    std::cout << N << '\n';
}

int main()
{
    print<5>();   // 无需转换
    print<'c'>(); // 'c' 转换为 int 类型，打印 99

    return 0;
}

这会打印：

5
99

在上面的例子中， 'c' 被转换为 int 以匹配函数模板的非类型模板参数 print()，然后将其值打印为 int。

在此上下文中，只允许某些类型的 constexpr 转换。最常见的允许转换类型包括：

  • 整型提升（例如 char 切换到 int)
  • 整型转换（例如 char 切换到 long 或 int 切换到 char)
  • 用户定义转换（例如某些程序定义的类转换为 int)
  • 左值到右值转换（例如某些变量 x 到 x)

的值）注意，此列表比列表初始化允许的隐式转换类型限制更严格。例如，你可以使用 double 列表初始化一个类型为 constexpr int的变量，但 constexpr int 非类型模板参数不会转换为 double 非类型模板参数。

允许转换的完整列表可以在 这里 子节“转换后的常量表达式”下找到。

与普通函数不同，匹配函数模板调用到函数模板定义的算法并不复杂，并且某些匹配不会根据所需转换的类型（或缺乏转换）而优先于其他匹配。这意味着，如果函数模板针对不同类型的非类型模板参数进行了重载，很容易导致歧义匹配：

#include <iostream>

template <int N> // int 非类型模板参数
void print()
{
    std::cout << N << '\n';
}

template <char N> // char 非类型模板参数
void print()
{
    std::cout << N << '\n';
}

int main()
{
    print<5>();   // 与 int N = 5 和 char N = 5 的匹配存在歧义
    print<'c'>(); // 与 int N = 99 和 char N = 'c' 的匹配存在歧义

    return 0;
}

也许令人惊讶的是，这两个对 print() 的调用都导致了歧义匹配。

使用 auto C++17

进行非类型模板参数的类型推导从 C++17 开始，非类型模板参数可以使用 auto 让编译器从模板实参推导非类型模板参数：

#include <iostream>

template <auto N> // 从模板实参推导非类型模板参数
void print()
{
    std::cout << N << '\n';
}

int main()
{
    print<5>();   // N 被推导为 int `5`
    print<'c'>(); // N 被推导为 char `c`

    return 0;
}

这可以编译并产生预期结果：

5
c

进阶读者

你可能想知道为什么这个例子没有像上一节中的例子那样产生歧义匹配。编译器首先查找歧义匹配，如果不存在歧义匹配，则实例化函数模板。在这种情况下，只有一个函数模板，因此不可能存在歧义。

实例化上述示例的函数模板后，程序看起来像这样：

#include <iostream>

template <auto N>
void print()
{
    std::cout << N << '\n';
}

template <>
void print<5>() // 注意这是 print<5> 而不是 print<int>
{
    std::cout << 5 << '\n';
}

template <>
void print<'c'>() // 注意这是 print<`c`> 而不是 print<char>
{
    std::cout << 'c' << '\n';
}

int main()
{
    print<5>();   // 调用 print<5>
    print<'c'>(); // 调用 print<'c'>

    return 0;
}

小测验时间

问题 #1

编写一个带有非类型模板参数的 constexpr 函数模板，返回模板参数的阶乘。以下程序在到达 factorial<-3>()。

// 在此处定义你的 factorial() 函数模板

int main()
{
    static_assert(factorial<0>() == 1);
    static_assert(factorial<3>() == 6);
    static_assert(factorial<5>() == 120);

    factorial<-3>(); // 应该编译失败

    return 0;
}

显示答案

template <int N>
constexpr int factorial()
{
    static_assert(N >= 0);

    int product { 1 };
    for (int i { 2 }; i <= N; ++i)
        product *= i;

    return product;
}

int main()
{
    static_assert(factorial<0>() == 1);
    static_assert(factorial<3>() == 6);
    static_assert(factorial<5>() == 120);

    factorial<-3>(); // 应该编译失败

    return 0;
}
