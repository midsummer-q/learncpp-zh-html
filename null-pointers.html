12.8 — 空指针

● 机器译文 课程 12.8 查看英文原文

在前一课（12.7 -- 指针简介我们介绍了指针的基础知识，指针是保存另一个对象地址的对象。可以使用解引用运算符（*）解引用该地址，以获取该地址处的对象：

#include <iostream>

int main()
{
    int x{ 5 };
    std::cout << x << '\n'; // 打印变量 x 的值

    int* ptr{ &x }; // ptr 持有 x 的地址
    std::cout << *ptr << '\n'; // 使用解引用运算符打印 ptr 所保存地址处的对象的值（即 x 的地址）

    return 0;
}

上面的示例输出：

5
5

在上一课中，我们还指出指针不必指向任何东西。在本课中，我们将进一步探讨这样的指针（以及指向空的各种含义）。

空指针

除了内存地址，指针还可以保存一个额外的值：空值。 空值 （常简称为 null）是一个特殊值，表示某物没有值。当指针持有空值时，意味着该指针没有指向任何东西。这样的指针称为 空指针。

创建空指针最简单的方法是使用值初始化：

int main()
{
    int* ptr {}; // ptr 现在是空指针，不保存地址
 
    return 0;
}

最佳实践

如果未用有效对象的地址初始化指针，请将其值初始化为空指针。

因为我们可以使用赋值来改变指针的指向，所以最初设置为空的指针稍后可以更改为指向有效对象：

#include <iostream>

int main()
{
    int* ptr {}; // ptr 是空指针，不保存地址

    int x { 5 };
    ptr = &x; // ptr 现在指向对象 x（不再是空指针）

    std::cout << *ptr << '\n'; // 通过解引用 ptr 打印 x 的值
 
    return 0;
}

nullptr 关键字

就像关键字 true 和 false 表示布尔字面值一样， 空指针 关键字表示空指针字面值。我们可以使用 nullptr 来显式初始化或给指针赋空值。

int main()
{
    int* ptr { nullptr }; // 可以使用 nullptr 将指针初始化为空指针

    int value { 5 };
    int* ptr2 { &value }; // ptr2 是有效指针
    ptr2 = nullptr; // 可以赋值 nullptr 使指针成为空指针

    someFunction(nullptr); // 我们也可以将 nullptr 传递给具有指针参数的函数

    return 0;
}

解引用空指针会导致未定义行为

就像解引用悬空（或野）指针会导致未定义行为一样，解引用空指针也会导致未定义行为。在大多数情况下，它会导致应用程序崩溃。

下面的程序说明了这一点，运行时可能会崩溃或异常终止你的应用程序（试试看，不会损坏你的机器）：

#include <iostream>

int main()
{
    int* ptr {}; // 创建一个空指针
    std::cout << *ptr << '\n'; // 解引用空指针

    return 0;
}

从概念上讲，这是有道理的。解引用指针意味着“转到指针指向的地址并访问那里的值”。空指针持有空值，从语义上讲，这意味着指针没有指向任何东西。那么它会访问什么值呢？

意外解引用空指针和悬空指针是 C++ 程序员最常犯的错误之一，并且可能是实践中 C++ 程序崩溃的最常见原因。

警告

每当你使用指针时，都需要格外小心，确保代码不会解引用空指针或悬空指针，因为这会导致未定义行为（可能是应用程序崩溃）。

检查空指针

就像我们可以使用条件语句测试布尔值是否为 true 或 false一样，我们可以使用条件语句测试指针的值是否为 nullptr ：

#include <iostream>

int main()
{
    int x { 5 };
    int* ptr { &x };

    if (ptr == nullptr) // 显式测试相等性
        std::cout << "ptr is null\n";
    else
        std::cout << "ptr is non-null\n";

    int* nullPtr {};
    std::cout << "nullPtr is " << (nullPtr==nullptr ? "null\n" : "non-null\n"); // 显式测试相等性

    return 0;
}

上面的程序打印：

ptr is non-null
nullPtr is null

在课程 4.9 -- 布尔值我们指出整数值会隐式转换为布尔值：整数值 0 转换为布尔值 false，任何其他整数值转换为布尔值 true。

类似地，指针也会隐式转换为布尔值：空指针转换为布尔值 false，非空指针转换为布尔值 true。这允许我们跳过显式测试 nullptr ，而直接使用隐式转换为布尔值来测试指针是否为空指针。下面的程序与上一个等效：

#include <iostream>

int main()
{
    int x { 5 };
    int* ptr { &x };

    // 指针为空时转换为布尔值 false，非空时转换为布尔值 true
    if (ptr) // 隐式转换为布尔值
        std::cout << "ptr is non-null\n";
    else
        std::cout << "ptr is null\n";

    int* nullPtr {};
    std::cout << "nullPtr is " << (nullPtr ? "non-null\n" : "null\n"); // 隐式转换为布尔值

    return 0;
}

警告

条件语句只能用于区分空指针和非空指针。没有方便的方法来确定非空指针是指向有效对象还是悬空（指向无效对象）。

使用 nullptr 避免悬空指针

上面我们提到，解引用空指针或悬空指针会导致未定义行为。因此，我们需要确保代码不会出现这两种情况。

我们可以通过使用条件语句确保指针在解引用前非空，从而轻松避免解引用空指针：

// 假设 ptr 是某个可能为空也可能不为空的指针
if (ptr) // 如果 ptr 不是空指针
    std::cout << *ptr << '\n'; // 可以解引用
else
    // 执行其他不涉及解引用 ptr 的操作（打印错误信息、什么都不做等）

但悬空指针呢？由于无法检测指针是否悬空，我们需要首先避免程序中存在任何悬空指针。我们通过确保任何不指向有效对象的指针被设置为 nullptr。

这样，在解引用指针之前，我们只需要测试它是否为空——如果非空，我们就假定指针没有悬空。

最佳实践

指针要么持有有效对象的地址，要么被设置为 nullptr。这样我们只需要测试指针是否为空，并可以假定任何非空指针都是有效的。

不幸的是，避免悬空指针并不总是容易：当一个对象被销毁时，指向该对象的任何指针都会悬空。这些指针 不是 不会自动置空！程序员有责任确保所有指向刚刚销毁的对象的指针被正确设置为 nullptr。

警告

当一个对象被销毁时，指向该对象的任何指针都会悬空（它们不会自动设置为 nullptr）。你有责任检测这些情况并确保这些指针随后被设置为 nullptr。

遗留的空指针字面量：0 和 NULL

在旧代码中，你可能会看到另外两个字面量值被用来代替 nullptr。

第一个是字面量 0。在指针的上下文中，字面量 0 被特别定义为表示空值，并且这是唯一可以将整数字面量赋值给指针的情况。

int main()
{
    float* ptr { 0 };  // ptr 现在是空指针（仅作示例，不要这样做）

    float* ptr2; // ptr2 未初始化
    ptr2 = 0; // ptr2 现在是空指针（仅作示例，不要这样做）

    return 0;
}

顺便说一句……

在现代架构中，地址 0 通常用于表示空指针。然而，这个值并非 C++ 标准所保证，某些架构使用其他值。字面量 0在空指针的上下文中使用时，会被转换为架构用来表示空指针的任何地址。

此外，还有一个名为 NULL 的预处理器宏（定义在 <cstddef> 头文件中）。这个宏继承自 C，在 C 中通常用于表示空指针。

#include <cstddef> // for NULL

int main()
{
    double* ptr { NULL }; // ptr 是空指针

    double* ptr2; // ptr2 未初始化
    ptr2 = NULL; // ptr2 现在是空指针

    return 0;
}

两者都 0 和 NULL 在现代 C++ 中应避免使用（使用 nullptr 代替）。我们将在课程 12.11 -- 按地址传递（第 2 部分）。

尽可能优先使用引用而非指针

指针和引用都赋予我们间接访问其他对象的能力。

int main()
{
    int* ptr { };
    
    {
        int x{ 5 };
        ptr = &x; // 将指针赋值给一个即将被销毁的对象（引用无法做到）
    } // ptr 现在是悬垂指针，指向无效对象

    if (ptr) // 条件求值为真，因为ptr不是空指针
        std::cout << *ptr; // 未定义行为

    return 0;
}

指针具有额外的能力：可以改变指向的对象，以及可以指向空。然而，这些指针能力本身也是危险的：空指针存在被解引用的风险，而改变指针指向的能力可能更容易创建悬空指针：

由于引用不能绑定到空，我们不必担心空引用。而且因为引用必须在创建时绑定到有效对象且之后不能重新绑定，悬空引用更难创建。

最佳实践

由于更安全，应优先使用引用而非指针，除非需要指针提供的额外能力。

除非需要指针提供的额外能力，否则优先使用引用而非指针。

问题 #3

为什么我们应该将不指向有效对象的指针设置为 'nullptr'？

显示答案

我们无法确定非空指针是有效还是悬垂，访问悬垂指针会导致未定义行为。因此，我们需要确保程序中没有任何悬垂指针。

如果我们确保所有指针要么指向有效对象，要么设置为 nullptr，那么我们可以使用条件判断来测试是否为空，以确保不会解引用空指针，并假设所有非空指针都指向有效对象。
