21.3 — 使用普通函数重载运算符

● 机器译文 课程 21.3 查看英文原文

在上一节课中，我们将 operator+ 重载为友元函数：

#include <iostream>
 
class Cents
{
private:
  int m_cents{};

public:
  Cents(int cents)
    : m_cents{ cents }
  {}

  // 使用友元函数实现 Cents + Cents
  friend Cents operator+(const Cents& c1, const Cents& c2);

  int getCents() const { return m_cents; }
};
 
// 注意：这个函数不是成员函数！
Cents operator+(const Cents& c1, const Cents& c2)
{
  // 使用 Cents 构造函数和 operator+(int, int)
  // 我们可以直接访问 m_cents，因为这是一个友元函数
  return { c1.m_cents + c2.m_cents };
}
 
int main()
{
  Cents cents1{ 6 };
  Cents cents2{ 8 };
  Cents centsSum{ cents1 + cents2 };
  std::cout << "I have " << centsSum.getCents() << " cents.\n";

  return 0;
}

使用友元函数重载运算符很方便，因为它可以直接访问操作类的内部成员。在上面的初始 Cents 示例中，我们的友元函数版本的 operator+ 直接访问了成员变量 m_cents。

但是，如果你不需要这种访问权限，你可以将重载的运算符写成普通函数。注意，上面的 Cents 类包含一个访问函数 (getCents())，它允许我们在不直接访问私有成员的情况下获取 m_cents。因此，我们可以将重载的 operator+ 写成非友元函数：

#include <iostream>

class Cents
{
private:
  int m_cents{};

public:
  Cents(int cents)
    : m_cents{ cents }
  {}

  int getCents() const { return m_cents; }
};

// 注意：此函数既不是成员函数也不是友元函数！
Cents operator+(const Cents& c1, const Cents& c2)
{
  // 使用 Cents 构造函数和 operator+(int, int)
  // 这里我们不需要直接访问私有成员
  return Cents{ c1.getCents() + c2.getCents() };
}

int main()
{
  Cents cents1{ 6 };
  Cents cents2{ 8 };
  Cents centsSum{ cents1 + cents2 };
  std::cout << "I have " << centsSum.getCents() << " cents.\n";

  return 0;
}

由于普通函数和友元函数的工作方式几乎相同（它们只是对私有成员的访问级别不同），我们通常不会区分它们。一个区别是，类内部的友元函数声明同时也充当了原型。对于普通函数版本，你需要提供自己的函数原型。

Cents.h：

#ifndef CENTS_H
#define CENTS_H

class Cents
{
private:
  int m_cents{};

public:
  Cents(int cents)
    : m_cents{ cents }
  {}
  
  int getCents() const { return m_cents; }
};

// 需要显式提供 operator+ 的原型，以便其他文件中使用 operator+ 的代码知道这个重载存在
Cents operator+(const Cents& c1, const Cents& c2);

#endif

Cents.cpp：

#include "Cents.h"

// 注意：此函数既不是成员函数也不是友元函数！
Cents operator+(const Cents& c1, const Cents& c2)
{
  // 使用 Cents 构造函数和 operator+(int, int)
  // 这里我们不需要直接访问私有成员
  return { c1.getCents() + c2.getCents() };
}

main.cpp:

#include "Cents.h"
#include <iostream>

int main()
{
  Cents cents1{ 6 };
  Cents cents2{ 8 };
  Cents centsSum{ cents1 + cents2 }; // 如果没有 Cents.h 中的原型，这将无法编译
  std::cout << "I have " << centsSum.getCents() << " cents.\n";

  return 0;
}

一般来说，如果可以通过现有的成员函数实现，应该优先使用普通函数而不是友元函数（接触类内部的函数越少越好）。但是，不要仅仅为了将运算符重载为普通函数而不是友元函数而添加额外的访问函数！

最佳实践

如果可能且无需添加额外函数，优先将运算符重载为普通函数而非友元函数。
