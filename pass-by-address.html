12.10 — 按地址传递

● 机器译文 课程 12.10 查看英文原文

在前面的课程中，我们介绍了两种向函数传递参数的方式：按值传递（2.4 -- 函数参数和实参简介）和按引用传递（12.5 -- 通过左值引用传递)。

下面是一个示例程序，展示了 std::string 对象按值传递和按引用传递的情况：

#include <iostream>
#include <string>

void printByValue(std::string val) // 函数参数是 str 的一个副本
{
    std::cout << val << '\n'; // 通过副本打印值
}

void printByReference(const std::string& ref) // 函数参数是一个绑定到 str 的引用
{
    std::cout << ref << '\n'; // 通过引用打印值
}

int main()
{
    std::string str{ "Hello, world!" };
    
    printByValue(str); // 按值传递 str，创建 str 的副本
    printByReference(str); // 按引用传递 str，不创建 str 的副本

    return 0;
}

当我们按值传递参数 str 时，函数参数 val 接收参数的副本。由于参数是实参的副本，对 val 所做的任何更改都是针对副本，而不是原始实参。

当我们按值传递参数 str 按引用传递时，引用参数 ref 绑定到实际实参。这避免了创建实参的副本。由于我们的引用参数是 const，我们不允许更改 ref。但如果 ref 是非 const 的，我们对 ref 所做的任何更改都会改变 str。

在这两种情况下，调用者都提供实际对象（str）作为函数调用的实参。

按地址传递

C++ 提供了第三种向函数传递值的方式，称为按地址传递。使用 按地址传递时，调用者不是提供对象，而是提供对象的 地址 （通过指针）。这个指针（持有对象的地址）被复制到被调用函数的指针参数中（该参数现在也持有对象的地址）。然后函数可以解引用该指针以访问其地址被传递的对象。

以下是上述程序的版本，添加了按地址传递的变体：

#include <iostream>
#include <string>

void printByValue(std::string val) // 函数参数是 str 的一个副本
{
    std::cout << val << '\n'; // 通过副本打印值
}

void printByReference(const std::string& ref) // 函数参数是一个绑定到 str 的引用
{
    std::cout << ref << '\n'; // 通过引用打印值
}

void printByAddress(const std::string* ptr) // 函数参数是一个指针，保存 str 的地址
{
    std::cout << *ptr << '\n'; // 通过解引用指针打印值
}

int main()
{
    std::string str{ "Hello, world!" };
    
    printByValue(str); // 按值传递 str，创建 str 的副本
    printByReference(str); // 按引用传递 str，不创建 str 的副本
    printByAddress(&str); // 按地址传递 str，不创建 str 的副本

    return 0;
}

注意这三个版本有多么相似。让我们更详细地探讨按地址传递的版本。

首先，因为我们希望 printByAddress() 函数使用按地址传递，我们将函数参数设置为一个名为 ptr。因为 printByAddress() 将以只读方式使用 ptr ， ptr 是指向 const 值的指针。

void printByAddress(const std::string* ptr)
{
    std::cout << *ptr << '\n'; // 通过解引用指针打印值
}

在 printByAddress() 函数中，我们解引用 ptr 参数以访问所指向对象的值。

其次，当函数被调用时，我们不能只传入 str 对象——我们需要传入 str的地址。最简单的方法是使用取地址运算符 (&) 获取一个持有 str：

printByAddress(&str); // 使用取地址运算符 (&) 获取保存 str 地址的指针

地址的指针。当这个调用被执行时， &str 将创建一个持有 str地址的指针。然后这个地址作为函数调用的一部分被复制到函数参数 ptr 中。因为 ptr 现在持有 str的地址，当函数解引用 ptr时，它将获得 str，函数将其打印到控制台。

就是这样。

尽管我们在上面的示例中使用了取地址运算符来获取 str的地址，但如果我们已经有一个指针变量保存了 str的地址，我们可以使用它：

int main()
{
    std::string str{ "Hello, world!" };
    
    printByValue(str); // 按值传递 str，创建 str 的副本
    printByReference(str); // 按引用传递 str，不创建 str 的副本
    printByAddress(&str); // 按地址传递 str，不创建 str 的副本

    std::string* ptr { &str }; // 定义一个指针变量，保存 str 的地址
    printByAddress(ptr); // 按地址传递 str，不创建 str 的副本    

    return 0;
}

术语

当我们使用 operator&将变量的地址作为参数传递时，我们说该变量是按地址传递的。

当我们有一个指针变量保存对象的地址，并将该指针作为参数传递给相同类型的参数时，我们说对象是按地址传递的，而指针是按值传递的。

按地址传递不会复制所指向的对象

考虑以下语句：

std::string str{ "Hello, world!" };
printByAddress(&str); // 使用取地址运算符 (&) 获取保存 str 地址的指针

正如我们在 12.5 -- 通过左值引用传递中提到的，复制一个 std::string 是昂贵的，所以这是我们想要避免的。当我们按地址传递一个 std::string 时，我们并没有复制实际的 std::string 对象——我们只是将指针（保存对象地址）从调用者复制到被调用函数。由于地址通常只有4或8字节，指针也只有4或8字节，因此复制指针总是很快的。

因此，就像按引用传递一样，按地址传递速度快，并且避免复制参数对象。

按地址传递允许函数修改参数的值

当我们按地址传递对象时，函数接收传递对象的地址，它可以通过解引用来访问。因为这是实际参数对象的地址（不是对象的副本），如果函数参数是指向非const的指针，函数可以通过指针参数修改参数：

#include <iostream>

void changeValue(int* ptr) // 注意：在此示例中，ptr 是指向非 const 的指针
{
    *ptr = 6; // 将值改为 6
}

int main()
{
    int x{ 5 };

    std::cout << "x = " << x << '\n';

    changeValue(&x); // 我们将 x 的地址传递给函数

    std::cout << "x = " << x << '\n';

    return 0;
}

这会打印：

x = 5
x = 6

如您所见，参数被修改，并且这种修改在 changeValue() 运行结束后仍然存在。

如果函数不应该修改传入的对象，则函数参数应设为指向const的指针：

void changeValue(const int* ptr) // 注意：ptr 现在是指向 const 的指针
{
    *ptr = 6; // 错误：无法更改 const 值
}

出于许多相同的原因，我们通常不会 const 常规（非指针、非引用）函数参数（在 5.1 -- 常量变量（命名常量）中讨论），我们通常也不会 const 指针函数参数。让我们提出两个断言：

  • 一个 const 关键字用于使指针函数参数成为const指针，其价值很小（因为它对调用者没有影响，主要作为指针不会改变的文档）。
  • 一个 const 关键字用于区分指向const的指针和可以修改传入对象的指向非const的指针，这一点很重要（因为调用者需要知道函数是否可能更改参数的值）。

如果我们只使用非const指针函数参数，那么所有使用 const 的情况都很重要。一旦我们开始使用 const 作为const指针函数参数，那么判断某个使用 const 是否重要就变得更加困难。更重要的是，这也使得指向非const的指针参数更难被注意到。例如：

void foo(const char* source, char* dest, int count);             // 使用非 const 指针时，所有 const 都很重要。
void foo(const char* const source, char* const dest, int count); // 使用 const 指针时，`dest` 是指向非 const 的指针这一事实可能会在大量无关的 const 中被忽略。

在前一种情况下，很容易看出 source 是指向const的指针，而 dest 是指向非const的指针。在后一种情况下，很难看出 dest 是一个指向非const的const指针，其指向的对象可以被函数修改！

最佳实践

优先使用指向const的指针函数参数，而不是指向非const的指针函数参数，除非函数需要修改传入的对象。
除非有特定原因，否则不要将函数参数设为const指针。

空指针检查

现在考虑这个看起来相当无害的程序：

#include <iostream>

void print(int* ptr)
{
	std::cout << *ptr << '\n';
}

int main()
{
	int x{ 5 };
	print(&x);

	int* myPtr {};
	print(myPtr);

	return 0;
}

当此程序运行时，它将打印该值 5 然后很可能会崩溃。

在调用 print(myPtr)， myPtr 是一个空指针，因此函数参数 ptr 也将是一个空指针。当在函数体内解引用这个空指针时，会导致未定义行为。

通过地址传递参数时，在解引用值之前应确保指针不是空指针。一种方法是使用条件语句：

#include <iostream>

void print(int* ptr)
{
    if (ptr) // 如果 ptr 不是空指针
    {
        std::cout << *ptr << '\n';
    }
}

int main()
{
	int x{ 5 };
	
	print(&x);
	print(nullptr);

	return 0;
}

在上面的程序中，我们在解引用之前检查 ptr 以确保它不是空指针。虽然这对于如此简单的函数来说没问题，但在更复杂的函数中，这可能导致冗余逻辑（多次检查 ptr 是否非空）或函数主要逻辑的嵌套（如果包含在块中）。

在大多数情况下，更有效的方法是反过来：将函数参数是否为 null 作为前置条件进行测试（9.6 -- Assert 和 static_assert）并立即处理否定情况：

#include <iostream>

void print(int* ptr)
{
    if (!ptr) // 如果 ptr 是空指针，则提前返回给调用者
        return;

    // 如果执行到此处，我们可以假设 ptr 是有效的
    // 因此无需更多测试或嵌套

    std::cout << *ptr << '\n';
}

int main()
{
	int x{ 5 };
	
	print(&x);
	print(nullptr);

	return 0;
}

如果永远不应该向函数传递空指针，则可以使用 assert （我们在第 9.6 -- Assert 和 static_assert课中介绍过）来代替（或同时使用）（因为断言旨在记录永远不应该发生的事情）：

#include <iostream>
#include <cassert>

void print(const int* ptr) // 现在是一个指向 const int 的指针
{
	assert(ptr); // 在调试模式下，如果传入空指针则终止程序（因为这种情况不应发生）

	// （可选）在生产模式下将其作为错误情况处理，以便在确实发生时不会崩溃
	if (!ptr)
		return;

	std::cout << *ptr << '\n';
}

int main()
{
	int x{ 5 };
	
	print(&x);
	print(nullptr);

	return 0;
}

优先使用按（const）引用传递

请注意，上面示例中的函数 print() 并不能很好地处理空值——它实际上只是中止了函数。既然如此，为什么还要允许用户传入空值呢？按引用传递具有与按地址传递相同的优点，而没有意外解引用空指针的风险。

按 const 引用传递相比按地址传递还有其他一些优点。

首先，因为通过地址传递的对象必须有地址，所以只有左值可以通过地址传递（因为右值没有地址）。按 const 引用传递更灵活，因为它可以接受左值和右值：

#include <iostream>

void printByValue(int val) // 函数参数是实参的一个副本
{
    std::cout << val << '\n'; // 通过副本打印值
}

void printByReference(const int& ref) // 函数参数是一个绑定到实参的引用
{
    std::cout << ref << '\n'; // 通过引用打印值
}

void printByAddress(const int* ptr) // 函数参数是一个保存实参地址的指针
{
    std::cout << *ptr << '\n'; // 通过解引用指针打印值
}

int main()
{
    printByValue(5);     // 有效（但会进行复制）
    printByReference(5); // 有效（因为参数是 const 引用）
    printByAddress(&5);  // 错误：无法获取右值的地址

    return 0;
}

其次，按引用传递的语法很自然，我们可以直接传入字面量或对象。而按地址传递时，我们的代码中会充斥着取地址符（&）和星号（*）。

在现代 C++ 中，大多数可以通过按地址传递完成的事情都可以通过其他方法更好地完成。遵循这条常见准则：“能按引用传递时就按引用传递，必须按地址传递时才按地址传递”。

最佳实践

除非有特定原因需要使用按地址传递，否则优先使用按引用传递而非按地址传递。
