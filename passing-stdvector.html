16.4 — 传递 std::vector

● 机器译文 课程 16.4 查看英文原文

类型为 std::vector 的对象可以像任何其他对象一样传递给函数。这意味着如果我们按值传递 std::vector ，将会产生昂贵的拷贝。因此，我们通常通过（const）引用传递 std::vector 以避免这种拷贝。

对于 std::vector，元素类型是对象类型信息的一部分。因此，当我们使用 std::vector 作为函数参数时，必须显式指定元素类型：

#include <iostream>
#include <vector>

void passByRef(const std::vector<int>& arr) // 我们必须在此处显式指定 <int>
{
    std::cout << arr[0] << '\n';
}

int main()
{
    std::vector primes{ 2, 3, 5, 7, 11 };
    passByRef(primes);

    return 0;
}

传递 std::vector 不同元素类型的

因为我们的 passByRef() 函数期望一个 std::vector<int>，我们无法传递具有不同元素类型的向量：

#include <iostream>
#include <vector>

void passByRef(const std::vector<int>& arr)
{
    std::cout << arr[0] << '\n';
}

int main()
{
    std::vector primes{ 2, 3, 5, 7, 11 };
    passByRef(primes);  // ok: 这是一个 std::vector<int>

    std::vector dbl{ 1.1, 2.2, 3.3 };
    passByRef(dbl); // 编译错误: std::vector<double> 不能转换为 std::vector<int>

    return 0;
}

在 C++17 或更新版本中，你可能尝试使用 CTAD 来解决这个问题：

#include <iostream>
#include <vector>

void passByRef(const std::vector& arr) // 编译错误: CTAD 不能用于推断函数参数
{
    std::cout << arr[0] << '\n';
}

int main()
{
    std::vector primes{ 2, 3, 5, 7, 11 }; // ok: 使用 CTAD 推断 std::vector<int>
    passByRef(primes);

    return 0;
}

虽然 CTAD 可以在定义时从初始化器中推导出向量的元素类型，但 CTAD 目前不适用于函数参数。

我们之前见过这类问题，即重载函数仅因参数类型不同而不同。这是使用函数模板的好地方！我们可以创建一个参数化元素类型的函数模板，然后 C++ 将使用该函数模板实例化具有实际类型的函数。

相关内容

我们在课程 11.6 -- 函数模板。

我们可以创建一个使用相同模板参数声明的函数模板：

#include <iostream>
#include <vector>

template <typename T>
void passByRef(const std::vector<T>& arr)
{
    std::cout << arr[0] << '\n';
}

int main()
{
    std::vector primes{ 2, 3, 5, 7, 11 };
    passByRef(primes); // ok: 编译器将实例化 passByRef(const std::vector<int>&)

    std::vector dbl{ 1.1, 2.2, 3.3 };
    passByRef(dbl);    // ok: 编译器将实例化 passByRef(const std::vector<double>&)

    return 0;
}

在上面的例子中，我们创建了一个名为 passByRef() 的函数模板，其参数类型为 const std::vector<T>&。 T 在前一行的模板参数声明中定义： template <typename T。 T 是一个标准类型模板参数，允许调用者指定元素类型。

因此，当我们调用 passByRef(primes) 从 main() （其中 primes 被定义为 std::vector<int>），编译器将实例化并调用 void passByRef(const std::vector<int>& arr)。

当我们调用 passByRef(dbl) 从 main() （其中 dbl 被定义为 std::vector<double>），编译器将实例化并调用 void passByRef(const std::vector<double>& arr)。

因此，我们创建了一个单一的函数模板，它可以实例化函数来处理 std::vector 任何元素类型和长度的参数！

传递 std::vector 使用泛型模板或缩写函数模板

我们也可以创建一个接受任何类型对象的函数模板：

#include <iostream>
#include <vector>

template <typename T>
void passByRef(const T& arr) // 将接受任何具有重载 operator[] 的对象类型
{
    std::cout << arr[0] << '\n';
}

int main()
{
    std::vector primes{ 2, 3, 5, 7, 11 };
    passByRef(primes); // ok: 编译器将实例化 passByRef(const std::vector<int>&)

    std::vector dbl{ 1.1, 2.2, 3.3 };
    passByRef(dbl);    // ok: 编译器将实例化 passByRef(const std::vector<double>&)

    return 0;
}

在 C++20 中，我们可以使用缩写函数模板（通过 auto 参数）来做同样的事情：

#include <iostream>
#include <vector>

void passByRef(const auto& arr) // 简写函数模板
{
    std::cout << arr[0] << '\n';
}

int main()
{
    std::vector primes{ 2, 3, 5, 7, 11 };
    passByRef(primes); // ok: 编译器将实例化 passByRef(const std::vector<int>&)

    std::vector dbl{ 1.1, 2.2, 3.3 };
    passByRef(dbl);    // ok: 编译器将实例化 passByRef(const std::vector<double>&)

    return 0;
}

这两种方法都会接受一个 任何 类型的参数，只要它能编译通过。这在编写可能不仅仅操作 std::vector的函数时非常有用。例如，上述函数也可以用于 std::array、 std::string，或者其他我们甚至没有考虑过的类型。

这种方法的潜在缺点是，如果传递给函数的对象类型能编译通过但在语义上没有意义，可能会导致错误。

断言数组长度

考虑以下模板函数，它与上面展示的类似：

#include <iostream>
#include <vector>

template <typename T>
void printElement3(const std::vector<T>& arr)
{
    std::cout << arr[3] << '\n';
}

int main()
{
    std::vector arr{ 9, 7, 5, 3, 1 };
    printElement3(arr);

    return 0;
}

虽然 printElement3(arr) 在这种情况下工作正常，但程序中存在一个粗心的程序员可能遇到的潜在错误。看到了吗？

上面的程序打印了索引为 3 的数组元素的值。只要数组有一个有效的索引为 3 的元素，这就没问题。然而，编译器会愉快地允许你传入索引 3 越界的数组。例如：

#include <iostream>
#include <vector>

template <typename T>
void printElement3(const std::vector<T>& arr)
{
    std::cout << arr[3] << '\n';
}

int main()
{
    std::vector arr{ 9, 7 }; // 一个包含2个元素的数组（有效索引0和1）
    printElement3(arr);

    return 0;
}

这会导致未定义行为。

一种选择是在 arr.size()上使用断言，这样在调试构建配置中运行时就能捕获此类错误。由于 std::vector::size() 不是 constexpr 函数，我们只能在这里进行运行时断言。

提示

更好的选择是避免在需要对数组长度进行断言的情况下使用 std::vector使用支持 constexpr 数组的类型（例如 std::array）可能是更好的选择，因为你可以对 constexpr 数组的长度进行 static_assert 我们将在后续课程 17.3 -- 传递和返回 std::array。

中介绍这一点。最好的选择是避免编写依赖用户传入具有最小长度的 vector 的函数。

小测验时间

问题 #1

编写一个接受两个参数的函数：一个 std::vector 和一个索引。如果索引越界，打印错误。如果索引在范围内，打印该元素的值。

以下示例程序应该可以编译：

#include <iostream>
#include <vector>

// 在此处编写你的 printElement 函数

int main()
{
    std::vector v1 { 0, 1, 2, 3, 4 };
    printElement(v1, 2);
    printElement(v1, 5);

    std::vector v2 { 1.1, 2.2, 3.3 };
    printElement(v2, 0);
    printElement(v2, -1);

    return 0;
}

并产生以下结果：

The element has value 2
Invalid index
The element has value 1.1
Invalid index

显示答案

#include <iostream>
#include <vector>

// 索引需要是 int 类型，而不是 std::size_t，否则我们将无法检测用户是否传入了负索引
template <typename T>
void printElement(const std::vector<T>& arr, int index)
{
    if (index < 0 || index >= static_cast<int>(arr.size())) // 在 C++20 中，可以使用 std::ssize(arr) 来避免强制转换
        std::cout << "Invalid index\n";
    else
        std::cout << "The element has value " << arr[static_cast<std::size_t>(index)] << '\n';  
}

int main()
{
    std::vector v1 { 0, 1, 2, 3, 4 };
    printElement(v1, 2);
    printElement(v1, 5);

    std::vector v2 { 1.1, 2.2, 3.3 };
    printElement(v2, 0);
    printElement(v2, -1);

    return 0;
}
