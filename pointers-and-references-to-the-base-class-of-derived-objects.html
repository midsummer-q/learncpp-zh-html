25.1 — 指向派生类对象的基类指针和引用

● 机器译文 课程 25.1 查看英文原文

在上一章中，你学习了如何使用继承从现有类派生新类。在本章中，我们将重点讨论继承中最重要和最强大的方面之一——虚函数。

但在讨论虚函数是什么之前，让我们先铺垫一下为什么需要它们。

在关于 派生类的构造一章中，你了解到当你创建一个派生类时，它由多个部分组成：每个继承类一个部分，以及自身的一个部分。

例如，这里有一个简单的例子：

#include <string_view>

class Base
{
protected:
    int m_value {};

public:
    Base(int value)
        : m_value{ value }
    {
    }

    std::string_view getName() const { return "Base"; }
    int getValue() const { return m_value; }
};

class Derived: public Base
{
public:
    Derived(int value)
        : Base{ value }
    {
    }

    std::string_view getName() const { return "Derived"; }
    int getValueDoubled() const { return m_value * 2; }
};

当我们创建一个 Derived 对象时，它包含一个 Base 部分（首先构造）和一个 Derived 部分（其次构造）。记住，继承意味着两个类之间的 is-a 关系。由于 Derived 是一种 Base，因此 Derived 包含一个 Base 部分是合适的。

指针、引用和派生类

很直观，我们可以将 Derived 指针和引用设置为 Derived 对象：

#include <iostream>

int main()
{
    Derived derived{ 5 };
    std::cout << "derived is a " << derived.getName() << " and has value " << derived.getValue() << '\n';

    Derived& rDerived{ derived };
    std::cout << "rDerived is a " << rDerived.getName() << " and has value " << rDerived.getValue() << '\n';

    Derived* pDerived{ &derived };
    std::cout << "pDerived is a " << pDerived->getName() << " and has value " << pDerived->getValue() << '\n';

    return 0;
}

这将产生以下输出：

derived is a Derived and has value 5
rDerived is a Derived and has value 5
pDerived is a Derived and has value 5

然而，由于 Derived 有一个 Base 部分，一个更有趣的问题是 C++ 是否允许我们将 Base 指针或引用设置为 Derived 对象。事实证明，我们可以！

#include <iostream>

int main()
{
    Derived derived{ 5 };

    // // 这两种都是合法的！
    Base& rBase{ derived }; // // rBase 是左值引用（不是右值引用）
    Base* pBase{ &derived };

    std::cout << "derived is a " << derived.getName() << " and has value " << derived.getValue() << '\n';
    std::cout << "rBase is a " << rBase.getName() << " and has value " << rBase.getValue() << '\n';
    std::cout << "pBase is a " << pBase->getName() << " and has value " << pBase->getValue() << '\n';

    return 0;
}

这会产生以下结果：

derived is a Derived and has value 5
rBase is a Base and has value 5
pBase is a Base and has value 5

这个结果可能一开始并不完全是你所期望的！

事实证明，因为 rBase 和 pBase 是 Base 引用和指针，它们只能看到 Base 的成员（或任何 Base 继承的类）。因此，即使 Derived::getName() 为 Derived 对象遮蔽（隐藏）了 Base::getName()，Base 指针/引用也无法看到 Derived::getName()。因此，它们调用 Base::getName()，这就是为什么 rBase 和 pBase 报告它们是 Base 而不是 Derived。

注意，这也意味着无法使用 rBase 或 pBase 调用 Derived::getValueDoubled()。它们无法看到 Derived 中的任何内容。

这是另一个稍微复杂一点的例子，我们将在下一课中继续使用：

#include <iostream>
#include <string_view>
#include <string>

class Animal
{
protected:
    std::string m_name;

    // // 我们将此构造函数设为 protected，因为
    // // 我们不希望人们直接创建 Animal 对象，
    // // 但我们仍然希望派生类能够使用它。
    Animal(std::string_view name)
        : m_name{ name }
    {
    }
    
    // // 为了防止切片（稍后介绍）
    Animal(const Animal&) = delete;
    Animal& operator=(const Animal&) = delete;

public:
    std::string_view getName() const { return m_name; }
    std::string_view speak() const { return "???"; }
};

class Cat: public Animal
{
public:
    Cat(std::string_view name)
        : Animal{ name }
    {
    }

    std::string_view speak() const { return "Meow"; }
};

class Dog: public Animal
{
public:
    Dog(std::string_view name)
        : Animal{ name }
    {
    }

    std::string_view speak() const { return "Woof"; }
};

int main()
{
    const Cat cat{ "Fred" };
    std::cout << "cat is named " << cat.getName() << ", and it says " << cat.speak() << '\n';

    const Dog dog{ "Garbo" };
    std::cout << "dog is named " << dog.getName() << ", and it says " << dog.speak() << '\n';

    const Animal* pAnimal{ &cat };
    std::cout << "pAnimal is named " << pAnimal->getName() << ", and it says " << pAnimal->speak() << '\n';

    pAnimal = &dog;
    std::cout << "pAnimal is named " << pAnimal->getName() << ", and it says " << pAnimal->speak() << '\n';

    return 0;
}

这会产生以下结果：

cat is named Fred, and it says Meow
dog is named Garbo, and it says Woof
pAnimal is named Fred, and it says ???
pAnimal is named Garbo, and it says ???

我们在这里看到了同样的问题。因为 pAnimal 是一个 Animal 指针，它只能看到类的 Animal 部分。因此， pAnimal->speak() 调用的是 Animal::speak() 而不是 Dog::Speak() 或 Cat::speak() 函数。

指向基类的指针和引用的用途

现在你可能会说：“上面的例子看起来有点傻。为什么我要将指针或引用设置为派生对象的基类，而我可以直接使用派生对象呢？”事实证明，有很多充分的理由。

首先，假设你想编写一个打印动物名称和声音的函数。如果不使用指向基类的指针，你必须使用重载函数来编写，像这样：

void report(const Cat& cat)
{
    std::cout << cat.getName() << " says " << cat.speak() << '\n';
}

void report(const Dog& dog)
{
    std::cout << dog.getName() << " says " << dog.speak() << '\n';
}

这并不太难，但考虑一下如果我们有 30 种不同的动物类型而不是 2 种会发生什么。你必须编写 30 个几乎相同的函数！此外，如果你添加了一种新的动物类型，你还必须为它编写一个新函数。考虑到唯一的真正区别是参数的类型，这非常浪费时间。

然而，因为 Cat 和 Dog 是从 Animal 派生的，Cat 和 Dog 有一个 Animal 部分。因此，我们应该能够做这样的事情：

void report(const Animal& rAnimal)
{
    std::cout << rAnimal.getName() << " says " << rAnimal.speak() << '\n';
}

这将允许我们传入任何从 Animal 派生的类，甚至是我们编写函数之后创建的类！每个派生类一个函数，我们得到一个适用于所有从 Animal 派生的类的函数！

当然，问题是，因为 rAnimal 是一个 Animal 引用， rAnimal.speak() 将调用 Animal::speak() 而不是派生版本的 speak()。

顺便说一句……

我们也可以使用模板函数来减少需要编写的重载函数数量：

template <typename T>
void report(const T& rAnimal)
{
    std::cout << rAnimal.getName() << " says " << rAnimal.speak() << '\n';
}

虽然这有效，但它有自己的问题：

  1. 不清楚类型 T 应该是什么，因为我们丢失了 T 旨在成为 Animal。
  2. 的文档。 T 是一个 Animal。相反，它将接受任何包含 getName() 和 speak() 成员函数的类型的对象，无论是否有意义。

其次，假设你有 3 只猫和 3 只狗，你想将它们放在一个数组中以便于访问。因为数组只能保存一种类型的对象，如果没有指向基类的指针或引用，你必须为每个派生类型创建一个不同的数组，像这样：

#include <array>
#include <iostream>

// // 来自上面示例的 Cat 和 Dog

int main()
{
    const auto& cats{ std::to_array<Cat>({{ "Fred" }, { "Misty" }, { "Zeke" }}) };
    const auto& dogs{ std::to_array<Dog>({{ "Garbo" }, { "Pooky" }, { "Truffle" }}) };
    
    // C++20 之前
    // // const std::array<Cat, 3> cats{{ { "Fred" }, { "Misty" }, { "Zeke" } }};
    // // const std::array<Dog, 3> dogs{{ { "Garbo" }, { "Pooky" }, { "Truffle" } }};

    for (const auto& cat : cats)
    {
        std::cout << cat.getName() << " says " << cat.speak() << '\n';
    }

    for (const auto& dog : dogs)
    {
        std::cout << dog.getName() << " says " << dog.speak() << '\n';
    }

    return 0;
}

现在，考虑一下如果你有 30 种不同类型的动物会发生什么。你需要 30 个数组，每种动物一个！

然而，因为 Cat 和 Dog 都是从 Animal 派生的，我们应该能够做这样的事情：

#include <array>
#include <iostream>

// // 来自上面示例的 Cat 和 Dog

int main()
{
    const Cat fred{ "Fred" };
    const Cat misty{ "Misty" };
    const Cat zeke{ "Zeke" };

    const Dog garbo{ "Garbo" };
    const Dog pooky{ "Pooky" };
    const Dog truffle{ "Truffle" };

    // // 设置一个指向动物的指针数组，并将这些指针指向我们的 Cat 和 Dog 对象
    const auto animals{ std::to_array<const Animal*>({&fred, &garbo, &misty, &pooky, &truffle, &zeke }) };
    
    // // 在 C++20 之前，显式指定数组大小
    // // const std::array<const Animal*, 6> animals{ &fred, &garbo, &misty, &pooky, &truffle, &zeke };
    
    for (const auto animal : animals)
    {
        std::cout << animal->getName() << " says " << animal->speak() << '\n';
    }

    return 0;
}

虽然这可以编译和执行，但不幸的是，数组“animals”的每个元素都是指向 Animal 的指针，这意味着 animal->speak() 将调用 Animal::speak() 而不是我们想要的派生类版本的 speak()。输出是

Fred says ???
Garbo says ???
Misty says ???
Pooky says ???
Truffle says ???
Zeke says ???

尽管这两种技术都可以节省我们大量的时间和精力，但它们都有同样的问题。指向基类的指针或引用调用函数的基类版本而不是派生版本。如果有什么方法可以让这些基类指针调用派生版本的函数而不是基类版本就好了……

小测验时间

  1. 上面的 Animal/Cat/Dog 示例没有按我们期望的方式工作，因为指向 Animal 的引用或指针无法访问派生版本的 speak() 来返回 Cat 或 Dog 的正确值。解决这个问题的一种方法是让 speak() 函数返回的数据作为 Animal 基类的一部分可访问（就像 Animal 的名字通过成员 m_name 可访问一样）。

更新上面课程中的 Animal、Cat 和 Dog 类，向 Animal 添加一个名为 m_speak 的新成员。适当地初始化它。以下程序应该能正常工作：

#include <array>
#include <iostream>

int main()
{
    const Cat fred{ "Fred" };
    const Cat misty{ "Misty" };
    const Cat zeke{ "Zeke" };

    const Dog garbo{ "Garbo" };
    const Dog pooky{ "Pooky" };
    const Dog truffle{ "Truffle" };

    // // 设置一个指向动物的指针数组，并将这些指针指向我们的 Cat 和 Dog 对象
    const auto animals{ std::to_array<const Animal*>({ &fred, &garbo, &misty, &pooky, &truffle, &zeke }) };
    
    // // 在 C++20 之前，显式指定数组大小
    // // const std::array<const Animal*, 6> animals{ &fred, &garbo, &misty, &pooky, &truffle, &zeke };
    
    for (const auto animal : animals)
    {
        std::cout << animal->getName() << " says " << animal->speak() << '\n';
    }

    return 0;
}

显示答案

#include <array>
#include <string>
#include <string_view>
#include <iostream>

class Animal
{
protected:
    std::string m_name;
    std::string m_speak;

    // // 我们将此构造函数设为 protected，因为
    // // 我们不希望人们直接创建 Animal 对象，
    // // 但我们仍然希望派生类能够使用它。
    Animal(std::string_view name, std::string_view speak)
        : m_name{ name }, m_speak{ speak }
    {
    }
    
    // // 为了防止切片（稍后介绍）
    Animal(const Animal&) = delete;
    Animal& operator=(const Animal&) = delete;

public:
    std::string_view getName() const { return m_name; }
    std::string_view speak() const { return m_speak; }
};

class Cat: public Animal
{
public:
    Cat(std::string_view name)
        : Animal{ name, "Meow" }
    {
    }
};

class Dog: public Animal
{
public:
    Dog(std::string_view name)
        : Animal{ name, "Woof" }
    {
    }
};

int main()
{
    const Cat fred{ "Fred" };
    const Cat misty{ "Misty" };
    const Cat zeke{ "Zeke" };

    const Dog garbo{ "Garbo" };
    const Dog pooky{ "Pooky" };
    const Dog truffle{ "Truffle" };

    // // 设置一个指向动物的指针数组，并将这些指针指向我们的 Cat 和 Dog 对象
    const auto animals{ std::to_array<const Animal*>({ &fred, &garbo, &misty, &pooky, &truffle, &zeke }) };
    
    // // 在 C++20 之前，显式指定数组大小
    // // const std::array<const Animal*, 6> animals{ &fred, &garbo, &misty, &pooky, &truffle, &zeke };
    
    // // animal 不是引用，因为我们遍历的是指针
    for (const auto animal : animals)
    {
        std::cout << animal->getName() << " says " << animal->speak() << '\n';
    }

    return 0;
}
  1. 为什么上述解决方案不是最优的？

提示：思考 Cat 和 Dog 的未来状态，我们希望在更多方面区分 Cat 和 Dog。
提示：思考在初始化时需要设置成员的方式会如何限制你。

显示答案

当前的解决方案由于多种原因不是最优的。

首先，我们需要为每种区分 Cat 和 Dog 的方式向 Animal 添加一个成员。随着时间的推移，我们的 Animal 类可能会变得内存占用很大且复杂！

其次，这个解决方案仅在基类成员可以在初始化时确定的情况下有效。例如，如果 speak() 为每个 Animal 返回随机结果（例如，调用 Dog::speak() 可能返回 "woof"、"arf" 或 "yip"），这种解决方案就会变得笨拙且失效。

第三，因为 speak() 是 Animal 的成员，speak() 对 Cat 和 Dog 的行为相同（即，它总是返回 m_speak）。如果我们想要 speak() 让 Cat 和 Dog 有不同的行为（例如，让 Dog 返回随机声音），我们就必须将所有额外的逻辑放在 Animal 中，这使得 Animal 更加复杂。
