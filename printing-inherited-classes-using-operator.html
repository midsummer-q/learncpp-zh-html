25.11 — 使用 operator<< 打印继承类

● 机器译文 课程 25.11 查看英文原文

考虑以下使用虚函数的程序：

#include <iostream>

class Base
{
public:
	virtual void print() const { std::cout << "Base";  }
};

class Derived : public Base
{
public:
	void print() const override { std::cout << "Derived"; }
};

int main()
{
	Derived d{};
	Base& b{ d };
	b.print(); // 将调用 Derived::print()

	return 0;
}

到现在，你应该已经熟悉这样一个事实：b.print() 会调用 Derived::print()（因为 b 引用了一个 Derived 类对象，Base::print() 是虚函数，而 Derived::print() 是覆盖版本）。

虽然像这样调用成员函数进行输出是可以的，但这种函数风格与 std::cout 配合得并不好：

#include <iostream>

int main()
{
	Derived d{};
	Base& b{ d };

	std::cout << "b is a ";
	b.print(); // 混乱，我们必须中断打印语句来调用这个函数
	std::cout << '\n';

	return 0;
}

在本节课中，我们将探讨如何为使用继承的类重写 operator<<，以便能够像预期那样使用 operator<<，例如：

std::cout << "b is a " << b << '\n'; // 好多了

operator<< 的挑战

让我们从以典型方式重载 operator<< 开始：

#include <iostream>

class Base
{
public:
	virtual void print() const { std::cout << "Base"; }

	friend std::ostream& operator<<(std::ostream& out, const Base& b)
	{
		out << "Base";
		return out;
	}
};

class Derived : public Base
{
public:
	void print() const override { std::cout << "Derived"; }

	friend std::ostream& operator<<(std::ostream& out, const Derived& d)
	{
		out << "Derived";
		return out;
	}
};

int main()
{
	Base b{};
	std::cout << b << '\n';

	Derived d{};
	std::cout << d << '\n';

	return 0;
}

由于这里不需要虚函数解析，程序按预期工作，并打印：

Base
Derived

现在，考虑以下 main() 函数：

int main()
{
    Derived d{};
    Base& bref{ d };
    std::cout << bref << '\n';
    
    return 0;
}

该程序打印出：

Base

这可能不是我们期望的结果。这是因为我们处理 Base 对象的 operator<< 版本不是虚函数，所以 std::cout << bref 调用的是处理 Base 对象的 operator<< 版本，而不是处理 Derived 对象的版本。

这就是挑战所在。

我们可以让 operator<< 成为虚函数吗？

如果问题在于 operator<< 不是虚函数，难道我们不能简单地让它成为虚函数吗？

简短的回答是不行。这有很多原因。

首先，只有成员函数可以被虚化——这很合理，因为只有类才能继承其他类，而且无法覆盖类外部的函数（可以重载非成员函数，但不能覆盖它们）。因为我们通常将 operator<< 实现为友元，而友元不被视为成员函数，所以友元版本的 operator<< 没有资格被虚化。（关于为什么这样实现 operator<< 的回顾，请重新学习课程 21.5 -- 使用成员函数重载运算符)。

其次，即使我们可以虚化 operator<<，还存在一个问题：Base::operator<< 和 Derived::operator<< 的函数参数不同（Base 版本接受 Base 参数，Derived 版本接受 Derived 参数）。因此，Derived 版本不会被视作 Base 版本的覆盖，从而没有资格进行虚函数解析。

那么程序员该怎么办呢？

一个解决方案

答案其实出奇地简单。

首先，我们像往常一样在基类中将 operator<< 设置为友元。但与其让 operator<< 决定打印什么，不如让它调用一个普通的成员函数，而该成员函数 可以 将被虚化！这个虚函数将负责确定每个类要打印的内容。

在第一个解决方案中，我们的虚成员函数（我们称之为 identify()）返回一个 std::string，由 Base::operator<<：

#include <iostream>

class Base
{
public:
	// 这是我们重载的 operator<<
	friend std::ostream& operator<<(std::ostream& out, const Base& b)
	{
		// 调用虚函数 identify() 获取要打印的字符串
		out << b.identify();
		return out;
	}

	// 我们将依赖成员函数 identify() 返回要打印的字符串
	// 因为 identify() 是一个普通成员函数，它可以被虚化
	virtual std::string identify() const
	{
		return "Base";
	}
};

class Derived : public Base
{
public:
	// 这是我们处理 Derived 情况的覆盖 identify() 函数
	std::string identify() const override
	{
		return "Derived";
	}
};

int main()
{
	Base b{};
	std::cout << b << '\n';

	Derived d{};
	std::cout << d << '\n'; // 注意，即使没有显式处理 Derived 对象的 operator<<，这也能工作

	Base& bref{ d };
	std::cout << bref << '\n';

	return 0;
}

打印。这打印出预期的结果：

Base
Derived
Derived

让我们更详细地研究一下这是如何工作的。

在 Base b， operator<< 被调用，参数 b 引用 Base 对象。虚函数调用 b.identify() 因此解析为 Base::identify()，返回“Base”以供打印。这里没什么特别的。

在 Derived d，编译器首先查找是否存在一个 operator<< 接受 Derived 对象。没有，因为我们没有定义。接下来编译器查找是否存在一个 operator<< 接受 Base 对象。有，所以编译器将我们的 Derived 对象隐式向上转换为 Base& 并调用该函数（我们本可以自己进行向上转换，但编译器在这方面很有帮助）。因为参数 b 引用了一个 Derived 对象，虚函数调用 b.identify() 解析为 Derived::identify()，返回“Derived”以供打印。

注意，我们不需要为每个派生类定义 operator<< ！处理 Base 对象的版本对于 Base 对象和任何从 Base 派生的类都同样适用！

第三种情况是前两种的混合。首先，编译器将变量 bref 与 operator<< 接受 Base 引用的版本匹配。因为参数 b 引用了一个 Derived 对象， b.identify() 解析为 Derived::identify()，它返回“Derived”。

问题解决。

更灵活的解决方案

上述解决方案效果很好，但有两个潜在的缺点：

  1. 它假设所需的输出可以表示为单个 std::string。
  2. 的对象时未提供显式初始化值，则将使用这些默认成员初始化值。我们的 identify() 成员函数无法访问流对象。

后者在需要流对象的情况下会带来问题，例如当我们想要打印具有重载 operator<< 的成员变量的值时。

幸运的是，我们可以轻松修改上述示例以解决这两个问题。在之前的版本中，虚函数 identify() 返回一个字符串，由 Base::operator<<打印。在这个版本中，我们将改为定义虚成员函数 print() 并将打印的责任委托 直接 给该函数。

下面是一个说明这个想法的例子：

#include <iostream>

class Base
{
public:
	// 这是我们重载的 operator<<
	friend std::ostream& operator<<(std::ostream& out, const Base& b)
	{
		// 将打印职责委托给虚成员函数 print()
		return b.print(out);
	}

	// 我们将依赖成员函数 print() 来执行实际的打印
	// 因为 print() 是一个普通的成员函数，它可以被虚化
	virtual std::ostream& print(std::ostream& out) const
	{
		out << "Base";
		return out;
	}
};

// 某个重载了 operator<< 的类或结构体
struct Employee
{
	std::string name{};
	int id{};

	friend std::ostream& operator<<(std::ostream& out, const Employee& e)
	{
		out << "Employee(" << e.name << ", " << e.id << ")";
		return out;
	}
};

class Derived : public Base
{
private:
	Employee m_e{}; // Derived 现在有一个 Employee 成员

public:
	Derived(const Employee& e)
		: m_e{ e }
	{
	}

	// 这是我们处理 Derived 情况的覆盖 print() 函数
	std::ostream& print(std::ostream& out) const override
	{
		out << "Derived: ";

		// 使用流对象打印 Employee 成员
		out << m_e;

		return out;
	}
};

int main()
{
	Base b{};
	std::cout << b << '\n';

	Derived d{ Employee{"Jim", 4}};
	std::cout << d << '\n'; // 注意，即使没有显式处理 Derived 对象的 operator<<，这也能工作

	Base& bref{ d };
	std::cout << bref << '\n';

	return 0;
}

这会输出：

Base
Derived: Employee(Jim, 4)
Derived: Employee(Jim, 4)

在这个版本中， Base::operator<< 本身不进行任何打印。相反，它只调用虚成员函数 print() 并将流对象传递给它。 print() 函数然后使用这个流对象进行自己的打印。 Base::print() 使用流对象打印“Base”。更有趣的是， Derived::print() 使用流对象打印“Derived: ”并调用 Employee::operator<< 来打印成员 m_e的值。后者在前一个例子中做起来会更困难！
