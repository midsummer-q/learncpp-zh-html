4.4 — 有符号整数

● 机器译文 课程 4.4 查看英文原文

一种 数 是一种整型，可以表示正负整数，包括0（例如-2，-1，0，1，2）。C++有 4 以下主要的基本整型可供使用：

类型最小尺寸备注
short int16位
整型16位在现代架构上通常为32位
long int32位
long long int64位

各种整型之间的关键区别在于它们的大小不同——较大的整型可以容纳更大的数字。

提醒

C++只保证整型具有特定的最小尺寸，而不保证它们具有特定的尺寸。请参阅课程 4.3 -- 对象大小和sizeof运算符 了解如何确定每种类型在您机器上的大小。

顺便说一句……

从技术上讲， bool 和 char 这些类型被认为是整型（因为这些类型将它们的值存储为整数值）。为了后续几节课的目的，我们将把这些类型排除在讨论之外。

有符号整数

在日常生活中写负数时，我们使用负号。例如， -3 表示“负3”。我们通常也会识别 +3 为“正3”（尽管通常惯例是我们省略加号前缀）。

这种为正、负或零的属性称为数字的 符号。

默认情况下，C++中的整型是 有符号这意味着数字的符号作为值的一部分存储。因此，有符号整数可以同时保存正数和负数（以及0）。

在本课中，我们将重点介绍有符号整数。我们将在下一课中讨论无符号整数（它只能保存非负数）。

定义有符号整数

以下是定义四种有符号整数的推荐方式：

short s;      // 优先使用 "short" 而非 "short int"
int i;
long l;       // 优先使用 "long" 而非 "long int"
long long ll; // 优先使用 "long long" 而非 "long long int"

尽管 short int， long int，或 long long int 可以工作，但我们更推荐使用这些类型的短名称（不使用 整型 后缀）。除了增加打字量之外，添加 整型 后缀会使该类型更难与类型变量区分开 整型。如果无意中遗漏了短或长修饰符，可能会导致错误。

整数类型还可以使用可选的 有符号 关键字，按照惯例通常放在类型名称之前：

signed short ss;
signed int si;
signed long sl;
signed long long sll;

但是，不应使用此关键字，因为它是多余的，因为整数默认是有符号的。

最佳实践

优先使用不使用 int 后缀或 signed 前缀的简写类型。

有符号整数范围

正如您在上一节中学到的，一个变量有 n 位可以保存2n 个可能的值。但具体是哪些值？我们将数据类型可以保存的特定值集合称为其 范围。整数变量的范围由两个因素决定：其大小（以位为单位）以及是否有符号。

例如，一个8位有符号整数的范围是-128到127。这意味着一个8位有符号整数可以安全地存储-128到127（包含）之间的任意整数值。

下表列出了不同大小的有符号整数的范围：

大小/类型范围
8位有符号-128 到 127
16位有符号-32,768 到 32,767
32位有符号-2,147,483,648 到 2,147,483,647
64位有符号-9,223,372,036,854,775,808 到 9,223,372,036,854,775,807

对于数学爱好者来说，一个n位有符号变量的范围是 -(2n-1) 到 (2n-1)-1.

对于非数学爱好者……请使用表格。:)

进阶读者

以上范围假设使用“二进制补码”表示。这种表示法是现代架构的事实标准（因为它更容易在硬件中实现），现在也是C++20标准所要求的。我们在课程 O.4 -- 在二进制和十进制表示之间转换整数。

中讨论二进制补码。在早期的标准中，由于历史原因，允许使用原码和反码表示。这样的表示产生的值范围为 -(2n-1-1) 到 +(2n-1-1).

溢出

如果我们尝试将一个值 140 赋值给一个8位有符号整数？这个数字超出了8位有符号整数能表示的范围。数字140需要9位来表示（8位数值位和1位符号位），但我们在8位有符号整数中只有8位可用（7位数值位和1位符号位）。

C++20标准做出了这样的概括性陈述：“如果在表达式求值过程中，结果在数学上没有定义，或者不在其类型可表示值的范围内，则行为是未定义的”。通俗地说，这被称为 溢出。

因此，将值140赋值给一个8位有符号整数将导致未定义行为。

如果一个算术运算（例如加法或乘法）试图创建一个超出可表示范围的值，则称为 整数溢出 （或 算术溢出)。对于有符号整数，整数溢出将导致未定义行为。

#include <iostream>

int main()
{
    // 假设为 4 字节整数
    int x { 2'147'483'647 }; // 4字节有符号整数的最大值
    std::cout << x << '\n';

    x = x + 1; // 整数溢出，未定义行为
    std::cout << x << '\n';

    return 0;
}

在作者的机器上，上述代码打印出了：

2147483647
-2147483648

然而，由于第二个输出是未定义行为的结果，输出的值可能在你的机器上有所不同。

进阶读者

我们在课程中介绍了无符号整数溢出时会发生什么 4.5 -- 无符号整数，以及为什么要避免使用它们。

通常，溢出会导致信息丢失，这几乎从来都不是我们所期望的。如果 任何 怀疑某个对象可能需要存储超出其范围的值，请使用一个更大范围的类型！

整数除法

当两个整数相除时，如果商是整数，C++的行为正如你所预期：

#include <iostream>

int main()
{
    std::cout << 20 / 4 << '\n';
    return 0;
}

这会输出预期的结果：

5

但让我们看看当整数除法产生小数结果时会发生什么：

#include <iostream>

int main()
{
    std::cout << 8 / 5 << '\n';
    return 0;
}

这会输出一个可能出乎意料的结果：

1

当使用两个整数进行除法运算时（称为 整数除法），C++ 总是产生整数结果。由于整数无法保存小数部分，任何小数部分都会被直接丢弃（不是四舍五入！）。

仔细看上面的例子，8 / 5 产生值 1.6。小数部分 (0.6) 被丢弃，剩下结果 1。或者，我们可以说 8 / 5 等于 1 余 3。余数被丢弃，剩下 1。

类似地，-8 / 5 的结果是 -1。

警告

使用整数除法时要小心，因为你会丢失商的所有小数部分。不过，如果你正是需要这样，整数除法是安全可用的，因为结果是可预测的。

如果需要小数结果，我们在课程中展示了实现方法 6.2 -- 算术运算符。

小测验时间

问题 #1

一个 5 位有符号整数的范围是多少？

显示答案

一个 5 位数可以支持 25 = 32 个唯一值。对于有符号整数，这些值几乎均匀地分布在正数和负数之间，负数多一个值。因此范围是 -16 到 15。

另一种思考方式：5 位中的 1 位用于表示符号。剩下 4 位用于数值部分。4 位可以提供 16 个唯一值。在负数一侧，这些数值位表示 -1 到 -16。在非负数一侧，这些数值位表示 0 到 15。非负数一侧范围少一个值是因为包含 0。

问题 #2

a) 13 / 5 的结果是多少？

显示答案

13 / 5 = 2 余 3。余数被丢弃，剩下 2。

b) -13 / 5 的结果是多少？

显示答案

-13 / 5 = -2 余 -3。余数被丢弃，剩下 -2。
