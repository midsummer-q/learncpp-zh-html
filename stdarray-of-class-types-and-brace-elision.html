17.4 — std::array 与类类型，以及花括号省略

● 机器译文 课程 17.4 查看英文原文

一个 std::array 并不局限于基本类型的元素。实际上， std::array 的元素可以是任何对象类型，包括复合类型。这意味着你可以创建一个 std::array 指针数组，或者一个 std::array 结构体（或类）数组。

然而，初始化一个 std::array 结构体或类数组往往会让新手程序员感到困惑，因此我们将专门用一节课来详细讲解这个主题。

作者注

在本课中，我们将使用结构体来阐述要点。这些内容同样适用于类。

定义和赋值一个 std::array 结构体数组

让我们从一个简单的结构体开始：

struct House
{
    int number{};
    int stories{};
    int roomsPerStory{};
};

定义一个 std::array 作为 House 和赋值元素的工作方式正如你所预期的那样：

#include <array>
#include <iostream>

struct House
{
    int number{};
    int stories{};
    int roomsPerStory{};
};

int main()
{
    std::array<House, 3> houses{};

    houses[0] = { 13, 1, 7 };
    houses[1] = { 14, 2, 5 };
    houses[2] = { 15, 2, 4 };

    for (const auto& house : houses)
    {
        std::cout << "House number " << house.number
                  << " has " << (house.stories * house.roomsPerStory)
                  << " rooms.\n";
    }

    return 0;
}

上述代码输出如下：

House number 13 has 7 rooms.
House number 14 has 10 rooms.
House number 15 has 8 rooms.

初始化一个 std::array 结构体数组

初始化结构体数组也如你所预期的那样工作，只要你明确指定元素类型：

#include <array>
#include <iostream>

struct House
{
    int number{};
    int stories{};
    int roomsPerStory{};
};

int main()
{
    constexpr std::array houses { // 使用 CTAD 推导模板参数 <House, 3>
            House{ 13, 1, 7 },
            House{ 14, 2, 5 },
            House{ 15, 2, 4 }
        };

    for (const auto& house : houses)
    {
        std::cout << "House number " << house.number
            << " has " << (house.stories * house.roomsPerStory)
            << " rooms.\n";
    }

    return 0;
}

在上面的例子中，我们使用 CTAD 来推导 std::array 为 std::array<House, 3>的类型。然后我们提供了 3 个 House 对象作为初始化器，这完全没问题。

不显式为每个初始化器指定元素类型的初始化

在上面的例子中，你会注意到每个初始化器都需要我们列出元素类型：

    constexpr std::array houses {
            House{ 13, 1, 7 }, // 我们在这里提到 House
            House{ 14, 2, 5 }, // 以及这里
            House{ 15, 2, 4 }  // 以及这里
        };

但在赋值的情况下，我们不需要这样做：

    // 编译器知道 houses 的每个元素都是 House
    // 所以它会隐式地将每个赋值的右侧转换为 House
    houses[0] = { 13, 1, 7 };
    houses[1] = { 14, 2, 5 };
    houses[2] = { 15, 2, 4 };

所以你可能会想尝试这样的写法：

    // 不起作用
    constexpr std::array<House, 3> houses { // 我们告诉编译器每个元素都是 House
            { 13, 1, 7 }, // 但这里没有提到它
            { 14, 2, 5 },
            { 15, 2, 4 } 
        };

也许令人惊讶的是，这并不起作用。让我们探讨一下原因。

一个 std::array 被定义为一个包含单个 C 风格数组成员（其名称由实现定义）的结构体，如下所示：

template<typename T, std::size_t N>
struct array
{
    T implementation_defined_name[N]; // 一个包含 N 个 T 类型元素的 C 风格数组
}

作者注

我们还没有介绍 C 风格数组，但就本课而言，你只需要知道 T implementation_defined_name[N]; 是一个包含 N 个 T 类型元素的固定大小数组（就像 std::array<T, N> implementation_defined_name;)。

一样）。我们将在接下来的课程中介绍 C 风格数组。 17.7 -- C风格数组简介。

所以当我们尝试按照上述方式初始化 houses 时，编译器会将初始化解释为：

// 不起作用
constexpr std::array<House, 3> houses { // houses 的初始化器
    { 13, 1, 7 }, // 具有 implementation_defined_name 的 C 风格数组成员的初始化器
    { 14, 2, 5 }, // ?
    { 15, 2, 4 }  // ?
};

编译器会将 { 13, 1, 7 } 解释为 houses第一个成员的初始化器，即具有实现定义名称的 C 风格数组。这将用 { 13, 1, 7 } 初始化 C 风格数组的元素 0，其余成员将被零初始化。然后编译器会发现我们提供了另外两个初始化值（{ 14, 2, 7 } 和 { 15, 2, 5 }），并产生一个编译错误，告诉我们提供了太多的初始化值。

正确初始化上述内容的方法是添加一组额外的花括号，如下所示：

// 这按预期工作
constexpr std::array<House, 3> houses { // houses 的初始化器
    { // 额外的一组花括号来初始化具有 implementation_defined_name 的 C 风格数组成员
        { 13, 4, 30 }, // 数组元素 0 的初始化器
        { 14, 3, 10 }, // 数组元素 1 的初始化器
        { 15, 3, 40 }, // 数组元素 2 的初始化器
     }
};

注意需要额外的一组花括号（以开始初始化 std::array 结构体内部的 C 风格数组成员）。在这些花括号内，我们可以单独初始化每个元素，每个元素都在自己的一组花括号内。

这就是为什么你会看到 std::array 初始化器在元素类型需要一组值并且我们没有在初始化器中显式提供元素类型时，会带有一组额外的花括号。

关键提示

当用元素值初始化一个 std::array 与结构体、类或数组一起使用，并且没有为每个初始化器提供元素类型时，你需要额外的一对花括号，以便编译器正确解释要初始化的内容。

这是聚合初始化的一个产物，其他标准库容器类型（使用列表构造函数）在这些情况下不需要双花括号。

我们的别名模板有一个巧妙之处：我们可以按任意顺序定义模板参数。由于

#include <array>
#include <iostream>

struct House
{
    int number{};
    int stories{};
    int roomsPerStory{};
};

int main()
{
    constexpr std::array<House, 3> houses {{ // 注意双花括号
        { 13, 1, 7 },
        { 14, 2, 5 },
        { 15, 2, 4 }
    }};

    for (const auto& house : houses)
    {
        std::cout << "House number " << house.number
                  << " has " << (house.stories * house.roomsPerStory)
                  << " rooms.\n";
    }

    return 0;
}

聚合体的花括号省略

根据上面的解释，你可能想知道为什么上面的情况需要双花括号，而我们见过的所有其他情况只需要单花括号：

#include <array>
#include <iostream>

int main()
{
    constexpr std::array<int, 5> arr { 1, 2, 3, 4, 5 }; // 单花括号

    for (const auto n : arr)
        std::cout << n << '\n';

    return 0;
}

事实证明，你可以为这样的数组提供双花括号：

#include <array>
#include <iostream>

int main()
{
    constexpr std::array<int, 5> arr {{ 1, 2, 3, 4, 5 }}; // 双花括号

    for (const auto n : arr)
        std::cout << n << '\n';

    return 0;
}

然而，C++ 中的聚合体支持一个称为 大括号省略的概念，它规定了一些何时可以省略多个大括号的规则。通常，当用标量（单个）值初始化 std::array 时，或者当用每个元素显式命名类型的类类型或数组初始化时，可以省略大括号。

始终使用双花括号初始化 std::array 没有坏处，因为它避免了需要考虑花括号省略是否适用于特定情况。或者，你可以尝试单花括号初始化，如果编译器无法解决，通常会报错。在这种情况下，你可以快速添加一组额外的花括号。

另一个示例

这里还有一个例子，我们初始化一个 std::array 替换为 Student 结构体。

#include <array>
#include <iostream>
#include <string_view>

// 每个学生有一个 id 和一个 name
struct Student
{
	int id{};
	std::string_view name{};
};

// 我们的 3 个学生的数组（单花括号，因为我们在每个初始化器中提到了 Student）
constexpr std::array students{ Student{0, "Alex"}, Student{ 1, "Joe" }, Student{ 2, "Bob" } };

const Student* findStudentById(int id)
{
	// 遍历所有学生
	for (auto& s : students)
	{
		// 返回匹配id的学生
		if (s.id == id) return &s;
	}

	// 未找到匹配的id
	return nullptr;
}

int main()
{
	constexpr std::string_view nobody { "nobody" };

	const Student* s1 { findStudentById(1) };
	std::cout << "You found: " << (s1 ? s1->name : nobody) << '\n';

	const Student* s2 { findStudentById(3) };
	std::cout << "You found: " << (s2 ? s2->name : nobody) << '\n';

	return 0;
}

这会打印：

You found: Joe
You found: nobody

注意，因为 std::array students 是 constexpr，我们的 findStudentById() 函数必须返回一个 const 指针，这意味着我们的 Student 指针在 main() 中也必须是 const。

小测验时间

问题 #1

定义一个名为 Item 的结构体，包含两个成员： std::string_view name 和 int gold。定义一个 std::array 并用 4 个 Item 对象初始化它。使用 CTAD 推导元素类型和数组大小。

显示提示

提示：你需要为每个初始化器显式指定元素类型。

程序应打印以下内容：

A sword costs 5 gold.
A dagger costs 3 gold.
A club costs 2 gold.
A spear costs 7 gold.

显示答案

#include <array>
#include <iostream>
#include <string_view>

struct Item
{
    std::string_view name {};
    int gold {};
};

template <std::size_t N>
void printStore(const std::array<Item, N>& arr)
{
    for (const auto& item: arr)
    {
        std::cout << "A " << item.name << " costs " << item.gold << " gold.\n";
    }
}

int main()
{
    constexpr std::array store { // CTAD，由于花括号省略使用单层花括号
        Item { "sword",    5 },
        Item { "dagger",   3 },
        Item { "club",     2 },
        Item { "spear",    7 } };
    printStore(store);
    
    return 0;
}

因为我们为每个初始化器显式指定了元素类型，所以我们可以在这里使用 CTAD 和单花括号（由于花括号省略）。

问题 #2

更新你对测验 1 的解决方案，不要为每个初始化器显式指定元素类型。

显示答案

#include <array>
#include <iostream>
#include <string_view>

struct Item
{
    std::string_view name {};
    int gold {};
};

template <std::size_t N>
void printStore(const std::array<Item, N>& arr)
{
    for (const auto& item: arr)
    {
        std::cout << "A " << item.name << " costs " << item.gold << " gold.\n";
    }
}

int main()
{
    constexpr std::array<Item, 4> store {{ // 无CTAD，必须使用双层花括号
        { "sword",    5 },
        { "dagger",   3 },
        { "club",     2 },
        { "spear",    7 }
    }};
    printStore(store);
    
    return 0;
}

因为我们没有为每个初始化器显式指定元素类型，所以我们不能使用 CTAD 或花括号省略。这意味着我们必须使用双花括号。
