15.1 — 隐藏的“this”指针与成员函数链式调用

● 机器译文 课程 15.1 查看英文原文

关于类，新手程序员经常问的一个问题是：“当调用成员函数时，C++ 如何跟踪它是在哪个对象上调用的？”

首先，让我们定义一个简单的类来使用。这个类封装了一个整数值，并提供了一些访问函数来获取和设置该值：

#include <iostream>

class Simple
{
private:
    int m_id{};
 
public:
    Simple(int id)
        : m_id{ id }
    {
    }

    int getID() const { return m_id; }
    void setID(int id) { m_id = id; }

    void print() const { std::cout << m_id; }
};

int main()
{
    Simple simple{1};
    simple.setID(2);

    simple.print();

    return 0;
}

正如你所料，这个程序产生的结果是：

2

不知何故，当我们调用 simple.setID(2);时，C++ 知道函数 setID() 应该操作对象 simple，并且 m_id 实际上引用的是 simple.m_id。

答案是 C++ 使用了一个名为 this的隐藏指针！在本课中，我们将更详细地了解 this

隐藏的 this 指针

在每个成员函数内部，关键字 这个 是一个 const 指针，它保存当前隐式对象的地址。

大多数时候，我们不会显式地提到 this ，但只是为了证明我们可以：

#include <iostream>

class Simple
{
private:
    int m_id{};

public:
    Simple(int id)
        : m_id{ id }
    {
    }

    int getID() const { return m_id; }
    void setID(int id) { m_id = id; }

    void print() const { std::cout << this->m_id; } // 使用 `this` 指针访问隐式对象，并使用 operator-> 选择成员 m_id
};

int main()
{
    Simple simple{ 1 };
    simple.setID(2);
    
    simple.print();

    return 0;
}

这与前面的示例完全相同，并输出：

2

中使用它的值。 print() 前两个示例中的成员函数做的事情完全相同：

    void print() const { std::cout << m_id; }       // 隐式使用 this
    void print() const { std::cout << this->m_id; } // 显式使用 this

事实证明，前者是后者的简写。当我们编译程序时，编译器会隐式地将任何引用隐式对象的成员前面加上 this->。这有助于使我们的代码更简洁，并避免重复显式地编写 this->

提醒

我们使用 -> 从指向对象的指针中选择成员。 this->m_id 等价于 (*this).m_id。

我们介绍 operator-> 在课程 13.12 -- 使用指针和引用选择成员。

如何设置 this ？

让我们仔细看看这个函数调用：

    simple.setID(2);

虽然对函数 setID(2) 的调用看起来只有一个参数，但实际上有两个！编译时，编译器将表达式 simple.setID(2); 重写如下：

    Simple::setID(&simple, 2); // 注意 simple 已从对象前缀变为函数参数！

注意，现在这只是一个标准的函数调用，对象 simple （以前是对象前缀）现在作为参数通过地址传递给函数。

但这只是答案的一半。由于函数调用现在多了一个参数，成员函数定义也需要修改以接受（并使用）这个参数。这是我们的原始成员函数定义 setID()：

    void setID(int id) { m_id = id; }

编译器如何重写函数是实现相关的细节，但最终结果类似于这样：

    static void setID(Simple* const this, int id) { this->m_id = id; }

注意，我们的 setId 函数有一个新的最左边的参数，名为 this，它是一个 const 指针（意味着它不能被重新指向，但指针的内容可以被修改）。 m_id 成员也被重写为 this->m_id，利用 this 指针。

进阶读者

在这种情况下， static 关键字意味着该函数不与类的对象关联，而是被视为类作用域内的普通函数。我们在第 15.7 课——静态成员函数。

中介绍了静态成员函数。

  1. 当我们调用 simple.setID(2)，编译器实际上调用 Simple::setID(&simple, 2)、和 simple 通过地址传递给函数。
  2. 该函数有一个名为 this 的隐藏参数，它接收 simple。
  3. 的地址。setID() 中的成员变量以 this->为前缀，它指向 simple。因此，当编译器计算 this->m_id时，实际上解析为 simple.m_id。

好消息是这一切都是自动发生的，你是否记得它的工作原理并不重要。你只需要记住所有非静态成员函数都有一个 this 指针，指向调用该函数的对象。

关键提示

所有非静态成员函数都有一个 this const 指针，保存隐式对象的地址。

this 始终指向正在操作的对象。

新手程序员有时会困惑于存在多少个 this 指针。每个成员函数都有一个 this 指针参数，指向隐式对象。考虑：

int main()
{
    Simple a{1}; // 在 Simple 构造函数内部，this = &a
    Simple b{2}; // 在 Simple 构造函数内部，this = &b
    a.setID(3); // 在成员函数 setID() 内部，this = &a
    b.setID(4); // 在成员函数 setID() 内部，this = &b

    return 0;
}

中使用它的值。 this 指针交替保存对象 a 或 b 的地址，具体取决于我们是在对象 a 或 b。

因为 this 只是一个函数参数（而不是成员），因此它不会增加类的实例的内存大小。

显式引用 this

大多数情况下，你不需要显式引用 this 指针。然而，在某些情况下这样做可能有用：

首先，如果成员函数有一个与数据成员同名的参数，你可以通过使用 this：

struct Something
{
    int data{}; // 不使用 m_ 前缀，因为这是一个结构体

    void setData(int data)
    {
        this->data = data; // this->data 是成员，data 是局部参数
    }
};

这 Something 类有一个名为 data的成员。 setData() 的函数参数也名为 data。在 setData() 函数内部， data 内部， data 指的是函数参数（因为函数参数隐藏了数据成员），所以如果我们想引用 this->data。

成员，我们使用 this-> 一些开发者喜欢显式地将

添加到所有类成员，以明确他们正在引用一个成员。我们建议你避免这样做，因为它往往会使代码可读性降低而收益甚微。使用“m_”前缀是区分私有成员变量与非成员（局部）变量的一种更简洁的方式。 *this

返回 其次，有时让成员函数返回隐式对象作为返回值可能很有用。这样做的主要原因是允许成员函数“链式调用”，从而可以在单个表达式中对同一个对象调用多个成员函数！这称为 （或 方法链)。

考虑这个常见示例，你使用 std::cout：

std::cout << "Hello, " << userName;

编译器会像这样评估上面的代码片段：

(std::cout << "Hello, ") << userName;

首先， operator<< 使用 std::cout 和字符串字面量 "Hello, " 来打印 "Hello, " 输出到控制台。然而，由于这是表达式的一部分， operator<< 也需要返回一个值（或 void）。如果 operator<< 返回 void，你会得到这个部分求值的表达式：

void{} << userName;

这显然没有意义（编译器会抛出错误）。相反， operator<< 返回传入的流对象，在这里是 std::cout。这样，在第一个 operator<< 求值后，我们得到：

(std::cout) << userName;

然后打印用户的名字。

这样，我们只需要指定 std::cout 一次，然后就可以使用 operator<< 链式连接任意多的文本片段。每次调用 operator<< 返回 std::cout ，所以下一次调用 operator<< 使用 std::cout 作为左操作数。

我们也可以在成员函数中实现这种行为。考虑以下类：

class Calc
{
private:
    int m_value{};

public:

    void add(int value) { m_value += value; }
    void sub(int value) { m_value -= value; }
    void mult(int value) { m_value *= value; }

    int getValue() const { return m_value; }
};

如果你想加5、减3、再乘以4，你必须这样做：

#include <iostream>

int main()
{
    Calc calc{};
    calc.add(5); // 返回 void
    calc.sub(3); // 返回 void
    calc.mult(4); // 返回 void

    std::cout << calc.getValue() << '\n';

    return 0;
}

然而，如果我们让每个函数返回 *this 的引用，我们就可以链式调用。这是新版本的 Calc ，带有“可链式”函数：

class Calc
{
private:
    int m_value{};

public:
    Calc& add(int value) { m_value += value; return *this; }
    Calc& sub(int value) { m_value -= value; return *this; }
    Calc& mult(int value) { m_value *= value; return *this; }

    int getValue() const { return m_value; }
};

注意 add()， sub() 和 mult() 现在返回 *this 的引用。因此，这允许我们执行以下操作：

#include <iostream>

int main()
{
    Calc calc{};
    calc.add(5).sub(3).mult(4); // 方法链

    std::cout << calc.getValue() << '\n';

    return 0;
}

我们实际上将三行代码浓缩成了一个表达式！让我们仔细看看这是如何工作的。

首先， calc.add(5) 被调用，它加上 5 切换到 m_value。 add() 然后返回对 *this的引用，这是对隐式对象 calc，所以 calc 将是后续求值中使用的对象。接下来 calc.sub(3) 求值，它减去 3 从 m_value 并再次返回 calc。最后， calc.mult(4) 将 m_value 乘以 4 赋值并返回 calc，这个结果不再使用，因此被忽略。

由于每个函数在执行时都修改了 calc ， m_value 作为 calc 现在包含值 (((0 + 5) - 3) * 4)，即 8。

这可能是 this最常用的显式用法，当你觉得需要可链式调用的成员函数时，应该考虑使用它。

因为 this 始终指向隐式对象，因此解引用前无需检查它是否为空指针。

将类重置为默认状态

如果你的类有默认构造函数，你可能希望提供一种将现有对象恢复为默认状态的方法。

如前几课所述（14.12 -- 委托构造函数），构造函数仅用于初始化新对象，不应直接调用。这样做会导致未定义行为。

将类重置为默认状态的最佳方法是创建一个 reset() 成员函数，让该函数创建一个新对象（使用默认构造函数），然后将该新对象赋值给当前隐式对象，如下所示：

    void reset()
    {
        *this = {}; // 值初始化一个新对象并覆盖隐式对象
    }

下面是一个完整的程序，演示了 reset() 函数的实际应用：

#include <iostream>

class Calc
{
private:
    int m_value{};

public:
    Calc& add(int value) { m_value += value; return *this; }
    Calc& sub(int value) { m_value -= value; return *this; }
    Calc& mult(int value) { m_value *= value; return *this; }

    int getValue() const { return m_value; }

    void reset() { *this = {}; }
};


int main()
{
    Calc calc{};
    calc.add(5).sub(3).mult(4);

    std::cout << calc.getValue() << '\n'; // 打印 8

    calc.reset();
    
    std::cout << calc.getValue() << '\n'; // 打印 0

    return 0;
}

this 和 const 对象

对于非 const 成员函数， this 是一个指向非 const 值的 const 指针（意味着 this 不能指向其他对象，但指向的对象可以被修改）。对于 const 成员函数， this 是一个指向 const 值的 const 指针（意味着指针不能指向其他对象，指向的对象也不能被修改）。

尝试在 const 对象上调用非 const 成员函数时产生的错误可能有点令人费解：

error C2662: 'int Something::getValue(void)': cannot convert 'this' pointer from 'const Something' to 'Something &'
error: passing 'const Something' as 'this' argument discards qualifiers [-fpermissive]

当我们在 const 对象上调用非 const 成员函数时，隐式的 this 函数参数是一个指向 非 const 对象的 const 指针。但参数的类型是指向 const 对象的 const 指针。将指向 const 对象的指针转换为指向非 const 对象的指针需要丢弃 const 限定符，这不能隐式完成。某些编译器生成的错误信息反映了编译器抱怨被要求执行这样的转换。

为什么 this 是指针而非引用

由于 this 指针始终指向隐式对象（并且除非我们做了导致未定义行为的事情，否则它永远不会是空指针），你可能想知道为什么 this 是指针而不是引用。答案很简单：当 this 被添加到 C++ 时，引用还不存在。

如果 this 如果今天才添加到 C++ 语言中，它无疑会是引用而不是指针。在其他更现代的类似 C++ 的语言中，例如 Java 和 C#， this 被实现为引用。
