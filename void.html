4.2 — Void

● 机器译文 课程 4.2 查看英文原文

Void 是最容易解释的数据类型。基本上， void 意思是“没有类型”！

Void 是我们遇到的第一个不完整类型。一个 不完整类型 是一种已被声明但尚未定义的类型。编译器知道这类类型的存在，但没有足够的信息来确定该类型的对象需要分配多少内存。 void void 是有意不完整的，因为它代表缺少类型，因此无法被定义。

不完整类型不能被实例化：

void value; // 不工作，变量不能定义为不完整的类型 void

void 通常在几种不同的上下文中使用。

不返回值的函数

最常见的是， void void 用于表示函数不返回值：

void writeValue(int x) // 这里的 void 表示没有返回值
{
    std::cout << "The value of x is: " << x << '\n';
    // 没有返回语句，因为这个函数不返回值
}

如果你使用 return 语句尝试在这样的函数中返回值，将导致编译错误：

void noReturn(int x) // 这里的 void 表示没有返回值
{
    std::cout << "The value of x is: " << x << '\n';

    return 5; // 错误
}

在 Visual Studio 2017 中，会产生以下错误：

error C2562: 'noReturn': 'void' function returning a value

已弃用：不接受参数的函数

在 C 语言中，void 被用来表示函数不接受任何参数：

int getValue(void) // 这里的 void 表示没有参数
{
    int x{};
    std::cin >> x;

    return x;
}

尽管这在 C++ 中能编译通过（出于向后兼容的原因），但这种使用关键字 void 在 C++ 中被认为是已弃用的。以下代码是等价的，并且在 C++ 中更推荐：

int getValue() // 空函数参数是隐式的 void
{
    int x{};
    std::cin >> x;

    return x;
}

最佳实践

使用空参数列表代替 void 来表示函数没有参数。

void 的其他用途

void 关键字在 C++ 中有第三种（更高级的）用法，我们将在第 19.5 -- void 指针。由于我们还没有介绍指针是什么，所以你现在不必担心这种情况。
